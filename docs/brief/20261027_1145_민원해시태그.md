# 작업요청서

2026-10-27 | 213am | 상·하수도 행정 민원 메뉴 단순화

## 배경

상·하수도 행정에서 상수·급수·하수·준설 민원을 사이드바 메뉴로 나눠 두면 메뉴가 늘고, 실제로는 같은 민원 업무를 태그로만 구분하면 되는 경우가 많다. 별도 메뉴·대장 분리보다 기존 민원관리 안에서 구분하는 편이 운영에 맞다.

## 활용

1. 상수·하수 담당자가 사이드바 «민원관리» 하나로 관련 민원을 모두 본다.
2. 목록에서 해시태그로 상수·급수·하수·준설 등만 골라 본다.
3. 준설 담당자는 준설민원 상세에서 준설대상지를 이어서 등록·수정한다.
4. 신규 업무 구분이 생겨도 메뉴를 늘리지 않고 태그만 추가한다.

## 필요 기능

1. 상·하수도 행정 사이드바에 공통 «민원관리»를 둔다. 업무별 민원 메뉴는 쓰지 않는다.
2. 민원 등록·수정 시 해시태그로 업무 구분을 붙인다.
3. 목록에서 태그 기준으로 걸러 볼 수 있다.
4. 준설 태그가 붙은 민원 상세에만 준설대상지 영역을 보여 주고, 대상지는 그 민원 하위로 관리한다.
5. 다른 시스템(공간정보 조회 등)의 민원관리는 기존과 같이 유지한다.

## 참고·제약

- 준설대상지는 별도 사이드바 메뉴가 아니라 준설민원 상세 커스텀으로 처리한다.
- 메모관리는 이번 범위에서 다루지 않는다. 필요 시 별도 요청.
- 기존에 나뉘어 있던 업무별 민원 자료는 공통 민원으로 옮기거나 태그로 맞추는 방안을 구현 전에 정한다.
