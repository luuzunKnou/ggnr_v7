# 작업요청서

2026-11-06 | gyujin | —

## 배경

도면 표시는 임시로만 보던 기능이었다. 이제 여러 도면을 올려 목록으로 두고 켜고 끄며 쓰려면 서버에 저장해 새로고침·재접속 후에도 같은 목록을 써야 한다.

## 활용

1. 담당자가 여러 DXF·DWG를 올려 한 지도에서 위치를 비교한다.
2. 목록에서 도면마다 표시를 켜고 끄며 겹침을 조절한다.
3. 패널을 닫으면 지도에서는 끄고, 서버에 남은 목록은 다시 열어 이어서 쓴다.
4. 필요 없는 도면만 목록에서 지운다.

## 필요 기능

1. 파일을 올리면 기존 도면을 덮지 않고 목록에 추가되어야 한다.
2. 여러 파일을 한 번에 고를 수 있어야 한다.
3. 올린 도면은 서버에 저장되어야 한다.
4. 목록 행마다 표시를 켜고 끌 수 있어야 한다.
5. 파일마다 좌표계·도면 안 레이어를 조절할 수 있어야 한다.
6. 행 삭제와 모두 지우기가 있어야 한다.
7. 패널을 닫으면 지도에서 도면이 사라져야 한다.
8. 새로고침 후에도 목록·on/off·좌표계 설정이 유지되어야 한다.
9. 업로드 칸 모양은 데이터 업로드와 같아야 한다.

## 참고·제약

1. 기존 도면 표시·수치지형도와 같은 그리기 방식을 쓴다.
2. 수치지형도(오른쪽)와 함께 켜도 서로 지워지지 않아야 한다.
3. 파일은 데이터 저장 폴더에 두고, 목록 설정은 서버 메타로 관리한다.
