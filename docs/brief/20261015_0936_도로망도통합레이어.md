# 작업요청서

2026-10-15 | dev.strcat | 도로 담당 요청

## 배경

도로망도는 지금까지 도로종류·개설여부별로 나뉜 공간자료 10종을 묶어 보여 주었다. 새로 정비된 도로망 자료는 도로 선 하나와 노선번호 위치 점 하나로 통합되어 있고, 선 안에 고속도로·국도·지방도·국가지원지방도·시군도·면도·리도·농도·철도 등급이 함께 들어 있다. 이 자료가 있는 지역은 통합 자료만으로 도로망도를 보여 주고, 노선번호는 실제 도로 표지판 모양으로 지도에 표시해야 한다.

## 활용

1. 도로 담당자가 도로망도를 열면 통합 자료가 있는 지역에서는 등급별 도로 선과 노선번호 표지를 함께 본다.
2. 담당자가 국도·지방도·군도·농도·철도 탭으로 원하는 등급만 골라 지도와 목록에서 확인한다.
3. 현장 확인 전 노선번호 표지 모양으로 도로 등급을 바로 구분한다.
4. 통합 자료가 없는 지역은 기존 도로망도를 그대로 사용한다.

## 필요 기능

1. 통합 도로 선·노선번호 점 자료가 있으면 기존 10종 대신 통합 자료만 사용한다.
2. 통합 자료의 등급을 기존 도로종류 탭에 묶는다. 고속도로·국도는 국도, 지방도·국가지원지방도는 지방도, 시군도는 군도, 면도·리도·농도는 농도에 넣는다.
3. 철도는 새 «철도» 분류로 목록과 탭에 보인다.
4. 파선·점선 노선은 미개설, 실선 노선은 개설로 본다.
5. 자료가 없는 도로종류 탭은 보이지 않게 한다.
6. 지도의 도로 선에는 라벨을 붙이지 않고 선만 보인다.
7. 노선번호 점 위치에 등급별 표지판 모양으로 번호를 보인다. 고속도로는 위 빨강·아래 파랑 네모, 국도는 파란 원, 지방도·국가지원지방도는 노란 네모, 시군도는 흰 육각형에 파란 글씨, 면·리·농도는 흰 네모에 회색 테두리.
8. 목록·상세·등록·수정·삭제·지도 클릭 선택은 기존과 같은 방식으로 동작한다.

## 참고·제약

통합 자료가 없는 프로젝트는 기존 동작이 바뀌지 않아야 한다. 노선번호 점 자료에는 철도가 없다. 지도 서버 기본 도형에 없는 육각형·두 색 네모는 이미지로 표지 바탕을 만든다. 접도구역 화면의 «도로망도» 켜기 버튼도 같은 기준을 따른다.
