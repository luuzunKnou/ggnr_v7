# 작업요청서

2026-08-25~28 | dev.strcat | —

## 배경

1. 법정동·행정동 코드표는 곧 전국 값이 한곳에 모인다. 프로젝트마다 자기 시군구만 보여야 하는데, 지금은 구분 없이 전부 나온다.
2. 메모관리 목록·상세가 민원관리와 달라 같은 지도 업무에서 쓰는 느낌이 갈린다. 목록은 민원과 비슷한 카드로 맞추고, 추가·상세는 지도를 가리지 않는 떠 있는 패널에서 위치를 찍어 저장할 수 있어야 한다.

## 활용

1. 관리자가 레이어설정 코드에서 법정동·행정동을 열면 해당 시군구만 보고 고친다. 영양·울진처럼 시군구가 다른 프로젝트는 자기 읍면동만 다룬다.
2. 담당자가 사이드바에서 메모관리를 열면 민원과 비슷한 목록으로 메모를 찾는다. 검색으로 제목·내용을 좁혀 보고, 행을 누르면 지도가 해당 점으로 가고 떠 있는 상세에서 제목·내용·위치를 고친다.
3. 추가는 목록을 둔 채 지도 위 패널에서 점을 찍어 등록한다. 저장 직후 주소 글자와 지도 점 표시가 새 위치로 맞춰진다.

## 필요 기능

1. 레이어설정 코드에서 한글명이 법정동 또는 행정동인 필드만 시군구 기준으로 목록을 줄인다. 화면에 안 보이는 다른 시군구 코드는 저장해도 지워지지 않아야 한다.
2. 메모관리 목록 머리글·검색·카드 배치를 민원관리와 같게 한다. 추가·상세는 지도 위 떠 있는 패널이다.
3. 위치는 지도에서 점을 찍고, 칸에는 좌표로 찾은 주소가 나온다. 작성일·작성자는 로그인 값으로 채워지고 고칠 수 없다.
4. 민원 위치는 주소 검색만 쓰고, 메모만 지도 점 찍기를 쓴다.

## 참고·제약

1. 지금은 코드표에 안동만 들어 있어, 영양·울진에서는 해당 목록이 비어 보일 수 있다. 전국 코드를 넣은 뒤에 해당 시군구만 나타난다.
2. 점 찍는 동안 다른 지도 식별 클릭은 받지 않는다.
3. 지도 부서업무 쪽 필터는 이번 범위에 넣지 않고, 같은 기준을 나중에 재사용한다.
