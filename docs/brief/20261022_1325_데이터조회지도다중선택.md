# 작업요청서

2026-10-22 | gyujin | —

## 배경

데이터조회에서 레이어를 켠 뒤 지도를 클릭하면, 한 점에 여러 건이 겹칠 때 오른쪽 목록이 식별 결과로 바뀐다. 기존 목록에서 해당 건이 어디 있는지 찾기 어렵고, 닫기도 이전이 되어 창이 바로 닫히지 않는다.

## 활용

1. 담당자가 레이어를 켜고 지도에서 겹친 시설·도형을 고를 때, 클릭한 위치의 후보를 지도 위에서 바로 본다.
2. 후보 중 하나를 고르면 기존 목록 화면의 해당 페이지·항목으로 이동해 상세를 본다.
3. 후보 창을 닫으면 목록은 그대로 두고 지도 위 창만 바로 닫는다.

## 필요 기능

1. 레이어가 켜진 상태에서 지도 클릭 결과가 여러 건이면, 선택한 목록이 지도 위에 떠야 한다.
2. 지도 위 목록에서 한 건을 고르면 기존 데이터 목록 화면에서 그 항목이 있는 페이지로 이동하고 상세가 열려야 한다.
3. 한 건만 맞으면 지도 위 목록 없이 기존 목록의 해당 항목으로 바로 이동해야 한다.
4. 지도 위 목록의 닫기는 창만 바로 닫고, 목록 화면을 바꾸거나 이전으로 돌아가지 않아야 한다.

## 참고·제약

1. 키워드·도형 검색 결과 목록은 이번 범위에서 바꾸지 않는다.
2. 시설관리 지도 클릭은 기존처럼 둔다.
3. 다른 메뉴(민원·메모·측정) 전환 시 검색창·패널 배치는 기존과 같아야 한다.
