# 작업요청서

2026-10-15 | luuzunKnou | —

## 배경

관망 도형의 연결·유수방향이 어긋나면 단수·송수 분석이 어긋난다. 공간분석에서 한 번에 오류 위치를 지도와 목록으로 보고 싶다.

## 활용

1. 관망 정비 담당자가 위상검증을 실행해 오류 지점을 확인한다.
2. 목록에서 항목을 고르면 지도에서 해당 위치를 본다.
3. 접합·유수방향 문제를 구분해 수정 우선순위를 잡는다.

## 필요 기능

1. 위상검증 실행 시 오류를 지도에 모두 표시하고 목록으로 보여 준다.
2. 오류 구분은 «접합확인필요»와 «유수방향 확인필요»이다.
3. 배수지·정수장·제수변·유량계·계량기에 연결된 관로가 없으면 접합확인필요로 시설 위치를 표시한다.
4. 유수방향이 한쪽으로 이어지지 않고 양쪽에서 만나면 유수방향 확인필요로 표시한다.
5. 정수장·배수지에서 계량기로 가야 할 방향이 반대로 도화된 관로도 유수방향 확인필요로 표시한다.

## 참고·제약

유수방향은 관로 도형 시작→끝을 기준으로 한다. 세션만 유지한다.
