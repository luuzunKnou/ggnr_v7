# 작업요청서

2026-09-11 | dev.strcat | 지도 내 정보

## 배경

내 정보와 더보기를 나눠 두면 즐겨찾기와 기본 기능을 보려면 화면을 바꿔야 한다. 촬영요청·알림을 같은 칸에서 펼치면 아래 즐겨찾기가 밀린다.

## 활용

1. 담당자가 한 칸에서 내 정보·즐겨찾기·기본 기능을 본다.
2. 자주 쓰는 업무는 즐겨찾기에서 바로 들어간다.
3. 공지·자료실처럼 부서 메뉴에 없는 기본 기능만 아래에서 고른다.
4. 촬영요청·알림은 옆 칸으로 열어 본문을 가리지 않는다.

## 필요 기능

1. 내 정보와 더보기를 한 화면으로 합친다. 위쪽 구간 나누기는 없앤다.
2. 알림 단추 아래에 즐겨찾기를 둔다.
3. 그 아래에는 시스템에 없는 기본 기능만 보이게 한다. 부서별 전체 목록은 빼 둔다.
4. 촬영요청·알림을 누르면 바로가기 설정처럼 오른쪽에 같은 너비의 칸이 열린다.
5. 즐겨찾기와 바로가기 설정은 이전처럼 동작한다.

## 참고·제약

사이드바 메뉴는 그대로 둔다. 바로가기 설정에서 부서 기능을 즐겨찾기에 넣는 것은 유지한다.
