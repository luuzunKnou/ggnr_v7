# 작업요청서

2026-11-24 | dev.strcat | 도로관리 — 도로대장 도로영상

## 배경

도로영상 위치 맞춤은 서버가 자동으로 맞추지만, 영상이 둘 이상으로 나뉘어 이어 붙이거나 직선·분기가 많은 구간에서는 지도 차 위치가 장면과 어긋날 수 있다. 담당자가 어긋남을 확인했을 때 직접 기준을 남겨 다시 맞출 수 있어야 한다.

## 활용

1. 개발·관리 계정으로 도로영상을 보며 자동 맞춤이 틀린 구간을 확인한다.
2. «수동 기준점»으로 지도에서 실제 위치를 찍고, 그 장면의 영상 시각을 적어 저장한다.
3. «다시 분석»으로 서버가 그 기준을 반영해 위치를 다시 맞춘다.
4. 일반 담당자는 기존처럼 자동 맞춤 결과만 본다.

## 필요 기능

1. 영상이 처음 들어오면 지금처럼 서버가 자동으로 위치를 맞춘다.
2. 관리 계정만 도로영상 창에서 «수동 기준점» 단추를 쓸 수 있다.
3. 단추를 누르면 지도 노선 위를 클릭해 위치를 정하고, 시간을 입력해 저장한다. 시간은 현재 재생 시각을 기본으로 두고 고칠 수 있다.
4. 기준점은 여러 개 둘 수 있고, 목록에서 지울 수 있다. 다시 맞춰도 기준점은 남는다.
5. «다시 분석»을 누르면 대기열에 넣어 서버가 기준점을 반영해 다시 맞춘다.
6. 상행·하행처럼 이어 재생하는 영상도 이어진 시각으로 찍고, 분석 시에는 맞게 나눠 반영한다.

## 참고·제약

1. 권한은 기존 분석 요청과 같이 슈퍼 계정만.
2. 자동으로 만든 시각별 위치 자료와 수동 기준점은 따로 둔다.
3. 예전에 미뤄 두었던 슈퍼계정 기준점 보정을 이번에 넣는다.
