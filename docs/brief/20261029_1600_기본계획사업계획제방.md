# 작업요청서

2026-10-29 | dev.strcat | —

## 배경

기본계획 상세에서 색인도·구조물·종단·횡단은 볼 수 있으나, 사업 구간(제방)을 색인도 도면과 함께 목록으로 보는 경로가 없다. 도면에 보이는 «보축1지구 (L=1,077m)» 같은 표기를 화면에서도 맞춰야 한다.

## 활용

1. 하천 담당자가 기본계획 상세에서 «사업계획»으로 해당 색인도 도면과 제방 목록을 한 화면에서 본다.
2. 목록에서 제방을 고르면 지도에서 위치·구간을 바로 확인한다.
3. 제방 이름·연장을 지도 라벨로 확인해 현장·보고서 작업에 쓴다.

## 필요 기능

1. 상세 상단 버튼을 두 줄(각 6칸)로 두고 둘째 줄에 «사업계획»을 둔다.
2. «사업계획»을 누르면 제방 레이어를 켜고 색인도 도면·목록 화면으로 들어간다.
3. 목록 제목은 «사업계획목록»이며 1차는 제방만 보여 준다.
4. 제방 표시는 이름과 연장(예: 보축1지구 (L=1,077m))을 목록·지도 라벨에 쓴다.
5. 목록 행을 누르면 색인도와 같이 강조·지도 이동이 된다.

## 참고·제약

기존 색인도 상세목록(종단·횡단·구조물·제방)은 유지한다. 사업계획으로 들어올 때만 목록을 제방으로 한정한다.
