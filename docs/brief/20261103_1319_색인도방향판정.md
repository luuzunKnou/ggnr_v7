# 작업요청서

2026-11-03 | dev.strcat | 하천기본계획 색인도 화면

## 배경

하천기본계획 상세의 색인도 도면(PDF)이 지도와 방향이 맞지 않게 뒤집히거나 옆으로 누워 보이는 장이 있다. 왕피천은 장마다 회전이 제각각이고, 같은 도면도 썸네일과 전체화면의 방향이 다르게 나온 적이 있다. 지금은 도면을 열 때마다 화면에서 방향을 추정하는데, 등고선·글자까지 함께 비교해 판단이 흔들린다.

## 활용

1. 하천 담당자가 색인도를 열면 지도에 보이는 하천 모양과 같은 방향으로 도면을 본다.
2. 시스템 관리자가 프로젝트를 새로 올릴 때 색인도 방향을 한 번에 판정해 두고, 판정이 애매한 장만 골라 검토한다.
3. 시스템 관리자가 판정이 틀린 장을 지도 모습과 나란히 보며 바로잡고, 바로잡은 결과는 다시 판정해도 유지된다.
4. 다른 프로젝트(울진·영덕 등)에서도 같은 방법으로 색인도 방향을 맞춘다.

## 필요 기능

1. 색인도 칸 안의 하천 모양(지도)과 도면 속 하천 모양(PDF)을 비교해 네 방향 중 맞는 방향을 고른다.
2. 판정 결과(방향·확신도·판정 방법)를 색인도별로 저장하고, 화면은 저장된 방향으로 썸네일과 전체화면을 같게 보여 준다.
3. 프로젝트의 색인도 전체(지방하천·소하천)를 한 번에 판정하고 진행 상황을 보여 준다.
4. 확신도가 낮은 장부터 지도 모습과 도면을 나란히 보여 주는 검토 화면을 둔다.
5. 검토 화면에서 사람이 방향을 바로잡아 확정하고, 다시 판정해도 사람이 확정한 값은 덮어쓰지 않는다.
6. 판정 결과가 없는 장은 지금처럼 화면에서 방향을 추정한다.

## 참고·제약

1. 도면의 수면은 하늘색으로 칠해져 있어 하천 모양을 뽑는 기준으로 쓴다. 업체마다 색이 다를 수 있어 색 기준을 조정할 수 있게 한다.
2. 보고서 원본 PDF 파일은 수정하지 않는다. 판정 결과는 색인도 첨부 폴더 옆 파일로 따로 저장한다. (PDF 자체 정리는 검토가 끝난 뒤 별도 결정)
3. 색인도 PDF는 네트워크 공유 폴더에 있어 전체 판정은 시간이 걸린다. 화면 응답을 막지 않도록 서버 뒤에서 돌린다.
