# 작업요청서

2026-07-23 | gyujin | —

## 배경

울진 하천점용 데이터는 기존 부과대장 형태와 달리 점용대장 테이블로 관리된다. 공통 하천점용 메뉴는 부과대장 테이블을 전제로 하여 울진에서 사용할 수 없다.

## 활용

1. 울진 하천 담당자가 지도에서 점용 허가 목록을 검색·조회한다.
2. 행을 선택해 해당 점용 위치로 지도를 이동한다.
3. 상세에서 허가번호·하천명·점용위치·점용자 등 속성을 확인·수정한다.
4. 다른 시군의 부과대장 기반 하천점용과는 메뉴·데이터를 분리해 혼선을 막는다.

## 필요 기능

1. 울진 전용 하천점용 메뉴 (점용대장 기준)
2. 목록 검색·선택·지도 이동
3. 상세 속성 조회 및 등록·수정·삭제
4. 점용대장 레이어 자동 표시
5. 울진에서만 해당 메뉴 노출, 기존 부과대장 하천점용은 숨김

## 참고·제약

기존 하천점용 UI·패널 패턴을 참고한다. 필지목록·물건지 자식 테이블은 울진 원본에 없으므로 본 기능 범위에서 제외한다.
