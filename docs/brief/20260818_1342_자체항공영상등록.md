# 작업요청서

## 배경

영상관리 «항공영상»은 목록·상세가 목업이다. 폴더 구분이 항공영상이면 드론영상과 같이 올리고 변환해야 하는데, 변환 결과는 드론영상 지도 체크가 아니라 배경지도 «자체항공영상»에 올라가야 한다.

## 활용

1. 승인·등록 담당자가 항공영상 작업단위 폴더를 만들고 TIF를 올린다.
2. 변환이 끝나면 배경지도 «자체항공영상»에서 해당 영상을 켜고 끈다.
3. 영상관리 항공영상 목록에서 작업단위·변환 상태를 확인한다.

## 필요 기능

1. 폴더 구분이 항공영상이면 드론영상과 같은 업로드·변환 흐름으로 진행한다.
2. 변환 완료 자료는 배경지도 «자체항공영상» 목록에 등록된다.
3. 항공영상 목록에는 지도 체크가 없고, 표시 on/off는 배경지도에서만 한다.
4. 영상관리 항공영상 목록·상세는 실저장 자료를 보여 준다.

## 참고·제약

- 드론영상 변환 산출·지도 체크 방식은 바꾸지 않는다.
- 사진·동영상·파노라마 흐름은 이번 범위 밖이다.
- 기존 배경지도 «자체항공영상» 표시 규칙을 재사용한다.
