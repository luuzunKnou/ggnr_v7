# 작업요청서

2026-09-14 | JungWooojin | UAV · 정책지도 바로가기

## 배경

정책지도·HTML 자료를 올려 두고 누구나 쉽게 열어 보게 할 공간이 필요하다. 일반 공지·자료실과는 별도로, UAV에서만 쓰는 바로가기가 맞다.

## 활용

1. 로그인한 담당자가 정책지도 묶음(압축 파일)을 올린다.
2. 동료가 내정보 공통의 «정책지도 바로가기»에서 목록을 보고 연다.
3. 올린 자료는 제목으로 찾아 새 창처럼 열어 쓴다.

## 필요 기능

1. uav_ulsan일 때만 내정보 «공통»에 «정책지도 바로가기» 표시
2. 로그인 사용자 누구나 제목과 압축 파일을 올려 등록
3. 목록에서 열어 보기(HTML·구성 파일 함께 표시)
4. 본인 또는 관리 가능한 경우 삭제

## 참고·제약

첨부 한 장보다 압축(zip) 업로드가 맞다. 다른 프로젝트 공통 메뉴에는 넣지 않는다.
