# 작업요청서

2026-09-11 | dev.strcat | 재난안전 · 물놀이 표지판

## 배경

목록 검색 옆에 따로 있는 초기화 단추가 번거롭고, 구조함·표지판 점을 한꺼번에만 켜서 구분해서 보기 어렵다.

## 활용

1. 검색어가 있을 때 칸 안 엑스만 눌러 검색을 비운다.
2. 전체·구조함·표지판을 눌러 지도에 보이는 점 종류를 고른다.
3. 축소·확대하며 선택한 종류만 개수 묶음·개별 위치를 본다.

## 필요 기능

1. 검색 칸 안에 엑스를 두고, 옆의 초기화 단추는 없앤다.
2. 검색 옆에 전체·구조함·표지판 단추를 둔다.
3. 전체는 구조함·표지판 점을 모두 켠다.
4. 구조함만 고르면 구조함 점만, 표지판만 고르면 표지판 점만 지도에 보인다.
5. 목록·읍면동·구분 필터는 그대로 둔다.

## 참고·제약

점사용료 목록의 검색·상태 단추 배치를 참고한다. 관리지역 토글은 이번 범위에서 바꾸지 않는다.
