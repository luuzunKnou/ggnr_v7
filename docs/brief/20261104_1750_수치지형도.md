# 작업요청서

2026-11-04 | gyujin | —

## 배경

수치지형도 도면이 데이터 폴더에 도엽 단위로 쌓여 있으나, 지도에서는 파일을 일일이 올려야만 볼 수 있다. 우측 레이어처럼 켜고 끄며 현재 화면 주변 도엽을 바로 보고 싶다.

## 활용

1. 지적·측량 담당자가 현장 확인 전 수치지형도 도엽을 지도 위에서 겹쳐 본다.
2. 주제도·지적도와 함께 켜 두어 지형·시설 맥락을 함께 확인한다.
3. 필요한 축척(폴더)만 선택해 불필요한 도엽 로드를 줄인다.

## 필요 기능

1. 지도 우측 주제도 아래에 «수치지형도» 버튼을 둔다.
2. 버튼을 누르면 데이터 폴더 아래 하위 폴더 목록이 레이어처럼 체크 목록으로 나온다.
3. 폴더를 켜면 그 안의 도면이 지도에 표시되고, 끄면 사라진다. 패널을 닫아도 켠 폴더는 지도에 남고 버튼이 켜진 상태로 보인다.
4. 도면을 지도에 그리는 방식은 기존 «도면 표시»와 같다.
5. 폴더에 도엽이 매우 많을 수 있으므로, 현재 지도 화면에 들어오는 도엽만 불러온다. 너무 멀리 축소한 상태에서는 안내하고 확대 후 표시한다.

## 참고·제약

1. 도면 원본 위치는 데이터 루트의 수치지형도 전용 폴더이다.
2. 서버에 도엽을 레이어로 등록하지 않으며, 세션에서만 표시한다.
3. 기존 왼쪽 메뉴 «도면 표시»(파일 업로드)와 병행한다.
