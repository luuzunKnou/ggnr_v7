# 작업요청서

2026-11-19 | JungWooojin | 경산 도로행정팀 자료(국공유재산 사용허가 대장)

## 배경

도로행정팀에서 관리하는 국·공유재산 사용허가 대장이 엑셀로만 있어, 지도에서 허가 건을 찾고 기간·사용료를 확인하기 어렵다. 점용대장과는 업무 개념이 다르므로 별도 기능으로 본다.

## 활용

1. 도로행정 담당자가 국유·공유 허가 건을 목록에서 검색·필터한다.
2. 상세에서 허가 정보·소재지·당해 사용료를 확인한다.
3. 지도에서 해당 위치를 확인한다.
4. 이후 실데이터·도형 연동 전에 화면 흐름을 검증한다.

## 필요 기능

1. 사이드바에서 «국공유재산 사용허가»를 열어 목록·상세를 본다.
2. 국유/공유·진행중/종료로 걸러 볼 수 있다.
3. 상세에 허가 본문·필지·사용료(당해) 구역이 있다.
4. 행 선택 시 지도에 위치가 표시된다.
5. 점용대장과 데이터·메뉴를 섞지 않는다. 화면 구성만 참고한다.

## 참고·제약

프로토타입은 메모리 목업이다. 경산 엑셀 양식(국유·공유 시트)을 표본으로 쓴다. DB·반입·점사용료 연계는 후속.
