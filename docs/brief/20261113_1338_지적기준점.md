# 작업요청서

2026-11-13 | gyujin | —

## 배경

지적측량·현장 확인 시 지적삼각점·지적삼각보조점·지적도근점 위치를 지도에서 바로 찾을 필요가 있다. 지금은 종류별로 모아 보고 상세를 보는 화면이 없다.

## 활용

1. 지적 담당자가 종류별로 기준점 목록을 보고 위치를 확인한다.
2. 현장 출장 전 점번호·좌표·위치설명으로 목적지를 찾는다.
3. 지도에서 점을 눌러 상세 속성을 확인한다.

## 필요 기능

1. 공간정보조회 메뉴에 «지적기준점»을 둔다.
2. 종류(지적삼각점·지적삼각보조점·지적도근점)별로 목록을 걸러 본다.
3. 점번호·주소·위치설명으로 검색한다.
4. 지도에 종류별 색으로 위치를 표시한다.
5. 목록 또는 지도에서 고르면 상세(번호·종류·좌표·표고·위치설명·관리기관·비고)를 본다.
6. 이번은 조회만 한다. 등록·수정·점검·사진 첨부는 하지 않는다.

## 참고·제약

실데이터·테이블은 아직 없다. 안동 일원 임시 자료로 화면을 맞춘다. 드론용 지상기준점(GCP)과 메뉴·자료를 섞지 않는다.
