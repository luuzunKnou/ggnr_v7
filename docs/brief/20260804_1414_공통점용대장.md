# 작업요청서

2026-08-04 | dev.strcat | 공통 점용대장

## 배경

점용대장은 하천·도로·국공유지 등 여러 시스템에서 쓰이는데, 지금은 울진 하천만 실데이터 화면이 있고 나머지는 공통 골격이 없다. 화면·동작은 하나로 맞추되, 데이터는 레이어를 시스템·사업별로 따로 두는 편이 중간 적재·교체가 쉽다. 울진 하천만 이미 쓰는 테이블 이름을 유지하면 되고, 기능 동작은 그 화면과 완전히 같아야 한다.

## 활용

1. 하천·도로·국공유지 담당자가 각자 시스템에서 같은 점용대장 목록·상세·지도 연동을 쓴다.
2. 사업(울진·안동 등)과 시스템마다 설정으로 읽을 레이어만 바꿔, 데이터 받는 쪽은 레이어 단위로 넣는다.
3. 필지·물건지 도형도 같은 규칙으로 붙여 지도에서 함께 본다.
4. 점사용료·연계는 이번 범위에서 바꾸지 않는다.

## 필요 기능

1. 점용대장 기능 동작(목록·검색·상세·지도 클릭·레이어 켜기)은 지금 울진 하천점용과 동일해야 한다.
2. 공통 컬럼으로 키, 공사명(점용명), 점용장소, 점용목적, 점용 시작일·종료일, 점용면적, 허가번호·허가일자, 신청자명·전화번호·신청자 주소, 담당자명, 상태, 비고, 도형을 담는다. (점용장소와 신청자 주소는 서로 다른 항목으로 둔다.)
3. 데이터는 스키마 고정 레이어에 두고, 기본은 시스템별 점용대장 레이어를 따로 둔다. 필지·물건지는 본대 뒤에 지적·물건지 접미로 붙인다. 레이어를 나누면 중간 데이터 받기가 쉽다.
4. 설정은 사업(울진·안동 등)과 시스템별로 실제 테이블을 지정한다. 울진 하천만 예외로 지금 쓰는 점용 테이블 이름을 가리키고, 그 외는 시스템별 점용대장 레이어를 가리킨다.
5. 기능관리에는 공통 점용대장 서비스로 등록하고, 서비스·파일·레이어 이름이 달라도 위 설정으로 화면이 올바른 레이어에 연결되게 한다.
6. 목록에서 검색·행 선택·상세 열기, 지도에서 점용·지적·물건지 클릭 시 같은 건이 선택되어야 한다.

## 참고·제약

점사용료는 이번 작업에서 변경하지 않는다. 울진 하천 기존 점용 데이터는 이름 바꾸거나 옮기지 않고, 설정으로만 연결한다. 안동 등 다른 사업은 시스템별 점용대장 레이어에 새로 적재한다.
