# 작업요청서

2026-10-01 | dev.strcat | 사유지분석 도로 확장 요청

## 배경

하천 사유지분석은 하천구역 레이어를 하천별로 시작·끝 두 선으로 잘라 쓰는 방식이라 그대로 유지한다. 도로는 전용 구역 레이어가 없어 실폭도로 레이어를 써야 하는데, 실폭도로는 도형이 잘게 나뉘고 서로 겹쳐 있어 두 선만으로는 교차로·갈림길 범위를 정할 수 없다. 다른 도로를 범위에 넣으려 할 때 하천의 지류처럼 따로 붙이는 방식이 되면 범위가 불분명해진다.

## 활용

1. 도로 담당자가 도로행정 업무지원시스템에서 특정 도로 구간·교차로에 걸친 사유지 필지를 조회한다.
2. 교차로처럼 여러 방향으로 뻗는 도로는 뻗어나가는 방향마다 경계선을 그어 닫힌 범위를 만든다.
3. 겹친 도로·갈라지는 도로도 하나로 합친 도로 면에서 범위를 정해 누락 없이 필지를 뽑는다.
4. 분석 결과 필지 목록과 소유구분으로 보상·매입 검토 자료를 만든다.

## 필요 기능

1. 도로행정 업무지원시스템 사이드바에 «사유지분석»을 추가한다.
2. 분석 구역 선택에서 «실폭도로» 하나만 고를 수 있게 한다.
3. 실폭도로는 원래 레이어 대신, 화면 안 도로 도형을 하나로 합친 통짜 면으로 보여 준다.
4. 사용자가 도로를 가로지르는 경계선을 2개 이상 원하는 만큼 찍어 닫힌 범위를 만든다.
5. 모든 경계선에 둘러싸인 도로 면만 범위로 잡고, 범위가 닫히지 않으면 뻗어나가는 도로에 선을 더 찍으라고 안내하며 적용을 막는다.
6. 마지막 선 되돌리기, 다시 지정, 취소를 제공한다.
7. 적용 시 바로 필지 분석까지 진행하고 결과 목록·상세는 하천과 동일하게 쓴다.

## 참고·제약

하천 사유지분석의 두 선·지류 방식은 바꾸지 않는다. 실폭도로는 도로 전체 범위가 넓어 화면이 너무 넓으면 합친 면을 만들지 않고 확대를 안내한다. 범위는 실폭도로 원래 도형 안쪽만 잡는다. DB 테이블 추가·변경은 없다.
