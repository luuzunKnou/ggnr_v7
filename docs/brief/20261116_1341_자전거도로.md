# 작업요청서

2026-11-16 | dev.strcat | 도로 부서업무 · 프로토타입

## 배경

도로 시스템에 자전거 도로 부서업무가 필요하다. 도로망도는 도로명 중심이지만, 자전거 도로는 «시점~종점» 노선 개념으로 먼저 보고, 그 안의 세부 구간을 나눠 보는 방식이 맞다. 1차는 목 데이터 프로토타입으로 화면·흐름을 잡는다.

## 활용

1. 도로 담당자가 자전거 도로 노선(시점~종점)을 목록에서 바로 찾는다.
2. 노선을 열어 연장·진행방향·시점·종점·교량·지하철역·비고를 확인한다.
3. 노선 아래 구간(일련번호·노선명·연장)을 보고 구간을 고른다.
4. 구간을 누르면 기존 부서업무처럼 모달로 구간 상세(폭원 등)를 본다.
5. 첨부파일은 노선(또는 구간) 단위로 확인한다.

## 필요 기능

1. 사이드바에서 «자전거도로»를 켜면 왼쪽 목록에 노선이 보인다. 목록 제목은 «삼성현로(대구시계) ~ 대학로(압량농협네거리)»처럼 시점~종점 형태다.
2. 노선 행을 누르면 우측(또는 상세)에 속성·구간 목록·첨부가 열린다.
3. 노선 속성: 연장, 진행방향, 시점, 종점, 교량, 지하철역, 비고.
4. 구간 목록: 일련번호, 노선명, 연장만 표로 보여 준다. (이미지의 폭원 등은 구간 상세로)
5. 구간 행 클릭 시 모달로 구간 상세를 연다. 폭원(전용·겸용 분리형/비분리형 등)은 구역을 나눠 보여 준다.
6. 도로망도와 비슷한 목록↔상세·첨부 느낌으로 맞추되, 목록 키는 도로명이 아니라 시점~종점 노선이다.
7. 1차는 목 데이터·화면 프로토타입. 실DB·지도 연동은 이후.

## 참고·제약

도로망도(목록·상세·구간·모달) 패턴을 참고한다. 자전거도로는 `_mapContents/road/` 아래 별도 기능 폴더로 둔다. 구간 상세 폭원 항목은 제공 이미지(일련번호·노선명·기점·종점·종류·연장·폭원 구분)를 기준으로 한다.
