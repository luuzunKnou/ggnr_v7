# 작업요청서

2026-09-11 | dev.strcat | 재난안전 · 물놀이 표지판

## 배경

구조함과 표지판을 같은 그림으로 두면 한눈에 구분이 안 된다. 축소해서 보면 점이 겹쳐 어디가 많은지 알기 어렵다.

## 활용

1. 담당자가 축소된 지도에서 지역별 개수를 보고 밀집 구간을 찾는다.
2. 확대해 가며 개수 묶음이 풀리고 개별 위치를 확인한다.
3. 파란 그림은 표지판, 주황 그림은 구조함으로 바로 구분한다.

## 필요 기능

1. 표지판 점은 파란 그림, 구조함 점은 주황 그림으로 구분한다.
2. 지도가 축소되면 가까운 점을 묶어 개수를 보여 준다. 글자는 묶음에만 낸다.
3. 확대하면 묶음이 풀리고 개별 위치가 그림으로 보인다.
4. 표지판과 구조함은 종류별로 따로 묶는다.

## 참고·제약

기존 표지판 그림을 유지하고, 구조함만 색·안쪽 모양을 바꾼다. 개별 점에는 주소를 붙이지 않는다.
