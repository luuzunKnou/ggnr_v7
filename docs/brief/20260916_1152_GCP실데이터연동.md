# 작업요청서

2026-09-16 | JungWooojin | —

## 배경

GCP 메뉴는 시험용 목록만 쓰고 있어, SHP로 올린 실제 기준점 자료와 연결되지 않는다. 업로드된 레이어를 목록·상세·지도·등록·수정에 바로 써야 한다.

## 활용

1. 담당자가 GCP 메뉴에서 업로드된 기준점 전체를 지도와 목록으로 확인한다.
2. 점을 골라 번호·좌표·위치설명을 보고 수정한다.
3. 지도에서 위치를 찍어 새 기준점을 등록한다.

## 필요 기능

1. 업로드된 GCP 레이어에서 목록을 불러온다.
2. 상세에서 속성·위치를 보고 수정한다.
3. 지도에 실좌표로 점을 표시하고 선택한다.
4. 새 기준점 등록 시 지도 클릭 위치를 저장한다.
5. 시험용 가짜 목록은 쓰지 않는다.

## 참고·제약

- 사진은 DB에 없으므로 이번엔 표시만 비워 둔다.
- 주소 컬럼이 없으면 목록은 위치설명 중심으로 두고, 상세 주소는 화면에서만 역검색할 수 있다.
- 점검·상태 기능은 이미 제외된 상태를 유지한다.
