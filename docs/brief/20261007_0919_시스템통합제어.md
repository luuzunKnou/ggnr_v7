# 작업요청서

2026-10-07 | gyujin | —

## 배경

필지정보 소유자명 마스킹 여부를 실행 설정 파일(시스템 변수)에서 관리하고 있어, 운영 중 켜고 끄려면 설정 파일을 직접 고쳐야 한다. 기존 시스템과 같이 통합제어 값으로 관리하고, 개발자 모드 화면에서 바로 바꿀 수 있어야 한다.

## 활용

1. 최고 관리자(su)가 개발자 모드 시스템관리 메뉴에서 개인정보 마스킹을 켜고 끈다.
2. 기관 개인정보 정책이 바뀌었을 때 재배포 없이 즉시 반영한다.
3. 마스킹이 켜지면 모든 사용자(최고 관리자 포함)에게 필지정보 소유자명이 가려져 보인다.

## 필요 기능

1. 개발자 모드 «시스템관리» 그룹에 «시스템 통합제어» 메뉴를 추가한다.
2. «시스템 통합제어» 메뉴는 최고 관리자(su)에게만 보이고, 다른 계정은 조회·변경할 수 없다.
3. 통합제어 항목별로 켜기·끄기를 바꾸고 즉시 저장한다.
4. 첫 항목으로 «개인정보 마스킹»(필지정보 소유자명 * 처리)을 둔다.
5. 값은 통합제어 테이블에 저장하고, 시스템 변수에서는 제거한다.

## 참고·제약

기존 시스템의 통합제어 테이블(항목명·값)을 그대로 사용한다. 테이블이 없으면 처음 사용할 때 생성한다. 개발자 모드에 들어가더라도 su 계정으로 로그인하지 않았으면 «시스템 통합제어»는 보이지 않아야 한다.
