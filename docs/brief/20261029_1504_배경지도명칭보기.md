# 작업요청서

2026-10-29 | gyujin | —

## 배경

항공영상은 사진만 보여 도로·지명 등 위치를 바로 알기 어렵다. 배경지도를 고를 때 명칭을 겹쳐 볼 수 있어야 하고, 항공영상을 켜면 따로 조작하지 않아도 명칭이 나와야 한다.

## 활용

1. 지적·도시·도로 담당자가 항공영상으로 현장을 볼 때 지명·도로명으로 위치를 바로 확인한다.
2. 민원 위치·현장 출장 전 항공영상과 명칭을 함께 보고 지번·도로를 찾는다.
3. 명칭이 가릴 때는 체크를 끄고 영상만 본다.

## 필요 기능

1. 배경지도 패널에 «명칭보기» 체크가 있어야 한다.
2. 항공영상(자체항공영상 포함)을 고르면 명칭보기가 자동으로 켜져야 한다.
3. 체크를 끄면 명칭이 지도에서 사라져야 한다.
4. 명칭은 다음 영상 타일을 겹쳐 보여야 한다.

## 참고·제약

1. 명칭 타일 주소는 다음 하이브리드 영상 경로를 쓴다.
2. 일반지도·지형도는 이미 글자가 있으므로, 항공영상으로 바꿀 때만 자동으로 켠다.
3. 2D 지도를 우선한다. 지도분할 우측도 같은 체크를 따른다.
