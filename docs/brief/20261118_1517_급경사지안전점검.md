# 작업요청서

2026-11-18 | JungWooojin | 경산 도로관리

## 배경

급경사지 안전점검 결과를 한글 체크리스트 서식으로 관리하는데, 지도 시스템에서는 목록과 상세를 바로 보기 어렵다. 접도구역 건축물·불법점용 관리카드처럼 서식 모양의 상세를 지도 기능으로 두는 것이 필요하다.

## 활용

1. 도로·시설 담당자가 급경사지 점검 이력을 지도 옆에서 목록으로 찾는다.
2. 상세에서 한글 점검표와 같은 칸으로 결과를 확인한다.
3. 필요 시 항목을 고치고 인쇄·파일로 남긴다.
4. 선택한 급경사지 위치를 지도에서 바로 확인한다.

## 필요 기능

1. 사이드바에 «급경사지 안전점검» 메뉴를 둔다.
2. 왼쪽 목록에서 지구·장소를 고른다.
3. 오른쪽에 안전점검표 서식(기본정보·체크·세부내용·사진)을 보여 준다.
4. 조회와 편집·저장(프로토타입)을 지원한다.
5. 단건 인쇄·파일 저장이 서식과 비슷하게 된다.
6. 목록에서 고른 건의 위치가 지도에 강조된다.

## 참고·제약

1차는 프로토타입(예시 자료)만. 실제 저장소·도면 연동·한글 원본 불러오기는 하지 않는다. 참고 서식은 급경사지 안전점검 체크리스트(서식)이다.
