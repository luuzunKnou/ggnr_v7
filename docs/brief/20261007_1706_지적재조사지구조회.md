# 작업요청서

2026-10-07 | gyujin | 안동시 토지정보과 지적재조사

## 배경

지적재조사 지구 현황은 바른땅 시스템에서만 볼 수 있고, 지도 위에서 지구 위치와 필지를 함께 보기 어렵다. 바른땅은 지구 경계 도형 내려받기를 제공하지 않고, 브이월드 지구 외곽경계는 2024년까지만 있으며, 토지행정망 연계 목록에도 지적재조사 지구 레이어가 없다. 데이터 확보 방식이 정해지기 전에 화면부터 임시 데이터로 만들어 담당자와 화면 구성을 먼저 확정한다.

## 활용

1. 지적재조사 담당자가 진행 중인 지구와 완료된 지구를 나눠 한눈에 확인한다.
2. 담당자가 지구를 선택해 사업 단계·필지수·동의율 등 진행 현황을 확인한다.
3. 담당자가 지구 안 필지별 재조사 전후 지번·면적 증감·경계 확정 여부·조정금을 확인한다.
4. 민원 응대 시 지도에서 지구와 필지 위치를 바로 찾아 안내한다.

## 필요 기능

1. 지구 목록을 진행 중·완료로 나눠 보여주고 건수를 표시한다.
2. 사업연도·읍면동·사업 단계 조건과 지구명 검색으로 목록을 좁힌다.
3. 지구 경계를 사업 단계별 색으로 지도에 표시하고 범례를 둔다.
4. 목록에서 지구를 고르면 지도가 해당 지구로 이동하고 경계가 강조된다.
5. 지도에서 지구를 클릭해도 목록에서 고른 것과 같이 상세가 열린다.
6. 지구 상세에 사업 단계 진행 표시, 기본 정보, 사업 현황, 행정 정보를 보여준다.
7. 지구 상세에 필지 목록(재조사 전후 지번·지목·면적, 증감, 경계 확정, 조정금)을 보여주고, 필지를 고르면 지도에서 강조한다.
8. 필지 목록을 엑셀(표 형식 파일)로 내려받는다.

## 참고·제약

1. 1차는 임시 데이터로 화면만 만든다. 실제 자료는 바른땅 지정고시 목록·필지 목록 엑셀을 받아 연결할 예정이다.
2. 지구 경계는 추후 필지 목록 도형을 합쳐 만들고, 2024년 이전 완료 지구는 브이월드 외곽경계를 보조로 쓴다.
3. 소유자 정보는 개인정보이므로 목록에 넣지 않는다.
4. 안동 프로젝트의 공간정보조회 시스템 메뉴에 둔다.
