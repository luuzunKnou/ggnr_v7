# 작업요청서

2026-11-12 | dev.strcat | 소규모 공공시설 담당

## 배경

1. 안전점검 목록·상세가 넓어 본문이 좁고, 점검은 평가표 항목 입력인데 후보지는 이미 첨부 방식으로 바뀌어 업무 흐름이 어긋난다.
2. 예시 자료에 세천 선정제외 등 맞지 않는 값이 섞여 화면 확인이 어렵다.
3. 미리보기가 버벅이고 페이지를 골라도 첫 장으로 열리는 경우가 있다.
4. 정비계획에서 예산 선택이 체크만 되고, 분석은 시설을 고른 뒤 다시 시작을 눌러야 하며, 추정은 예산에 넣지 못한다. 피해이력은 목록 아래에 펼쳐져 읽기 불편하다.

## 활용

1. 담당자가 안전점검을 후보지와 같이 파일·일자·담당·결과만으로 등록·확인한다.
2. 담당자가 정비계획 명세서에서 추정 시설도 골라 예산 계획에 넣는다.
3. 담당자가 분석할 시설을 고르면 바로 분석 화면으로 들어간다.
4. 담당자가 후보지 피해이력을 모달로 열어 수정한다.

## 필요 기능

1. 안전점검 목록·상세 공간을 줄이고, 점검은 첨부 파일과 메타만 등록·보여 준다.
2. 후보지·안전점검 예시 자료를 서로 맞게 정리하고, 세천 예시의 선정제외는 뺀다.
3. 미리보기 스크롤이 덜 끊기고, 고른 페이지가 그대로 열려야 한다.
4. 정비계획 예산 선택은 체크 칸 전체를 누르고, 분석 시설은 행을 누르면 바로 시작하며, 추정도 예산 계획에 넣을 수 있어야 한다.
5. 후보지 피해이력 상세는 모달로 연다.

## 참고·제약

1. 검토 중인 정비계획은 예산 배정에서 계속 뺀다.
2. 등급에 따른 평가구분(양호·보통·불량 → 일반·관리·위험) 규칙은 유지한다.
