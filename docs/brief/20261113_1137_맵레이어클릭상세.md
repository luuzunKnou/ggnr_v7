# 작업요청서

2026-11-13 | 200BingSu | —

## 배경

지도에서 레이어를 켜고 피처를 눌러도, 데이터조회·관망조회처럼 클릭 모달이 있는 업무가 아니면 속성 정보가 버려져 바로 볼 수 없다. 일반 조회·확인 업무에서 바로 속성을 볼 필요가 있다.

## 활용

1. 담당자가 업무 메뉴 없이 레이어만 켠 뒤 피처를 눌러 목록 표시 항목을 바로 확인한다.
2. 현장·민원 대응 전 속성 값을 빠르게 훑어본다.
3. 이미 클릭 모달이 있는 업무에서는 기존 화면만 쓰고 이 기능은 켜지지 않는다.
4. 여러 피처가 겹치면 헤더에서 골라 본다.
5. 잠시 최소화했다가 다시 펼쳐 같은 위치에서 이어서 본다.

## 필요 기능

1. 클릭→모달이 없는 상황에서만 지도 레이어 클릭으로 상세 플로팅을 연다.
2. 필드 설정에서 목록 표시가 켜진 항목만 플로팅에 보인다.
3. 관망조회와 같은 최소화·펼치기 가능한 플로팅을 쓴다.
4. 데이터조회·도로기반·관망·시설 등 기존 클릭 모달·패널과 겹치지 않는다.
5. 여러 건이 잡히면 헤더에서 전환할 수 있다.

## 참고·제약

기존 지도 클릭 식별 결과를 재사용한다. 목록·상세 패널을 쓰는 데이터조회·도로기반은 그대로 두고, 결과가 버려지던 경우에만 플로팅을 연다.
