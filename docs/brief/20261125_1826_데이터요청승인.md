# 작업요청서

2026-11-25 | 200BingSu | —

## 배경

데이터 요청 목록이 관리자만 전체를 보고, 팀장은 팀원 요청을 보지 못한다. 승인 대기 건을 처리하는 전용 화면도 없어 팀장·관리자가 승인·반려하기 어렵다.

## 활용

1. 일반 사용자는 본인이 요청한 자료만 조회·다운로드한다.
2. 팀장은 같은 부서 팀원의 요청 목록을 함께 본다.
3. 관리자·슈퍼 계정은 전체 요청을 본다.
4. 팀장·관리자는 «데이터 요청 승인»에서 대기 건을 승인·반려한다.

## 필요 기능

1. 데이터 요청 목록은 역할에 따라 본인 / 부서 팀원 / 전체로 나뉜다.
2. 사용자 이름 검색은 일반 사용자에게는 보이지 않는다.
3. «데이터 요청 승인» 메뉴·화면을 별도로 둔다.
4. 승인 화면은 데이터 요청과 같은 검색 조건을 쓰고, 기본은 대기만 보여 주며 상태 컬럼으로 구분한다.
5. 승인 주체가 팀장인 요청은 해당 부서 팀장만, 관리자·슈퍼는 전체를 본다.
6. 새 테이블은 만들지 않고 기존 요청 파일 이력을 그대로 쓴다.

## 참고·제약

1. 팀장 판별은 부서관리자 여부와 동일 부서명 기준이다.
2. 승인·반려·대기 상태는 기존 승인상태 값을 사용한다.
