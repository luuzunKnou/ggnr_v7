# 작업요청서

2026-10-19 | dev.strcat | 하천 담당 요청 (울진 하천·계곡 불법 점용시설 관리카드)

## 배경

하천·계곡 구역 안 불법 점용시설은 지금 한글 문서 관리카드(위치·행위자·조치현황·사진)로 따로 관리한다. 하천 시스템에서 카드를 목록으로 모아 보고, 같은 카드 모양으로 바로 등록·수정할 수 있어야 한다. 자료 항목의 영문 이름은 DB팀이 정해 줄 예정이라, 우선 임시 이름으로 화면 시제품을 먼저 만든다.

## 활용

1. 하천 담당자가 «불법점용시설 관리카드» 메뉴에서 등록된 카드를 목록으로 보고 연번·위치로 찾는다.
2. 담당자가 목록에서 한 건을 골라 원본 관리카드와 같은 모양의 상세를 본다.
3. 현장 확인 후 새 카드를 추가하거나 조치내용·조치계획을 고쳐 기록한다.
4. 시설 종류별 적발·조치·미조치 건수를 한 표에서 확인한다.
5. 위치도·현황사진·완료사진을 카드 안에서 함께 본다.

## 필요 기능

1. 카드 목록: 연번·하천구분·위치·최초확인일자를 보이고 검색·추가할 수 있다.
2. 카드형 상세: 원본 관리카드 칸 배치(연번, 하천구분, 최초확인일자, 완료(예정)일자, 위치, 재발여부, 행위자, 조치현황, 위법내용, 관련법, 조치내용, 조치계획, 관리책임자, 사진 4칸)로 보이고, 같은 카드 안에서 추가·수정·삭제한다.
3. 조치현황은 시설 종류 10가지(평상 등, 그늘막, 방갈로, 건축물, 불법경작, 데크 등, 형질변경, 물건적치, 비닐하우스, 기타)마다 적발·조치·미조치 건수를 칸으로 나눠 입력한다.
4. 여러 줄 항목은 저장 자료에서 «@»로 줄을 나눈다. 화면에서는 «@»마다 줄을 바꿔 보이고, 입력할 때 줄을 바꾸면 저장 시 «@»로 합친다.
5. 사진 4칸(위치도, 현황사진 2장, 완료사진)은 주소(경로)로 불러와 보이고, 수정 중 주소를 입력할 수 있다.

## 참고·제약

접도구역 건축물 관리대장의 목록·카드형 상세·건축물내용 칸 나눔을 참고한다. 이번에는 시제품으로 보내준 카드 1건을 예시 자료로 넣고, 추가·수정은 화면 안에서만 반영한다(새로고침 시 처음 상태). DB 항목 영문 이름은 임시이며 DB팀 자료를 받으면 바꾸고 저장 연동을 붙인다. 하천 시스템을 켠 프로젝트(울진 등)에서 메뉴가 보여야 한다.
