# 작업요청서

2026-09-10 | dev.strcat | 지도 내 정보

## 배경

내 정보 칸의 더보기를 가려 두었고, 다시 켤 때도 위쪽 밑줄 탭으로 나누면 찾기 어렵다. 자주 쓰는 기능은 위에 모아 두고, 나머지는 한 목록에서 찾아 고르는 쪽이 맞다.

## 활용

1. 담당자가 내 정보와 더보기를 같은 칸에서 바꿔 가며 본다.
2. 자주 여는 업무는 즐겨찾기에 모아 바로 들어간다.
3. 이름만 알고 있을 때 검색으로 기능을 찾는다.
4. 공지·자료실과 부서 기능을 한 목록에서 고른다.

## 필요 기능

1. 더보기를 다시 보이게 한다.
2. 내 정보와 더보기는 칸 위쪽 구간 단추로 화면을 나눈다. 밑줄 탭은 쓰지 않는다.
3. 더보기 칸 크기·아래·옆 간격은 내 정보·부서업무와 같게 둔다.
4. 즐겨찾기는 개수 제한 없이 두고, 한 줄을 넘으면 화살표나 끌어 넘기기로 본다. 스크롤 막대는 보이지 않게 한다.
5. 즐겨찾기가 비어 있으면 추가 단추만 두고, 높이는 즐겨찾기 칸과 같게 한다.
6. 바로가기 설정은 옆 칸으로 열고, 항목은 한 줄에 두 개씩 고른다.
7. 기능 이름을 검색할 수 있다. 목록은 겹치지 않게 한 번에 보여 주고, 공지·자료실은 앞에 둔다.
8. 기능을 고르면 해당 화면을 연다.

## 참고·제약

사이드바 메뉴는 그대로 둔다. 즐겨찾기는 이 칸에서만 다루는 시험용이다. 이전 내 정보 더보기 계획은 이 요청으로 이어 간다.
