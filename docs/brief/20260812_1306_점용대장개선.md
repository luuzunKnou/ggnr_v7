# 작업요청서

2026-08-12 | dev.strcat | —

## 배경

1. 점용대장 허가번호를 건마다 손으로 넣기 어렵고, 연도별 일련 규칙이 필요하다. 면적도 도형과 어긋난 값을 넣는 경우가 있어 도형 기준으로 맞출 수 있어야 한다.
2. 울진 하천점용은 점용장소를 직접 타이핑해야 해 불편하고, 도형을 그린 뒤 장소를 다시 찾는 중복 입력이 있다.
3. 울진 상세에 불필요한 주소·면적 세부가 보이고, 하천명·하천유형을 손으로 넣어 하천 레이어와 어긋날 수 있다.

## 활용

1. 담당자가 신규·수정 시 시작일 연도에 맞는 허가번호를 자동으로 받는다.
2. 면적은 직접 입력하거나 버튼으로 도형 면적을 채운다.
3. 울진·공통 모두 점용장소를 주소검색으로 고르고, 도형을 그리거나 수정하면 중심 주소가 들어간다.
4. 울진에서는 불필요 필드를 보지 않고, 하천명·하천유형은 하천계획 레이어 값만 고른다.

## 필요 기능

1. 허가번호는 시작일 연도 기준 «년도-번호»(예: 2026-01). 해당 연도 건이 없으면 01부터, 해가 바뀌면 다시 01부터. 추가 직후 바로 채워진다.
2. 공통 점용 키는 다음 순번이 입력 불가 필드로 바로 보인다.
3. 점용면적은 입력란과 «자동계산»으로 본표 도형 면적(㎡)을 넣을 수 있다.
4. 울진 점용장소를 공통과 같이 검색 가능하게 한다.
5. 울진·공통 모두 도형 추가·수정 시 중심 주소로 점용장소를 갱신한다.
6. 울진에서 읍면동명·리명·본번·부번·구분·일시점용면적은 상세에 표시하지 않는다.
7. 울진 하천명·하천유형은 하천계획 레이어 값으로 선택하고, 하천유형은 하천명에 따라 자동 반영되며 직접 수정하지 않는다.
8. 울진 상세는 더보기·접기 없이 남은 속성을 한 번에 보여 준다.

## 참고·제약

울진은 허가번호·점용기간 시작일·점용장소 필드, 공통은 허가번호·허가시작일·점용장소 필드를 쓴다. 공사코드(키) 채번과 별개다. 하천계획 목록은 하천계획 레이어를 출처로 한다.
