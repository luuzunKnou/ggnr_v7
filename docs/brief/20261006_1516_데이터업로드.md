# 작업요청서

2026-10-06 | gyujin | —

## 배경

담당자가 보유한 SHP·엑셀 자료를 지도에 띄우려면 지금은 개발자가 개발자 화면에서 대신 올려야 한다. 사용자가 직접 파일을 올려 레이어로 확인하고, 속성도 기존 데이터조회처럼 관리할 수 있어야 한다.

## 활용

1. 업무 담당자가 외부 기관에서 받은 SHP 자료를 올려 지도에서 위치를 바로 확인한다.
2. 담당자가 엑셀 대장(주소 또는 좌표 포함)을 올려 지도 위 점·필지로 표시한다.
3. 올린 자료의 속성을 데이터조회 화면에서 조회·수정·등록·삭제한다.
4. 올리기 전에 좌표계·인코딩·위치 컬럼을 확인해 잘못된 위치로 등록되는 일을 막는다.

## 필요 기능

1. 지도 왼쪽 메뉴 «데이터 업로드»에서 SHP(zip 또는 개별 파일)와 엑셀·CSV 파일을 올릴 수 있어야 한다.
2. SHP는 필수 구성 파일(도형·색인·속성) 누락 여부를 올리기 전에 알려야 한다.
3. SHP 좌표계 정의 파일이 있으면 좌표계를 자동으로 알아내고, 없으면 사용자가 고를 수 있어야 한다.
4. SHP 속성 한글 인코딩(국내 표준·유니코드)을 고를 수 있어야 한다.
5. 엑셀은 시트·머리글 행을 고르고, 위치를 좌표·주소·도형문자 중 무엇으로 만들지 지정할 수 있어야 한다.
6. 등록 전 건수·도형 유형·속성 컬럼·앞부분 자료를 미리보기로 보여줘야 한다.
7. 레이어 이름과 공개 범위(나만·부서·전체)를 정할 수 있어야 한다.
8. 등록된 레이어는 데이터조회에서 속성 관리가 가능해야 한다. (후속 단계)

## 참고·제약

1. 이번 단계는 업로드 화면(파일 선택·설정·미리보기)만 만든다. 서버 저장·레이어 등록은 후속 작업이다.
2. 개발자 화면의 SHP·엑셀 등록 마법사 처리 방식(인코딩, 좌표계 목록, 주소로 필지 찾기)을 서버 단계에서 재사용한다.
3. 메뉴 추가는 공통 기능 목록 설정으로 하며 DB 작업은 하지 않는다.
