# 작업요청서

2026-11-25 | JungWooojin | 도로대장 교량 표시

## 배경

교량 원본이 면형이라 지도에서 도로·시설과 겹칠 때 형태가 잘 안 보인다. 외곽 방향에 맞춘 양쪽 선으로 그리면 교량 위치가 더 분명해진다.

## 활용

1. 도로 담당자가 도로대장 «주요시설»에서 교량 위치를 선으로 확인한다.
2. 레이어 목록에서도 교량 선형 레이어를 켜 고배율 확인에 쓴다.
3. 시설 목록·건수 조회는 기존 교량 속성 테이블을 그대로 쓴다.

## 필요 기능

1. 교량 면형을 양쪽 선으로 변환한 뷰를 둔다.
2. 해당 뷰를 스타일·지도 레이어로 등록한다.
3. 도로대장 주요시설 켜기 시 지도에는 선형 교량이 보이게 한다.
4. 시설 목록·건수는 기존 교량 테이블 기준을 유지한다.

## 참고·제약

원본 교량 면형 테이블은 유지한다. 뷰는 조회·표시용이며 편집 대상이 아니다. 경산·청도 도로 DB에 동일 적용한다.
