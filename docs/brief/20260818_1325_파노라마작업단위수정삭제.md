# 작업요청서

2026-08-18 | JungWooojin | —

## 배경

파노라마 작업단위명 수정이 화면 표시에만 그치면 실제 폴더와 등록 경로가 어긋난다. 사진·동영상과 같이 폴더·경로를 함께 바꾸고, 삭제 시에도 실제 파일까지 정리해야 한다.

## 활용

1. 담당자가 파노라마 작업단위명을 수정해 실제 저장 폴더와 맞춘다.
2. 담당자가 작업목적·작성자·촬영자·메모를 보완해 다시 조회해도 유지한다.
3. 담당자가 불필요한 파노라마 작업단위나 개별 파일을 실제 저장소까지 삭제한다.

## 필요 기능

1. 파노라마 작업단위명 수정 시 실제 폴더명과 소속 파일 경로를 함께 변경해야 한다.
2. 작업목적·작성자·촬영자·메모를 데이터베이스에 저장해야 한다.
3. 작업일과 상태는 수정할 수 없어야 한다.
4. 연결 신청은 상세에서 숨기되 내부 연결은 유지해야 한다.
5. 작업단위 삭제 시 소속 파일과 실제 폴더를 함께 제거해야 한다.
6. 파일 한 건 삭제 시 해당 파일만 제거하고 작업단위는 유지해야 한다.

## 참고·제약

사진·동영상과 같은 저장 구조·삭제 정책을 재사용한다. 드론영상 경로 고정 정책은 변경하지 않는다.
