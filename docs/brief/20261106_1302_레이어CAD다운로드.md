# 작업요청서

2026-11-06 | gyujin | —

## 배경

지도 레이어 설정에서 보이는 벡터 자료를 캐드에서 바로 쓰려면, 레이어를 고르고 도면·캐드 형식 중 하나로 내려받는 경로가 필요하다. 지금은 레이어 켜기·끄기만 되고 CAD보내기가 없다.

## 활용

1. 현장·설계 담당자가 현재 보고 있는 지도 범위의 여러 레이어를 한 파일로 받아 캐드에서 겹쳐 본다.
2. 민원·협의 자료용으로 필요한 레이어만 골라 DXF 또는 DWG로 공유한다.
3. 레이어마다 따로 받지 않고 한 번의 다운로드로 합본 도면을 만든다.

## 필요 기능

1. 레이어 설정에 CAD 다운로드 버튼이 있어야 한다.
2. 누르면 레이어를 고르고 DXF·DWG 중 형식을 고를 수 있어야 한다.
3. 선택한 레이어가 하나의 CAD 파일로 내려받아져야 한다.
4. 도형은 현재 지도 화면 범위 안만 포함해야 한다.
5. 배경·정사 등 벡터가 아닌 항목은 고를 수 없어야 한다.

## 참고·제약

1. 지도 표시는 이미지 레이어라 서버에서 DB 도형을 읽어 변환한다.
2. DWG는 서버에 캐드 변환 도구가 있을 때만 제공한다.
3. 기존 개발도구의 형상파일→도면 변환과 단건 형상파일 받기는 그대로 둔다.
