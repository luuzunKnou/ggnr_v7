# 작업요청서

2026-07-27 | dev.strcat | 업무 알림 서버 저장·시스템 필터

## 배경

점용 만료·점사용료 미납 알림의 읽음·지우기가 브라우저에만 있어, 브라우저를 초기화하면 같은 알림이 다시 뜬다. 또한 알림을 시스템(하천 등) 들어온 뒤에야 조회하고 있어, 로그인 후 한꺼번에 모은 뒤 시스템별로만 걸러 보여 주는 편이 낫다.

## 활용

1. 담당자가 로그인하면 대상 업무 알림을 먼저 모아 두고, 하천 등 시스템을 열면 그 시스템에 해당하는 알림만 본다.
2. 읽음·지우기는 계정 기준으로 서버에 남아, 다른 피시·브라우저에서도 동일하게 유지된다.
3. 내 정보 알림·사이드바 미읽음 표시가 같은 상태를 공유한다.

## 필요 기능

1. 만료 임박·미납 임박 알림 후보를 업무 데이터에서 모은다.
2. 읽음·지우기 상태를 계정별로 서버에 저장·조회한다.
3. 시스템 진입 시 해당 시스템 알림만 보이게 걸러 준다.
4. 로그인 이후(시스템 선택 화면 포함)에도 알림을 미리 받을 수 있게 한다.

## 참고·제약

기존 공지사항 기능과 별개다. 디비 스키마 반영은 담당자가 적용한다. 로컬에서 차세대 연계 스케줄이 꺼져 있어도 알림 조회·읽음 저장은 동작해야 한다.
