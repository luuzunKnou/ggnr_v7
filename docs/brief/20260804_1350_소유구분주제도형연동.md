# 작업요청서

2026-08-04 | dev.strcat | 지도 소유구분 패널

## 배경

소유구분 레이어는 이미 정의에서 주제도 그룹과 분리해 두었으나, 지도에서는 예전 방식(고정 목록·우클릭 패널)으로만 열려 주제도와 사용 느낌이 달랐다. 주제도처럼 버튼을 눌러 목록을 고르는 방식으로 맞춰야 한다.

## 활용

1. 담당자가 지도 우측 «소유구분»을 눌러 국유지·군유지·개인 등 소유별 레이어를 골라 본다.
2. 주제도를 볼 때와 같은 방식으로 전체 선택·해제·개별 체크를 한다.
3. 레이어 데이터가 아직 없어도 화면·목록 구조는 준비해 두고, 업로드 후 바로 쓸 수 있게 한다.
4. 인쇄·편집 화면에서도 같은 소유구분 켜짐 상태를 이어받는다.

## 필요 기능

1. «소유구분» 버튼을 누르면 주제도와 같이 목록 패널이 열리고 다시 누르면 닫힌다.
2. 패널에서 소유자정보 그룹의 레이어를 체크해 지도에 표시한다.
3. 정의에 있는 소유자정보만 대상으로 하며, 실제 데이터가 있는 항목만 목록에 나온다.
4. 주제도 목록과는 섞이지 않고 따로 보인다.
5. 선택한 내용은 다시 들어와도 유지된다.

## 참고·제약

레이어 파일 업로드·발행은 별도 진행 중이다. 이번 작업은 화면·목록·표시 연동만 맞춘다. 지목 버튼은 바꾸지 않는다.
