# 작업요청서

2026-10-20 | luuzunKnou | 상수도 행정 · 공사대장

## 배경

상수도 행정에서 공사대장을 열면 빈 화면만 있어, 연도별 사업과 개별 공사·구역·첨부를 한곳에서 볼 수 없다. 현장·행정 담당자가 사업 규모와 공사 현황을 바로 확인해야 한다.

## 활용

1. 담당자가 연도별 사업 목록에서 기간·총괄금액을 본다.
2. 사업을 고르면 사업 상세·공사 목록·변경 건을 아래에 확인한다.
3. 공사를 고르면 우측에서 공사 속성과 공사구역을 본다.
4. 지도 아래쪽에서 해당 공사 첨부파일을 확인한다.

## 필요 기능

1. 사업 목록에 기간·총괄금액을 보여 준다.
2. 사업 선택 시 아래에 사업 상세·공사 목록·변경 건을 보여 준다.
3. 공사 목록에 기간·업체·금액을 보여 준다.
4. 공사 선택 시 오른쪽에 패널을 열고 상단에 공사 속성을 보여 준다.
5. 오른쪽 패널 하단에 공사구역을 보여 준다.
6. 남은 지도 아래쪽 절반에 첨부파일을 보여 준다.

## 참고·제약

데이터는 상수 공사대장 원본 자료를 참고한다. 이번은 조회·표시 중심이며 등록·수정·실파일 저장은 넣지 않는다.
