# 작업요청서

2026-08-13 | JungWooojin | 촬영요청·항공영상 관리

## 배경

파노라마는 목록·상세가 목업만 있어, 촬영요청에서 승인 후 실제 파일을 올려 관리할 수 없다. 사진·동영상과 같은 업무 흐름이 필요하다.

## 활용

1. 담당자가 촬영요청을 파노라마로 올려 승인받는다.
2. 승인 후 작업단위 폴더를 만들고 파노라마 이미지를 등록한다.
3. 지도 메뉴 «파노라마»에서 작업단위·파일을 조회·추가·삭제한다.
4. 파일을 선택하면 미리보기로 확인한다.

## 필요 기능

1. 촬영형태가 파노라마일 때 사진·동영상과 같이 폴더 생성 후 파일 업로드가 이어져야 한다.
2. 파노라마 목록·파일은 서버·저장소 기준으로 표시되어야 한다.
3. 파일 추가·작업단위·파일 삭제가 가능해야 한다.
4. 파일 선택 시 저장된 이미지를 미리볼 수 있어야 한다.
5. 업로드·삭제 후 촬영요청 등록 상태가 사진·동영상과 같이 맞춰져야 한다.

## 참고·제약

사진·동영상과 동일하게 작업단위·파일 테이블과 항공 저장 경로를 쓴다. 드론영상(TIF 변환)과 달리 타일 변환은 없다. 360 전용 뷰어 라이브러리 추가는 가능하나, 1차는 실파일 미리보기·관리 연동을 우선한다.
