# 작업요청서

2026-10-22 | gyujin | —

## 배경

받은 형상파일을 캐드에서 바로 열 수 있는 도면으로 바꾸는 경로가 없다. 담당자가 개발자 모드에서 파일을 골라 도면으로 내려 받을 필요가 있다.

## 활용

1. 지적·도로 담당자가 받은 형상파일을 캐드에서 열어 경계를 확인한다.
2. 외부에 형상을 도면으로 넘겨줄 때 쓴다.
3. 지도 등록·레이어 업로드와 분리해, 변환만 수행한다.

## 필요 기능

1. 개발자 모드 File Converter에 «SHP to DXF» 항목이 있어야 한다.
2. 지정 작업 폴더의 형상파일을 도면 파일로 변환해야 한다.
3. 같은 이름 도면이 있으면 덮어써야 한다.
4. 좌표값은 원본 그대로 두어야 한다.
5. 이번 범위는 도면(DXF)만 한다.

## 참고·제약

1. 레이어 업로드용 형상 폴더와 섞지 않고 전용 작업 폴더를 쓴다.
2. 도형만 변환한다. 속성을 도면 글자로 넣지는 않는다.
3. 면은 채움보다 외곽선으로 내리는 편이 캐드에서 다루기 쉽다.
4. DWG는 이번 범위에 넣지 않는다.
