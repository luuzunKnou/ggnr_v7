# 작업요청서

2026-09-11 | dev.strcat | 재난안전 · 물놀이 표지판

## 배경

물놀이 표지판은 점 좌표와 구조함·표지판 수량만으로 관리하고 있어, 실제 설치 위치와 관리 범위가 한눈에 보이지 않는다. 주소에 해당하는 필지 범위와, 구조함·표지판 각각의 점이 따로 보여야 현장 확인이 된다.

## 활용

1. 담당자가 목록에서 구분·주소·제목만 보고 해당 관리 구간을 찾는다.
2. 상세에서 관리 구간 속성을 본 뒤, 구조함·표지판 위치를 점용대장 필지목록처럼 눌러 지도로 이동한다.
3. 수정 때 구조함·표지판을 지도에 점으로 찍어 각각의 레이어에 넣는다.
4. 이력은 이 관리 구간과 하나씩 대응하며, 이번 작업에서는 건드리지 않는다.

## 필요 기능

1. 관리 구간 도형은 주소로 지적 면을 찾아 멀티폴리곤으로 둔다. 주소가 여러 개면 면을 합친다.
2. 목록 열은 구분, 주소, 제목 순이다. 구조함·표지판 수량은 목록에 내지 않는다.
3. 관리 구간 레이어는 글자를 붙이지 않는다.
4. 구조함 목록·표지판 목록 레이어를 새로 둔다. 기존 물놀이 표지판과 하나는 여러 개 관계이다.
5. 상세에서 속성과 이력 사이에 구조함 목록·표지판 목록을 둔다. 수정 때 각각 점을 추가할 수 있다.
6. 상세의 구분은 고칠 수 있게 한다. 이력 화면은 이번 범위에서 바꾸지 않는다.
7. 구조함·표지판 저장 칸은 키, 관리 구간 번호, 주소, 도형이다.

## 참고·제약

새 목록 테이블은 기동 시 없으면 만든다. 관리 구간 도형 종류 변경은 기동 보정으로 넣되, 실데이터 밀어넣기 명령은 실행하지 않는다. 이력은 관리 구간과 하나 대 하나이며 이번엔 손대지 않는다.
