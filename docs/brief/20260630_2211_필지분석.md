# 작업요청서

2026-06-30 | luuzunKnou | 지적·토지 업무 개선 요청

## 배경

지도에서 필지를 골라 토지·건축 관련 정보를 한곳에서 보는 기능이 필요하다. 우클릭 주소정보와는 용도가 다르며, 담당자가 업무 구역을 정한 뒤 여러 필지를 순차적으로 조회할 수 있어야 한다.

## 활용

1. 커서관련지적·토지 담당자가 현장·사무실에서 지도 위 필지를 지정해 지번·토지 기본 정보를 확인한다.
2. 용도지역·공시지가·소유·이용계획을 필지 단위로 빠르게 조회해 민원·검토 자료로 활용한다.
3. 건축물대장·건축인허가 등 연관 대장을 같은 필지 맥락에서 이어서 본다.
4. 읍면동·리 단위 또는 지도에 그린 구역으로 **분석 범위**를 정해, 범위 밖 필지는 조회 대상에서 제외한다.
5. 다른 지도 기능(메모·민원·측정 등)과 겹치지 않게 «필지분석» 전용 모드로 사용한다.

## 필요 기능

1. 사이드바 «필지분석»으로 분석 모드 진입·종료.
2. 분석 범위: 도형(사각형·다각형·원) 그리기 또는 행정경계(읍면동·리) 선택.
3. 범위 안 필지 좌클릭 선택, 선택 필지 지도 강조.
4. 우측 패널에서 지번·도로명·좌표, 토지 기본·소유·이용계획 조회.
5. 공시지가 이력, 건축물대장·건축인허가 탭 조회.
6. 범위 미지정·범위 밖 클릭·필지 미식별 시 안내.

## 참고·제약

- 우클릭 «주소정보»와 동작·패널 분리 유지.
- 외부 연동(토지·대장) 설정 없으면 조회 불가 안내 필요.
- 1차: 분석 범위 + 단일 필지 조회·패널. 2차: 범위 내 다필지 목록 등은 제외.
