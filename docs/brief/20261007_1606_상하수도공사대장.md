# 작업요청서

2026-10-07 | dev.strcat | —

## 배경

공사대장은 하천 시스템에서만 쓸 수 있어, 상수도·하수도 공사 이력은 지도에서 관리할 방법이 없다. 상수·하수 공사대장과 필지 레이어를 새로 올릴 예정이며, 속성은 하천 공사대장과 거의 같으므로 화면은 공유하고 저장 대상만 나누려 한다.

## 활용

1. 상수도 담당자가 «상수도 공사대장»에서 상수 공사의 계약·착공·준공 정보와 공사 구간을 조회·등록한다.
2. 하수도 담당자가 «하수도 공사대장»에서 하수 공사와 공사 필지(구간)를 관리한다.
3. 상하수도 통합 시스템 사용자는 두 메뉴를 오가며 상수·하수 공사를 각각 본다.
4. 하천 담당자는 기존 하천 공사대장을 지금과 똑같이 쓴다.

## 필요 기능

1. 메뉴에 따라 하천·상수·하수 공사대장 데이터를 각각 불러오고 저장한다. 서로 데이터가 섞이지 않는다.
2. 화면 구성(목록·상세·필지·첨부)은 하천 공사대장과 같다.
3. 레이어에 실제로 있는 속성만 보여 준다. 예: 상수·하수에는 «대상 하천»이 없으므로 표시하지 않는다.
4. 필지 저장 시 레이어에만 있는 필지 속성(필지코드·비고·설명·사용여부 등)이 지워지지 않는다.
5. 신규 필지는 필지코드를 이어서 자동 부여한다.
6. 첨부파일 폴더도 공사대장 종류별로 따로 둔다.

## 참고·제약

1. 하수 레이어: 공사대장 본표·필지 두 개. 상수 레이어는 이름만 다르고 속성은 하수와 같다.
2. 하수 필지의 주소 컬럼명이 하천과 다르다(도로명주소 컬럼).
3. 레이어는 사용자가 SHP 업로드로 올린다. 데이터베이스 테이블 생성은 개발 작업 범위에서 제외한다.
4. 기존 하천 공사대장 동작이 바뀌면 안 된다.
