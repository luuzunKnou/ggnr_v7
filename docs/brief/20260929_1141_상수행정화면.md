# 작업요청서

2026-09-29 | luuzunKnou | —

## 배경

상수도 행정 업무지원은 메뉴만 있고 화면이 비어 있어, 관망·시설·공사·급수·민원·현장·통계·편람을 어떤 구성으로 쓸지 볼 수 없다.

## 활용

1. 담당자가 사이드바에서 업무를 고르고, 왼쪽 메뉴로 세부 화면을 넘긴다.
2. 목록·상세·등록 자리와 지도 연동 화면의 구성을 예시 자료로 먼저 검토한다.

## 필요 기능

1. 관망조회, 시설조회, 공사대장, 급수공사, 민원관리, 작업/현장관리, 통계/보고서, 업무편람이 있어야 한다.
2. 각 업무 안의 세부 메뉴를 누르면 그에 맞는 화면이 나와야 한다.
3. 관망도·시설 위치·민원 위치는 목록과 상세, 지도 설명이 함께 보여야 한다.
4. 등록·수정·저장은 화면에서만 동작하고 서버에는 넣지 않는다.

## 참고·제약

실데이터·저장·도면 파일은 이번 범위가 아니다. 화면 구성과 예시 값만 둔다.
