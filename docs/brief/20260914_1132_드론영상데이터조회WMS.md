# 작업요청서

2026-09-14 | JungWooojin | —

## 배경

울산 UAV에 올려 둔 드론영상은 영상조회에서만 켜지고, 데이터 조회·레이어권한과는 연결되어 있지 않다. 현장·담당자가 범위만 먼저 보고 필요한 영상만 켜거나, QGIS에서 권한 있는 영상을 지도 서비스로 보고 싶어 한다.

## 활용

1. 담당자가 데이터 조회에서 드론영상 범위를 보라색 상자로 한눈에 본다.
2. 관심 범위를 클릭하면 해당 드론영상이 지도에 뜬다.
3. QGIS 사용자가 레이어권한으로 허용된 드론영상을 WMS로 불러 확인한다.

## 필요 기능

1. 데이터 조회에 드론영상 범위 항목을 두고, 켜면 변환 완료된 영상마다 보라색 영역(상자)을 지도에 그린다.
2. 그 영역을 클릭하면 해당 드론영상이 지도에 표시된다.
3. 레이어권한 목록에 드론영상을 넣고, 읽기 허용 시 QGIS WMS로 영상이 보이게 한다.
4. 기존 영상조회(타일 체크) 동작은 유지한다.

## 참고·제약

데이터 조회는 영역 표시·클릭 표시가 우선이다. QGIS 쪽은 WFS가 아니라 WMS로 영상을 본다.
