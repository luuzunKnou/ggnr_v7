# 작업요청서

2026-08-18 | JungWooojin | —

## 배경

드론영상은 원본과 변환 타일 경로가 작업단위 폴더에 연결되어 있어 작업단위명을 변경하면 안 된다. 반면 작업일·임무 목적·작성자·메모는 실제 업무 내용에 맞게 수정하고 다시 조회해도 유지할 수 있어야 한다.

## 활용

1. 드론 담당자가 등록된 드론영상의 실제 작업일을 바로잡는다.
2. 드론 담당자가 임무 목적·작성자·메모를 보완해 자료의 업무 맥락을 남긴다.
3. 담당자가 원본과 변환 경로를 유지한 채 업무 속성만 관리한다.

## 필요 기능

1. 드론영상 작업단위명은 수정할 수 없어야 한다.
2. 작업일·임무 목적·작성자·메모만 수정할 수 있어야 한다.
3. 수정 내용은 데이터베이스에 저장되어 다시 조회해도 유지되어야 한다.
4. 속성 수정은 실제 폴더명·원본 경로·변환 타일 경로에 영향을 주지 않아야 한다.
5. 작업단위 삭제 시 소속 원본·변환 타일·실제 폴더를 함께 제거해야 한다.
6. 파일 한 건을 삭제하면 해당 원본과 변환 타일만 제거하고 작업단위는 유지해야 한다.

## 참고·제약

이번 범위는 드론영상 속성 수정과 삭제만 대상으로 한다. 사진·동영상과 파노라마의 수정 동작은 변경하지 않는다.
