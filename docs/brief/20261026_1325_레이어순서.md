# 작업요청서

2026-10-26 | 213am | —

## 배경

레이어 설정에 순번이 있으나 데이터 조회와 지도 우측 레이어 목록은 한글 이름이나 고정 목록 순으로 나온다. 순번을 바꿔도 업무 화면의 줄 순서가 바뀌지 않는다.

## 활용

1. 담당자가 레이어 설정에서 순번을 정하면 데이터 조회 목록이 그 순서로 나온다.
2. 지도 우측의 주제도, 지하시설물, 소유구분, 지목, 지적도, 건물·도로 목록도 같은 순번을 따른다.
3. 순번이 같으면 지금처럼 한글 이름순으로 남는다.

## 필요 기능

1. 데이터 조회에서 같은 그룹 안의 레이어를 순번이 작은 것부터 보여 준다.
2. 우측 레이어 목록도 그룹 안에서는 순번이 작은 것부터 보여 준다.
3. 순번이 없거나 같으면 한글 이름순을 유지한다.
4. 소유구분의 기타는 목록 맨 아래에 둔다.
5. 그룹 자체의 순서와 지도에 겹치는 순서는 바꾸지 않는다.

## 참고·제약

레이어 설정 화면의 줄 순서와 엑셀 내보내기는 이번 범위가 아니다.
