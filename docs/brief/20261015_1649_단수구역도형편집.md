# 작업요청서

2026-10-15 | luuzunKnou | —

## 배경

단수구역은 잠금으로 관로를 미리 본 뒤 결과를 남겨야 한다. 저장 후에는 자동으로 잡힌 단수 면을 업무에 맞게 고칠 수 있어야 한다.

## 활용

1. 담당자가 제수변을 잠가 단수 관로를 확인한 뒤 분석 결과를 이력에 저장한다.
2. 저장된 단수 구역 도형을 수정·행정경계·직접그리기로 다듬어 안내·문자 대상 범위로 쓴다.

## 필요 기능

1. «분석실행»을 «분석결과저장»으로 바꾸고, 잠금 미리보기 결과를 이력에 저장한다.
2. 저장 후 단수구역 도형편집을 제공한다.
3. 도형편집은 기존 도형 수정, 읍면동리 선택, 직접그리기 세 가지로 한다.
4. «새 분석»은 잠금부터 다시 할 수 있게 초기화한다.

## 참고·제약

세션 이력만 유지한다. 행정경계·그리기는 기존 분석영역 공용 도구를 재사용한다.
