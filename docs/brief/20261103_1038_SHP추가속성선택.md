# 작업요청서

2026-11-03 | JungWooojin | —

## 배경

SHP를 올릴 때 속성 전부를 일반 컬럼으로 넣으면 상세·목록이 복잡해진다. 일부 속성은 추가속성으로만 묶어두면 업무에 맞는 화면을 유지할 수 있다.

## 활용

1. 공간정보 담당자가 신규 레이어 SHP를 올릴 때, 본문에 둘 속성과 추가속성으로 뺄 속성을 나눈다.
2. 올린 뒤 일반 목록·상세는 핵심 속성만 보고, 추가 정보는 추가속성 화면에서 본다.
3. 올리기 전에 추가속성이 어떤 형태로 저장되는지 미리 확인한다.

## 필요 기능

1. 업로드 두 번째 단계에서 신규 레이어에 한해 추가속성으로 넣을 속성을 고른다.
2. 고른 속성에 한글 이름을 붙일 수 있다.
3. 저장될 추가속성 형태를 미리보기로 확인한다.
4. 실제로 올릴 때 고른 속성은 일반 컬럼이 아니라 추가속성으로만 들어간다.
5. 고르지 않은 속성과, 선택을 안 한 경우는 지금과 같이 동작한다.
6. 이미 있는 레이어를 갱신하는 흐름은 이번 범위에서 바꾸지 않는다.

## 참고·제약

기존 추가속성 저장 형식과 맞춘다. 자동 번역은 하지 않고 한글 이름은 직접 입력한다.
