# 작업요청서

2026-10-16 | gyujin | —

## 배경

1. 개발부담금 담당자가 대상 사업·지구를 엑셀과 도면으로 따로 관리하고 있어, 지도에서 위치와 목록을 한눈에 보기 어렵다.
2. 민원·현장 확인 전에 대상 지역이 어디인지 먼저 확인하려는 요청이 있다.
3. 실데이터·연계는 아직 준비되지 않았으므로, 화면 구성과 조작 흐름을 먼저 확인한다.

## 활용

1. 담당자가 사이드바에서 개발부담금 화면을 켜고 대상 지역 목록을 본다.
2. 목록에서 지역을 고르면 지도가 해당 위치로 이동하고 경계가 강조된다.
3. 지도에서 경계를 눌러도 같은 지역을 선택할 수 있다.
4. 읍면동·상태·검색으로 목록을 좁혀 필요한 대상만 본다.

## 필요 기능

1. 지도 사이드바 «개발부담금» 메뉴로 전용 화면을 켜고 끌 수 있어야 한다.
2. 대상 지역 목록에 사업명·소재지·면적·상태·기준연도를 보여준다.
3. 목록 행을 누르면 지도에 해당 지역 경계를 강조하고 위치로 이동한다.
4. 지도에 대상 지역 경계를 표시하고, 경계를 눌러 선택할 수 있다.
5. 선택한 지역의 기본 속성을 상세 패널에서 본다.
6. 이번 단계는 임시 자료로 화면만 구성하고, 저장·연계·산정은 포함하지 않는다.

## 참고·제약

1. 자료는 임시값이며 실제 부과·산정과 무관하다.
2. 실데이터·DB·외부 연계는 후속 단계에서 다룬다.
3. 기존 필지분석·지적재조사 등 다른 지도 메뉴와 동시에 켜지지 않도록 기존 패널 배치 규칙을 따른다.
