# 작업요청서

2026-08-25 | dev.strcat | 메모관리 화면

## 배경

메모관리 목록·상세가 민원관리와 달라 같은 지도 업무에서 쓰는 느낌이 갈린다. 목록은 민원과 비슷한 카드로 맞추고, 추가·상세는 지도를 가리지 않는 떠 있는 패널에서 위치를 찍어 저장할 수 있어야 한다.

## 활용

1. 담당자가 사이드바에서 메모관리를 열면 민원과 비슷한 목록으로 메모를 찾는다.
2. 검색으로 제목·내용을 좁혀 보고, 행의 번호·작성자·날짜로 건을 구분한다.
3. 행을 누르면 지도가 해당 점으로 가고, 떠 있는 상세에서 제목·내용·위치를 고친다.
4. 추가는 목록을 둔 채 지도 위 패널에서 점을 찍어 등록한다.
5. 저장 직후 주소 글자와 지도 점 표시가 새 위치로 맞춰진다.

## 필요 기능

1. 목록 머리글·검색·카드 행 배치를 민원관리와 같게 한다. 구분 칩은 두지 않는다.
2. 카드에 구분 이름·번호·작성자·날짜·제목·내용 미리보기를 둔다.
3. 추가·상세는 지도 위 떠 있는 패널이다. 가운데를 가리는 창은 쓰지 않는다.
4. 위치는 지도에서 점을 찍고, 칸에는 지정됨 대신 좌표로 찾은 주소가 나온다.
5. 작성일·작성자는 로그인 값으로 채워지고 고칠 수 없다. 작성그룹은 화면에 보이지 않되 저장 시 부서명이 들어간다.
6. 제목·내용·위치 지정·등록·수정·삭제·지도 이동은 유지한다. 민원의 이력·첨부·상태는 넣지 않는다.
7. 위치가 있는 건을 열면 민원처럼 지도에 점이 강조되고, 위치 수정 저장 후 바로 반영된다.

## 참고·제약

민원 위치는 주소 검색만 쓰고, 메모만 지도 점 찍기를 쓴다. 점 찍는 동안 다른 지도 클릭은 받지 않는다.
