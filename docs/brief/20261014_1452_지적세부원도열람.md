# 작업요청서

2026-10-14 | gyujin | 토지정보과

## 배경

1. 토지정보과는 경계 분쟁·측량 검사·등록사항 정정 업무에서 최초 등록 당시의 지적 세부원도를 확인해야 하지만, 현재는 스캔 이미지를 파일로 찾아 따로 열어 보고 있어 현재 지적도와 위치를 맞춰 비교하기 어렵다.
2. 2019년 모자이크 사업으로 세부원도 스캔본마다 네 모서리 실제 좌표(Bessel 동부원점)가 이미 만들어져 있어, 별도 좌표 작업 없이 지도에 정확히 겹쳐 볼 수 있는 기반이 갖춰져 있다.
3. 원도 파일명에 필지 고유번호가 포함되어 있어 필지와 원도를 바로 연결할 수 있다.

## 활용

1. 지적 담당자가 경계 분쟁·경계 민원 처리 시 해당 필지의 원도를 지도에 겹쳐 최초 등록 경계와 현재 지적도를 비교한다.
2. 측량 검사·토지이동(분할·합병) 검토 시 원래 필지 모양과 인접 필지를 원도로 확인한다.
3. 등록사항 정정·지적불부합지 조사 시 원도와 연속지적도의 어긋남을 투명도를 조절해 확인한다.
4. 지적재조사 사업 검토 시 사업지구 일대에 어떤 원도가 있는지 도곽 경계로 한눈에 파악하고 필요한 원도를 골라 본다.
5. 대장·도면 이력 확인 시 원도에 적힌 옛 지번·옛 동 명칭을 확인한다.

## 필요 기능

1. 지도 사이드바에 «세부원도» 메뉴를 두고, 켜면 원도가 있는 지역에 원도별 도곽 경계(사각형 선)를 표시한다.
2. 지도에서 필지를 클릭하면 그 필지와 연결된 원도 목록(동명·원도 번호·일련번호)을 보여준다.
3. 도곽 경계를 클릭하면 그 위치에 있는 원도 목록을 보여준다. 같은 도곽에 동만 다른 원도가 여러 장이면 모두 나와야 한다.
4. 목록에서 원도를 선택하면 원본 스캔 이미지를 실제 좌표·회전까지 반영해 지도 위에 정확히 겹쳐 표시한다.
5. 겹친 원도마다 투명도 조절, 켜기·끄기, 해당 원도 범위로 이동을 제공한다. 여러 장을 동시에 켤 수 있어야 한다.
6. 원도를 켠 상태에서 기존 측정(거리·면적), 지도 인쇄, 필지 정보 조회를 그대로 쓸 수 있어야 한다.
7. 원도 원본 이미지와 좌표 정보 파일을 서버 데이터 폴더에 등록하면, 필지·일련번호·동·도곽 범위 목록이 일괄로 만들어져야 한다.

## 참고·제약

1. 원본 위치: 모자이크 사업 산출물(원도 이미지, 네 모서리 좌표 정보, 월드파일, 전용 타일). 현재 길안면 지적 원도 339장과 임야 원도 5장, 총 344장이 있으며 다른 읍면 자료 확보 여부는 확인이 필요하다.
2. 좌표는 모든 원도에 공통으로 있는 «네 모서리 좌표 정보»를 기준으로 한다. 월드파일은 일부(135장)에만 있고, 전용 타일은 우리 지도에서 쓸 수 없는 형식이라 사용하지 않는다.
3. 원도는 약 0.3° 회전된 상태로 좌표가 맞춰져 있어, 회전을 무시하고 범위만 맞추면 1~2m 어긋난다. 회전까지 반영해 표시해야 한다.
4. 좌표계는 Bessel 동부원점 50만이며, 현재 지적도와 겹쳤을 때 위치가 맞는지 시범 확인이 필요하다.
5. 필지 고유번호가 들어간 파일명과 일련번호만 있는 파일명이 섞여 있어, 일련번호로 서로 연결해야 한다. 파일명 뒷부분 규칙(2003년 스캔 일련번호, 법정동·도면 번호형)은 담당자 확인이 필요하다.
6. 한 필지에 원도가 여러 장(최대 4장 이상)일 수 있다.
7. 원도에는 옛 소유자 이름 등이 적혀 있어 대민 서버에는 노출하지 않고, 메뉴 권한으로 토지정보과 등 지정 부서에만 연다.
8. 원도 한 장이 약 12MB라 처음 표시에 수 초가 걸릴 수 있다. 내부 업무용으로는 허용하고, 대량 열람·현장·대민 활용이 필요해지면 타일 변환을 추가 검토한다.
