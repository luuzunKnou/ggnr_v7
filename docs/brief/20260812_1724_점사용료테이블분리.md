# 작업요청서

2026-08-12 | dev.strcat | 점사용료 스케줄러·테이블 분리

## 배경

점사용료가 하천·도로·국공유지로 나뉘는데, 지금은 한 테이블·한 스케줄러로만 맞춰져 있다. 프로젝트마다 스케줄러를 끄고, 세입과목명에 따라 저장 테이블을 갈라야 한다.

## 활용

1. 운영자가 runtime에서 점사용료 스케줄러만 끌 수 있다.
2. 허용된 시스템(하천·도로·건설)에 해당하는 점사용료만 연계·저장한다.
3. 지도 점사용료 화면은 시스템마다 해당 테이블을 조회한다.

## 필요 기능

1. runtime에 스케줄러 차단 목록을 두고, 이름으로 점사용료 스케줄러를 끈다.
2. 연계 시 세입과목명으로 하천·도로·국공유지 테이블에 나눠 저장한다.
3. 기존 단일 점사용료 테이블은 하천용으로 이름을 맞춘다.
4. 화면·조회는 공통 점용대장처럼 같은 코드에서 접두만 바꿔 처리한다.

## 참고·제약

DB 테이블 생성·이름 변경은 스키마 소스와 SQL 스크립트만 준비하고, 실제 DB 적용은 별도 요청 시 진행한다.
