# 작업요청서

2026-08-13 | JungWooojin | 드론촬영시스템 · 드론영상 실기능

## 배경

드론촬영 메뉴의 «드론영상»은 목록·변환·지도 표시가 목업이다. 사진·동영상은 이미 업로드·진행률·작업단위가 동작하므로, 드론영상도 같은 업무 흐름으로 올리고 변환까지 이어가야 한다. 개발자모드 정사영상 변환과 같은 방식으로 타일을 만들되, 배경지도 «자체항공영상»에 넣지 않고 드론영상 화면에서만 켜고 끈다.

## 활용

1. 촬영요청이 드론영상인 건을 승인·등록할 때 담당자가 작업단위 폴더를 만들고 TIF를 올린다.
2. 업로드가 끝나면 변환이 바로 큐에 들어가 진행률을 보며 기다린다.
3. 변환이 끝난 영상을 드론영상 목록·상세에서 선택해 지도에 올리고 끈다.
4. 사진·동영상과 구분된 드론영상 자료로 이력을 관리한다.

## 필요 기능

1. 촬영요청 유형이 드론영상일 때 작업단위 폴더명에 «드론영상»이 들어가고, 저장 경로는 사진·동영상과 같이 항공자료의 드론영상 폴더 아래 작업단위 폴더다.
2. TIF 업로드 후 메타데이터를 전용 테이블에 남긴다.
3. 업로드가 끝나면 정사 변환을 바로 큐에 넣고, 진행률은 사진·동영상 작업단위와 같은 방식으로 보여 준다.
4. 변환 결과는 배경지도 자체항공영상에 등록하지 않는다.
5. 드론영상 관리·조회 화면에서 변환 완료 건을 체크해 지도에 켜고 끌 수 있다.
6. 드론영상 목록·상세의 목업 데이터를 실제 작업단위·TIF·변환 상태로 바꾼다.

## 참고·제약

1. 변환 엔진은 개발자모드 정사영상관리와 동일한 방식을 재사용한다.
2. 원본은 항공자료 드론영상 경로, 변환 산출은 시스템에서 드론영상 전용으로 구분할 수 있게 둔다.
3. DB 테이블 반영(푸시·마이그레이션)은 스키마 작성 후 사용자가 적용한다.
