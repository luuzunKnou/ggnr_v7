# 작업요청서

2026-10-23 | 213am | —

## 배경

상수도 행정에는 관망조회가 있으나, 하수도 행정 업무지원에는 같은 조회가 없다. 하수 담당자도 지도에서 관로와 시설을 같은 방식으로 찾아야 한다.

## 활용

1. 하수 담당자가 현장 확인 전 관로·맨홀·물받이 위치를 지도에서 조회한다.
2. 화면 범위나 지정 구역 안의 시설을 목록으로 걸러 상세를 본다.
3. 현황 연장·개수를 패널에서 확인하고, 목록은 엑셀과 도형 파일로 내려받는다.

## 필요 기능

1. 하수도 행정 메뉴에 관망조회를 둔다.
2. 구분은 관로, 배수설비, 하수도시설, 기타로 나눈다.
3. 관로는 하수관거, 측구, 하수연결관이다.
4. 배수설비는 배수설비와 배수설비구역이다.
5. 하수도시설은 맨홀, 물받이, 토구, 환기구, 우수토실, 펌프장, 처리장, 역사이펀, 집수정으로 구성한다.
6. 기타는 심도, 면형관거, 처리·배수 구역과 분구, 업데이트 내역이다.
7. 연도·관경·재질·검색, 목록·상세·지도 클릭, 구역설정, 단면도, 엑셀, 다운로드, 현황을 함께 둔다.

## 참고·제약

상수 관망조회 화면을 따른다. 상수 전용 관망도 출처와 급수·단수 기능은 넣지 않는다. 저장과 편집은 하지 않는다.
