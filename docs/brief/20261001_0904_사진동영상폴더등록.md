# 작업요청서

2026-10-01 | JungWooojin | —

## 배경

사진·동영상은 화면에서 파일을 하나씩 올려야만 목록에 나온다. 같은 작업의 파일이 많으면 등록이 오래 걸린다.

## 활용

1. 담당자가 사진·동영상 자료 폴더 안에 작업 이름과 같은 폴더를 만들고 사진·동영상을 넣는다.
2. 잠시 뒤 지도의 사진,동영상 목록에 그 작업과 파일이 올라온다.
3. 이미 있는 작업 폴더에 파일을 더 넣으면 그 파일만 추가로 등록된다.

## 필요 기능

1. 사진·동영상 자료 폴더의 하위 폴더 이름이 작업 이름이 된다.
2. 그 폴더 안의 사진·동영상을 주기적으로 읽어 등록한다.
3. 사진에 위치 정보가 있으면 지도 좌표로 저장하고, 없거나 동영상이면 위치 없이 등록한다.
4. 이미 등록된 파일은 다시 올리지 않는다.
5. 복사가 끝나기 전의 파일은 등록하지 않는다.
6. 드론영상·항공뷰·항공영상은 이번 범위가 아니다.

## 참고·제약

화면에서 올리는 기존 등록은 그대로 둔다. 자료 폴더에 넣은 파일만 추가로 읽는다.
