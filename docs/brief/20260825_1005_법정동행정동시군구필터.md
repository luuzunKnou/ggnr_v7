# 작업요청서

2026-08-25 | dev.strcat | 레이어설정 코드

## 배경

법정동·행정동 코드표는 곧 전국 값이 한곳에 모인다. 프로젝트마다 자기 시군구만 보여야 하는데, 지금은 구분 없이 전부 나온다.

## 활용

1. 관리자가 레이어설정 코드에서 법정동·행정동을 열면 해당 시군구만 보고 고친다.
2. 영양·울진처럼 시군구가 다른 프로젝트는 자기 읍면동만 다룬다.
3. 이후 지도 부서업무 선택 목록도 같은 기준으로 맞출 수 있다.

## 필요 기능

1. 레이어설정 코드에서 한글명이 법정동 또는 행정동인 필드만 시군구 기준으로 목록을 줄인다.
2. 기준은 실행환경의 시군구 코드 앞 다섯 자리와, 코드값 앞 다섯 자리가 같은 항목이다.
3. 화면에 안 보이는 다른 시군구 코드는 저장해도 지워지지 않아야 한다.
4. 지도 부서업무 쪽 필터는 이번 범위에 넣지 않고, 같은 기준을 나중에 재사용한다.

## 참고·제약

지금은 코드표에 안동만 들어 있어, 영양·울진에서는 해당 목록이 비어 보일 수 있다. 전국 코드를 넣은 뒤에 해당 시군구만 나타난다.
