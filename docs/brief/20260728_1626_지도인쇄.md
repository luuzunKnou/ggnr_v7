# 작업요청서

2026-07-28 | dev.strcat | 지도 인쇄(v6 이식)

## 배경

지도 화면에서 현재 보고 있는 위치를 문서·보고용으로 바로 뽑을 수 있어야 한다. 이전 버전에서는 인쇄 전용 화면에서 주석·측정·도형을 넣은 뒤 이미지 저장·인쇄까지 한 번에 할 수 있었으나, 현행에는 인쇄 버튼만 있고 실제 동작이 없다.

## 활용

1. 담당자가 현장·민원·보고 자료를 만들 때 지도 화면을 그대로 인쇄하거나 이미지로 저장한다.
2. 인쇄 전에 위치·글자·거리·면적·고도·경사 정보를 지도 위에 표시해 설명한다.
3. 점·선·면 도형과 색으로 관심 구역을 강조한 뒤 출력한다.
4. 필요 시 레이어 켜기·끄기, 배경지도를 바꿔 가며 출력 내용을 맞춘다.
5. 잘못 그린 내용은 선택 삭제·되돌리기·다시 실행·초기화로 바로잡는다.

## 필요 기능

1. 지도에서 «인쇄»를 누르면 인쇄 전용 전체 화면이 열린다.
2. 인쇄 화면은 메인 지도의 위치·확대 수준·켜진 레이어·배경을 이어받는다.
3. 색상 선택, 위치 찍기, 글자 입력이 가능하다.
4. 거리·면적·고도·경사 측정이 가능하다.
5. 점·선·직사각형·다각형·정사각형·원 도형을 그릴 수 있다.
6. 좌표 입력으로 위치를 지정할 수 있다.
7. 선택 삭제·되돌리기·다시 실행·초기화가 가능하다.
8. 이미지 저장과 인쇄가 가능하다.
9. 인쇄 화면에서 레이어 켜기·끄기, 배경지도 변경이 가능하다.
10. 화면 하단에 참고 문구·축척·담당자·일시가 보인다.

## 참고·제약

이전 버전 인쇄 화면을 기준으로 한다. 메인 지도의 측정·레이어 선택과 동작을 맞추되, 인쇄 전용 화면 안에서만 그리고 출력한다. 모바일 전용 인쇄는 이번 범위에서 후순위로 둔다.
