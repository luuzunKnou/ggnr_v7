# 작업요청서

2026-10-30 | gyujin | —

## 배경

형상파일을 도면으로 바꾸는 기능은 열려 있으나, 캐드에서 바로 여는 형식은 아직 없다. QCAD가 준비되었으므로 변환 때 형식을 고를 수 있어야 한다.

## 활용

1. 캐드 담당자가 형상파일을 캐드 형식으로 받아 바로 연다.
2. 도면 형식만 필요한 경우는 기존처럼 도면만 받는다.
3. 개발자 모드에서 작업 폴더를 골라 한 번에 변환한다.

## 필요 기능

1. File Converter «SHP to DXF»에서 도면(DXF)과 캐드(DWG)를 고를 수 있어야 한다.
2. 도면을 고르면 기존처럼 도면 폴더에 파일이 생겨야 한다.
3. 캐드를 고르면 같은 작업의 캐드 폴더에 파일이 생겨야 한다.
4. 캐드 변환 환경이 없으면 안내가 나오고 도면 변환은 그대로 가능해야 한다.

## 참고·제약

1. 캐드 변환은 도면을 만든 뒤 QCAD로 한 번 더 바꾼다.
2. 체험판은 파일마다 대기·제한이 있을 수 있다.
3. 속성은 이번에도 넣지 않는다.
