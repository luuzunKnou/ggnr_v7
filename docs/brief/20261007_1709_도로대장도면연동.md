# 작업요청서

2026-10-07 | dev.strcat | 경산 도로대장 레이어 업데이트

## 배경

도로대장 상세의 «매설물도·종평면도·용지도» 버튼은 연결된 공간정보가 없어 눌러도 «준비 중» 안내만 나왔다. 경산 군도 도로대장 전산화 용역으로 노선별 용지도·종평면도·지하매설물도 구역 레이어와 도면 파일이 확보되어 상세 화면에서 바로 볼 수 있도록 연결이 필요하다.

## 활용

1. 도로 관리 담당자가 노선 상세에서 해당 노선의 용지도·종평면도·매설물도 목록을 확인한다.
2. 도면 한 장을 골라 지도에서 위치를 확인하고, 첨부된 도면 이미지·PDF를 크게 열어 본다.
3. 굴착·점용 협의 전 매설물도를 바로 열어 지하시설 위치를 확인한다.
4. 용지 보상·경계 민원 응대 시 용지도를 현장 위치와 함께 대조한다.

## 필요 기능

1. 노선 상세의 «매설물도·종평면도·용지도» 버튼이 레이어가 있을 때 활성화되고, 해당 노선의 도면 건수가 표시되어야 한다.
2. 버튼을 누르면 지도에 해당 도면 구역 레이어가 켜지고, 상세 아래쪽에 도면 목록 탭이 나와야 한다.
3. 도면 목록은 노선(도로대장 식별번호)과 같은 노선·구간의 도면만 보여야 한다.
4. 도면을 고르면 지도에서 그 구역으로 이동해 강조하고, 하천 기본계획 색인도 상세처럼 첨부 도면 미리보기와 속성이 나와야 한다.
5. 첨부 도면은 분할코드(예: KS_GD_000012_JM_0002) 기준 폴더에서 불러오며, 이미지·PDF는 전체화면으로 넘겨 볼 수 있어야 한다.
6. 속성 항목 이름·표시 여부는 레이어 관리 설정을 그대로 따른다.
7. 상세에서 «목록으로»를 누르면 도면 목록으로 돌아가야 한다.

## 참고·제약

1. 레이어: 용지도, 종평면도, 지하매설물도 (경산 도로대장 레이어 업데이트 자료, 노선당 각 12장).
2. 노선 연결은 기존 시설 목록과 같은 도로대장 식별번호 규칙을 쓴다.
3. 첨부 저장소는 도로대장 보고서와 같은 공통 첨부 저장소를 쓴다.
4. 주요시설~기타시설 목록·속성 팝업 동작은 기존과 같아야 한다.
