# 작업요청서

2026-09-21 | gyujin | —

## 배경

프로젝트마다 쓸 시스템·기능·레이어 그룹이 다른데, 지금은 시스템 변수에 키를 직접 넣거나 공통 목록을 고쳐야 해서 한눈에 구성하기 어렵다.

## 활용

1. 개발·구축 담당자가 현재 프로젝트 기준으로 노출할 시스템을 고른다.
2. 프로젝트에서 숨길 기능을 한꺼번에 끈다.
3. 시스템별 데이터조회 레이어 그룹을 프로젝트 단위로 맞춘다.

## 필요 기능

1. 개발자 모드에 «프로젝트 구성» 메뉴가 있다.
2. 현재 프로젝트 이름이 보이고, 시스템 켜기/끄기를 저장할 수 있다.
3. 기능 목록에서 이 프로젝트에서 숨길 기능을 고를 수 있다.
4. 켠 시스템마다 레이어 그룹을 고를 수 있고, 저장 후 데이터조회에 반영된다.
5. 값은 해당 프로젝트 runtime 설정 파일에 저장된다. 공통 카탈로그 파일은 바꾸지 않는다.

## 참고·제약

기존 시스템·기능·레이어 목록관리·시스템 변수 메뉴는 유지한다. 카탈로그 정의는 기존 화면, 프로젝트 노출만 새 메뉴에서 다룬다.
