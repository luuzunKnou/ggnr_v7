# 작업요청서

2026-10-22 | gyujin | 토지정보과

## 배경

토지정보과는 토지대장·지적도·측량성과도 등 지적 기록물을 민원·경계 확인·등록사항 검토에 자주 쓰지만, 지금은 파일 보관 위치를 따로 찾아 열어 본다. 지도에서 기록물 목록을 보고 속성과 첨부 원본을 바로 확인할 화면이 필요하다. 실제 자료 연결 전에 화면 구성을 먼저 확정한다.

## 활용

1. 지적 담당자가 민원 응대 시 해당 지번의 대장·도면 기록물을 목록에서 찾아 속성과 스캔본을 확인한다.
2. 경계 분쟁·등록사항 정정 검토 시 관련 측량성과도와 폐쇄대장을 첨부 뷰어로 대조한다.
3. 신규 담당자가 기록물 종류별 구성(속성·첨부)을 화면에서 먼저 익힌다.

## 필요 기능

1. 지도 사이드바에 «지적기록물» 메뉴를 둔다.
2. 메뉴를 열면 기록물 목록이 나오고, 종류·읍면동·연도·검색으로 좁힌다.
3. 목록에서 한 건을 고르면 옆 패널에 속성이 나온다.
4. 같은 상세에 해당 기록물의 첨부파일이 표시된다.
5. 첨부파일을 누르면 뷰어가 열려 스캔 이미지를 본다. 미리보기 없는 파일은 뷰어를 열지 않는다.

## 참고·제약

1. 1차는 임시 자료로 화면만 만든다. 서버 조회·저장·실제 파일 연동은 포함하지 않는다.
2. 지도에 경계를 그리거나 필지를 클릭해 찾는 동작은 이번 범위에 넣지 않는다.
3. 안동 프로젝트의 공간정보조회 시스템 메뉴에 둔다.
