# 작업요청서

2026-11-13 | dev.strcat | 데이터관리 · 기준 레이어와 첨부 파일 비교

## 배경

기준이 되는 DB 레이어와, 새로 받은 파일(엑셀·SHP·DBF 등)이 같은지 빠르게 보고 싶다. 역할 이름·판정 문구보다, 먼저 구조가 맞는지 보고, 맞춰진 데이터끼리 무엇이 다른지만 보면 된다.

## 활용

1. 담당자가 기준 레이어를 고르고 받은 파일을 올려 1차로 구조 차이를 확인한다.
2. 맞춰진 행·항목에 대해 값 차이를 보고 갱신·인수 범위를 가늠한다.
3. 필요하면 결과를 엑셀로 넘긴다. 시스템 반영은 하지 않는다.

## 필요 기능

1. 개발자 도구 데이터관리에 비교 메뉴를 둔다. (기존 비교 화면은 이 방향으로 단순화·교체)
2. 기준은 DB 레이어만 고른다.
3. 비교 대상은 첨부 파일(xlsx, shp, zip, dbf 등)이다. 파일은 임시로만 올리고 정의·지도서비스·목록에 남기지 않는다. 끝나면 정리한다.
4. 1차 비교(구조): 컬럼, 건수, 도형 타입, 좌표계를 양쪽으로 보여 주고 차이를 표시한다. 컬럼은 같은 것·기준만·파일만으로 나눈다.
5. 맞춰진 데이터에 대해 무엇이 다른지 결과를 보여 준다. (짝이 난 행의 값 차이 중심)
6. 반영·저장 버튼은 두지 않는다.

## 참고·제약

- 공공/수급 역할 라벨·판정 배너보다 «구조 먼저 → 맞춘 뒤 값 차이»가 우선이다.
- 짝 짓는 방식(키·위치)은 화면에서 짧게 고를 수 있게 하되, 1차 구조 비교는 짝 없이도 바로 볼 수 있게 한다.
- 미니맵은 넣지 않는다.
