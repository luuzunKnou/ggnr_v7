# 작업요청서

2026-10-23 | dev.strcat | 점용대장 원천자료(도로점용대장·점용필지, 하천점용대장·점용필지) 수령

## 배경

점용대장은 지금 «공통 점용»(하천점용·도로점용·국공유지)과 «울진 하천점용» 두 갈래로 따로 만들어져 있다. 실제 원천자료를 받아 보니 허가번호가 없는 건이 많고(울진 하천점용 511건 중 301건), 점용기간도 날짜만 있는 것이 아니라 «영구», «허가일로부터 3개월», «2024.03~2028.12.31»처럼 글자가 섞여 있다. 허가번호로 필지를 묶고 기간을 날짜로만 받는 지금 구조로는 받은 자료를 그대로 담을 수 없다. 또 원천자료는 칸 이름이 10글자를 넘을 수 없어(도형 파일 제약) 칸 이름을 맞춰야 한다.

## 활용

1. 하천·도로 담당자가 받은 점용대장·점용필지를 그대로 올려 한 화면(공통 점용)에서 조회·수정한다.
2. 허가번호가 없는 점용 건도 필지목록과 함께 관리한다.
3. 점용기간이 날짜가 아닌 글자(영구, 허가일로부터 ○개월 등)여도 그대로 적고 본다.
4. 점용 건을 열면 필지목록에서 필지를 골라 필지별 상세를 본다(보상편입용지와 같은 방식).
5. 물건지 목록·점사용료 이력은 필요할 때만 버튼으로 펼쳐 본다.

## 필요 기능

1. 공통 점용 하나로 하천점용(울진 하천점용 자료 기준)·도로점용·국공유지를 처리한다.
2. 대장마다 같은 뜻의 칸은 같은 영문 이름(10글자 이내)으로 맞추고, 대장에만 있는 칸은 추가속성(extra)에 넣는다.
3. 필지·물건지는 허가번호가 아니라 점용 건의 고유키로 연결한다.
4. 점용 시작·종료는 글자로 입력·저장하고, 날짜로 읽히는 경우에만 진행중·종료 상태와 만료 알림에 쓴다.
5. 필지는 받은 칸을 그대로 쓰고, 레이어 설정(필드 정의)으로 보일 칸·숨길 칸을 정한다.
6. 상세 화면은 속성정보·추가속성·필지목록(선택 시 필지 상세)을 다른 화면과 같은 모양으로 맞춘다.
7. 물건지 목록·점사용료 이력은 상단 버튼으로 펼치는 방식으로 정리한다.
8. 첨부파일은 지금 방식 그대로 쓴다.

## 참고·제약

1. 테이블 이름: 하천점용 → 울진 하천점용 테이블, 도로점용 → 받은 도로점용대장 테이블, 국공유지 → 지금 이름 그대로.
2. 기준 자료는 울진 자료로 잡고 순서대로 맞춰 나간다.
3. 1단계(지금): 필지 연결을 고유키로 바꾸고, 점용 시작·종료를 글자 입력으로 바꾼다. 테이블 이름 전환·칸 이름 맞춤·상세 화면 개편은 다음 단계.
4. 기존 도로점용 필지(허가번호로만 연결된 273건)는 화면에서 계속 보이게 하고, 저장할 때 고유키 연결로 옮긴다.
5. 날짜 형식 칸을 글자 칸으로 바꾸는 DB 변경은 서버 기동 시 앱이 처리하며, 운영 반영 전 확인이 필요하다.
