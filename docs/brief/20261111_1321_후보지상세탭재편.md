# 작업요청서

2026-11-11 | dev.strcat | 소규모 공공시설 후보지 상세

## 배경

1. 후보지 상세에 평가·점검·정비계획·첨부가 탭으로 나뉘어 있어, 같은 시설의 평가 자료를 한곳에서 보기 어렵다.
2. 후보지 평가와 안전점검은 실제로는 평가표 파일을 올리고 일자·담당·결과만 남기는 업무인데, 화면은 항목 입력과 정비계획 요약까지 섞여 있다.
3. 피해 내용은 정비계획 분석의 피해이력지수와 맞물려야 하는데, 시설에 따로 두지 않아 분석할 때마다 다시 넣게 된다.

## 활용

1. 담당자가 후보지 상세에서 후보지 평가 파일과 선정 결과만 모아 본다.
2. 위험도·일반·관리·현장조사 자료를 안전점검 한 탭에서 목록과 미리보기로 확인한다.
3. 시설별 피해 일자·내용·물량을 후보지에서 관리하고, 정비계획 분석은 그 값을 그대로 쓴다.
4. 요약·공공시설대장 등 평가가 아닌 자료만 첨부파일 탭에 둔다.

## 필요 기능

1. 상세 탭은 후보지 평가, 안전점검, 피해이력, 첨부파일 네 개만 둔다. 일반·관리 평가·위험도 평가·정비계획 탭은 뺀다.
2. 후보지 평가는 파일과 함께 평가일·평가자·선정여부를 넣고, 목록과 썸네일을 같이 보여 주며, 아래에 최근 결과를 둔다. 썸네일을 누르면 첨부 미리보기와 같이 연다.
3. 안전점검은 위험도 평가·일반·관리 평가·현장조사를 한 목록으로 두고, 목록과 썸네일·최근 결과를 보여 준다. 일반·관리는 해마다 없을 수 있다.
4. 첨부파일 탭에는 평가가 아닌 요약·공공시설대장 등만 올린다.
5. 피해이력에는 피해 내용·날짜·물량 등을 넣고, 정비계획 분석의 피해이력은 여기서 읽어 가며 분석 화면에서는 고치지 않는다.

## 참고·제약

1. 파일 내용에서 평가일 등을 자동으로 뽑지 않고, 올릴 때 함께 입력한다.
2. 정비계획은 사이드바 메뉴에서만 다루고, 후보지 상세의 정비계획 이동은 두지 않는다.
3. 예시 자료·화면 저장소 단계이며, 서버 저장은 이후 작업이다.
