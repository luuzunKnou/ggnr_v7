# 작업요청서

2026-09-29 | dev.strcat | —

## 배경

하천기본계획 상세 안의 사유지 기능은 선을 두 번 직접 그어야 하고, 결과가 소유구분별 묶음으로만 보여 전체 필지를 한눈에 보기 어렵다. 하천 구간을 지도에서 바로 지정하고 구간 안 필지를 개인·국유지 등으로 나눠 목록으로 확인할 수 있는 별도 메뉴가 필요하다.

## 활용

1. 하천 담당자가 정비·보상 검토 전에 특정 하천 구간에 걸친 사유지 필지를 목록으로 확인한다.
2. 담당자가 개인·국유지·군유지 등 소유구분별로 필지를 걸러 보고, 주소로 원하는 필지를 찾는다.
3. 필지를 선택해 지도 위치와 소유자·토지 정보를 바로 확인한다.
4. 구간을 바꿔 가며 다시 분석해 구간별 사유지 현황을 비교한다.

## 필요 기능

1. 하천 시스템 사이드바에 «사유지분석» 메뉴를 둔다.
2. 메뉴를 열면 하천 대상 레이어(하천구역, 소하천구역) 목록을 보여 주고 하나를 고르도록 안내한다.
3. 레이어를 고르면 지도에 해당 레이어를 켜고, 지도에서 그 레이어 위를 찍어 분석 구간을 지정하게 안내한다.
4. 레이어 범위 밖을 찍으면 선택되지 않고 안내만 나온다.
5. 레이어 위를 찍으면 그 지점에서 하천 양쪽 경계까지 가로지르는 시작선이 생긴다.
6. 마우스를 움직이면 끝선이 따라오며 두 선 사이 구간이 지도에 보이고, 다시 찍으면 끝선이 정해진다.
7. «적용»을 누르면 두 선 사이 하천 구간이 확정되어 지도에 표시되고 «분석» 버튼이 켜진다.
8. «분석»을 누르면 구간과 겹치는 필지 전체가 목록으로 나온다.
9. 목록은 도로망도처럼 소유구분(전체·개인·국유지 등) 선택과 주소 검색으로 거를 수 있다.
10. «영역변경»으로 같은 레이어에서 구간만 다시 지정하고, «재설정»으로 레이어 선택부터 다시 시작한다.
11. 목록에서 필지를 고르면 오른쪽에 상세 패널이 열려 필지·토지·소유 정보를 보여 주고 지도에서 해당 필지를 강조한다.

## 참고·제약

1. 도로 시스템은 이번 범위에서 제외하고, 이후 도로 레이어 기준을 정해 같은 흐름으로 확장한다.
2. 소유구분은 기존 사유지 기능과 같이 연속지적의 소유구분 값을 쓰고, 소유자 정보는 필지정보 조회를 재사용한다.
3. 두 선 사이 구간 계산은 기존 하천기본계획 사유지 기능의 구간 선택 방식을 따른다.
4. 하천기본계획 상세의 기존 사유지 기능(현재 버튼 숨김)은 그대로 둔다.
5. 데이터베이스 구조 변경은 없다.
