# 작업요청서

2026-10-19 | dev.strcat | 도로관리 — 도로대장 도로영상

## 배경

도로대장 «도로영상»은 360° 영상을 볼 수는 있지만, 지금 보는 장면이 노선 어디인지 지도에서 알 수 없다. 영상에 위치(GPS) 기록이 없고, 영상이 들어올 때마다 사람이 기준점을 찍는 방식은 담당자 부담이 커서 쓰기 어렵다.

영상 화면의 움직임(회전·전진)을 분석해 노선 모양(굽이·교차로)에 자동으로 맞추는 시험에서 굽이·교차로 근처는 수십 m 안으로 맞는 것을 확인했다. 이 방식으로 영상이 첨부되면 서버가 자동으로 위치를 맞추고, 영상과 지도를 함께 보게 한다.

## 활용

1. 도로 담당자가 사무실에서 도로영상을 재생하면서 지도에서 지금 장면의 위치와 진행 방향을 함께 확인한다.
2. 민원·점검 위치를 지도에서 고른 뒤 자동차를 그 자리로 옮겨 해당 구간 영상을 바로 본다.
3. 영상 관리자는 첨부 폴더에 영상을 올리기만 하고, 위치 맞춤은 서버가 알아서 처리한다.
4. 분석이 아직 안 된 영상도 노선 시작~끝을 시간 비율로 나눈 대략 위치로 볼 수 있다.

## 필요 기능

1. 서버가 10분마다 도로대장 첨부 폴더를 확인해, 위치 맞춤 자료가 없는 도로영상을 한 개씩 자동으로 분석한다.
2. 분석은 영상의 회전·이동을 노선 굽이·거리에 맞추고, 교차로에서 한 바퀴 도는 구간은 교차시설 위치에서만 제자리 회전으로 처리한다.
3. 영상이 노선 시작→끝 방향인지 반대 방향인지 자동으로 판단한다.
4. 분석 결과(영상 정보, 시각별 노선 위치)는 DB에 저장하고, 같은 영상이 바뀌면 다시 분석한다. 실패한 영상은 같은 파일이면 다시 시도하지 않는다.
5. 도로영상은 지도를 가리지 않는 이동·크기 조절 창으로 띄운다.
6. 영상 재생 위치에 맞춰 지도에 자동차 모양이 노선을 따라 진행 방향으로 움직인다.
7. 지도에서 자동차를 끌어 놓거나 노선을 누르면 영상이 그 위치 장면으로 옮겨 간다.
8. 창에 위치 맞춤 상태(자동 맞춤 완료·분석 대기·분석 실패)를 표시하고, 분석 전에는 시간 비율 위치로 보여 준다.

## 참고·제약

1. 영상 위치: 도로대장 첨부 폴더(도로대장 요약 레이어, 도로 고유번호 폴더)의 360° 영상(mp4 등).
2. 분석 도구는 서버 Python 환경에 영상 분석 라이브러리를 추가해 쓴다(환경 설치·분할압축 배포에 포함).
3. 처리 시간: 10분 영상 기준 개발 PC에서 약 2분. 서버 성능에 따라 더 걸릴 수 있어 한 번에 한 개씩 처리한다.
4. 정확도: 굽이·교차로 근처는 약 10~30m, 긴 직선 구간은 최대 약 100m 어긋날 수 있다. 정지 구간 판별은 약하다.
5. 슈퍼계정 기준점 보정은 이번 범위에서 제외하고, 저장 구조만 보정을 넣을 수 있게 둔다.
6. 이전 기준점 파일 방식(첨부 폴더에 기준점 파일 저장)은 쓰지 않는다.
