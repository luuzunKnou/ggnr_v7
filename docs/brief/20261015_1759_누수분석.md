# 작업요청서

2026-10-15 | luuzunKnou | —

## 배경

누수 지점을 알면 어느 제수변을 잠가야 구간을 막을 수 있는지 바로 알고 싶다. 단수구역과 같은 화면에서 관망에 붙여 위치를 고르고 잠글 제수변 목록을 보고 싶다.

## 활용

1. 현장·민원 누수 위치를 지도 관망에 스냅해 지정한다.
2. 분석 결과로 잠가야 할 제수변 목록을 확인하고 작업에 쓴다.
3. 세션 이력으로 같은 분석을 다시 불러본다.

## 필요 기능

1. 지도 클릭 시 상수관로에 스냅해 누수 위치를 잡는다.
2. 해당 위치 기준으로 격리에 필요한 제수변 목록을 보여 준다.
3. 화면 구성은 단수구역과 같이 이력·결과·하단 액션(새 분석·분석결과저장)을 쓴다.

## 참고·제약

제수변은 기존과 같이 제수변(SA200)만 대상으로 한다. 저장소 없이 세션 이력만 유지한다.
