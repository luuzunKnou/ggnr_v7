# 작업요청서

2026-10-01 | luuzunKnou | 상수도 행정 업무지원

## 배경

상수도 업무에서 계량기 위치를 여러 필지에 걸쳐 확인할 때, 주소를 하나씩 지도에서 찾는 시간이 길어집니다. 주소 목록을 한 번에 넣고 해당 필지를 지도에서 함께 보는 메뉴가 필요합니다.

## 활용

1. 급수·시설 담당자가 계량기 확인 대상 주소를 붙여 넣고, 해당 필지를 지도에서 한꺼번에 봅니다.
2. 같은 읍·면·동의 인접 주소를 비교할 때 필지 위치를 한 화면에서 확인합니다.

## 필요 기능

1. 상수도 행정 업무지원 사이드바에 «계량기위치» 메뉴가 있어야 한다.
2. 주소를 한 줄에 하나씩 텍스트로 입력할 수 있어야 한다.
3. 입력한 주소의 필지를 지도에 일괄 표시해야 한다.
4. 찾지 못한 주소는 목록에서 구분되어야 한다.
5. 계량기 속성·저장·검침 등 이후 단계는 이번 범위에 넣지 않는다.

## 참고·제약

1. 입력 예는 «읍·면·동 도로명 건물번호»이다.
2. 건물번호가 다른 주소(예: 18과 18-1)는 서로 다른 위치로 본다.
3. 지역은 접속 지자체 범위 안에서 찾는다.
