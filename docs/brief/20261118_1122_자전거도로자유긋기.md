# 작업요청서

2026-11-18 | dev.strcat | 도로 부서업무 · 자전거도로

## 배경

기점이 같고 종점이 다른 경우, 기점이 다르고 종점이 같은 경우, 기점·종점이 겹치는 경우가 섞여 있다. 시스템이 경로를 대신 정하면 한 바퀴 돌거나 좌·우 길이를 맞출 수 없다. 도로 형태만 보여 주고 사용자가 자유롭게 긋고, 여러 줄을 모았다가 한꺼번에 넣는 편이 맞다.

## 활용

1. 담당자가 수정 중 «추가»로 편측·우측·좌측을 고른 뒤 도로 안내선 위에 점을 찍어 한 줄을 만든다.
2. «이 줄 확정»으로 초안에 쌓고, 같은 방식으로 다른 측·다음 구간을 더 그린다.
3. 같은 기점·종점이 필요하면 이미 찍힌 끝점에 맞춰 찍는다.
4. «일괄 반영»으로 표·지도에 한꺼번에 넣는다.

## 필요 기능

1. 도로구간은 안내·스냅만 하고, 점과 점 사이 최단경로는 쓰지 않는다. 찍은 점 순서대로 잇는다.
2. 한 줄은 한 측(편측·우·좌) 구간 행이다. 좌·우 기점·종점·길이는 서로 달라도 된다.
3. 편집 세션에서 여러 줄을 초안으로 모은 뒤 일괄 반영한다. 취소면 초안 전체만 버린다.
4. 되돌리기는 현재 줄의 마지막 점을 지운다.

## 참고·제약

기존 양측 한 번에 평행 오프셋은 쓰지 않는다. 측별로 따로 긋는다. 우·좌는 그린 중심 경로를 해당 측으로 밀어 표시한다.
