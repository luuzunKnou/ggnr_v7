# 작업요청서

2026-08-12 | JungWooojin | 영상관리·승인관리

## 배경

촬영요청 승인 후 작업단위 폴더는 만들 수 있으나, 사진·동영상을 그 폴더에 올리고 촬영 위치를 지도에 보여 주는 흐름이 없다. 자료 등록을 끝내기 어렵다.

## 활용

1. 승인 담당자가 승인 상세에서 폴더를 만든 뒤 바로 사진·동영상을 올린다.
2. 영상관리 «사진,동영상» 상세에서도 같은 폴더에 파일을 추가한다.
3. 올린 사진의 위치를 상세 목록에서 눌러 지도에서 확인한다.

## 필요 기능

1. 사진·동영상 작업단위에만 파일 업로드가 된다.
2. 여러 파일을 한 번에 고를 수 있다.
3. 폴더 생성 직후 파일 선택 창이 열린다.
4. 파일은 데이터 루트 작업단위 폴더에 저장되고, 메타(좌표 등)는 작업단위 테이블에 저장된다.
5. 사진 좌표는 5181로 변환해 저장하고, 동영상은 좌표가 없으면 좌표 없이 저장한다.
6. 상세에서 파일을 누르면 지도가 해당 좌표로 이동·표시한다.
7. 업로드가 끝나면 연결 신청은 등록완료가 된다.

## 참고·제약

- 정사·파노라마·항공 업로드는 이번 범위 밖이다.
- DB 테이블 반영(푸시)은 사용자가 직접 실행한다. 스키마 소스만 추가한다.
