## 목적

불법점용 관리카드 패널을 열면 지도에 전체 카드 위치가 레이어로 보이고, 점을 클릭하면 해당 목록·상세가 열리도록 한다.

## 요약

관리카드 목록이 열릴 때 `illegal_usage_as` WMS를 켜고, 닫을 때 끈다. 지도에서 해당 레이어를 클릭하면 목록 선택과 상세 패널이 열린다. 저장·삭제 후에는 지도 점을 다시 불러와 반영한다. 패널 전용 레이어는 지도 상태 저장에서 제외한다.

## 테스트

1. 사이드바에서 불법점용 관리카드를 열면 지도에 관리카드 점 레이어가 보여야 한다.
2. 관리카드 패널을 닫으면 해당 점 레이어가 사라져야 한다.
3. 지도에서 관리카드 점을 클릭하면 목록에서 해당 행이 선택되고 상세가 열려야 한다.
4. 점이 없는 위치를 클릭해도 관리카드 상세가 잘못 열리지 않아야 한다.
5. 위치 저장·삭제 후 지도 점 위치가 반영되어야 한다.
6. 다른 지도 기능으로 전환한 뒤 다시 들어와도 관리카드 레이어가 잔상으로 남지 않아야 한다.
