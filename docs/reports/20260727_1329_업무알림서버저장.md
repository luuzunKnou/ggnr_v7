# 결과보고서

2026-07-27 | dev.strcat | 업무 알림 서버 저장·시스템 필터

## 목적

알림 읽음·지우기를 계정별 서버에 두고, 로그인 후 후보를 먼저 받은 뒤 시스템(하천 등)에 맞는 항목만 보여 준다.

## 요약

기존 브라우저 저장 방식은 브라우저를 초기화하면 알림이 다시 떴다. 계정별 상태 테이블을 두고 읽음·지우기를 서버에 저장한다. 후보(만료·미납)는 한꺼번에 받은 뒤 URL 시스템 값으로 걸러 표시한다. 시스템 선택 화면에서도 로그인 상태면 미리 조회한다. 테이블 SQL은 담당자 적용이 필요하다.

## 테스트

1. SQL 적용 후 로그인하면 시스템 선택 화면에서도 알림 조회가 일어나야 한다.
2. 하천 지도에서 만료·미납 알림이 보여야 한다.
3. 알림을 지우면 브라우저 저장을 지워도 다시 나오지 않아야 한다.
4. 다른 브라우저·같은 계정에서도 읽음·지우기가 같아야 한다.
5. 하천이 아닌 시스템으로 들어가면 하천 전용 알림이 목록에 없어야 한다.
6. 테이블 미적용 시에도 후보 목록은 보이되, 지우기가 새로고침 후 유지되지 않을 수 있다.
