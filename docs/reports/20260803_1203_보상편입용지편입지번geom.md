# 결과보고서

2026-08-03 | gyujin | 편입 지번 우선 geom

## 목적

보상편입용지 필지 지도 도형을 당초 지번이 아닌 편입 지번 기준으로 맞춘다. 편입 조회 실패 시에만 당초 지번으로 폴백한다.

## 요약

필지 pnu·geom 해석을 편입 지번 우선으로 바꿨다. 저장·일괄 동기화·일괄 보강 경로에 동일 규칙을 적용했고, 기존 데이터는 전량 재조회해 당초≠편입 9건의 pnu가 편입 지번에 맞게 갱신됐다. 부모 케이스 geom도 자필지 합집합으로 다시 계산했다.

## 파일수정

수정 | src/service/roadRewardService.ts
 `resolveParcelPnuAndGeomByJibun` — 편입 지번으로 pnu/geom 조회 후 실패 시 당초 지번 폴백
 `fillMissingParcelPnuGeom` — refreshAll 시 기존 geom도 편입 기준으로 재조회, 갱신 후 부모 geom 재계산
 `syncParcels` / `saveParcel` — 당초 단독 조회를 편입 우선 해석으로 교체

해당 없음 (스키마 변경 없음. `layer.road_reward_parcel` pnu/geom·`layer.road_reward` geom 데이터 갱신)

## 테스트

1. 당초와 편입 지번이 다른 필지의 pnu 끝자리가 편입 번지에 맞아야 한다.
2. 해당 필지 지도 위치가 편입 필지여야 한다.
3. 편입 지번 조회가 안 되면 당초 지번 geom이 나와야 한다.
4. 필지 저장·일괄 동기화 후에도 편입 우선 규칙이 유지되어야 한다.
5. 부모 케이스 지도 범위가 자필지 합집합으로 보여야 한다.
