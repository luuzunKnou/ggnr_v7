## 목적
공통 점용 목록·사이드바에서 brief 없이 맞춘 UI와, 키를 기존처럼 순번으로 되돌린 처리, 수정 화면에서 본표 도형만 보이게 한 작업을 하루 보고로 모은다.

## 요약
목록에서 도형이 없으면 알림 없이 상세만 연다. 점용명·점용장소 헤더는 왼쪽, 나머지는 가운데다. 목록이 비어도 컬럼 헤더는 남긴다. 점용명이 없으면 키를 넣지 않고 빈 칸으로 둔다. 하천·도로 점용은 깃발, 국공유지는 기존 건물 아이콘이다. 목록·상세 키는 허가번호가 아니라 순번이며, 필지·물건지는 본표 허가번호로만 연결한다. 예전처럼 지적 id와 본표 순번을 맞추지 않아, 순번이 같은 다른 건 지적이 붙지 않는다. 목록·상세에서 점용명·점용장소의 시·군 접두는 앞뿐 아니라 가운데에 반복돼도 빼고 보여 준다. 수정 중 지도에는 본표 도형만 두고, 필지·물건지 지적 도형은 목록으로만 다루되, 목록에서 고르면 조회와 같이 지도에 강조한다. 도형수정 후 다시 그리면 기존 도형은 화면에서만 사라지고, 필지는 적용·저장 때 새 도형 기준으로 바뀐다. 주소검색으로 넣은 필지(본번만 있는 893 등)도 저장 시 지적 도형이 비지 않게 맞춘다. 수정에 들어가도 조회에 보이던 필지목록을 그대로 둔다. 주소가 그대로면 필지 자식 행(도형 포함)은 다시 쓰지 않는다. 저장 때 허가번호로 다른 행을 덮지 않는다. 수정에서는 허가번호를 새로 매기지 않고, 안 고친 필지·물건지·본표 도형은 빈 값으로 덮지 않는다. 조회에서 필지를 고르면 본표와 겹친 면만 강조하고, 겹치지 않으면 그 필지 도형 그대로 보여 준다. 레이어 관리는 탭을 열 때마다 설정·코드·추가속성을 한꺼번에 부르지 않고, 지금 보는 화면만 불러 목록이 빨리 나오게 한다.
