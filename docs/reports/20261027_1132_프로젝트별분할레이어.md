# 결과보고서

2026-10-27 | 213am | 지자체별 코드 분할 설정

## 목적

지자체마다 하수관거 등 코드 분할 세트가 다르므로, 공통 레이어 정의와 분리해 프로젝트별 설정으로 관리한다.

## 요약

코드 분할 선택·한글명·그룹을 `GGNR_PROJECT`별 설정 파일에 저장하고, 정의 조회·지도 목록·식별 시 해당 설정으로 자식 레이어를 교체한다. 안동 기본 세트를 이관했고, 함양처럼 압송관을 추가하는 경우 같은 방식으로 프로젝트 파일만 두면 된다.

## 테스트

1. `ggnr_ad`로 실행 시 하수관거 분할이 우수·오수·기타로 보여야 한다.
2. 레이어 설정에서 하수관거 분할을 열면 프로젝트명이 보이고 기존 선택이 유지되어야 한다.
3. 미리보기에서 한글명·그룹을 바꾼 뒤 발행하면 해당 프로젝트 설정 파일에 반영되어야 한다.
4. 압송관 코드를 추가 선택해 발행하면 기타 조건에서 압송이 제외되고 단독 레이어가 생겨야 한다.
5. 하수맨홀 교체대상(커스텀 분할)은 코드 분할 재발행 후에도 남아 있어야 한다.
6. 지하시설물 목록에 프로젝트에 없는 분할 레이어가 섞여 나오지 않아야 한다.
7. 프로젝트가 없는 환경에서 발행하면 안내 메시지가 나와야 한다.
8. 다른 지도 기능(메모·측정 등) 전환이 분할 설정과 무관하게 동작해야 한다.
