# 결과보고서

2026-07-31 | gyujin | 보상편입용지 UI 개선 후속 지시(모달 비차단화·도형편집·도로시스템 이관)

## 목적

보상편입용지가 도로 사업(도로 확장·선형개량 등)의 보상 업무와 맞닿아 있어, 하천 시스템이 아닌 도로 시스템에서 관리하도록 옮기고, 필지 정보 입력이 가운데 모달로 지도를 가리는 문제를 없애 도형(편입 영역) 편집이 가능하도록 개선했다.

## 요약

기존 하천 시스템의 «보상편입용지»(riverReward)를 도로 시스템의 «보상편입용지»(roadReward)로 폴더·설정을 모두 이관했다. 필지 수정 화면은 가운데 뜨는 모달을 없애고 상세 패널 안에서 바로 입력하는 방식으로 바꾸었으며, 필지마다 지도 위에서 편입 영역 폴리곤을 직접 그리거나 정점을 수정할 수 있게 했다(편집 중에도 지도 확대·축소·이동은 계속 가능). 상세 속성 표시는 공사대장 상세 화면과 같은 표 형식(항목명 칸 + 값 칸)으로 맞춰 빈 공간 문제도 함께 해결했다.

## 테스트

1. 도로행정 업무지원시스템 메뉴에서 «보상편입용지»가 보여야 하고, 하천행정 통합관리 시스템 메뉴에서는 더 이상 보이지 않아야 한다.
2. 사이드바 아이콘이 깨지지 않고 정상 표시되어야 한다.
3. 건명 목록에서 건을 선택하면 상세 패널에 속성 표(항목명+값 짝)와 필지 요약 표가 보여야 한다.
4. 상세 조회 화면에서 필지 행 클릭 시 모달 없이 지도만 해당 위치로 이동해야 한다.
5. «수정»을 누르면 속성 입력과 필지 인라인 카드가 함께 열려야 한다.
6. 필지 카드에서 감정평가1·2 금액이나 편입면적을 바꾸면 적용단가·보상금액이 자동으로 갱신되어야 한다.
7. 필지 카드의 «도형» 버튼을 누르면 가운데 모달 없이 지도 위 작은 안내 배너만 뜨고, 지도 확대·축소·이동이 계속 가능해야 한다.
8. 도형이 없는 필지는 지도 클릭으로 다각형을 그릴 수 있고, 세 점 미만이면 다시 그리라는 안내가 나와야 한다.
9. 이미 그린 필지 도형은 정점을 끌어 수정할 수 있어야 하고, «초기화»로 편집 시작 시점 도형으로 되돌아가야 한다.
10. «취소»를 누르면 속성·필지 변경이 모두 되돌아가고, «저장»을 눌러야 목록·조회 화면에 반영되어야 한다.
11. 새 건 추가·필지 추가/삭제·건 삭제가 정상 동작해야 한다.
