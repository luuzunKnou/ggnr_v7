# 결과보고서

2026-11-24 | JungWooojin | docs/plan 사이드바 메뉴 묶음

## 목적

도로 시스템 좌측 메뉴가 많아 스크롤이 생기므로, 업무 묶음 아이콘과 옆 패널로 줄여 찾기 쉽게 한다.

## 요약

도로 기능을 도로현황·점용·재산·안전·시설·분석·조회·업무기록 묶음으로 나눴다. 묶음 아이콘을 누르면 옆에 하위 기능이 나오고, 도형편집은 단독으로 둔다. 묶음 메타가 없거나 하위가 한 개뿐인 시스템은 예전처럼 한 줄로 보인다.

## 파일수정

수정 | src/config/serviceList.config

추가 | src/lib/mapSidebarGroups.ts

## 테스트

1. 도로 시스템에서 좌측에 묶음 아이콘(도로현황·점용·재산 등)과 도형편집이 보여야 한다.
2. 묶음 클릭 시 옆에 하위 기능 목록이 열려야 한다.
3. 하위 기능을 고르면 해당 패널이 열리고 플라이아웃이 닫혀야 한다.
4. 같은 묶음을 다시 누르거나 바깥을 누르면 플라이아웃이 닫혀야 한다.
5. 묶음에 속한 기능이 열린 상태면 해당 묶음 아이콘이 선택처럼 보여야 한다.
6. 묶음 메타가 없는 다른 시스템 사이드바는 이전처럼 개별 아이콘이 나열되어야 한다.
