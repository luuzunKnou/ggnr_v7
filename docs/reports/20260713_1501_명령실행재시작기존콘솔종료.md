# 결과보고서

2026-07-13 | 200BingSu | 버전관리 명령 실행 재시작 시 기존 콘솔 창 잔류

## 목적

「명령 실행」재시작으로 새 창에서 서버를 다시 띄울 때, 더 이상 쓰지 않는 기존 콘솔 창이 남지 않게 한다.

## 요약

명령 실행 모드는 `sourceVersionService`만으로 새 콘솔에서 재시작 명령을 돌리고, 프로세스 종료 직후 기존 cmd/PowerShell 창을 닫는다. `restart-watch`는 process.exit 전용으로 두며 command와 연동하지 않는다.

## 파일수정

수정 | src/service/sourceVersionService.ts
 `spawnDelayedRestartCommand` — Windows에서 start로 기존 창과 분리된 새 콘솔에서 재시작 명령 실행
 `scheduleClosePreviousConsoleWindow` — 조상 cmd/PowerShell만 지연 종료해 빈 기존 창 제거(새 재시작 창은 유지)
 `scheduleRestart` (command) — 재시작 예약 시 기존 콘솔 종료를 함께 예약

수정 | scripts/restart-watch.ps1
 process.exit 전용 유지 — command 분기·대기 루프 제거(선택지 간 영향 없음). exit가 아니면 감시만 종료

## 테스트

1. 명령 실행 재시작으로 적용하면 새 콘솔에서 서버가 떠야 한다.
2. 같은 적용 후 기존에 서버를 돌리던 콘솔 창은 닫혀야 한다.
3. process.exit 재시작(감시 스크립트)으로 적용하면 같은 창에서 서버가 다시 떠야 한다.
4. 재시작 안 함으로 적용하면 기존 콘솔이 강제 종료되지 않아야 한다.
5. 명령 실행 재시작 안내 문구에 기존 콘솔 종료·새 창 실행 의미가 보여야 한다.
