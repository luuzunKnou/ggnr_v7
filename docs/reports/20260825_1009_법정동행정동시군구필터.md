# 결과보고서

## 목적

레이어설정 코드에서 법정동·행정동만 현재 프로젝트 시군구에 해당하는 항목을 보여 준다. 전국 코드를 넣어도 다른 시군구 값은 저장 시 지워지지 않게 한다.

## 요약

실행환경 시군구 코드 앞 다섯 자리와 코드값 앞 다섯 자리가 같은 법정동·행정동만 목록에 나온다. 다른 코드 필드는 전체를 그대로 보여 준다. 저장할 때는 화면에 없는 다른 시군구 값을 유지한다. 지도 부서업무 필터는 이번에 넣지 않았고, 같은 거르기 규칙을 나중에 재사용할 수 있다.

지금은 코드표에 안동만 있어 영양에서는 해당 목록이 비어 보인다. 전국 코드를 넣으면 영양 시군구만 나타난다.

## 파일수정

추가 | src/lib/defineLayerSggCodeFilter.ts
 `isLegalOrAdminDongField` — 한글명이 법정동·행정동이거나 해당 코드 필드이면 대상으로 본다
 `filterCodesBySggPrefix` — 코드값 앞 다섯 자리가 시군구와 같은 항목만 남긴다
 `mergeSggFilteredCodesForSave` — 화면에서 고친 시군구 목록과 나머지 시군구 원본을 합쳐 저장한다

수정 | src/service/configService.ts
 `getSggCode` — 실행환경 시군구 코드를 화면에서 조회한다

수정 | src/app/(pages)/dev/_components/LayerCodeManager.tsx
 `sggFilterActive` — 법정동·행정동이고 시군구가 있을 때만 목록을 줄인다
 `saveConfig` — 필터가 켜져 있으면 다른 시군구 값을 유지한 채 저장한다
 `setSggView` — 시군구·전체 전환. 보이는 개수 / 전체 개수로 표시

## 테이블 수정

해당 없음

## 테스트

1. 레이어설정 코드에서 법정동을 열면 시군구 기준 버튼과 건수(해당 / 전체)가 한 줄에 나와야 한다.
2. 영양에서 법정동·행정동은 해당 시군구 코드만 보이거나, 없으면 0개 / 전체 개수로 나와야 한다.
3. 전체를 고르면 전체 개수 / 전체 개수가 나오고, 시군구를 고르면 해당 시군구만 나와야 한다.
4. 관리기관 같은 다른 코드는 전체가 나와야 한다.
5. 법정동에서 저장해도 다른 시군구 코드가 사라져서는 안 된다.
6. 시군구 값이 없는 프로젝트에서는 법정동·행정동도 전체를 보여야 한다.
