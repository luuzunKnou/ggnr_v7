# 결과보고서

2026-08-28 | 200BingSu | —

## 목적

하천 기본계획도 확장패널 «보고서» 버튼으로 선택 연도 기본계획의 PDF 보고서를 전용 뷰어에서 볼 수 있게 한다. 이미지 뷰어와 분리된 공용 PDF 뷰어를 두어 다른 화면에서도 재사용할 수 있게 한다.

## 요약

«보고서» 버튼을 항상 클릭 가능하게 연결하고, 선택 기본계획 `ogc_fid` 첨부 폴더의 PDF만 조회해 새 전체화면 PDF 뷰어를 연다. 뷰어는 확대·패닝·회전·다운로드·인쇄·파일·페이지 이동을 지원하며, 헤더 menu로 PDF 목록·페이지 썸네일 사이드바를 열고 닫을 수 있다.

## 테스트

1. 기본계획도 상세에서 «보고서» 버튼이 흐리게 보이지 않고 항상 클릭 가능해야 한다.
2. 연도 미선택·속성 로딩 중 클릭 시 안내 메시지가 나와야 한다.
3. PDF 첨부 없으면 «보고서 PDF가 없습니다» 안내가 나와야 한다.
4. PDF 있으면 전체화면 뷰어가 열리고 확대·패닝·회전·초기화·다운로드·인쇄가 동작해야 한다.
5. 헤더 menu 버튼으로 사이드바가 열리고 닫혀야 한다(애니메이션).
6. 사이드바 PDF 목록·페이지 썸네일 클릭 시 파일·페이지가 전환되어야 한다.
7. 뷰어 열린 동안 «보고서» 버튼이 active 스타일이어야 하고, 닫으면 해제되어야 한다.
8. 색인도·도면 기존 ServiceFileImagePreview 동작이 변하지 않아야 한다.
