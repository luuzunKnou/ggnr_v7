# 결과보고서

2026-08-14 | dev.strcat | 배경지도·목록패널 배타

## 목적

우측 배경지도(·드론영상) 펼침 패널과 지적도 등 목록 패널이 동시에 열리지 않고, 하나만 보이도록 한다.

## 요약

배경지도를 연 뒤 지적도를 열면 둘 다 보이던 동작을 없앴다. 목록 패널을 열면 배경지도·드론영상 패널을 닫고, 배경지도·드론영상을 열면 지적도 등 목록을 닫는다.

 `handleControlClick` / `handleItemRightClick` — 배경지도·드론영상 열 때 목록 패널 닫기. 동시 표시 주석·분기 제거

## 테이블 수정

해당 없음

## 테스트

1. 배경지도를 연 뒤 지적도를 누르면 배경지도 패널이 닫히고 지적도 목록만 보여야 한다.
2. 지적도 목록이 열린 뒤 배경지도를 누르면 목록이 닫히고 배경지도만 보여야 한다.
3. 드론영상과 지적도 목록도 동시에 열리지 않아야 한다.
4. 배경지도와 드론영상은 서로만 열려야 한다(기존과 동일).
