## 목적

정수장 내부설비 목록을 왼쪽 상세 안에서 빼서, 오른쪽에 별도 패널로 본다.

## 요약

왼쪽 패널은 정수장 목록과 기본정보만 둔다. 정수장을 고르면 오른쪽에 내부설비 패널이 열린다. 설비를 누르면 같은 오른쪽 패널 아래에 제원·유지보수·정기점검·계약정보가 나온다.

## 파일수정

수정 | src/app/(pages)/map/_mapContents/wtlAdmin/facility/WtlFacilityPlantView.tsx
 `WtlFacilityPlantView` — 위 목록·아래 기본정보만 둠. 내부설비 탭은 없앰
 `onSelect` — 고른 정수장을 바깥으로 알려 오른쪽 패널을 연다

추가 | src/app/(pages)/map/_mapContents/wtlAdmin/facility/WtlFacilityEquipPanel.tsx
 `WtlFacilityEquipPanel` — 오른쪽 내부설비 패널. 위 목록·아래 설비 상세
 `equipTab` — 제원, 유지보수, 정기점검, 계약정보

수정 | src/app/(pages)/map/_mapContents/wtlAdmin/facility/WtlFacilityShell.tsx
 `equipOpen` — 정수장을 고르면 오른쪽에 내부설비 패널을 둠
 `equipWidth` — 내부설비 패널 너비. 닫으면 정수장 선택도 해제

## 테이블 수정

해당 없음

## 테스트

1. 정수장을 고르면 오른쪽에 내부설비 패널이 열려야 한다.
2. 왼쪽 상세에는 기본정보만 있고 내부설비 탭은 없어야 한다.
3. 오른쪽 목록에 펌프·염소투입설비·수질계측기가 나와야 한다.
4. 설비 행을 누르면 아래에 제원이 나와야 한다.
5. 유지보수·정기점검·계약정보 탭에 이력이 나와야 한다.
6. 다른 정수장을 누르면 오른쪽 설비 목록이 바뀌어야 한다.
7. 오른쪽 닫기를 누르면 내부설비 패널이 사라져야 한다.
