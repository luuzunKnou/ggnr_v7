# 결과보고서

2026-07-13 | 200BingSu | 버전관리 적용 실패 복구·안내·이력 새로고침

## 목적

QC·코드 리뷰에서 지적한 위험을 줄인다. 적용 실패 시 GeoServer가 꺼진 채로 남지 않게 하고, 중지 실패 시에도 잠시 기다린 뒤 진행하며, 앱 재시작과 GeoServer 재가동을 화면에 구분하고, 재시작 직후 이력이 안 보이는 경우를 줄인다.

## 요약

소스 적용은 실패해도 GeoServer 기동을 시도하고 temp를 정리한다. 중지 실패 시에도 대기 후 복사하며 안내에 잠금 가능성을 남긴다. 버전관리 화면에 앱/GeoServer 재시작 구분을 적고, 재시작이 예약되면 이력 새로고침을 여러 번 시도하며 재기동 후 확인 안내를 보여 준다.

## 테스트

1. GeoServer 기동 중 적용 실패(복사 오류 등) 후에도 GeoServer가 다시 기동되어야 한다.
2. 적용 실패 후에도 임시 폴더가 남지 않아야 한다.
3. GeoServer 중지가 실패해도 잠시 대기 후 적용이 이어져야 한다.
4. 버전관리 화면에 앱 재시작과 GeoServer 항상 재가동 안내가 보여야 한다.
5. 명령 실행·process.exit 재시작으로 적용 성공 시 «재기동 후 이력 확인» 안내가 나와야 한다.
6. 재시작 없이 적용 성공 시 이력이 바로 갱신되어야 한다.
7. 재시작 예약 적용 성공 후 서버가 다시 뜬 뒤 «이력»에 성공 기록이 있어야 한다.
