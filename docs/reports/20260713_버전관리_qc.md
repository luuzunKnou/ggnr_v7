## 시나리오 1. 업무 순서·메뉴 위치 확인

### 전제조건

1. 개발자 모드에 로그인된 상태여야 한다.
2. 좌측 메뉴에 «소스코드 관리»와 «버전관리»가 있어야 한다.

### 절차

- [x] 좌측에서 «소스코드 관리»를 선택한다.
- [x] 상단 탭에 «설치파일 다운로드»·«소스코드 업로드»가 있는지 확인한다.
- [x] 좌측에서 «버전관리»를 선택한다.
- [x] «최신 소스 적용»만 보이는지 확인한다.

### 기대결과

1. 기대 업무 순서는 «설치파일 다운로드» → «소스코드 업로드» → «최신 소스 적용»이어야 한다.
2. 설치·업로드는 «소스코드 관리» 탭에 있어야 한다.
3. «버전관리»에는 «최신 소스 적용»만 있어야 하고, «설치파일 다운로드»는 없어야 한다.

## 시나리오 2. 설치파일 다운로드 · 화면 기본값

### 전제조건

1. «소스코드 관리» 화면에 들어와 있어야 한다.
2. 이 시나리오에서는 «설치파일 다운로드» 버튼을 누르지 않는다.

### 절차

- [x] «설치파일 다운로드» 탭을 선택한다.
- [x] 망 기본값이 «폐쇄망 (node_modules 포함)»인지 확인한다.
- [x] «설치파일 다운로드» 버튼과 «취소» 버튼이 보이는지 확인한다.
- [x] 대기 중 «취소»가 비활성인지 확인한다.

### 기대결과

1. «설치파일 다운로드» 탭이 선택되어야 한다.
2. 기본 망은 «폐쇄망 (node_modules 포함)»이어야 한다.
3. 대기 중 «취소»는 비활성이어야 한다.

## 시나리오 3. 설치파일 다운로드 · 폐쇄망

### 전제조건

1. «소스코드 관리» → «설치파일 다운로드» 탭에 들어와 있어야 한다.
2. 브라우저에서 파일 저장이 가능해야 한다.

### 절차

- [x] «폐쇄망 (node_modules 포함)»을 선택한다.
- [x] «설치파일 다운로드»를 누른다.
- [x] 단계·진행률·실시간 로그가 갱신되는지 확인한다.
- [x] 완료 후 브라우저에 ZIP이 저장되는지 확인한다.
- [x] «이력»을 열어 설치파일 다운로드 성공 이력이 있는지 확인한다.

### 기대결과

1. 진행 중 망 선택과 «설치파일 다운로드»가 비활성되어야 한다.
2. 진행 중 «취소»만 활성되어야 한다.
3. 서버 정보·스캔·압축·다운로드 단계가 순서대로 진행되어야 한다.
4. ZIP 파일이 저장되어야 한다.
5. «이력»에 설치파일 다운로드 성공이 남아야 한다.

## 시나리오 4. 설치파일 다운로드 · 개방망

### 전제조건

1. «소스코드 관리» → «설치파일 다운로드» 탭에 들어와 있어야 한다.

### 절차

- [ ] «개방망 (node_modules 미포함)»을 선택한다.
- [ ] «설치파일 다운로드»를 누른다.
- [ ] 완료 후 ZIP 저장과 로그·이력을 확인한다.

### 기대결과

1. 개방망 선택이 유지된 채 다운로드가 완료되어야 한다.
2. 스캔·압축 결과에 패키지 폴더 미포함이 반영되어야 한다.
3. ZIP이 저장되고 «이력»에 성공이 남아야 한다.

## 시나리오 5. 설치파일 다운로드 · 취소

### 전제조건

1. «소스코드 관리» → «설치파일 다운로드» 탭에 들어와 있어야 한다.
2. 다운로드에 시간이 걸릴 수 있는 환경이어야 한다.

### 절차

- [ ] «폐쇄망 (node_modules 포함)»을 선택한다.
- [ ] «설치파일 다운로드»를 누른다.
- [ ] 진행 중 «취소»를 누른다.
- [ ] 안내·로그·버튼 상태를 확인한다.

### 기대결과

1. 진행이 멈추고 취소 안내가 나와야 한다.
2. 취소 후 «설치파일 다운로드»가 다시 활성되어야 한다.
3. 페이지가 이탈하지 않아야 한다.

## 시나리오 6. 소스코드 업로드 · 화면 기본값

### 전제조건

1. «소스코드 관리» 화면에 들어와 있어야 한다.
2. 이 시나리오에서는 «현재 코드 자동 업로드»를 누르지 않는다.

### 절차

- [ ] «소스코드 업로드» 탭을 선택한다.

3. «node_modules 미포함»이 기본이어야 한다.
4. 대기 중 «취소»는 비활성이어야 한다.

## 시나리오 7. 소스코드 업로드 · node_modules 미포함

### 전제조건

1. GNMS 서버에 연결할 수 있어야 한다.
2. «소스코드 관리» → «소스코드 업로드» 탭에 들어와 있어야 한다.

### 절차

- [ ] «설치»를 선택한다.
- [ ] «node_modules 미포함»을 선택한다.
- [ ] 날짜를 확인하고, 필요하면 변경 사항 메모를 입력한다.
- [ ] «현재 코드 자동 업로드»를 누른다.
- [ ] 단계 목록에 npm install 단계가 있는지 확인한다.
- [ ] 완료까지 진행·로그를 확인한다.
- [ ] «이력»에서 업로드 성공을 확인한다.

### 기대결과

1. 대상 서버 확인 → 스캔 → (필요 시 DB 비교) → 압축 → 전송 → 병합 → npm install → 결과 집계 순으로 진행되어야 한다.
2. npm install 단계가 «완료»로 끝나야 한다.
3. GNMS에 최신 소스가 등록되어야 한다.
4. «이력»에 소스코드 업로드 성공이 남아야 한다.

## 시나리오 9. 소스코드 업로드 · DB 불일치 안내

### 전제조건

1. 스키마 SQL과 접속 DB가 다른 상태이거나, 그 상황을 재현할 수 있어야 한다.
2. «소스코드 관리» → «소스코드 업로드» 탭에 들어와 있어야 한다.

### 절차

- [ ] «node_modules 미포함»을 선택한다.
- [ ] «현재 코드 자동 업로드»를 누른다.
- [ ] «접속 DB와 스키마 SQL이 다릅니다» 안내가 나오면 «중단»을 누른다.
- [ ] 업로드가 멈췄는지 확인한다.
- [ ] 다시 업로드를 시작한 뒤, 안내가 나오면 «계속 진행»을 누른다.
- [ ] 이후 단계가 이어지는지 확인한다.

### 기대결과

1. 불일치 시 확인 안내 없이 자동으로 압축·전송으로 넘어가면 안 된다.
2. «중단» 시 업로드가 멈춰야 한다.
3. «계속 진행» 시 이후 단계로 이어져야 한다.

## 시나리오 11. 최신 소스 적용 · 화면 기본값

### 전제조건

1. «버전관리» 화면에 들어와 있어야 한다.
2. 이 시나리오에서는 «최신 소스 전체 적용»을 누르지 않는다.

### 절차

- [ ] «최신 소스 적용» 제목이 보이는지 확인한다.
- [ ] 망 기본값이 «폐쇄망 (node_modules 포함)»인지 확인한다.
- [ ] «적용 후 서버 재시작»이 켜져 있는지 확인한다.
- [ ] 재시작 방식이 «명령 실행 재시작»인지 확인한다.
- [ ] «최신소스 일부 적용(준비중)»이 비활성인지 확인한다.
- [ ] 대기 중 «취소»가 비활성인지 확인한다.
- [ ] «적용 후 서버 재시작»을 끈 뒤 재시작 방식이 비활성인지 확인한다.
- [ ] 다시 켠 뒤 재시작 방식이 활성인지 확인한다.

### 기대결과

1. «버전관리»에는 «최신 소스 적용»만 보여야 한다.
2. 기본 망은 폐쇄망, 재시작 체크는 켜짐, 방식은 명령 실행이어야 한다.
3. «최신소스 일부 적용(준비중)»·대기 중 «취소»는 비활성이어야 한다.
4. 재시작 체크를 끄면 방식 선택이 비활성되어야 한다.

## 시나리오 12. 최신 소스 적용 · 입력 조합 목록

### 전제조건

1. 앞 단계에서 GNMS에 최신 소스가 등록되어 있어야 한다. (시나리오 7 또는 8)
2. «버전관리» 화면에 들어와 있어야 한다.
3. 실제 적용 조합은 아래 8가지이다.

### 절차

- [ ] 아래 목록이 시나리오 13~20과 하나씩 대응하는지 확인한다.
- [ ] 폐쇄망 + 재시작 켜짐 + 명령 실행 재시작 → 시나리오 13
- [ ] 폐쇄망 + 재시작 켜짐 + process.exit 재시작 → 시나리오 14
- [ ] 폐쇄망 + 재시작 켜짐 + 재시작 안 함 → 시나리오 15
- [ ] 폐쇄망 + 재시작 꺼짐 → 시나리오 16
- [ ] 개방망 + 재시작 켜짐 + 명령 실행 재시작 → 시나리오 17
- [ ] 개방망 + 재시작 켜짐 + process.exit 재시작 → 시나리오 18
- [ ] 개방망 + 재시작 켜짐 + 재시작 안 함 → 시나리오 19
- [ ] 개방망 + 재시작 꺼짐 → 시나리오 20

### 기대결과

1. 조합마다 시나리오가 하나씩 있어야 한다.
2. 재시작 체크가 꺼진 조합에서는 재시작 방식을 고르지 않아야 한다.
