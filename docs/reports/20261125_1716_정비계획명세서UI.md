# 결과보고서

2026-11-25 | dev.strcat | 정비계획 명세서 UI 정리

## 목적

중기 정비계획 명세서의 연차 입력을 숫자·소수점만 받도록 하고, 표 세로선·연도 등록·엑셀 조작을 업무 형식에 맞게 정리한다.

## 요약

연차 칸은 테두리 없이 숫자와 소수점만 입력된다. 시설명·위치는 관리번호로 시설을 조회해 채우고, 전체 정비계획은 중기 계와 같다. 상태 열을 제거해 헤더·본문 선을 맞췄고, 연도 등록은 모달로 바꿨으며 엑셀은 내려받기만 남겼다.

## 테스트

1. 중기 연차 칸에 문자를 넣으면 반영되지 않아야 한다.
2. 연차 칸에 숫자와 소수점만 넣고 포커스를 벗어나면 값이 저장되어야 한다.
3. 연차 칸 테두리가 보이지 않아야 한다.
4. 헤더와 본문 세로선이 맞아야 한다.
5. 상태 열이 없어야 한다.
6. 관리번호가 있는 행의 시설명·위치가 시설 정보와 같아야 한다.
7. 연차를 입력하면 전체 정비계획과 중기 계가 같아야 한다.
8. «연도 등록» 클릭 시 모달이 열려야 한다.
9. 모달에서 구간을 등록하면 연도 선택에 추가되고 표 머리연도가 바뀌어야 한다.
10. 잘못된 연도 입력 시 안내가 나와야 한다.
11. 엑셀 가져오기 버튼이 없어야 한다.
12. 엑셀 내려받기 파일에 상태 열이 없고 명세서 열 순서가 화면과 같아야 한다.
