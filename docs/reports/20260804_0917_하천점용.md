# 결과보고서

2026-08-04 | dev.strcat | 하천점용 (필지·알림·지도클릭·속성·내 정보 연동 통합)

## 목적

하천점용1 상세의 필지·도형 연동, 만료·업무 알림(서버 저장·시스템 필터), 지도 클릭으로 목록·상세 이동, 상세 속성 더보기·제외, «내 정보» 프로필·알림 실연동까지 하천점용 관련 작업을 한 흐름으로 정리한다.

## 요약

점용 도형 그리기·수정에 맞춰 필지목록이 지적 교차로 채워지고, 필지 삭제 시 부모 도형에서 해당 영역만 빠지도록 했다. «내 정보»는 로그인 프로필·하천점용 만료 알림을 실데이터로 보고, 읽음·지우기는 계정별 서버 상태로 유지하며 시스템(하천 등)에 맞게 걸러 보여 준다. 점용 패널이 열린 상태에서 지도 도형을 클릭하면 목록·상세가 열리고 도형이 지도 중앙에 맞춰진다. 상세는 기본 속성만 보이고 «더보기»로 숨김 필드를 펼치며, 하천코드·관리코드·user_name은 표시하지 않는다.

## 테스트

1. 하천점용1 상세에서 «수정» 후 도형을 그리면 필지목록이 지적 교차 기준으로 자동 채워져야 한다.
2. 도형을 수정하면 필지목록이 갱신되어야 한다(수동 추가 항목은 유지).
3. 필지목록에서 한 필지를 삭제하면 점용 도형에서 해당 필지 영역만 빠져야 한다.
4. 저장 후 solo 테이블에 필지목록이 반영되어야 한다.
5. 로그인 후 «내 정보»에 본인 이름·부서·전화·메일이 DB와 같거나 없으면 «—»로 보여야 한다.
6. 점용종료일이 15일 이내인 건이 «내 정보» 알림에 요약·목록으로 나와야 한다.
7. 알림 항목 클릭 시 하천점용 상세가 해당 건으로 열려야 한다.
8. SQL 적용 후 알림을 지우면 브라우저를 초기화해도 다시 나오지 않아야 하고, 같은 계정·다른 브라우저에서도 같아야 한다.
9. 하천이 아닌 시스템으로 들어가면 하천 전용 알림이 목록에 없어야 한다.
10. 하천점용 패널을 연 뒤 지도에서 점용 도형을 클릭하면 목록·상세가 열리고 도형이 지도 중앙에 맞아야 한다.
11. 패널을 닫은 뒤 같은 레이어를 클릭하면 기존 식별·데이터조회 동작으로 가야 한다.
12. 상세 기본에는 공사코드·허가번호·점용기간·점용명·점용장소·점용면적·점용목적·하천명·하천유형이 보이고, «더보기»로 읍면동명·리명·비고 등이 나와야 한다.
13. 하천코드·관리코드·user_name은 기본·더보기·등록 폼 어디에도 나오지 않아야 한다.
14. 수정 진입 시 숨김 속성까지 펼쳐지고 저장이 반영되어야 한다.
15. 도로대장·측정·점사용료 등 다른 기능 전환 시 점용 연동이 남지 않아야 한다.
