# 결과보고서

2026-07-14 | 200BingSu | 설치ZIP다운로드빌드경고

## 목적

설치 ZIP 다운로드 API 빌드 시 Turbopack이 임시 경로를 프로젝트 전체 파일 패턴으로 추적해 나오던 «Overly broad patterns» 경고를 없앤다.

## 요약

임시 폴더명을 `path.join(임시디렉터리, 고정문자…)`로 쓰지 않고 런타임에 이어 붙이도록 바꿨다. 다운로드 route에서는 파일 열기·경로 조합을 하지 않고 서비스만 호출한다.

## 파일수정

수정 | src/service/sourceInstallZipService.ts
 `installZipDownloadRoot` — 임시 폴더 leaf를 런타임 합성해 정적 경로 추적 회피
 `resolveInstallZipForDownload` / `openInstallZipDownloadStream` — 경로 조회·스트림 열기를 서비스로 모음

수정 | src/app/api/source/version/install-zip/download/route.ts
 `GET` — fs·임시경로 직접 사용 제거, 서비스 결과로 응답만 구성

## 테이블 수정

해당 없음

## 테스트

1. 설치 ZIP 생성 후 다운로드가 이전과 같이 완료되어야 한다.
2. `next build` 또는 개발 빌드 로그에 해당 download 경로의 «Overly broad patterns» 경고가 나오지 않아야 한다.
3. 같은 세션에서 progressId로 다운로드 시 404가 나지 않아야 한다.
