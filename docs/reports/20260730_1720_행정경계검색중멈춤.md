# 결과보고서

2026-07-30 | gyujin | 행정경계 검색에서 읍면동·리 선택 후 검색하면 "검색 중"만 뜨고 안 끝남

## 목적

데이터조회(표준) 「행정경계 검색」에서 읍면동·리를 골라 검색하면 결과 없이 "검색 중…" 상태가 끝나지 않는 문제의 원인을 찾아 수정한다.

## 요약

행정경계 검색은 좌측 레이어 목록에서 켜져(체크·선택) 있는 레이어만 대상으로 검색하도록 되어 있는데, 켜진 레이어가 하나도 없으면 검색 요청이 조용히 대기 상태로 넘어가고 다시 실행되지 않아 "검색 중" 스피너가 끝없이 표시됐다. 검색 시작 전에 켜진 레이어가 있는지 먼저 확인해 없으면 안내 문구를 보여주도록 고쳐, 스피너가 무한정 멈춰 있지 않게 됐다.

## 테스트

1. 좌측 레이어를 하나도 켜지 않은 채 행정경계 검색에서 읍면동을 고르고 검색하면 "레이어를 켜라"는 안내가 바로 나와야 한다.
2. 좌측에서 레이어 하나를 클릭(활성화)하거나 체크박스를 켠 뒤 행정경계 검색을 하면 정상적으로 결과가 나오고 "검색 중" 표시가 사라져야 한다.
3. 여러 읍면동·리를 추가해 한 번에 검색해도 정상 동작해야 한다.
4. 통합검색·도형(그리기) 검색은 기존과 동일하게 동작해야 한다(회귀 없음).
