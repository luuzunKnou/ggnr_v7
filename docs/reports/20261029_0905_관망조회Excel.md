# 결과보고서

2026-10-29 | 200BingSu | 관망조회 Excel 버튼

## 목적

관망조회 시설목록을 현재 검색·구역·레이어 조건 그대로 엑셀로 내려받을 수 있게 한다. 레이어별 시트로 나누고, 상세 표시 필드를 컬럼으로 쓴다.

## 요약

Excel 버튼이 켜진 레이어마다 조건에 맞는 전체 건을 조회해 `.xlsx`로 저장한다. 시트는 출처·레이어별로 나뉘고, 컬럼은 상세 표시가 켜진 필드만 순서대로 넣는다. 파일 형식은 도로망도 엑셀과 같은 방식으로 맞췄다. 파일명은 내려받는 시각(시분초 포함)과 «관망조회»로 붙인다.

## 파일수정

추가 | src/app/(pages)/map/_mapContents/wtlAdmin/networkMap/exportWtlNetworkMapExcel.ts
 `exportWtlNetworkMapExcel` — 레이어별 시트로 워크북 생성 후 `날짜시분초_관망조회.xlsx` 저장. 도로망도와 동일하게 시트·파일 쓰기
 `resolveExportFields` — 상세 표시 필드를 우선하고, 없으면 행 속성 키로 대체. 도형 필드는 제외
 `rowToExcelObject` — 필드 한글명 헤더·코드 한글화 값을 행 객체로 변환

 `handleExcelExport` — 현재 조건으로 레이어별 전체 페이지를 모아 정의 필드 번들 로드 후 엑셀 저장
 `excelExporting` — 내려받기 중 버튼 비활성·안내 문구
 Excel 버튼 — 클릭 시 내보내기 실행

## 테스트

1. 관망조회에서 레이어·필터를 켠 뒤 Excel을 누르면 시분초가 들어간 «관망조회» 엑셀이 내려받아야 한다.
2. 엑셀 시트가 켜진 출처·레이어별로 나뉘고, 건수가 0인 레이어는 시트가 없어야 한다.
3. 시트 컬럼이 상세 화면과 같은 상세 표시 필드·순서여야 한다.
4. 코드형 필드는 한글 라벨로 보여야 한다.
5. 화면 목록은 페이지당 일부만 보여도 엑셀에는 같은 조건의 전체 건이 들어가야 한다.
6. 내보낼 목록이 없을 때 안내가 나와야 한다.
7. 내려받기 중에는 Excel 버튼이 비활성되어야 한다.
8. 도로망도 엑셀과 같이 일반 표 형식(.xlsx)으로 열려야 한다.
