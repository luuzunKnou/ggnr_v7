# 결과보고서

2026-11-26 | dev.strcat | 정비계획 명세서 DB 사용 전환 요청

## 목적

정비계획 명세서와 안전점검 이관이 DB의 정비계획·계획시설 표를 사용하도록 바꾼다. 시설명과 위치는 관리번호로, 소교량은 묶음 관리번호와 리로 가져온다.

## 요약

- 명세서가 DB에서 연도구간별로 불러오고 저장된다. 1~5년차 구간 80곳, 5개년 이후 구간 90곳이 보이며 합이 170곳이다.
- 시설명칭과 위치는 관리번호로 시설 표를 조회해 채우고, 소교량 묶음은 묶음 매핑의 묶음 관리번호와 리 정보를 쓴다. 확인 결과 이름·위치가 비는 행은 없었다.
- 안전점검 이관은 DB에 작성중으로 직접 추가하며, 이미 들어간 시설·묶음은 중복 추가하지 않는다.
- DB에는 «정비된 부분» 항목이 없어 전체에서 중기·5개년 후를 뺀 값으로 보여주고, 저장 시 전체 값에 합산해 넣는다.
- 예산 화면은 기존 임시 저장소를 그대로 쓴다.
- 영향 받는 기능: 안전점검 이관, 정비계획 명세서·엑셀, 예산(변경 없음).

## 테스트

1. 정비계획을 열면 첫 연도구간 80곳이 보여야 한다.
2. 연도구간을 바꾸면 90곳이 보여야 한다.
3. 시설명칭과 위치가 빈 행이 없어야 한다.
4. 소교량 묶음 행에 «리명_소교량_통합»과 읍면·리가 나와야 한다.
5. 값을 입력하면 계·정비율이 바로 바뀌고, 저장하면 입력 표시가 풀리며 새로고침 후에도 유지되어야 한다.
6. 연도 등록 시 새 구간이 목록에 나오고 선택되어야 한다.
7. 안전점검 이관 시 작성중 행이 추가되고 정비계획 화면으로 이동해야 한다.
8. 이미 계획에 있는 시설·소교량 묶음은 이관 창에서 «포함됨»으로 보이고 중복 추가되지 않아야 한다.
9. 엑셀 다운로드에 시설명·위치·백만원 단위 값이 맞게 들어가야 한다.
10. 예산 화면이 기존처럼 열려야 한다.
