# 결과보고서

2026-07-14 | 200BingSu | 소스 스캔 실제 제외 경로 표시

## 목적

소스코드 업로드 «소스 스캔/필터링» 단계에서 «제외 n»만으로는 무엇이 빠졌는지 알 수 없어, 실제로 제외된 경로 목록을 볼 수 있게 한다.

## 요약

스캔 중 제외된 파일·폴더 경로를 모은다. 전체 폴더 제외(예: node_modules/)는 폴더 한 줄로 기록해 부하를 줄인다. 단계 우측 «포함 n, 제외 m»에 마우스를 올리면 실제 경로 목록이 뜨고, 스캔 완료 시 실시간 로그에도 일부 경로를 남긴다.

## 테스트

1. 업로드 스캔 후 단계에 «포함 n, 제외 m»이 보여야 한다.
2. «제외 m»에 마우스를 올리면 실제 제외 경로가 보여야 한다.
3. `node_modules/` 등 폴더 제외는 `node_modules/`처럼 폴더 단위로 보여야 한다.
4. 실시간 로그에 제외 경로 예시가 일부 남아야 한다.
5. 결과 표의 «제외» 행에 호버하면 해당 파일 경로가 보여야 한다.
