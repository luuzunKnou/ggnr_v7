## 목적

자전거도로 상세 속성·구간 모달 표현을 도로망도·도로대장과 같은 표·오버레이 패턴으로 맞춘다.

## 요약

속성정보를 2열 라벨·값 표로 바꾸고, 구간·첨부는 하단 탭으로 구성했다. 구간 상세 모달은 목록·상세를 덮는 반투명 오버레이와 동일 속성 표로 통일했다.

## 테스트

1. 노선 상세 속성정보가 2열 표로 보여야 한다.
2. 긴 비고는 한 줄 전체로 보여야 한다.
3. 하단 «구간» 탭에서 행 클릭 시 구간 상세 모달이 열려야 한다.
4. 모달이 목록·상세 패널 영역을 반투명으로 덮어야 한다.
5. 모달 안 기점·종점·폭원 등이 속성 표 형태로 보여야 한다.
6. Esc 또는 바깥 클릭·닫기로 모달이 닫혀야 한다.
7. «첨부» 탭에서 파일 썸네일 목록이 보여야 한다.
