## 목적

관망조회 시설목록 상세보기에서 슈퍼유저일 때 영문 필드명을 화면 본문이 아니라 툴팁에만 보이게 맞춘다. ThreeJs 범례 선택은 흰 테두리 깜빡임·도형 포커스, 단면도 탭 전환은 재조회 없이, 시설 상세·단면도 겹침 z-index를 맞춘다.

## 요약

상세 속성 라벨·코드 값은 한글명만 표시하고, 영문 필드명·코드 원문은 HTML 타이틀(툴팁)에만 괄호로 병기한다. ThreeJs 범례는 흰 테두리 펄스·선택 시 카메라 이동, 절단선 적용 시 횡·종단을 캐시해 탭 전환 재조회를 없앤다. 플로팅 패널은 나중에 연 쪽·클릭한 쪽이 앞에 온다.

## 테스트

1. 슈퍼유저로 관망조회 시설목록 상세를 열면 속성 라벨·값이 한글만 보여야 한다.
2. 슈퍼유저로 라벨에 마우스를 올리면 툴팁에 영문 필드명이 괄호로 보여야 한다.
3. 슈퍼유저로 코드형 값에 마우스를 올리면 툴팁에 코드 원문이 괄호로 보여야 한다.
4. 일반 사용자는 화면·툴팁 모두 한글명만 보여야 한다.
5. 시설목록 표 헤더·셀은 기존처럼 화면은 한글, 툴팁에만 영문이 남아야 한다.
6. ThreeJs 범례 항목 클릭 시 흰 테두리만 깜빡이고 빨강이 없어야 한다.
7. 관로 선택 시 도형 전체가 하얗게 덮이지 않고 테두리만 깜빡여야 한다.
8. 단면도 탭을 바꿔도 로딩·재조회가 없어야 한다.
9. ThreeJs 범례 항목 선택 시 해당 도형이 화면에 들어오도록 뷰가 이동해야 한다.
10. 시설 상세만 켜진 뒤 단면도를 열면 단면도가 앞에 와야 한다.
11. 단면도만 켜진 뒤 시설 상세를 열면 상세가 앞에 와야 한다.
12. 둘 다 켜진 상태에서 뒤에 가린 쪽을 클릭하면 그 패널이 앞으로 와야 한다.
13. 앞에 있던 쪽을 다시 클릭하면 그 패널이 앞으로 유지되어야 한다.
14. ThreeJs 뷰 안에는 동서남북 글자가 없고 좌하단 나침반만 보여야 한다.
15. 나침반을 클릭하면 뷰가 정북 방향으로 회전해야 한다.
16. ThreeJs 데이터 범례 최상단에 «지형»이 있고 체크 해제 시 지형 도형이 사라져야 한다.
17. 단면도 모달 헤더 접기로 본문이 숨겨지고, 다시 펼치면 내용이 보여야 한다.
