## 목적

SLD를 화면에서 고칠 때 색·선만 바꾸고, 필터와 화살표 설정은 유지한다. 선 색을 바꾸면 같은 색을 쓰는 화살표도 같이 바뀌게 한다.

## 요약

제목이 레이어명과 같은 규칙의 환경변수 기본값을 색·선 항목에 보여 준다. 저장하면 그 이름의 기본값만 문서 전체에서 바꾼다. 선 색은 화살표 규칙에 같은 이름으로 들어 있으면 함께 바뀌고, 필터와 화살표 모양은 남는다. SLD로 바꾼 뒤에는 화면에서 CSS와 같은 항목을 고치고, 관리자 화면에는 그 CSS를 지오서버가 변환한 SLD가 나온다.

## 파일수정

수정 | src/lib/geoserverStyleUtils.ts
 `parseSldEnvStyle` — 제목이 레이어명인 규칙에서 환경변수 기본값을 읽어 화면 값으로 만든다
 `patchSldEnvDefaults` — 같은 환경변수 이름의 기본값만 문서 전체에서 바꾼다. 선 색은 화살표 규칙까지 반영되고 필터·벤더 옵션은 유지

수정 | src/service/devTestService.ts
 `getGeoServerStyle` — SLD에 환경변수가 있으면 색·선 항목을 열 수 있게 값을 돌려준다
 `updateGeoServerStyle` — SLD는 CSS를 고친 뒤 지오서버가 변환한 SLD로 저장한다. CSS 원본이 없는 환경변수 스타일만 기본값을 직접 고친다
 `setGeoServerStyleFormat` — SLD로 바꿀 때 화면의 CSS를 지오서버에 변환받아 그 문서를 저장
 `translateCssToSld` — 임시 스타일로 CSS를 올려 변환된 SLD 본문을 받는다

수정 | src/app/(pages)/dev/_components/LayerInfoManager.tsx
 `스타일 수정 안내` — SLD여도 화면 항목은 CSS와 같고, 관리자 화면에는 변환된 SLD가 나온다는 문구
 `handleStyleFormatChange` — SLD로 바꾼 뒤에도 색·선 항목을 열어 둔다

## 테스트

1. 환경변수가 있는 SLD를 열면 선 색과 두께가 보여야 한다.
2. 선 색을 저장하면 화살표가 쓰는 같은 색 기본값도 바뀌어야 한다.
3. 필터와 화살표 따라가기 설정은 저장 후에도 남아 있어야 한다.
4. CSS 원본도 환경변수도 없는 SLD는 색 항목이 열리지 않아야 한다.
5. CSS 스타일 저장은 이전과 같이 동작해야 한다.
6. SLD로 바꾼 뒤에도 색·선 항목이 남아 있어야 한다.
7. 관리자 화면의 SLD는 화면에서 고친 CSS를 변환한 내용이어야 한다.
