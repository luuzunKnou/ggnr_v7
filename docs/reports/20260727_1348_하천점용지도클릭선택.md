# 결과보고서

2026-07-27 | dev.strcat | 하천점용 지도 레이어 클릭 → 목록·상세 이동

## 목적

하천점용 패널이 열린 상태에서 지도의 점용 레이어를 클릭하면 해당 대장 항목이 목록에서 선택·상세가 열리고, 클릭한 도형이 지도 중앙에 오도록 맞춘다.

## 요약

도로대장·하천기본계획과 같이 지도 식별 결과를 패널이 소비한다. 점용 부모·단독·면적 레이어 hit 시 대장번호로 목록 선택·상세 오픈하고, 목록 행 클릭과 동일하게 도형 범위로 지도 중앙에 맞춘다(상세 패널 패딩 반영).

## 테스트

1. 하천 시스템에서 하천점용 패널을 열면 점용 레이어가 켜져야 한다.
2. 지도에서 점용 도형을 클릭하면 목록 행이 선택되고 상세 패널이 열리며, 해당 도형이 지도 중앙에 맞아야 한다.
3. 단독·면적 레이어만 클릭해도 같은 대장번호의 상세가 열리고 지도가 맞춰져야 한다.
4. 선택한 행이 목록 화면 밖이면 해당 행이 보이도록 스크롤되어야 한다.
5. 하천점용 패널을 닫은 뒤 같은 레이어를 클릭하면 기존 데이터조회·식별 동작으로 가야 한다.
6. 도로대장·측정 등 다른 패널 전환 시 점용 지도 픽이 남지 않아야 한다.
