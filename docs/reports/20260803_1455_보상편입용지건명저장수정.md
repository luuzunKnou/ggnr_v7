# 결과보고서

2026-08-03 | gyujin | 보상편입용지 건명 미저장·빈 행 등록 수정

## 목적

건명을 입력해도 목록에 «(건명 없음)»이 나오던 문제를 고치고, 등록·수정이 속성·도형·필지를 실제로 DB에 남기도록 한다.

## 요약

공통 행 저장이 defineLayer에 등록된 필드만 INSERT하도록 되어 있는데, 보상편입용지는 defineLayer가 없어 `DEFAULT VALUES` 빈 행만 생기고 건명이 빠졌다. 부모·필지 저장을 테이블 직접 INSERT/UPDATE로 바꿨다. 서버에서도 건명 필수를 검사하고, 화면은 저장 시 초안 값을 ref로 읽어 목록에 반영한다. 잘못 생긴 빈 건명 행(ogc_fid 12)은 DB에서 삭제했다.

## 파일수정

수정 | src/service/roadRewardService.ts

## 테이블 수정

해당 없음 (스키마 변경 없음. 빈 건명 오류 행 1건 삭제)

## 테스트

1. «추가» 후 건명만 입력하고 등록하면 목록에 그 건명이 보여야 한다.
2. 건명 없이 등록하면 안내만 나오고 DB 행이 생기지 않아야 한다.
3. 등록 후 다시 열어 조직·감정기관·도형·필지가 유지되어야 한다.
4. 기존 건 수정·저장 시 건명 변경이 DB에 반영되어야 한다.
5. 취소 시 목록·DB에 신규 행이 없어야 한다.
6. 도형 그린 뒤 등록하면 지도 범위가 유지되어야 한다.
