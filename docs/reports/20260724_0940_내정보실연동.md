## 목적

지도 «내 정보» 패널 상단 프로필(이름·부서·연락처·이메일)을 더미 데이터 대신 로그인 사용자 DB 정보와 연동한다. 알림 탭은 기존 더미 유지.

## 요약

사용자 테이블 조회 API를 추가하고 패널에서 패널 열릴 때 호출하도록 연결했다. 중앙 API 게이트웨이는 수정하지 않고, 서버에서 세션을 직접 읽어 본인 정보만 반환한다. 실패 시 세션 이름으로 최소 표시한다.
