# 결과보고서

2026-11-23 | JungWooojin | —

## 목적

청도 도로 전용 프로젝트 `road_cd`를 추가해 별도 DB·설정으로 기동할 수 있게 한다.

## 요약

`road_cd` env·runtime을 만들고 192.168.127.32:5433에 DB·유저·스키마를 생성했다. 활성 시스템은 도로행정만이며, 시군구 코드는 청도군이다. 인덱스 로고도 프로젝트명으로 두었다.

## 파일수정

추가 | src/config/projects/road_cd.env
 `DATABASE_*` / `GGNR_DATA_DIR` / `BASE_PATH` — 개발·시연·운영 접속·데이터경로를 road_cd 기준으로 설정. 개발은 5433

추가 | src/config/projects/road_cd.runtime.env
 `ENABLED_SYSTEMS` — 도로행정만 활성
 `SYSTEM_KOR_NAME` · `SGG_CODE` — 청도군 표시명·코드(47730)
 `DISABLED_SERVICES` — 경산 도로와 동일하게 일부 서비스 비활성
 `FOOTER_ADDR` — 청도군청 도로팀 · 대표번호 054-370-6335

추가 | public/image/indexImage/road_cd_index_logo.svg
 `road_cd_index_logo` — 인덱스 로고. 경산 도로 로고를 이름만 바꿔 복사

재사용 | scripts/create-db-user.ts
 `ensureDbUser` — road_cd 유저·DB·PostGIS·layer/public_layer/land_linkage 스키마 생성

## 테이블 수정

해당 없음 (DB·스키마만 생성. 앱 테이블은 `npm run dev -- road_cd dev` 기동 시 동기화)

- DB/사용자: `road_cd` / `road_cd` (비밀번호 `road_cd`)
- 호스트: `192.168.127.32:5433` (dev)
- 스키마: `layer`, `public_layer`, `land_linkage` + PostGIS

## 테스트

1. `npm run dev -- road_cd dev`로 기동되어야 한다.
2. 인덱스·지도에서 도로행정 시스템만 보여야 한다.
3. 시스템 한글명이 «청도군 도로행정 업무지원시스템»으로 보여야 한다.
4. 하천·상하수도 등 다른 시스템은 노출되지 않아야 한다.
5. road_cd DB로 접속·스키마 동기화가 되어야 한다.
