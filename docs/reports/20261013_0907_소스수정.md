# 결과보고서

2026-10-13 | dev.strcat | 경산 도로망도 선·포인트 통합 표시

## 목적

경산 도로망도의 선 레이어와 번호 포인트 레이어를 레이어 목록의 «도로망도» 한 항목으로 함께 켜고 끄며, 포인트 위치에 노선 번호를 분류별 도형 바탕으로 표시한다.

## 요약

1. 선 레이어를 켜면 짝 포인트 레이어가 지도 요청에 자동으로 함께 붙는다. 포인트 테이블이 DB에 없는 프로젝트는 붙지 않아 기존 표시가 유지된다.
2. 레이어 목록에서 포인트 레이어는 숨겨 «도로망도» 한 항목만 보인다.
3. 선 스타일은 도로 분류별 색·굵기와 선종류(점선·파선)를, 포인트 스타일은 점 표시 없이 번호를 원·사각 바탕 도형으로 그린다.
4. 테이블명은 선 «rdl_network_ls», 포인트 «rdl_network_ps» 기준이며, SHP 업로드(DB 반영)는 담당자가 직접 진행한다. 지도 인쇄 화면에는 아직 포인트 라벨이 붙지 않는다.
5. (사용자 요청) 영덕 하천(river_yd) DB에 드론영상 TIF 테이블을 만들고 작업단위 테이블에 빠진 컬럼을 추가했다. 폴더에 넣은 TIF가 매분 등록 실패하던 문제가 해소되어 등록·변환이 시작됐다.
6. 첫 변환 대상(하천27, 원본 14.7GB)은 좌표 변환 임시 파일이 약 673GB로 예상되어, 공유 저장소 여유(약 2.3TB) 보호를 위해 사용자 확인 후 변환을 중단했다. 해당 TIF는 «변환 실패» 상태로 남아 자동 재시도되지 않는다. 전날 실패 임시 파일(31.6GB)은 다른 곳에서 사용 중이라 삭제하지 못했다.
7. 드론영상 변환의 좌표 변환 임시 파일을 무손실 압축으로 쓰도록 바꿨다. 결과 타일의 해상도·화질과 진행 순서(작업폴더 → 임시 → 타일 → 결과 이동)는 그대로다. 소하천 TIF 시험에서 임시 파일이 0.72GB → 0.14GB, 시간 9초 → 4초로 줄었고 픽셀 값은 동일했다. 진행률은 압축 전 크기 대신 변환 도구가 알려 주는 %로 표시한다.
8. 1분 폴더 감시에 기본 영상 폴더(aerial/basic)를 추가했다. 드론영상과 같은 방식으로 작업폴더의 TIF를 «basic» 종류 작업으로 등록·변환하고, 타일은 aerial/basic/작업폴더/xyz 아래에 만든다. 화면 표시는 추후 별도 작업이다. 하천27을 basic으로 옮기면서 비어 있던 이전 드론영상 작업 기록은 사용자 승인 후 삭제했다.
9. 하천27 basic 변환이 타일 생성(약 1시간 45분)까지 끝난 뒤 결과 이동 단계에서 NAS가 폴더 이름 변경을 거부(권한 오류)해 실패했고, 실패 처리 과정에서 생성된 타일이 임시 폴더와 함께 삭제됐다. 폴더 이름 변경이 거부되면 파일 단위 이동으로 넘어가도록 하고, 이동 단계에서 실패하면 생성된 타일을 지우지 않고 남기도록 수정했다.

## 테스트

1. 경산 프로젝트에 선·포인트 SHP 업로드 후 «도로망도»를 켜면 선과 번호 라벨이 함께 보여야 한다.
2. 레이어 목록에 번호 포인트 레이어가 따로 보이지 않아야 한다.
3. 고속도로·국가지원지방도·지방도 번호는 사각, 국도·시군구·면리농도 번호는 원 바탕이어야 한다.
4. 선종류가 점선·파선인 구간은 끊어진 선으로 보여야 한다.
5. «도로망도»를 끄면 선과 번호가 함께 사라져야 한다.
6. 포인트 테이블이 없는 프로젝트(영양 등)의 도로망도는 기존과 같이 보여야 한다.
7. 다른 레이어를 함께 켜도 지도 이미지가 오류 없이 나와야 한다.
8. 영덕 하천 서버 로그에 드론영상 폴더 등록 실패 메시지가 더 이상 나오지 않아야 한다.
9. 드론영상 목록에 «2026_지방하천_32652» 작업과 하천27 TIF가 보여야 한다.
10. 변환을 중단한 TIF가 다음 감시 주기에 자동으로 다시 변환되지 않아야 한다.
11. 드론영상 TIF 변환 중 임시 폴더의 파일 크기가 원본 압축 크기와 비슷한 수준이어야 한다.
12. 변환 완료 후 지도의 드론영상이 이전과 같은 선명도로 보여야 한다.
13. 변환 진행 표시에 «좌표 변환 N%»와 임시 파일 크기가 나와야 한다.
14. 서버 재시작 후 aerial/basic 작업폴더에 넣은 TIF가 약 1~2분 뒤 기본 영상 작업으로 등록되어야 한다.
15. 등록된 기본 영상 TIF가 자동으로 변환되고 타일이 aerial/basic/작업폴더/xyz 아래에 생겨야 한다.
16. 드론영상(aerial/ortho)·사진동영상·항공뷰 폴더 감시는 기존과 같이 동작해야 한다.
17. 공유 폴더(NAS)에서 변환할 때 결과 이동이 이름 변경으로 안 되면 파일 이동으로 이어져 완료되어야 한다.
18. 결과 이동 단계에서 실패해도 임시 폴더의 생성된 타일이 남아 있어야 한다.
