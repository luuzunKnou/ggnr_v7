## 목적

항공영상 레이어 목록 화면의 타입 오류를 없애 전체 타입 검사가 통과되게 한다.

## 요약

드론영상(정사영상)은 이미 앞에서 작업단위로 목록을 만들고 넘어가기 때문에, 뒤쪽 파일 단위 처리 안의 드론영상 조건은 실행될 수 없는 코드였다. 이 조건을 지워 타입 오류를 없앴고, 화면 동작은 바뀌지 않는다.
