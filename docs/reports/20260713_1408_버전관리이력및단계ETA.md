## 목적

소스코드 업로드 진행률에 예상 시간을 보이게 하고, 버전관리 단계를 실제 적용 흐름에 맞게 나누며, 재시작 전에 성공 이력이 남도록 한다.

## 요약

업로드 전체 진행 바에 예상 소요 시간을 표시한다. 버전관리 단계는 병합·적용 → GeoServer 재가동 → 앱 재시작으로 분리했다. 성공 이력은 운영 서버가 재시작을 예약하기 직전에 기록해, 서버가 곧 꺼져도 INSERT가 빠지지 않게 했다.

## 테스트

1. 소스코드 업로드 진행 중 전체 진행 바에 예상 소요 시간이 보여야 한다.
2. 버전관리 적용 중 단계에 병합·적용·GeoServer 재가동·앱 재시작이 순서대로 보여야 한다.
3. 적용 완료 후 각 단계 상세에 적용 건수·GeoServer·재시작 안내가 있어야 한다.
4. 명령 실행 재시작으로 적용 성공 시 «이력»에 최신 소스 적용 성공이 남아야 한다.
