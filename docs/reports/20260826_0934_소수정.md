## 목적

정사영상 변환 임시 작업을 데이터 디렉터리에서 하도록 되돌리고, 화면 진행률·남은 시간을 단계별로 보이도록 한다. 타일·복사는 총 장수 기준, 좌표 변환·합본은 GDAL 진행률 기준으로 표시한다. 남은 항공영상은 개발 서버와 별도 프로세스로 일괄 변환할 수 있게 한다. 지도에서 시스템을 바꿀 때 이전 시스템의 좌측 패널과 켜진 레이어가 남지 않도록 한다. 촬영요청은 UAV 시스템에서만 쓸 수 있게 한다. 접도구역 건축물 첨부는 클릭 시 다른 기능과 같은 이미지 뷰어로 본다. DB에서 뺀 표주 불필요 컬럼에 맞춰 소스를 정리한다.

## 요약

로컬 임시 폴더 우선·용량 폴백을 제거하고 데이터 디렉터리 임시 경로만 사용한다(화면·API 변환). 타일링·복사는 예상 총 장수 대비 생성 장수로 %·남은 시간을 내고, 좌표 변환은 warp 파일 예상 용량 대비 기록 크기로 %·남은 시간을 낸다(stdout %는 버퍼링으로 실시간이 아님). VRT 합본은 GDAL stdout 진행률을 쓴다. 미변환 그룹을 한 줄씩 끝낼 때까지 기다리는 배치 CLI를 추가했고, **배치는 로컬 SSD에서 만든 뒤 robocopy로 G에 배포**하며, **같은 볼륨에서 작업하면 rename 이동**한다. 시스템 키가 바뀔 때 좌측 패널(열림·상세)을 닫고 전체 레이어를 끈다. 최초 지도 진입·시스템 최초 부여는 제외한다. 우측 지도 컨트롤 «촬영요청»과 관련 패널·모달은 UAV일 때만 표시한다. 접도구역 건축물 위치도·배치도·사진·첨부파일은 클릭하면 전체화면 뷰어가 열린다. 표주 테이블에서 삭제한 is_del·일시·lon/lat에 맞춰 스키마·서비스·시드를 고쳤고, 지도 표시 좌표는 geom에서 계산한다.
