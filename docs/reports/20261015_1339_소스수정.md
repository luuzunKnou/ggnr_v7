# 결과보고서

2026-10-15 | dev.strcat | 도로영상 전체화면 정보 위치, 지도 서버 한글 인코딩

## 목적

도로대장 도로영상을 전체화면으로 볼 때 왼쪽 위 영상 정보가 어중간하게 아래로 내려와 보이는 문제를 고친다. 지도 서버 스타일(SLD)의 한글이 스타일 화면과 지도 양쪽에서 깨지지 않게 한다.

## 요약

평소에는 검색창 자리를 비우려고 영상 정보를 위에서 조금 내려 두는데, 전체화면에는 검색창이 없어 정보만 떠 보였다. 전체화면일 때만 닫기 버튼과 같은 높이로 올렸다. 항공뷰 화면 위치는 바뀌지 않는다.

지도 서버가 한국어 윈도우 기본 인코딩(MS949)으로 떠서 UTF-8 한글 스타일·요청을 잘못 읽고 있었다. 그래서 그동안 도로망도 스타일은 한글을 문자참조 코드로 바꿔 올렸고, 지도 서버 스타일 화면에는 한글 대신 코드가 보였다. 지도 서버를 UTF-8로 실행하도록 바꾸고 도로망도 스타일을 한글 그대로 SLD로 다시 등록했다. 데이터 폴더에서 MS949로 저장돼 있던 스타일 3개(한글은 주석만)는 UTF-8로 변환했다. 나머지 한글 포함 파일 74개는 원래 UTF-8이라 이번 변경으로 바르게 읽힌다. 주석 외에 한글을 쓰는 스타일은 도로망도 두 개뿐이라 다른 레이어의 지도 표시는 바뀌지 않는다.

영향 받는 기능: 지도 서버를 쓰는 전체 레이어(재시작 필요), 도로망도 선·표지 스타일.

## 테스트

1. 도로영상을 전체화면으로 켜면 왼쪽 위 영상 정보가 오른쪽 위 닫기 버튼과 같은 높이에 보여야 한다.
2. 전체화면을 끄면 영상 정보가 원래 위치(검색창 아래)로 돌아와야 한다.
3. 항공뷰 화면의 촬영 정보 위치는 바뀌지 않아야 한다.
4. 지도 위 촬영 정보(검색창 아래 왼쪽) 위치는 바뀌지 않아야 한다.
5. 지도 서버 관리 화면에서 도로망도 선·표지 스타일을 열면 등급 조건이 한글로 보여야 한다.
6. 지도 서버를 다시 시작한 뒤 도로망도 선 색·노선번호 표지가 이전과 똑같이 나와야 한다.
7. 지도 서버 스타일 화면에서 도로망도 스타일을 저장한 뒤에도 지도 표시가 깨지지 않아야 한다.
8. 지적·도로명 등 다른 지도 레이어가 재시작 전과 같이 보여야 한다.
