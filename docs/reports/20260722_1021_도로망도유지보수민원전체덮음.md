# 결과보고서

2026-07-22 | gyujin | 유지보수·민원 편집 시트를 목록+상세 전체 오버레이로 변경

## 목적

유지보수·민원 편집 시트가 상세 패널 하단 탭 영역만 덮던 것을, 도로대장 시설속성 모달과 같은 방식으로 목록+상세 패널 전체를 덮도록 바꾼다.

## 요약

기존 절대배치(하단 탭 영역 한정) 시트를 `document.body` 포털 기반 오버레이로 교체했다. 목록 패널 왼쪽 끝·목록+상세 폭 합을 지도 레이아웃에서 계산해 넘겨, 반투명 배경 위 중앙 카드로 뜬다. 저장·삭제·닫기 버튼과 편집 내용은 기존과 동일, ESC·배경 클릭으로도 닫힌다.

## 테이블 수정

해당 없음

## 테스트

1. 유지보수 카드를 클릭하면 목록·상세 패널 전체가 반투명 배경으로 덮이고 중앙에 편집 카드가 떠야 한다.
2. 민원도 동일하게 전체 오버레이로 열려야 한다.
3. 오버레이가 열린 상태에서도 지도에서 현장 점 지정 배너(도형추가·초기화·도형삭제)가 정상 동작해야 한다.
4. 저장·삭제·닫기, ESC, 카드 바깥 배경 클릭으로 닫혀야 한다.
5. 목록·상세 패널 폭을 드래그로 바꾼 뒤 열어도 오버레이가 두 패널 폭에 맞게 덮어야 한다.
