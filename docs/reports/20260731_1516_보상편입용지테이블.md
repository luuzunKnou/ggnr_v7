## 목적

현재 UI 목업 구조(건당 편입 범위 도형 1개 + 교차 필지목록)에 맞춰 `layer` 스키마에 보상편입용지·필지목록 테이블 DDL을 준비한다.

## 요약

부모 테이블 `layer.road_reward`(건·편입 범위 geom)와 자식 `layer.road_reward_parcel`(필지목록, `reward_code` 조인) DDL을 추가했다. 좌표는 하천점용과 같이 EPSG:5181이다. DB에는 자동 적용하지 않았으므로 SQL을 직접 실행해야 한다.

## 테스트

1. `scripts/sql/road_reward.sql`을 대상 DB에서 실행하면 `layer.road_reward`, `layer.road_reward_parcel`이 생성되어야 한다.
2. `\d layer.road_reward` 에 geom(5181)·reward_code UNIQUE·건 속성 컬럼이 있어야 한다.
3. `\d layer.road_reward_parcel` 에 reward_code·필지 속성·geom 인덱스가 있어야 한다.
4. 같은 SQL을 다시 실행해도 IF NOT EXISTS 로 오류 없이 통과해야 한다.
