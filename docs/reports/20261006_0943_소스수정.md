# 결과보고서

2026-10-06 | gyujin | 드론영상 체크 마커 타입 오류 · 필지정보 소유자명 마스킹 설정 · QGIS WMS 연결 오류 로그

## 목적

타입 검사에서 드론영상 체크 마커 훅의 중복 선언 오류가 나던 것을 고친다. 필지정보의 소유자명 마스킹 여부를 프로젝트별 설정 파일에서 Y/N으로 관리하도록 한다. QGIS WMS 연결 시 공용 GeoServer에 다른 프로젝트 테이블 부재 오류가 대량으로 쌓이고 응답이 느린 문제를 없앤다.

## 요약

병합 과정에서 지도 객체 타입을 가져오는 줄이 두 번 들어가 중복 선언 오류가 났으므로, 중복된 줄을 제거했다.

필지정보 소유자명 마스킹은 기존에 DB 통합제어 값을 읽는 기능만 있고 화면에 연결되지 않았다. 재시작 없이 반영되는 실행 설정 파일(공용·프로젝트별)의 Y/N 값으로 바꾸고, 행망 응답은 서버에서 가려서 내려보내며, 화면의 소유자명 항목에도 같은 설정을 적용했다. 값을 넣지 않은 프로젝트는 그대로 표시되며, 필요한 프로젝트 설정 파일에만 Y를 넣는다. su 계정으로 로그인한 경우에는 설정과 관계없이 항상 원래 이름을 보여 준다. admin 계정은 일반 사용자와 같이 마스킹된다.

QGIS WMS 레이어 목록 요청을 GeoServer 전체 목록 대신 사용자 읽기 권한 레이어로 앱이 직접 만들도록 바꿨다. GeoServer 전체 목록은 모든 워크스페이스 레이어의 테이블을 검사해, 공용 GeoServer에서 다른 프로젝트 테이블이 없으면 오류가 수백 건 쌓이고 목록 응답이 45초 걸렸다. 변경 후 목록은 0.4초 안에 오고 GeoServer가 꺼져 있어도 목록이 뜬다. 지도 이미지 요청은 기존대로 GeoServer(드론영상은 원본 영상 직접 렌더)로 처리한다.

## 테스트

1. `npx tsc --noEmit`이 오류 없이 끝나야 한다.
2. 드론영상에서 체크한 촬영 단위 마커가 지도에 이전과 같이 보여야 한다.
3. 설정이 없거나 N이면 필지정보 토지소유내역의 소유자명이 그대로 보여야 한다.
4. 프로젝트 설정을 Y로 바꾸면 재시작 없이 필지정보를 다시 열 때 소유자명이 *로 보여야 한다.
5. Y일 때 공유인 조회·변동일자 연혁조회 모달의 소유자 열이 *로 보여야 한다.
6. Y일 때 소유구분·주소·변동원인 등 다른 항목은 그대로 보여야 한다.
7. Y여도 su 계정으로 로그인하면 소유자명·공유인·변동연혁의 소유자가 원래 이름으로 보여야 한다.
8. Y일 때 admin 계정으로 로그인하면 소유자명이 *로 보여야 한다.
9. 소유자명이 없는 필지는 *가 아니라 «-»로 보여야 한다.
10. QGIS에서 WMS 연결 시 레이어 목록이 수 초 안에 떠야 한다.
11. QGIS WMS 연결 후 GeoServer 로그에 테이블 부재 오류가 쌓이지 않아야 한다.
12. WMS 목록에 읽기 권한을 준 레이어만 한글명·그룹으로 보여야 한다.
13. 목록에서 드론영상과 메모 레이어를 추가하면 지도에 영상과 도형이 그려져야 한다.
14. 권한 없는 레이어 이름으로 지도 이미지를 요청하면 읽기 권한 오류가 나와야 한다.
15. QGIS WFS 연결·편집은 이전과 같이 동작해야 한다.
