## 목적

재시작 명령을 프로젝트 env에 따로 두지 않고, 서버 기동 때 쓰는 프로젝트·타입으로 조합한다.

## 요약

명령 실행 재시작은 구동 시 설정된 프로젝트·타입으로 감시 스크립트(또는 npm) 명령을 만든다. env의 재시작 명령 키는 제거했다. GeoServer·다른 재시작 방식은 건드리지 않았다.

## 테스트

1. 감시 스크립트 또는 npm으로 기동한 뒤 명령 실행 재시작으로 적용하면 새 창에 동일 프로젝트·타입으로 서버가 떠야 한다.
2. build_yy env에 재시작 명령 키가 없어야 한다.
3. 버전관리 화면에 env 키 이름이 라벨에 없어야 한다.
4. process.exit·재시작 안 함 동작은 이전과 같아야 한다.
5. GeoServer는 적용 시 여전히 중지 후 기동되어야 한다.
