## 목적

버전관리·소스 업로드 «이력» 조회 시 «Failed to fetch»·콘솔 `ClientFetchError` 원인을 정리하고, 네트워크·세션 오류 시 안내를 개선한다.

## 요약

콘솔 스택의 `SessionProvider` → `getSession` → `Failed to fetch`는 **이력 API 자체 버그가 아니라** Auth.js가 `/api/auth/session`에 **연결하지 못할 때** 발생한다. dev 서버 미기동·재시작 직후·`localhost` 접속(해당 PC에서 IP만 동작) 등에서 동일 증상이 난다. SessionProvider 불필요 재조회를 줄이고, 이력 조회 fetch에 재시도·한국어 안내를 추가했으며, dev 서버는 `0.0.0.0` 바인딩으로 localhost 접속 가능성을 높였다.
