## 목적 (병합)

master 최신 변경을 minami에 병합하면서 지적 스타일·지도 레이아웃 충돌을 해소한다.

## 요약 (병합)

지적 CSS 주석은 UTF-8 한글 주석을 유지했다. 지도 레이아웃은 minami의 지적재조사·개별공시지가·개발부담금 패널과 master의 불법점용 관리카드 패널을 모두 남기고, 패널 너비·위치 계산도 이어 붙였다.

## 파일수정 (병합)

수정 | geoserver_modules/data_dir/styles/jijuk.css
 주석 — UTF-8 한글 주석 유지(줌 구간·라벨 설명)

수정 | src/app/(pages)/map/map-layout-client.tsx
 지적재조사·개별공시지가·개발부담금·불법점용 — import·상태·닫기·패널 배치·너비 합산 모두 유지

## 테스트 (병합)

1. 충돌 마커 없이 지도가 열려야 한다.
2. 지적재조사·개별공시지가·개발부담금 패널이 이전과 같이 열려야 한다.
3. 불법점용 관리카드 목록·상세가 열려야 한다.
4. 여러 패널을 동시에 열면 가로 배치·검색창 위치가 맞아야 한다.

도로망도 도로종류 타입과 코드 문자열이 어긋나 생기던 타입 오류를 맞춘다.

4. 레이어 목록에 «농도망도» 그룹으로 농도 관련 테이블이 묶여 있어야 한다.
