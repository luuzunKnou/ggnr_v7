## 목적

공사대장 도형 편집 중 «도형삭제»를 누르면 지도 위 안내창(도형추가·초기화·도형삭제 버튼)이 함께 사라져, 삭제 후 바로 다시 그릴 수 없었다. 삭제 후에도 안내창이 남아 바로 재작업할 수 있도록 고친다.

## 요약

«도형삭제»를 눌러도 도형 편집 세션이 끝나지 않고, 도형 없는 빈 상태로 안내창이 계속 떠 있도록 수정했다. 안내 문구도 자동으로 «도형추가 버튼으로 공사구간을 그리세요.»로 바뀌어 바로 다시 그릴 수 있다. 함께, 모드 값이 바뀌지 않아 지도가 갱신되지 않던 문제(같은 «수정» 모드 안에서 삭제·초기화 시 이전 도형이 지도에 남아있던 문제)도 고쳤다.

 `geomModifyResetToken` — 편집 모드 값이 그대로("수정")인데 도형만 바뀌는 경우(삭제·초기화) 지도 편집 세션을 강제로 다시 시작시키는 토큰 신규 추가

 `clearGeomDraft`(도형삭제) — 세션을 종료하던 동작을 제거, 도형만 비우고 안내창은 유지해 바로 «도형추가»로 다시 그릴 수 있음
 `resetGeomToSnapshot`(초기화) — 동일한 원인으로 지도가 갱신되지 않던 문제 함께 수정

## 테스트

1. 도형을 그린 뒤 «도형삭제»를 누르면 지도의 도형은 지워지고 안내창은 계속 떠 있어야 한다.
2. 도형삭제 후 안내창의 «도형추가»를 눌러 바로 새 도형을 그릴 수 있어야 한다.
3. 도형을 수정한 뒤 «초기화»를 누르면 지도가 편집 시작 시점 도형으로 바로 되돌아가 보여야 한다(이전 도형이 화면에 남지 않아야 한다).
4. 여러 개 그린 도형 중 «도형삭제»로 전체를 지운 뒤 다시 그린 도형이 필지목록에도 정상적으로 반영돼야 한다.
5. «취소»로 편집을 종료하면 삭제·초기화와 무관하게 편집 시작 전 상태로 정상 복귀해야 한다.
