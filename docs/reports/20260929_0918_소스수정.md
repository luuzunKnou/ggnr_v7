관리자(su) 계정에서도 상세 패널 버튼 아래 폴더 경로가 더 이상 보이지 않는다. 대신 «보고서» 버튼으로 연 PDF 뷰어 상단 파일명 옆에 흐린 글씨로 폴더 경로가 나온다. 일반 계정과 도로대장 보고서 뷰어는 이전과 같다.

영향 받는 기능: 도로대장 보고서 PDF 뷰어 — 보조 표시를 넘기지 않아 변화 없음.

## 테스트

1. 관리자 계정으로 기본계획을 선택해도 버튼 아래 폴더 경로가 보이지 않아야 한다.
2. 관리자 계정으로 «보고서»를 열면 뷰어 상단 파일명 옆에 폴더 경로가 보여야 한다.
3. 일반 계정으로 «보고서»를 열면 폴더 경로가 보이지 않아야 한다.
4. 도로대장 보고서 뷰어 상단은 이전과 같이 파일명만 보여야 한다.
5. 경로가 길면 말줄임되고 마우스를 올리면 전체 경로가 보여야 한다.
