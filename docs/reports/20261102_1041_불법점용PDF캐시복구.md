## 목적

pdf-lib 서식 채우기 방식을 되돌리고, 인쇄와 동일한 Chrome PDF 품질로 «저장 시 캐시 → 전체는 병합»을 다시 쓴다. 캐시가 있을 때 받기 속도를 올린다.

## 요약

서식 그리기 PDF 경로와 fontkit 의존성을 제거했다. 다시 Chromium 인쇄 HTML로 단건 PDF를 만들고 `pdf_cache`에 남긴다. 전체 PDF는 캐시를 읽어 한 파일로 합치며, 없는 카드만 Chrome을 재사용해 병렬로 채운다. 캐시가 모두 있으면 Chrome을 거치지 않는다.

## 테스트

1. 관리카드 저장 후 `pdf_cache/illegal_usage_as/{관리번호}.pdf`가 생겨야 한다.
2. 캐시가 있는 카드만으로 «전체 PDF 저장»하면 Chrome 없이 PDF 1개가 비교적 빨리 받아져야 한다.
3. 받은 PDF 서식·사진이 인쇄 미리보기와 같아야 한다.
4. 캐시 없는 카드가 포함되면 첫 전체 저장은 더 걸려도, 다시 받으면 빨라져야 한다.
5. 사진 변경 후 PDF에 새 사진이 반영되어야 한다.
6. «인쇄»는 HTML 미리보기로 동작해야 한다.
