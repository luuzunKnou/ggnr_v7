## 목적

## 요약

지도 서버에 없는 제방 레이어가 한 장으로 묶인 요청을 실패시켜, 있는 색인도·기본계획까지 안 보였다. 실제 올라간 레이어만 켜도록 바꿨다.

영향 받는 기능: 하천기본계획 목록·상세의 지도 레이어. 제방은 지도 서버에 올린 뒤에야 켜진다.

 `getRiverBasicPlanExistingMapLayers` — DB에 테이블이 있어도 지도 서버에 없는 레이어는 빼서, 없는 제방 때문에 전체가 실패하지 않게 함

수정 | src/app/(pages)/map/_mapContents/river/riverBasicPlan/RiverBasicPlanListPanel.tsx
 목록 로드 후 레이어 켜기 — 가능한 레이어 전부를 켜던 것을, 실제 있는 레이어만 켜도록 변경

## 테스트

2. 지방하천·소하천 탭을 바꿔도 해당 탭 도형이 보여야 한다.
