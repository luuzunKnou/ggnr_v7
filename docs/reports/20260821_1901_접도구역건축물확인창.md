## 목적

## 요약

저장·등록·수정·삭제·취소를 누르면 패널 위에 확인 창이 뜬다. 아니오를 누르면 그대로이고, 확인을 눌러야 반영된다. 저장·삭제 실패와 첨부 안내도 같은 창으로 보여 준다.

## 테스트

1. 저장을 누르면 확인 창이 뜨고, 아니오를 누르면 저장되지 않아야 한다.
2. 확인을 누르면 저장되어야 한다.
3. 등록도 같은 방식으로 한 번 더 물어야 한다.
4. 수정을 누르면 확인 창이 뜬 뒤 편집으로 들어가야 한다.
5. 삭제를 누르면 확인 창이 뜬 뒤 확인해야 삭제되어야 한다.
6. 취소를 누르면 확인 창이 뜬 뒤 편집이 끝나야 한다.
7. 저장 실패 시 브라우저 기본 창이 아니라 같은 안내 창이 떠야 한다.
