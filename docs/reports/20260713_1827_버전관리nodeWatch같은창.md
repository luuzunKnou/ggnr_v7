## 목적

최신소스 적용 순간에만, 새 창 없이 기존 콘솔에서 동일 포트로 웹앱을 다시 띄우도록 맞춘다. 평소 상시 `--watch` 기동은 쓰지 않는다.

## 요약

«같은 창 앱 재실행»은 평소 `npm run dev` 기동을 유지한다. 적용 시에만 같은 콘솔에서 포트를 비운 뒤 `npm run dev -- 프로젝트 타입`으로 앱을 다시 실행한다. 새 CMD를 열지 않고, 기존 콘솔도 강제 종료하지 않으며, 상시 파일 watch는 켜지지 않는다.

## 테스트

1. `npm run dev -- build_yy dev`로 기동한 뒤 «같은 창 앱 재실행»으로 적용하면 새 CMD가 뜨지 않아야 한다.
2. 기존 콘솔이 강제 종료되지 않아야 한다.
3. 적용 후 앱이 같은 포트로 다시 떠야 한다.
4. 평소에는 파일 저장만으로 앱이 자동 재시작되지 않아야 한다.
5. «명령 실행 재시작(새 창)»은 새 창 기동·기존 콘솔 종료가 되어야 한다.
6. 개방망+같은 창 재실행 시 재기동 전에 의존성 설치가 되어야 한다.
