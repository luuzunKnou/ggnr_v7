## 목적

버전관리 화면의 «설치파일 다운로드»·«최신 소스 적용»에 소스코드 업로더와 동일한 단계 체크·실시간 로그·진행률을 추가하고, 설치 ZIP 다운로드를 스트림 방식으로 개선한다.

## 요약

설치파일·최신소스 적용 양쪽 패널에 단계 목록(완료/진행/대기/실패)·진행률 바·실시간 로그를 추가했다. 설치 ZIP은 서버 정보 확인 → 스캔 → 압축 → 다운로드 순으로 단계를 표시하며, 빌드 중 progress 폴링으로 상태를 갱신한다. 최신 소스 적용은 GNMS 조회 → ZIP 수신 → relay 세션 → 청크 전송 → 병합·적용·재시작 단계를 표시한다. 다운로드는 서버에서 `Content-Length`와 파일 스트림을 내려주고, 클라이언트는 `showSaveFilePicker` pipe 또는 스트림 읽기 후 저장한다(기존 `blob()` 전체 버퍼 방식 제거). 압축 생성 시 이미 압축된 확장자는 store(재압축 없음) 정책을 그대로 유지한다.

## 테스트

1. «설치파일 다운로드» 클릭 시 서버 정보·스캔·ZIP 압축·다운로드 단계가 순서대로 표시되어야 한다.
2. 빌드 진행 중 progress 폴링으로 스캔·압축 단계 상세·로그가 갱신되어야 한다.
3. 다운로드 완료 후 브라우저에 ZIP 파일이 저장되어야 한다.
4. 다운로드 중 진행률·전송량(가능 시)이 표시되어야 한다.
5. «최신 소스 전체 적용» 클릭 시 GNMS 조회·다운로드·relay·청크·병합 단계가 표시되어야 한다.
6. 청크 전송 중 N/M 상세와 진행률 바가 갱신되어야 한다.
7. 적용 완료 시 «적용 결과»에 적용·제외·재시작 정보가 보여야 한다.
8. 한쪽 작업 중 반대쪽 패널 버튼이 비활성화되어야 한다.
9. 실패 시 해당 단계가 «실패»로 표시되고 오류가 로그에 남아야 한다.
10. 소스코드 업로더·메모·민원 등 다른 dev 메뉴 동작에 영향이 없어야 한다.
