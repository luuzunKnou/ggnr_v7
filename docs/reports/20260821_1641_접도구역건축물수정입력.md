# 결과보고서

2026-08-21 | JungWooojin | 접도구역 건축물 수정 입력 복구

## 목적

수정·추가 때 서식이 밀리지 않게 하고, 건축물(공작물) 내용과 확인 결과를 표에서 바로 넣고 저장되게 한다.

## 요약

수정 모드에서 칸을 한 줄 더 넣던 것을 없애 보기 화면과 같은 칸 배치를 유지한다. 건축물 내용·확인 결과는 표 칸에 바로 입력한다. 저장 시 숫자 값도 빠지지 않게 맞춘다. 영향 받는 기능은 접도구역 건축물 상세·저장이다.

## 테스트

1. 추가를 눌러도 관리대장 서식 칸이 옆으로 밀리지 않아야 한다.
2. 수정을 눌러도 서식 칸이 옆으로 밀리지 않아야 한다.
3. 건축물(공작물) 내용 칸에 구조·용도·면적을 바로 넣을 수 있어야 한다.
4. 확인 결과 칸에 날짜·이름을 바로 넣을 수 있어야 한다.
5. 저장 후 다시 열어도 건축물 내용이 남아야 한다.
6. 저장 후 다시 열어도 확인 결과가 남아야 한다.
7. 위치(도로예정지·접도구역)와 불량 표시는 수정 때 눌러 바꿀 수 있어야 한다.
8. 보기 화면의 서식 칸 배치는 이전과 같아야 한다.
