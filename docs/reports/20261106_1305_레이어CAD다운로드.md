## 목적

개발자모드 레이어 관리의 레이어 목록에서 선택한 벡터 레이어를 DXF 또는 DWG 단일 파일로 내려받을 수 있게 한다.

## 요약

지도 레이어 설정이 아니라 **개발자모드 › 레이어 관리 › 레이어 목록** 상단에 CAD 다운로드를 두었다. 레이어·형식을 고르면 서버가 테이블 전체 도형을 하나의 CAD로 합쳐 내려준다. 캐드(DWG)는 서버 변환 환경이 있을 때만 선택 가능하다. 행별 SHP·표 다운로드는 그대로이다. (처음에 지도 레이어 설정에 넣었던 UI는 제거했다.)

## 테스트

1. 개발자모드 레이어 관리 › 레이어 목록 상단에 CAD 다운로드 버튼이 보여야 한다.
2. 버튼을 누르면 레이어·형식 선택 창이 열려야 한다.
3. 레이어를 고르지 않으면 다운로드가 진행되지 않아야 한다.
4. 도면으로 받으면 파일 하나가 받아져야 한다.
5. 캐드 변환 환경이 없으면 캐드 항목이 비활성이어야 한다.
6. 여러 레이어를 고르면 하나의 CAD에 합쳐져야 한다.
7. 행별 SHP·표 다운로드는 이전과 같이 동작해야 한다.
8. 지도 레이어 설정에는 CAD 버튼이 없어야 한다.
