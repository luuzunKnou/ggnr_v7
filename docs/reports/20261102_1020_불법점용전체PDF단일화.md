## 목적

전체 관리카드 PDF를 ZIP 분할 없이 사진 포함 PDF 한 장으로 받고, 서버 렌더를 병렬화해 대기 시간을 줄인다.

## 요약

50장 단위 ZIP 분할을 없애고, 건수와 관계없이 인쇄와 같은 서식·사진을 담은 PDF 1개를 내려받게 했다. 사진은 디스크에서 읽어 넣고, Chrome에는 소량씩만 올려 조각을 만든 뒤 순서대로 합친다. 사진 읽기와 Chrome 렌더는 동시에 여러 건 처리한다.

## 파일수정

수정 | src/lib/chromeHtmlToPdf.ts
 `htmlChunksToMergedPdfWithChrome` — concurrency 옵션으로 Chrome 여러 개가 조각을 나눠 렌더. 순서는 유지한 채 병합
 `mergePdfBuffers` — 조각이 많으면 배치 병합으로 피크 메모리 완화

수정 | src/service/riverIllegalOccupationPdfService.ts

## 테스트

1. 목록 «전체 PDF 저장» 결과가 ZIP이 아니라 PDF 파일이어야 한다.
2. 50장 초과(예: 전체 목록)여도 PDF 1개여야 한다.
3. 받은 PDF를 열면 인쇄 미리보기와 같은 서식이어야 한다.
4. 위치도·현황사진·완료사진이 카드에 있을 때 PDF에도 보여야 한다.
5. 카드 순서가 목록에서 넘긴 순서와 같아야 한다.
6. 상세 «PDF 저장»(1장)은 이전과 같이 PDF 1장이 받아져야 한다.
7. 생성 중 서버 Navigation timeout 오류가 나지 않아야 한다.
