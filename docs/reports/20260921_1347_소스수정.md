## 목적

건설행정 메뉴에 둔 도로점용·국공유지(점용대장) 알림을 눌렀을 때 해당 대장으로 이동되지 않던 문제를 고친다.

## 요약

알림 표시 기준을 데이터 접두가 아니라 **현재 시스템 부서업무(메뉴)에 그 기능이 있는지**로 맞췄다. 도로점용·국공유지가 건설행정에만 있으면 건설에서만 보이고(목록에서는 도로/국공유로 구분), 도로행정 부서업무에 없으면 도로에서는 안 뜬다. 클릭 시에도 해당 대장·점사용료 패널로 연다.

## 테스트

1. 건설행정 부서업무에 도로점용·국공유지가 있으면 알림에 둘 다 보여야 하고, 이름·제목으로 구분되어야 한다.
2. 도로행정 부서업무에 도로점용·국공유지가 없으면 도로행정 알림에 해당 건이 나오지 않아야 한다.
3. 건설행정에서 도로점용 알림 클릭 시 도로점용 목록·상세가 열려야 한다.
4. 건설행정에서 국공유지 알림 클릭 시 국공유지 점용 목록·상세가 열려야 한다.
5. 도로·국공유지 점사용료 알림도 부서업무가 있는 시스템에서만 보이고, 클릭 시 각각 맞는 패널이 열려야 한다.
6. 하천점용·울진점용 알림은 하천 부서업무 기준으로 기존과 같이 동작해야 한다.
