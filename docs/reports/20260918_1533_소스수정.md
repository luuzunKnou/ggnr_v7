# 결과보고서

2026-09-18 | dev.strcat | 공통점용 등록 실패

## 목적

공통점용대장 등록 시 geometry 타입 불일치로 INSERT가 거절되던 문제를 바로잡는다.

## 요약

점용대장 테이블 geom은 MultiPolygon인데 화면에서 넘긴 Polygon을 그대로 넣어 PostGIS가 거부했다. 컬럼 타입에 맞게 Multi로 변환한 뒤 넣도록 수정했다. 속성 필드(상태·장소·기간·허가번호)는 문제 없었다.

## 파일수정

수정 | src/service/layerRowService.ts
 `coerceWktToMultiPolygon` — POLYGON((…))을 MULTIPOLYGON(((…))) WKT로 변환
 `geomSetExpr` — MultiPolygon 컬럼에는 MULTIPOLYGON WKT로 GeomFromText
 점용대장 INSERT — geom 타입을 MULTIPOLYGON으로 고정 적용
 등록 실패 메시지 — PostGIS 상세 오류가 보이도록 정리
 `bumpSerialPkIfNeeded` — 등록 전 ogc_fid 시퀀스를 MAX에 맞춰 PK 중복 방지

## 테이블 수정

해당 없음

## 테스트

1. 하천(또는 도로·공유재산) 공통점용에서 도형·필수값 입력 후 등록이 되어야 한다.
2. 등록된 건이 목록에 나타나고 상세에서 도형이 보여야 한다.
3. 기존 점용 건 도형 수정 후 저장이 되어야 한다.
4. 허가번호·점용장소·기간만 넣은 등록도 동일하게 되어야 한다.
