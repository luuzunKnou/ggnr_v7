# 결과보고서

2026-07-10 | 200BingSu | 업로드 이력 메시지 단순화

## 목적

소스 업로드 이력 메시지를 단계별 여러 줄 요약이 아니라, 선택한 라디오·최종 성공/실패·한 줄 본문 형태로 남긴다.

## 요약

이력 메시지 형식을 `node_modules 포함|미포함 - 성공|실패 : 본문`으로 통일했다. 성공 시 본문은 «성공 - 최종 집계 (성공 N / 제외 M / 실패 K)», 실패 시 «실패 - 사유» 한 줄만 기록한다. 서버·클라이언트 모두 동일 규칙을 쓰며 preflight 실패는 클라이언트에서만 기록한다.

## 테스트

1. 업로드 1회 실행 시 «이력»에 행 1개만 추가되어야 한다.
2. 성공 시 메시지가 «node_modules … - 성공 : 성공 - 최종 집계 (…)» 한 줄 형태여야 한다.
3. 청크 등 중간 실패 시 «… - 실패 : 실패 - {사유}» 한 줄만 있어야 하며 단계별 여러 줄이 없어야 한다.
4. preflight 실패 시에도 라디오 선택이 반영된 실패 한 줄이 남아야 한다.
5. 서버가 이미 기록했으면 같은 실행에 클라이언트 중복 행이 없어야 한다.
