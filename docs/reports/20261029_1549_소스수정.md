# 결과보고서

2026-10-29 | gyujin | docs/brief/20261029_1504_배경지도명칭보기.md

## 목적

일반영상·지형도·기타영상을 고르면 명칭보기가 자동으로 꺼지게 한다.

## 요약

항공영상이 아닌 배경을 고르면 명칭보기 체크와 명칭 타일이 함께 꺼진다. 다시 항공영상을 고르면 이전과 같이 자동으로 켜진다.

## 테스트

1. 일반지도를 고르면 명칭보기 체크가 해제되고 명칭이 사라져야 한다.
2. 지형도·백색지도·배경없음을 고를 때도 명칭보기가 꺼져야 한다.
3. 다시 항공영상을 고르면 명칭보기가 체크되고 명칭이 나와야 한다.
4. 일반지도에서 명칭보기를 수동으로 켜면 명칭이 나와야 한다.
