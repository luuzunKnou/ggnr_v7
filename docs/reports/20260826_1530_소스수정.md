# 결과보고서

2026-08-26 | dev.strcat | —

## 목적

하천 알림에 도로 점사용료 사용자가 섞여 나와 클릭해도 상세로 가지 않던 문제를 고친다. 알림은 도로·하천·국공유지 소속에 맞게만 보이게 한다.

## 요약

점사용료 알림 소속을 부서명으로 나누고 있었다. 건설과만 국공유지로 보고 나머지는 전부 하천으로 넣어, 도로 점사용료가 하천 알림에 나왔다. 클릭 시에도 항상 하천 점사용료 화면만 열어 해당 건을 찾지 못했다.

이제 점사용료가 들어 있는 테이블(하천·도로·국공유지)로 소속 시스템을 정한다. 알림 클릭은 현재 시스템에 맞는 점사용료 화면을 연다.

영향 받는 기능: 업무 알림, 점사용료.

## 파일수정

수정 | src/service/useFeeService.ts
 `getUseFeeUnpaidDueNotifications` — 알림 행에 부서명 대신 소속 접두·시스템 값을 넣는다. 세 테이블을 돌 때 어느 테이블에서 왔는지를 그대로 넘긴다

수정 | src/service/bizNotifService.ts
 `listMyBizNotifications` — 부서명이 건설과이면 국공유지, 아니면 하천이던 분기를 제거하고, 점사용료 테이블 소속으로 시스템을 지정한다. 표시 이름도 하천·도로·국공유지 점사용료로 구분한다

수정 | src/app/(pages)/map/map-layout-client.tsx
 `onOpenFee` — 알림 클릭 시 하천 점사용료만 열던 것을 현재 시스템에 맞는 점사용료 화면으로 연다

수정 | src/database/schema/usr_biz_notif_state.ts
 `notif_key` 주석 — 점사용료 알림 키에 소속 접두를 포함하도록 설명을 맞춤. 세 테이블 번호가 겹쳐도 읽음·지우기가 섞이지 않게 한다

## 테스트

1. 하천 시스템 알림에 도로 점사용료 사용자가 나오지 않아야 한다.
2. 하천 시스템 알림의 점사용료 항목을 누르면 하천 점사용료 상세가 열려야 한다.
3. 도로 시스템 알림에는 도로 점사용료만 나와야 한다.
4. 도로 알림 항목을 누르면 도로 점사용료 상세가 열려야 한다.
5. 국공유지 알림에는 국공유지 점사용료만 나와야 한다.
6. 국공유지 알림 항목을 누르면 국공유지 점사용료 상세가 열려야 한다.
7. 하천 점용 종료 임박 알림은 하천에서만 보여야 한다.
8. 사이드바 미읽음 표시가 현재 시스템 알림만 반영해야 한다.
