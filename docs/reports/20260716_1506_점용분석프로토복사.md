## 목적

원본 분석 모달은 git 기준으로 되돌렸다. 프로토타입 폴더에 복사본을 두고 도로·하천·국공유지별 입지 기준·미충족 원인·필요서류 설명·점사용료 산정 안내를 반영했다. 사이드바는 시스템별 도로점용/하천점용/국공유지점용과 점사용료로 표시한다.

## 테스트

1. 기존 도로점용 분석(원본 메뉴) 동작이 이전과 같아야 한다.
2. 프로토 목록 «점용분석»이 열려야 한다.
3. 도로 시스템에서 사이드바에 «도로점용»·«점사용료»가 보여야 한다.
4. 하천 시스템에서 사이드바에 «하천점용»이 보여야 한다.
5. 점용분석 결과에서 미충족 항목에 원인 문구가 보여야 한다.
6. 필요 서류에 설명이 함께 보여야 한다.
7. 하천 시스템에서 분석 시 하천 기준·서류가 나와야 한다.
