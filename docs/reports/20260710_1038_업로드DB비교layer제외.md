## 목적

`dbManagerService` 공용 비교를 건드리지 않고 소스 업로드만 Drizzle 테이블 비교로 분리한다. 소스코드 업로더 «이력»은 업로드 이력만 조회한다.

## 요약

`dbManagerService`의 `definedTablesOnly` 옵션은 롤백했다. 업로드 DB 비교는 `compareDrizzleSchemaForSourceUpload`로 분리해 Drizzle 테이블만 검사한다. 이력 API에 `filter=source_upload_only`가 오면 `version_all`로 잘못 해석되던 버그를 수정했다.

## 테스트

1. DB에 `layer.*`만 많아도 소스 업로드 시 DB 불일치 알림이 없어야 한다.
2. dev DB 스키마 동기화는 기존처럼 DB 전용 테이블도 표시되어야 한다.
3. 소스코드 업로더 «이력»에는 소스코드 업로드 이력만 나와야 한다.
4. 버전관리 «이력»에는 설치·적용 이력만 나와야 한다.
