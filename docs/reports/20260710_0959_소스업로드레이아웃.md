## 목적

소스코드 자동 업로드 화면에서 통계·결과 표와 실시간 로그를 좌우로 나란히 배치해 업로드 진행 중에도 로그와 결과를 동시에 확인할 수 있게 한다.

## 요약

실시간 로그를 우측 열로 분리하고, 좌측에 core/runtime 통계·완료 진행률·분류-파일-상태-비고 표를 세로로 묶어 flex 2:1 비율로 배치했다. 로그 영역은 업로드 전에도 항상 표시되며 남은 높이를 채우도록 스크롤을 적용했다.

## 테스트

1. 개발자 모드 «Source Code Uploader» 진입 시 좌측에 통계·표, 우측에 «실시간 로그» 패널이 나란히 보여야 한다.
2. 업로드 전 우측 로그에 «로그 대기 중...»이 표시되어야 한다.
3. 업로드 시작 후 로그가 우측 패널에 누적되고 자동 스크롤되어야 한다.
4. 업로드 완료 후 좌측 표에 파일별 분류·상태·비고가 표시되어야 한다.
5. 좌측 통계에 core·runtime·data·성공·실패·스킵 건수가 맞게 갱신되어야 한다.
6. 단계 진행·상단 폼·업로드 중 진행률 바는 기존과 같이 동작해야 한다.
