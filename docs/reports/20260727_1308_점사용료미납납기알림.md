# 결과보고서

2026-07-27 | dev.strcat | 점사용료 미납 납기일 15일 이내 알림

## 목적

미납 점사용료의 납기일이 오늘부터 15일 이내이면, 하천점용 만료 알림과 같이 내 정보·사이드바 중요 알림으로 알려 준다.

## 요약

미납만 대상으로 최종납기일(없으면 최초납기일)을 보고, 남은 일수가 0~15일이면 알림에 올린다. 로그인·내 정보 열 때 조회하며, 클릭 시 점사용료 상세가 열린다. 만료 알림과 같이 계정별 읽음·지우기를 로컬에 두고, 두 종류 알림이 서로 덮어쓰지 않게 순차 갱신한다.

## 테이블 수정

해당 없음

## 테스트

1. 미납이고 납기일이 오늘~15일 이내인 건이 내 정보 알림에 «미납임박»으로 보여야 한다.
2. 납기일이 16일 이후이거나 이미 지난 미납은 알림에 나오지 않아야 한다.
3. 수납 상태 건은 알림에 나오지 않아야 한다.
4. 알림 행을 누르면 점사용료 상세가 열려야 한다.
5. 하천점용 만료 알림과 미납 알림이 함께 있어도 서로 사라지지 않아야 한다.
6. 알림을 지우면 같은 계정에서 다시 보이지 않아야 한다.
7. 사이드바 중요 알림 표시가 미읽음 미납에도 반응해야 한다.
