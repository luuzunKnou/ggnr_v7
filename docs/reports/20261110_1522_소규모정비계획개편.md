# 결과보고서

2026-11-10 | dev.strcat | 정비계획 — 기존 계획(보고서 4장) 적재·분석 모달 정리·산출근거 재구성

## 목적

정비계획을 기존 정비계획 값으로 먼저 채우고, 새 위험시설 분석 모달을 간결하게 다시 꾸미며, 결과를 자동으로 만들고 산출근거를 보고서·근거 법령 기준으로 정리한다.

## 요약

기존 계획 적재: 보고서 4장(소규모 공공시설 정비사업 시행계획)의 표 4.2.1-1(사업규모·저감대책), 표 4.2.2-9(기본적 평가 5항목·총점·기초순위), 표 4.2.2-11(부가적 평가·최종순위), 표 4.3.2-2(사업비·연차)를 시설별로 옮겨 170개소를 확정 계획으로 넣었다. 유형별 사업비 합계가 보고서 단계별 시행계획과 같고(세천 11,114 · 마을진입로 1,340 · 농로 1,645 · 소교량 3,160 · 낙차공 170, 합계 17,429백만원), 1~5차년 시설은 80개소로 1단계 기준과 같다. 명세서의 우선순위·연차·사업비·사업량은 이 값을 쓰고, 확정 행을 누르면 개요(저감대책·사업규모 포함)와 결과(기초·최종순위, 단계·연차, 항목별 점수, 부가적 평가)를 본다. 구산리1 마을진입로 2곳은 보고서 표에 부가적 평가가 없어 «—»로 둔다. 후보지 시설명과 같은 7곳은 시설에 연결했고, 소교량은 보고서가 리 단위 통합이라 연결되지 않는다.

명세서: 읍면·상태·연도 선택을 검색 왼쪽에 두었고 «계획 시작» 문구를 빼고 연도 선택을 «2026~2030년»처럼 보이게 했다. 연차 배분 버튼·창·계산을 없앴다. «분석»은 위험시설 중 정비계획에 없는 시설만 고르며(지금은 소교량 3곳 중 1곳이 분석 중, 2곳 선택 가능), 분석 중 시설은 명세서 행에서 연다.

분석 모달: 위쪽을 속성표(유형·상태·위치·제원·평가구분·최근 위험도 평가·위험시설 지정일)로 바꾸고, 단계를 정비내용·사업비와 보상·평가·결과 넷으로 줄였다(기본적·부가적 평가를 «평가» 하나로). 아래에 «닫기»를 추가하고 안내는 맨 아래 «개략 산정이며 참고용입니다» 한 줄만 둔다. 표·입력 칸은 한 줄로 고정하고 칸 폭을 정리했으며, «?»는 누르면 계산식·근거가 열린다. 편입 필지는 주소(지번)를 검색해 고르면 PNU·지목·필지면적·공시지가가 자동으로 들어가고 편입면적은 필지면적으로 먼저 채운다. 평가는 한 표로 B/C(비우면 15점)·피해이력지수(그대로)·재해위험도(기본 나등급·인명피해 없음)·주민불편도·경과년수(지정일 입력)와 부가적 평가(기본 지속성 1·정책성 0·계획성 0, 기존 계획에서 가장 많은 값)를 넣는다.

결과(자동): 입력 칸 없이 총점·예상 기초/최종순위·단계(순위 80위 기준)·연차(검토 후 배분)·사업비·사업량·사업효과(수혜자 = 주민불편도 거주인구, 농경지 = 피해이력 농경지 유실·매몰 면적, 건물 = 피해이력 주택 동·세대)·순위 변동을 보여 준다. 후속 절차는 체크 대신 «검토 후 할 일»(부서 검토 → 유관기관 협의 → 보상 협의 → 실시설계 → 연차 배분·예산 → 공사 발주·확정) 안내로 바꿨다. 산출근거는 사업비(복구계획수립 요령 단가), 보상비(토지보상법·요령 보상배율), 기본적 평가(자연재해위험개선지구 관리지침·보고서 표 4.2.2-1~8, 항목별 근거 표·산정기준·적용 점수), 피해이력 지원기준지수(국토부·행안부·농식품부 고시), 부가적 평가·최종순위(표 4.2.2-10~11), 단계·연차·명세서(4.3절·시행규칙 별지 제3호) 순으로 근거 한 줄과 적용 값을 묶었다.

## 요약

분석할 시설 고르기는 표(시설명·유형·위치·최근 위험도 평가·위험시설 지정일)에서 한 줄을 고르고 «분석 시작»을 누르는 방식으로 바꿨다. 분석 모달은 왼쪽에 시설 정보 상자와 단계(단계마다 «입력 필요 n건» 또는 한 줄 설명), 가운데에 단계 내용, 오른쪽에 계산 결과를 두고, 글자·입력칸·표를 키웠다. 단계마다 위쪽에 «이 단계에서 할 일»을 번호로 보여 준다. «?»는 제목과 줄별 목록으로 크게 열린다.

정비내용: 공종 표를 키우고, 부속 시설(소교량·낙차공)은 이름·리명을 입력하면 후보지 시설에서 찾아 위치·L·B를 넣고 개략 사업비(소교량 재설치 단가, 낙차공 L 기준 단가)를 계산한다. 사업비·보상: 위쪽 «필지 주소 검색»에서 주소를 고르면 필지 한 줄이 추가되고 지목·필지면적·공시지가를 자동으로 가져오며, 편입면적은 필지면적으로 먼저 채운다. 기타 금액은 직접 입력한다. 평가: 항목마다 카드(배점·현재 점수·설명)로 나누고, B/C는 «기존 계획 기준(15점, 170개소 모두 15점)»과 «B/C 값 입력(경제성 분석 결과, 관리지침 개선법)» 중 고르게 했다. 피해이력은 피해 없음·지수 직접·항목별 재난지수·항목과 물량 중 고르고, 재해위험도·인명피해·부가적 평가는 버튼으로 고르며, 주민불편도·경과년수는 계산 값과 해당 구간 점수를 강조해 보여 준다.

결과: 위쪽 요약 카드, «다음 할 일»(지금 할 일 주황·끝난 일 초록, 저장 전에는 임시저장, 저장 후에는 유관기관 협의), 평가 점수 표, 산출근거 전체 표(구분·항목·근거 법령·고시·조항·표·산정 방법·이 시설 적용 값), 변경 이력으로 정리했다. 검토 요청·검토 상태는 화면에서 뺐고, 추정 상태 분석은 «삭제»할 수 있다. «보고서 다운로드»는 결과 요약·정비내용·사업비와 보상·평가·산출근거·확인 필요 항목을 담은 문서(워드)로 내려받는다. 협의·실시설계 입력과 명세서 반영은 정리 후 추후에 붙인다.

확정 계획 개요의 사업규모·저감대책은 보고서 값이라 분석한 시설에는 넣을 곳이 없었다. 정비내용 단계 맨 위에 «사업 개요»(사업규모·저감대책 직접 입력, 보고서 예시 안내)를 두고 완성도 항목에 넣었으며, 결과 단계·확정 후 개요·한글 보고서에 같은 값을 보여 준다.

비용-편익은 «B/C 값 입력» 대신 «편익 입력(B/C 계산)»으로 바꿨다. 편익(백만원)을 넣으면 비용은 분석 사업비를 그대로 써서 B/C = 편익 ÷ 사업비를 계산하고 구간 점수로 바꾼다. 기존 계획은 모두 15점이라 편익을 넣으면 점수가 같거나 낮아진다는 안내를 붙였다. 확인 필요 항목에 사망·부상 이중 반영, 피해이력 집계 기준일, 경과년수 기준일(기존 계획 2점 고정 대 분석 오늘 기준), 비용-편익 전 시설 적용 여부를 더했다.

시험 자료로 분석 3건을 넣었다. 봉평리 세천(입력 완료, 비용-편익 기본 15점, 농경지 유실 1,200㎡·주택침수 2세대로 피해이력지수 16,710.1 → 4.2점, 총점 49.2), 명도리 낙차공(입력 완료, 편익 5백만원 ÷ 사업비 6.6백만원 = B/C 0.76 → 6점, 주택 반파 1동·부상 1인으로 지수 68,800 → 17.2점, 가등급·부상 25점, 총점 68.2), 온정리 소교량(사업 개요·주민불편도 미입력, 입력 중)이다. 손계산과 화면 계산이 같음을 확인했다.
