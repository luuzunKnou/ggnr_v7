# 결과보고서

2026-08-21 | JungWooojin | 접도구역 건축물 — 도면·사진은 기존 첨부 폴더 방식

## 목적

도면·사진은 대장 번호로 폴더에서 한 장씩 불러오면 되므로, 따로 두었던 첨부 저장 칸은 없앤다.

## 요약

위치도·건축물·종전·변경은 대장 키 아래 폴더에 종류당 한 장만 둔다. 기존 첨부 불러오기와 같다. 건축물 내용·확인 결과만 딸린 칸으로 남기고, 촬영 연월일만 대장에 둔다. 화면 배치는 바꾸지 않았다.

## 파일수정

수정 | src/database/schema/road_frontage_building.ts
 `roadFrontageBuildingAttach` — 도면·사진 칸 정의 삭제. 파일은 폴더에서 읽기로 맞춤

수정 | src/service/ensureLayerAppTables.ts
 `ensureRoadFrontageBuildingTables` — 첨부 칸을 만들지 않고, 이미 있으면 제거

수정 | src/service/roadFrontageBuildingService.ts
 `loadChildren` — 건축물 내용·확인 결과만 읽음. 그림 주소는 저장소에서 두지 않음
 `replaceChildren` — 저장 시 첨부 칸에 쓰지 않음. 촬영일은 대장에만 유지

## 테이블 수정

삭제 | layer.road_frontage_building_attach
 `road_frontage_building_attach` — 위치도·건축물·종전·변경을 칸에 두지 않음. 서버 기동 시 있으면 제거

## 테스트

1. 서버를 다시 켠 뒤 대장 저장·조회가 이전과 같아야 한다.
2. 건축물 내용·확인 결과는 같이 저장되어야 한다.
3. 종전·변경 촬영 연월일은 대장에 남아야 한다.
4. 도면·사진용 별도 칸은 생기지 않아야 한다.
5. 화면 상세 칸 배치는 그대로여야 한다.
