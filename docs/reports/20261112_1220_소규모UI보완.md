## 목적

미리보기에서 보던 페이지가 크게 보기에서 첫 장으로 돌아가던 문제를 고친다. 정비계획 이관 모달의 제목·열 겹침과 잘림을 없애고, 안전점검은 표 대신 짧은 선택 카드로 바꿔 다시 누르면 닫히게 한다.

## 요약

PDF는 파일을 바꿀 때만 1쪽으로 돌리고, 열 때 지정한 쪽은 문서가 준비된 뒤 한 번만 맞춘다. 이관은 지도 남은 폭으로 모달을 넓히고 체크·시설명·유형 열을 나눠 겹침을 없앴다. 안전점검은 연도 칩·카드 선택과 재클릭 닫기, 선택 시 아래 상세(개요 접힘)로 공간을 줄였다.

## 테스트

1. 인라인 미리보기에서 3쪽으로 넘긴 뒤 크게 보면 3쪽으로 열려야 한다.
2. 크게 보기에서 다른 PDF로 바꾸면 1쪽으로 돌아가고, 같은 파일 썸네일 3쪽을 누르면 3쪽이 보여야 한다.
3. 정비계획 이관 모달에서 제목·안내 문구가 잘리지 않아야 한다.
4. 이관 표에서 체크와 «시설명» 제목이 겹치지 않아야 한다.
5. 이관 표의 구분 변경·점검일이 가로로 잘리지 않거나 스크롤로 볼 수 있어야 한다.
6. 안전점검에서 보고서 카드를 누르면 아래에 개요·대상이 나타나야 한다.
7. 같은 보고서 카드를 다시 누르면 상세가 닫혀야 한다.
8. 보고서 선택 전 목록이 패널을 넓게 쓰고, 선택 후에는 목록이 위쪽 일부만 차지해야 한다.
9. 다른 메뉴(후보지·정비계획) 전환 시 안전점검 패널이 남지 않아야 한다.
