## 목적

드론영상 작업단위명과 저장 경로는 고정하고 작업일·임무 목적·작성자·메모만 영구 수정할 수 있게 한다. 작업단위·파일 삭제 시 원본과 변환 타일까지 함께 제거한다.

## 요약

드론영상 상세의 편집 범위를 네 가지 업무 속성으로 제한하고 서버 저장과 목록 재조회를 연결했다. 실제 작업일 저장 영역을 추가했으며, 속성 수정 과정에서는 작업단위명·폴더명·원본 경로·변환 타일 경로를 변경하지 않는다. 작업단위 삭제는 소속 TIF·변환 타일·실제 폴더를 제거하고, 파일 행 삭제는 해당 원본과 변환 타일만 제거한다.

영향 받는 기능: 드론영상 목록, 작업단위 상세, 드론영상 지도 표시.

## 테스트

1. 드론영상 상세에서 작업단위명은 입력할 수 없어야 한다.
2. 작업일·임무 목적·작성자·메모만 입력할 수 있어야 한다.
3. 올바르지 않은 작업일은 저장되지 않아야 한다.
4. 저장 후 상세를 다시 열어도 수정값이 유지되어야 한다.
5. 수정 전후 실제 폴더명이 같아야 한다.
6. 수정 전후 원본과 변환 타일이 지도에 동일하게 표시되어야 한다.
7. 작업단위 삭제 시 소속 원본·변환 타일·실제 폴더가 함께 제거되어야 한다.
8. 파일 한 건 삭제 시 해당 원본과 변환 타일만 사라지고 다른 파일은 남아야 한다.
9. 사진동영상과 파노라마의 수정 동작은 바뀌지 않아야 한다.
