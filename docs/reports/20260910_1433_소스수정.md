# 결과보고서

2026-09-10 | gyujin | —

## 목적

무인비행장치 촬영신청서에서 촬영형태가 항공영상일 때 촬영지역(위치도) 입력을 받지 않도록 한다.

## 요약

항공영상은 시·군 전역 성격으로 보고, 신청서·제출 검증·PDF에서 촬영지역 행을 제외했다. 다른 촬영형태는 기존처럼 범위 지정이 필수다.

## 파일수정

수정 | src/app/(pages)/map/_mapContents/shootingRequest/ShootingRequestForm.tsx
 `isSatellite` — 항공영상 선택 시 촬영지역(지번·위치도) 행을 숨김. 선택 전환 시 범위·지번 초기화
 `handleSubmit` — 항공영상이 아니면 범위 필수 검증 유지. 항공영상 제출 시 범위·지번 비움

수정 | src/service/shootingRequestService.ts
 `create` — 촬영형태가 항공영상이면 범위 WKT 없이 접수. hasScope false·범위·지번 null 저장

수정 | src/app/(pages)/map/_mapContents/shootingRequest/shootingRequestDocument.ts
 `buildShootingRequestHtml` — 항공영상 PDF에서 촬영지역(위치도) 행 생략

## 테이블 수정

해당 없음

## 테스트

1. 촬영형태 «항공영상» 선택 시 촬영지역(위치도) 칸이 보이지 않아야 한다.
2. 항공영상으로 부서·신청자·목적만 채워 제출하면 접수되어야 한다.
3. 항공영상 외 형태로 범위 없이 제출하면 «촬영지역 범위를 먼저 지정하세요» 안내가 나와야 한다.
4. 다른 형태에서 범위를 그린 뒤 항공영상으로 바꾸면 범위·지번이 비워져야 한다.
5. 항공영상 신청서 PDF에 촬영지역(위치도) 행이 없어야 한다.
6. 드론영상·사진동영상·파노라마는 기존처럼 범위 그리기·제출이 동작해야 한다.
