# 결과보고서

2026-07-13 | 200BingSu | 버전관리 최신 소스 적용 시 GeoServer 재가동

## 목적

최신 소스 적용 중 GeoServer가 파일을 잠가 덮어쓰기가 실패하는 문제를 막기 위해, 적용 시 GeoServer를 먼저 끄고 반영한 뒤 다시 켠다.

## 요약

버전관리 소스 적용은 항상 GeoServer 중지 → 복사 → 기동 → 앱 재시작 예약 순으로 동작한다. 기동·중지는 공통 모듈로 분리해 개발자 모드와 공유하며, 적용 결과에 중지·기동 안내를 표시한다. 중지·기동 실패는 적용을 막지 않는다.

## 테스트

1. GeoServer가 떠 있는 상태에서 최신 소스 적용 시 JDK 파일 잠김으로 복사가 실패하지 않아야 한다.
2. 적용 완료 후 GeoServer가 다시 기동되어야 한다.
3. «적용 후 서버 재시작»을 꺼도 GeoServer는 중지 후 기동되어야 한다.
4. «재시작 안 함»을 골라도 GeoServer는 중지 후 기동되어야 한다.
5. 적용 결과에 GeoServer 안내 문구가 보여야 한다.
6. GeoServer가 꺼져 있거나 스크립트가 없어도 소스 적용은 끝까지 진행되어야 한다.
7. 개발자 모드에서 GeoServer 기동·중지가 이전과 같이 동작해야 한다.
8. 명령 실행 재시작 시 앱 재시작 예약과 GeoServer 기동이 모두 이뤄져야 한다.
