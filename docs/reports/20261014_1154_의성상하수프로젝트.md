## 목적

의성 상하수 전용 프로젝트를 만들고, 영양에 붙어 있던 상·하수도 행정 시스템을 그쪽으로 옮긴다.

## 요약

`water_us` 프로젝트 설정을 추가하고, 상수도·하수도 행정 업무지원 시스템을 영양(`build_yy`)에서 빼 의성 프로젝트에서만 켜지게 했다. 기능 코드는 공용이라 이동하지 않았다.

## 파일수정

추가 | src/config/projects/water_us.env
 `[dev]`·`[demo]`·`[prod]` — water_us DB·데이터 경로 설정

추가 | src/config/projects/water_us.runtime.env
 `ENABLED_SYSTEMS` — wtlAdmin, swlAdmin
 `SYSTEM_KOR_NAME` — 의성군 상하수도 행정 업무지원 시스템
 `SGG_CODE` — 47940(의성군)

수정 | src/config/projects/build_yy.runtime.env
 `ENABLED_SYSTEMS` — wtlAdmin, swlAdmin 제거 (건설·하천 등만 유지)

## 테이블 수정

해당 없음 (DB·역할·스키마만 생성. 앱 테이블 push는 별도)

- DB/사용자: `water_us` / `water_us` (비밀번호 `water_us`)
- 호스트: `192.168.127.32:5433` (dev)
- 스키마: `layer`, `public_layer`, `land_linkage` + PostGIS

## 테스트

1. `npm run dev -- water_us dev`로 기동 시 상수도·하수도 행정 메뉴가 보여야 한다.
2. 영양(`build_yy`) 기동 시 상수도·하수도 행정 메뉴가 없어야 한다.
3. 의성 프로젝트에서 관망조회·시설관리·설비관리·공간분석이 열려야 한다.
4. water_us DB로 접속·기동이 되어야 한다.
