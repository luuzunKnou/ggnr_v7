# 결과보고서

2026-07-13 | 200BingSu | 버전관리 이력 IP·성공메시지

## 목적

최신 소스 적용 성공 이력에 계정명 대신 클라이언트 IP가 남고, 성공 메시지가 깨지지 않게 한다.

## 요약

적용 성공 이력은 브라우저에서 확정한 IP를 relay로 넘겨 `mvh_ip`에 저장한다. 계정명을 `clientHost`에 넣던 처리를 제거했다. 성공 메시지의 특수 구분 문자는 일반 슬래시·화살표로 바꿔 표시 깨짐을 줄였다.

## 테스트

1. 최신 소스 적용 성공 후 이력에 사설 IP가 보여야 한다.
2. 이력에 로그인 계정명이 IP 자리에 나오지 않아야 한다.
3. 성공 메시지에 적용·제외 건수·망·GeoServer 안내가 깨지지 않고 보여야 한다.
4. 소스코드 업로드·설치파일 다운로드 이력 IP 기록은 이전과 같아야 한다.
