# 결과보고서

2026-09-11 | JungWooojin | docs/brief/20260911_1342_QGIS레이어권한.md

## 목적

레거시와 같이 QGIS가 키로 WMS에 붙을 수 있게 권한 프록시를 만든다.

## 요약

`/wms.do`를 추가했다. 접속 키로 읽기 권한이 있는 레이어만 Capabilities·지도 요청에 통과시키고, 관리 화면에 WMS 주소도 보여 준다. WFS·편집 주소는 기존과 같다.

## 파일수정

추가 | src/app/api/ogc/wms/route.ts
 `GET` — `/wms.do` 요청을 WMS 프록시로 전달

수정 | src/service/qgisLayerControlService.ts
 `proxyWmsGet` — 키 검사 후 GeoServer WMS 중계. Capabilities는 읽기 허용 레이어만 남김
 `filterWmsCapabilitiesXml` — 접속 주소를 프록시로 바꾸고 권한 없는 레이어 제거
 `regenerateUserQgisKey` — WMS 주소 안내 값 추가

수정 | next.config.ts
 `rewrites` — `/wms.do` → API

수정 | src/middleware.ts
 `/wms.do` — 로그인 없이 키로 접근 허용

수정 | src/app/(pages)/map/_mapContents/qgisLayerControl/QgisLayerControlPanel.tsx
 WMS 접속 주소 — 복사 버튼과 함께 표시

## 테이블 수정

해당 없음

## 테스트

1. 키가 없으면 WMS 요청이 오류 안내를 돌려줘야 한다.
2. 읽기 권한이 있는 키로 Capabilities를 받으면 허용 레이어만 보여야 한다.
3. 읽기 권한이 없는 레이어 GetMap은 거절되어야 한다.
4. 레이어권한 화면에서 WFS·WMS 주소가 같이 보여야 한다.
5. WMS 주소 복사 시 안내가 나와야 한다.
6. 기존 WFS·저장(편집) 동작은 그대로여야 한다.
