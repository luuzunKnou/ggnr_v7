# 결과보고서

2026-07-21 | gyujin | 현장 점 이동 표시 오류 수정 · 첨부 다중 선택

## 목적

유지보수·민원 현장 점을 지도에서 옮겨도 반영되지 않던 문제를 고치고, 첨부파일을 한 번에 여러 개 고를 수 있게 한다.

## 요약

편집 중 저장 점과 임시 점이 겹쳐 보여 이동이 안 된 것처럼 보이던 표시를 임시 점으로 대체하도록 바꿨다. 편집 중에는 해당 항목 강조를 유지한다. 도로·유지보수·민원 첨부 모두 다중 선택이 된다.

## 파일수정

수정 | src/app/(pages)/map/_mapComponents/hooks/useRoadNetworkOverlayLayer.ts
 현장 점 오버레이 — 편집 중 임시 점이 있으면 해당 항목 저장 점은 숨기고 같은 강조 키로 임시 점만 표시해 이동이 보이게 함

수정 | src/app/(pages)/map/_mapContents/road/roadNetwork/RoadNetworkDetailPanel.tsx
 `siteModal` 포커스 유지 — 편집 시트 동안 현장 강조 키가 풀리지 않도록 재설정, 탭 전환 시에만 초기화
 `addRoadAttachmentsFromFiles` / `addDraftAttachments` — 파일 여러 개를 한 번에 첨부 목록에 추가
 파일 입력 — `multiple`로 다중 선택

수정 | docs/reports/도로망도.md
 첨부 다중 추가 문구 반영

## 테스트

1. 점이 있는 유지보수를 열어 지도를 클릭하면 강조 점이 새 위치로 옮겨져야 한다.
2. 시트 현장 주소가 새 좌표 기준으로 갱신되어야 한다.
3. 초기화 시 열었을 때 위치로 돌아와야 한다.
4. 첨부 «추가»에서 파일을 여러 개 고르면 모두 썸네일로 붙어야 한다.
5. 도로 공통 첨부 탭에서도 여러 파일을 한 번에 추가할 수 있어야 한다.
6. 저장 후 목록·지도에 옮긴 위치가 유지되어야 한다.
