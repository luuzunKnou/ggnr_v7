## 목적

하천기본계획 상세보기의 속성명을 defineLayer 필드 조회 대신, 현재 정의와 동일한 하드코딩 목록으로 표시하도록 변경한다.

## 요약

상세 속성 라벨·순서를 기능 폴더의 고정 목록으로 두어 defineLayer 필드 API에 의존하지 않는다. 표시 항목은 기존 상세표시(수립년도·기본계획명·연장·하천명·기본계획명·하천연장·시점·종점)와 동일하다.

## 파일수정

추가 | src/app/(pages)/map/_mapContents/river/riverBasicPlan/riverBasicPlanDetailFields.ts
 `PLAN_AS_DETAIL_FIELDS` — 하천·소하천 기본계획 상세에 쓸 영문 필드명·한글 라벨 8건을 고정 목록으로 둠
 `getRiverBasicPlanDetailFields` — 탭별 상세 필드 목록 반환(현재 하천·소하천 동일)

수정 | src/app/(pages)/map/_mapContents/river/riverBasicPlan/RiverBasicPlanDetailPanel.tsx
 `planDetailFields` — defineLayer 필드 API 비동기 조회 제거, 하드코딩 목록을 바로 사용
 `detailEntries` — 고정 필드 기준으로만 속성 행 구성, 원본 키 폴백 제거

## 테이블 수정

해당 없음

## 테스트

1. 하천기본계획 목록에서 하천을 선택하면 상세에 속성정보가 보여야 한다.
2. 속성명 순서가 수립년도 → 기본계획명 → 하천기본계획연장 → 하천명 → 하천기본계획명 → 하천연장 → 시점 → 종점 이어야 한다.
3. 속성 한글명이 defineLayer를 바꿔도 화면 라벨이 바뀌지 않아야 한다.
4. 소하천 탭 상세에서도 동일한 8개 속성명이 보여야 한다.
5. 연도 값은 천단위 콤마 없이 표시되어야 한다.
