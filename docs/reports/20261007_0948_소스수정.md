# 결과보고서

2026-10-07 | dev.strcat | —

## 목적

영덕군 상하수도 프로젝트를 새로 실행할 수 있도록 프로젝트 설정을 추가한다. SHP 업로드로 덮어써진 도로구간·실폭도로·기초구간 지도 스타일을 원래대로 되돌린다.

## 요약

스타일 원복: SHP 업로드 위저드가 레이어를 다시 만들면서 도로구간(파란 선·끝점 화살표·도로명)·실폭도로(회색 면)·기초구간 스타일을 자동 생성 스타일(보라·주황 반투명 면)로 덮어썼다. 세 스타일 파일을 저장소의 원래 내용으로 되돌리고, 업로드가 새로 만든 기초구간 스타일 파일은 지웠으며, 지도 서버 설정을 다시 읽어 바로 반영했다. 영향 받는 기능: 지도 도로구간·실폭도로·기초구간 표시.

스타일 재생성을 «연결 복구» 기능으로 변경: 같은 이름의 스타일이 이미 있으면(지도 서버 등록 스타일 또는 스타일 폴더에 남은 CSS·SLD 파일) 색상·구조 등 내용은 전혀 바꾸지 않고, 레이어 기본 스타일로 다시 연결만 한다. 스타일 폴더에 파일만 남고 등록이 빠진 경우에도 그 파일 내용 그대로 다시 등록한다. 스타일이 전혀 없을 때만 자동 스타일을 새로 만든다. 개발 화면의 «스타일 재생성»·«전체 스타일 재생성»·«자동 스타일 적용» 버튼, SHP 업로드, 레이어 설정 오류 수정, 엑셀 업로드 등 모든 경로에 똑같이 적용된다. 레이어를 다시 발행할 때도 지도 서버가 붙이는 기본 도형 스타일 대신 기존 스타일을 다시 연결한다. 영향 받는 기능: SHP 업로드, 엑셀 업로드, 레이어 설정 오류 수정, 지오서버 관리, 레이어 정보 관리, 도로변 건물·마커, 민원 레이어 생성.

연결 검증: 레이어가 없으면 «레이어를 먼저 생성하세요»라고 안내한다. 연결 후 지도 이미지를 한 장 그려 오류가 없는지 확인하고, 오류가 나면 사유를 보여준다. 새로 만드는 자동 스타일은 실제 데이터의 도형 종류(점·선·면)를 우선해 선 레이어에 면 스타일이 붙지 않게 한다. 라벨 컬럼이 데이터에 없으면 라벨을 넣지 않는다. «전체 스타일 재생성»은 실패한 레이어 목록을 보여준다.

영덕군 상하수도 프로젝트 설정(접속 정보·실시간 설정)을 만들었다. 메인 화면과 지도에는 상하수도 통합관리시스템만 보이고, 하천·도로·건설 등 다른 시스템은 노출하지 않는다. 개발·시연·운영 데이터베이스 이름과 계정은 프로젝트명과 같게 두었고, 운영 서버 주소는 비워 두었다. 영향 받는 기능: 없음(새 프로젝트로 실행할 때만 적용).

## 테스트

1. 영덕 상하수도 프로젝트로 개발 서버를 실행하면 정상 기동되어야 한다.
2. 메인 화면에 상하수도 통합관리시스템만 보여야 한다.
3. 하천·도로·건설 등 다른 시스템은 메인 화면과 메뉴에 나오지 않아야 한다.
4. 상단 시스템명과 하단 주소가 영덕군 기준으로 표시되어야 한다.
5. 지도 레이어에 상수·하수 그룹이 보여야 한다.
6. 지도에서 도로구간을 켜면 파란 선과 끝점 화살표, 도로명이 보여야 한다.
7. 실폭도로를 켜면 회색 반투명 면으로 보여야 한다.
8. 기초구간을 켜면 업로드 전과 같은 스타일로 보여야 한다.
9. 스타일이 있는 기존 레이어를 SHP 업로드에서 재생성해도 기존 스타일이 유지되어야 한다.
10. 지오서버 관리에서 레이어를 다시 발행해도 기존 스타일이 기본 스타일로 연결되어 있어야 한다.
11. 스타일이 없는 신규 레이어를 업로드하면 자동 스타일이 새로 만들어져야 한다.
12. 지오서버 관리에서 실폭도로 «스타일 재생성»을 눌러도 회색 면 그대로여야 하며 색이 바뀌지 않아야 한다.
13. 스타일 폴더에 파일만 있고 등록이 빠진 레이어를 재생성하면 기존 파일 내용 그대로 등록·연결되어야 한다.
14. 재생성 후 지도에서 해당 레이어를 켜면 오류 없이 표시되어야 한다.
15. 지오서버에 없는 레이어의 스타일을 재생성하면 «레이어를 먼저 생성하세요» 안내가 나와야 한다.
16. «전체 스타일 재생성»에서 실패한 레이어가 있으면 건수와 사유가 표시되어야 한다.
17. 스타일이 없는 선 데이터 레이어를 재생성하면 면이 아닌 선 스타일로 새로 만들어져야 한다.
