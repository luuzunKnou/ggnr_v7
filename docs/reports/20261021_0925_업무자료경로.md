# 결과보고서

2026-10-21 | gyujin | 업무자료 원본을 데이터 폴더로 이전

## 목적

업무자료 문서·도면 원본을 소스 트리가 아니라 프로젝트 데이터 폴더의 업무자료 위치에 두도록 바꿨다.

## 요약

문서와 도면을 데이터 폴더 아래 업무자료 루트에 나눠 저장한다. 목록·업로드·내려받기·미리보기는 그대로이고, 빈 도면 안내만 경로 없이 짧게 바꿨다. 영향 받는 기능은 업무자료이다.

## 테스트

1. 업무자료 문서 탭이 비어 있으면 파일 없음 안내가 나와야 한다.
2. 업무자료 도면 탭이 비어 있으면 «도면 파일이 없습니다.»가 나와야 한다.
3. 문서 업로드 시 데이터 폴더 업무자료 문서 위치에 파일이 생겨야 한다.
4. 도면 업로드 시 데이터 폴더 업무자료 도면 위치에 파일이 생겨야 한다.
5. 도면을 열면 같은 폴더의 미리보기 그림이 보여야 한다.
6. 소스 안 예전 폴더에 파일을 넣어도 목록에 나오지 않아야 한다.
7. 메모·민원 등 다른 지도 메뉴는 그대로여야 한다.
