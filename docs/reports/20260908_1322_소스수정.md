# 결과보고서

2026-09-08 | gyujin | PDF 미리보기 타입 오류 · 공사대장 목록 정렬 · 공사대장 상세 UI 통일 · 데이터 조회 목록 로딩·토글 레이스

## 목적

타입 검사 시 PDF 첨부 미리보기 컴포넌트에서 선언 전 참조 오류가 나던 것을 고친다. 공사대장 목록·상세 UI를 보상편입용지와 맞춰 헤더·선택·버튼·섹션 라벨을 통일한다. 데이터 조회에서 레이어를 골랐을 때 목록이 «로딩 중»에 멈추는 문제와, 닫은 뒤 다시 열면 바로 닫히던 문제를 고친다.

## 요약

패닝·회전 상태보다 앞에서 ref를 초기화해 타입 오류가 났으므로, 상태를 먼저 선언한 뒤 ref에 연결하도록 순서를 바꿨다. 공사대장 목록은 헤더 정렬·표준 테이블 헤더 높이·선택 행 스타일을 보상편입용지와 같게 맞췄다. 상세는 속성 접기, 수정·삭제 아이콘 버튼, 필지목록 구분선·건수·라벨, 첨부파일 라벨 스타일을 통일했다. 데이터 조회 목록은 같은 레이어인데도 요청이 취소된 뒤 재조회를 건너뛰어 로딩이 풀리지 않던 레이스를 막았다. 레이어 토글은 유지한다. 패널을 다시 열 때 opened 정리 로직이 목록 보기와 함께 테이블 선택을 지워 바로 닫히던 오류를, 목록 보기가 없을 때만 정리하도록 고쳤다. 지도·검색으로 고른 뒤에는 «닫기» 대신 «이전»으로 레이어 목록에 돌아가게 했다.

## 테스트

1. `npx tsc --noEmit`이 오류 없이 끝나야 한다.
2. 지도에서 PDF 첨부 미리보기가 이전과 같이 열려야 한다.
3. 확대·패닝·회전이 정상 동작해야 한다.
4. 공사대장 목록 헤더 높이가 보상편입용지와 비슷해야 한다.
5. 목록 행 선택 시 좌측 강조선·배경 강조가 보여야 한다.
6. 목록 헤더를 누르면 정렬이 되고, 다시 누르면 방향 전환·해제가 되어야 한다.
7. 속성정보 헤더를 누르면 속성표가 접히고 다시 누르면 펼쳐져야 한다.
8. 속성정보가 펼쳐진 상태에서 수정·삭제에 아이콘이 보여야 한다.
9. 필지목록 위에 구분선이 있고 «필지목록 (N)» 형태로 건수가 보여야 한다.
10. 필지목록·첨부파일 제목 글자 크기·색상이 속성정보와 같아야 한다.
11. 필지가 많을 때 첨부 영역이 최소 높이 이상으로 보여야 한다.
12. 필지·첨부 목록이 넘칠 때 스크롤바가 보여야 한다.
13. 다른 행을 선택하거나 수정을 시작하면 속성정보가 다시 펼쳐져야 한다.
14. 첨부 미리보기·업로드·다운로드가 이전과 같이 동작해야 한다.
15. 데이터 조회에서 레이어를 선택하면 «로딩 중»이 끝나고 목록이 나와야 한다.
16. 다른 레이어로 바꿔도 목록이 다시 조회되어야 한다.
17. 목록 행을 골라도 전체 목록이 사라지거나 로딩에 멈추지 않아야 한다.
18. 지도에서 식별한 뒤 같은 레이어를 데이터 조회로 열면 전체 목록이 나와야 한다.
19. 레이어를 닫은 뒤 다시 열면 패널이 열린 채로 유지되어야 한다.
20. 같은 레이어 재클릭으로 패널이 닫히는 토글은 그대로 동작해야 한다.
21. 시스템 전환 시 목록 보기가 없으면 테이블·행 선택 쿼리만 정리되어야 한다.
22. 패널이 열린 채 지도에서 고르면 하단에 «이전»이 보여야 한다.
23. «이전»을 누르면 패널은 유지되고 해당 레이어 목록으로 돌아가야 한다.
24. 일반 레이어 목록의 «닫기»는 패널을 닫아야 한다.
