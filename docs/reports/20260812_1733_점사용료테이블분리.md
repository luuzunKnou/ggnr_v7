# 결과보고서

2026-08-12 | dev.strcat | 점사용료 스케줄러·테이블 분리

## 목적

점사용료 스케줄러를 runtime에서 이름으로 차단하고, 세입과목명에 따라 하천·도로·국공유지 테이블에 나눠 저장하며, 화면은 시스템별로 같은 코드로 해당 테이블만 조회하도록 한다.

## 요약

`DISABLED_SCHEDULERS=useFeeSync`로 스케줄러를 끌 수 있게 했다. 연계 시 `rprs_txm_nm`으로 water/road/public 테이블에 저장하고, `ENABLED_SYSTEMS`에 없는 시스템 과목은 스킵한다. 기존 `ngl_fee_list`는 코드상 하천(`water_ngl_fee_list`)으로 맞췄다. UI·WMS는 `system`에 따라 접두만 바꾼다. DB 이름 변경은 SQL 스크립트만 준비했다(자동 적용 없음).

## 테스트

1. UAV runtime에 스케줄러 차단이 있으면 기동 로그에 점사용료 스케줄러 skip이 나와야 한다.
2. 울진처럼 차단이 없으면 스케줄러가 등록되어야 한다.
3. 하천 시스템 점사용료 목록이 하천 테이블만 조회해야 한다.
4. 도로·건설 시스템에서도 각각 도로·국공유지 테이블을 조회해야 한다.
5. 연계 시 하천·소하천 과목은 water, 도로 과목은 road, 국공유·공유 과목은 public에 저장되어야 한다.
6. ENABLED_SYSTEMS에 없는 시스템 과목은 연계에서 스킵되어야 한다.
7. SQL 적용 전·후 테이블 이름과 GeoServer 레이어를 확인해야 한다.
