# 결과보고서

2026-11-02 | gyujin | docs/brief/20261029_1504_배경지도명칭보기.md

## 목적

배경지도 패널의 명칭보기를 목록과 구분되게 보이게 한다. 아이콘·켜짐 글자는 빼고 스위치만 둔다.

## 요약

명칭보기를 스위치가 있는 강조 줄로 바꿨다. 켜져 있으면 파란 줄로 구분된다. 글자 아이콘과 켜짐·꺼짐 문구는 빼서 «명칭보기»와 스위치만 남겼다.

## 테스트

1. 배경지도를 열면 맨 위 명칭보기와 스위치만 보여야 한다.
2. 항공영상일 때 명칭보기 줄이 파랗게 강조되어야 한다.
3. 일반지도를 고르면 강조가 풀려야 한다.
4. 명칭보기 줄을 눌러도 켜고 끌 수 있어야 한다.
5. 글자 아이콘과 켜짐·꺼짐 문구는 보이지 않아야 한다.
