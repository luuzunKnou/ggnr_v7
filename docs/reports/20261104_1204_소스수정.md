## 목적
코드 정의 JSON이 있는 필드인데 레이어 필드 타입이 TEXT로 남아 목록·기본정보에서 한글 코드 변환이 되지 않던 항목을 CODE로 맞춘다. 데이터조회 목록에서 긴 셀 값이 옆 칸과 겹치지 않게 한다. 원도 데이터가 없는 프로젝트에서 빈 기본 폴더만으로 우측 «세부원도» 버튼이 보이지 않게 한다. 시설관리 안전점검 탭의 기준 조회 안내를 빼고 목록 행 수를 늘려 하단 여백을 줄인다. 울산 동구 UAV 프로젝트 식별자를 새 이름으로 맞춘다. 수치지형도 폴더 목록이 느리던 것과 버튼 말줄임을 고친다.

## 요약
codes 루트의 field_테이블__필드.json과 fields 테이블 JSON을 대조해, 코드가 있는데 타입이 CODE가 아닌 필드를 일괄 CODE로 수정했다. 49개 테이블, 272개 필드. 이미 CODE인 항목(570건)은 유지했다. 이어서 데이터조회 목록 헤더·셀에 넘침 숨김·말줄임을 넣어 긴 ID가 옆 칸과 겹치지 않게 했다. 세부원도 버튼 노출은 폴더 존재만 보지 않고, 보관 목록에 원도가 있거나 폴더 안에 실제 항목이 있을 때만 켠다. 시설관리 안전점검 탭에서는 시설명 기준 조회 문구를 제거하고 페이지당 14행으로 표시한다. 울산 UAV 프로젝트 설정·이미지·코드 판별을 새 프로젝트명으로 통일했다. 개발·시연 DB와 데이터 폴더도 동일 이름으로 rename했다. 수치지형도 폴더 목록은 파일마다 정보 조회하던 방식을 이름만 세거나 색인 개수를 쓰도록 바꿔 빠르게 뜨게 했고, 버튼 글자는 말줄임 없이 전체가 보이게 했다.
