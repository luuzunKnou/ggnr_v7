## 목적

점용대장·울진 하천점용·점사용료 화면을 정리한다. 목록에서는 본표만 보이게 하고, 필지 선택 시 점용과 겹치는 부분만 강조하며, 점사용료 목록·상세 표시를 맞춘다. 울진 하천점용에는 점용시설물 레이어 on/off를 두고, 점용·시설물·필지·물건지 색으로 겹침이 구분되게 맞춘다.

## 요약

점용대장·울진 하천점용은 목록·오픈 시 본표만 켜고, 상세에서 필지·물건지를 누르면 전체 자식 레이어 대신 선택 도형만 강조한다. 필지는 본표와의 면 교집합만 표시하며, 교집합 실패 시 전체 필지로 되돌리지 않는다. 점사용료는 목록 컬럼·스크롤바·상세 기본 항목 순서를 맞췄다. 울진 하천점용 목록에 «시설물» 토글을 두어 점용시설물 레이어를 켜고 끌 수 있게 했다(꺼짐은 «추가»와 동일 빈 스타일, 켜짐만 노란색). 시설물은 점용·필지보다 항상 아래에 깔린다. 색은 GeoServer CSS/SLD를 기준으로 울진·공통 점용(하천·도로·공유재산) 본표·필지·물건지·시설물에 동일 적용했다. 점용대장 #68CCCA·시설물 #FBBA00·필지 #1D4ED8·물건지 #EF4444(투명 0.35). 목록 선택·도형 수정 시 본표 벡터 강조만 기존 빨간 표시를 유지한다.

## 테스트

1. 점용대장·울진 하천점용 목록을 열거나 행을 눌러도 필지·물건지 레이어 전체가 켜지지 않아야 한다.
2. 울진·공통 점용에서 점용대장은 청록(#68CCCA), 필지는 파랑, 물건지는 빨강, 울진 시설물은 주황(#FBBA00) 반투명으로 보여야 한다.
3. 상세에서 필지를 누르면 본표와 겹치는 부분만 파란 반투명으로 강조되고, 필지 전체가 본표 밖으로 길게 남지 않아야 한다.
4. 상세에서 물건지를 누르면 해당 물건지만 빨간 반투명으로 강조되어야 한다.
5. 같은 필지·물건지를 다시 누르면 강조가 해제되고 본표만 남아야 한다.
6. 점사용료 목록에 대장번호·부서명이 보이고 부과번호·연도는 없어야 한다.
7. 점사용료 목록에서 스크롤바는 숨겨지고 휠로 스크롤되어야 한다.
8. 점사용료 상세 더보기 위에 지정한 16개 항목이 해당 순서로 보여야 한다.
9. 울진 하천점용 «시설물»은 꺼져 있으면 «추가»와 같은 빈 버튼이고, 켜면 주황 톤으로 채워져야 한다.
10. «시설물»을 켜면 점용시설물이 점용·필지보다 아래에 주황(#FBBA00)으로 보여야 한다.
11. 시설물을 끄거나 패널을 닫으면 시설물 레이어가 꺼져야 한다.
12. 시설물을 켠 뒤 본표 도형을 클릭하면 기존처럼 목록·상세 선택이 동작해야 한다.
13. 다른 기능(공유재산·도로점용·메모·측정 등)의 필지·패널 전환은 이전처럼 동작해야 한다.
