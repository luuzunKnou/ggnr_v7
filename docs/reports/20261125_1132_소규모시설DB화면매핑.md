# 결과보고서

2026-11-25 | dev.strcat | 소규모 공공시설 DB → 화면 매핑

## 목적

shp로 넣어 둔 시설·점검·보고서를 후보지·안전점검 화면이 바로 쓰도록 시드 로딩을 DB 우선으로 바꾼다.

## 요약

화면 진입 시 `spf_fac`·`spf_check`·`spf_report`를 읽어 시설·점검·보고서 상태로 채운다. 관리번호 폴더 첨부가 있으면 그대로 붙이고, DB가 비어 있을 때만 예전 seed.json·디스크 시드로 넘어간다. 보고서는 DB 1건(2020 전수조사)이 목록에 나온다.

1. 후보지 목록에 시설이 5천건대 규모로 보여야 한다.
2. 시설 행의 구분·등급이 최근 점검과 맞아야 한다.
3. 시설 선택 시 속성·지도 위치가 나와야 한다.

7. DB가 비어 있으면 예전 시드·예시 보고서로 열려야 한다.
