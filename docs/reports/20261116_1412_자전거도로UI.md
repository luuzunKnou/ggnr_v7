## 요약

구분은 연장과, 시점은 종점과 한 줄에 2칸으로 두고 진행방향은 두 줄로 보이게 했다. 구간은 속성 아래 접기 목록으로, 첨부는 하단 탭·썸네일 격자로 맞춰 도로망도와 같은 구조로 바꿨다.
