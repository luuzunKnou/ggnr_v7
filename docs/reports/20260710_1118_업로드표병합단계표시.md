# 결과보고서

2026-07-10 | 200BingSu | 업로드표·병합단계표시

## 목적

하단 결과 표의 파일 열 폭을 줄이고, 원격 병합/압축 해제 단계가 실제 작업 전에 완료로 보이던 표시 오류를 수정한다.

## 요약

파일 열에 고정 폭·말줄임을 적용해 비고 열 공간을 확보했다. 병합 단계 조기 완료는 GNMS 응답이 아니라 ggnr_v7이 complete API 호출 전에 npm install 단계로 progress를 넘기면서, UI가 병합을 이미 지난 단계로 처리한 것이 원인이었다. complete 응답 대기 중에는 병합(및 npm install) 단계가 진행 중으로 유지되도록 수정했다.
