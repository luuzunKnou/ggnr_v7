# 결과보고서

2026-11-19 | 200BingSu | 물놀이 표지판·구조함 지도 아이콘 소실

## 목적

상세에 구조함·표지판 위치가 있는데 지도에 점이 안 보이던 원인을 확인하고, 지도 아이콘이 다시 그려지도록 스타일을 고친다.

## 요약

원인은 심볼 파일 경로가 아니라, 자식 점 레이어 스타일이 묶음용 count 속성을 쓰는데 실제 테이블에는 그 칸이 없어 지도 요청이 예외로 실패한 것이었다. 묶음 규칙을 빼고 방사선 대피소와 같이 그림만 그리도록 바꿨고, 서버 스타일 다시 읽기 후 지도 그림 요청이 정상 PNG로 나온다. 축소 시 숫자 묶음은 이번엔 보류했다.

## 테스트

1. 물놀이 표지판 패널을 열면 지도에 표지판·구조함 점이 보여야 한다.
2. 상세 위치 목록에 있는 점이 지도에도 보여야 한다.
3. 표지판 점은 파란 그림, 구조함 점은 주황 그림이어야 한다.
4. 전체·구조함·표지판 종류 전환 시 해당 점만 보여야 한다.
5. 검색·읍면동 등 필터를 켜도 지도 요청이 예외 없이 그려져야 한다.
6. 확대·축소해도 점이 통째로 사라지지 않아야 한다.
7. 방사선 대피소 아이콘은 이전과 같이 보여야 한다.
