# 결과보고서

2026-07-21 | gyujin | 공사대장 도형편집 지도 안내창 추가

## 목적
직전 작업에서 «수정»에 도형 편집을 통합했지만 안내문구·조작 버튼을 상세 패널 안쪽에 텍스트로만 넣어, 도로망도가 지도 위에 띄우는 안내창(포털 배너)과 다르게 보였다. 도로망도와 동일하게 지도 화면 위에 안내창을 띄우도록 맞춘다.

## 요약
도로망도의 `mapEditBanner`(지도 시각적 중심에 `createPortal`로 띄우는 안내창) 패턴을 그대로 가져와, 공사대장 도형 편집 중에도 지도 위에 안내 문구 + «도형추가»·«초기화»·«도형삭제» 버튼이 뜨도록 했다. 상세 패널 안에 있던 텍스트 안내·버튼은 지도 배너로 옮기며 제거했다.

## 파일수정

 상세 패널 내부 텍스트 안내·버튼 — 지도 배너로 대체되어 제거

## 테스트

1. «수정» 진입 시 지도 화면 위(검색창 아래)에 안내창이 떠야 한다.
2. 도형이 없는 신규 공사는 «그려주세요» 안내와 «도형추가» 버튼이 보여야 한다.
3. 기존 도형이 있으면 «정점을 끌어 수정» 안내와 «초기화» 버튼이 함께 보여야 한다.
4. 그리는 중에는 «도형추가» 버튼이 비활성화돼야 한다.
5. «초기화»를 누르면 편집을 유지한 채 도형이 편집 시작 시점 모양으로 돌아가야 한다.
6. «도형삭제»를 누르면 확인창 없이 도형이 즉시 사라져야 한다.
7. «취소»를 누르면 안내창이 사라지고 도형도 편집 전 상태로 되돌아가야 한다.
8. 패널 안쪽에는 더 이상 도형 안내 텍스트·버튼이 중복으로 보이지 않아야 한다.
