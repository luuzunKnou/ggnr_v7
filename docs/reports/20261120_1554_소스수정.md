## 테스트

1. «보안등»에서 «수급» 필터 시 목록 건수가 나와야 한다.
2. 수급 행을 누르면 행정동·주소·램프종류 등이 보여야 한다.
3. 지도에 수급 점이 보이고 클릭 시 상세가 열려야 한다.
4. 목업 관리번호(10001 등)는 나오지 않아야 한다.
5. «보안등»을 열면 필터된 목록 점이 지도에 표시되어야 한다.
6. 목록 행·지도 점 클릭 시 해당 위치로 이동하고 상세가 열려야 한다.
