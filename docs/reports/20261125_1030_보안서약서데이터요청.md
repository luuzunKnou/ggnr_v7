# 결과보고서

2026-11-25 | 200BingSu | 레이어 다운로드 권한·데이터 요청 목록/승인

## 목적

레이어 다운로드 승인 주체를 DB로 관리하고, 데이터 요청 목록·승인 화면을 역할(본인·팀장·관리자·슈퍼)에 맞게 나눈다. 개발자 모드 다운로드는 서약 없이 바로 저장한다.

## 요약

개발자모드 레이어 목록에 SHP/엑셀·첨부 권한을 두고 저장한다. 자동승인은 서약 후 즉시 승인, 관리자·팀장은 승인 대기, 없음은 서약 없이 바로 받되 이력은 남긴다. 데이터 요청은 일반=본인, 팀장=동일부서, 관리자·슈퍼=전체를 보며 사용자 검색은 일반에게 숨긴다. «데이터 요청 승인» 화면에서 기본 대기 목록을 보고 승인·반려하며, 팀장은 팀장 승인·동일부서만, 관리자·슈퍼는 전체를 본다.

## 테스트

1. 레이어 목록 스타일 옆에 SHP/엑셀·첨부파일 선택란이 보여야 한다.
2. SHP/엑셀이 없음일 때 개발자모드 다운로드는 서약 없이 바로 받아져야 한다.
3. 일반 계정 데이터 요청에 사용자 검색란이 보이지 않아야 한다.
4. 팀장 계정은 같은 부서 팀원 요청이 데이터 요청 목록에 나와야 한다.
5. 다른 부서 요청은 팀장 데이터 요청 목록에 나오지 않아야 한다.
6. 관리자·슈퍼는 데이터 요청 전체 목록이 보여야 한다.
7. 데이터 요청 승인 메뉴로 들어가면 기본이 대기 목록이어야 한다.
8. 팀장 승인 대기 건은 해당 부서 팀장 승인 화면에만 보여야 한다.
9. 관리자 승인 대기 건은 팀장 승인 화면에 나오지 않아야 한다.
10. 승인·반려 후 목록 상태가 바뀌고, 승인된 건은 데이터 요청에서 다운로드할 수 있어야 한다.
