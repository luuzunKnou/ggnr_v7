# 공사대장 기능 목록

2026-07-16 | gyujin | 하천행정

하천행정 통합관리 시스템 사이드바 «공사대장». 목록·상세·지도·대상 하천·첨부까지 한 세트로 동작한다.

---

## 1. 메뉴·진입

1. 하천 시스템 서비스 목록에 «공사대장»이 등록되어 있다.
2. 사이드바에 공사대장 메뉴 아이콘이 표시된다.
3. 메뉴를 켜면 좌측 목록 패널이 열린다.
4. 목록에서 공사를 고르면 오른쪽에 상세 패널이 붙는다.
5. 목록·상세 패널 폭은 드래그로 조절된다.
6. 메뉴를 끄면 선택·지도 표시·공간검색·하천 위치 강조가 함께 초기화된다.

---

## 2. 목록·검색

1. 검색 방식은 **통합검색 / 도형검색 / 행정경계 검색** 세 가지이다.
2. 통합검색은 공사명·위치·하천·업체·감독·비고 등 키워드로 걸러 본다.
3. 도형검색은 사각형·다각형·원형을 지도에 그려 범위와 겹치는 공사만 남긴다.
4. 행정경계 검색은 읍면동·리를 골라 경계 합집합으로 공간 필터한다.
5. 공간 필터가 켜져 있으면 «범위 적용 중 · 해제»로 한 번에 풀 수 있다.
6. 목록 행에는 공사명·하천(축약)·업체명·착수일자가 보인다. 하천이 많으면 «남천, 동천 외 N» 형태로 표시된다.
7. 행을 클릭하면 상세가 열리고 해당 공사 구간이 지도에 강조·이동된다.
8. «추가»로 빈 공사를 만들고 바로 상세 편집으로 들어간다.
9. 필터된 목록이 지도 공사구간 표시에 그대로 반영된다.

---

## 3. 상세 · 속성

1. 속성 표 순서: 공사명·공사위치 → 대상 하천(전체 폭) → 공사량·계약일 → 착수일자·준공일자 → 실준공일자·업체명 → 대표자명·전화번호 → 감독관·감독관명 → 사업비_전·사업비_증가 → 사업비_감소·사업비_후 → 업체주소·변경사유 → 비고.
2. 대상 하천은 속성 표에 대표 2개(+외 N)만 요약 표시하고, «관리»로 속성 칸 옆 작은 패널을 열어 추가·삭제를 처리한다.
3. 수정 시에도 같은 표 레이아웃을 유지하고, 칸 안에서 입력·저장·취소한다.
4. 삭제가 가능하다.
5. 신규 추가는 공사명 입력 후 저장한다.
6. «도형 그리기»로 지도에 공사구간(다각형)을 새로 그린다. 기존 구간이 있으면 지우고 다시 그릴지 확인한 뒤, 확인 즉시 이전 구간은 지도에서 사라진다.
7. «도형 수정»으로 정점을 끌어 수정한 뒤 «수정 완료»로 반영한다. 취소 시 수정 전 모양으로 되돌린다.
8. 도형 편집 중에는 해당 공사의 기존 오버레이·선택 강조를 숨기고 편집 레이어만 보여, 이전 구간이 겹쳐 남지 않는다.
9. 도형 편집은 다른 지도 그리기와 배타로 동작한다.
10. 긴 공사명은 목록·상세 헤더에서 잘리고, 커서를 올리면 전체 이름이 보인다.

---

## 4. 상세 · 대상 하천

1. 속성 표에는 대표 하천 2개와 «외 N»만 요약으로 보인다.
2. «관리»를 누르면 속성 칸 옆에 작은 패널이 뜬다. (화면 전체를 가리지 않음)
3. 패널 «등록» 탭에서 전체 목록을 보고 삭제·지도 이동한다.
4. «추가» 탭에서 등록된 하천 목록만 검색·선택할 수 있다. (임의 이름 입력 불가)
5. 이미 넣은 하천은 추가 후보에서 빠진다.

---

## 5. 상세 · 첨부

1. 파일을 올리고 목록에 표시한다.
2. 이미지·PDF는 미리보기·다운로드·삭제가 가능하다.

---

## 6. 지도 연동

1. 패널이 열리면 필터된 공사구간(폴리곤)이 지도에 표시된다.
2. 목록에서 공사를 고르면 선택 강조가 뜨고 해당 구간으로 화면이 이동한다.
3. 지도에서 공사구간을 클릭하면 상세가 열린다.
4. 상세에서 대상 하천을 고르면 임시 하천 위치로 이동·강조된다. (공사 구간과 별개)
5. 도형검색은 다른 지도 그리기와 배타로 동작한다.
6. 패널을 닫으면 구간·강조·공간 필터가 사라진다.
