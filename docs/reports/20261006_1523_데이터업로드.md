# 결과보고서

2026-10-06 | gyujin | 데이터 업로드 화면 (1단계: 업로드 UI)

## 목적

사용자가 SHP·엑셀 자료를 직접 올려 레이어로 등록하는 기능의 첫 단계로, 지도 왼쪽 패널에서 파일 선택 → 설정 → 미리보기까지 진행하는 업로드 화면을 만든다.

## 요약

지도 메뉴에 «데이터 업로드»를 추가하고, 올린 파일을 브라우저에서 바로 읽어 SHP 구성 파일 점검, 좌표계·인코딩 자동 감지, 엑셀 시트·머리글·위치 컬럼 지정, 건수·도형·속성 미리보기를 제공한다. 설정·미리보기 단계에서는 앞 100건을 고른 좌표계로 변환해 지도에 주황색으로 임시 표시하고, 국내 범위를 벗어나면 좌표계 오류로 경고한다. 좌표계 후보는 개발자 SHP 마법사와 같은 방식으로 원시 좌표 범위를 우리 지역 읍면동 경계와 비교해, 겹치는 좌표계만 일치율 순으로 보여주고 1순위를 자동 선택한다. 서버 저장·레이어 등록·데이터조회 연결은 후속 작업이며 «등록» 버튼은 비활성 상태다. 메뉴는 시험(test) 시스템에만 추가했다.

영향 받는 기능: 지도 왼쪽 패널 배치(검색창·지도 여백 계산), 사이드바 메뉴 목록(공통 기능 설정), 개발자 SHP 등록 마법사의 좌표계 자동 탐지(공유 서비스 함수 분리).

## 테스트

1. 시험 시스템 지도에서 «데이터 업로드» 메뉴를 누르면 왼쪽 패널이 열리고 «파일 선택» 단계가 표시되어야 한다.
2. SHP zip을 올리면 도형·색인·속성·좌표계·인코딩 파일 유무가 표시되어야 한다.
3. 도형·색인·속성 중 하나라도 빠진 SHP는 «다음»이 눌리지 않아야 한다.
4. 좌표계 파일이 있는 SHP는 설정 단계에서 좌표계가 «자동 감지»로 선택되어야 한다.
5. 좌표계 파일이 없는 SHP는 «추정» 표시와 확인 안내가 나와야 한다.
6. 속성 인코딩을 바꾸면 미리보기의 한글 속성이 다시 읽혀야 한다.
7. 미리보기 건수가 원본 SHP 건수와 같아야 한다.
8. 엑셀을 올리면 경도·위도 또는 주소 컬럼이 자동으로 선택되어야 한다.
9. 머리글 행을 바꾸면 컬럼 목록이 바뀌어야 한다.
10. 위치를 만들 수 없는 엑셀 행이 있으면 «위치 없음» 건수가 경고 색으로 표시되어야 한다.
11. 패널을 닫았다 다시 열면 처음 단계부터 시작해야 하고 지도의 주황색 미리보기도 사라져야 한다.
12. 다른 메뉴(데이터조회·메모·민원)로 전환해도 검색창 위치와 기존 패널 배치가 달라지지 않아야 한다.
13. 설정 단계에서 좌표계를 고르면 앞 100건이 지도에 주황색으로 표시되고 해당 범위로 이동해야 한다.
14. 좌표계를 바꾸면 도형이 바뀐 좌표계 기준 위치로 다시 그려져야 한다.
15. 국내 범위를 벗어나는 좌표계를 고르면 지도 이동 없이 경고가 나와야 한다.
16. 파일 선택 단계로 돌아가면 지도 미리보기가 사라져야 한다.
17. 좌표계 파일이 없는 SHP는 지역 경계와 가장 많이 겹치는 좌표계가 «지역 경계 기준»으로 자동 선택되어야 한다.
18. 좌표계 목록에서 우리 지역과 겹치는 좌표계가 일치율과 함께 위쪽에 보여야 한다.
19. 좌표계 파일이 잘못되어 지역과 겹치지 않으면 경고와 함께 맞는 후보가 안내되어야 한다.
20. 다른 지역 자료를 올리면 «우리 지역 경계와 겹치지 않습니다» 안내가 나와야 한다.
21. 개발자 화면 SHP 등록 마법사의 좌표계 자동 탐지가 이전과 같이 동작해야 한다.
