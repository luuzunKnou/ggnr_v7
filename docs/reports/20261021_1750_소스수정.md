# 결과보고서

2026-10-21 | 213am | —

## 목적

분할 코드 선택에서 검색 결과가 적어도 모달 높이가 줄어들지 않게 한다.

## 요약

코드 목록 영역을 최대 높이가 아니라 고정 높이로 두어, 검색 조건이 바뀌어도 모달 크기가 유지된다. 목록이 넘치면 그 안에서 스크롤된다.

## 테스트

1. 분할 코드 선택 모달을 열면 코드 목록 영역 높이가 일정해야 한다.
2. 검색어를 입력해 결과가 줄어도 모달 높이가 변하지 않아야 한다.
3. 검색 결과가 없으면 «표시할 코드가 없습니다»가 같은 높이의 목록 안에 나와야 한다.
4. 코드가 목록 높이를 넘으면 목록 안에서만 스크롤되어야 한다.
5. 분할 미리보기 단계 높이는 이전과 같아야 한다.
