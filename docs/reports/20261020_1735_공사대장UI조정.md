# 결과보고서

2026-10-20 | luuzunKnou | 공사대장 UI·데이터 조정

## 목적

사업목록을 엑셀 «…사업» 제목 기준으로 한 줄 표시하고, 검색·엑셀 속성·상세 아래 공사목록·구역 절반·첨부 썸네일을 맞춘다.

## 요약

공사명에서 사업명을 뽑아 묶고, 좌측은 검색·한 줄 사업행 → 사업 상세(엑셀 컬럼명) → 공사목록 순으로 둔다. 우측 공사정보는 엑셀 필드명을 쓰고 구역이 패널 절반을 차지하며, 하단 첨부는 썸네일 격자로 보여 준다.

## 테스트

1. 사업목록이 한 줄로 사업명·기간·금액이 보여야 한다.
2. 사업명에 «사업»이 들어간 제목만 묶여 보여야 한다.
3. 검색어 입력 시 사업목록이 걸러져야 한다.
4. 사업 선택 시 상세정보 아래에 공사목록이 바로 나와야 한다.
5. 사업·공사 속성 라벨이 엑셀 컬럼명(공사위치, 사업비_전 등)과 같아야 한다.
6. 우측 패널에서 공사구역이 대략 절반 높이를 차지해야 한다.
7. 첨부영역이 썸네일 형태로 보여야 한다.
