## 목적

시스템 상세에서 레이어 그룹·서비스 선택 패널 열 수를 보기 좋게 맞춘다. 프로젝트 구성에서 다른 프로젝트 runtime도 골라 편집할 수 있게 한다. 레이어 그룹 후보를 레이어 정의 전체에서 가져오도록 맞춘다. 권한관리 목록을 직접 생성·신청 권한으로 나눈다.

## 요약

레이어 그룹 목록은 2열, 서비스 목록은 1열로 바꿨다. 프로젝트 구성 상단에 프로젝트 선택 목록을 두어 선택한 프로젝트의 runtime 설정을 조회·저장한다. 레이어 그룹 후보는 시스템 카탈로그만이 아니라 레이어 정의 그룹 전체를 쓴다. 권한관리 왼쪽 목록에 «공통 권한»·«사용자 권한» 탭을 두었다.

## 테스트

1. 시스템 목록관리에서 공통 시스템 상세를 열면 레이어 그룹 선택 패널이 2열로 보여야 한다.
2. 같은 상세에서 서비스 목록 선택 패널이 1열로 보여야 한다.
3. 레이어 그룹·서비스 검색·다중 선택이 기존과 같이 동작해야 한다.
4. 프로젝트 구성 상단에 프로젝트 목록이 보여야 한다.
5. 다른 프로젝트를 고르면 해당 runtime 경로·시스템·기능·레이어 그룹이 바뀌어야 한다.
6. 다른 프로젝트에 저장하면 그 프로젝트 runtime 파일만 갱신되고, 기동 중인 서버와 다를 때 안내가 보여야 한다.
7. 현재 서버 프로젝트에 저장하면 재시작 없이 반영되어야 한다.
8. 프로젝트 구성 레이어 그룹 목록이 시스템 목록관리와 비슷하게 수십 개 보여야 한다.
9. 레이어 그룹 버튼이 «공통 시스템 목록과 동일»로 보여야 한다.
10. «공통 시스템 목록과 동일»을 누르면 선택 시스템 그룹 체크가 공통 목록과 같아져야 한다.
11. 레이어 그룹을 모두 해제한 뒤 저장하면 체크는 비어 있고 «공통 시스템 목록 사용 중» 안내가 보여야 한다.
12. runtime에 시스템만 있고 그룹이 비어 있어도 공통 목록이 데이터조회에 쓰여야 한다.
13. 권한관리 왼쪽 목록에 «공통 권한»·«사용자 권한» 탭이 보여야 한다.
14. «사용자 권한» 탭에는 신청 승인으로 자동 생성된 권한만 보여야 한다.
15. «공통 권한» 탭에서만 «권한 추가»가 보여야 한다.

## 목적 (병합)

## 요약 (병합)

사이드 목록 패널은 쓰기 권한 연동과 고정폭(리사이즈 끔) 옵션을 모두 유지했다. GCP 패널은 고정폭·권한 키를 함께 적용했다. QGIS 레이어 권한은 master UI(서비스 종류 표시 등)에 읽기 전용일 때 키·스위치·저장 비활성 가드를 유지했다. CCTV 패널에 잘못 붙어 있던 점사용료 권한 키는 CCTV 권한 키로 바로잡았다.
