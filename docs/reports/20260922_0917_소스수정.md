## 목적

시스템 상세에서 레이어 그룹·서비스 선택 패널 열 수를 보기 좋게 맞춘다. 프로젝트 구성에서 다른 프로젝트 runtime도 골라 편집할 수 있게 한다. 레이어 그룹 후보를 레이어 정의 전체에서 가져오도록 맞춘다.

## 요약

레이어 그룹 목록은 2열, 서비스 목록은 1열로 바꿨다. 프로젝트 구성 상단에 프로젝트 선택 목록을 두어 선택한 프로젝트의 runtime 설정을 조회·저장한다. 레이어 그룹 후보는 시스템 카탈로그만이 아니라 레이어 정의 그룹 전체를 쓴다.

## 테스트

1. 시스템 목록관리에서 공통 시스템 상세를 열면 레이어 그룹 선택 패널이 2열로 보여야 한다.
2. 같은 상세에서 서비스 목록 선택 패널이 1열로 보여야 한다.
3. 레이어 그룹·서비스 검색·다중 선택이 기존과 같이 동작해야 한다.
4. 프로젝트 구성 상단에 프로젝트 목록이 보여야 한다.
5. 다른 프로젝트를 고르면 해당 runtime 경로·시스템·기능·레이어 그룹이 바뀌어야 한다.
6. 다른 프로젝트에 저장하면 그 프로젝트 runtime 파일만 갱신되고, 기동 중인 서버와 다를 때 안내가 보여야 한다.
7. 현재 서버 프로젝트에 저장하면 재시작 없이 반영되어야 한다.
8. 프로젝트 구성 레이어 그룹 목록이 시스템 목록관리와 비슷하게 수십 개 보여야 한다.
9. 레이어 그룹 버튼이 «공통 시스템 목록과 동일»로 보여야 한다.
10. «공통 시스템 목록과 동일»을 누르면 선택 시스템 그룹 체크가 공통 목록과 같아져야 한다.
11. 레이어 그룹을 모두 해제한 뒤 저장하면 체크는 비어 있고 «공통 시스템 목록 사용 중» 안내가 보여야 한다.
12. runtime에 시스템만 있고 그룹이 비어 있어도 공통 목록이 데이터조회에 쓰여야 한다.
