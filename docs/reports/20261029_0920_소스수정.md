## 목적

하천행정 통합관리 시스템 부서업무에서 숨겨 두었던 «불법점용 관리카드»를 다시 보이게 하고, 관리카드를 PDF로 저장할 수 있게 하며, 상세 표 제목 칸 색을 회색으로 맞춘다.

## 요약

하천 시스템 부서업무 목록에서 빠져 있던 «불법점용 관리카드»를 원래 자리(보상편입용지 다음)에 다시 넣었다. 기능 화면·데이터는 그대로이며 메뉴 노출만 되돌렸다.
관리카드 상세에 «PDF 저장»을 추가해 인쇄 화면과 같은 모양의 카드를 PDF 한 쪽으로 내려받는다. 목록에는 «전체 PDF 저장»을 추가해 현재 목록(검색·정렬 반영)의 카드를 카드마다 한 쪽씩 하나의 PDF로 내려받는다.
불법점용 관리카드·접도구역 건축물 상세 표 제목 칸은 글씨 검정·배경 회색(#F5F5F5)으로 맞췄다.
PDF 저장은 브라우저 인쇄 창(대상: PDF로 저장)을 여는 방식으로 바꿨다.
레이어정의서·DBF를 반영해 최초확인·완료일자를 DB 년/월/일로 나누고, 완료 Y/N 체크를 화면에 넣었다. 화면 날짜 칸은 기존과 같고 저장 매핑만 분리한다.
관리카드 본문에서 `#내용#`으로 감싼 글은 화면·인쇄·PDF에서 빨간색으로 보이게 하고, 조치현황 합계는 적발만 검정·조치·미조치는 빨간색이다. 수정 화면 상단에 안내를 두고, 조치현황 칸은 숫자와 `#`만 입력받게 했다.
화면 속성 영문 컬럼명은 DBF·레이어정의서 기준으로 맞췄고, 일자는 화면에서 한 칸으로 다루며 SHP 수신 시 년·월·일로 나누도록 매핑해 두었다. 상세 표에는 완료 체크가 조회·수정 모두에서 보인다.
제방 GeoServer 스타일은 선만 두고, 이름·연장 라벨은 API 값을 브라우저에서 그대로 표시해 한글 깨짐·WMS 오류를 피했다. 사업계획(제방 레이어) ON일 때만 라벨이 나온다.

## 테스트

1. 하천행정 통합관리 시스템 사이드바에 «불법점용 관리카드»가 보여야 한다.
2. 메뉴를 누르면 불법점용 관리카드 목록 패널이 열려야 한다.
3. 목록에서 카드를 누르면 상세 패널이 열려야 한다.
4. 다른 부서업무 메뉴로 바꾸면 불법점용 관리카드 패널이 닫혀야 한다.
5. 관리카드 상세 «PDF 저장» 시 인쇄 화면과 같은 모양의 A4 한 쪽 PDF가 «불법 점용시설 관리카드_연번» 이름으로 내려받아져야 한다.
6. 위치도·현황사진·완료사진이 PDF에도 나와야 한다.
7. 목록 «전체 PDF 저장» 시 목록의 카드 수만큼 쪽이 있는 PDF 하나가 내려받아져야 한다.
8. 검색·정렬한 상태에서 전체 PDF 저장 시 화면 목록과 같은 카드·순서로 저장되어야 한다.
9. 목록이 비어 있으면 «전체 PDF 저장»이 비활성이어야 한다.
10. 불법점용 관리카드·접도구역 건축물 상세 표 제목 칸이 회색(#F0F0F0)으로 보여야 한다.
11. 기존 «인쇄»는 그대로 동작해야 한다.
12. 상세에서 완료 체크 시 «완료»가 표시되고 저장 후 다시 열어도 유지되어야 한다.
13. 최초확인·완료일자는 화면에서 날짜 한 칸으로 입력·조회되어야 한다.
14. PDF 저장·전체 PDF 저장 시 인쇄 창이 열리고 대상 «PDF로 저장»으로 내려받을 수 있어야 한다.
15. 수정 모드에서 상단과 제목 사이에 빨간 글씨 안내가 보여야 한다.
16. 행위자·위법내용 등에 `#중요#`를 넣고 저장하면 조회·인쇄·PDF에서 해당 구간만 빨간색이어야 한다.
17. 조치현황 합계는 화면·인쇄·PDF에서 항상 빨간색이어야 한다.
18. 조치현황 칸에 글자·기호를 넣으면 숫자와 `#`만 남아야 한다.
19. 조치현황에 `#3#`을 넣으면 조회·인쇄에서 빨간 숫자로 보이고 합계에 반영되어야 한다.
20. 상세·인쇄에서 완료는 날짜와 별도 칸이며, 완료 시 «완료» 글씨만 보여야 한다(조회·인쇄에 체크박스 없음).
21. 조치현황 적발 합계는 검정, 조치·미조치 합계는 빨간색이어야 한다.
22. 인쇄·PDF에서도 완료 체크와 합계 색 구분이 같아야 한다.
23. 제방 라벨 한글이 네모로 깨지지 않고, 횡단 라벨과 같은 글꼴로 보여야 한다.
24. 기본계획 진입(하천 선택) 시 보고서 제외 칩(하천구역·색인도·구조물도·종단·횡단·사업계획)이 켜진 상태여야 한다.
24. 색인도 상세에서 제방 활성화 시 선이 두꺼워지지 않고 흰·빨간 실선이 같이 깜빡여야 한다.
25. 지도 확대·축소·이동 시 제방 라벨이 선 따라 반복 생기지 않아야 한다.
26. 사업계획 on/off 시 색인도 상세목록은 제방으로 필터되지 않고 전체 항목이 유지되어야 한다.
27. 사업계획은 제방 레이어·라벨만 켜고 끄며, 깜빡임 없이 구조물도와 같이 동작해야 한다.
28. 구조물도 칩과 사업계획 칩은 서로 레이어 상태에 영향을 주지 않아야 한다.
