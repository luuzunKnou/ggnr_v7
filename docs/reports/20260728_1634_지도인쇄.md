## 목적

지도 «인쇄»를 이전 버전처럼 인쇄 전용 화면으로 열어, 주석·측정·도형 후 이미지 저장·인쇄할 수 있게 한다.

## 요약

인쇄 버튼 stub을 제거하고 인쇄 전용 전체 화면을 추가했다. 메인 지도의 위치·확대·배경·켜진 레이어를 이어받고, 색·위치·글자·거리·면적·고도·경사·도형·좌표·선택삭제·되돌리기·다시실행·초기화·레이어·배경·이미지 저장·인쇄를 제공한다. 이미지 저장은 html2canvas를 사용한다. 좌표 입력은 EPSG:5181(X Y) 기준으로, 좌표만 넣으면 자동으로 점을 찍고(여러 쌍이면 선으로 연결) 지도가 맞춰진다. 컨트롤 레이어(지적·건물·지목 등)는 그룹 일괄 켜기 대신 메인처럼 목록에서 개별 선택하며, 선택된 레이어명은 그룹 아래에 작게 표시한다.

## 테스트

1. 지도 «인쇄» 클릭 시 인쇄 전용 화면이 열려야 한다.
2. 메인에서 보던 위치·확대가 인쇄 지도에 반영되어야 한다.
3. 거리·면적·경사도·고도 측정이 인쇄 지도에서 동작해야 한다.
4. 점·선·직사각형·다각형·정사각형·원·위치·글자가 그려져야 한다.
5. 좌표 한 쌍을 넣으면 점이 찍히고 해당 위치로 이동해야 한다.
5-1. 좌표를 여러 쌍 넣으면 각 점이 찍히고 선으로 연결되며, 전체가 보이게 맞춰져야 한다.
5-2. 경위도(WGS84)만 넣으면 적용되지 않고 안내가 나와야 한다.
6. 선택 삭제·되돌리기·다시 실행·초기화가 동작해야 한다.
7. 레이어·배경을 바꾸면 인쇄 지도에 반영되어야 한다.
7-1. 인쇄에서 지적도 등을 누르면 왼쪽에 레이어 목록이 열리고, 체크한 이름만 그룹 아래에 보여야 한다.
7-2. 컨트롤 레이어 그룹을 한 번에 전부 켜는 체크는 없어야 한다.
8. 이미지 저장 시 PNG가 내려받아지고, 인쇄 시 도구 줄이 가려져야 한다.
9. 닫기 후 메인 지도 측정·패널이 깨지지 않아야 한다.
