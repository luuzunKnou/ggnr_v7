## 목적

방사선 대피소 목록·지도 선택 시 우측 확장 패널(속성보기)을 열고, «추가»로 주소 검색·좌표 연동 등록을 제공한다. Field 기준 동적 목록·헤더 정렬·검색 초기화·수용인원 천단위 표시를 적용한다.

## 요약

목록 패널 오른쪽에 상세·등록 확장 패널 2단 레이아웃을 추가했다. 목록 행·지도 심볼 클릭 시 속성보기, «추가» 시 등록 폼(주소 검색·지도 찍기)으로 신규 등록한다. 검색창 X로 초기화·재조회, 컬럼 헤더 3단 정렬, 수용인원 천단위는 목록·상세·입력 blur 시 동일하게 적용했다.

## 테스트

1. 목록 행 클릭 시 목록 오른쪽에 확장 패널이 열리고 «속성보기»에 시설명·주소·수용인원·비고가 표시되어야 한다.
2. 지도에서 방사선 대피소 심볼 클릭 시 동일 상세가 열려야 한다.
3. «추가» 클릭 시 등록 폼이 열리고, 주소 검색 선택 후 등록하면 좌표·목록·지도에 반영되어야 한다.
4. 수용인원 1000 이상은 목록·상세 모두 천단위 쉼표로 보여야 한다.
5. 검색어 입력 후 X 클릭 시 입력이 비워지고 필터 없이 전체 목록이 다시 조회되어야 한다.
6. 목록 헤더(시설명·주소·수용인원·비고) 클릭 시 정렬 아이콘이 바뀌고 행 순서가 반영되어야 한다.
7. 패널 닫기·다른 메뉴 전환 시 확장 패널·하이라이트가 남지 않아야 한다.
8. TypeScript 검사(`npx tsc --noEmit`) 오류가 없어야 한다.
