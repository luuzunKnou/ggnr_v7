# 결과보고서

2026-10-27 | 213am | —

## 목적

상수도 관로·시설 통계 화면의 검색·초기화·다운로드 버튼 크기를 하수관로 관종 현황과 동일하게 맞춘다. 하수 관망조회의 레이어 범례는 SLD·CSS로 정의된 실제 범례 이미지를 쓴다. 상수관로·상수도시설 현황 필터를 하수 관종 현황과 같은 체크박스 드롭다운으로 바꾼다. 레이어 스타일 모달에서 SLD 심볼도 CSS와 같이 SYMBOL로 읽고 저장되게 한다. 관망조회 선 범례는 대각선 대신 가로선으로 표시한다. GeoServer Web에서 고친 스타일이 로컬 sld/css와 앱 조회에 맞게 동기화되게 한다. 상수관로 통판 스타일은 용도 코드별로 색을 나누고 정의 외 관로는 기타 색으로 모두 표시한다. 상수관로·상수도시설 현황 본문 행 높이를 하수관로 관종·관경 현황과 같게 맞춘다.

## 요약

자체 버튼 스타일(37px)을 공통 목록 버튼(34px)으로 바꿔 하수 관종 현황과 크기를 통일했다. 하수 관망조회 범례는 CSS/SLD 파싱 SVG 대신 GeoServer 범례 그래픽 API 이미지를 표시하도록 바꿨다. 상수관로·상수도시설 현황 필터는 단일 선택에서 다중 체크 드롭다운으로 바꾸고, 서버도 다중 조건을 받도록 맞췄다. SLD 전용 점 스타일은 외부 심볼 주소를 읽어 SYMBOL로 열고, 저장 시 심볼·크기를 SLD에 반영한다. 관망조회 선 레이어 범례는 스타일 선색으로 가로선을 그린다. 스타일 조회는 GeoServer REST를 우선하고 로컬 파일에 pull하며, SLD 저장 시 낡은 CSS sidecar로 덮어쓰지 않는다. 상수관로 통판 SLD는 용도별 색 분리와 기타 규칙으로 전 관로를 그린다. 상수 현황 표 본문은 고정 높이 28px와 좁은 여백 대신 하수 현황과 같은 6px 여백으로 행 높이를 맞췄다.

## 테스트

1. 상수도 관로 통계에서 검색·초기화·다운로드 버튼이 하수 관종 현황과 같은 크기로 보여야 한다.
2. 상수도 시설 통계에서도 동일하게 보여야 한다.
3. 검색·초기화·다운로드 클릭이 기존과 같이 동작해야 한다.
4. 하수 관망조회에서 레이어 버튼 옆 범례가 GeoServer 스타일과 같아야 한다.
5. 우수관·오수관·맨홀 등 서로 다른 레이어 심볼이 구분되어 보여야 한다.
6. 범례 이미지 로드 실패 시에도 레이어 토글·조회는 동작해야 한다.
7. 조회 결과 그룹 헤더의 범례도 동일하게 보여야 한다.
8. 상수관로 현황에서 관로·읍면동·매설연도·관용도 필터가 체크박스 드롭다운으로 보여야 한다.
9. 여러 읍면동·연도를 선택 후 검색하면 해당 조건만 집계되어야 한다.
10. 전체 선택·초기화 후 검색하면 이전과 같이 전체 집계가 나와야 한다.
11. 매설년도별 모드에서는 매설연도 필터가, 관용도별 모드에서는 관용도 필터가 숨겨져야 한다.
12. 상수도시설 현황 년도 필터가 체크 드롭다운으로 보여야 한다.
13. 여러 년도를 선택 후 검색하면 해당 년도만 집계되어야 한다.
14. 상수관로·상수도시설 엑셀이 하수 관종 현황과 같은 색·제목·틀고정으로 내려받아야 한다.
15. 배수설비 등 SLD 심볼 레이어 스타일 모달을 열면 SYMBOL과 심볼 파일이 보여야 한다.
16. SYMBOL에서 다른 심볼을 고른 뒤 저장하고 다시 열면 선택한 심볼이 유지되어야 한다.
17. SYMBOL을 POINT로 바꿔 저장하면 원형 점으로 열리고 심볼 파일이 없어야 한다.
18. CSS 형식 점·심볼 레이어 스타일 열기·저장은 이전과 같아야 한다.
19. 관망조회에서 우수관·오수관 등 선 레이어 범례가 가로선으로 보여야 한다.
20. 선 범례 색이 해당 레이어 스타일 선색과 같아야 한다.
21. 맨홀 등 점·면 레이어 범례는 이전과 같이 스타일 이미지로 보여야 한다.
22. GeoServer Web에서 스타일을 바꾼 뒤 레이어 설정 모달을 열면 Web과 같은 내용이 보여야 한다.
23. 모달을 연 뒤 로컬 스타일 파일이 GeoServer 내용과 같아야 한다.
24. 앱에서 SLD 스타일을 저장해도 Web에서 고친 규칙이 CSS 재변환으로 사라지지 않아야 한다.
25. 상수관로 통판에서 급수·배수·송수·광역·도수·취수·폐관이 서로 다른 색으로 보여야 한다.
26. 위 용도가 아닌 관로도 기타 색으로 누락 없이 보여야 한다.
27. 폐관은 점선으로 보여야 한다.
28. 확대 시 화살표·라벨이 관로 색과 맞게 보여야 한다.
29. Title이 없거나 스타일명과 다른 SLD(맨홀 등)도 모달에서 심볼·속성 편집이 가능해야 한다.
30. 고정 색만 있는 선 스타일도 모달에 선색이 보여야 한다.
31. 정말 파싱 불가인 레이어만 관리자 화면 안내가 나와야 한다.
32. 상수도 행정 사이드바에 민원관리·메모관리가 보여야 한다.
33. 하수도 행정 사이드바에 민원관리·메모관리가 보여야 한다.
34. 상수·급수·하수·준설 전용 민원·메모 메뉴는 사이드바에 없어야 한다.
35. 상수관로시설·상수도시설 현황 본문 행 높이가 하수관로 관종·관경 현황과 같아야 한다.
36. 본문 글자 크기·색은 이전과 같아야 한다.
37. 민원관리에서 «기존UI»/«분류UI» 임시 버튼으로 화면이 바뀌어야 한다.
38. 분류UI에서 상수·하수·급수·준설을 누르면 해당 민원만 나와야 한다.
39. 메모관리에서도 동일하게 기존·분류 UI를 바꿀 수 있어야 한다.
