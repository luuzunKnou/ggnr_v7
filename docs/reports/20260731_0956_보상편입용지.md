2026-07-31 | gyujin | 보상편입용지 UI 목업 요청

## 목적

지도 사이드바 하천 그룹에 이름만 등록되어 있던 «보상편입용지» 메뉴에 실제 화면을 만들어, 건명 목록·상세 속성·편입 필지 목록을 확인할 수 있게 한다. 이번 단계는 화면(UI) 목업으로, 실제 서버 저장 없이 화면 안 예시 데이터로 등록·수정·삭제 동작을 확인한다.

## 요약

건명 목록 패널과 상세 패널(조직·정책·단위·세부·편성목·통계목 + 필지 목록 표)을 새로 만들고, 지도 사이드바 «보상편입용지» 메뉴로 열리도록 `map-layout-client.tsx`에 연동했다. 필지 목록은 상세 패널 안 표로 바로 보여주고(모달 아님), 읍면·리동은 «읍면동» 한 열로 합쳐 표시했다. 필지 행을 클릭하면 지도가 해당 위치로 이동하며 노란색으로 강조 표시된다. 건·필지 모두 화면 안에서만 추가·수정·삭제되며 서버에는 저장되지 않는다.

## 테스트

1. 지도 사이드바 하천 그룹에서 «보상편입용지»를 선택하면 건명 목록 패널이 열려야 한다.
2. 건명 검색어를 입력하면 일치하는 건만 남아야 한다.
3. «추가» 버튼을 누르면 새 건이 목록 맨 위에 생기고 상세 패널이 자동으로 열려야 한다.
4. 상세 패널에서 «수정» 후 조직·정책·단위·세부·편성목·통계목 값을 바꾸고 «저장»하면 값이 반영되고, «취소»하면 원래 값으로 돌아와야 한다.
5. «삭제»를 누르면 확인 후 건이 목록·상세에서 함께 사라져야 한다.
6. 필지 목록 표에 읍면동·지번(당초)·지번(편입)·당초면적·편입면적·지목·새롬감정·대호감정·적용단가·보상금액·토지소유자 주소·토지소유자 성명·비고가 열로 나와야 하며, 열이 많으면 좌우 스크롤로 볼 수 있어야 한다.
7. 필지 «추가» 팝업에서 적용단가·편입면적을 입력하면 보상금액이 자동 계산되어야 한다.
8. 필지 행을 클릭하면 지도가 해당 위치로 이동하고 노란색으로 표시되어야 한다.
9. 필지를 «수정»·«삭제»하면 표에 바로 반영되어야 한다.
10. 상세 패널을 닫으면 지도의 필지 강조 표시도 함께 사라져야 한다.
11. 건·필지 추가·수정·삭제는 새로고침하면 초기 목업 데이터로 돌아가야 한다 (서버 미저장, 이번 단계는 UI 목업).
12. 하천기본계획·점용대장·공사대장·점용사용료 등 다른 하천 기능 패널을 열고 닫아도 위치·너비가 정상이어야 한다 (좌표 체인 변경에 대한 회귀 확인).
