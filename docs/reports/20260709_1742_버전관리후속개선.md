2026-07-09 | 200BingSu | —

## 목적

버전관리·소스코드 업로드 이력에 실행 PC IP가 올바르게 남도록 하고, 이력 플로팅 패널 사용성을 개선하며, 설치파일·최신소스 작업 중 취소·메뉴 전환 시 패널 정리가 되게 한다.

## 요약

이력에 `localhost:3001` 등 서버 접속 주소가 남던 문제를 수정했다. HTTP Host 헤더를 클라이언트 주소로 쓰지 않고, 브라우저에서 PC LAN IP를 탐색해 요청과 함께 보낸 뒤 서버가 루프백이 아닌 IP를 우선 저장한다. 이력 목록은 IP를 먼저 표시한다. 최신 소스 적용 이력에 GNMS 서버 URL을 잘못 넣던 부분을 제거했다.

이력 UI는 배경 딤 없는 드래그 플로팅 패널을 사용한다(기존 커밋). 소스코드 업로드·버전관리 메뉴를 벗어나 컴포넌트가 언마운트되면 이력 패널이 자동으로 닫힌다.

설치파일 다운로드·최신 소스 적용에 «취소» 버튼과 중단 처리를 두었고, 설치 ZIP 빌드·소스 업로드 요청 시에도 클라이언트 IP를 함께 전달한다.

## 테스트

1. 소스코드 업로드·버전관리에서 «이력»을 연 뒤 다른 dev 메뉴로 이동하면 플로팅 이력 패널이 닫혀야 한다.
2. 설치파일 다운로드 완료 후 이력에 PC IP(예: 192.168.x.x)가 표시되어야 하며 `localhost:3001`만 남지 않아야 한다.
3. 최신 소스 적용 완료 후 이력 IP가 GNMS 서버 URL이 아니어야 한다.
4. 소스코드 업로드 완료·실패 이력에도 동일하게 IP가 기록되어야 한다.
5. 설치파일·최신소스 작업 중 «취소» 시 진행이 멈추고 취소 안내가 로그에 남아야 한다.
6. 이력 플로팅 패널은 배경을 어둡게 하지 않고 드래그로 이동할 수 있어야 한다.
7. 버전관리 «설치파일 다운로드»는 서버 정보·스캔·ZIP·다운로드 단계와 스트림 저장이 정상 동작해야 한다.
8. 메모·민원 등 다른 지도·dev 메뉴 동작에 회귀가 없어야 한다.
