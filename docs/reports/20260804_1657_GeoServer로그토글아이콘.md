# 결과보고서

2026-08-04 | dev.strcat | —

## 목적

슈퍼관리자·개발자 권한 사용자에게 지도 상단에서 GeoServer 로그를 바로 켜고 끌 수 있는 버튼을 둔다.

## 요약

시스템 선택 왼쪽에 전체 레이어 끄기와 같은 형태의 로그 토글(아이콘·라벨·스위치)을 추가했다. 슈퍼계정(`su`)이거나 개발자 모드 콘솔 권한이 있을 때만 보이며, 켜면 기존처럼 지도 하단에 GeoServer·콘솔 로그가 표시된다. 사이드바 내 정보 아래 5회 클릭 영역은 제거했다.

## 파일수정

수정 | src/lib/consoleMenuAccess/client.ts
 `hasAnyDevConsoleAccess` — 개발자 모드 콘솔 권한 유무 판별

수정 | src/app/(pages)/map/_mapComponents/map-search-bar.tsx
 GeoServer 로그 토글 — 시스템 선택 왼쪽. 아이콘·«로그»·스위치형 on/off

수정 | src/app/(pages)/map/_mapComponents/map-sidebar.tsx
 디버그 5회 클릭 영역 — 제거 (상단 토글로 대체)

## 테스트

1. 슈퍼관리자로 로그인하면 시스템 선택 왼쪽에 로그 아이콘이 보여야 한다.
2. 개발자 모드 콘솔 권한이 있는 계정도 아이콘이 보여야 한다.
3. 일반 계정에는 아이콘이 보이지 않아야 한다.
4. 아이콘을 누르면 지도 하단에 GeoServer 로그가 나타나고, 다시 누르면 사라져야 한다.
5. 사이드바 내 정보 아래에 예전 5회 클릭 영역이 없어야 한다.
6. 시스템 선택·주소검색·전체 레이어 끄기는 이전과 같아야 한다.
