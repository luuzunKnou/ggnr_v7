# 결과보고서

2026-11-09 | JungWooojin | 안동 건물번호판 엑셀 적재·레이어 발행

## 목적

건물번호판 보수 요청 엑셀을 읍면동·도로명·본번·부번으로 주소를 찾아 좌표를 붙인 뒤, 안동 DB에 새 테이블로 넣고 데이터조회용 «건물번호판» 레이어까지 발행한다. 잘못되면 되돌릴 수 있게 한다.

## 요약

2025·2026 시트에서 도로명이 있는 행만 넣었다(476건, 좌표 443건·미매칭 33건). 빈 번호 행·구간 제목은 제외했다. 도로명·본번·부번으로 건물·건물군 좌표를 붙였고, 항목 설정 «건물번호판»과 GeoServer 발행까지 했다. 롤백은 `--rollback`.

## 파일수정

## 테이블 수정

추가 | layer.building_number_plate
 `building_number_plate` — 건물번호판 보수 요청 적재용 점 레이어. 좌표는 도로명주소 건물·건물군에서 조회

## 테스트

1. 안동 지도 데이터조회에 «건물번호판»이 보여야 한다.
2. 목록에 연도·도로명·본번·부번·진행상황이 보여야 한다.
3. 좌표가 있는 행을 누르면 지도에 점이 잡혀야 한다.
4. 좌표가 없는 행도 목록에는 남아 있어야 한다.
5. `npx tsx scripts/import-building-number-plate-xlsx.ts ggnr_ad dev --rollback` 실행 후 테이블과 레이어가 사라져야 한다.
