# 결과보고서

2026-10-14 | dev.strcat | 하천기본계획 드론영상(하천 정사영상) 연도별 표시

## 목적

하천 정사영상을 배경지도와 분리해, 하천기본계획 부서업무에서만 탭(지방하천·소하천)별 드론영상과 연도를 골라 지도에 깔아 보도록 한다.

## 요약

타일 폴더 이름이 «지방하천·소하천 구분_연도_좌표계» 형식인 영상을 하천 영상으로 인식한다. 배경지도 목록은 기존대로 항공영상 폴더만 보여 주므로 하천 영상은 배경지도에 나타나지 않는다.
하천기본계획을 열면 주소검색 아래에 «지방하천 드론영상»(소하천 탭이면 «소하천 드론영상») 체크와 연도 선택이 나온다. 현재 탭 종류의 영상만 배경지도 바로 위(모든 데이터 레이어 아래)에 깔리며, 탭을 바꾸면 체크가 해제된다.
변환된 타일은 JPEG라 영상 밖이 검게 채워져 있어, 불러올 때 검정 영역을 투명 처리해 배경지도가 보이게 했다. 하천기본계획을 닫으면 영상도 함께 사라진다.
중간에 시도한 «최상단 표시»·«기본계획 면만 영상 아래로 분리» 방식은 요청 변경으로 모두 되돌려 공용 지도 파일 변경은 남기지 않았다.
(추가) 하천기본계획 드론영상 체크·연도 선택을 지도 위 떠 있는 위치에서 목록 패널 «하천명 통합검색» 바로 아래로 옮겼다. 상세 패널 버튼 줄에 «하천구역»을 색인도 왼쪽에 추가해, 지도에 노란 면으로 보이는 기본계획도(현재 탭·선택 하천) 레이어를 버튼을 누를 때마다 «켜기 → 선만 → 끄기» 순으로 바꿀 수 있게 했다. «선만»은 면 없이 흰 외곽선만 그려 다른 레이어와 겹쳐 보기 쉽게 하며, 탭 전환·상세 닫힘 시 기본 스타일로 돌아간다. 이를 위해 지도에 레이어별 스타일 대체 설정을 추가했고(기본은 없음, 다른 화면 영향 없음), 지도 서버에 흰 선 전용 스타일을 등록했다. 영향 받는 기능: 지도 서비스 레이어 표시 전체(대체 설정이 없으면 기존과 동일), 지도 인쇄·도형편집기는 변경 없음.
(추가) 지도 우측 «지적도» 목록에 시군구 경계를 추가하고 «지적 / 시군구 / 읍면동 / 리» 순으로 정렬했다. 시군구도 데이터가 있을 때만 목록에 나온다. 다른 기능(사유지분석·점용대장·하천점용)이 지적도를 켤 때는 지적만 지정하므로 시군구가 자동으로 켜지지 않는다. 영향 받는 기능: 지적도 목록, 지도 인쇄 지적도 목록, 3D 지적도.
(추가) 시군구 스타일을 기본 연두색 면 채움에서 읍면동과 같은 형식(면 투명·경계선·가운데 시군구명 라벨)으로 바꿨다. 읍면동(초록)·리(파랑)와 구분되도록 보라색, 선 3px, 글자 20으로 했으며 실행 중인 지도 서버에도 반영했다.

## 테스트

1. 배경지도 선택 목록에 하천 영상 폴더가 나타나지 않아야 한다.
2. 하천기본계획 지방하천 탭에서 주소검색 아래에 «지방하천 드론영상»과 연도 선택이 보여야 한다.
3. 소하천 탭으로 바꾸면 문구가 «소하천 드론영상»으로 바뀌어야 한다.
4. 지방하천 탭에서 체크하면 지방하천 영상만, 소하천 탭에서는 소하천 영상만 표시되어야 한다.
5. 탭을 바꾸면 체크가 해제되고 영상이 사라지며, 연도 목록은 해당 종류 영상 연도로 바뀌어야 한다.
6. 드론영상은 배경지도 바로 위에 깔리고 기본계획 면·구조물·종횡단·지적 등 모든 레이어가 영상 위에 그려져야 한다.
7. 영상 바깥 영역이 검게 보이지 않고 배경지도가 그대로 보여야 한다.
8. 배경지도를 바꿔도 드론영상이 배경지도 위에 그대로 남아 있어야 한다.
9. 체크를 끄면 영상이 사라지고 연도 선택이 비활성화되어야 한다.
10. 하천기본계획을 닫으면 컨트롤과 영상이 모두 사라져야 한다.
11. 다른 부서업무 메뉴에서는 드론영상 컨트롤이 나오지 않아야 한다.
12. 지도 우측 «지적도» 버튼 목록이 «지적 / 시군구 / 읍면동 / 리» 순으로 나와야 한다.
13. «시군구»를 선택하면 낮은 줌에서 시군구 경계가 표시되어야 한다.
14. 사유지분석·점용대장을 열 때 지적만 켜지고 시군구는 켜지지 않아야 한다.
15. 지도 인쇄의 지적도 목록에도 시군구가 같은 순서로 나와야 한다.
16. 시군구는 면 채움 없이 보라색 경계선과 가운데 시군구명만 보여야 한다.
17. 시군구·읍면동·리를 함께 켰을 때 색으로 서로 구분되어야 한다.
18. 하천기본계획 목록의 «하천명 통합검색» 바로 아래에 드론영상 체크·연도 선택이 보여야 하고, 지도 위에는 나오지 않아야 한다.
19. 상세 버튼 줄에 «보고서 / 하천구역 / 색인도 / 구조물도 / 종단면도 / 횡단면도»가 한 줄로 보여야 한다.
20. 켜진 상태에서 «하천구역»을 한 번 누르면 노란 면이 사라지고 흰 외곽선만 남아야 한다.
21. 한 번 더 누르면 면과 선이 모두 사라져야 한다.
22. 다시 누르면 원래 노란 면으로 돌아와야 한다.
23. 버튼 모양이 켜기(채움)·선만(점선)·끄기(회색)로 구분되어야 한다.
24. 소하천 탭에서도 같은 방식으로 동작해야 하고, 탭을 바꾸면 «선만»이 해제되어야 한다.
25. 하천기본계획을 닫은 뒤 데이터조회 등에서 기본계획도를 켜면 원래 노란 면으로 보여야 한다.
26. 구조물도·하천제방이 하천구역 노란 면 위에 그려져야 한다.
27. 하천제방이 흰 테두리의 밝은 파란색 선으로 영상·하천구역 위에서 뚜렷하게 보여야 한다.
28. 구조물도 원(파랑·노랑·빨강·초록)과 흰 테두리가 이전보다 진하게 보여야 한다.
