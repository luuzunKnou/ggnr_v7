## 목적

레이어 필드 정의에 같은 이름이 여러 번 있어도 목록·상세 React key 경고가 나지 않도록, 필드 로드·선택 단계에서 중복을 한 곳에서 없앤다. 설비관리 상세 «이력 카드» 탭을 «데이터 이력관리»와 같이 패널 너비를 꽉 채우도록 맞춘다.

## 요약

경고의 직접 원인은 `sup_are` 같은 필드명이 정의 JSON에 중복되고, UI가 그 이름을 key로 쓴 것이었다. 필드마다 key만 바꾸면 다른 테이블에서도 같은 경고가 이어지므로, 필드 API·표시 캐시·목록/상세 필드 선택에서 동일 이름을 병합 제거하도록 바꿨다. 표시 플래그는 OR로 합쳐 목록·상세 노출이 빠지지 않게 했다. 이력 카드 패널은 바깥 여백·테이블 외곽 테두리를 제거하고, 검색줄만 살짝 들여 테이블·건수 영역이 패널 너비를 채우게 했다.

## 테스트

1. 정수장(또는 정수시설) 상세를 열어도 콘솔에 동일 key 경고가 나오지 않아야 한다.
2. 시설관리 목록 헤더에 같은 컬럼명이 두 번 나오지 않아야 한다.
3. 설비관리 «시설정보보기» 플로팅 상세에도 동일 key 경고가 없어야 한다.
4. 다른 시설 탭으로 바꿔도 key 이름만 바뀐 동일 경고가 반복되지 않아야 한다.
5. `sup_are`가 있던 테이블에서 목록·상세에 해당 항목이 한 번만 보여야 한다.
6. 설비관리 상세 «이력 카드» 탭에서 테이블·건수 영역이 «데이터 이력관리»처럼 패널 너비를 채워야 한다.
7. 이력 카드 패널 테이블에 외곽 테두리가 없어야 한다.
8. 재난시설 등 접기형 이력 섹션에서는 테이블 테두리가 그대로여야 한다.
