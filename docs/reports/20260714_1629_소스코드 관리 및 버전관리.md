## 목적

개발자가 <<소스코드>> 내 '설치파일 다운로드'를 통해 설치 파일을 받고 해당 파일을 대상 서버에 설치할 수 있고, '소스코드 업로드'를 통해 현재 코드를 GNMS에 업로드할 수 있다.
사용자가 <<버전관리>>에서 폐쇄망/개방망 여부와 재시작 방식(프로제스 종료/Node 런처/재시작 안함)을 선택해 '최신 소스 전체 적용'을 통해 자동으로 소스를 최신화할 수 있도록 구현한다.
위 과정은 이력 목록에 남기고 추후 검색, 조회할 수 있도록 구현한다.

## 요약

재시작이 있으면 적용 직후가 아니라 앱이 다시 뜬 뒤 성공 이력을 남긴다. 신호 파일에 적용 PC IP·방식·기동 명령을 넣고, 메시지에 성공·IP·mode·command를 담는다. **프로세스 종료·Node 런처 모두** 서버가 켜진 상태에서 사전 npm install(개방망)·사전 빌드를 한다. 앱 종료 단계는 응답 전에 완료로 표시하고, 재시작으로 연결이 끊기면 실패가 아니라 안내로 처리한다. 이력 펼침은 화살표 아이콘을 쓴다. 최신 소스 적용은 ZIP에 있는 파일만 덮어쓰며, `ggnr_start.bat`은 **소스코드 업로드·설치파일 다운로드 ZIP 모두에서 제외**한다.

## 테스트

1. «소스코드 업로더»에서 «설치파일 다운로드»로 폐쇄망 또는 개방망을 고른 뒤 설치 파일을 받으면, 로컬에 ZIP이 받아지고 단계·이력이 남아야 한다.
2. 설치 ZIP으로 운영·시연 서버를 세팅한 뒤, «이력»에서 설치파일 다운로드 성공·날짜·IP를 조회할 수 있어야 한다.
3. «소스코드 업로드» 기본값은 «설치»·node_modules 미포함이어야 하고, «업데이트 (준비 중)»는 비활성이어야 한다.
4. «현재 코드 자동 업로드» 시 GNMS 연결 확인 → 스캔 → 압축·청크 전송 → 원격 병합/압축 해제 순으로 단계가 진행되어야 한다.
5. 스키마와 DB가 다르면 확인 창이 뜨고, 중단하면 업로드가 이어지지 않아야 한다.
6. node_modules 미포함이면 스캔·ZIP에서 빠지고 원격 «npm install» 단계가 있어야 하며, 포함이면 npm install은 건너뛰어야 한다.
7. 업로드가 끝나면 GNMS에 최신 소스가 등록되고, «이력»에 소스코드 업로드 성공이 남아야 한다.
8. 업로드·설치 ZIP 모두 ggnr_start.bat이 패키지에 포함되지 않아야 한다.
9. «버전관리» «최신 소스 적용»에서 폐쇄망/개방망과 재시작 방식(프로세스 종료(nssm)·Node 런처·재시작 안 함)을 고른 뒤 «최신 소스 전체 적용»하면, GNMS 조회·ZIP 중계·운영 반영이 진행되고 PC에 ZIP이 따로 저장되지 않아야 한다.
10. 「재시작 안 함」이면 적용 직후 이력에 성공·IP·mode=none이 남고, 「프로세스 종료(nssm)」·「Node 런처」이면 적용 직후엔 없고 재기동 후 성공 이력( mode·command·IP)이 남아야 한다.
11. 재시작이 있는 적용에서는 「사전 빌드」가 보이고(개방망이면 「npm install (개방망·사전)」도), «앱 종료(nssm 재기동)» 또는 «Next 종료 (런처)»가 완료로 표시되어야 한다.
12. 재시작으로 연결이 끊겨도 빨간 실패가 아니라 「재시작으로 연결이 끊어졌습니다」류 안내여야 한다.
13. «이력»에서 접힌 행은 날짜·성공/실패·IP(소스코드 쪽은 기능명 포함)만 보이고, 클릭하면 상세가 펼쳐지며 화살표는 접힘 오른쪽·펼침 아래여야 한다.
14. 적용 보류 없이 처음 기동만 한 경우 최신 소스 적용 성공 이력이 새로 생기지 않아야 하고, ZIP에 ggnr_start.bat이 없으면 적용 후에도 운영 서버 bat이 그대로여야 한다.

## 소스코드 관리 제외 파일

GNMS 「소스코드 업로드」·「설치파일 다운로드」 공통 패키징 기준이다. (`ggnr_start.bat`도 둘 다 제외.)

### 공통 제외 (폴더·경로)

1. `.cursor/` — 편집기·Agent 작업용 설정. 운영에 필요 없음
2. `.vscode/` — VS Code 개인/팀 설정. 운영에 필요 없음
3. `.next/` — 빌드 산출물. 받는 쪽에서 다시 빌드하므로 올리지 않음
4. `.git/` — Git 저장소 메타. 배포 패키지에 불필요
5. `.yarn/` — Yarn 캐시. 용량만 키움
6. `coverage/` — 테스트 커버리지 결과. 운영 불필요
7. `out/` — 내보내기·빌드 산출 폴더. 운영 불필요
8. `build/` — 빌드 산출 폴더. 운영 불필요
9. `.cad-preview-work/` — CAD 미리보기 임시 작업. 운영 불필요
10. `python/env/` — Python 가상환경. 환경마다 다시 구성
11. `geoserver_modules/data_dir/logs/` — GeoServer 로그. 서버별 이력
12. `geoserver_modules/data_dir/gwc/` — GeoServer 타일 캐시. 용량 크고 서버에서 재생성

### 항상 제외 (파일·패턴)

1. `next-env.d.ts` — Next가 로컬에서 다시 만드는 타입 보조 파일
2. `ggnr_start.bat` — 운영 서버 서비스 기동용. 프로젝트명·환경·node 경로가 서버마다 달라 업로드·설치 ZIP에 넣으면 덮어쓸 위험이 있어 제외. 현장에서는 `make_ggnr_starter.bat`으로 생성
3. `*.log` — 로그 파일. 서버·날짜별로 다름
4. 경로에 `/.cache/` 포함 — 도구 캐시
5. 경로에 `/.tmp/` 포함 — 임시 파일

### 개방망 패키지일 때 추가 제외

1. `node_modules/` — 받는 쪽에서 `npm install` 하므로 패키지에 넣지 않음 (폐쇄망은 포함)



### 모드 요약

1. **프로세스 종료(nssm)**
  적용 → GeoServer → **사전 빌드(서버 가동 중)** → `process.exit(0)` → nssm(또는 기동 런처)이 다시 올림 → 부팅 시 성공 이력.
2. **Node 런처**
  적용 → 신호만 기록 → `scripts/run.ts`가 Next 종료 → (개방망이면 install) → 빌드 → Next 재기동 → 부팅 시 성공 이력.
3. **재시작 안 함**
  소스만 반영, 적용 직후 성공 이력.

## NSSM 통해 서비스 등록

### 1. 서비스 실행용 bat 준비

- 서비스 등록용 `ggnr_start.bat` 파일 만들기 위한 `make_ggnr_starter.bat` 작성
루트 폴더 및 'where node', 사용자 입력 통해 ggnr_start.bat 생성

### 2. 서비스 등록 (nssm-install-ggnr.bat 실행)

**nssm 자동 등록 (권장)**  
프로젝트 root의 `nssm-install-ggnr.bat`을 **관리자 CMD**에서 실행한다.

- 프로젝트 경로 = bat이 있는 root (`ggnr_start.bat`과 동일 폴더)
- 앱 = `root\ggnr_start.bat`
- 로그 = `C:\logs\GGNR_V7_stdout.log` / `C:\logs\GGNR_V7_stderr.log`
- `nssm.exe`는 `C:\nssm\win64\nssm.exe` 우선 (없으면 PATH/`C:\nssm\nssm.exe`)

```bat
@echo off
chcp 65001 >nul
setlocal EnableExtensions

:: =============================================================================
:: nssm에 GGNR_V7 서비스 자동 등록 (관리자 권한으로 실행)
:: - 프로젝트 경로 = 이 bat이 있는 root (ggnr_start.bat 과 동일 폴더)
:: - 앱 = root\ggnr_start.bat
:: - 로그 = C:\logs\GGNR_V7_stdout.log / GGNR_V7_stderr.log
:: - C:\logs · C:\logs\backup 폴더만 생성 (자동 분류/이동 없음)
:: =============================================================================

set "SERVICE_NAME=GGNR_V7"
set "ROOT=%~dp0"
if "%ROOT:~-1%"=="\" set "ROOT=%ROOT:~0,-1%"
set "APP_BAT=%ROOT%\ggnr_start.bat"
set "LOG_DIR=C:\logs"
set "LOG_BACKUP=%LOG_DIR%\backup"
set "LOG_OUT=%LOG_DIR%\GGNR_V7_stdout.log"
set "LOG_ERR=%LOG_DIR%\GGNR_V7_stderr.log"

echo.
echo [nssm-install] root     = %ROOT%
echo [nssm-install] app      = %APP_BAT%
echo [nssm-install] log dir  = %LOG_DIR%
echo [nssm-install] backup   = %LOG_BACKUP%
echo.

:: 관리자 여부
net session >nul 2>&1
if errorlevel 1 (
  echo [오류] 관리자 권한 CMD에서 실행하세요.
  exit /b 1
)

if not exist "%APP_BAT%" (
  echo [오류] ggnr_start.bat 이 root에 없습니다: %APP_BAT%
  exit /b 1
)

:: nssm 찾기 (기본: C:\nssm\win64\nssm.exe)
set "NSSM="
if exist "C:\nssm\win64\nssm.exe" set "NSSM=C:\nssm\win64\nssm.exe"
if not defined NSSM if exist "C:\nssm\nssm.exe" set "NSSM=C:\nssm\nssm.exe"
if not defined NSSM (
  where nssm >nul 2>&1
  if not errorlevel 1 (
    for /f "delims=" %%I in ('where nssm') do (
      set "NSSM=%%I"
      goto :nssm_found
    )
  )
)

:nssm_found
if not defined NSSM (
  echo [오류] nssm.exe 를 찾지 못했습니다.
  echo   기대 경로: C:\nssm\win64\nssm.exe
  exit /b 1
)
echo [nssm-install] nssm     = %NSSM%

:: log / log\backup 폴더만 생성
call :EnsureLogFolders

:: 기존 서비스면 중지 후 제거(재등록)
"%NSSM%" status %SERVICE_NAME% >nul 2>&1
if not errorlevel 1 (
  echo [nssm-install] 기존 서비스 중지/제거...
  "%NSSM%" stop %SERVICE_NAME% confirm >nul 2>&1
  "%NSSM%" remove %SERVICE_NAME% confirm >nul 2>&1
)

echo [nssm-install] 서비스 등록...
"%NSSM%" install %SERVICE_NAME% "%APP_BAT%"
if errorlevel 1 (
  echo [오류] nssm install 실패
  exit /b 1
)

"%NSSM%" set %SERVICE_NAME% AppDirectory "%ROOT%"
"%NSSM%" set %SERVICE_NAME% AppExit Default Restart
"%NSSM%" set %SERVICE_NAME% AppRestartDelay 3000
"%NSSM%" set %SERVICE_NAME% AppStdout "%LOG_OUT%"
"%NSSM%" set %SERVICE_NAME% AppStderr "%LOG_ERR%"
:: 로그 회전(약 10MB, 5개 백업)
"%NSSM%" set %SERVICE_NAME% AppStdoutCreationDisposition 4
"%NSSM%" set %SERVICE_NAME% AppStderrCreationDisposition 4
"%NSSM%" set %SERVICE_NAME% AppRotateFiles 1
"%NSSM%" set %SERVICE_NAME% AppRotateBytes 10485760
"%NSSM%" set %SERVICE_NAME% AppRotateOnline 1

echo [nssm-install] 서비스 시작...
"%NSSM%" start %SERVICE_NAME%
if errorlevel 1 (
  echo [경고] 시작 실패. ggnr_start.bat 의 프로젝트명/환경·node PATH 를 확인하세요.
  echo         상태: "%NSSM%" status %SERVICE_NAME%
  exit /b 1
)

echo.
echo [완료] 서비스 %SERVICE_NAME% 등록·시작됨.
echo   stdout: %LOG_OUT%
echo   stderr: %LOG_ERR%
echo   backup 폴더: %LOG_BACKUP%
echo.
echo [실시간 로그 예]
echo   powershell -Command "[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; Get-Content '%LOG_OUT%' -Encoding UTF8 -Wait -Tail 10"
echo.
exit /b 0

:: ---------------------------------------------------------------------------
:EnsureLogFolders
if not exist "%LOG_DIR%" (
  mkdir "%LOG_DIR%"
  if errorlevel 1 (
    echo [오류] 로그 폴더 생성 실패: %LOG_DIR%
    exit /b 1
  )
  echo [nssm-install] 생성: %LOG_DIR%
)
if not exist "%LOG_BACKUP%" (
  mkdir "%LOG_BACKUP%"
  if errorlevel 1 (
    echo [오류] 백업 폴더 생성 실패: %LOG_BACKUP%
    exit /b 1
  )
  echo [nssm-install] 생성: %LOG_BACKUP%
)
exit /b 0
```
