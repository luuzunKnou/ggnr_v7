## 목적

**소스코드 관리 및 버전관리**
개발자가 <<소스코드 관리>> 내 '설치파일 다운로드'를 통해 설치 파일을 받고 해당 파일을 대상 서버에 설치할 수 있고, '소스코드 업로드'를 통해 현재 코드를 GNMS에 업로드할 수 있다.
업로드 전 '빌드 확인'으로 현재 코드의 npm run build 통과 여부를 임시 복사본에서 검사할 수 있다.
사용자가 <<최신 소스 적용>>에서 적용 버전 및 폐쇄망/개방망 여부와 재시작 방식(프로제스 종료/Node 런처/재시작 안함)을 선택해 '최신 소스 전체 적용'을 통해 자동으로 소스를 최신화할 수 있도록 구현한다.
위 과정은 이력 목록에 남기고 추후 검색, 조회할 수 있도록 구현한다.

**Window 서비스 등록 따른 로그 백업 스케줄러**
Window 서비스 등록시 로그를 보여주는 cmd 창을 바로 볼 수 없고, Window 서비스의 로그 경로를 설정해야 해당 로그에 대한 실시간 로그를 볼 수 있다. 
서비스 등록후 해당 로그에 대한 스케줄러 작업을 통해 날짜별 로그를 확인할 수 있도록 구현한다.

## 요약
**소스코드 관리 및 버전관리**
개발자는 «소스코드 관리»에서 설치파일 다운로드(폐쇄망/개방망)·현재 코드 업로드로 GNMS에 소스를 올리고, 
업로드 전 «빌드 확인»으로 현재 코드가 `npm run build`에 통과하는지 임시 복사본에서 검사할 수 있다(원본 소스·`.next` 무영향, demo env·버전 이력 없음).
사용자는 «최신 소스 적용»에서 적용 버전·폐쇄망/개방망·재시작 방식을 고른 뒤 전체 적용으로 운영에 반영한다. «최신소스 일부 적용(준비중)»은 비활성이다.
적용 버전은 GNMS 목록을 받아 기본은 최신이고, 과거 버전은 준비 후 받아 중계한다. 적용 시 GeoServer를 중지한 뒤 병합하고, 재시작이 없으면 GeoServer를 다시 기동한다. 재시작이 있으면 앱이 다시 뜬 뒤 성공 이력을 남기고, 개방망은 사전 패키지 설치·사전 빌드 후 종료한다. 재시작으로 연결이 끊기면 실패가 아니라 안내로 본다. ZIP에 있는 파일만 덮어쓰며 기동용 bat은 패키지에서 빼 둔다.
«이력»은 메뉴마다 다르다. «소스코드 관리»는 기능 구분을 고를 수 있고, «최신 소스 적용»은 해당 이력만 본다. 날짜·기능·성공여부·IP·선택·메모·본문을 통합 검색하고, 검색·초기화로 조회하며 펼쳐 상세를 본다.

**Window 서비스 등록 따른 로그 백업 스케줄러**
매일 0시에 현재 로그 파일을 'backup' 폴더에 복사한 뒤 '해당날짜_원본이름.log'로 이름을 변경하고 로그파일은 초기화시킨다.

**폐쇄망 VM 생성**
기존 개방망 VM을 복사한 뒤, DNS 서버 값을 지우고 네트워크 통신 차단한 뒤 내부 네트워크 통신만 허용하도록 설정한다.

## 테스트

**소스코드 관리 > 설치파일 다운로드**
1. «소스코드 관리» «설치파일 다운로드»에서 폐쇄망 또는 개방망을 선택.
2. 로컬에 ZIP이 받아지고 단계·이력이 남아야 한다.
2. «이력»에서 설치파일 다운로드 성공·날짜·IP·선택을 조회할 수 있어야 한다.

**소스코드 관리 > 소스코드 업로드**
1. «소스코드 업로드» 기본은 설치·node_modules 미포함이어야 하고, «업데이트 (준비 중)»는 비활성이어야 한다.
2. «현재 코드 자동 업로드» 시 연결 확인 → 스캔 → 압축·전송 → 원격 반영 순으로 단계가 진행되어야 한다.
3. 스키마와 DB가 다르면 확인이 뜨고, «중단»하면 업로드가 이어지지 않아야 하며, «계속 진행»하면 업로드가 이어져야 한다.
4. node_modules 미포함이면 ZIP에서 빠지고 원격 설치 단계가 있어야 하며, 포함이면 설치 단계를 건너뛰어야 한다.
5. 업로드가 끝나면 GNMS에 최신으로 등록되고 «이력»에 소스코드 업로드 성공이 남아야 한다.
6. 업로드·설치 ZIP에 기동용 bat이 포함되지 않아야 한다.

**소스코드 관리 > 빌드 확인**
1. «소스코드 업로드»에서 «빌드 확인»·«현재 코드 자동 업로드» 클릭 시 실시간 로그가 이전 내용 없이 새로 시작되어야 한다.
2. «빌드 확인»을 누르면 로그에 `GGNR_ENV=demo`·`NODE_ENV=production`·임시 복사 안내가 보여야 한다.
3. 임시 폴더에서 npm install·npm run build가 진행되고, stdout·stderr가 실시간 로그에 쌓여야 한다.
4. 빌드 성공·실패 요약이 로그 마지막에 나와야 한다.
5. 빌드 확인 중 «빌드 확인»·«현재 코드 자동 업로드»가 비활성이어야 하고, 버전 이력에는 기록되지 않아야 한다.
6. GGNR_PROJECT 없이(프로젝트 미기동) 실행하면 «기동 프로젝트 없음» 등 명확한 오류가 나와야 한다.

**최신 소스 적용**
1. «최신 소스 적용» 진입 시 적용 버전 목록이 보이고, 기본 선택은 «(최신)»이어야 한다.
2. «최신소스 일부 적용(준비중)»은 비활성이어야 한다.
3. 최신 버전·폐쇄망/개방망·재시작 방식을 고른 뒤 «최신 소스 전체 적용»하면 ZIP 중계·운영 반영이 되고 PC에 ZIP이 남지 않아야 한다.
4. 과거 버전을 고른 뒤 적용하면 준비 후 해당 버전 ZIP으로 반영되어야 한다.
5. 과거 버전·개방망 적용 시 준비 단계(ZIP 확인·설치 등)가 로그·안내에 나타나야 한다.
6. 「재시작 안 함」이면 적용 직후 이력에 성공이 남고, 「프로세스 종료」·「Node 런처」이면 재기동 후 성공 이력이 남아야 한다.
7. 성공 이력 본문에 선택한 버전(version=…)이 포함되어야 한다.
8. 「Node 런처」인데 운영에 프로젝트/타입이 없으면 적용이 막히고 안내가 나와야 한다.
9. 재시작이 있는 적용에서 사전 빌드(개방망이면 사전 설치도)와 앱 종료 단계가 완료로 보여야 한다.
10. 재시작으로 연결이 끊겨도 빨간 실패가 아니라 안내로 처리되고, 서버 대기 후 화면이 새로고침되어야 한다.
11. 적용 중 «취소»하면 사용자 취소 안내가 나오고, GNMS·중계 정리가 되어야 한다.

**이력 관리**
1. «이력»에서 «소스코드 관리»는 기능 구분을 고를 수 있고, «최신 소스 적용»은 기능 구분 없이 해당 이력만 보여야 한다.
2. «이력»에서 통합검색·검색·초기화로 날짜·기능·성공여부·IP·선택·메모·본문을 찾을 수 있어야 한다.
3. «이력» 접힌 행은 날짜·성공/실패·IP(소스코드 쪽은 기능명 포함)만 보이고, 펼치면 선택·메모·본문이 보여야 한다.
4. 적용 보류 없이 처음 기동만 한 경우 최신 소스 적용 성공 이력이 새로 생기지 않아야 한다.

## 소스코드 관리 제외 파일

GNMS 「소스코드 업로드」·「설치파일 다운로드」 공통 패키징 기준이다. (`ggnr_start.bat`도 둘 다 제외.)

### 공통 제외 (폴더·경로)

1. `.cursor/` — 편집기·Agent 작업용 설정. 운영에 필요 없음
2. `.vscode/` — VS Code 개인/팀 설정. 운영에 필요 없음
3. `.next/` — 빌드 산출물. 받는 쪽에서 다시 빌드하므로 올리지 않음
4. `.git/` — Git 저장소 메타. 배포 패키지에 불필요
5. `.yarn/` — Yarn 캐시. 용량만 키움
6. `coverage/` — 테스트 커버리지 결과. 운영 불필요
7. `out/` — 내보내기·빌드 산출 폴더. 운영 불필요
8. `build/` — 빌드 산출 폴더. 운영 불필요
9. `.cad-preview-work/` — CAD 미리보기 임시 작업. 운영 불필요
10. `python/env/` — Python 가상환경. 환경마다 다시 구성
11. `geoserver_modules/data_dir/logs/` — GeoServer 로그. 서버별 이력
12. `geoserver_modules/data_dir/gwc/` — GeoServer 타일 캐시. 용량 크고 서버에서 재생성



### 항상 제외 (파일·패턴)

1. `next-env.d.ts` — Next가 로컬에서 다시 만드는 타입 보조 파일
2. `ggnr_start.bat` — 운영 서버 서비스 기동용. 프로젝트명·환경·node 경로가 서버마다 달라 업로드·설치 ZIP에 넣으면 덮어쓸 위험이 있어 제외. 현장에서는 `make_ggnr_starter.bat`으로 생성
3. `*.log` — 로그 파일. 서버·날짜별로 다름
4. 경로에 `/.cache/` 포함 — 도구 캐시
5. 경로에 `/.tmp/` 포함 — 임시 파일



### 개방망 패키지일 때 추가 제외

1. `node_modules/` — 받는 쪽에서 `npm install` 하므로 패키지에 넣지 않음 (폐쇄망은 포함)



## 모드 요약

1. **프로세스 종료(nssm)**
  적용 → GeoServer → **사전 빌드(서버 가동 중)** → `process.exit(0)` → nssm(또는 기동 런처)이 다시 올림 → 부팅 시 성공 이력.
2. **Node 런처**
  적용 → 신호만 기록 → `scripts/run.ts`가 Next 종료 → (개방망이면 install) → 빌드 → Next 재기동 → 부팅 시 성공 이력.
3. **재시작 안 함**
  소스만 반영, 적용 직후 성공 이력.

## GNMS 수정

### 취소 동작 추가
- ggnr에서 취소했을 때, 현재 작업 중지 및 파일 정리 추가

### 동작 요약
**폐쇄망** (`includeNodeModules=1`)

1. 캐시 ZIP 있으면 → install/압축 생략 → `ready`
2. 없으면 → modules 없으면 설치 → ZIP 생성(모듈 포함) → `ready`
3. 다운로드 **성공 종료 후** GNMS가 디스크의 `node_modules`만 지우고 **ZIP은 유지**(다음 적용 가속)

**개방망** (`includeNodeModules=0`)

1. install 없음, 모듈 제외 임시 ZIP 생성 → `ready`
2. 다운로드 종료 후 임시 ZIP 삭제

## NSSM 통해 서비스 등록
NSSM 통해 현재 프로젝트(ggnr_v7)을 Window 서비스로 등록하기.

### 1. 서비스 실행용 bat 준비
- 서비스 등록용 `ggnr_start.bat` 파일 만들기 위한 `make_ggnr_starter.bat` 작성
루트 폴더 및 'where node', 사용자 입력 통해 ggnr_start.bat 생성


### 2. 서비스 등록 (nssm-install-ggnr.bat 실행)
**nssm 자동 등록 (권장)**  
프로젝트 root의 `nssm-install-ggnr.bat`을 **관리자 CMD**에서 실행한다.

- 프로젝트 경로 = bat이 있는 root (`ggnr_start.bat`과 동일 폴더)
- 앱 = `root\ggnr_start.bat`
- 로그 = `C:\logs\GGNR_V7_stdout.log` / `C:\logs\GGNR_V7_stderr.log`
- `nssm.exe`는 `C:\nssm\win64\nssm.exe` 우선 (없으면 PATH/`C:\nssm\nssm.exe`)

```bat
@echo off
chcp 65001 >nul
setlocal EnableExtensions

:: =============================================================================
:: nssm에 GGNR_V7 서비스 자동 등록 (관리자 권한으로 실행)
:: - 프로젝트 경로 = 이 bat이 있는 root (ggnr_start.bat 과 동일 폴더)
:: - 앱 = root\ggnr_start.bat
:: - 로그 = C:\logs\GGNR_V7_stdout.log / GGNR_V7_stderr.log
:: - C:\logs · C:\logs\backup 폴더만 생성 (자동 분류/이동 없음)
:: =============================================================================

set "SERVICE_NAME=GGNR_V7"
set "ROOT=%~dp0"
if "%ROOT:~-1%"=="\" set "ROOT=%ROOT:~0,-1%"
set "APP_BAT=%ROOT%\ggnr_start.bat"
set "LOG_DIR=C:\logs"
set "LOG_BACKUP=%LOG_DIR%\backup"
set "LOG_OUT=%LOG_DIR%\GGNR_V7_stdout.log"
set "LOG_ERR=%LOG_DIR%\GGNR_V7_stderr.log"

echo.
echo [nssm-install] root     = %ROOT%
echo [nssm-install] app      = %APP_BAT%
echo [nssm-install] log dir  = %LOG_DIR%
echo [nssm-install] backup   = %LOG_BACKUP%
echo.

:: 관리자 여부
net session >nul 2>&1
if errorlevel 1 (
  echo [오류] 관리자 권한 CMD에서 실행하세요.
  exit /b 1
)

if not exist "%APP_BAT%" (
  echo [오류] ggnr_start.bat 이 root에 없습니다: %APP_BAT%
  exit /b 1
)

:: nssm 찾기 (기본: C:\nssm\win64\nssm.exe)
set "NSSM="
if exist "C:\nssm\win64\nssm.exe" set "NSSM=C:\nssm\win64\nssm.exe"
if not defined NSSM if exist "C:\nssm\nssm.exe" set "NSSM=C:\nssm\nssm.exe"
if not defined NSSM (
  where nssm >nul 2>&1
  if not errorlevel 1 (
    for /f "delims=" %%I in ('where nssm') do (
      set "NSSM=%%I"
      goto :nssm_found
    )
  )
)

:nssm_found
if not defined NSSM (
  echo [오류] nssm.exe 를 찾지 못했습니다.
  echo   기대 경로: C:\nssm\win64\nssm.exe
  exit /b 1
)
echo [nssm-install] nssm     = %NSSM%

:: log / log\backup 폴더만 생성
call :EnsureLogFolders

:: 기존 서비스면 중지 후 제거(재등록)
"%NSSM%" status %SERVICE_NAME% >nul 2>&1
if not errorlevel 1 (
  echo [nssm-install] 기존 서비스 중지/제거...
  "%NSSM%" stop %SERVICE_NAME% confirm >nul 2>&1
  "%NSSM%" remove %SERVICE_NAME% confirm >nul 2>&1
)

echo [nssm-install] 서비스 등록...
"%NSSM%" install %SERVICE_NAME% "%APP_BAT%"
if errorlevel 1 (
  echo [오류] nssm install 실패
  exit /b 1
)

"%NSSM%" set %SERVICE_NAME% AppDirectory "%ROOT%"
"%NSSM%" set %SERVICE_NAME% AppExit Default Restart
"%NSSM%" set %SERVICE_NAME% AppRestartDelay 3000
"%NSSM%" set %SERVICE_NAME% AppStdout "%LOG_OUT%"
"%NSSM%" set %SERVICE_NAME% AppStderr "%LOG_ERR%"
:: 로그 회전(약 10MB, 5개 백업)
"%NSSM%" set %SERVICE_NAME% AppStdoutCreationDisposition 4
"%NSSM%" set %SERVICE_NAME% AppStderrCreationDisposition 4
"%NSSM%" set %SERVICE_NAME% AppRotateFiles 1
"%NSSM%" set %SERVICE_NAME% AppRotateBytes 10485760
"%NSSM%" set %SERVICE_NAME% AppRotateOnline 1

echo [nssm-install] 서비스 시작...
"%NSSM%" start %SERVICE_NAME%
if errorlevel 1 (
  echo [경고] 시작 실패. ggnr_start.bat 의 프로젝트명/환경·node PATH 를 확인하세요.
  echo         상태: "%NSSM%" status %SERVICE_NAME%
  exit /b 1
)

echo.
echo [완료] 서비스 %SERVICE_NAME% 등록·시작됨.
echo   stdout: %LOG_OUT%
echo   stderr: %LOG_ERR%
echo   backup 폴더: %LOG_BACKUP%
echo.
echo [실시간 로그 예]
echo   powershell -Command "[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; Get-Content '%LOG_OUT%' -Encoding UTF8 -Wait -Tail 10"
echo.
exit /b 0

:: ---------------------------------------------------------------------------
:EnsureLogFolders
if not exist "%LOG_DIR%" (
  mkdir "%LOG_DIR%"
  if errorlevel 1 (
    echo [오류] 로그 폴더 생성 실패: %LOG_DIR%
    exit /b 1
  )
  echo [nssm-install] 생성: %LOG_DIR%
)
if not exist "%LOG_BACKUP%" (
  mkdir "%LOG_BACKUP%"
  if errorlevel 1 (
    echo [오류] 백업 폴더 생성 실패: %LOG_BACKUP%
    exit /b 1
  )
  echo [nssm-install] 생성: %LOG_BACKUP%
)
exit /b 0
```
