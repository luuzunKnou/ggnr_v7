## 목적

개발자 모드에 «프로젝트 구성» 메뉴를 추가해, 현재 프로젝트의 시스템 노출·기능 숨김·레이어 그룹을 한 화면에서 runtime 설정에 저장할 수 있게 한다.

## 요약

공통 시스템·기능 카탈로그는 그대로 두고, 프로젝트 runtime 파일의 노출·숨김·레이어 그룹 키만 편집하는 전용 화면을 붙였다. 저장 값은 재시작 없이 시스템 목록·데이터조회에 반영된다.

## 테스트

1. 개발자 모드 사이드바에 «프로젝트 구성»이 보여야 한다.
2. 화면 상단에 현재 프로젝트명과 runtime 파일 경로가 보여야 한다.
3. 시스템을 일부만 체크해 저장하면 메인·지도 시스템 목록에 해당 항목만 남아야 한다.
4. 기능을 숨김으로 체크해 저장하면 해당 기능이 사이드바 메뉴에서 빠져야 한다.
5. 켠 시스템의 레이어 그룹을 바꿔 저장하면 그 시스템 데이터조회 그룹 목록에 반영되어야 한다.
6. «카탈로그 기본값»을 누른 뒤 저장하면 해당 시스템 레이어 그룹이 공통 목록 기준과 같아져야 한다.
7. 시스템 변수 화면에서 같은 키가 갱신되어 있어야 한다.
8. 공통 시스템·기능 목록관리 파일 내용은 바뀌지 않아야 한다.
9. 메모·민원 등 다른 개발자 메뉴 전환이 정상이어야 한다.
