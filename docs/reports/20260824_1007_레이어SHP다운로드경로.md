## 목적

레이어 목록에서 SHP를 받을 때 뜨던 실패 안내를 없애고, 파일이 내려받게 한다.

## 요약

프로젝트 폴더 이름에 빈칸이 있어 변환 프로그램이 경로 앞부분만 명령으로 실행했다. 변환 프로그램을 직접 실행하도록 바꿔 빈칸이 있어도 SHP를 만든다.

## 파일수정

수정 | src/service/shpUploadService.ts
 `spawnGdalProcess` — Windows 명령 창을 거치지 않고 변환 실행 파일을 바로 띄워, 폴더 이름 빈칸이 명령을 자르지 않게 함
 `exportLayerTableToShp` — 실패 안내에서 지오메트리 오류로 단정하던 문구를 실제 원인 메시지만 남기도록 변경
 `runOgr2ogr` / `createTableFromShp` / `ogrinfo` 호출 — 공통 실행 경로로 통일

## 테스트

1. 시스템관리 → 레이어관리 → 레이어 목록에서 행 맨 오른쪽 아래 화살표를 누르면 SHP 압축 파일이 받아져야 한다.
2. 「내부 또는 외부 명령…」 안내가 뜨지 않아야 한다.
3. 지적 레이어를 받아도 같은 안내 없이 파일이 열려야 한다.
4. 엑셀 아이콘 다운로드는 이전과 같이 동작해야 한다.
