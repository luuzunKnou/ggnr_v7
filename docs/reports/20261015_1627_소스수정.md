패널 상단에 «주소»·«계량기번호» 선택 버튼을 두었다. 번호 모드는 급수전계량기 대장에서 번호를 찾아 필지·점으로 표시한다. 모드를 바꾸면 이전 결과는 지운다.

## 테스트

1. 계량기위치 패널에 «주소»·«계량기번호» 선택 버튼이 보여야 한다.
2. 주소 모드에서 기존처럼 주소로 필지가 표시되어야 한다.
3. 계량기번호 모드에서 번호를 한 줄씩 넣고 표시하면 해당 위치가 지도에 나와야 한다.
4. 없는 번호는 목록에 «못 찾음»으로 남아야 한다.
5. 모드를 바꾸면 이전 표시 결과가 사라져야 한다.
6. 목록 행을 누르면 해당 위치로 이동해야 한다.
