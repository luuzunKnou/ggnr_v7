# 결과보고서

2026-07-27 | dev.strcat | 점사용료 수납 시 수납 전용 컬럼만 머지

## 목적

미납을 먼저 적재한 뒤 수납이 오면, 과세번호로 같은 건을 찾아 수납 컬럼만 기존 행에 넣고 미납 전용 값은 그대로 둔다.

## 요약

미납 저장 시 조회용 특별회계사업코드를 행에 넣는다. 수납 시 과세번호와 미납 조합키가 같으면 수납일자·금액·은행·유형·회계일·납부일·구분·상태·과세번호·수납일련·상태만 갱신한다. 가상계좌·관리항목 등 미납에만 있던 값은 덮어쓰지 않는다.

## 파일수정

수정 | src/lib/nextGenLinkage/upsertFee.ts
 `receiptOnlyMergeSet` — 기존 미납 행에 수납 전용 컬럼만 반영
 `upsertReceiptRow` — 과세번호 매칭 시 merge만 수행. 미매칭·충돌 시 수납 upsert

수정 | src/lib/nextGenLinkage/syncRunner.ts
 미납 저장 — 조회조건 특별회계사업코드를 행에 저장

## 테이블 수정

해당 없음

## 테스트

1. 미납 연계 후 특별회계사업코드가 채워져 있어야 한다.
2. 동일 과세번호 수납 연계 후 상태가 수납으로 바뀌고 수납금액·일자가 채워져야 한다.
3. 가상계좌·관리항목 등 미납 때 있던 값이 비지 않아야 한다.
4. 매칭 미납이 없으면 수납 행이 새로 생겨야 한다.
