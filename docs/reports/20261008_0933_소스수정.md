# 결과보고서

2026-10-08 | dev.strcat | —

## 목적

경산 도로·영덕 상하수도 프로젝트 이름을 짧은 이름으로 바꿔 실행 명령과 관리를 간단하게 한다.

## 요약

경산 도로 프로젝트는 «road_gg», 영덕 상하수도 프로젝트는 «water_yd»로 이름을 바꿨다. 프로젝트 설정 파일 이름, 시스템 이름, 설정 머리말, 게이트·기본 경로 주석을 새 이름으로 맞췄다.

설정 안의 데이터베이스 이름·계정·비밀번호와 첨부 데이터 폴더 경로도 개발·시연·운영 모두 새 이름으로 바꿨다. 실행 명령은 «npm run dev -- road_gg dev», «npm run dev -- water_yd dev»이다. 실제 데이터베이스·계정과 데이터 폴더는 아직 기존 이름이므로, 새 이름으로 바꾸거나 만들어야 접속·첨부 조회가 된다.

영향 받는 기능: 두 프로젝트의 실행·빌드 명령. 다른 프로젝트와 소스 코드는 영향 없음.

영덕 하천 프로젝트(«river_yd»)는 하천행정 시스템만 노출하도록 바꿨다. 기존에 함께 켜져 있던 상수도·소하천 시스템은 빠진다. 영덕 상하수도 프로젝트와 같은 하단 주소·시군구 코드를 넣었다.

## 파일수정

수정 | src/config/projects/road_gg.env (기존 road_gyeongsan.env)
 파일 이름 — 프로젝트 이름을 road_gg로 변경
 머리말·게이트·기본 경로 주석 — 새 이름으로 수정
 `DATABASE_NAME`, `DATABASE_USER`, `DATABASE_PASSWORD`, `GGNR_DATA_DIR` — 개발·시연·운영 모두 road_gyeongsan을 road_gg로 변경

수정 | src/config/projects/road_gg.runtime.env (기존 road_gyeongsan.runtime.env)
 `SYSTEM_NAME` — road_gg로 변경

수정 | src/config/projects/water_yd.env (기존 water_yeongdeok.env)
 파일 이름 — 프로젝트 이름을 water_yd로 변경
 머리말·게이트·기본 경로 주석 — 새 이름으로 수정
 `DATABASE_NAME`, `DATABASE_USER`, `DATABASE_PASSWORD`, `GGNR_DATA_DIR` — 개발·시연·운영 모두 water_yeongdeok을 water_yd로 변경

수정 | src/config/projects/water_yd.runtime.env (기존 water_yeongdeok.runtime.env)
 `SYSTEM_NAME` — water_yd로 변경

수정 | src/config/projects/river_yd.runtime.env
 `ENABLED_SYSTEMS` — 상수도·하천·소하천에서 하천만 노출하도록 변경
 `FOOTER_ADDR`, `FOOTER_RSS`, `SGG_CODE` — 영덕군청 하단 주소·저작권 문구·시군구 코드 47770 추가

## 테스트

1. 새 이름으로 경산 도로 프로젝트 개발 서버가 실행되어야 한다.
2. 새 이름으로 영덕 상하수도 프로젝트 개발 서버가 실행되어야 한다.
3. 데이터베이스·계정을 새 이름으로 바꾼 뒤 두 프로젝트 모두 로그인·지도 조회가 되어야 한다.
4. 데이터 폴더를 새 이름으로 옮긴 뒤 경산 도로대장 도면 첨부 미리보기가 기존처럼 보여야 한다.
5. 기존 이름으로 실행하면 프로젝트 설정을 찾지 못해야 한다.
6. 영덕 하천 프로젝트 메인·지도에 하천행정 시스템만 보이고 상수도·소하천은 보이지 않아야 한다.
7. 영덕 하천 프로젝트 하단에 영덕군청 주소가 표시되어야 한다.
