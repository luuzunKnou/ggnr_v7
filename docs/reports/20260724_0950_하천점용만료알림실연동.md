# 결과보고서

2026-07-24 | dev.strcat | —

## 목적

지도 «내 정보» 알림 탭을 더미에서 실제 하천점용대장 데이터로 전환한다. 점사용료 알림은 제외하고, 점용종료일이 15일 이내인 건만 요약·목록으로 표시한다.

## 요약

하천점용대장 목록과 동일한 종료일 기준으로 15일 이내 만료 임박 건을 조회하는 API를 추가했다. 알림 패널·사이드바 미읽음 표시는 DB 조회 결과를 사용하며, 읽음·삭제는 브라우저 저장소에 유지한다. 알림 항목 클릭 시 실제 «하천점용» 상세 패널이 열린다.

## 테스트

1. 점용종료일이 15일 이내인 하천점용 건이 있으면 «내 정보» 알림 탭에 «점용종료일이 15일 이내인 건이 N건입니다» 요약이 보여야 한다.
2. 펼치면 점용명·종료일·남은 일수(D-N) 목록이 나와야 한다.
3. 점사용료(미납) 알림은 더 이상 나오지 않아야 한다.
4. 알림 항목 클릭 시 «하천점용» 상세가 해당 건으로 열려야 한다.
5. 미읽음 알림이 있으면 사이드바 «내 정보»·말풍선 표시가 동작해야 한다.
6. «모두 지우기»·개별 삭제 후 새로고침해도 삭제 상태가 유지되어야 한다.
7. 종료일이 15일을 넘거나 날짜로 해석되지 않는 건은 알림에 포함되지 않아야 한다.
