# 결과보고서

2026-10-23 | dev.strcat | 공통점용 통합 2·3단계 — 공통 칸 이름 적용, 울진 하천점용 제거, 상세 화면 개편

## 목적

하천점용·도로점용을 받은 원천자료 테이블과 공통 칸 이름(고유키·관리번호·허가번호·허가일자·점용명·점용장소·점용목적·점용 시작·종료·점용면적·점용자명·점용주소·상태·비고)으로 처리하도록 화면을 먼저 바꾼다. 울진 하천점용 메뉴는 없애고 공통 하천점용으로 처리하며, 상세 화면을 보상편입용지와 같은 형태로 바꾼다.

## 요약

화면·서비스가 하천은 하천점용 원천자료 테이블(본표·점용필지·물건지), 도로는 도로점용 원천자료 테이블(본표·점용필지·물건지)을 보도록 연결 설정을 바꿨다. 국공유지는 기존 테이블·칸 이름을 그대로 쓴다. 공통 칸은 연결 설정 한 곳에만 적혀 있어, DB 칸 이름을 바꾸거나 레이어를 다시 올리면 별도 코드 수정 없이 반영된다. 필드 정의가 아직 옛 칸 이름이어도 실제 DB에 공통 칸이 있으면 상세·등록·저장에 보이고 저장된다.

하천·도로의 키는 관리번호(ftr_idn)이고, 필지·물건지와 첨부파일 모두 이 키 값으로 읽는다. 관리번호는 새 건 등록 때 마지막 번호 +1로 자동 채번한다(하천 JY_000520 형식). 국공유지는 기존처럼 고유키(ogc_fid)가 키다. 허가번호 자동발급은 이전처럼 새 건 등록 때만 한다. 도로 점용필지처럼 주소 칸이 없고 읍면동·리·지번이 나뉜 경우 이어 붙여 보이고, 저장할 때는 나눠 넣는다.

울진·영덕(하천)에서 울진 하천점용 메뉴를 빼고 공통 하천점용을 켰다. 울진 전용 만료 알림은 공통 하천점용 알림과 같은 표를 보므로 중복을 없앴다. 울진 하천점용 코드는 메뉴에서만 빠졌고 파일은 남겨 두었다. 정리는 다음에 별도로 한다.

상세 화면은 다음과 같이 바꿨다.
- 속성정보·추가속성: 보상편입용지와 같은 테두리 표, 한 줄에 한 칸.
- 필지목록·물건지목록·점사용료 이력: 위에서 아래로 차례로 두고, 묶음마다 «제목 (건수)» 머리로 접고 펼친다. 0건이면 접힌 채, 1건 이상이면 펼친 채 시작한다. 상단 버튼은 두지 않는다.
- 필드 정의 «보기»와 연결: 점용대장 목록·필지목록·물건지목록의 열은 각 테이블 필드 정의의 «목록» 칸(정의 순서), 본표 상세 속성과 필지·물건지 상세는 «상세보기» 칸만 보인다. 목록 정의가 없으면 점용대장 목록은 점용명·점용장소·시작일·종료일, 필지·물건지 목록은 주소만 보인다. 목록 맨 앞 상태 배지는 고정이고, 모든 열로 정렬할 수 있다.
- 필지목록·물건지목록: 조회 중 행을 고르면 지도에서 위치를 보여 주고, 보상편입용지처럼 목록·상세 패널을 덮는 모달로 상세가 열린다. 수정 중에는 지도 위치만 보여 준다.
- 점용 시작일·종료일은 따로 보이고, 한 칸 점용기간으로 묶어 읽던 처리는 없앴다.
- 공통 칸도 필드 정의에 있으면 상세 표시 여부를 따른다(정의에 아직 없는 공통 칸은 보인다).
- 첨부파일: 본표 키 값 폴더(하천·도로 관리번호, 국공유지 고유키). 울진 기존 첨부는 점용코드 폴더라 관리번호로 이름만 바꾼 값과 같아 그대로 이어진다.
- 점사용료 화면의 «점용 레이어» 버튼도 새 본표를 켠다.
- 연결 칸(관리번호)이 없는 필지·물건지 테이블에 저장할 때 다른 칸에 키가 덮어써지지 않도록, 공통 점용대장은 정해진 연결 칸만 쓴다.

읽기 전용 확인 결과, 울진 개발 DB의 하천점용 본표는 아직 옛 칸 이름이라 공통 칸 중 비고만 맞는다. 점용필지에 연결 칸이 없어 필지목록은 비어 보인다. 도로점용 원천자료 테이블은 아직 없어 «테이블이 없습니다»가 나온다. 울진 개발 DB의 기존 도로점용 테이블(269건)은 화면에서 더 이상 보지 않는다.

레이어 정의(설정 파일)에서 예전 하천·도로 공통 점용 6개(점용대장 그룹)와 울진 하천점용 3개(하천점용대장 그룹)를 지웠다. 하천점용은 레이어를 다시 올려 정의를 새로 만들고, 국공유지 점용 3개와 하천 점용시설물은 그대로 둔다. 정의가 없는 동안에도 공통 하천점용 화면은 실제 DB 공통 칸으로 보인다. 서버 시작 시 자동 생성은 하천(usage_data_as 계열)·도로(rdl_occ_as 계열)를 공통 칸으로, 국공유지는 예전 칸으로 없을 때만 만든다. 이미 있는 테이블의 칸은 바꾸지 않는다.

DB 변경(사용자 진행)이 필요한 항목:
1. 하천점용 본표 칸 이름을 공통 칸 이름으로 변경. 점용기간 한 칸은 시작·종료 두 칸으로 나눠 글자로 저장한다. 점용코드(cons_code)는 관리번호(ftr_idn)로 이름만 바꾼다(자동 채번·울진 첨부 폴더에 쓰므로 값은 그대로).
2. 하천 점용필지(usage_data_solo_as)·물건지의 점용코드(cons_code)도 관리번호(ftr_idn)로 이름을 바꿔 본표와 같은 값으로 연결한다.
3. 도로점용 원천자료 테이블(본표·점용필지·물건지)을 올리고, 공통 칸 이름과 연결 칸(ftr_idn)을 맞춘다.
4. 레이어 필드 정의(보일 칸·라벨)를 새 칸 이름으로 갱신한다.
5. 대장에만 있는 칸은 추가속성(extra)으로 옮긴다.

## 테스트

1. 하천 시스템 사이드바에 «하천점용»이 하나만 보이고, 울진 하천점용 메뉴는 보이지 않아야 한다.
2. 상세에 상단 버튼 없이 속성정보·추가속성 다음에 필지목록·물건지목록·점사용료 이력이 차례로 보여야 한다.
3. 필지목록·물건지목록·점사용료 이력 머리에 건수가 보이고, 0건이면 접힌 채, 1건 이상이면 펼친 채 열려야 한다.
4. 속성정보는 테두리 표로 한 줄에 한 칸씩 보이고, 점용 시작일·종료일이 따로 보여야 한다.
5. 필지목록·물건지목록에서 행을 고르면 지도에서 강조되고, 목록·상세 패널을 덮는 상세 모달이 열려야 한다. Esc·닫기·바깥 클릭으로 닫혀야 한다.
6. 수정 중 점용 시작·종료에 «영구»·«허가일로부터 3개월» 같은 글자를 넣어 저장할 수 있어야 하고, 종료 글자에 따라 상태가 자동으로 바뀌어야 한다.
7. 하천·도로 새 건 등록 시 허가번호와 관리번호가 자동발급되고, 기존 건 수정에서는 바뀌지 않아야 한다.
8. 저장 후 필지·물건지가 본표 관리번호로 연결되어 다시 열었을 때 목록에 남아 있어야 한다.
9. 도로점용 점용필지는 읍면동·리·지번이 이어 붙은 주소로 보이고, 필지 추가 저장 시 세 칸에 나눠 들어가야 한다.
10. 하천·도로 첨부파일은 관리번호 폴더로 보이고, 울진 기존 첨부(점용코드 폴더)가 그대로 보여야 한다.
11. 지도에서 점용 도형을 누르면 겹침 목록에 허가번호가 보이고 해당 건 상세가 열려야 한다.
12. 점사용료 화면의 «점용 레이어» 버튼이 새 하천·도로 점용 본표를 켜고 꺼야 한다.
13. 국공유지 점용은 기존처럼 조회·수정·필지 저장이 되어야 한다.
14. 업무 알림에 같은 하천점용 만료 건이 두 번 나오지 않아야 한다.
15. 점용대장 목록·필지목록의 열 제목이 «…»로 잘리지 않아야 하고, 열이 많으면 가로로 스크롤되어야 한다.
16. 필드 정의에서 «목록»·«상세보기»를 바꾸면 점용대장 목록·필지목록 열과 상세·필지 상세 속성이 그대로 따라 바뀌어야 한다.
17. 레이어 목록에 예전 하천·도로 점용대장과 울진 하천점용대장 레이어가 보이지 않고, 국공유지 점용·하천 점용시설물은 그대로 보여야 한다.
18. 서버 재시작 후 하천·도로 점용 테이블이 없던 프로젝트에는 공통 칸으로 새 테이블이 생기고, 이미 있던 테이블의 칸은 바뀌지 않아야 한다.
