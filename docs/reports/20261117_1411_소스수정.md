# 결과보고서

2026-11-17 | gyujin | 정사 배치 gdal2tiles DLL 오류 · warp 보존

## 목적

정사영상 좌표 변환 후 타일 단계에서 Python GDAL DLL을 못 찾아 실패하던 문제를 막고, 타일 실패 시 수 시간 걸린 변환 결과 파일이 지워지지 않게 한다. CAD 다운로드에서 점형 레이어(변류시설 등)가 캐드에 안 보이던 문제를 고친다.

## 요약

타일 도구가 conda `Library\bin`을 PATH에 넣지 않아 `_gdal` DLL 로드에 실패했다. 자식 프로세스 PATH에 해당 경로를 넣도록 고쳤다. 타일 실패 시 임시 폴더 전체를 지우던 동작을 바꿔, 변환된 영상 파일은 남기고 안내하도록 했다. 이미 실패한 이번 변환 결과물은 정리 과정에서 삭제된 상태라 재실행이 필요하다. CAD 점 레이어는 SVG 아이콘 삽입을 철회하고 다시 작은 원으로만 표시한다.

## 파일수정

수정 | src/service/orthophotoService.ts
 `buildGdalChildEnv` — conda Library·Scripts·bin 을 PATH 앞에 추가. Python GDAL DLL 로드 실패 방지
 `runOrthophotoJob` (타일 실패 분기) — 타일 실패 시 변환 영상은 유지하고 타일 임시만 삭제, 보존 경로를 실패 메시지에 기록

삭제 | src/lib/cadSvgSymbol.ts
 `cadSvgSymbol` — SVG→블록 변환 유틸 제거. 아이콘 삽입 원복에 맞춤

수정 | src/service/layerCadExportService.ts

 `convertDxfPointsToCircles` — 점 레이어를 작은 원으로 표시
 `resolveGeoServerLayerTrueColor` — 점 심볼 색 보조

## 테스트

1. 정사 배치 실행 시 타일 단계에서 DLL 로드 오류가 나지 않아야 한다.
2. 타일 단계만 실패하면 변환 영상 파일이 임시 작업 폴더에 남아 있어야 한다.
3. 실패 메시지에 보존된 변환 영상 경로가 포함되어야 한다.
4. 정상 완료 시에는 이전과 같이 임시 작업 폴더가 정리되어야 한다.
5. 상수관로·변류시설을 함께 받으면 변류시설이 작은 원으로 보여야 한다.
6. 점 레이어 원은 GeoServer 등록 색과 맞아야 한다.
7. SVG 아이콘 블록·INSERT가 CAD 파일에 없어야 한다.
