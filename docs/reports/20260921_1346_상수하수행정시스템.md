# 결과보고서

2026-09-21 | luuzunKnou | docs/brief/20260921_1346_상수하수행정시스템.md

## 목적

메인에 상수행정 업무지원과 하수행정 업무지원을 추가하고, 공통 조회·민원 메뉴만 연다.

## 요약

두 시스템을 목록에 등록했다. 메뉴는 데이터조회, 변동이력분석, 필지분석, 민원관리, 메모관리, 도형편집기다. 영양군 사용 시스템에 넣어 포털에 보이게 했다. 기존 상수도·하수도 통합관리와는 별도다.

## 파일수정

수정 | src/config/systemList.config
 `wtlAdmin` — 상수행정 업무지원 시스템. 데이터조회·변동이력분석·필지분석·민원관리·메모관리·도형편집기만 포함
 `swlAdmin` — 하수행정 업무지원 시스템. 메뉴 구성은 상수행정과 동일

수정 | src/config/projects/build_yy.runtime.env
 `ENABLED_SYSTEMS` — 영양군 사용 시스템에 상수행정·하수행정 키 추가. 메인 카드 노출

## 테이블 수정

해당 없음

## 테스트

1. 영양군 메인에 «상수행정 업무지원 시스템» 카드가 나와야 한다.
2. 영양군 메인에 «하수행정 업무지원 시스템» 카드가 나와야 한다.
3. 상수행정 진입 시 데이터조회·변동이력분석·필지분석·민원관리·메모관리·도형편집기만 보여야 한다.
4. 하수행정 메뉴도 상수행정과 같아야 한다.
5. 기존 상수도·하수도 통합관리와 도로·하천·건설 카드는 이전과 같아야 한다.
