## 목적

하천·도로 점용 신규 등록 시 도형 교차로 채워지는 필지목록에 주소·지적에서 넣을 수 있는 값을 자동 반영하고, 나머지 속성은 보상편입용지처럼 모달에서 사용자가 입력·저장할 수 있게 한다.

## 요약

도형 «적용» 시 지적 조회 결과(주소, 지목, 면적 등)를 필지 행의 목록·상세 칸 값으로 매핑한다. 수정 중 필지·물건지 행 클릭 시 편집 모달이 열리고, 건 저장 시 필지 동기화에 목록·상세 칸 값이 함께 반영된다.

## 테스트

1. 하천 또는 도로 점용 «신규»에서 도형을 그리고 «적용»하면 필지목록에 교차 필지가 채워져야 한다.
2. 목록에 주소·읍면동·리·지번·지목·면적 등 정의된 칸이 자동으로 들어가야 한다(정의에 있는 칸만).
3. 수정 중 필지 행 클릭 시 «필지 정보» 모달이 열리고 빈 칸·나머지 칸을 입력할 수 있어야 한다.
4. 모달 «확인» 후 목록 열 값이 갱신되어 보여야 한다.
5. 건 «등록»·«저장» 후 상세 조회에서 필지 모달로 동일 속성이 보여야 한다.
6. 도형을 다시 바꿔 «적용»해도 사용자가 이미 입력한 칸은 지워지지 않아야 한다.
7. «추가»로 주소 검색 필지 넣을 때 주소 관련 칸이 자동 채워져야 한다.
8. 조회 모드에서 필지 클릭 시 기존 읽기 전용 상세 모달이 동작해야 한다.
