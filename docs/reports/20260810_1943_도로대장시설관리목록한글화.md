# 결과보고서

2026-08-10 | dev.strcat | 도로대장·시설관리 목록 헤더 한글화

## 목적

도로대장 시설 하위 목록과 시설관리 결과 목록의 열 제목을, 데이터 조회와 같이 정의된 한글 필드명으로 보이게 한다.

## 요약

목록에 영문 컬럼키가 그대로 나오던 부분을 데이터 조회와 동일한 필드 한글명으로 바꿨다. 열 순서·노출 설정은 기존을 유지하고, 헤더 문구만 한글화했다. 시설 속성 모달의 항목 이름도 같은 방식으로 맞췄다.

## 테스트

1. 도로대장 상세에서 시설 구분을 켜면 하위 목록 열 제목이 한글로 보여야 한다.
2. 시설관리에서 레이어를 조회하면 결과 목록 열 제목이 한글로 보여야 한다.
3. 데이터 조회에서 같은 레이어를 열었을 때와 열 제목 한글이 같아야 한다.
4. 시설 행을 눌러 속성 모달을 열면 항목 이름이 한글로 보여야 한다.
5. 한글명이 없는 필드는 기존처럼 영문 키가 보여야 한다.
