## 목적

도로 사이드바에 자전거도로 부서업무 프로토타입을 붙여, 시점~종점 노선 목록 → 속성·구간·첨부 상세 → 구간 상세 모달 흐름을 목 데이터로 확인한다.

## 요약

사이드바 «자전거도로»를 켜면 왼쪽 노선 목록이 열리고, 노선 선택 시 우측 상세(속성·구간·첨부)가 붙는다. 구간 행 클릭 시 폭원 구역이 나뉜 모달이 뜬다. 실DB·지도 연동 없이 목 데이터·화면만 구성했다.

## 테스트

1. 사이드바 «자전거도로» 선택 시 왼쪽 노선 목록이 열려야 한다.
2. 목록 제목이 «시점 ~ 종점» 형태로 보여야 한다.
3. 노선 행 클릭 시 우측 상세에 연장·진행방향·시점·종점·교량·지하철역·비고가 보여야 한다.
4. 상세 구간 표에 일련번호·노선명·연장만 보여야 한다.
5. 구간 행 클릭 시 모달로 폭원 등 구간 상세가 열려야 한다.
6. 상세 닫기 시 목록은 유지되고 선택만 해제되어야 한다.
7. 목록 닫기 또는 다른 메뉴 전환 시 자전거도로 패널·선택이 남아 있지 않아야 한다.
8. 도로망도·자전거도로를 번갈아 열어도 패널 위치가 겹치지 않아야 한다.
