## 목적

개발자 모드 File Converter에서 형상파일을 도면(DXF)으로 바꿀 수 있게 한다. 레이어 등록 없이 변환만 수행한다.

## 요약

File Converter에 «SHP to DXF» 탭을 추가했다. 전용 작업 폴더의 형상파일을 같은 이름 도면으로 만들고, 좌표는 원본 그대로 둔다. 짝 파일이 없는 건은 건너뛰고 안내한다. 캐드 전용 형식(DWG)은 넣지 않았다. 영향 받는 기능은 File Converter와 파일 관리 기본 폴더·변환 이력이다.

## 파일수정

추가 | src/service/shpToDxfService.ts

 `runShpToDxfConversion` — 선택한 작업의 형상파일을 도면으로 바꾸고, 같은 이름은 덮어쓴다. 좌표는 재투영하지 않으며 면은 외곽선으로 기록한다. 짝 파일이 없으면 해당 파일만 실패로 남긴다

## 테이블 수정

해당 없음

## 테스트

1. File Converter에 «SHP to DXF» 항목이 보여야 한다.
2. 전용 폴더에 작업이 없으면 빈 안내가 나와야 한다.
3. 작업명/SHP 에 형상파일과 짝 파일을 넣으면 목록에 개수가 나와야 한다.
4. 변환 시작 후 같은 작업의 DXF 폴더에 같은 이름 도면이 생겨야 한다.
5. 이미 있는 같은 이름 도면은 덮어써져야 한다.
6. 짝 파일(.shx, .dbf)이 없으면 해당 파일은 실패 안내가 나와야 한다.
7. 좌표값은 원본과 같아야 한다.
8. TIF·PDF·OBJ·LAS·OCR 탭은 그대로 보여야 한다.
