PostgreSQL JS 드라이버만 쓰므로 네이티브 모듈은 설치하지 않고 번들에서 제외한다. 접속통계는 IP 정규화만 쓰도록 바꿔 브라우저 번들에 OS 모듈이 들어가지 않게 한다.
