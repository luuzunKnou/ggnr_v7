# 결과보고서

## 목적

상수행정 업무지원에 관망도조회·시설관리·공사대장·급수공사 메뉴를 넣고, 빈 패널로 진입만 확인한다.

## 요약

네 메뉴를 서비스 목록과 상수행정에 등록했다. 사이드바에서 누르면 제목과 닫기만 있는 빈 패널이 열린다. 공통 여섯 메뉴는 아래에 그대로다.

## 파일수정

추가 | src/app/(pages)/map/_mapContents/wtlAdmin/wtlAdminBinding.ts
 `WTL_ADMIN_EMPTY_SER_ENGS` — 관망도조회·시설관리·공사대장·급수공사 키와 제목
 `findOpenedWtlAdminEmptySerEng` — 열린 메뉴를 찾아 빈 패널에 연결

추가 | src/app/(pages)/map/_mapContents/wtlAdmin/WtlAdminEmpty.shell.tsx
 `WtlAdminEmptyShell` — 제목·닫기만 있는 빈 패널

수정 | src/config/serviceList.config
 `wtlNetworkMap` · `wtlFacility` · `wtlConstructionLedger` · `wtlWaterSupply` — 네 메뉴 등록

수정 | src/config/systemList.config
 `wtlAdmin.serviceList` — 공통 메뉴 위에 네 메뉴 추가

수정 | src/app/(pages)/map/map-layout-client.tsx
 `WtlAdminEmptyShell` — 지도 레이아웃에 빈 패널 연동

## 테이블 수정

해당 없음

## 테스트

1. 상수행정에서 관망도조회·시설관리·공사대장·급수공사가 공통 메뉴 위에 보여야 한다.
2. 관망도조회 클릭 시 빈 패널이 열려야 한다.
3. 시설관리·공사대장·급수공사도 각각 빈 패널이 열려야 한다.
4. 닫기를 누르면 패널이 사라져야 한다.
5. 데이터조회·변동이력분석·필지분석·민원관리·메모관리·도형편집기는 이전과 같아야 한다.
