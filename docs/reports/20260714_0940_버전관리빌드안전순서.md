## 목적

최신소스 적용 시 `.next` 경합 오류를 줄이기 위해, 앱을 먼저 종료한 뒤 빌드하고 다시 기동하도록 순서를 바꾸고, 버전관리 화면 단계도 그 흐름에 맞게 나눈다.

## 요약

재시작이 켜진 적용은 GeoServer 중지 → 병합·적용 → 앱 종료 → `npm run build` → 앱 기동 → GeoServer 기동 순으로 콘솔 파이프라인이 진행된다. 재시작이 꺼진 경우에는 적용 직후 GeoServer만 다시 켠다. 화면 단계는 중지·적용·앱 종료·빌드·앱 재기동·GeoServer 기동으로 쪼개 표시한다.

## 테스트

1. 재시작 켠 채 적용 시 단계에 GeoServer 중지·병합·적용·앱 종료·빌드·앱 재기동·GeoServer 기동이 보여야 한다.
2. 적용 직후 GeoServer가 바로 켜지지 않고, 앱 종료·빌드 뒤에 켜져야 한다.
3. 콘솔에 앱 종료 후 `npm run build`가 실행되어야 한다.
4. 빌드가 끝난 뒤 앱이 다시 떠야 한다.
5. 재시작을 끄고 적용하면 앱 종료·빌드 단계는 생략이고 GeoServer는 적용 후 바로 기동되어야 한다.
6. Node 런처·start/b·명령 실행·process.exit 각 방식에서도 빌드가 앱 종료 이후에만 돌아야 한다.
