# 결과보고서

2026-10-26 | 213am | —

## 목적

스타일을 SLD로 저장해도 지오서버 설정이 CSS로 남고, 만들어진 SLD 파일이 한 줄로 붙어 관리자 화면에서 고치기 어려웠다. 설정 파일이 SLD로 바뀌고, SLD 본문은 줄바꿈과 들여쓰기가 된 채로 저장되게 한다. 레이어 설정 범례는 조건이 여러 개여도 글자가 아닌 도형으로 보이게 한다. 하수도 관망조회 현황의 관경·연도·관재질 헤더는 정해진 순서로 보이게 한다. 우측 지하시설물 범례도 관로의 화살표·라벨이 있어도 선으로 보이게 한다. 상수관로시설·상수도시설 현황 표 글자를 하수관로 관종·관경 현황과 같게 맞춘다. 하수관로 관종·관경 현황에서는 시군구 열을 빼고 행정구역명 열을 읍면동으로 보여 준다.

## 요약

SLD로 저장한 뒤에도 CSS 파일을 스타일 폴더에 다시 써서, 지오서버가 설정 XML을 CSS로 되돌려 저장했다. 형식이 SLD로 바뀐 뒤에도 설정 파일명이 `.css`로 남아 관리자 편집기가 CSS 파일을 찾았다. SLD로 바꿀 때는 CSS 파일을 지우고, 형식과 파일명이 SLD인지 확인한 뒤에만 성공으로 본다. 화면에서 다시 고칠 CSS 원본은 스타일 폴더 밖에 둔다. 한 줄로 나온 SLD는 두 칸 들여쓰기로 펼쳐 저장한다. 이미 줄바꿈이 있는 SLD는 그대로 둔다.

레이어 설정의 범례는 화살표·라벨 규칙이 있으면 글자로 나왔다. 그런 스타일은 첫 선·면·점만 잘라 그림으로 받게 했다. 우측 메뉴는 그 처리를 타지 않았고, 선과 화살표·라벨이 한 규칙에 있으면 규칙이 통째로 빠져 다시 글자 범례가 나왔다. 지도 범례도 대표 도형을 요청하고, 같은 규칙에서는 화살표와 글자만 빼도록 바꿨다.

하수도 관망조회 현황은 연장이 긴 항목부터 나왔다. 관경과 연도는 작은 값부터, 관재질은 코드표 순으로 두고 미분류·기타는 맨 오른쪽으로 바꿨다. 상수관로시설 현황과 상수도시설 현황 표의 글자 크기·색·줄간격·굵기를 하수관로 관종·관경 현황과 같게 맞췄다. 상수 현황의 열 구성은 그대로다. 하수관로 관종·관경 현황에서는 시군구 열을 없애고 행정구역명 열 이름을 읍면동으로 바꿨다. 관경별 현황은 행정구역 110px, 관재질 150px, 총계 150px, 원형 관경 160px, 사각형·기타 140px로 맞췄다.

## 테스트

1. 스타일 수정에서 SLD를 고르고 저장하면 스타일 설정 XML의 형식이 SLD이고 파일명이 sld로 끝나야 한다.
2. 같은 스타일의 CSS 파일은 스타일 폴더에 남지 않아야 한다.
3. 저장된 SLD 파일은 한 줄이 아니라 단계마다 들여쓰기가 보여야 한다.
4. 관리자 화면에서 스타일 직접 수정을 열면 CSS 파일을 찾지 못하고, SLD 내용이 보여야 한다.
5. 화면에서 색과 선을 고쳐 저장해도 관리자 화면 형식이 CSS로 돌아가지 않아야 한다.
6. 줄바꿈이 있는 기존 SLD는 저장 후에도 내용 구조가 유지되어야 한다.
7. CSS로 다시 바꾸면 설정 XML이 CSS로 바뀌고 SLD 파일은 남지 않아야 한다.
8. 심볼을 SLD로 둔 레이어의 목록 범례가 CSS 심볼 범례와 비슷한 크기로 보여야 한다.
9. 레이어 스키마가 없는 면 스타일도 노란 배경 대신 스타일 색 범례가 보여야 한다.
10. 점·선·면 목록 범례가 칸 안에서 비슷한 크기로 보여야 한다.
8. 레이어 설정에서 화살표·라벨이 있는 스타일의 범례는 글자가 아니라 선·면·점 그림으로 보여야 한다.
9. 규칙이 하나인 스타일의 범례는 이전과 같이 보여야 한다.
10. 하수도 관망조회 현황의 관경 헤더는 작은 관경부터 큰 관경 순이어야 한다.
11. 연도 헤더는 과거 연도부터 최근 연도 순이어야 한다.
12. 관재질 헤더는 코드표 순이어야 하고, 미분류와 기타는 맨 오른쪽에 있어야 한다.
13. 우측 «지하시설물»에서 화살표·라벨이 있는 관로 범례는 글자가 아니라 선으로 보여야 한다.
14. 규칙이 하나인 점·면 레이어 범례는 이전과 같이 보여야 한다.
15. 주제도·레이어 목록 범례도 같은 대표 도형으로 보여야 한다.
16. 상수관로시설 현황 표의 헤더·본문 글자 크기와 색이 하수관로 관종·관경 현황과 같아야 한다.
17. 상수관로시설 현황 총계 숫자는 본문보다 약간 굵고, 구분 칸은 본문과 같은 굵기여야 한다.
18. 상수도시설 현황 표도 같은 글자 크기·색·줄간격이어야 한다.
19. 두 현황의 열 구성·고정 열·대각선 칸은 이전과 같아야 한다.
20. 하수관로 관종별·관경별 현황 표에 시군구 열이 없어야 한다.
21. 그 표의 구역 열 이름은 읍면동이어야 하고, 읍면동 이름이 보여야 한다.
22. 다른 하수 시설 현황 표의 시군구 열은 그대로여야 한다.
23. 하수관로 관경별 현황의 행정구역 열은 110px, 관재질은 150px, 총계는 150px, 원형 아래 관경은 160px, 사각형과 기타는 140px이어야 한다.
24. 하수관로 관종별 현황 열 너비는 이전과 같아야 한다.
