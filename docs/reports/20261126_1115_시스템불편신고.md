# 결과보고서

2026-11-26 | 200BingSu | 시스템 불편신고

## 목적

사용자가 내 정보에서 불편·오류를 작성해 로컬에 이력을 남기고, 동일 내용을 GNMS 서버로 직접 보낼 수 있게 한다.

## 요약

내 정보 공통에 «시스템 불편신고» 메뉴(메일 아이콘)를 추가했다. 선택 시 지도 기본 플로팅 높이의 좌·우 모달이 열리며, 왼쪽에서 기능·내용·첨부를 작성하고 오른쪽에서 본인(슈퍼는 전체) 제출 목록을 본다. 본문은 TipTap 에디터(이미지 서버 업로드)와 별도 첨부를 쓰고, 제출 시 로컬 DB 저장 후 브라우저가 GNMS로 multipart 전송한다. GNMS 수신 규격은 정의서로 넘긴다. DB 테이블 적용(push)은 별도 요청 시에만 한다.

## 테스트

1. 내 정보 공통에 «시스템 불편신고»와 메일 아이콘이 보여야 한다.
2. 선택 시 좌 작성·우 목록 플로팅 모달이 열려야 한다.
3. 기능 목록 맨 위에 «선택 없음»이 있고, 기본값은 현재 열린 기능이어야 한다.
4. 작성자는 수정할 수 없어야 한다.
5. 내용에 이미지를 넣으면 본문에 표시되어야 한다.
6. 별도 첨부를 올리고 목록·전체 내려받기가 동작해야 한다.
7. 제출 후 우측 목록에 항목이 생기고, GNMS 전송 성공/실패가 표시되어야 한다.
8. 일반 사용자는 본인 목록만, 슈퍼 계정은 전체 목록이 보여야 한다.
9. 목록 행을 누르면 왼쪽에서 내용·첨부를 읽을 수 있어야 한다.
10. DB에 테이블이 없으면 초안 생성 오류가 나므로, 스키마 적용 후 재확인해야 한다.
