# 결과보고서

2026-11-06 | dev.strcat | 울진군 소규모 공공시설 자료(소규모공공시설.hwpx)

## 목적

하천행정·도로행정·건설행정 시스템처럼 «소규모 공공시설관리 시스템»을 하나 만들어 울진 사이트에서 보이게 한다. 함께 받은 소규모 공공시설 자료를 업무지시서로 정리한다.

## 요약

시스템 목록에 «소규모 공공시설관리 시스템»(설명 «#세천 #소교량 #안전점검 #위험시설 #정비계획», 황토색, 다리와 물결 아이콘)을 추가했다. 울진 건설통합행정 사이트의 사용 시스템에 넣어 첫 화면에서 도로·하천·건설 시스템과 함께 보인다. 공개 시스템이라 따로 권한을 주지 않아도 들어갈 수 있다.

업무 화면이 아직 없어서 메뉴는 다른 시스템과 같은 공통 메뉴(데이터조회, 변동이력, 필지분석, 민원, 메모, 도형편집)만 붙였다. 시설 대장, 안전점검, 치수안전도, 위험시설, 정비계획, 시행계획 메뉴는 업무지시서에 정리했고, 확인 후 하나씩 만든다.

영향 받는 기능: 울진 사이트 첫 화면 시스템 목록. 다른 사이트는 사용 시스템에 넣지 않아 바뀌지 않는다.

## 파일수정

수정 | src/config/systemList.config

수정 | src/config/projects/build_uj.runtime.env
 `ENABLED_SYSTEMS` — 울진 사이트에 소규모 공공시설관리 시스템 추가

추가 | docs/brief/20261106_1042_소규모공공시설관리시스템.md
 업무지시서 — 소규모 공공시설 범위·관리체계·평가 기준·정비계획을 정리하고 필요 기능 정의

## 테이블 수정

해당 없음

## 테스트

1. 울진 사이트 첫 화면 시스템 목록에 «소규모 공공시설관리 시스템»이 보여야 한다.
2. 카드를 누르면 지도 화면이 열리고 사이드바에 공통 메뉴 6개가 보여야 한다.
3. 하천행정·도로행정·건설행정 시스템은 이전과 같이 보이고 들어가져야 한다.
4. 울진 외 다른 사이트 첫 화면에는 새 시스템이 나오지 않아야 한다.
