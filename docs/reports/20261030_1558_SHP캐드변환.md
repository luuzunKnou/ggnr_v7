# 결과보고서

2026-10-30 | gyujin | docs/brief/20261030_1554_SHP캐드변환.md

## 목적

File Converter에서 형상파일을 도면뿐 아니라 캐드 형식으로도 받을 수 있게 한다.

## 요약

«SHP to DXF»에 도면(DXF)·캐드(DWG) 선택지를 넣었다. 캐드를 고르면 도면을 만든 뒤 QCAD로 바꾼다. QCAD가 없으면 캐드 선택은 막고 도면 변환은 그대로 둔다. 영향 받는 기능은 File Converter와 도면 표시에서 쓰는 QCAD 변환이다.

## 파일수정

수정 | src/lib/dwgToDxf.ts
 `runDwg2Dwg` — QCAD 변환 실행 공통 처리. 도면 표시의 DWG 읽기와 같은 경로
 `convertDxfFileToDwg` — 도면 파일을 캐드 파일로 변환. 한글 경로를 피하려고 작업 폴더에 복사한 뒤 결과를 되돌린다
 `isQcadDwgConverterAvailable` — QCAD 사용 가능 여부

수정 | src/service/shpToDxfService.ts
 `listShpToDxfJobs` — 캐드 파일 수와 QCAD 가능 여부를 함께 반환
 `runShpToDxfConversion` — 출력 형식이 캐드면 도면 생성 후 QCAD로 이어서 변환. 없으면 안내 후 중단

수정 | src/app/(pages)/dev/_components/fileConverter/ShpToDxfTab.tsx
 `ShpToDxfTab` — 도면·캐드 선택, 목록에 캐드 개수 표시. QCAD 없으면 캐드 선택 비활성화

수정 | src/app/(pages)/dev/_components/FileConverterContent.tsx
 `TAB_ITEMS` — 탭 안내에 캐드 형식 포함

수정 | src/service/fileManagerService.ts
 `UploadConvertHistoryEntry.kind` — 캐드 변환 이력 종류 추가

## 테이블 수정

해당 없음

## 테스트

1. File Converter «SHP to DXF»에 도면·캐드 선택지가 보여야 한다.
2. 도면을 고르고 변환하면 DXF 폴더에 파일이 있어야 한다.
3. 캐드를 고르고 변환하면 DWG 폴더에 파일이 있어야 한다.
4. QCAD가 없으면 캐드 선택이 비활성화되고 안내가 보여야 한다.
5. 짝 파일이 없는 형상파일은 이전처럼 실패 안내가 나와야 한다.
6. 다른 변환 탭은 그대로 보여야 한다.
