2026-09-14 | JungWooojin | docs/brief/20260914_1132_드론영상데이터조회WMS.md

## 목적

데이터 조회에서 드론영상 범위를 보라색 상자로 보고 클릭 시 영상을 켜며, 레이어권한으로 QGIS WMS에 같은 영상을 노출한다.

## 요약

변환 완료 드론영상의 범위를 데이터 조회 «드론영상 범위»로 켜면 지도에 보라색 상자가 그려지고, 상자 클릭 시 해당 영상이 지도에 표시된다. 레이어권한 목록에 드론영상을 넣고 읽기 허용 시 QGIS WMS 능력·지도요청으로 원본 정사를 렌더한다. 기존 영상조회 체크 표시는 유지한다.

## 테스트

1. 데이터 조회에 «드론영상»·«드론영상 범위»가 보여야 한다.
2. «드론영상 범위»를 켜면 변환 완료 영상마다 보라색 상자가 보여야 한다.
3. 상자를 클릭하면 해당 드론영상이 지도에 뜨고 범위로 맞춰져야 한다.
4. «드론영상 범위»를 끄면 상자와 클릭으로 켠 영상이 사라져야 한다.
5. 레이어권한에 «드론영상» 그룹 항목이 보여야 한다.
6. 읽기를 허용한 뒤 QGIS WMS에 해당 레이어가 보여야 한다.
7. QGIS에서 허용 레이어를 켜면 영상이 보여야 한다.
8. 읽기 거부 영상은 QGIS에 나오지 않아야 한다.
9. 영상조회에서 기존처럼 체크로 영상을 켜고 끌 수 있어야 한다.
