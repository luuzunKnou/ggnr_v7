# 결과보고서

2026-07-31 | gyujin | 보상편입용지 UI 목업 개선 요청

## 목적

보상편입용지 상세 화면에서 필지 목록 표의 좌우 스크롤과 속성 영역의 빈 공간을 없애고, 감정평가 금액·적용단가 계산 방식과 소유자 주소 입력 방식을 실제 업무에 맞게 개선한다.

## 요약

필지 목록 표에서 읍면동·지번(편입)·편입면적·보상금액 핵심 열만 보이도록 좁혀 좌우 스크롤을 없앴고, 행마다 있던 수정·삭제 버튼을 없애고 행을 클릭하면 바로 필지 수정 모달이 열리도록 단순화했다(삭제는 모달 안 버튼으로 이동). 상단 건 속성 영역도 항목별 좁고 긴 한 줄짜리 표 대신 2열 카드형 입력 그리드로 바꿔 빈 공간을 줄였다. 감정평가 금액 항목명(예: 새롬감정·대호감정)을 건마다 다르게 지정할 수 있도록 건 속성에 «감정기관1»·«감정기관2» 입력을 추가했고, 적용단가는 두 감정 금액의 평균, 보상금액은 적용단가 × 편입면적으로 자동 계산되도록 해 더 이상 직접 입력하지 않는다. 토지소유자 주소는 직접 입력 대신 기존 지도 주소검색과 동일한 VWorld 주소 검색 API로 검색해 선택하도록 변경했다.

## 테스트

1. 보상편입용지 상세에서 필지가 여러 개여도 표에 좌우 스크롤이 생기지 않아야 한다.
2. 상세 속성 영역이 2열로 나뉘어 표시되어 이전보다 빈 공간이 줄어야 한다.
3. 필지 목록에 수정·삭제 아이콘이 보이지 않아야 한다.
4. 필지 행을 클릭하면 지도 하이라이트·이동과 함께 해당 필지 수정 모달이 바로 열려야 한다.
5. 기존 필지 수정 모달에는 «삭제» 버튼이 보이고, «추가»로 새로 여는 모달에는 삭제 버튼이 보이지 않아야 한다.
6. 모달의 «삭제» 클릭 시 확인 후 필지가 목록에서 제거되고 모달이 닫혀야 한다.
7. 건마다 감정기관1·감정기관2 이름을 다르게 저장하면 필지 모달의 항목명이 해당 건의 감정기관명으로 표시되어야 한다.
8. 필지 추가·수정 모달에서 감정평가1·2 금액을 입력하면 적용단가가 두 금액의 평균으로 자동 표시되어야 한다.
9. 편입면적 또는 감정평가 금액을 바꾸면 보상금액이 적용단가 × 편입면적으로 즉시 재계산되어야 한다.
10. 적용단가·보상금액 입력란이 직접 입력되지 않고 읽기 전용으로만 보여야 한다.
11. 필지 모달에서 «토지소유자 주소»를 검색어 입력 후 검색 결과 목록에서 선택하면 주소가 채워져야 한다.
12. VWorld API 키가 설정되지 않은 환경에서는 주소검색 영역에 안내 문구가 나와야 한다.
13. 건명 변경·건 삭제 등 건 단위 CRUD 동작은 변경 전과 동일하게 동작해야 한다.
