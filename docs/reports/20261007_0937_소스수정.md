# 결과보고서

2026-10-07 | gyujin | QGIS WMS 드론영상 전용 정리

## 목적

QGIS WMS 연결을 관리 화면 안내와 같이 드론영상 전용으로 맞추고, WMS 요청이 공용 GeoServer를 거치지 않게 한다.

## 요약

전날 WMS 레이어 목록을 앱이 직접 만들도록 바꾸면서 일반 레이어도 목록에 넣었으나, 일반 레이어는 WFS로 쓰는 것이 원래 방식이다. WMS 목록에는 읽기 권한이 있는 드론영상만 넣고, 일반 레이어로 지도 이미지를 요청하면 WFS로 추가하라는 안내 오류를 돌려준다. 이로써 WMS는 GeoServer 없이 원본 영상만으로 동작하며, GeoServer 상태나 다른 프로젝트 레이어 설정과 무관해졌다.

## 파일수정

수정 | src/service/qgisLayerControlService.ts
 `buildWmsCapabilitiesXml` — 일반 레이어 그룹 생성을 빼고 드론영상만 목록에 넣도록 변경. 지원 요청은 목록·지도 이미지(PNG)만 선언
 `loadDefineTableMetaMap` — 일반 레이어 한글명·그룹 조회가 필요 없어져 삭제
 `proxyWmsGet` — 기존에는 드론영상이 아닌 지도 이미지 요청을 GeoServer로 중계했으나, 안내 오류를 반환하도록 변경. 그 밖의 요청은 지원하지 않음 오류로 응답하고 GeoServer 중계 코드 삭제

## 테스트

1. QGIS WMS 연결 시 레이어 목록에 읽기 권한이 있는 드론영상만 보여야 한다.
2. 목록에 일반 레이어(메모 등)가 보이지 않아야 한다.
3. 드론영상을 추가하면 지도에 영상이 그려져야 한다.
4. 일반 레이어 이름으로 WMS 지도 이미지를 요청하면 «WMS는 드론영상 전용입니다» 안내가 나와야 한다.
5. GeoServer가 꺼져 있어도 WMS 목록과 드론영상 표시가 동작해야 한다.
6. QGIS WFS 연결·조회·편집은 이전과 같이 동작해야 한다.
