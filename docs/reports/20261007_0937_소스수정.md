# 결과보고서

## 목적

QGIS WMS 연결을 관리 화면 안내와 같이 드론영상 전용으로 맞추고, WMS 요청이 공용 GeoServer를 거치지 않게 한다. 운영 QGIS에서 드론영상 WMS가 타임아웃으로 표시되지 않는 문제를 해결한다.

## 요약

울산은 지금 고른 시스템이 데이터조회여도 우측 드론영상·촬영요청이 항상 보인다. 다른 프로젝트는 드론 시스템일 때만 두 버튼이 나온다. 전날 WMS 레이어 목록을 앱이 직접 만들도록 바꾸면서 일반 레이어도 목록에 넣었으나, 일반 레이어는 WFS로 쓰는 것이 원래 방식이다. WMS 목록에는 읽기 권한이 있는 드론영상만 넣고, 일반 레이어로 지도 이미지를 요청하면 WFS로 추가하라는 안내 오류를 돌려준다. 이로써 WMS는 GeoServer 없이 원본 영상만으로 동작하며, GeoServer 상태나 다른 프로젝트 레이어 설정과 무관해졌다. 접속 키·WFS·WMS 주소 복사는 보안 주소가 아닐 때도 클립보드에 들어가게 바꿨다. 우측 드론영상은 버튼을 켜도 보라색 범위와 사진이 한꺼번에 나오지 않고, 드론영상·사진동영상·항공뷰를 파일 단위로 켜며 종류별 전체 켜기·끄기가 있다.

운영에서는 지도 이미지 요청마다 축소본이 없는 원본 영상 전체를 읽어 QGIS 대기 시간(60초)을 넘겼다. 영상 변환 때 이미 만들어 둔 줌 단계별 타일 중 필요한 몇 장만 이어 붙여 그리도록 바꿔, 영상 전체 범위 요청이 0.3초 안팎으로 응답한다. 타일 최대 줌보다 크게 확대한 경우에만 원본 영상으로 그려 원본 화질을 유지하며, 이때는 좁은 범위만 읽어 빠르다. 타일이 웹 메르카토르 좌표계이므로 목록에는 이 좌표계만 선언하고, 다른 좌표계 프로젝트에서는 QGIS가 재투영해 표시한다. 기존 영상을 다시 변환할 필요는 없다.

## 테스트

1. QGIS WMS 연결 시 레이어 목록에 읽기 권한이 있는 드론영상만 보여야 한다.
2. 목록에 일반 레이어(메모 등)가 보이지 않아야 한다.
3. 드론영상을 추가하고 전체 범위로 보았을 때 타임아웃 없이 영상이 그려져야 한다.
4. 화면을 이동·확대·축소할 때 수 초 안에 영상이 갱신되어야 한다.
5. 아주 크게 확대했을 때 영상이 흐려지지 않고 원본 화질로 보여야 한다.
6. 영상에 타일 경계선이 보이지 않아야 한다.
7. 프로젝트 좌표계가 5186 등이어도 영상이 올바른 위치에 겹쳐 보여야 한다.
8. 일반 레이어 이름으로 WMS 지도 이미지를 요청하면 «WMS는 드론영상 전용입니다» 안내가 나와야 한다.
9. GeoServer가 꺼져 있어도 WMS 목록과 드론영상 표시가 동작해야 한다.
10. QGIS WFS 연결·조회·편집은 이전과 같이 동작해야 한다.

## 테스트

1. 우측 드론영상을 켜면 목록만 열리고, 보라색 범위와 사진 점이 한꺼번에 나오지 않아야 한다.
2. 드론영상은 작업단위로 보이고, 그 작업을 켜면 안의 영상이 지도에 나와야 한다.
3. 범위가 겹친 곳을 누르면 작업이름과 날짜가 줄바꿈되어 구분되어야 한다.
4. 사진,동영상은 작업단위로 보이고, 작업단위를 켜면 그 안의 파일 수만큼 점이 함께 나와야 한다.
5. 항공뷰도 파일 하나만 켜져야 한다.
6. 드론영상·사진,동영상·항공뷰 옆 전체 켜기로 그 종류가 모두 켜지고, 다시 누르면 꺼져야 한다.
7. 목록을 닫아도 이미 켠 레이어는 지도에 남아 있어야 한다.
