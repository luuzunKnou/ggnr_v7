# 결과보고서

## 목적

QGIS WMS 연결을 관리 화면 안내와 같이 드론영상 전용으로 맞추고, WMS 요청이 공용 GeoServer를 거치지 않게 한다. 운영 QGIS에서 드론영상 WMS가 타임아웃으로 표시되지 않는 문제를 해결한다.

## 요약

전날 WMS 레이어 목록을 앱이 직접 만들도록 바꾸면서 일반 레이어도 목록에 넣었으나, 일반 레이어는 WFS로 쓰는 것이 원래 방식이다. WMS 목록에는 읽기 권한이 있는 드론영상만 넣고, 일반 레이어로 지도 이미지를 요청하면 WFS로 추가하라는 안내 오류를 돌려준다. 이로써 WMS는 GeoServer 없이 원본 영상만으로 동작하며, GeoServer 상태나 다른 프로젝트 레이어 설정과 무관해졌다.

운영에서는 지도 이미지 요청마다 축소본이 없는 원본 영상 전체를 읽어 QGIS 대기 시간(60초)을 넘겼다. 영상 변환 때 이미 만들어 둔 줌 단계별 타일 중 필요한 몇 장만 이어 붙여 그리도록 바꿔, 영상 전체 범위 요청이 0.3초 안팎으로 응답한다. 타일 최대 줌보다 크게 확대한 경우에만 원본 영상으로 그려 원본 화질을 유지하며, 이때는 좁은 범위만 읽어 빠르다. 타일이 웹 메르카토르 좌표계이므로 목록에는 이 좌표계만 선언하고, 다른 좌표계 프로젝트에서는 QGIS가 재투영해 표시한다. 기존 영상을 다시 변환할 필요는 없다.

## 파일수정

수정 | src/service/qgisLayerControlService.ts
 `buildWmsCapabilitiesXml` — 일반 레이어 그룹 생성을 빼고 드론영상만 목록에 넣도록 변경. 지원 요청은 목록·지도 이미지(PNG)만 선언
 `loadDefineTableMetaMap` — 일반 레이어 한글명·그룹 조회가 필요 없어져 삭제
 `proxyWmsGet` — 기존에는 드론영상이 아닌 지도 이미지 요청을 GeoServer로 중계했으나, 안내 오류를 반환하도록 변경. 그 밖의 요청은 지원하지 않음 오류로 응답하고 GeoServer 중계 코드 삭제

수정 | src/service/orthoWmsRenderService.ts
 `renderOrthoWmsGetMap` — 기존에는 항상 원본 영상을 잘라 그렸으나, 웹 메르카토르 요청은 타일 합성으로 처리하고 최대 줌보다 확대·타일 없음·타 좌표계일 때만 원본 렌더로 전환
 `renderXyzTilesToPng` — 요청 범위에 걸친 타일을 읽어 정수 픽셀 경계로 캔버스에 배치 후 PNG 반환
 `readXyzZoomInfo` — 타일 폴더의 줌·열 목록을 1분 캐시로 조회
 `buildWmsExtentXml` — 선언 좌표계를 웹 메르카토르 하나로 줄이고 해당 범위만 기재

수정 | src/service/aerialOrthoService.ts
 `resolveOrthoTifAbsPath` — 원본 경로와 함께 타일 폴더 경로를 반환. 원본이 없어도 타일이 있으면 렌더 가능하도록 변경

## 테스트

1. QGIS WMS 연결 시 레이어 목록에 읽기 권한이 있는 드론영상만 보여야 한다.
2. 목록에 일반 레이어(메모 등)가 보이지 않아야 한다.
3. 드론영상을 추가하고 전체 범위로 보았을 때 타임아웃 없이 영상이 그려져야 한다.
4. 화면을 이동·확대·축소할 때 수 초 안에 영상이 갱신되어야 한다.
5. 아주 크게 확대했을 때 영상이 흐려지지 않고 원본 화질로 보여야 한다.
6. 영상에 타일 경계선이 보이지 않아야 한다.
7. 프로젝트 좌표계가 5186 등이어도 영상이 올바른 위치에 겹쳐 보여야 한다.
8. 일반 레이어 이름으로 WMS 지도 이미지를 요청하면 «WMS는 드론영상 전용입니다» 안내가 나와야 한다.
9. GeoServer가 꺼져 있어도 WMS 목록과 드론영상 표시가 동작해야 한다.
10. QGIS WFS 연결·조회·편집은 이전과 같이 동작해야 한다.
