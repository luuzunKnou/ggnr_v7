## 정의 방식 (Tailwind v4 @utility)

- **버전:** tailwindcss 4.1.18
- **파일:** [`standard-utilities.css`](../src/app/standard-utilities.css) — `@utility` 블록으로 등록
- **로드:** [`globals.css`](../src/app/globals.css)에서 `@import "./standard-utilities.css"`
- **섹션 타이틀 기준:** 도로대장 확장 패널 «속성정보» — 12px semibold muted (접·펼 없음·있음 공통)
- **레이어 토글 칩 기준:** 도로대장 확장 패널 문서·레이어 버튼 (`standard-layer-toggle-chip-*`)

## 조합 예

**목록 패널**

- th: `standard-table-th` + `standard-table-th-left` 또는 `standard-table-th-center`
- 필터 칩: `standard-filter-chip` + (선택 시) `standard-filter-chip-active` 또는 `standard-filter-chip-active-[#e63946]`
- 정렬: `standard-sort-button` + left/center + (활성) `standard-sort-button-active`
- 행: `standard-list-row` + (선택) `standard-list-row-selected`
- 상태 뱃지: `standard-status-badge` + `standard-status-badge-primary` / `standard-status-badge-ended`
- 레이어 토글: `standard-layer-toggle-chip` + `active` / `inactive`
- 건수: `standard-list-footer` — `{n}건`

**확장 패널**

- 패널: `standard-panel-root` + `standard-panel-header` (상세 헤더) + `standard-detail-scroll`
- 섹션: `standard-detail-section-title-wrap` («상세 속성») / 접·펼 시 `standard-detail-section-toggle` + chevron + `standard-detail-section-toggle-label`
- 속성: `standard-detail-attr-table` + `standard-detail-attr-label` / `standard-detail-attr-value`
- 필지: `standard-detail-section-block` + `standard-detail-address-list` + card + (선택) `standard-detail-address-card-selected`
