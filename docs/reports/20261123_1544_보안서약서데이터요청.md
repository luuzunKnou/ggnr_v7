2026-11-23 | 200BingSu | 보안서약서·데이터요청 신규 구현

## 목적

SHP 다운로드 시 공통 보안서약서 모달을 띄우고, 동의·접수 후 데이터 요청 목록에서 파일을 내려받도록 한다. 내 정보 공통 메뉴에서 요청 목록·승인 화면으로 진입한다.

## 요약

SHP를 받는 화면(레이어관리·엑셀/SHP 상태·관망·시설)에서 즉시 다운로드 대신 서약 접수 흐름으로 바꿨다. 당분간 요청은 전부 자동승인으로 저장되며, 데이터 요청 페이지에서 검색·상세·다운로드·승인 처리를 할 수 있다. DB 테이블은 스키마 소스만 추가했으며 실제 DB 반영은 별도 적용이 필요하다.

## 테스트

1. 레이어관리에서 SHP를 누르면 보안서약서 모달이 최상단에 열려야 한다.
2. 모달 배경을 눌러도 닫히지 않고, 취소로만 닫혀야 한다.
3. 서약자 미입력 시 동의가 비활성이어야 한다.
4. 서약자를 계정 이름과 다르게 입력하면 안내 후 접수되지 않아야 한다.
5. 서약자 일치 후 동의 시 접수 confirm이 나오고, 예 선택 시 데이터 요청 페이지로 이동해야 한다.
6. 데이터 요청 헤더 뒤로가기는 들어왔던 화면으로 돌아가야 한다.
7. 내 정보 공통란에 데이터 요청이 보이고 목록이 열려야 한다.
8. 자동승인된 요청은 목록에서 다운로드가 가능해야 한다.
9. 관망·시설 SHP도 서약 모달 후 동일하게 접수되어야 한다.
10. DB에 data_request_file 테이블이 없으면 접수·목록이 실패하므로 스키마 적용 후 확인해야 한다.
