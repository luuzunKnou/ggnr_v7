## 목적

상수민원 저장·엑셀에서 저장된 연번 컬럼을 더 이상 다루지 않는다. 관로 통계 수치는 소수점 둘째 자리까지 보이고, 행 이름에서 내용년수는 빼 둔다. 테스트용 레이어 정의는 목록과 파일에서 제거한다. 시스템 목록에 두 번 들어 있던 상수도·하수도 행정 항목은 하나씩만 남긴다. 스타일 수정에서 관리 화면을 열 때 그 요청에 로그인 세션을 실어, 로그인 화면이 반반으로 나오지 않게 한다.

## 요약

스타일 수정에서 관리 화면으로 넘길 때, 브라우저 쿠키 시점 대신 그 화면 요청에 로그인 세션을 실어 로그인 화면이 반반으로 나오던 경우를 막는다. 시스템 목록 끝의 상수도·하수도 행정 중복을 지워 메인 카드가 하나씩만 나오게 했다. 목록과 엑셀의 연번은 작성일로 계산한다. 저장·수정 때 연번을 빼던 처리와, 엑셀에서 저장 연번 열을 빼던 처리를 제거했다. 관로 통계의 연장·비율·평균연령은 소수점 둘째 자리로 맞추고, 관재질 이름 뒤의 내용년수는 잠시 보이지 않게 했다. 레이어 목록의 테스트 레이어와 그에 붙은 필드·지오서버 파일을 삭제했다. 상수도 브랜치를 합치면서 기존 시스템 목록은 유지하고, 메인 차트와 대시보드 등록만 반영했다. 지도 화면은 상수 관망 패널이 두 번 들어가 컴파일이 끊겼고, 한 벌만 남겼다. 상수민원 항목 이름을 실제 컬럼 한글명으로 바꿨다. 하수민원 항목도 같은 방식으로 맞췄다. 급수민원·준설민원·준설대상지 항목도 실제 컬럼으로 바꿨다.
