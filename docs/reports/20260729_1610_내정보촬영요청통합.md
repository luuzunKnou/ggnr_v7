# 결과보고서

2026-07-29 | JungWooojin | 내 정보 패널에 촬영요청 통합

## 목적

사이드바에 두 개로 나뉘어 있던 «내 정보»를 하나로 맞춘다. 드론 촬영요청 목록을 기존 내 정보 패널 탭으로 넣어 자연스럽게 쓰게 한다.

## 요약

별도 촬영요청 내 정보 버튼을 제거하고, 기존 내 정보(프로필·알림) 패널에 «촬영요청» 탭을 추가했다. 행을 누르면 이전과 같이 신청서 모달이 열린다.

## 테스트

1. 사이드바 «내 정보»가 하나만 보여야 한다.
2. 내 정보를 열면 프로필과 «촬영요청»·«알림» 탭이 보여야 한다.
3. 촬영요청 탭에서 내 신청 목록이 나와야 한다.
4. 신청 행을 누르면 패널이 닫히고 신청서 모달이 열려야 한다.
5. 알림 탭·로그아웃은 이전과 같이 동작해야 한다.
6. 읽지 않은 알림 표시(빨간 점·말풍선)는 유지되어야 한다.
