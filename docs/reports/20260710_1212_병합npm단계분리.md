## 목적

소스 업로드 진행 표시에서 «원격 병합/압축 해제»와 «npm install» 메시지·단계를 분리한다.

## 요약

병합 단계 메시지에 npm install 문구가 섞이던 문제를 제거했다. GNMS complete는 병합·압축 해제만 처리하고, npm install은 별도 API로 나눴다. ggnr_v7은 complete 대기 중에는 병합 단계만, 이후 npm install API 대기 중에는 npm 단계만 표시한다.

## 테스트

1. node_modules 미포함 업로드 시 «원격 병합/압축 해제» 문구에 npm install이 포함되지 않아야 한다.
2. 병합 API 대기 중 진행 단계는 complete만 활성, npm install은 대기여야 한다.
3. 병합 완료 후 «npm install 중...» 단계가 별도로 활성화되어야 한다.
4. node_modules 포함 업로드 시 npm install 단계는 생략으로 끝나야 한다.
5. GNMS에 npm-install API가 배포된 상태에서 전체 업로드가 완료되어야 한다.
