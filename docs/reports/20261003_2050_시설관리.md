## 목적

시설관리에 들어가면 관망조회와 같은 상단 밑줄 탭으로 취수장부터 CCTV까지 고를 수 있게 한다.

## 요약

시설관리 빈 패널을 전용 화면으로 바꿨다. 위쪽에 취수장, 정수장, 배수지, 가압장, 감압변, 소방시설, CCTV 탭이 한 줄로 있다. 탭을 바꾸면 아래 안내 문구만 바뀌고, 목록·상세는 다음에 넣는다.

## 파일수정

추가 | src/app/(pages)/map/_mapContents/wtlAdmin/facility/WtlFacilityShell.tsx
 `FACILITY_TABS` — 취수장, 정수장, 배수지, 가압장, 감압변, 소방시설, CCTV
 `WtlFacilityShell` — 시설관리 패널. 관망조회와 같은 밑줄 탭으로 종류를 고름
 `tab` — 고른 탭 이름을 본문에 안내. 목록은 아직 없음

수정 | src/app/(pages)/map/_mapContents/wtlAdmin/WtlAdminEmpty.shell.tsx
 `WtlFacilityShell` — 시설관리 메뉴일 때 전용 화면으로 연결

해당 없음

## 테스트

1. 사이드바에서 시설관리를 누르면 시설관리 패널이 열려야 한다.
2. 위쪽에 취수장, 정수장, 배수지, 가압장, 감압변, 소방시설, CCTV 탭이 보여야 한다.
3. 탭은 아이콘 없이 밑줄로 선택되어야 한다.
4. 정수장을 누르면 선택 표시가 바뀌고 아래에 정수장 안내가 나와야 한다.
5. CCTV를 눌러도 같은 방식으로 안내가 바뀌어야 한다.
6. 닫기를 누르면 시설관리 패널이 사라져야 한다.
