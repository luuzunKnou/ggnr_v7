## 목적
공사대장 상세 패널에 «도형 수정/그리기»와 «수정»이 완전히 분리된 두 모드로 있어, 속성과 도형을 동시에 고치려면 저장·취소를 두 번 거쳐야 했다. 도로망도는 «수정» 진입 시 속성·도형 편집을 함께 시작해 저장/취소가 한 번에 처리되므로, 같은 패턴으로 통합한다.

## 요약
헤더의 «도형 수정/그리기» 버튼을 없애고, «수정»을 누르면 속성 입력과 함께 지도 도형 편집(신규는 그리기, 기존 도형은 정점 수정)이 자동으로 시작되도록 했다. «저장»은 속성+도형을 함께 반영하고 편집을 종료하며, «취소»는 속성과 도형을 편집 시작 시점 상태로 함께 되돌린다. 편집 중에는 도형 아래 안내줄에 «다시 그리기»·«도형 삭제» 버튼을 둬 기존에 두 버튼이 하던 역할(새로 그리기, 삭제)을 그대로 편집 세션 안에서 처리할 수 있게 했다.

 `beginEdit` — «수정» 클릭 시 속성 draft 초기화 + `beginGeomSession` 호출로 도형 편집 동시 시작. 기존 별도 «도형 수정/그리기» 버튼·핸들러 대체

 `handleSave` — 속성 저장 후 도형 편집 세션도 함께 종료(도형은 그리기·수정 중 실시간 반영이라 별도 커밋 불필요)
 `handleCancel` — 속성 되돌리기와 함께 도형도 편집 시작 시점 스냅샷으로 복원 후 세션 종료
 신규 공사 진입 시 자동 편집 — `row.id` 전환 useEffect에서 신규 행이면 속성 편집과 동시에 도형 그리기/수정도 자동 시작(도로망도 신규 도로 패턴과 동일)
 헤더 버튼 — 비편집 시 «수정»·«삭제» 2개로 축소(«도형 수정/그리기» 제거), 편집 시 «저장»·«취소» 유지
 편집 안내줄 — 도형 모드별 안내 문구 + «다시 그리기»(그리기 중엔 비활성)·«도형 삭제»(도형 있을 때만) 버튼 추가

## 테스트

1. 목록에서 기존 공사대장을 열고 «수정»을 누르면 속성 입력칸과 함께 지도에 정점 수정 도형이 바로 나와야 한다.
2. 신규 공사대장을 추가하면 속성 편집과 지도 도형 그리기가 함께 시작돼야 한다.
3. 편집 중 «다시 그리기»를 누르면(기존 도형 있으면 확인 후) 도형이 지워지고 새로 그릴 수 있어야 한다.
4. 편집 중 «도형 삭제»를 누르면 확인 후 도형 없이 저장할 수 있어야 한다.
5. 편집 중 속성만 고치고 «저장»을 누르면 도형은 그대로 유지되고 속성만 반영돼야 한다.
6. 편집 중 도형 정점을 옮긴 뒤 «취소»를 누르면 도형이 편집 시작 전 상태로 되돌아가야 한다.
7. 헤더에 «도형 수정»·«도형 그리기» 버튼이 더 이상 보이지 않아야 한다.
8. 첨부파일 탭·하천 관리 팝오버는 편집 여부와 무관하게 기존처럼 동작해야 한다(회귀 없음).
