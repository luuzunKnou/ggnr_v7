# 결과보고서

2026-07-21 | gyujin | 유지보수·민원 현장 위치를 도로 도형과 동일 배너 방식으로 통일

## 목적

유지보수·민원 편집 시 패널의 «위치 지정·보기·지우기» 버튼을 없애고, 도로 노선 수정과 같은 지도 플로팅 배너로 현장 점을 지정·초기화·삭제한다.

## 요약

시트에는 현장 주소만 표시하고, 위치 조작은 지도 중앙 배너(도형추가·초기화·도형삭제)만 사용한다. 편집 진입 시 바로 점찍기 세션이 열리며, 초기화는 열었을 때 위치로 되돌린다.

## 테스트

1. 유지보수 추가 시 지도에 도형추가·도형삭제 배너가 보이고, 지도 클릭으로 현장 점이 찍혀야 한다.
2. 점이 있는 민원을 열면 초기화 버튼이 보이고, 위치 변경 후 초기화 시 원래 점·주소로 돌아와야 한다.
3. 도형삭제로 점을 지운 뒤 다시 지도에서 찍을 수 있어야 한다.
4. 시트에는 현장 주소만 보이고 위치 지정·보기·지우기 버튼은 없어야 한다.
5. 속성 «수정» 중 도형 배너와 현장 배너가 동시에 뜨지 않아야 한다.
6. 저장·닫기 후 지도 배너와 점찍기가 사라져야 한다.
