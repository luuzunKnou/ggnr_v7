# 결과보고서

2026-11-25 | JungWooojin | 사이드바 묶음 다중 펼침·선택 표시

## 목적

지도 사이드바 기능 묶음이 한 번에 하나만 펼쳐지던 동작을, 여러 묶음을 동시에 내릴 수 있게 바꾸고, 열린 항목·개폐 상태가 눈에 띄게 구분되도록 한다.

## 요약

묶음 펼침을 여러 개 동시에 유지한다. 묶음 헤더는 라벨 아래 원형 화살표로 개폐를 표시하고, 펼친 목록에서 선택한 하위 기능은 밝은 배경·왼쪽 강조선으로 표시한다.

## 파일수정

수정 | src/app/(pages)/map/_mapComponents/map-sidebar.tsx
 `openGroupCats` — 단일 카테고리 대신 배열로 펼침 목록 관리. 그룹 클릭 시 포함/제외 토글, 여러 묶음 동시 펼침. 기능 선택 시에는 묶음을 닫지 않음
 `SidebarButton` — 묶음 헤더 라벨 아래 원형 개폐 힌트. 하위 선택 시 배경·왼쪽 강조선 표시

해당 없음

## 테스트

1. 사이드바에서 묶음 A를 펼친 뒤 묶음 B를 펼치면 A·B가 모두 열린 채로 남아야 한다.
2. 열린 묶음을 다시 클릭하면 해당 묶음만 접혀야 한다.
3. 펼친 묶음 안 기능을 선택해도 다른 펼친 묶음이 닫히지 않아야 한다.
4. Esc 또는 시스템 전환 시 펼쳐진 묶음이 모두 접혀야 한다.
5. 묶음 안 기능을 선택하면 해당 항목만 밝게·왼쪽 강조선으로 표시되어야 한다.
6. 묶음 헤더 라벨 아래 원형 화살표로 열림/접힘이 구분되어야 한다.
