# 결과보고서

2026-07-22 | gyujin | 소하천 탭을 소하천기본계획 테이블 기준으로 조회

## 목적

하천 기본계획 소하천 탭이 유형 문자열 필터 대신 소하천 전용 기본계획 테이블을 조회하도록 바꿔, 데이터가 있는 소하천 목록이 정상 표시되게 한다.

## 요약

소하천 탭은 소하천기본계획·색인도·종단·횡단·시설물 전용 레이어로 조회·표시한다. 지방하천 탭은 기존 지방 하천 테이블을 그대로 쓴다. 지도에서 소하천 색인도를 눌러도 소하천 탭으로 맞춰진다.

## 테스트

1. 소하천 탭에서 소하천기본계획 하천 목록이 보여야 한다.
2. 지방하천 탭과 소하천 탭 목록이 서로 섞이지 않아야 한다.
3. 소하천 하천 선택 시 상세 패널과 지도 이동이 되어야 한다.
4. 소하천 선택 시 소하천 색인도·기본계획 레이어가 켜져야 한다.
5. 지방하천으로 탭을 바꾸면 소하천 전용 레이어가 꺼지고 지방 레이어가 켜져야 한다.
6. 소하천 색인도를 지도에서 클릭하면 소하천 탭·해당 하천 상세로 열려야 한다.
7. 지방하천 기존 목록·상세·색인도 동작이 그대로여야 한다.
