## 목적

공사대장 상세에서 공사구간 도형을 하나만 그릴 수 있어, 공사구간이 여러 구역으로 나뉜 경우를 표현할 수 없었다. 도형을 여러 개 추가·수정할 수 있도록 개선한다.

## 요약

공사대장 도형 데이터를 단일 폴리곤에서 다중 폴리곤 구조로 변경했다. 「도형추가」 버튼을 누르면 기존 도형을 지우지 않고 새 폴리곤 하나를 추가로 그리며, 그린 뒤에는 기존 도형과 함께 정점 수정 모드로 전환돼 모든 도형을 한 화면에서 같이 수정할 수 있다. 지도 표시·강조·공간검색(도형필터)도 다중 폴리곤을 그대로 처리하도록 맞췄다. 「도형삭제」는 기존과 동일하게 전체 도형을 지운다(개별 도형 단위 삭제는 이번 범위에 포함하지 않음).

## 테스트

1. 공사대장 상세에서 「도형추가」로 폴리곤 1개를 그린 뒤 다시 「도형추가」를 눌러 폴리곤을 하나 더 그리면 두 도형 모두 지도에 남아있어야 한다.
2. 정점 수정 모드에서 기존에 그린 여러 폴리곤의 정점을 각각 드래그해 모양을 바꿀 수 있어야 한다.
3. 「초기화」를 누르면 편집 시작 시점의 모든 도형(여러 개 포함)으로 되돌아가야 한다.
4. 「도형삭제」를 누르면 그려둔 도형이 전부 지도에서 사라지고 저장 시 도형 없이 저장돼야 한다.
5. 저장 후 상세를 다시 열면 여러 개로 그렸던 도형이 모두 지도에 그대로 표시돼야 한다.
6. 목록에서 지도 영역(도형) 검색 필터를 적용했을 때 다중 도형으로 저장된 공사대장 행도 겹치면 정상적으로 목록에 나와야 한다.
7. 도로망도·필지분석 등 다른 지도 기능의 도형 편집·강조 동작이 이번 수정으로 영향받지 않아야 한다.
