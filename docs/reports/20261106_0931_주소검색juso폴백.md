# 결과보고서

2026-11-06 | gyujin | 지도 상단 주소검색 VWorld 실패 시 도로명주소 API 폴백

## 목적

지도 상단 주소 검색에서 브이월드 요청이 실패할 때 행정안전부 도로명주소 검색 API로 대체해, 외부 장애 시에도 주소 결과와 지도 이동이 가능하도록 한다.

## 요약

주소 검색은 기존처럼 브이월드 서버 프록시·JSONP를 우선 쓰고, 업스트림 오류(HTTP 실패·ERROR 응답·JSONP 실패)일 때만 도로명주소 검색 API로 폴백한다. 폴백은 서버 프록시로 호출하며, 좌표는 좌표제공 API → 브이월드 좌표 조회 → OSM 순으로 보강해 선택 시 지도 이동이 되게 했다. 장소(POI) 검색은 도로명주소 API 범위 밖이라 기존과 같다. 검색 API 승인키는 공용 runtime에 넣었고, 좌표제공 API 키는 별도 발급이 필요하다.

## 파일수정

추가 | src/lib/jusoAddrLink.ts
 `searchJusoAddress` — 도로명주소 검색 API 호출 후 좌표제공 API·브이월드·OSM 순으로 WGS84 좌표를 붙여 검색 결과 형태로 반환
 `fetchCoordFromNominatim` — 좌표 API·브이월드 실패 시 OSM으로 좌표 보강(괄호 주소 정규화)

추가 | src/app/api/juso/search/route.ts
 `GET` — 키워드·건수로 서버에서 도로명주소 검색을 대행. 승인키 없으면 서비스 불가 응답

수정 | src/app/(pages)/map/_mapComponents/addressSearch/vworldAddressSearch.ts
 `searchAddress` — 도로명·지번 병합 결과가 없고 업스트림 실패일 때 도로명주소 폴백 1회
 `searchAddressViaProxy` — 정상은 성공·결과없음만, 그 외 상태는 실패로 분류해 폴백 유도
 `searchAddressViaJuso` — 서버 폴백 호출. 동일 검색어 중복 요청 방지

수정 | src/service/configService.ts
 `getMapConfig` — 도로명주소 검색·좌표 승인키 필드 추가

수정 | src/config/projects/common.runtime.env
 `JUSO_CONFM_KEY` — 검색 API 승인키 설정
 `JUSO_COORD_CONFM_KEY` — 좌표제공 API 키 슬롯(미발급 시 비움)

## 테스트

1. 브이월드가 정상일 때 기존과 같이 주소·장소 결과가 나와야 한다.
2. 브이월드 검색이 실패하고 도로명주소 승인키가 있으면 주소 결과가 나와야 한다.
3. 폴백 결과 항목을 선택하면 해당 위치로 지도가 이동해야 한다.
4. 도로명주소 승인키가 비어 있으면 폴백 없이도 앱이 깨지지 않고 빈 결과만 나와야 한다.
5. 장소 검색은 브이월드만 사용하며 폴백과 섞이지 않아야 한다.
6. 메모·민원 등에서 쓰는 동일 주소검색 패널도 주소 검색 실패 시 같은 폴백을 타야 한다.
7. 브이월드 장애 시에도 «세종대로 110» 검색 시 시청 주소와 좌표가 나와야 한다.
