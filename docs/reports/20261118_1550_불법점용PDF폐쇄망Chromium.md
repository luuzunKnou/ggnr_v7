# 결과보고서

2026-11-18 | dev.strcat | 운영 PDF Code 1002 · 폐쇄망 Chromium

## 목적

운영(폐쇄망)에서 관리카드 PDF 저장 시 서버 Chrome 기동이 실패하는 문제를, 인터넷 없이 로컬 Chromium만으로 돌릴 수 있게 맞춘다.

## 요약

PDF는 계속 서버에서 인쇄 엔진으로 만든다. 런타임 인터넷은 쓰지 않는다. 배포 폴더의 Chromium·환경변수 경로를 먼저 찾고, 서버 GPU 기동 실패에 맞춰 실행 옵션을 보강했다. 바이너리는 저장소에 넣지 않고 반입 절차만 안내한다.

## 테스트

1. 인터넷 되는 PC에서 Windows용 Chrome for Testing을 받아 tools/chromium/chrome-win64 에 두면 경로가 잡혀야 한다.
2. CHROME_PATH를 그 chrome.exe로 두면 시스템 Chrome보다 먼저 쓰여야 한다.
3. 서버에서 같은 계정으로 headless dump-dom 이 되면 PDF 단건 저장이 alert 없이 받아져야 한다.
4. Chromium이 없을 때 안내 메시지에 시도 경로가 보여야 한다.
5. 전체 PDF 저장이 기존처럼 동작해야 한다.
6. 메모·민원 등 다른 지도 기능은 영향 없어야 한다.
