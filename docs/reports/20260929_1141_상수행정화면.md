## 목적

상수도 행정에 관망부터 업무편람까지 세부 메뉴와 예시 화면을 붙여, 저장 없이 화면 구성을 보게 한다.

## 요약

사이드바에 여덟 업무를 두었다. 누르면 왼쪽 메뉴와 오른쪽 예시 화면이 열린다. 목록·상세·등록·지도 범위 설명은 화면에서만 동작하고 서버에는 저장하지 않는다. 데이터조회·변동이력분석·필지분석·메모·도형편집기는 아래에 그대로 두었다.

## 테스트

1. 상수도 행정에서 관망조회·시설조회·공사대장·급수공사·민원관리·작업현장·통계보고서·업무편람이 보여야 한다.
2. 관망조회를 누르면 관망도 보기 화면이 열려야 한다.
3. 왼쪽에서 시설물 검색을 누르면 조건과 결과 표가 나와야 한다.
4. 시설 상세에서 기본정보·설비 목록·설비 상세 탭이 바뀌어야 한다.
5. 등록 후 저장을 눌러도 서버 자료는 변하지 않아야 한다.
6. 데이터조회·필지분석·메모·도형편집기는 이전과 같아야 한다.
7. 목록·상세 여백, 검색, 표, 닫기는 다른 지도 조회 화면과 같아야 한다.

## 추가

넓은 별도 화면을 빼고, 기존 조회 목록과 상세 패널 구성으로 바꿨다. 세부 메뉴는 목록 위 선택 목록과 필터로 고른다.
