# 결과보고서

2026-08-14 | dev.strcat | 기초구간 라벨 표시 개선

## 목적

기초구간 지도 라벨을 소수 없이 정수로 보이게 하고, 글씨 휨을 줄이며, 중간 확대에서는 선만·더 확대했을 때만 숫자가 나오게 맞춘다.

## 요약

라벨 숫자 형식을 정수로 바꿨고, 선 따라 과도하게 휘던 허용각을 줄였다. 라벨 축척은 한때 중간 확대까지 열었다가, 원래처럼 더 확대한 뒤(축척 2000 이하)에만 숫자가 보이도록 되돌렸다. 중간 확대는 선만, 추가 확대 시 정수 라벨이 나타난다.

## 파일수정

수정 | geoserver_modules/data_dir/styles/tl_sprd_intrvl.sld
 `numberFormat` — `0.00` → `0` (예: 64, 5-4)
 `maxAngleDelta` — 120→35. 선 따라 과도하게 휘던 라벨 완화
 `goodnessOfFit`·`partials`·`maxDisplacement` — 곡선·충돌로 라벨이 통째 빠지는 경우 완화
 글씨 크기 Categorize — 표시 축척 안에서 크기 0으로 꺼지던 구간 제거
 라벨 Rule `MaxScaleDenominator` — 최종 2000 유지. 중간 확대 미표시, 추가 확대 시 표시

## 테이블 수정

해당 없음

## 테스트

1. 기초구간 라벨이 64.00이 아니라 64처럼 정수로 보여야 한다.
2. 구간 표기가 5.00-4.00이 아니라 5-4처럼 보여야 한다.
3. 중간 확대에서는 기초구간 선만 보이고 숫자는 거의 없어야 한다.
4. 더 확대하면 정수 라벨이 보여야 한다.
5. 곡선 구간에서 글씨가 이전보다 덜 휘어야 한다.
6. GeoServer가 이 data_dir를 쓰면 스타일 반영(필요 시 재로드·캐시 삭제) 후 확인한다.
