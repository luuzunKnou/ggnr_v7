# 결과보고서

2026-10-22 | gyujin | 설치파일 파이썬 환경 분할 압축 캐시

## 목적

시연용 설치파일을 만들 때마다 파이썬 환경을 처음부터 나누어 압축하느라 오래 걸리던 것을 줄인다. 환경이 같으면 지난 분할본을 그대로 넣고, 패키지가 바뀐 뒤에만 다시 압축한다.

## 요약

설치파일에는 파이썬 분할본이 계속 들어간다. 다만 같은 환경이면 압축·분할을 건너뛰고 저장해 둔 조각을 쓴다. 시연을 새 폴더에 풀어도 복원은 이전과 같다. 영향 받는 기능: 설치파일 다운로드.

## 파일수정

수정 | src/service/pythonEnvSplitZip.ts
 `createPythonEnvSplitParts` — 기존에는 호출마다 압축·분할했다. 환경 파일 목록·크기·시각 지문이 같으면 저장본을 쓰고, 다르면 압축·분할한 뒤 저장본을 갈아끼운다. 컴파일 캐시 파일은 지문에서 빼 실행만으로 캐시가 깨지지 않게 했다
 `onStatus` — 저장본 사용·다시 압축을 진행 안내에 넘긴다. 저장본을 쓴 경우에는 임시 폴더를 만들지 않아 설치파일 정리 때 지워지지 않는다

수정 | src/service/sourceInstallZipService.ts
 `buildInstallZip` — 확인 중 → 저장본 사용 또는 분할 압축 중으로 안내를 나눈다
 `purgeStaleInstallTemps` — 이전 임시 분할 폴더만 지우고, 파이썬 분할 저장본은 남긴다

## 테스트

1. 파이썬 환경 포함을 켠 채 설치파일을 만들면 처음에는 분할 압축이 진행되어야 한다.
2. 환경을 바꾸지 않고 바로 다시 만들면 분할 압축을 다시 하지 않아야 한다.
3. 두 번째 진행 안내에 저장된 분할본을 쓴다는 문구가 나와야 한다.
4. 설치파일을 새 폴더에 풀고 시작하면 파이썬 환경이 복원되어야 한다.
5. 파이썬 패키지를 설치·삭제한 뒤에는 다시 분할 압축되어야 한다.
6. 포함을 끄면 분할본이 들어가지 않아야 한다.
7. 소스코드 업로드는 이전처럼 파이썬 환경을 넣지 않아야 한다.
