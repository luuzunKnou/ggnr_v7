# 결과보고서

2026-10-15 | luuzunKnou | 단수구역 분석결과저장·도형편집

## 목적

잠금 미리보기를 «분석결과저장»으로 이력에 남기고, 저장 후 단수 면을 기존 수정·읍면동리·직접그리기로 다듬을 수 있게 한다.

## 요약

«분석실행»을 «분석결과저장»으로 바꿨다. 저장 후에만 도형편집이 열리며, 기존 도형 꼭짓점 수정·행정경계 선택·지도 직접그리기 세 가지로 단수 면을 바꾸고 수용가 목록을 다시 채운다. 새 분석은 잠금부터 초기화한다.

영향 받는 기능: 공간분석(단수구역). 행정경계 조회는 기존 분석영역 공용 도구 재사용.

## 테스트

1. 제수변 잠금 후 «분석결과저장»이 활성화되어야 한다.
2. 저장 전 «도형편집»은 안내만 보이고 편집이 불가해야 한다.
3. 저장 후 기존 수정으로 꼭짓점을 옮겨 «도형 적용»하면 단수 면이 바뀌어야 한다.
4. 읍면동리 선택 적용 시 단수 면이 행정경계로 바뀌어야 한다.
5. 직접그리기로 다각형을 그려 적용하면 단수 면이 바뀌어야 한다.
6. 도형 적용 후 수용가 건수가 새 면에 맞게 갱신되어야 한다.
7. «새 분석» 시 잠금·결과·도형편집이 초기화되어야 한다.
