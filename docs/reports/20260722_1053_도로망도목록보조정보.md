## 목적

기점·종점(군도·농도), 국가지원지방도(지방도), 입체교차로(국도)를 상세 속성정보뿐 아니라 목록에서 바로 볼 수 있게 한다.

## 요약

이전 작업에서 상세 패널 속성정보에만 넣었던 데이터를, 목록 각 행 이름 아래 보조 줄로 추가 노출했다. 도로를 열지 않고도 목록에서 바로 확인 가능하다.

해당 없음

## 테스트

1. 군도·농도 목록 행에 «기점 → 종점»이 이름 아래 보여야 한다.
2. 국가지원지방도로 지정된 지방도 행에 «국가지원지방도 · 지정번호»가 보여야 한다.
3. 입체교차로가 있는 국도 행에 «입체교차로 N건 · 명칭»이 보여야 한다.
4. 해당 정보가 없는 도로(일반도로·임도, 미지정 지방도 등)는 보조 줄이 없어야 한다.
5. 보조 줄이 길어도 말줄임되고 행 높이가 과도하게 늘어나지 않아야 한다.
