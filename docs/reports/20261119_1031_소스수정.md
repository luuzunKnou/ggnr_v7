# 결과보고서

2026-11-19 | gyujin | 주소검색 클라이언트 직접 호출

## 목적

운영 서버가 폐쇄망이라도 주무관 PC 개방망에서 주소검색·건축·인허가·실거래가·필지분석 포털·ITS CCTV·통행타일 조회가 되도록, 서버 아웃바운드 대신 브라우저 직접 호출로 바꾼다.

## 요약

지도 주소검색의 브이월드는 JSONP만 쓰고 `/api/vworld/search`를 거치지 않는다. 도로명주소·건축물대장·인허가·실거래가(RTMS)·필지분석 건축물대장 포털 폴백도 PC에서 `apis.data.go.kr` 등을 직접 친다. ITS CCTV·실시간 통행 타일도 `/api/its/*` 대신 `openapi.its.go.kr`·`its.go.kr`를 PC에서 직접 친다. 생활안전지도 WMS는 기존부터 클라이언트. 세움·행정경계(DB)·연계 적재는 서버 유지. 키는 설정 조회로 받는다.

## 테스트

1. 지도 주소검색에 «안동시 퇴계로 115»를 넣으면 도로명·지번 후보가 나와야 한다.
2. 네트워크에서 주소검색 시 `api.vworld.kr` 스크립트(JSONP) 요청이 보여야 하고, `/api/vworld/search`는 주소검색 경로로 호출되지 않아야 한다.
3. 브이월드 키가 없거나 JSONP가 실패하면 도로명주소(`business.juso.go.kr`) 직접 호출로 후보가 나와야 한다.
4. 도로명 폴백 시 `/api/juso/search`를 거치지 않아야 한다.
5. 장소(POI) 검색도 브이월드 JSONP로 결과가 나와야 한다.
6. 개발 서버에서 기존처럼 주소 선택 후 지도 이동이 되어야 한다.
7. 필지정보에서 세움에 없는 필지의 건축물대장 조회 시 네트워크에 `apis.data.go.kr` 요청이 보여야 하고, `/api/public-data/building`은 호출되지 않아야 한다.
8. 건축인허가 탭도 세움 없을 때 `apis.data.go.kr` 건축·주택인허가 API를 직접 호출해야 한다.
9. 공공데이터포털이 일시 타임아웃이면 «연결이 불안정합니다» 안내가 나와야 한다.
10. 세움 DB에 데이터가 있는 필지는 기존처럼 세움 결과가 우선 표시되어야 한다.
11. 실거래가 목록·상세·지도 색칠 시 네트워크에 RTMS(`apis.data.go.kr` …LandTrade) 요청이 보여야 하고, 실거래 서버 액션으로 포털을 치지 않아야 한다.
12. 필지분석에서 세움에 건축물이 없으면 브라우저가 포털 건축물대장을 직접 호출해야 한다.
13. 필지분석에서 세움에 건축물이 있으면 포털 요청 없이 세움 결과만 나와야 한다.
14. 도로 CCTV 조회 시 네트워크에 `openapi.its.go.kr` 요청이 보여야 하고, `/api/its/cctv`는 호출되지 않아야 한다.
15. 실시간 통행 타일 표시 시 `its.go.kr` WMTS 요청이 보여야 하고, `/api/its/traffic-tile`은 호출되지 않아야 한다.
16. 생활안전지도 WMS는 기존처럼 `safemap.go.kr`로 표시되어야 한다.
