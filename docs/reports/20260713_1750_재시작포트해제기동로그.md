# 결과보고서

2026-07-13 | 200BingSu | 재시작 포트 해제·기동 로그

## 목적

명령 실행·감시 재시작 때 앱 포트가 비워졌는지·같은 포트로 다시 뜨는지 콘솔에서 확인할 수 있게 한다.

## 요약

재시작 전후 포트(기본 3000 또는 PORT) LISTENING 여부를 로그로 남기고, 자식 창은 포트가 빌 때까지 기다린 뒤 기동한다. «node --watch» 라디오는 이 작업에 포함하지 않았다.

## 파일수정

수정 | src/service/sourceVersionService.ts
 `getAppListenPort` — PORT env 또는 3000
 `spawnDelayedRestartCommand` — 런처 스크립트에 포트 대기·FREE/BUSY 로그 후 동일 포트로 명령 실행
 `scheduleRestart` — 종료·포트 해제 console 로그

수정 | scripts/restart-watch.ps1
 `Wait-AppPortFree` / `Test-AppPortListening` — 기동 전·종료 후 포트 상태 로그, 재기동 전 포트 해제 대기

## 테이블 수정

해당 없음

## 테스트

1. 명령 실행 재시작 시 부모 콘솔에 포트 번호·해제 로그가 나와야 한다.
2. 자식 창에 포트 FREE 대기 후 기동 로그가 나와야 한다.
3. 감시 스크립트 exit 재시작 시 종료 후 포트 해제·재기동 전 FREE 로그가 나와야 한다.
4. 재기동 후 앱이 이전과 같은 포트로 열려야 한다.
