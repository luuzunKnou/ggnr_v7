2026-11-27 | 200BingSu | 시스템 불편신고 기능 입력란

## 목적

시스템 불편신고 작성 화면의 «기능»을 목록 선택만 되는 형태에서, 직접 입력과 목록 선택이 모두 되도록 바꾼다. 기능·작성자 입력란은 한 줄로 나란히 배치한다.

## 요약

기능 칸을 텍스트 입력으로 바꾸고, 포커스·입력 시 등록된 기능명 목록에서 고를 수 있게 했다. 목록에 없는 문구도 그대로 제출되며, 목록과 일치하면 기존처럼 기능 영문·한글 키가 함께 저장된다. 기능·작성자는 가로 flex로 한 줄에 둔다.

## 테스트

1. 불편신고 작성에서 기능 칸에 직접 글자를 입력할 수 있어야 한다.
2. 기능 칸 포커스 시 등록된 기능 목록이 보여야 한다.
3. 목록에서 기능을 고르면 해당 이름이 입력란에 들어가야 한다.
4. 목록에 없는 문구를 입력해도 제출·목록에 그 문구가 보여야 한다.
5. 목록에서 고른 뒤 제출하면 목록·상세에 기능명이 정상 표시되어야 한다.
6. 제출 건 조회 시 기능 칸은 수정할 수 없어야 한다.
7. 기능 칸을 비운 채 제출하면 목록에 «선택 없음»으로 보여야 한다.
8. 작성 화면에서 기능·작성자가 한 줄에 나란히 보여야 한다.
