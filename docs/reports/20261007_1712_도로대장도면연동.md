# 결과보고서

2026-10-07 | dev.strcat | 경산 도로대장 레이어 업데이트

## 목적

도로대장 상세의 «매설물도·종평면도·용지도» 버튼에 경산 도면 구역 레이어를 연결해, 노선별 도면 목록과 첨부 도면·속성을 상세 패널에서 바로 보게 한다.

## 요약

세 버튼이 도면 레이어와 연결되어 레이어가 있으면 활성화된다. 도면 버튼과 탭에는 건수를 표시하지 않는다. 버튼을 켜면 지도에 도면 구역이 나오고, 아래 시설 탭 줄에 도면 탭이 추가된다.

도면 탭은 안전점검 점검진단 목록처럼 표로 보이며, 열은 레이어 관리의 목록 보기 설정 항목을 순서대로 쓰고 12건씩 넘겨 본다. 행을 고르면 지도가 그 구역으로 이동·강조하고, 상세 화면이 노선 속성정보와 도면 목록 전체를 덮는다. 구성은 하천 색인도 상세와 같아 구분선 아래 «종평면도» 제목과 목록으로 버튼, 색인도와 같은 틀에 흰 여백·얇은 테두리를 둔 도면 미리보기(잘림 없이 전체 표시), 그 아래 속성정보 순이다. 목록·속성표는 노선 속성정보와 같은 회색 계열로 맞췄고, 목록은 탭 영역 아래까지 꽉 차게 늘렸다. 첨부파일 목록은 미리보기로 대신해 두지 않았다. 목록으로 버튼을 누르면 목록으로 돌아오며 선택이 풀린다. 미리보기를 누르면 이미지·PDF를 전체화면으로 넘겨 본다. 지도에서 도면 구역을 클릭해도 같은 상세가 열린다.

하단 탭 영역은 상세 패널의 남은 높이를 꽉 채우도록 늘렸다.

레이어 관리의 키는 ogc_fid로 두고, 첨부는 이와 별개로 분할코드(cons_code) 폴더에서 읽는다. 목록의 분할코드 열도 같은 값을 쓴다. 속성 항목명·상세 표시·순서는 레이어 관리 설정을 따른다. 윈도우 썸네일 캐시 같은 시스템 파일은 첨부 목록에서 숨긴다.

도로시설물 메뉴의 레이어 그룹과 데이터조회의 시설 목록 열 제한에는 도면 레이어가 섞이지 않도록 시설 목록과 분리했다.

영향 받는 기능: 도로대장 시설 버튼·건수·시설 탭 목록, 시설 속성 팝업, 지도 클릭 시설 식별, 도로시설물 메뉴, 데이터조회 시설 목록 열.

## 테스트

1. 경산 도로대장에서 자인-용성 상세를 열면 «매설물도·종평면도·용지도» 버튼이 건수 없이 활성화되어야 한다.
2. «용지도»를 누르면 지도에 용지도 구역이 켜지고 아래에 «용지도» 탭과 레이어 관리 목록 보기 항목으로 된 표 목록이 나와야 한다.
3. 목록 아래 이전·다음 버튼이 항상 보이고, 12건을 넘으면 페이지를 넘길 수 있어야 한다.
4. 행을 고르면 행이 강조되고 지도가 해당 구역으로 이동해 강조되어야 한다.
5. 상세가 노선 속성정보와 도면 목록을 덮고, 도면 미리보기 아래 속성정보가 나와야 한다.
6. 상세 속성표 색상이 노선 속성정보 표와 같아야 하고 첨부파일 목록은 보이지 않아야 한다.
7. 미리보기를 누르면 전체화면 미리보기가 열려야 한다.
8. 상세 오른쪽 위 «‹» 버튼을 누르면 목록 화면으로 돌아오고 지도 강조가 해제되어야 한다.
9. 지도에서 도면 구역을 클릭하면 팝업 없이 해당 도면 탭·행이 선택되고 상세가 열려야 한다.
10. 하단 탭 영역이 상세 패널 아래 끝까지 채워져야 한다.
11. 주요시설~기타시설 탭은 기존처럼 표 목록과 속성 팝업으로 동작하고 버튼 건수도 그대로여야 한다.
12. 도로시설물 메뉴에 도면 그룹이 새로 생기지 않아야 한다.
