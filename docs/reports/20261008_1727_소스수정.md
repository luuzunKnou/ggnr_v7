# 결과보고서

2026-10-08 | gyujin | 시스템 상세 서비스 목록 순서 변경

## 목적
시스템 상세에서 서비스 사이드바 순서를 화면에서 바로 바꿀 수 있게 한다.

## 요약
기존 서비스 선택은 체크박스 방식이라 체크하면 맨 뒤에 붙기만 해서, 순서를 바꾸려면 전부 해제 후 다시 체크하거나 설정 파일을 직접 고쳐야 했다. 레이어 그룹과 같은 좌우 이동 화면으로 바꾸고, 오른쪽 «이 시스템» 목록에 순번과 위·아래 버튼을 두어 저장 시 그 순서가 사이드바 순서가 되도록 했다.

## 파일수정
수정 | src/app/(pages)/dev/_components/SystemListManager.tsx
 `ServiceTransferPick` — 좌측 추가 가능한 서비스(비공개만 필터·검색), 우측 이 시스템 서비스(순번 표시). 화살표·더블클릭으로 추가 시 맨 뒤에 붙고 빼기 가능
 `moveOrder` — 우측에서 선택한 서비스(여러 개 가능)를 한 칸씩 위·아래로 이동, 선택 항목끼리 상대 순서 유지. 맨 위·맨 아래면 버튼 비활성
 `CheckboxMultiPick` — 서비스 선택 전용이던 체크박스 팝업 선택 제거, 미사용 import 정리
 `ServiceMultiPick` — 좌우 이동 방식으로 대체되어 제거

## 테스트

1. 시스템 상세 서비스 목록이 좌우 두 목록과 가운데 화살표로 표시되어야 한다.
2. 왼쪽에서 서비스를 골라 오른쪽으로 옮기면 오른쪽 맨 뒤에 추가되어야 한다.
3. 오른쪽에서 서비스를 골라 위·아래 버튼을 누르면 한 칸씩 순서가 바뀌고 순번이 갱신되어야 한다.
4. 여러 개를 함께 골라 위·아래로 옮겨도 서로의 순서가 유지되어야 한다.
5. 맨 위 항목은 위로, 맨 아래 항목은 아래로 버튼이 비활성이어야 한다.
6. 저장 후 지도 사이드바 메뉴가 바꾼 순서대로 나와야 한다.
7. «비공개만» 체크 시 왼쪽에 비공개 서비스만 남아야 한다.
8. 레이어 그룹 좌우 이동은 기존처럼 동작해야 한다.
