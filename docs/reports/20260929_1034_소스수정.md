## 목적

QGIS API 화면의 상세 영역이 넓게 비어, 절반을 사용매뉴얼로 쓴다. QGIS에서 메모 레이어를 넣을 때 폐지된 좌표계 코드 때문에 도형 받기가 실패해, 그 정의만 다시 넣는다.

## 요약

사용자 목록 오른쪽 상세를 둘로 나눠, 왼쪽은 레이어 권한, 오른쪽은 QGIS 연결 순서를 보여 준다. 사용설명은 좁은 칸에 두고, 사진은 눌러 크게 본다. 중부원점 좌표계 정의를 GeoServer 사용자 좌표계 파일로만 추가했다. 파일을 지우고 GeoServer를 다시 켜면 이전 상태로 돌아간다.

## 테스트

1. QGIS API를 열면 오른쪽이 레이어 권한과 사용매뉴얼로 나뉘어야 한다.
2. 사용설명 사진은 작게 보이고, 누르면 크게 열려야 한다.
3. 매뉴얼 사진을 누르면 첨부파일과 같은 이미지 뷰어가 열리고, 닫기로 빠져나와야 한다.
4. WFS와 WMS가 연결 단계에 함께 설명되고, WMS만 따로 반복되지 않아야 한다.
5. 연결 설명에 QGIS를 켠 뒤 레이어, 데이터 원본 관리자, WFS, 편집을 거쳐 주소를 넣는 순서가 나와야 한다.
6. 주의에 매뉴얼 사진 주소는 참고이고, 왼쪽 화면의 WFS·WMS 주소를 넣어야 한다고 나와야 한다.
7. 사용자를 고르고 읽기·수정을 바꾼 뒤 저장이 되어야 한다.
8. 왼쪽 사용자 목록과 접속 주소 복사는 그대로여야 한다.
9. QGIS에서 메모 레이어를 추가하면 도형 다운로드 오류 없이 들어와야 한다.
10. 좌표계 정의 파일을 지우고 GeoServer를 다시 켜면 추가 전 상태로 돌아가야 한다.
11. QGIS API 레이어 목록에는 현재 데이터베이스에 있는 레이어와 드론영상만 나와야 한다.
12. 사진,동영상 위치를 누르면 미리보기 카드에 테두리가 보여야 한다.
13. 항공뷰 왼쪽 아래 지도가 이전보다 작아야 한다.
14. 울산 UAV에서 레이어 목록·데이터 조회·QGIS API에 안전점검, 보상편입용지, 재난안전이 나오면 안 된다.
15. QGIS API 오른쪽 설명은 읽을 수 있는 글자 크기여야 하고, 사진은 잘리지 않은 채로 보여야 한다.
16. QGIS API 레이어 목록에서 읽기·수정은 오른쪽에 있고, 한글명·영문명·WFS/WMS 너비는 서로 같아야 한다.
17. 좌측 드론영상에서는 상세보기만 나오고, 지도 좌측 상단 메타는 나오지 않아야 한다.
18. 우측 드론영상에서 항목을 켜면 좌측 상단 메타가 나와야 한다.
19. 우측 드론영상을 열면 영상 범위가 보여야 하고, 범위를 누르면 해당 영상과 체크가 켜져야 한다.
20. 우측 사진,동영상·항공뷰 위치를 누르면 해당 항목과 체크가 켜져야 한다.
21. 사진,동영상 미리보기를 닫으면 그 항목의 체크도 해제되어야 한다.
22. 항공뷰 왼쪽 아래 지도에서 끌면 이동되고, 휠로 확대·축소되어야 한다.
23. 항공뷰 오른쪽 위 닫기를 누르면 화면이 닫히고 해당 체크도 해제되어야 한다.
24. 정책지도 등록을 열면 제목, 파일 놓기, 등록 버튼이 한 카드로 보여야 한다.
25. GCP 목록에서 항목을 열면 그 점으로 이동하고 확대되어야 한다.
26. 시스템 목록에서 공간정보 조회 시스템이 맨 앞에 나와야 한다.
27. 우측 드론영상에서 사진,동영상은 하늘색 원, 항공뷰는 주황색 마름모여야 하고, 범례와 점 위 이름으로 구분되어야 한다.
28. 드론영상 메타의 날짜는 «작업일»로 보여야 한다.
29. QGIS API 사용설명은 스크롤 없이 한 화면에 보여야 하고, 그림을 누르면 크게 보여야 한다.
30. 정책지도 등록 안내에는 «올리면 됩니다»가 나와야 하고, HTML을 알아서 읽는다는 문구는 없어야 한다.
31. 좌측 항공뷰를 열면 상세보기만 나오고, 뷰어 왼쪽 위 메타는 나오지 않아야 한다.
32. 우측 드론영상에서 범위가 겹친 곳을 누르면 작업 이름 목록이 그 자리에 나와야 하고, 이름을 고르면 그 영상과 체크가 켜져야 한다.
33. 우측 드론영상 겹침 목록에서 이름에 마우스를 올리면 그 범위만 진하게 보여야 하고, 개수 숫자는 없어야 한다.
34. 우측 드론영상 범위는 테두리만 보이고 안쪽은 채워지지 않아야 한다.
35. 항공뷰 왼쪽 아래 지도에 다른 항공뷰 위치가 보여야 하고, 누르면 그 파노라마로 바뀌어야 한다.
36. 우측 드론영상에서 이미 켜진 영상을 범위나 이름 목록에서 다시 누르면 영상과 체크가 꺼져야 한다.
37. 우측 드론영상에서 겹친 곳을 누르면 이름 목록이 남고, 켠 항목 옆에만 체크가 보여야 한다. 지도 위에는 체크가 없어야 한다.
38. 우측 드론영상에서 켠 영상의 범위 테두리는 빨간색이어야 하고, 끈 뒤에는 원래 색으로 돌아와야 한다.
39. 항공뷰 왼쪽 아래 지도 테두리는 조금 더 보이는 회색 한 줄이어야 한다.
40. 우측 드론영상에서 드론영상·사진,동영상·항공뷰를 펼치면 항목이 한 줄로 보여야 한다.
