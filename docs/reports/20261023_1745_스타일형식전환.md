## 목적

스타일 수정에서 CSS와 SLD를 고르면 그 형식으로 스타일을 다시 저장한다. 지오서버가 설정 파일의 형식과 파일명을 바꾸게 한다.

## 요약

관리자 화면 버튼 오른쪽에 SLD와 CSS 선택을 넣었다. SLD는 화면의 색과 선으로 기본 스타일을 만들고, CSS로 되돌릴 때는 화살표 같은 추가 규칙이 사라진다는 확인을 받는다. 형식 변경이 거절되면 스타일을 지운 뒤 새 형식으로 만들어 레이어에 다시 붙인다.

## 파일수정

수정 | src/lib/geoserverStyleUtils.ts
 `buildSldFromSimpleStyle` — 화면의 색·선·라벨로 기본 SLD 본문을 만든다. 화살표와 벤더 옵션은 넣지 않음

수정 | src/service/devTestService.ts
 `setGeoServerStyleFormat` — 고른 형식의 본문을 지오서버에 저장한다. 형식 변경이 거절되면 스타일을 지운 뒤 다시 만들어 레이어에 붙임
 `patchStyleCatalogFormat` — 설정 파일의 형식과 파일명을 고른 값으로 맞춘다
 `writeStyleBodyToDataDir` — 고른 형식의 본문 파일을 저장하고 반대 형식 파일은 지운다

수정 | src/app/(pages)/dev/_components/LayerInfoManager.tsx
 `handleStyleFormatChange` — SLD·CSS 선택 시 확인 후 형식을 저장하고, SLD이면 색·선 항목을 닫는다
 `openEdit` — 조회한 스타일 형식을 선택 상태에 표시한다

## 테스트

1. 스타일 수정에서 SLD를 고르면 확인 후 설정 파일 형식이 SLD로 바뀌어야 한다.
2. CSS를 고르면 추가 규칙이 사라진다는 확인 뒤에 설정 파일 형식이 CSS로 바뀌어야 한다.
3. 확인을 취소하면 형식이 바뀌지 않아야 한다.
4. SLD인 동안에는 색·선 항목 대신 관리자 화면 안내가 나와야 한다.
5. CSS로 바꾼 뒤에는 색·선을 저장할 수 있어야 한다.
6. 바꾼 스타일이 해당 레이어의 범례에 반영되어야 한다.
