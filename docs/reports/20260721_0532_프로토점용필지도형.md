# 결과보고서

2026-07-21 | dev.strcat | 프로토 점용 도형·필지목록

## 목적

점용(프) 상세에서 도형 추가 후 필지목록이 자동으로 채워지지 않고, 도형 그린 뒤 초기화 버튼이 보이지 않던 문제를 수정한다.

## 요약

프로토 패널에서 필지 반영 콜백 등록 순서를 도형 편집 시작보다 앞당겼고, 공유 도형 편집 안내에서 그리기 완료 후 필지 조회 재시도·초기화 버튼 표시·그리기 모드 초기화 동작을 보완했다. 도로점용 등 기존 그리기 모드 흐름에도 동일하게 적용된다.

해당 없음

## 테스트

1. 점용(프) 목록에서 신규 또는 기존 행 «수정» 후 «도형추가»로 폴리곤을 완료하면 필지목록에 주소가 채워져야 한다.
2. 필지목록 행 클릭 시 지도가 해당 필지로 이동해야 한다.
3. 도형을 그린 뒤 지도 안내에 «초기화» 버튼이 보여야 한다.
4. «초기화» 클릭 시 도형과 자동 채워진 필지가 지워지고, 수동 추가 필지는 남아야 한다.
5. 도로점용 신규 등록에서도 동일하게 그리기 후 초기화 버튼이 보여야 한다.
6. 점용(프) «저장»·«취소» 후 도형 편집 안내·overlay가 남지 않아야 한다.
