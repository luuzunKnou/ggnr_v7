# 결과보고서

2026-09-17 | gyujin | 정사영상 배치 원본·작업 경로 옵션

## 목적

다른 PC에서 정사영상 변환을 돌릴 때 원본 TIF 위치와 임시 작업 디스크를 명령으로 지정할 수 있게 한다.

## 요약

배치 CLI에 원본 경로·작업 경로·데이터 루트 옵션을 추가했다. 원본은 `tiles_tif` 폴더나 그룹 폴더를 넣을 수 있고, 작업 경로는 warp·타일 임시 폴더로 쓴다. 결과 타일은 데이터 루트의 결과 폴더로 배포된다. 다른 PC용 경로 예시 bat도 남겨 두었다.

## 파일수정

수정 | src/service/orthophotoService.ts
 `getOrthoLocalWorkDir` — 환경변수 작업 경로 우선, 없으면 E 드라이브 기본
 `getTilesTifRoot`·`normalizeOrthoSourceTilesTifRoot` — 원본 경로 환경변수 지원. 그룹 폴더를 넣으면 부모를 원본 루트로 사용
 `resolveSafeRelative` — 원본 상대경로를 지정된 tiles_tif 루트에서 해석
 `getPathFreeBytes` — 폴더가 없어도 상위·드라이브 여유를 조회. 작업 폴더는 미리 생성

수정 | scripts/ortho-batch.ts
 `--source-dir`·`--work-dir`·`--data-dir` — 원본·작업·데이터 루트 CLI 옵션

추가 | scripts/ortho-batch-remote.example.bat
 경로 예시 — 다른 PC에서 경로만 고쳐 쓰는 배치 샘플

## 테스트

1. `--dry-run --source-dir=…\tiles_tif` 시 해당 경로의 그룹이 목록에 나와야 한다.
2. 그룹 폴더를 `--source-dir`로 넣어도 같은 그룹이 잡혀야 한다.
3. `--work-dir=F:\temp\ortho_work` 시 로그에 해당 작업 경로가 나오고, 여유가 되면 그 아래에 임시 폴더가 생겨야 한다.
4. 옵션 없이 실행하면 기존처럼 데이터 경로 tiles_tif·E 작업 경로를 써야 한다.
5. 변환 완료 후 결과 타일은 `--data-dir`(또는 환경 데이터 경로)의 tiles_jpg에 있어야 한다.
