## 목적

코드리뷰에서 지적된 재시작 신호 스킵·Geo 복구·exit 지연·명령 모드 콘솔·문구 문제를 바로잡는다.

## 요약

매 적용 시 이전 `launcherConsumed`를 지워 2회차부터 재기동이 스킵되지 않게 했다. GeoServer는 적용 직후 기동하고, 실패할 때만 재기동 파이프라인에서 재시도한다. 프로세스 종료는 HTTP 응답을 위해 최소 2초를 보장하고, 명령 실행 모드는 새 창에서 기동 명령만 한 번 돌리며 구 콘솔 종료 여유를 늘렸다. 화면 안내는 모드별로 구분한다.

## 테스트

1. 동일 세션에서 버전관리 적용(재시작)을 두 번 해도 두 번째도 빌드·앱 재기동이 되어야 한다.
2. GeoServer 기동이 적용 직후 성공하면 재기동 로그에 Geo 재시도가 없어야 한다.
3. 적용 직후 Geo 기동을 실패시키면 재기동 파이프라인에서 Geo 재시도 로그가 나와야 한다.
4. start/b·exit 적용 직후 브라우저가 성공 응답을 받은 뒤에 앱이 내려가야 한다.
5. 명령 실행(새 창) 적용 시 새 창에서 빌드·기동이 되고, 기존 콘솔은 수 초 뒤 닫혀야 한다.
6. 화면에서 재시작 예약 직후 앱 종료만 진행 중으로 보이고 build는 대기로 보여야 한다.
7. 명령 실행 모드 안내가 «새 창»으로, start/b·런처는 «기동 런처»로 구분되어야 한다.
