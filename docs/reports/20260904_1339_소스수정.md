## 목적

점용·점사용료에서 지도 도형을 눌렀을 때 화면이 해당 위치로 이동하지 않고, 지금 보고 있는 지도를 그대로 두게 한다.

## 요약

공통 이동 함수는 건드리지 않고, 두 기능의 지도 픽에서만 화면 맞춤을 뺐다. 목록 행을 고를 때는 이전처럼 해당 위치로 이동한다. 점사용료는 상세가 바뀔 때마다 맞추던 동작도 목록 클릭으로만 남겼다.

영향 받는 기능: 공통점용, 점사용료. 도로대장·데이터조회·기타 대장은 이번 범위 밖이다.
