## 개발목표

상수도 행정 업무지원 사이드바에 «계량기위치»를 추가한다. 주소를 한 줄에 하나씩 넣고 표시하면, 각 주소에 해당하는 필지 경계를 지도에 함께 그린다. 찾은 건과 못 찾은 건을 목록으로 나누고, 목록을 누르면 그 필지로 이동한다. 저장·계량기 대장은 하지 않는다.

영향 받는 기능: 상수도 행정 사이드바 메뉴(관망조회·시설관리·공사대장·급수공사). 기존 메뉴 동작은 그대로 두고 메뉴만 추가한다.

## 플로우차트

상수도 행정 → 계량기위치 → 주소 목록 입력 → 필지 일괄 표시 → (행 클릭) 해당 필지

## 화면설계

### MAP-WTL-METER-01 계량기위치

```
┌────────┬──────────────────────────────┬─────────────────────────────┐
│ 로고   │ 계량기위치                X │                             │
│ 관망조회│ 주소를 한 줄에 하나씩 입력  │                             │
│ 시설관리│ ┌────────────────────────┐ │         지도                │
│ 공사대장│ │의성읍 동서1길 22       │ │                             │
│ 급수공사│ │의성읍 동서1길 18-1     │ │      필지 경계·주소         │
│계량기위치│ └────────────────────────┘ │                             │
│        │ [지도에 표시]  [지우기]     │                             │
│        │ 표시 4   못 찾음 2          │                             │
│        │ 의성읍 동서1길 22    표시됨 │                             │
│        │ 의성읍 동서1길 18    못 찾음│                             │
└────────┴──────────────────────────────┴─────────────────────────────┘
```

#### 설명

1. 사이드바 «계량기위치»를 누르면 왼쪽 패널이 열린다.
2. 텍스트 칸에 주소를 한 줄에 하나씩 붙여 넣는다.
3. «지도에 표시»를 누르면 찾은 필지 경계와 입력 주소가 지도에 나타난다.
4. 목록에서 표시된 주소를 누르면 그 필지로 지도가 이동한다.
5. «지우기»는 입력·목록·지도 표시를 함께 비운다.

#### 확인사항

1. 상수도 행정에서 «계량기위치» 메뉴가 보여야 한다.
2. 예시처럼 여러 주소를 넣으면 찾은 필지가 지도에 함께 표시되어야 한다.
3. 없는 주소는 «못 찾음»으로 남고 필지가 그려지지 않아야 한다.
4. 메뉴를 닫으면 필지 표시가 사라져야 한다.
