## 개발목표

레이어 설정의 코드 분할을 공통 정의에 고정하지 않고, 프로젝트(지자체)마다 단독으로 쓸 코드·한글명·그룹을 다르게 둔다. 선택하지 않은 값은 기타로 묶이며, 기타 범위도 프로젝트 선택 코드에 따라 달라진다.

## 플로우차트

```
레이어설정 → 분할 코드 선택 → 한글명·그룹 확인 → 프로젝트 설정 저장 → 지도 목록 반영
```

## 화면설계

### DEV-SPLIT-01 분할 코드 선택

```
┌──────────────────────────────────────────────┐
│ 분할 코드 선택: 하수관거                      │
│ 하수관용도                                    │
│ 프로젝트 설정: ggnr_ad                        │
│ ┌──────────────────────────────────────────┐ │
│ │ ☐ SBA003 우수관                          │ │
│ │ ☐ SBA004 오수관                          │ │
│ │ ☐ SBA903 압송관                          │ │
│ └──────────────────────────────────────────┘ │
│                         [취소]  [다음]        │
└──────────────────────────────────────────────┘
```

#### 설명

1. 사이드바 레이어 설정에서 분할 대상 부모를 고르면 코드 목록이 열린다.
2. 현재 프로젝트에 저장된 선택이 있으면 그 코드가 미리 선택된다.
3. 고르지 않은 코드와 빈 값은 기타로 묶인다고 안내한다.

#### 확인사항

1. 프로젝트명이 화면에 보여야 한다.
2. 안동 설정이 열려 있으면 우수·오수만 선택되어 있어야 한다.
3. 프로젝트가 없으면 발행 시 안내가 나와야 한다.

### DEV-SPLIT-02 분할 미리보기

```
┌──────────────────────────────────────────────┐
│ 분할 미리보기: 하수관거                       │
│ 레이어명 | 코드 | 한글명 | 그룹               │
│ …_sba003 | SBA003 | 우수관 | 하수             │
│ …_etc    | 기타   | 하수관거(기타) | 하수     │
│                         [이전]  [발행]        │
└──────────────────────────────────────────────┘
```

#### 설명

1. 선택한 코드와 기타 행마다 한글명·그룹을 수정할 수 있다.
2. 발행하면 현재 프로젝트 설정 파일에 저장되고 지도·발행에 반영된다.

#### 확인사항

1. 한글명·그룹 입력이 가능해야 한다.
2. 발행 후 같은 프로젝트에서 다시 열면 선택이 유지되어야 한다.
3. 다른 프로젝트 설정과 섞이지 않아야 한다.
