# 작업계획서

2026-10-21 | gyujin | 세로 색인도 도면은 가로 도형일 때만 돌림

## 개발목표

색인도 미리보기에서 세로로 저장된 도면을 바로 세우는 처리는, 지도의 색인도 칸이 가로일 때만 적용한다. 세로로 놓인 색인도 칸과 보고서·연관 도면은 원본 방향을 그대로 둔다.

## 플로우차트

```
색인도 선택 → (칸이 가로) → 세로 도면이면 글자 방향으로 바로 세움 → 썸네일·전체화면
```

## 화면설계

### MAP-RBP-IDX-03 가로 색인도 칸

```
┌──────────────────────────────────────────────────────────┐
│ [사이드바]  │ 지도                                      │
│ 소하천     │      ┌──────────┐                          │
│ 기본계획   │      │ 가로 칸   │                          │
│            │      └──────────┘                          │
│            │     ┌ 상세 ──────────────────────────┐     │
│            │     │ 색인도                         │     │
│            │     │ ┌──────────────────────────┐   │     │
│            │     │ │ 바로 선 가로 도면         │   │     │
│            │     │ └──────────────────────────┘   │     │
│            │     └────────────────────────────────┘     │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 지도에서 가로로 보이는 색인도 칸을 고른다.
2. 첨부 도면이 세로로 저장돼 있으면 글자가 바로 서도록 돌려 보여 준다.
3. 썸네일과 전체화면이 같은 방향을 쓴다.

#### 확인사항

1. 가로 칸의 세로 저장 도면은 한글이 바로 서야 한다.
2. 가로 칸의 가로 도면은 돌지 않아야 한다.

### MAP-RBP-IDX-04 세로 색인도 칸

```
┌──────────────────────────────────────────────────────────┐
│ [사이드바]  │ 지도                                      │
│ 소하천     │         ┌────┐                             │
│ 기본계획   │         │세로│                             │
│            │         │ 칸 │                             │
│            │         └────┘                             │
│            │     ┌ 상세 ──────────────────────────┐     │
│            │     │ 색인도                         │     │
│            │     │ ┌────────┐                     │     │
│            │     │ │ 원본   │                     │     │
│            │     │ │ 방향   │                     │     │
│            │     │ └────────┘                     │     │
│            │     └────────────────────────────────┘     │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 지도에서 세로로 보이는 색인도 칸을 고른다.
2. 첨부 도면이 세로여도 자동으로 돌리지 않는다.
3. 보고서와 연관 도면 미리보기도 자동 회전을 쓰지 않는다.

#### 확인사항

1. 세로 칸의 세로 도면은 원본 방향 그대로여야 한다.
2. 보고서 미리보기는 이전과 같아야 한다.
3. 연관 도면 미리보기는 돌지 않아야 한다.
