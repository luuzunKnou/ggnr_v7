## 개발목표

상수도 행정 사이드바에 여덟 업무를 두고, 각 업무의 세부 메뉴를 누르면 예시 화면이 나오게 한다. 목록·상세·등록과 지도가 필요한 화면의 자리만 정리하고 저장은 하지 않는다.

## 플로우차트

상수도 행정 → 업무 선택 → 세부 메뉴 → 예시 화면

## 화면설계

### MAP-WTL-02 상수 업무 화면

```
┌────┬──────────┬──────────────────────────────┐
│사이│ 1 관망조회│ 관망도 보기            [등록]│
│드바│  관망도   │  지금 지도 범위의 목록       │
│    │  시설검색 │  ─────────────────────       │
│관망│  …       │  번호  구분  상태 │ 상세     │
│시설│ 2 시설조회│  P-1042 관로 노후│ 구경     │
│공사│          │                    │ [저장]   │
│급수│          │                              │
│민원│          │                              │
└────┴──────────┴──────────────────────────────┘
```

#### 설명

1. 사이드바에서 여덟 업무 중 하나를 누르면 넓은 패널이 열린다.
2. 왼쪽에 여덟 묶음과 세부 메뉴가 있고, 오른쪽은 고른 메뉴의 화면이다.
3. 관망도·시설·민원처럼 지도가 필요한 화면은 범례와 범위 목록, 상세가 같이 있다.
4. 등록·수정·저장은 이 화면 안에서만 바뀌고 저장 안내가 나온다.

#### 확인사항

1. 여덟 업무 메뉴가 사이드바에 보여야 한다.
2. 세부 메뉴를 바꾸면 오른쪽 제목과 표가 바뀌어야 한다.
3. 등록을 누르면 입력 칸이 나와야 한다.
4. 저장 후에도 서버의 자료는 변하지 않아야 한다.
