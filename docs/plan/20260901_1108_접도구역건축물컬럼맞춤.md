## 개발목표

접도구역 건축물 관리대장 테이블 컬럼명을 수급 자료(속성 파일)와 같게 맞춘다. 시설 식별값은 키로 두고, 건축물 내용·확인결과는 이번 범위에서 건드리지 않는다. 화면·저장 로직도 새 컬럼명에 맞게 고친다.

## 플로우차트

```
수급 속성 컬럼 → 대장 테이블 구조 맞춤 → 화면·저장 반영 → 실DB 적용
```

## 화면설계

### RFB-COL-01 관리대장(컬럼명만 변경)

```
┌─────────────────────────────────────────────┐
│ 사이드바 │ 접도구역 건축물 목록 · 상세      │
│          │ (화면 라벨은 기존과 동일)         │
│          │ 저장·조회는 새 컬럼명 사용         │
└─────────────────────────────────────────────┘
```

#### 설명

1. 목록·상세에 보이는 한글 라벨은 그대로 둔다.
2. 저장·조회만 수급 자료와 같은 컬럼명을 쓴다.
3. 시설 식별값은 중복되지 않는 키로 다룬다.

#### 확인사항

1. 상세 저장 후 목록에 위치·노선이 다시 보여야 한다.
2. 식별값이 비어 있으면 저장이 막히거나 안내가 나와야 한다.
3. 건축물 내용·확인결과 화면은 이전과 같이 동작해야 한다.
