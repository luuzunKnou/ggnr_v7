## 개발목표

메모관리 목록을 민원관리와 같은 머리글·검색·카드로 맞춘다. 추가·상세는 목록을 둔 채 지도 위 떠 있는 패널에서 한다. 위치는 지도에서 점을 찍고 칸에는 주소가 나온다. 작성일·작성자는 고칠 수 없게 두고, 작성그룹은 화면에 보이지 않는다. 행을 열면 민원처럼 지도에 점이 강조된다.

## 플로우차트

```
지도 → 메모관리 목록 → (검색) → (행 클릭) → 떠 있는 상세·지도이동 ⇄ (메모 추가) → 위치 찍기 → 저장 → 목록
```

## 화면설계

### 목록-01 메모 목록

```
┌──────────────────────────────────────────────────────────────────┐
│ [아이콘] 메모관리          [+ 메모 추가]                         │
│          전체 12건                                               │
│ [검색                              ]                             │
│ ┌──────────────────────────────────────────────┐                 │
│ │ [도로 메모] #1  홍길동  2026-08-25        > │                 │
│ │ 제목 · 내용 미리보기                         │                 │
│ └──────────────────────────────────────────────┘                 │
│                          지도                                    │
└──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 머리글에 아이콘·제목·건수와 «메모 추가»가 민원관리와 같이 놓인다.
2. 검색만 두고 구분 칩은 두지 않는다. 카드에 구분 이름은 표시만 한다.
3. 카드 윗줄은 구분·번호·작성자·날짜이고, 아랫줄은 제목과 내용이다.
4. 행을 누르면 떠 있는 상세가 열리고 지도가 해당 점으로 가며 붉은 표시가 난다.
5. 목록 닫기는 사이드바에서 하며, 머리글 닫기 단추는 두지 않는다.

#### 확인사항

1. 메모 추가를 누르면 목록은 남고 지도 위 떠 있는 등록 화면이 열려야 한다.
2. 목록에 전체·구분 칩이 없어야 한다.
3. 카드에 번호가 민원과 같이 보여야 한다.
4. 검색어에 맞는 제목·내용만 나와야 한다.
5. 행을 누르면 지도가 해당 점으로 가고 붉은 표시가 나와야 한다.

### 추가-01 메모 추가

```
┌──────────────────────────────────────────────────────────────────┐
│ 메모관리          │                    지도                      │
│ [+ 메모 추가]     │  ┌──────────────────────────────┐            │
│ 검색 · 카드       │  │ 메모 추가                 [닫기]│          │
│                   │  │ 제목     [                ]  │            │
│                   │  │ 작성일   (읽기전용)          │            │
│                   │  │ 작성자   (읽기전용)          │            │
│                   │  │ 내용     [                ]  │            │
│                   │  │ 위치     [주소 글자] [지도에서 위치 찍기]│ │
│                   │  │         [저장] [닫기]        │            │
│                   │  └──────────────────────────────┘            │
└──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. «메모 추가»를 누르면 목록은 왼쪽에 남고 작성 칸이 지도 위에 떠 있는 패널로 열린다.
2. 작성일·작성자는 로그인 값으로 채워지고 고칠 수 없는 칸으로 둔다. 작성그룹은 보이지 않는다.
3. «지도에서 위치 찍기»로 점을 찍으면 칸에 주소가 나온다.
4. 점 찍는 동안 지도를 클릭할 수 있고, 다른 식별 클릭은 받지 않는다.
5. 저장하면 작성자 이름과 부서가 함께 들어가고, 패널이 닫힌 뒤 같은 건의 상세가 열린다.

#### 확인사항

1. 추가 시 가운데를 가리는 창이 열리지 않아야 한다.
2. 작성자·작성일이 고칠 수 없는 칸으로 보여야 한다.
3. 작성그룹이 화면에 없어야 한다.
4. 점을 찍으면 위치 칸에 주소가 나와야 한다.
5. 저장 후 도형·작성자·작성그룹이 들어가야 한다.

### 상세-01 메모 상세

```
┌──────────────────────────────────────────────────────────────────┐
│ 메모관리          │                    지도                      │
│ 검색 · 카드       │  ┌──────────────────────────────┐            │
│ [카드 행]         │  │ 메모 번호                 [닫기]│          │
│                   │  │ 제목 · 작성일 · 작성자 · 내용 │            │
│                   │  │ 위치  [주소 글자] [지도에서 위치 찍기]│   │
│                   │  │         [삭제] [저장] [닫기] │            │
│                   │  └──────────────────────────────┘            │
└──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 목록 행을 누르면 민원 상세와 같이 지도 위 떠 있는 패널이 열린다.
2. 제목·내용은 고칠 수 있고, 작성일·작성자는 회색 읽기 전용이다.
3. 위치 칸에는 주소가 나오고, 점을 다시 찍어 저장하면 주소와 지도 표시가 바로 바뀐다.
4. 아래쪽에 삭제·저장·닫기가 있다. 목록은 왼쪽 그대로이다.

#### 확인사항

1. 행을 누르면 떠 있는 상세가 열려야 한다.
2. 작성일·작성자는 제목·내용과 구분해 보여야 한다.
3. 위치가 있으면 지정됨이 아니라 주소가 나와야 한다.
4. 위치를 바꿔 저장하면 주소와 지도 점이 바로 바뀌어야 한다.
5. 삭제 후 상세가 닫히고 목록에서 빠져야 한다.
