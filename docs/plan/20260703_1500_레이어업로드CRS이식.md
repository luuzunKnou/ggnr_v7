# 작업계획서

2026-07-03 | 213am | 레이어 업로드 좌표계 자동탐지 (정사영상 기능 이식)

## 개발목표

SHP 레이어 업로드 시 원본 좌표계를 자동으로 찾거나 후보를 제시하고, 사용자가 지도 미리보기로 확인·선택한 뒤 DB에 반영한다. DB 적재 좌표계는 기존과 같이 **EPSG:5181**로 변환한다.

> **참고 — 정사영상 관리 (현행, 본 작업에서 수정하지 않음)**
>
> 정사영상 관리에는 이미 좌표계 자동 탐지·선택이 구현되어 있다. GeoTIFF 그룹의 좌표계는 먼저 그룹 폴더명(`satellite_연도_좌표계숫자_…`)이나 `.meta/orthophoto_group_crs.json` 저장값에서 찾는다. 둘 다 없으면 «변환시작»·«작업 일괄시작» 직전에 «원본 좌표계 선택» 모달이 열린다. 모달은 그룹 안 첫 번째 tif 샘플의 네 모서리 좌표(범위)를 읽고, 한국에서 쓰는 좌표계 후보 여섯 가지(통합·서부·중부·동부·동해·제주에 해당하는 EPSG 번호)를 각각 가정한다. 각 가정마다 범위를 **EPSG:5181**로 바꾼 뒤 읍면동 경계 전체(union)와 겹치는지·겹치는 면적 비율(일치율)을 계산한다. 읍면동과 교차하는 후보만 일치율 내림차순으로 두 열 카드에 보여 주며, 카드마다 좌표계 이름·일치율·교차 여부·항공영상 배경 위 워프된 샘플 미리보기가 있다. 사용자가 카드를 고르고 «좌표계 저장»을 누르면 그룹별 좌표계가 메타 파일에 저장되고, 이후 타일 변환에 사용된다.

SHP 레이어 업로드에도 위 현행과 같은 화면·흐름을 이식한다. 다만 좌표계를 알아내는 1차 순서는 SHP에 맞게 prj 좌표 정의 파일 → shp 파일명(밑줄로 나눈 두 번째 조각이 네 자리 숫자) → 업로드 폴더명(같은 규칙)이다. 셋 중 하나로 확정되면 모달 없이 바로 테이블·레이어·스타일·정의 후처리로 넘어간다. 셋 다 없을 때만 shp 범위를 읽어(정사영상의 tif 범위 읽기와 대응) 위와 같은 여섯 후보·읍면동 겹침률·일치율 정렬로 후보를 만들고, 확인이 필요하면 동일한 형태의 좌표계 선택 모달을 연다. SHP는 미리보기를 래스터 워프 대신 범위 네모(벡터)로 항공영상 위에 그린다. 선택한 좌표계는 해당 업로드·마법사 세션의 ogr2ogr 원본 좌표계로 쓰이며, 정사영상처럼 별도 메타 파일 저장은 하지 않는다. 기능은 SHP 전용 서비스·화면 파일에 먼저 독립 구현하고(정사영상 코드는 참고만, 수정 없음), 공용 모듈 분리는 SHP 완료 후 후속으로 둔다. 동기화·이력 문구 개선은 본 계획 범위에서 제외한다.

## 플로우차트

```
SHP 폴더 업로드 → (prj·파일명·폴더명으로 좌표계 확인) → (없으면) shp 범위·읍면동 후보·일치율 → (확인 필요 시) 좌표계 선택 모달 → 테이블·레이어·스타일·정의 후처리
```

## 화면설계

### DEV-SHP-CRS-01 SHP 좌표계 선택 모달

```
+----------------------------------------------------------------------+
| 원본 좌표계 선택 - 하천망.shp                              [닫기]    |
+----------------------------------------------------------------------+
|                                                                      |
|  +---------------------------+    +---------------------------+      |
|  | [x] EPSG:5181  일치율 92%|    | [ ] EPSG:5186  일치율 61%|      |
|  | 읍면동 교차: 있음         |    | 읍면동 교차: 있음         |      |
|  +---------------------------+    +---------------------------+      |
|  | [항공영상 배경 지도]      |    | [항공영상 배경 지도]      |      |
|  |    +----------+           |    |      +------+             |      |
|  |    | SHP 범위 |           |    |      | 범위 |             |      |
|  |    +----------+           |    |      +------+             |      |
|  +---------------------------+    +---------------------------+      |
|                                                                      |
| 선택 좌표계: EPSG:5181                    [ 취소 ] [ 좌표계 저장 ]  |
+----------------------------------------------------------------------+
```

#### 설명

1. prj·shp 파일명·업로드 폴더명으로 원본 좌표계를 알 수 없을 때, 해당 shp의 후처리(테이블 생성 등) 직전에 모달이 열린다.
2. «후보 좌표계를 계산하는 중...» 표시 후, 읍면동과 겹치는 후보만 일치율 내림차순으로 두 열 카드에 나온다. 카드 배치·문구·로딩·저장 버튼은 개발목표 인용의 정사영상 «원본 좌표계 선택» 모달과 동일하다.
3. 각 카드에는 좌표계 이름(또는 EPSG 표기)·일치율·읍면동 교차 여부·항공영상 위 SHP 범위 네모 미리보기가 보인다. 정사영상과 달리 래스터 워프 없이 범위만 벡터로 그린다.
4. 카드를 눌러 선택하고 «좌표계 저장»을 누르면 모달이 닫히고, 선택 좌표계를 원본으로 테이블 생성·동기화 비교가 이어진다.
5. «취소»는 모달만 닫으며, 해당 파일 후처리는 중단·실패 상태로 남고 다음 파일 처리는 계속할 수 있다.

#### 확인사항

1. prj에서 좌표계를 읽거나, 파일명·폴더명 규칙(`…_5181_…` 형태의 두 번째 네 자리)으로 정해지면 모달 없이 바로 후처리되어야 한다.
2. prj가 없고 파일명·폴더명에도 좌표계 정보가 없을 때만 후보 탐지·모달이 열려야 한다.
3. 후보가 여러 개일 때 일치율과 미리보기가 함께 보여야 하며, 일치율이 같아도(예: 100%) 지도에서 범위 위치가 다르면 사용자가 구분할 수 있어야 한다.
4. «좌표계 저장» 후 선택한 좌표계로 DB 반영(**EPSG:5181** 변환)이 되어야 한다.
5. 파일 변환기 SHP→DB 마법사에서도 같은 모달·규칙이 적용되어야 한다.

### DEV-SHP-UP-01 SHP 업로드 후처리 (좌표계 확인 삽입)

```
+----------------------------------------------------------------------+
| SHP 파일 업로더                                                      |
| [업로드]  [이력 조회]                                                |
+----------------------------------------------------------------------+
| 폴더 업로드 진행: 12/12 파일                                         |
+----------------------------------------------------------------------+
| 후처리 진행: 2/5                                                     |
| 하천망.shp   테이블 ...  레이어 ...  (좌표계 확인 중)                |
+----------------------------------------------------------------------+
```

#### 설명

1. 폴더 업로드가 끝나면 shp 파일마다 순서대로 후처리한다.
2. 각 shp에 대해 prj·파일명·폴더명으로 좌표계를 먼저 확인하고, 불명확할 때만 좌표계 선택 모달이 테이블·레이어·스타일·정의 단계 전에 끼어든다.
3. 모달에서 저장하면 해당 파일 후처리가 재개되고, 다음 shp로 넘어간다.

#### 확인사항

1. 좌표계 확인·모달 대기 중에도 다른 파일 후처리 로그가 꼬이지 않아야 한다.
2. 모달에서 취소한 파일은 실패·대기 상태로 남고 다음 파일 처리는 계속할 수 있어야 한다.
