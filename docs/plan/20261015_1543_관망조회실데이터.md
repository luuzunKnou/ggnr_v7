## 개발목표

의성에 올라간 상수 레이어를 바탕으로 관망조회에서 실제 관로·시설을 조회한다. 표시 켜기·필터·화면 범위 목록·상세·지도 표시·클릭 선택은 동작하고, 편집·저장·엑셀·구역설정 등은 이번 범위에서 하지 않는다. 현황판·단면도는 기존 예시 화면을 유지한다.

## 플로우차트

상수행정 → 관망조회 → (표시·필터) → 시설목록 ⇄ 상세 → 지도

## 화면설계

### NET-02 관망조회(실데이터)

```
┌────┬────────────────────────────┬──────────────────────────────────┐
│사이│ 관망조회              [×] │                                  │
│드바│ 표시·연도·관경·검색        │      ════◆════●════             │
│    │ [시설목록]                 │                                  │
│관망│ 배수관로 · N건             │                                  │
│조회│ 번호 구경 재질 연장        │                                  │
└────┴────────────────────────────┴──────────────────────────────────┘
```

#### 설명

1. 표시에서 켠 레이어만 지도와 목록에 나온다.
2. 지도를 옮기면 화면 안 시설만 목록에 다시 불러온다.
3. 목록·지도 클릭 시 상세가 열리고 해당 위치가 강조된다.
4. 구역도·읍면 등 데이터가 없는 필터는 비워 두고, 연도·관경·재질·통합검색만 실데이터에 맞춘다.

#### 확인사항

1. 배수관로를 켜면 지도와 목록에 관로가 나와야 한다.
2. 표시를 끄면 해당 종류가 목록·지도에서 사라져야 한다.
3. 화면 이동 후 «화면에 보이는 시설만»이면 목록이 바뀌어야 한다.
4. 행 클릭 시 관리번호·관경·재질 등 속성이 상세에 나와야 한다.
5. 저장·엑셀 등은 이번 작업에서 바꾸지 않는다.
