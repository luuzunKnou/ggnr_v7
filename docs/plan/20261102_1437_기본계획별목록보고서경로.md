# 작업계획서

2026-11-02 | dev.strcat | 기본계획도 하천별·기본계획별 + 보고서 폴더

## 개발목표

하천기본계획 목록을 하천별과 기본계획별로 나눠 본다. 기본계획별에서는 연도·계획명·계획명(차수) 단위로 접어 소속 하천을 고르고, 상세는 기존과 같다. 보고서 첨부는 계획 폴더를 기준으로 두고, 지방하천은 그 아래 하천 폴더에서, 소하천은 통합 파일이면 계획 폴더에서 읽는다. 실제 폴더 배치는 운영 데이터에서 맞춘다.

## 플로우차트

```
지도 → 기본계획 (지방|소하천) → (하천별|기본계획별) → (기본계획 접기 → 하천) → 상세·보고서
```

## 화면설계

### MAP-RBP-01 목록 축 선택

```
┌──────────────────────────────────────────────────────────┐
│ [사이드] 기본계획                              [지도]     │
│  지방하천 | 소하천                                         │
│  기본계획별 | 하천별                                       │
│  [검색]                                                    │
│  · 2024 부구천 · …보고서_1차 ▾ 하천 2                    │
│      나곡천                                                │
│      박금천                                                │
│  · 2026 장수포천 …보고서                                   │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 지방·소하천 탭 아래에 기본계획별·하천별 축이 있다.
2. 기본계획별은 연도·계획 행을 접어 소속 하천을 보여 준다.
3. 하천을 고르면 우측 상세가 열린다.
4. 하천별은 기존처럼 하천 목록만 보인다.

#### 확인사항

1. 기본계획별에서 소하천이 많아도 목록 접기로 볼 수 있어야 한다.
2. 하천별 전환 시 이전과 같이 하천 목록이 나와야 한다.
3. 1·2차 계획이 다른 행으로 나뉘어야 한다.

### MAP-RBP-02 상세·보고서

```
┌──────────────────────────────────────────────────────────┐
│ [목록]              [상세] 하천명 · 연도표 · 보고서…      │
│                     속성 · 색인도 · 도면                   │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 상세 구성은 기존과 같다.
2. 보고서는 계획 폴더(및 지방·분리 시 하천 하위)에서 읽는다.
3. 기본계획별에서 고른 계획이 상세 연도표 초기 선택에 반영된다.

#### 확인사항

1. 같은 계획 아래 나곡천을 고르면 나곡천 쪽 보고서가 열려야 한다.
2. 소하천 통합 건은 계획 폴더의 파일이 열려야 한다.
3. 색인도·도면은 이전과 같이 동작해야 한다.
