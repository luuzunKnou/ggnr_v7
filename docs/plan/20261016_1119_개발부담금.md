## 개발목표

공간정보조회 시스템 사이드바에 «개발부담금» 메뉴를 추가한다. 임시 대상 지역 목록을 왼쪽 패널에 보여주고, 지도에는 각 지역 경계를 표시한다. 목록이나 지도에서 지역을 고르면 경계가 강조되고 화면이 해당 위치로 이동하며, 오른쪽 상세 패널에 기본 속성을 보여준다. 이번 단계는 화면·조작만 확인하며 저장·연계는 하지 않는다.

영향 받는 기능: 지도 화면 공용 레이아웃(패널 배치·검색창 위치), 지적재조사·개별공시지가 등 같은 줄에 붙는 패널.

## 플로우차트

```
지도 → 개발부담금 목록 → (행·경계 클릭) → 위치 강조·상세
```

## 화면설계

### MAP-DVC-01 개발부담금 목록

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│    │ 개발부담금                 X │ [주소/지번 검색                    ] │
│메뉴│ [전체 연도 ▼] [전체 읍면동 ▼]│                                      │
│    │ [전체 상태 ▼]                │                                      │
│    │ [검색                        ]│                                      │
│    ├──────────────────────────────┤             지도                     │
│    │ 사업명  소재지  면적  상태   │       대상 지역 경계 표시           │
│    │ …                            │                                      │
│    │ N건                          │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 사이드바 «개발부담금»을 누르면 왼쪽에 목록 패널이 열린다.
2. 연도·읍면동·상태와 검색으로 목록을 거른다.
3. 행을 누르면 지도가 해당 지역으로 이동하고 경계가 강조된다.
4. 지도에 보이는 경계를 눌러도 같은 지역이 선택된다.

#### 확인사항

1. 메뉴를 누르면 패널이 열리고 다시 누르면 닫혀야 한다.
2. 필터·검색을 바꾸면 목록 건수가 바뀌어야 한다.
3. 행을 누르면 지도가 해당 지역으로 이동해야 한다.
4. 패널을 닫으면 지도 경계가 남지 않아야 한다.

### MAP-DVC-02 개발부담금 상세

```
┌────┬──────────────┬──────────────────┬──────────────────────────────────┐
│메뉴│ 개발부담금   │ 상세           X │                                  │
│    │ 목록 …       │ 사업명            │             지도                 │
│    │              │ 소재지·면적·상태  │       선택 지역 경계 강조       │
│    │              │ 기준일·부담금 등  │                                  │
└────┴──────────────┴──────────────────┴──────────────────────────────────┘
```

#### 설명

1. 목록이나 지도에서 지역을 고르면 오른쪽에 상세 패널이 열린다.
2. 사업명·소재지·면적·상태·기준일·예상부담금 등 임시 속성을 보여준다.
3. 상세를 닫아도 목록은 유지되며, 목록을 닫으면 상세도 함께 닫힌다.

#### 확인사항

1. 선택 시 상세 패널이 열려야 한다.
2. 다른 지역을 고르면 상세 내용이 바뀌어야 한다.
3. 상세를 닫으면 선택 강조가 해제되어야 한다.
