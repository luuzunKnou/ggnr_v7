# 작업계획서

2026-10-29 | dev.strcat | docs/brief/20261029_1600_기본계획사업계획제방.md

## 개발목표

기본계획 상세 상단 버튼을 두 줄(각 6칸)로 두고 둘째 줄에 «사업계획»을 넣는다. 누르면 제방 레이어를 켠 뒤 색인도 도면과 목록 화면으로 이동한다. 목록은 «사업계획목록»이며 1차는 제방만 보인다. 목록·지도 라벨은 제방 이름과 연장으로 «보축1지구 (L=1,077m)» 형식을 쓴다.

## 플로우차트

```
기본계획상세 → 사업계획 → (색인도 미선택 시 첫 색인도) → 색인도도면+사업계획목록(제방) ⇄ 행클릭·깜빡임·지도이동
```

## 화면설계

### BP-BIZ-01 버튼 두 줄

```
┌────────────────────────────────────────┐
│ 기본계획 상세                      ✕   │
├────────────────────────────────────────┤
│ 연도 목록 …                            │
├────────────────────────────────────────┤
│ [보고서][하천구역][색인도][구조물도][종단][횡단] │
│ [사업계획][ ][ ][ ][ ][ ]              │
├────────────────────────────────────────┤
│ 속성 · 색인도 그리드 …                 │
└────────────────────────────────────────┘
```

#### 설명

1. 첫째 줄은 기존 여섯 버튼을 그대로 둔다.
2. 둘째 줄 첫 칸이 «사업계획»이고 나머지는 빈 칸으로 자리를 남긴다.
3. 사업계획으로 들어온 상태면 해당 버튼이 선택된 것처럼 보인다.

#### 확인사항

1. 버튼이 두 줄로 보여야 한다.
2. 사업계획을 누르면 제방 레이어가 켜져야 한다.

### BP-BIZ-02 사업계획목록

```
┌────────────────────────────────────────┐
│ ‹  색인도                              │
├────────────────────────────────────────┤
│ ┌ 색인도 도면 썸네일 ───────────────┐ │
│ └──────────────────────────────────┘ │
├────────────────────────────────────────┤
│ 사업계획목록                           │
│ [하천제방] 보축1지구 (L=1,077m)        │
└────────────────────────────────────────┘
```

#### 설명

1. 색인도 도면 미리보기는 기존과 같다.
2. 목록 제목만 «사업계획목록»이고 항목은 제방만 나온다.
3. 행을 누르면 강조·지도 이동이 기존 상세목록과 같다.

#### 확인사항

1. 일반 색인도 상세의 상세목록에는 종단 등이 그대로 나와야 한다.
2. 사업계획으로 들어온 목록에는 제방만 보여야 한다.
3. 지도에 제방 이름·연장 라벨이 보여야 한다.
