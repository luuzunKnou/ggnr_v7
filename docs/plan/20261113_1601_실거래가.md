## 개발목표

지도 사이드바 «실거래가»를 켜면 계약 연월을 고르고, 시군구 토지 매매를 읍면동 단위로 집계해 목록과 지도에 본다. 지번이 일부만 공개되므로 필지 매칭은 하지 않고, 동 경계 강조와 거래 목록만 제공한다.

## 플로우차트

```
지도 → 실거래가 → 연월 선택 → 동별 집계 목록 → (동 선택) → 동 경계·거래 목록
```

#### 설명

1. 사이드바에서 «실거래가»를 선택하면 왼쪽 목록 패널이 열린다.
2. 연·월을 고르고 조회하면 읍면동별 건수와 중간 면적당가가 나온다.
3. 동을 고르면 지도에 동 경계가 표시되고 화면이 맞춰진다.
4. 같은 패널 아래에 해당 동의 거래 목록이 나온다.
5. 상단에 지번 부분 공개 안내가 보인다.

#### 확인사항

1. 실거래가 메뉴가 선택된 상태로 보여야 한다.
2. 연월 조회 후 동이 목록에 나와야 한다.
3. 동 선택 시 지도에 경계가 보이고 화면이 맞춰져야 한다.
4. 해제 거래는 건수·목록에 포함되지 않아야 한다.
5. 다른 지도 기능과 동시에 켜져도 패널이 겹치지 않아야 한다.
