# 작업계획서

2026-10-21 | gyujin | 소하천 기본계획 색인도 도면이 세로로 저장되어 눕혀 보임

## 개발목표

소하천 기본계획 상세에서 색인도를 누르면, 세로로 저장된 도면도 글자가 바로 서도록 돌려 보여 준다. 가로 도면은 그대로 둔다. 원본 파일은 바꾸지 않고, 미리보기와 썸네일만 맞춘다.

새로 같은 형식의 세로 도면이 들어와도 같은 규칙으로 맞춘다. 글자가 이미 바로 선 세로 문서는 돌리지 않는다.

## 플로우차트

```
색인도 선택 → 도면 열기 → (세로 페이지) → 글자 방향으로 바로 세움 → 썸네일·전체화면
```

## 화면설계

### MAP-RBP-IDX-01 색인도 상세 썸네일

```
┌──────────────────────────────────────────────────────────┐
│ [사이드바]  │ 지도                                      │
│ 소하천     │                                            │
│ 기본계획   │     ┌ 상세 ──────────────────────────┐     │
│            │     │ 하천명                         │     │
│            │     │ 연도별 기본계획                │     │
│            │     │                                │     │
│            │     │ 색인도                         │     │
│            │     │ ┌──────────────────────────┐   │     │
│            │     │ │ 가로로 바로 선 색인도     │   │     │
│            │     │ └──────────────────────────┘   │     │
│            │     └────────────────────────────────┘     │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 색인도를 고르면 상세에 도면 미리보기 칸이 가로로 보인다.
2. 세로로 저장된 도면은 글자가 바로 서도록 돌려서 칸에 맞춘다.
3. 가로로 저장된 도면은 돌리지 않는다.

#### 확인사항

1. 세로로 누워 있던 색인도 썸네일의 한글이 바로 서야 한다.
2. 가로 색인도 썸네일은 이전과 같아야 한다.
3. 글자가 처음부터 바로 선 세로 문서는 돌지 않아야 한다.

### MAP-RBP-IDX-02 도면 전체화면

```
┌──────────────────────────────────────────────────────────┐
│ 닫기   파일명                              회전 확대 축소 │
│                                                          │
│              ┌────────────────────────────┐              │
│              │ 가로로 바로 선 색인도 도면  │              │
│              └────────────────────────────┘              │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 썸네일을 누르면 전체화면에서 같은 방향으로 도면이 열린다.
2. 화면의 회전 버튼은 바로 선 상태를 기준으로 추가로 돈다.
3. 한 장 보기와 여러 장 이어 보기 모두 같은 방향을 쓴다.

#### 확인사항

1. 전체화면에서 세로 저장 도면의 한글이 바로 서야 한다.
2. 회전 버튼을 누르면 바로 선 상태에서 더 돌아야 한다.
3. 기본계획 보고서처럼 처음부터 바로 선 문서는 그대로여야 한다.
