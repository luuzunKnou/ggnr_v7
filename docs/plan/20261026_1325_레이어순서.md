# 작업계획서

2026-10-26 | 213am | docs/brief/20261026_1325_레이어순서.md

## 개발목표

데이터 조회와 지도 우측 레이어 목록이 레이어 설정의 순번을 따르게 한다. 같은 그룹 안에서 순번이 작은 레이어가 위에 온다. 순번이 같거나 없으면 한글 이름순이다. 그룹 제목 순서와 지도에 겹치는 순서는 유지한다. 소유구분의 기타는 맨 아래에 둔다.

## 플로우차트

레이어 설정 순번 → 데이터 조회 그룹 안 목록 → 우측 주제도·지하시설물·소유구분·지목·지적도·건물·도로 목록

## 화면설계

### MAP-DQ-01 데이터조회 레이어 목록

```
┌──────────────────────────────────────────────┐
│ 데이터조회                                닫기 │
├──────────────┬───────────────────────────────┤
│ 상수         │ 지도                          │
│  상수관로    │                               │
│  상수맨홀    │                               │
│ 하수         │                               │
│  하수관로    │                               │
│  하수맨홀    │                               │
└──────────────┴───────────────────────────────┘
```

#### 설명

1. 그룹 제목의 순서는 지금과 같다.
2. 그룹 안 레이어는 레이어 설정의 순번이 작은 것부터 나온다.
3. 순번이 같으면 한글 이름순이다.

#### 확인사항

1. 같은 그룹에서 순번이 작은 레이어가 위에 있어야 한다.
2. 순번이 같은 레이어는 한글 이름순이어야 한다.
3. 그룹 제목 순서는 바뀌지 않아야 한다.

### MAP-RIGHT-01 우측 레이어 목록

```
┌──────────────────────────────────────────────┐
│ 지도                          │ 지하시설물 닫기 │
│                               │ 상수           │
│                               │  상수관로      │
│                               │  상수맨홀      │
│                               │ 하수           │
│                               │  하수관로      │
│                               │ 소유구분       │
│                               │  개인          │
│                               │  기타          │
└───────────────────────────────┴────────────────┘
```

#### 설명

1. 주제도, 지하시설물, 지목, 지적도, 건물·도로의 그룹 안 목록이 순번을 따른다.
2. 지하시설물 그룹 제목은 상수부터 통신까지 지금 순서를 유지한다.
3. 소유구분의 기타는 순번과 관계없이 맨 아래다.
4. 지도에 겹치는 순서는 바꾸지 않는다.

#### 확인사항

1. 우측 지하시설물에서 순번이 작은 레이어가 그룹 안 위에 있어야 한다.
2. 주제도, 지목, 지적도, 건물·도로도 같은 순번 규칙이어야 한다.
3. 소유구분에서 기타가 맨 아래에 있어야 한다.
4. 레이어를 켜고 끄면 지도에 겹치는 순서가 이전과 같아야 한다.
