# 작업계획서

2026-07-27 | dev.strcat | 업무 알림 서버 저장·시스템 필터

## 개발목표

점용 종료 임박·점사용료 미납 임박 알림의 읽음·지우기를 계정별 서버 상태로 옮긴다. 알림 후보는 로그인 이후 미리 모으고, 하천 등 시스템을 열면 그 시스템에 해당하는 항목만 보여 준다. 브라우저 초기화와 무관하게 같은 계정이면 읽음·지우기가 유지된다.

## 플로우차트

```
로그인 → 알림후보조회·서버상태병합 → 시스템선택 → (시스템필터) → 내정보알림·사이드바미읽음 ⇄ 읽음·지우기(서버)
```

## 화면설계

### NOTIF-01 시스템 선택 후 알림(필터)

```
+----------------------------------------------------------------------+
| 통합지도                                              [로그인계정]   |
+---+------------------------------------------------------------------+
|메 | [내 정보]                                                        |
|뉴 | +---------------- 알림 ------------------+                       |
|   | 총 2건 · 미읽음 1                        |                       |
|하 | 점용종료일이 15일 이내인 건이 1건입니다  |                       |
|천 | · 점용명 | 2026-08-15 · D-14             |                       |
|점 | 납기일이 15일 이내인 미납이 1건입니다    |                       |
|용 | · 납부자 | 2026-08-10 · D-9              |                       |
|   +------------------------------------------+                       |
|점 | (지도)                                                           |
|사 |                                                                  |
|용 |                                                                  |
|료 |                                                                  |
+---+------------------------------------------------------------------+
+----------------------------------------------------------------------+
```

#### 설명

1. 하천 시스템에 들어오면 하천 관련 만료·미납 알림만 목록에 보인다.
2. 읽음·지우기는 서버에 남아 새로고침·다른 브라우저에서도 같다.
3. 항목을 누르면 대장 또는 점사용료 상세로 이동한다.

#### 확인사항

1. 브라우저 저장을 지워도 지운 알림이 다시 나오지 않아야 한다.
2. 하천 화면에서 다른 시스템 전용 알림은 보이지 않아야 한다.
3. 미읽음이 있으면 사이드바 표시가 나와야 한다.

### NOTIF-02 로그인 후 사전 조회

```
+----------------------------------------------------------------------+
| 메인 (시스템 선택)                                    [로그인계정]   |
+----------------------------------------------------------------------+
| 하천행정  | 도로행정  | ...                                          |
| (알림은 뒤에서 미리 받아 두고, 시스템 진입 시 걸러 씀)               |
+----------------------------------------------------------------------+
```

#### 설명

1. 로그인된 상태에서 시스템 선택 화면에 있어도 알림 후보를 미리 받는다.
2. 시스템을 열 때는 전체를 다시 받기보다, 받은 목록에서 해당 시스템만 걸러 보여 주는 것을 우선한다.
3. 내 정보를 열 때 최신 후보와 서버 읽음·지우기 상태를 다시 맞출 수 있다.

#### 확인사항

1. 로그인 후 지도에 들어가기 전에도 알림 조회가 일어나야 한다.
2. 하천 진입 후 보이는 알림이 하천 관련만이어야 한다.
