## 개발목표

점사용료 스케줄러를 runtime 차단 목록으로 끄고, 세입과목명에 따라 하천·도로·국공유지 테이블에 나눠 저장한다. 화면은 시스템마다 같은 코드로 해당 접두 테이블만 조회한다. 기존 단일 테이블은 하천용으로 이름을 맞춘다.

## 플로우차트

runtime 스케줄러허용 → 차세대조회 → 세입과목명분기 → 하천·도로·국공유지테이블 → 지도점사용료(시스템별조회)

## 화면설계

### MAP-FEE-01 점사용료 목록

```
┌──────────────────────────────────────────────────────────────┐
│ [사이드]  검색│필터│지도                                      │
│  점사용료     ┌────────────────────────────────────────────┐ │
│              │ 점사용료 목록 (해당 시스템 테이블)            │ │
│              │ 상태 · 대장번호 · 부서 · 납부자 …            │ │
│              └────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 하천·도로·건설 시스템에서 같은 점사용료 메뉴를 연다.
2. 시스템은 각각 하천·도로·국공유지 테이블만 조회한다.
3. 스케줄러는 runtime에서 차단할 수 있고, 허용된 시스템에 해당하는 과목만 저장한다.

#### 확인사항

1. 하천 시스템에서 연 목록이 하천 점사용료만 보여야 한다.
2. 도로 시스템에서 연 목록이 도로 점사용료만 보여야 한다.
3. 스케줄러 차단이 켜진 프로젝트에서는 연계 스케줄이 등록되지 않아야 한다.
