# 작업계획서

2026-11-04 | dev.strcat | 안전점검 연계 테이블을 도로 테이블 한 쌍으로 통합

## 개발목표

안전점검 연계 자료(시설물, 점검진단실적)를 지금까지는 상하수도·도로·건축물 구분에 따라 세 쌍의 테이블에 나눠 담았으나, 앞으로는 도로 쪽 시설물 테이블과 점검진단실적 테이블 한 쌍에 모두 담고, 그 안에서 시설물구분으로 상하수도·도로·건축물을 나눈다.

연계 저장, 테이블 생성, 지도 위치 보강, 코드 한글 변환, 초기 적재·이관 스크립트, 데이터조회 레이어 설정이 모두 이 한 쌍만 쓰도록 고쳐, 나머지 두 쌍(상하수도·건축물용)은 더 이상 어디에서도 쓰지 않게 한다. 기존 두 쌍 테이블 삭제와 지도서버 레이어 정리는 사용자가 직접 한다.

안전점검 화면(목록·상세·지도 표시)의 상하수도·도로·건설 거르기는 지금처럼 시설물구분으로 동작하고, 화면 모양은 바뀌지 않는다.

## 플로우차트

```
연계 수신 → 도로 시설물·점검 테이블 저장 → 코드 한글 변환·위치 보강 → 안전점검 목록(시설물구분 거르기) → 상세
```

## 화면설계

### FMS-01 안전점검 목록

```
┌──────────────────────────────────────────────────────────────────────┐
│ 검색창                                                               │
├──────────┬───────────────────────────┬───────────────────────────────┤
│ 사이드바 │ 안전점검                  │                               │
│          │ ┌───────────────────────┐ │                               │
│          │ │ 전체 상하수도 도로 건설│ │            지도               │
│          │ ├───────────────────────┤ │                               │
│          │ │ 검색                  │ │                               │
│          │ ├───────────────────────┤ │                               │
│          │ │ 시설물종류 시설명 주소│ │                               │
│          │ │ 시설물종류 시설명 주소│ │                               │
│          │ └───────────────────────┘ │                               │
└──────────┴───────────────────────────┴───────────────────────────────┘
```

#### 설명

1. 목록은 도로 시설물 테이블 하나에서 읽는다.
2. 상하수도·도로·건설 버튼은 시설물구분으로 거른다.
3. 지도에는 같은 조건의 시설물 위치가 표시된다.

#### 확인사항

1. «전체»에서 상하수도·도로·건축물 시설물이 모두 나와야 한다.
2. «상하수도»를 누르면 상하수도 시설물만 나와야 한다.
3. 목록 화면 모양은 이전과 같아야 한다.

### FMS-02 안전점검 상세

```
┌──────────────────────────────────────────────────────────────────────┐
│ 검색창                                                               │
├──────────┬───────────────────────────┬───────────────────┬───────────┤
│ 사이드바 │ 안전점검 목록             │ 시설명            │           │
│          │                           │ 속성              │   지도    │
│          │                           │ 점검진단실적      │           │
│          │                           │ 회차 기간 등급    │           │
└──────────┴───────────────────────────┴───────────────────┴───────────┘
```

#### 설명

1. 시설물 속성은 도로 시설물 테이블에서, 점검진단실적은 도로 점검진단실적 테이블에서 읽는다.
2. 상세를 열면 지도가 시설물 위치로 이동한다.

#### 확인사항

1. 상하수도 시설물 상세에도 점검진단실적이 나와야 한다.
2. 위치가 있는 시설물은 지도가 그 위치로 이동해야 한다.
