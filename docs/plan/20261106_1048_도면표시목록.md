## 개발목표

도면 표시를 여러 파일을 목록으로 쌓아 두고 파일마다 표시를 켜고 끌 수 있게 바꾼다. 올린 도면은 서버에 저장해 새로고침 후에도 목록을 복원한다. 패널을 닫으면 지도에서는 꺼진다. 업로드 칸은 데이터 업로드와 같은 모양으로 맞춘다.

## 플로우차트

```
지도 → 도면 표시 → 파일 업로드(서버 저장) → 목록 on/off·좌표계 → 지도 표시 / 패널 닫기 시 지도 해제 · 다시 열면 목록 복원
```

## 화면설계

### MAP-DRAW-02 도면 표시 목록

```
┌────┬──────────────────────────────┬──────────────────────────────┐
│메뉴│ 도면 표시                [X] │ [ 주소·지명 검색          ]  │
│    │ ─────────────────────────────│                              │
│조회│ ┌──────────────────────────┐ │                              │
│    │ │  파일을 놓거나 눌러 선택  │ │                              │
│도면│ │  DXF·DWG 올리면 서버 저장 │ │            지도              │
│표시│ └──────────────────────────┘ │      (켠 도면 겹침 표시)      │
│    │  ☑ ○○○.dxf            [삭제] │                              │
│    │  ☐ △△△.dwg            [삭제] │                              │
│    │  [모두 지우기]               │                              │
└────┴──────────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 사이드바 «도면 표시»를 누르면 왼쪽 패널이 열린다.
2. 파일을 올리면 서버에 저장되고 목록에 행이 추가되며.
3. 행 스위치로 해당 도면만 켜고 끈다. 펼치면 좌표계·도면 레이어를 조절한다.
4. 패널을 닫으면 지도에서 도면이 사라지고, 다시 열면 서버 목록을 불러온다.
5. 행 삭제·모두 지우기로 서버 파일과 목록을 제거한다.

#### 확인사항

1. 두 번째 파일을 올려도 첫 번째가 목록·지도에 남아야 한다.
2. 행 스위치를 끄면 해당 도면만 지도에서 사라져야 한다.
3. 패널을 닫으면 지도에서 도면이 사라져야 한다.
4. 새로고침 후 다시 열면 목록·on/off가 서버에서 복원되어야 한다.
5. 업로드 칸 모양이 데이터 업로드와 같아야 한다.
6. 수치지형도와 함께 켜도 서로 지워지지 않아야 한다.
