# 작업계획서

2026-11-27 | 213am | v6 나의지도 전 기능 이관

## 개발목표

레거시 «나의지도(개인 레이어)»를 v7로 이관한다. SHP·Excel 생성, Excel 좌표(가로·세로)·주소(지번 우선·도로명 보완) 모드, 생성 마법사(좌표분류·레이어정보·스타일·좌표계·미리보기·컬럼 한글화·고유값·목록보기), 본인 목록·검색, 상세 수정·삭제, 지도 켜기·끄기(레이어 목록용·나의지도용 이중 등록), 개인 스타일·지도 서버 발행, SHP 내려받기까지 v6에 있던 기능을 빠짐없이 포함한다. 동일 키 재등록은 거절하며, 행 단위 동기화·덮어쓰기는 v6에 없으므로 이번 범위에서 제외한다. 관리자용 데이터 업로드와 화면·권한을 분리하고, 기존 SHP·Excel·주소 매칭·지도 서버 발행 처리는 재사용한다.

## 플로우차트

```
지도·목록 → 파일선택 → 생성마법사 → 개인레이어 등록 → 지도켜기끄기 ⇄ 상세수정·삭제·SHP받기
```

## 화면설계

### MAP-MYLAYER-01 나의지도 목록

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                          [레이어] │
│ ┌──────┐                                    ┌──────────┐ │
│ │사이드│              지도                   │ 나의지도 │ │
│ │ 바   │                                    │ [검색]   │ │
│ │나의지도│                                  │ [레이어추가]│
│ │ …    │                                    │ ▼그룹A   │ │
│ │      │                                    │  ·레이어1│ │
│ │      │                                    │  ·레이어2│ │
│ │      │                                    │ ▼그룹B   │ │
│ └──────┘                                    │ [받기][상세]│
│                                             └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 사이드바 «나의지도»로 목록 패널을 연다.
2. 본인이 만든 레이어만 그룹 트리로 보이고, 검색·초기화가 된다.
3. «레이어 추가»로 SHP 세트 또는 Excel을 고르면 생성 마법사가 열린다.
4. 행에서 상세·SHP 내려받기·삭제로 이어진다.

#### 확인사항

1. 다른 사용자 레이어가 목록에 보이면 안 된다.
2. 그룹 접기·펼치기와 검색이 동작해야 한다.
3. SHP·Excel 외 파일은 안내 후 막혀야 한다.
4. 내려받기로 SHP 묶음이 나와야 한다.

### MAP-MYLAYER-02 생성 마법사 — 좌표 분류

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                          [레이어] │
│ ┌──────┐              지도                   ┌──────────┐ │
│ │사이드│                                    │레이어추가│ │
│ │      │                                    │ 좌표분류 │ │
│ │      │                                    │ ○가로세로│ │
│ │      │                                    │ ○주소    │ │
│ │      │                                    │ (SHP면   │ │
│ │      │                                    │  지오메트리│
│ │      │                                    │  고정)   │ │
│ │      │                                    │ [다음]   │ │
│ └──────┘                                    └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. Excel이면 가로·세로 또는 주소 중 하나를 고르고, 해당 컬럼을 지정한다.
2. SHP이면 지오메트리 모드로 두고 컬럼은 속성 파일에서 읽는다.
3. 필수 미선택 시 다음 단계로 가지 않는다.

#### 확인사항

1. Excel에서 가로·세로 미지정 시 진행이 막혀야 한다.
2. Excel에서 주소 컬럼 미지정 시 진행이 막혀야 한다.
3. SHP는 좌표 분류를 바꾸지 않고 다음으로 가야 한다.

### MAP-MYLAYER-03 생성 마법사 — 레이어 정보·스타일

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                          [레이어] │
│ ┌──────┐              지도                   ┌──────────┐ │
│ │사이드│         (미리보기 반영)              │레이어정보│ │
│ │      │                                    │ 그룹명   │ │
│ │      │                                    │ 영문명   │ │
│ │      │                                    │ 한글명   │ │
│ │      │                                    │ 형태·좌표│ │
│ │      │                                    │ 선·면색  │ │
│ │      │                                    │ [이전][다음]│
│ └──────┘                                    └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 그룹명·영문명·한글명·도형 형태·좌표계·선·면 스타일을 입력한다.
2. 지도에 스타일 미리보기를 보여 준다.
3. 필수값 없으면 다음 단계로 가지 않는다.

#### 확인사항

1. 필수 미입력 시 안내 후 진행이 막혀야 한다.
2. 점·선·면에 맞는 기본 스타일이 잡혀야 한다.
3. 미리보기가 선택 스타일을 반영해야 한다.

### MAP-MYLAYER-04 생성 마법사 — 컬럼·저장

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                          [레이어] │
│ ┌──────┐              지도                   ┌──────────┐ │
│ │사이드│                                    │컬럼설정  │ │
│ │      │                                    │ 영문|한글│ │
│ │      │                                    │ ○고유값  │ │
│ │      │                                    │ □목록보기│ │
│ │      │                                    │ [이전][저장]│
│ └──────┘                                    └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 컬럼 한글명을 넣고, 고유값 하나·목록보기 하나 이상을 고른다.
2. 한글명 비움 시 영문 유지 여부를 확인한 뒤 저장한다.
3. 저장 시 실데이터·메타·개인 스타일·지도 서버 발행·레이어 켜기끄기용·나의지도용 등록·권한·조회용 필드 정의까지 한 흐름으로 만든다.
4. Excel 주소 모드는 지번 검색 후 없으면 도로명으로 위치를 붙인다. 실패 행은 위치 없이 속성만 넣을 수 있다.
5. 이미 같은 영문명 키가 있으면 거절하고 안내한다.

#### 확인사항

1. 고유값·목록보기 미선택 시 저장이 막혀야 한다.
2. SHP·Excel 가로세로·Excel 주소 각각 생성이 되어야 한다.
3. 주소로 위치를 찾은 행은 지도에 점이 보여야 한다.
4. 동일 키 재등록 시 거절 안내가 나와야 한다.
5. 저장 후 목록·레이어 켜기끄기에 본인 레이어가 나타나야 한다.

### MAP-MYLAYER-05 레이어 상세

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                          [레이어] │
│ ┌──────┐              지도          ┌ 상세보기 ───────┐ │
│ │사이드│                            │ 한글명 그룹명   │ │
│ │      │                            │ 순번 영문 고유값│ │
│ │      │                            │ 목록보기 한글명 │ │
│ │      │                            │ [저장][삭제][닫기]│
│ └──────┘                            └─────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 한글명·그룹명과 필드(고유값·목록보기·한글명)를 수정·저장한다.
2. 그룹명 변경 시 같은 그룹의 다른 본인 레이어·켜기끄기 이름·나의지도 이름·조회 정의 그룹을 함께 맞춘다.
3. 삭제 시 메타·스타일·조회 정의·서비스·지도 서버·실데이터까지 정리한다.
4. 상세에서는 파일 재업로드로 행 데이터를 바꾸지 않는다.

#### 확인사항

1. 저장 후 목록·지도 메뉴 이름이 바뀌어야 한다.
2. 삭제 후 목록과 지도에서 사라져야 한다.
3. 다른 사용자 레이어는 열리거나 수정되지 않아야 한다.

### MAP-MYLAYER-06 지도 켜기·끄기

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                    [레이어목록]   │
│ ┌──────┐              지도                   ┌──────────┐ │
│ │사이드│                                    │ □개인그룹 │ │
│ │나의지도│                                  │  □레이어  │ │
│ │(선택)│                                    │ …         │ │
│ └──────┘              (개인 도형 표시)        └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 생성 시 레이어 목록용 그룹과 나의지도용 그룹에 모두 등록한다.
2. 켠 레이어는 개인 스타일로 지도에 그려진다.
3. 다른 지도 기능과 배타 충돌 없이, 일반 레이어 켜기·끄기 패턴을 따른다.

#### 확인사항

1. 레이어 목록과 나의지도 양쪽에서 켜고 끌 수 있어야 한다.
2. 본인 레이어만 보여야 한다.
3. 켠 뒤 도형·스타일이 지도에 보여야 한다.
