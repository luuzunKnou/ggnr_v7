## 개발목표

지도에서 우클릭하면 곧바로 필지정보 패널을 열지 않고, 커서 근처에 레거시와 같은 플로팅 메뉴를 띄운다. 메뉴에서 «상세보기»를 고르면 현재 주소정보 패널을 연다. 주소·좌표 복사, 외부 지도, 토지이음·이음지도·도시계획도는 메뉴에서도 바로 쓸 수 있게 하며, 패널 안 동일 버튼과 중복을 허용한다. 전 프로젝트 공통이며, 같은 필지 재우클릭으로 패널을 닫는 동작은 쓰지 않는다.

## 플로우차트

```
지도 우클릭 → 플로팅 메뉴 → (상세보기) → 필지정보 패널
```

## 화면설계

### MAP-RCLICK-01 우클릭 플로팅 메뉴

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                          [레이어] │
│ ┌──────┐                                                 │
│ │사이드│              ┌ 지도 영역 ──────────────────┐   │
│ │ 바   │              │                             │   │
│ │      │              │      ┌──────────────┐       │   │
│ │      │              │      │ 주소정보     │       │   │
│ │      │              │      │ 상세보기     │       │   │
│ │      │              │      │ 지번 … [복사]│       │   │
│ │      │              │      │ 도로명 …[복사]│       │   │
│ │      │              │      │ 위치정보·좌표│       │   │
│ │      │              │      │ 카카오 네이버│       │   │
│ │      │              │      │ 구글 토지이음│       │   │
│ │      │              │      │ 이음지도 도시│       │   │
│ │      │              │      └──────────────┘       │   │
│ └──────┘              └─────────────────────────────┘   │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 지도를 우클릭하면 클릭 위치 근처에 메뉴가 열린다.
2. 메뉴에 지번·도로명·좌표가 채워지고, 복사와 외부 연결을 바로 할 수 있다.
3. «상세보기»를 누르면 기존 우측 필지정보 패널이 열린다.
4. 메뉴 바깥을 클릭하거나 닫기를 누르면 메뉴만 닫힌다.

#### 확인사항

1. 우클릭 직후 필지정보 패널이 바로 열리지 않아야 한다.
2. «상세보기» 후에만 우측 필지정보 패널이 열려야 한다.
3. 지번·도로명·좌표 복사가 동작해야 한다.
4. 카카오·네이버·구글·토지이음·이음지도·도시계획도 연결이 동작해야 한다.

### MAP-RCLICK-02 상세보기 후 필지정보 패널

```
┌──────────────────────────────────────────────────────────┐
│ [검색]                                          [레이어] │
│ ┌──────┐                                    ┌──────────┐ │
│ │사이드│           지도                     │ 필지정보 │ │
│ │ 바   │                                    │ (기존)   │ │
│ │      │                                    │ 주소·탭  │ │
│ │      │                                    │ 외부지도 │ │
│ └──────┘                                    └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 패널 구성·탭·조회 방식은 현재 화면을 유지한다.
2. 패널 안의 복사·외부지도·이음 버튼은 그대로 둔다.
3. 메뉴는 상세보기 선택 후 닫힌다.

#### 확인사항

1. 상세보기 후 패널 내용이 기존과 같아야 한다.
2. 패널을 닫아도 지도 우클릭 메뉴는 다시 열 수 있어야 한다.
