## 개발목표

지도 사이드바에 «지적기록물» 메뉴를 추가한다. 메뉴를 열면 좌측에 기록물 목록이 나오고, 한 건을 고르면 옆에 속성 패널이 열린다. 속성 아래에 그 기록물의 첨부파일이 보이며, 첨부파일을 누르면 기존 파일 뷰어로 스캔본을 본다.

이번 범위는 임시 자료로 만드는 화면이며, 서버 조회·저장·지도 도형 표시는 포함하지 않는다. 실제 자료 연결 시 임시 자료만 바꾸면 되도록 화면과 자료를 분리한다.

## 플로우차트

```
지도 → 지적기록물 목록 → (행 선택) → 속성·첨부 → (첨부 클릭) → 뷰어
```

## 화면설계

### MAP-RECORD-01 기록물 목록

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│메뉴│ 지적기록물                 X │ [검색                         ]      │
│    ├──────────────────────────────┤                                      │
│지적│ [종류▼] [읍면동▼] [연도▼]    │                                      │
│기록│ [검색 (지번, 관리번호)     ] │                                      │
│물  ├──────────────────────────────┤                                      │
│    │ 종류   소재지  지번  연도 첨부│                                      │
│지적│ 토지대장 명륜동 115  2018  2 │                                      │
│재조│ 지적도  길안면 고란리1 2019 3│                                      │
│사  │ 분할측량 서후면 교리78 2023 4│                                      │
│    │ ...                          │                                      │
│    ├──────────────────────────────┤                                      │
│    │ 12건                         │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 사이드바 «지적기록물»을 누르면 좌측에 목록 패널이 열린다.
2. 종류·읍면동·연도 선택과 검색으로 목록을 좁힌다.
3. 행에는 종류·소재지·지번·생산연도·첨부 건수가 보인다.
4. 행을 누르면 선택 표시되고 옆에 상세 패널이 열린다.
5. 메뉴를 닫으면 목록과 상세가 함께 닫힌다.

#### 확인사항

1. 사이드바에 «지적기록물»이 보여야 한다.
2. 종류를 고르면 해당 종류만 목록에 남아야 한다.
3. 행을 누르면 선택 표시되어야 한다.
4. 메뉴를 닫으면 패널이 사라져야 한다.

### MAP-RECORD-02 속성·첨부

```
┌────┬──────────────────────┬────────────────────────────┬───────────────────┐
│메뉴│ 지적기록물         X │ 토지대장 명륜동 115      X │                   │
│    ├──────────────────────┤ 속성                       │                   │
│    │ 토지대장 명륜동 ■선택 │ 관리번호 / 종류 / 소재지   │                   │
│    │ 지적도  길안면        │ 지번 / 지목 / 면적         │                   │
│    │ 분할측량 서후면       │ 생산연도 / 등록일 / 면수   │                   │
│    │                      ├────────────────────────────┤                   │
│    │                      │ 첨부파일 (2)               │                   │
│    │                      │ 토지대장_표지.jpg          │                   │
│    │                      │ 토지대장_본문.jpg          │                   │
└────┴──────────────────────┴────────────────────────────┴───────────────────┘
```

#### 설명

1. 상세 위쪽에 관리번호·종류·소재지·지번·지목·면적·생산연도·등록일·보존기간·면수·담당·비고가 나온다.
2. 아래쪽에 그 기록물에 묶인 첨부파일 목록이 파일명·크기·등록일과 함께 나온다.
3. 첨부가 없으면 «첨부파일 없음» 안내가 나온다.
4. 상세 닫기를 누르면 목록만 남는다.

#### 확인사항

1. 선택한 행의 속성이 상세에 나와야 한다.
2. 첨부 건수가 목록의 숫자와 같아야 한다.
3. 첨부가 없는 건은 «첨부파일 없음»이 나와야 한다.
4. 다른 행을 누르면 속성과 첨부가 바뀌어야 한다.

### MAP-RECORD-03 첨부 뷰어

```
┌────┬──────────────────────┬────────────────────────────┬───────────────────┐
│메뉴│ 지적기록물         X │ 토지대장 명륜동 115      X │                   │
│    ├──────────────────────┤ 첨부파일                   │                   │
│    │ ...                  │ 토지대장_표지.jpg  ■클릭   │                   │
│    │                      │                            │                   │
│    │                      │  ┌──────────────────────┐  │                   │
│    │                      │  │ 토지대장_표지.jpg  X │  │                   │
│    │                      │  │                      │  │                   │
│    │                      │  │   (스캔 미리보기)    │  │                   │
│    │                      │  │                      │  │                   │
│    │                      │  └──────────────────────┘  │                   │
└────┴──────────────────────┴────────────────────────────┴───────────────────┘
```

#### 설명

1. 미리보기 가능한 첨부(그림)를 누르면 화면 위에 뷰어가 열린다.
2. 같은 기록물의 그림 첨부는 뷰어에서 앞뒤로 넘길 수 있다.
3. 미리보기 없는 파일은 뷰어가 열리지 않는다.
4. 뷰어 닫기를 누르면 상세 화면으로 돌아온다.

#### 확인사항

1. 그림 첨부를 누르면 뷰어가 열려야 한다.
2. 여러 장이 있으면 다음·이전으로 넘겨야 한다.
3. 미리보기 없는 파일은 뷰어가 열리지 않아야 한다.
4. 뷰어를 닫으면 목록·상세가 그대로 남아야 한다.
