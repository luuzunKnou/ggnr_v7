## 개발목표

개발자 모드에 «프로젝트 구성» 화면을 추가한다. 현재 프로젝트의 시스템 노출·기능 숨김·시스템별 레이어 그룹을 한 화면에서 보고 runtime 설정에 저장한다. 공통 시스템·기능 목록 파일은 수정하지 않는다.

## 플로우차트

개발자모드 → 프로젝트구성 → 시스템·기능·레이어그룹 선택 → 저장 → 지도·데이터조회 반영

## 화면설계

### DEV-PROJ-01 프로젝트 구성

```
┌────────────────────────────────────────────────────────────┐
│ [사이드] 개발자모드          │ 프로젝트 구성                  │
│  · 시스템 목록관리           │ ggnr_ad · …/ggnr_ad.runtime.env │
│  · 기능 목록관리             ├────────────────────────────────┤
│  · 프로젝트 구성 ←선택       │ 시스템                          │
│  · …                         │ ☑ 상수도  ☐ 하수도  ☑ 하천 …   │
│                              │                                │
│                              │ 기능 (이 프로젝트에서 숨김)     │
│                              │ ☑ 데이터조회  ☐ 점용대장 …      │
│                              │                                │
│                              │ 레이어 그룹 — [상수도 ▼]        │
│                              │ ☑ 상수  ☐ 하수  ☑ 하천 …        │
│                              │                                │
│                              │              [저장]            │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 메뉴 «프로젝트 구성»을 열면 현재 프로젝트와 설정 파일 경로가 보인다.
2. 시스템 목록은 공통 카탈로그 기준이며, 체크한 항목만 이 프로젝트에 노출된다.
3. 기능은 카탈로그 전체에서 «숨김»을 체크하면 이 프로젝트 메뉴에서 빠진다.
4. 켜진 시스템을 고르면 그 시스템의 레이어 그룹을 고를 수 있고, 저장 후 데이터조회에 쓰인다.
5. 저장은 프로젝트 runtime 파일의 관련 키만 갱신한다.

#### 확인사항

1. 개발자 모드 사이드바에 «프로젝트 구성»이 보여야 한다.
2. 시스템을 끄고 저장하면 메인·지도 시스템 목록에서 빠져야 한다.
3. 기능을 숨김으로 저장하면 해당 시스템 사이드바 메뉴에서 빠져야 한다.
4. 레이어 그룹을 바꾼 뒤 해당 시스템 데이터조회에 반영되어야 한다.
5. 저장 후 시스템 변수 화면에서 같은 키가 갱신되어 있어야 한다.
