## 현재 구현범위

**단수구역**
제수변 잠금 후 단수 관로·면 미리보기, 수용가·도로명·필지, 도형 편집(기존 수정·읍면동리·직접그리기), 분석결과저장·새 분석, 세션 이력, 누수·송수에서 이어가기가 있다. 배경에 급수관로·제수변을 보여 준다. 추적 결과가 현장 기대(잠근 뒤 끊기는 하류만)와 어긋나는 경우가 있다.

**누수분석**
관망 스냅으로 누수 위치를 잡고 잠글 제수변 목록을 보여 준다. 세션 이력·새 분석·분석결과저장, 단수구역으로 이어가기가 있다. 제수변은 차단용만 대상으로 한다.

**송수경로**
정수장·배수지 목록을 고르면 관로 유수방향(도형 시작→끝)을 따라 하류 송수 경로·흐름 애니메이션을 보여 준다. 제수변 열림·잠금·선택 표시가 배경 관로와 어긋나 보이는 경우가 있다.

**위상검증**
검증실행 시 접합확인필요·유수방향 확인필요 오류를 지도와 목록으로 보여 준다. 목록에서 고르면 해당 위치로 이동한다.

## 개발목표

이미 있는 화면·동작은 여기에 다시 쓰지 않는다. 아래는 **손볼 필요가 확인된 항목**과 **이번 계획 밖 미구현**만 둔다.

**1. 단수구역 — 탐색·면·수용가·필지**
잠근 제수변 뒤 끊기는 하류만 잡히도록 탐색을 고친다. 멀리 떨어진 조각·과다 탐색을 줄이고, 단수 관로에 맞는 구역 면과 그 안의 수용가·도로명·필지가 맞게 나오도록 한다.

**2. 송수경로 — 제수변 표시 위치**
송수 관로 제수변의 열림·잠금·선택 표시가 배경 관로와 어긋나지 않도록 한다.

**3. 이후(이번 계획 밖)**
문자 발송·연락처.

## 플로우차트

단수구역 → 제수변 잠금 → 관로·면·수용가 미리보기 → 분석결과저장 → 세션 이력 ⇄ 도형편집 → (새 분석) 잠금부터

누수분석 → 관망 스냅 → 잠글 제수변 → 분석결과저장 → 세션 이력 → (이어가기) 단수구역

송수경로 → 정수장·배수지 선택 → 하류 경로·애니메이션 → 제수변 열림·잠금 → (이어가기) 단수구역

위상검증 → 검증실행 → 오류 목록·지도 → (항목 선택) 위치 확인
