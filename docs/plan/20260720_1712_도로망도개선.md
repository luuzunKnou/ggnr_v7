# 작업계획서

2026-07-20 | gyujin | 도로망도 개선(개설·필터·도형·모달)

## 개발목표

도로망도에서 개설여부를 모든 도로종류에 두고 목록에서 바로 걸러 볼 수 있게 한다. 도로종류 칩은 한 줄로 두고 종류가 늘어나도 가로 스크롤로 모두 고를 수 있게 한다. 노선 도형 수정은 도로점용과 같이 지도 위 안내·도형추가·초기화·도형삭제로 맞춘다. 유지보수·민원은 목록에서 고르면 모달로 상세를 보고 그 안에서 수정·삭제한다.

## 플로우차트

목록(종류·개설 필터) → 상세 → (도형 수정·지도 배너) → 완료 · 유지보수·민원 목록 → 모달 상세 ⇄ 수정·삭제

## 화면설계

### RN-01 목록 필터

```
┌──────────────────────────────────────────────────────────┐
│ [사이드바]  │ 검색·필터·목록          │ 지도 │ 상세     │
│ 도로망도*   │ 통합검색|도형|행정경계  │      │          │
│            │ [검색창…………………]         │      │          │
│            │ ←전체 국도 … 임도→(스크롤)│      │          │
│            │ 전체 개설 미개설         │      │          │
│            │ (목록…)                 │      │          │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 도로종류 칩은 한 줄이며 넘치면 가로로 스크롤한다.
2. 개설여부 칩은 종류와 관계없이 항상 보이며 건수를 함께 표시한다.
3. 통합검색·종류·개설을 함께 적용해 목록과 지도 노선을 걸러 본다.

#### 확인사항

1. 종류 칩이 두 줄로 줄바꿈되지 않아야 한다.
2. 모든 도로종류에서 개설·미개설 필터가 동작해야 한다.
3. 종류가 늘어나도 스크롤로 모든 칩을 고를 수 있어야 한다.

### RN-02 도형 수정

```
┌──────────────────────────────────────────────────────────┐
│ [사이드바]  │ 목록 │ 지도(노선 편집)     │ 상세 속성   │
│            │      │  ┌안내·추가·초기화·삭제┐ │ 완료·취소 │
│            │      │  └──────────────────┘ │            │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. «도형 수정/그리기»로 편집에 들어가면 지도 위에 안내와 도형추가·초기화·도형삭제가 뜬다.
2. 도형추가는 기존 선을 지우고 다시 그리고, 끝나면 정점 수정으로 이어진다.
3. 완료로 확정하고 취소로 편집 전 상태로 되돌린다.

#### 확인사항

1. 도로점용과 같은 버튼 구성(추가·초기화·삭제)이 보여야 한다.
2. 취소 시 편집 전 노선으로 돌아와야 한다.
3. 도형삭제 후 다시 그릴 수 있어야 한다.

### RN-03 유지보수·민원 모달

```
┌──────────────────────────────────────────────────────────┐
│ 목록 │ 지도 │ 상세                                     │
│      │      │ 유지보수·민원 카드 목록                 │
│      │      │ ┌──────── 모달 상세 ────────┐            │
│      │      │ │ 내용·현장·첨부 · 수정·삭제 │            │
│      │      │ └──────────────────────────┘            │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 카드를 누르면 모달로 상세가 열리고 지도 현장도 강조·이동한다.
2. 모달에서 수정·저장·삭제를 처리한다.
3. «추가»는 빈 내용 모달을 연다.

#### 확인사항

1. 카드 클릭 시 인라인 편집이 아니라 모달이 열려야 한다.
2. 모달에서 저장·삭제 후 목록이 갱신되어야 한다.
3. 현장에서 위치 지정이 모달 연 상태에서도 가능해야 한다.
