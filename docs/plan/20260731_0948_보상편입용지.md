# 작업계획서

2026-07-31 | gyujin | 보상편입용지 UI 목업 요청

## 개발목표

지도 사이드바 하천 그룹에 이름만 등록되어 있던 «보상편입용지» 메뉴에 실제 화면을 만든다. 메뉴를 열면 건명 목록이 패널로 뜨고, 목록에서 건을 선택하면 옆에 상세 패널이 열려 조직·정책·단위·세부·편성목·통계목 속성과 편입 필지 목록을 보여준다. 이번 작업은 화면(UI)만 구성하는 목업 단계로, 실제 서버 저장 없이 화면 안 예시 데이터로 등록·수정·삭제 동작까지 확인할 수 있게 만들고, 필지 목록에서 행을 선택하면 지도에 위치가 표시되도록 한다.

## 플로우차트

```
지도 → 보상편입용지 목록 → (건 선택) → 보상편입용지 상세 → 필지 목록 → (필지 선택) → 지도 위치 표시
```

## 화면설계

### MAP-RIVERREWARD-01 보상편입용지 목록

```
+----------------------------------------------------------------------+
|통합지도 [로그인]                                                     |
+----------------------------------------------------------------------+
|메뉴          |[측정][주소검색][메모][민원][필지분석][레이어]         |
|- 지도        |             |                           |             |
|- 하천기본계획|                                                       |
|- 점용대장    |                                                       |
|- 공사대장    |                                                       |
|* 보상편입용지|보상편입용지 [건명검색____] [+]                        |
|- 필지분석    |+-------------------------+|                           |
|- 레이어      |건명                       |(지도 영역)                |
|              |+-------------------------+|                           |
|              |OO천 정비사업 보상용지     |                           |
|              |XX천 하상정비 보상용지     |                           |
|              |VV천 제방보강 보상용지     |[+][-][현위치]             |
|              |+-------------------------+|                           |
+----------------------------------------------------------------------+
```

#### 설명

1. 사이드바 하천 그룹에서 «보상편입용지»를 선택하면 지도 옆에 건명 목록 패널이 열린다.
2. 목록 상단 검색창에 건명을 입력하면 목록이 즉시 걸러진다.
3. «+» 버튼을 누르면 새 건이 목록에 추가되고 바로 상세 패널이 열려 입력할 수 있다.
4. 목록의 건을 클릭하면 상세 패널이 목록 옆에 열린다 (화면 2).

#### 확인사항

1. «보상편입용지» 메뉴가 선택된 상태로 표시되어야 한다.
2. 등록된 건이 없으면 «등록된 건이 없습니다» 안내가 나와야 한다.
3. 검색어와 일치하는 건명만 목록에 남아야 한다.
4. 다른 하천 기능(하천기본계획·점용대장·공사대장) 패널과 동시에 열리지 않아야 한다.

### MAP-RIVERREWARD-02 보상편입용지 상세

```
+----------------------------------------------------------------------+
|통합지도 [로그인]                                                     |
+----------------------------------------------------------------------+
|메뉴          |[측정][주소검색][메모][민원][필지분석][레이어]         |
|- 지도        |             |                           |             |
|* 보상편입용지|건명         |보상편입용지 상세          |(지도        |
|- 필지분석    |+-----------+|[수정][삭제][닫기]         |영역)        |
|- 레이어      |OO천 정비    |건명 OO천 정비사업         |             |
|              |사업 보상    |조직 치수과                |필지         |
|              |             |정책 하천정비사업          |선택 시      |
|              |XX천 하상    |단위 하천환경정비          |하이라       |
|              |정비 보상    |세부 OO천 정비사업         |이트         |
|              |             |편성목 공유재산관리비      |표시         |
|              |+-----------+|통계목 보상금              |             |
|              |             |필지 목록 [+ 추가]         |             |
|              |             |+-------------------------+|             |
|              |             |읍면동|편입면적|보상금액   |             |
|              |             |+-------------------------+|             |
|              |             |울진읍|120.0 |24,000천원   |             |
|              |             |근남면|85.0  |17,000천원   |             |
|              |             |+-------------------------+|             |
+----------------------------------------------------------------------+
```

#### 설명

1. 목록에서 건을 선택하면 목록 패널 오른쪽에 상세 패널이 열린다.
2. 상세 패널 위쪽에는 건명과 조직·정책·단위·세부·편성목·통계목 속성이 나오고, «수정»을 누르면 값을 바로 고칠 수 있다.
3. 속성 아래 필지 목록 표에는 읍면동·지번(당초)·지번(편입)·당초면적·편입면적·지목·새롬감정·대호감정·적용단가·보상금액·토지소유자 주소·토지소유자 성명·비고가 열로 나오며, 열이 많아 좌우로 스크롤한다.
4. «+ 추가» 버튼을 누르면 필지 입력창이 별도 팝업으로 뜨고, 저장하면 표에 한 행이 추가된다.
5. 표에서 필지 행을 클릭하면 지도에 해당 위치가 표시되고 지도가 그 위치로 이동한다.
6. 필지 행마다 «수정»·«삭제» 버튼이 있어 값 변경과 삭제도 화면에서 바로 확인할 수 있다.

#### 확인사항

1. 상세 패널을 닫으면 지도의 필지 위치 표시도 함께 사라져야 한다.
2. «수정» 중 «취소»를 누르면 값이 원래대로 돌아와야 한다.
3. 건을 «삭제»하면 목록과 상세 패널에서 함께 사라져야 한다.
4. 필지를 추가·수정·삭제해도 실제 서버에는 저장되지 않고 화면 안에서만 반영되어야 한다 (이번 단계는 UI 목업).
5. 필지 목록에서 다른 행을 선택하면 이전 필지의 지도 표시가 새 필지 위치로 바뀌어야 한다.
