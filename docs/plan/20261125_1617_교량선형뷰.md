## 개발목표

교량 면형에서 방향 맞는 양쪽 선을 만든 뷰를 두고, 스타일을 붙여 지도에 보여 준다. 도로대장 주요시설을 켜면 지도에는 이 선형이 나오고, 시설 목록·건수는 기존 교량 속성을 쓴다.

## 플로우차트

원본 교량 → 선형 뷰 → 스타일·레이어 등록 → 주요시설 켜기 → 지도 선형 표시

## 화면설계

### MAP-BRDG-01 주요시설 교량 표시

```
┌──────────────────────────────────────────────────────┐
│ [로고]  검색…                              레이어…   │
├────┬─────────────────────────────────────────────────┤
│메뉴│                                                 │
│ …  │              (지도)                             │
│도로│         ════╗          ╔════                    │
│대장│             ║  교량선형 ║                       │
│    │             ╚══════════╝                       │
│    │  ┌─────────────────────┐                        │
│    │  │ 도로대장 상세       │                        │
│    │  │ [주요시설] …        │                        │
│    │  └─────────────────────┘                        │
└────┴─────────────────────────────────────────────────┘
```

#### 설명

1. 주요시설을 켜면 교량은 면형이 아니라 양쪽 선으로 보인다.
2. 시설 목록의 교량 항목·건수는 기존과 같이 속성 기준으로 나온다.
3. 레이어 목록에서 교량 선형 레이어를 따로 켜고 끌 수 있다.

#### 확인사항

1. 주요시설 켜기 시 교량이 선으로 보여야 한다.
2. 교량 목록·건수가 이전과 같아야 한다.
3. 원본 교량 면형만 켜도 기존처럼 면으로 볼 수 있어야 한다.
