## 개발목표

도로영상은 처음에는 서버 자동 맞춤을 쓰고, 어긋나면 관리 계정이 «수동 기준점»으로 지도 위치와 영상 시각을 저장한 뒤 «다시 분석»으로 다시 맞춘다. 자동으로 만든 위치 자료와 수동 점은 따로 두어, 다시 맞춰도 수동 점은 남는다.

## 플로우차트

```
도로영상 → 자동맞춤 → (어긋남) → 수동기준점 → 지도위치·시간입력 → 다시분석 → 도로영상
```

## 화면설계

### ROAD-VID-LM-01 수동 기준점

```
┌──────────────────────────────────────────────────────────────┐
│ 사이드 │ 검색                                              │
│  도로  │ ┌──────────────────────────────────────────────┐ │
│  대장  │ │                  지  도                       │ │
│        │ │         · 노선 · 차 · (기준점 핀)              │ │
│        │ └──────────────────────────────────────────────┘ │
│        │  ┌─────────────────────────────┐                 │
│        │  │ 도로영상          [수동기준점][다시분석] × │ │
│        │  │ 상행 | 하행                              │ │
│        │  │ 360° 화면                                │ │
│        │  │ 기준점 목록: 1:12 · 498m  [삭제]         │ │
│        │  │ (찍기 중) 위치 확정 → 시간 [1:12] [저장] │ │
│        │  └─────────────────────────────┘                 │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 관리 계정만 «수동 기준점»·«다시 분석»이 보인다.
2. «수동 기준점»을 켜면 지도 노선을 클릭해 위치를 정한다.
3. 위치가 정해지면 시간 입력란이 뜨고, 현재 재생 시각이 기본값이며 고칠 수 있다.
4. 저장 후 목록·지도 핀에 반영되고, «다시 분석»으로 서버 대기열에 넣는다.

#### 확인사항

1. 일반 계정에는 수동 기준점 단추가 보이지 않아야 한다.
2. 시간 없이 위치만 찍은 상태에서는 저장되지 않아야 한다.
3. 다시 분석 후에도 수동 기준점 목록이 남아 있어야 한다.
4. 상행 이어 재생에서 찍은 시각이 해당 분할에 맞게 저장되어야 한다.
