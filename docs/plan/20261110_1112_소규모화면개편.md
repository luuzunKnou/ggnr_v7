# 작업계획서

## 개발목표

후보지는 유형 탭에 «전체»를 두고, 상세 수정·삭제 버튼을 아래로 옮긴다. 상세 탭을 후보지 과거이력·일반관리 평가 이력·위험도 평가 이력·첨부파일로 나눈다. 후보지 과거이력은 후보지 평가표(여·부 항목, 하나라도 «여»면 선정제외)로 등록·수정하고, 최근 평가가 선정제외면 시설이 제외가 된다. 일반관리 평가 이력은 해마다 마지막 위험도 평가로 정해진 평가구분(일반·관리·위험)을 보여 준다. 위험도 평가를 등록하면 등급으로 평가구분이 자동으로 정해진다(양호 일반, 보통 관리, 불량 위험).

안전점검은 보고서 단위로 바꾼다. 목록은 보고서이고, 검색 옆에 연도 필터를 두며 시설 유형 탭은 없앤다. 보고서를 고르면 상세에 보고서 개요(속성)와 점검 대상 시설 목록이 나온다. 시설을 고르면 그 시설의 점검 내용(이력·상세·점검 등록)이 모달로 열린다. 상세의 «보고서 다운로드»는 점검 대상 목록과 사업발주 근거자료로 쓸 수 있는 문서로 내려받는다. «보고서 추가»는 그 시점 일반·관리 시설을 자동으로 넣고 보고서 내용을 쓰게 한다.

정비계획은 지도 없이 화면을 꽉 채운 중기계획 명세서 양식(전체 정비계획·정비된 부분·중기 정비계획 계와 5개 연도·사업효과·5개년 후·우선순위, 맨 위 계)으로 보여 준다. 기존 계획(확정)은 개요와 결과만 보이고, 새로 위험시설이 된 시설만 «분석»에서 골라 정비내용·사업비와 보상·기본평가·부가평가·결과 순서로 분석한다. 분석은 모달로 띄우고 읽기 쉽게 다시 꾸미며, 분석 내용은 다운로드와 임시저장을 한다. 확정은 이후 공사대장·실시설계에서 하며, 이번에는 추정⇄검토만 바꾼다.

## 플로우차트

```
후보지 목록 → 시설 상세 → 후보지 과거이력 ⇄ 후보지 평가 / 일반관리 평가 이력 / 위험도 평가 이력 / 첨부파일
안전점검 보고서 목록 → 보고서 상세(개요·점검 대상) → (시설 클릭) → 시설 점검 모달 ⇄ 점검 등록
안전점검 보고서 목록 → 보고서 추가 → 보고서 상세 → 보고서 다운로드
정비계획 명세서 → (분석) → 시설 선택 → 분석 모달: 정비내용 → 사업비·보상 → 기본평가 → 부가평가 → 결과
정비계획 명세서 → (확정 행) → 개요·결과 모달
```

## 화면설계

### SPC-01 후보지 상세

```
┌──────┬──────────────────────┬───────────────────────────────┬──────────────┐
│사이드│ 후보지                │ [세천] 두천리 세천           ✕ │              │
│ 바   │ [전체][세천][소교량]… │ ▾ 속성정보                    │              │
│      │ [전체][일반][관리]…   │ 관리번호 …  시설명 …          │    지  도   │
│      │ 시설명  읍면 구분 등급│ [후보지 과거이력][일반·관리 평가 이력]│              │
│      │                      │ [위험도 평가 이력][첨부파일]  │              │
│      │                      │ 평가일 평가자 결과   [+후보지 평가]│              │
│      │                      │ 2020-01-04 동진… 선정          │              │
│      │                      │               [수정] [삭제]   │              │
└──────┴──────────────────────┴───────────────────────────────┴──────────────┘
```

#### 설명

1. 유형 탭 맨 앞에 «전체»를 두어 모든 유형을 한 목록으로 본다.
2. 상세의 수정·삭제는 아래쪽에 두고, 수정 중에는 그 자리에 저장·취소가 나온다.
3. 후보지 과거이력은 후보지 평가 목록이며 «후보지 평가»로 등록하고, 행을 누르면 평가표 모달에서 수정·삭제한다.
4. 일반·관리 평가 이력은 연도별 평가구분과 근거(그해 마지막 위험도 평가 점검일·등급·점수)를 보여 준다.
5. 정비계획에 들어간 시설은 삭제할 수 없다.

#### 확인사항

1. «전체» 탭에서 모든 유형 시설이 보여야 한다.
2. 후보지 평가에서 항목 하나라도 «여»면 결과가 선정제외로 나와야 한다.
3. 최근 후보지 평가가 선정제외이면 시설 구분이 제외로 바뀌어야 한다.
4. 위험도 평가를 등록하면 그해 일반·관리 평가 이력이 등급에 맞는 구분으로 보여야 한다.

### SPC-02 후보지 평가

```
┌──────┬──────────────────────────────────────────────────────────────────┐
│사이드│ ┌ 후보지 평가 · 두천리 세천 ──────────────────────────────────┐ │
│ 바   │ │ 평가일* [2026-11-10]  평가자 [__________]                    │ │
│      │ │ 구분      평가항목                 기준    제원   여  부     │ │
│      │ │ 시설규모  세천연장 부족 여부       50m 이상 545m  ○  ●     │ │
│      │ │ 시설위치  사유지내(분쟁·민원지역)  ·       ·     ○  ●     │ │
│      │ │ 선정여부  선정                                              │ │
│      │ │ 비고 [________________________]          [삭제] [저장] [취소]│ │
│      │ └────────────────────────────────────────────────────────────┘ │
└──────┴──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 유형별 후보지 평가표(세천은 원본 양식 8항목, 그 밖의 유형은 양식 확인 전 임시 항목)를 보여 준다.
2. 제원은 시설 연장·폭으로 채우고, 모든 항목을 «부»로 고르면 선정, 하나라도 «여»면 선정제외다.

#### 확인사항

1. 고르지 않은 항목이 있으면 저장되지 않아야 한다.
2. 저장한 평가가 후보지 과거이력에 보여야 한다.

### SPI-01 안전점검 보고서 목록·상세

```
┌──────┬──────────────────────┬───────────────────────────────┬──────────────┐
│사이드│ 안전점검  [+보고서 추가]│ 2026년 안전점검            ✕ │              │
│ 바   │ [검색_________][2026▼]│ ▾ 보고서 개요                 │              │
│      │ 연도 보고서명 기준일 대상 점검│ 연도 2026  기준일 2026-01-02  │    지  도   │
│      │ 2026 2026년…  01-02  48  6 │ 대상 48곳  점검 6곳(13%)     │              │
│      │ 2025 2025년…  01-02  48 24 │ [보고서 다운로드][대상 목록 엑셀][인쇄]│              │
│      │                      │ 점검 대상 (48)        [+시설 추가]│              │
│      │                      │ [전체 유형▼][검색____] [전체][점검][미점검]│              │
│      │                      │ 시설명 유형 읍면 점검일 등급 구분│              │
│      │                      │               [수정] [삭제]   │              │
└──────┴──────────────────────┴───────────────────────────────┴──────────────┘
```

#### 설명

1. 목록은 보고서이고 검색 옆 연도로 거른다.
2. 상세 위쪽은 보고서 개요(연도·기준일·제목·점검 기관·작성자·작성일·대상·점검 완료·전년 대비 변동·개요 내용)다.
3. «보고서 다운로드»는 근거자료 문서, «대상 목록 엑셀»은 대상 목록·집계 시트, «인쇄»는 미리보기 후 인쇄다.
4. 점검 대상은 보고서 연도의 점검 여부·마지막 점검일·등급·평가구분을 보여 주고, 시설을 누르면 점검 모달이 열린다.
5. 지도에는 고른 보고서의 대상 시설을 그해 등급 색으로 그린다.

#### 확인사항

1. 연도를 바꾸면 그 연도 보고서만 보여야 한다.
2. 점검 등록 후 점검 대상 목록의 점검일·등급이 바로 바뀌어야 한다.
3. 다운로드한 문서에 대상 목록과 선정 기준·전년 대비 변동이 있어야 한다.

### SPI-02 보고서 추가·시설 점검 모달

```
┌──────┬──────────────────────────────────────────────────────────────────┐
│사이드│ ┌ 보고서 추가 ──────────────────┐ ┌ 두천리 세천 · 2026년 점검 ─┐ │
│ 바   │ │ 연도 [2026▼] 기준일 [____]   │ │ 관리번호 … 위치 … 구분 관리 │ │
│      │ │ 제목 [2026년 안전점검______] │ │ 점검이력          [+점검 등록]│ │
│      │ │ 점검 기관 [____] 작성자 [__] │ │ 점검일 구분 점검자 점수 등급 │ │
│      │ │ 개요 [____________________]  │ │ 점검 상세 …                 │ │
│      │ │ 대상 48곳(일반 29·관리 19)   │ │ [보고서에서 빼기]    [닫기] │ │
│      │ │                 [추가] [취소]│ └────────────────────────────┘ │
│      │ └──────────────────────────────┘                                │
└──────┴──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 보고서 추가는 기준일 시점 일반·관리 시설(계속 점검 시설 포함)을 대상으로 자동으로 넣고, 대상 수를 미리 보여 준다.
2. 시설 점검 모달은 시설 요약, 점검이력, 점검 상세, 점검 등록·수정·삭제, 평가표 보기를 한 곳에서 한다.
3. 상세의 «시설 추가»로 위험시설 재점검 등 대상 밖 시설을 보고서에 넣고, 모달의 «보고서에서 빼기»로 뺀다.

#### 확인사항

1. 같은 연도 보고서가 이미 있으면 추가 전에 확인을 물어야 한다.
2. 모달 위에서 점검 등록 창을 열고 닫아도 아래 모달은 유지되어야 한다.

### SPP-01 정비계획 명세서

```
┌──────┬────────────────────────────────────────────────────────────────────────────┐
│사이드│ 정비계획  중기 정비계획 명세서(단위 m, 백만원, %)  [분석][연차 배분][엑셀]   ✕ │
│ 바   │ [검색____][전체 읍면▼][전체 상태▼][계획 시작 2026▼]                          │
│      │ 대상 10곳 · 총사업비 · 1단계 · 2단계 · 분석 중 3곳                           │
│      │ 시설 위치 전체정비계획 정비된부분   중기정비계획                       5개년후 우선│
│      │ 명칭      사업량 사업비 사업량 사업비 정비율 계  2026 2027 … 사업효과    정비대상 순위│
│      │ 계                                                                            │
│      │ 이평리 소교량 …                                                               │
└──────┴────────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 지도 없이 사이드바 오른쪽을 꽉 채운 명세서 표다. 맨 위 줄은 계이고, 연도 칸은 계획 시작 연도부터 5개다.
2. 한 시설 사업비는 배분한 연도에 모두 들어가고, 정비율은 정비된 사업량÷전체 사업량, 중기 계 정비율은 중기 사업량÷전체 사업량이다.
3. 추정·검토 행은 시설명 옆에 상태를 붙이고 누르면 분석 모달, 확정 행은 개요·결과 모달이 열린다.
4. «분석»은 새로 위험시설이 된 시설과 추정·검토 중 시설을 골라 분석 모달을 연다.
5. «연차 배분»은 확정 시설 연차는 그대로 두고 추정·검토 시설만 한도 안에서 배분한다.

#### 확인사항

1. 맨 위 계가 아래 행 합과 같아야 한다.
2. 계획 시작 연도를 바꾸면 연도 머리줄이 바뀌어야 한다.
3. 엑셀이 명세서 칸 순서와 같아야 한다.

### SPP-02 분석 모달

```
┌──────┬────────────────────────────────────────────────────────────────────────────┐
│사이드│ ┌ 봉평리 세천 정비계획 분석 · 세천 · 죽변면 봉평리 · 추정 ────────────────┐ │
│ 바   │ │ ①정비내용 ─ ②사업비·보상 ─ ③기본평가(1) ─ ④부가평가 ─ ⑤결과          │ │
│      │ │ 연장 296m · 폭 1.6m · 위험시설 지정일 [2020-12-31] · 최근 점검 불량 74점 │ │
│      │ │ ┌ 정비 공종·수량 ───────────────────────┐ ┌ 요약 ────────────┐      │ │
│      │ │ │ 공종     수량  단가   금액   출처        │ │ 총점 55 / 100     │      │ │
│      │ │ │ 호안정비 296m  195,000 57.7 자동        │ │ 예상 순위 5위 ▲1  │      │ │
│      │ │ └─────────────────────────────────────┘ │ 사업비 92.7       │      │ │
│      │ │                                          │ 완성도 91%        │      │ │
│      │ │ [다운로드] 법령·고시 기준 개략 산정  [이전][임시저장][다음][검토 요청]│ │
│      │ └──────────────────────────────────────────────────────────────────────┘ │
└──────┴────────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 위쪽 단계 표시로 다섯 단계를 오가고, 단계마다 미입력 수를 붙인다.
2. 단계 표시 아래에 시설 개요 한 줄과 위험시설 지정일 입력을 둔다.
3. 글자·표·입력칸을 키우고 단계별 내용을 구획으로 나눠 읽기 쉽게 한다.
4. «다운로드»는 개요·공종·필지·평가·결과를 엑셀로 내려받고, «임시저장»은 계획에 반영한다.
5. 추정은 «검토 요청», 검토는 «추정으로 되돌리기»가 있고, 검토 중에는 읽기만 한다.

#### 확인사항

1. 저장하지 않고 닫으면 확인을 물어야 한다.
2. 검토 중인 시설은 값을 고칠 수 없어야 한다.
3. 다운로드 파일에 단계별 시트가 있어야 한다.
