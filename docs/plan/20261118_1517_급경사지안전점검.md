## 개발목표

지도 사이드바 «급경사지 안전점검»으로 목록을 열고, 행을 고르면 오른쪽에 한글 체크리스트와 같은 안전점검표 상세를 본다. 조회·편집·단건 인쇄와 지도 위치 강조까지 프로토타입으로 맞춘다. 실제 저장소·도면 연동은 하지 않는다.

## 플로우차트

지도 → 급경사지 안전점검 목록 → (행 선택) → 점검표 상세 ⇄ 편집·저장 → 인쇄

## 화면설계

### MAP-SSS-01 급경사지 안전점검 목록

```
┌──────┬──────────────────────────────┐
│메뉴  │ 급경사지 안전점검        [닫기]│
│      │ [검색........]                 │
│급경  │──────────────────────────────│
│사지  │ 급경사지명 │ 분류 │ 점검일    │
│안전  │ 용성 고죽… │ 인공…│ 2026-08-25│
│점검  │ …                              │
│      │                                │
│      │              [지도]            │
└──────┴──────────────────────────────┘
```

#### 설명

1. 사이드바에서 «급경사지 안전점검»을 고르면 왼쪽 목록이 열린다.
2. 검색어로 급경사지명·장소를 걸러 볼 수 있다.
3. 행을 고르면 오른쪽 상세가 열리고 지도에 위치가 강조된다.

#### 확인사항

1. 메뉴 선택 시 목록이 열려야 한다.
2. 행을 고르면 상세가 함께 열려야 한다.
3. 다른 지도 기능과 동시에 켜지지 않아야 한다.

### MAP-SSS-02 급경사지 안전점검표 상세

```
┌──────┬──────────┬─────────────────────┐
│메뉴  │ 목록     │ 급경사지 안전점검표 │
│      │          │ [인쇄][저장][수정]  │
│      │          │ 점검일시 · 명칭 …   │
│      │          │ 세부점검 있음/없음… │
│      │          │ 세부내용 · 사진     │
└──────┴──────────┴─────────────────────┘
```

#### 설명

1. 상세는 한글 점검표와 같이 기본정보·체크·세부내용·사진 순으로 보인다.
2. 수정 모드에서 체크와 내용을 고치고 저장하면 목록·상세에 반영된다.
3. 인쇄는 같은 서식 모양으로 나온다.

#### 확인사항

1. 있음·없음·해당없음 표시가 보여야 한다.
2. 저장 후 다시 열어도 고친 내용이 남아야 한다(같은 화면 세션).
3. 인쇄 시 점검표 형태가 유지되어야 한다.
