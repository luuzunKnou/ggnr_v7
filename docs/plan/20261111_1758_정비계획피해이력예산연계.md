## 개발목표

정비계획 분석에서 피해이력지수를 후보지 원본에만 묶지 않고, 가져온 뒤 부족한 피해를 추가·수정할 수 있게 한다. 명세서에서는 확정 시설을 모아 기존 예산에 일괄 배정하는 «예산 연계»를 1차로 넣는다.

## 플로우차트

```
분석 평가 → 피해이력 추가·수정 → 저장 → 목록
명세서 → 확정 시설 선택 → 예산 연계 → 배정 → 예산·공사
```

## 화면설계

### PLAN-DMG-01 분석 피해이력

```
┌──────────────────────────────────────────────────────────────────────┐
│ ○○세천 정비계획 분석                                              [X] │
├──────────┬───────────────────────────────────────────────────────────┤
│ 시설 정보 │ 평가 · 피해이력지수                                       │
│ ···      │ 후보지에서 가져온 뒤 추가·수정할 수 있습니다.               │
│          │ 피해 여부  [피해 있음] [피해 없음(0점)]                    │
│          │ 피해 내역 (집계 ···)                    [피해 추가]       │
│          │ 발생일 │ 항목 │ 물량 │ 지원기준지수 │ 가중치 │ 지수 │     │
│          │ ···   │ ··· │ ··· │ ···        │ ···  │ ··· │ [🗑] │
│          │ 피해이력지수 / 100,000 × 25 = ··점                        │
└──────────┴───────────────────────────────────────────────────────────┘
```

#### 설명

1. 분석 시작 시 후보지 피해이력을 초안에 넣고, 이후 분석 초안이 기준이다.
2. «피해 없음»을 고르면 내역을 비우고 0점으로 본다.
3. «피해 추가»로 행을 넣고 발생일·항목·물량을 채우면 지수가 다시 계산된다.

#### 확인사항

1. 후보지에 없는 피해를 분석에서 추가한 뒤 저장하면 점수에 반영되어야 한다.
2. «피해 없음»을 고르면 0점이 되어야 한다.
3. 저장하지 않고 닫으면 목록에 남지 않아야 한다.

### PLAN-BUD-01 예산 연계

```
┌──────────────────────────────────────────────────────────────────────┐
│ 정비계획   [분석] [예산 연계 N] [엑셀]                            [X] │
├──────────────────────────────────────────────────────────────────────┤
│ □ │ 시설명 │ …                                                      │
│ ☑ │ 확정시설A │ …                                                   │
│ □ │ 분석중시설 │ (선택 불가)                                         │
└──────────────────────────────────────────────────────────────────────┘
                    ↓ «예산 연계»
┌──────────────────────────────────────────────────────────────────────┐
│ 예산 연계                                                         [X] │
│ [2026년 ▼] [군비 · ○○사업 ▼]                                        │
│ 시설명 │ 위치 │ 순위 │ 계획 사업비 │ 배정액 │ 상태                   │
│ ···   │ ··· │ ··· │ ···      │ [원]  │ 배정 가능/이미 배정       │
│                              [배정] [취소]                           │
└──────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 확정 이후 시설만 체크할 수 있고, 선택한 뒤 «예산 연계»를 누른다.
2. 연도·예산을 고르고 시설별 배정액(기본은 계획 사업비)을 넣은 뒤 «배정»한다.
3. 이미 그 예산에 있는 시설은 건너뛰고, 끝나면 예산·공사 화면으로 전환한다.

#### 확인사항

1. 분석 중 시설은 선택할 수 없어야 한다.
2. 배정 합이 예산 잔액을 넘으면 저장되지 않아야 한다.
3. 배정 후 예산·공사 화면이 열려야 한다.
