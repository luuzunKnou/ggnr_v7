## 개발목표

지도 사이드바 «국공유재산 사용허가»로 허가 목록·상세를 보는 프로토타입을 만든다. 점용대장과 같은 목록·상세·지도 강조 패턴을 따르되, 메뉴·데이터는 별도이다. 국유·공유 구분과 허가기간·당해 사용료를 목업으로 확인한다.

## 플로우차트

```
지도 → 국공유재산 사용허가 목록 → (행 선택) → 허가 상세 ⇄ 수정 → 목록
```

## 화면설계

### MAP-PPP-01 사용허가 목록

```
┌────────사이드바────────┬──────────────지도──────────────────────────┐
│ …                     │                                           │
│ 국공유재산 사용허가    │                                           │
│ …                     │                                           │
└───────────────────────┴───────────────────────────────────────────┘
┌─목록──────────────────────────────────┐
│ 국공유재산 사용허가            [+][×] │
│ [검색…………………………………]                │
│ [전체][국유][공유] [진행중][종료]     │
│ 상태│허가번호│국유/공유│용도│종료일   │
│ 진행│00-01  │국유    │가스│25.12.31 │
└───────────────────────────────────────┘
```

#### 설명

1. 사이드바에서 «국공유재산 사용허가»를 선택하면 목록 패널이 열린다.
2. 검색·국유/공유·진행중/종료 필터로 목록을 줄인다.
3. 행을 누르면 상세가 열리고 지도에 위치가 표시된다.
4. 추가 단추로 빈 허가 건 등록 화면으로 간다.

#### 확인사항

1. 메뉴 선택 시 목록만 열리고 점용대장과 섞이지 않아야 한다.
2. 국유·공유 필터가 동작해야 한다.
3. 종료일이 지난 건은 종료로 보여야 한다.

### MAP-PPP-02 사용허가 상세

```
┌─목록──┬─상세──────────────────────────────────────┐
│ …     │ 국공유재산 사용허가              [수정][×]│
│       │ ┌허가정보───────────────────────────────┐ │
│       │ │허가번호 · 구분 · 국유/공유 · 용도 …  │ │
│       │ └──────────────────────────────────────┘ │
│       │ ┌소재지(필지)───────────────────────────┐ │
│       │ │읍면동 · 리 · 본번 · 부번 · 면적       │ │
│       │ └──────────────────────────────────────┘ │
│       │ ┌사용료(당해)───────────────────────────┐ │
│       │ │부과기간 · 산정 · 부과 · 국고/시 …     │ │
│       │ └──────────────────────────────────────┘ │
└───────┴──────────────────────────────────────────┘
```

#### 설명

1. 상세는 허가정보·소재지·사용료 구역으로 나눈다.
2. 수정·저장·삭제는 프로토타입 메모리에만 반영한다.
3. 점용대장 필지·부과 화면과 비슷하게 구역만 두고, 저장 API는 없다.

#### 확인사항

1. 국유·공유 표본 건이 상세에 채워져야 한다.
2. 수정 후 목록에 반영되어야 한다.
3. 닫기·다른 메뉴 전환 시 패널이 남아 있지 않아야 한다.
