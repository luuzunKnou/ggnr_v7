# 작업계획서

2026-07-30 | jdong | 변동이력분석 (살아 있는 지도·세로 타임라인)

## 개발목표

공사·민원 때 「언제 공사했는지」를 추정하던 일을, **정사영상(항공 배경)과 도형 레이어 변경 이력**으로 보는 「변동이력분석」을 만든다.

필지분석과 같이 **영역 지정 → 표시 레이어 → 이력 보기 → 결과**로 들어간다. 결과는 맵캡처가 아니라 **줌·이동 가능한 살아 있는 지도**이다. **왼쪽 세로 타임라인**(날짜 점), **오른쪽 지도**, **아래 변경 레이어 요약**이다. 날짜를 고르면 그날 기준 도형과 **「바로 앞」 정사**(선택일보다 이전인 정사 중 가장 늦은 날)를 쓰고, 없으면 **항공영상**으로 둔다. **가로 변경량 막대 그래프는 쓰지 않는다.** 속성은 보지 않는다.

영역은 도형 또는 행정경계로 지정한다. 넓은 범위는 막지 않고 경고만 한다. 시점 도형은 날짜마다 SHP·발행 레이어를 쌓지 않고, **이력 + 필터**로 「영역 ∩ 선택 레이어 ∩ 선택일」을 맞춘다.

### 주요 데이터

1. **타임라인·날짜** — 레이어 업로드·상세이력(및 필요 시 동기화 로그). 영역·표시 레이어와 관련된 변경일(+정사 갱신일).
2. **날짜별 요약** — 그날 바뀐 레이어 이름.
3. **지도 배경** — 「바로 앞」 자체 정사 타일. 없으면 항공영상.
4. **지도 위 도형** — 선택일 기준 유효 시설(이력 반영). 운영 발행 레이어 본문은 덮어쓰지 않는다.

## 플로우차트

지도 → 변동이력분석 → 영역 지정 → 표시 레이어 → 이력 보기 → 결과(좌 타임라인 · 우 지도 · 하단 요약)

## 기능목록

1. **모드 진입·종료** — 사이드바. 다른 지도 기능과 동시 오픈 안 함.

2. **영역 지정** — 도형 / 행정경계. 넓으면 경고만.

3. **표시 레이어** — 좌측 목록에서 결과·지도에 쓸 레이어만 선택. 기본도 그룹은 숨김.

4. **이력 보기** — 영역·레이어 적용 후 결과 화면.

5. **세로 타임라인** — 날짜 점·연도(전체/연도). 날짜 표기 `YYYY-MM-DD`. 변경량 막대 없음.

6. **살아 있는 결과 지도** — 줌·이동·영역으로 맞추기. 영역 바깥 검정 반투명·노란 경계. 날짜·레이어 변경 시 다시 그림.

7. **바로 앞 정사 / 항공 폴백** — 정사 없으면 항공영상. 「가장 가까운(이후 포함)」 방식은 쓰지 않음.

8. **날짜별 요약** — 바뀐 레이어 이름(알약). 개발용 시나리오 설명 문구는 화면에 내지 않음.

9. **데이터** — 시점 도형 = 이력·필터(실데이터 전 단계는 더미로 검증). 신규 도형 저장 테이블·날짜별 SHP 스냅샷 양산은 두지 않음.

10. **빈 결과·안내** — 타임라인 없음·넓은 영역·정사 없음(항공 폴백 안내). 변경 요약이 있을 때 「시점 도형 없음」 긴 안내는 내지 않음.

## 개발시 이슈되는 부분

1. **시점 도형 = 최신본이 아님**  
   타임라인에서 과거 날짜를 고르면 운영 테이블 최신만 그리면 안 된다.  
   → 이력(추가·제거)을 반영한 그날짜 유효 도형만. 실데이터는 이력 스키마·필터(조회 조건) 확정 후 지도 서버 한 판으로 맞춤.

2. **정사 「바로 앞」**  
   선택일 이하가 아니라 **이전(`<`)** 정사 중 가장 늦은 날. 이후 정사는 제외.  
   → 자체 타일이 없으면 항공영상. 빈 자체 정사 ID를 억지로 쓰지 않음(흰 화면 방지).

3. **영역을 크게 잡으면 느려짐**  
   → 금지 없이 경고만. 결과 지도 요청은 연속 변경 시 잠시 모아 한 번 요청.

4. **하루엔 레이어가 잔뜩 바뀔 수 있음**  
   → 좌측 «표시 레이어»에서만 고름. 결과 지도 위에 레이어 체크 목록은 두지 않음.

5. **타임라인 날짜를 어디서 모을지**  
   업로드·상세이력·정사 메타 등 출처가 여럿이다.  
   → 영역·선택 레이어와 관련된 날(+정사 갱신일). 동기화 로그는 날짜·더미 검증에 쓰고, 지도 도형 본문은 아님.

6. **영역과 이력을 어떻게 걸지**  
   → 기본은 지정 영역과 공간으로 겹치는 것만. 더미 단계는 영역 전제·레이어 필터로 검증하고, 실데이터는 지도 서버 영역 필터로 맞춤.

7. **필지분석·공용과의 겹침**  
   영역 UI는 필지분석 패턴을 빌려 씀. 결과 마스크·항공 배경·노란 경계는 필지분석 결과와 같은 느낌.  
   → 공용 파일 수정은 최소화·승인. 발행 레이어 정의는 바꾸지 않음.

8. **구안과의 차이**  
   맵캡처·가로 막대·이력 SHP 파일 합성은 **하지 않음**. (구 계획서 `20260723_1336` 보존)

9. **프로젝트마다 레이어·정사 유무가 다름**  
   → 있는 것만 노출. 정사 없으면 항공영상·안내.
