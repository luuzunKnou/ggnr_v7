# 작업계획서

2026-11-26 | dev.strcat | 소교량 리 단위 통합 정비계획 연동 요청

## 개발목표

소규모 공공시설 중 소교량은 정비계획에서 위험 소교량을 리 단위로 묶어 한 건으로 다룬다. 소교량만 «리 묶음 매핑 테이블» 하나를 새로 만들어, 리별 묶음 관리번호와 개별 소교량 관리번호를 연결하고, 정비계획 목록은 이 묶음 관리번호로 연동한다. 나머지 시설 유형은 기존처럼 개별 관리번호로 처리한다.

엑셀 중기계획명세서의 소교량 통합 48건을 정비계획 목록에 넣고, 안전점검 이관 화면에서는 소교량을 리 단위 한 줄로 보여 주며 이관 시 해당 리 묶음으로 정비계획에 추가한다. 이미 정비계획에 있는 리는 새 건을 만들지 않고 묶음 구성원만 늘린다.

## 플로우차트

안전점검 보고서 → 이관 목록(소교량은 리 단위) → (이관) → 리 묶음 등록·정비계획 추가 → 정비계획 명세서

## 화면설계

### SP-PLAN-01 안전점검 정비계획 이관

```
┌────────────────────────────────────────────────────────────────┐
│ 정비계획 이관                                              [X] │
│ 위험으로 바뀐 시설을 고른 뒤 «이관»을 누르면 정비계획에 추가됩니다. │
├────────────────────────────────────────────────────────────────┤
│ [전체 유형 v] [시설명·읍면·리명                         ]      │
├────────────────────────────────────────────────────────────────┤
│ [ ] 시설명                    유형     구분 변경       조사일  │
│ [v] 온양리_마을진입로_007     마을진입로 일반 → 위험   2026-10-02│
│ [v] 고성리_소교량_통합 (2곳)  소교량   일반 → 위험     2026-10-05│
│ [ ] 명도리_소교량_통합 (1곳)  소교량   일반 → 위험     2026-10-05│
│     기존 묶음에 추가                                           │
├────────────────────────────────────────────────────────────────┤
│ 2곳 선택                                      [이관] [취소]    │
└────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 소교량은 개별 시설이 아니라 리 단위 묶음 한 줄로 표시되고 괄호에 이번에 위험으로 바뀐 소교량 수가 보인다.
2. 이미 정비계획에 있는 리 묶음은 «기존 묶음에 추가»로 표시되며 선택할 수 있다.
3. 「이관」을 누르면 선택한 리 묶음에 소교량이 등록되고, 정비계획에 없는 리는 작성중으로 새로 추가된다.
4. 소교량 외 유형은 지금처럼 시설 한 곳이 한 줄이다.

#### 확인사항

1. 소교량이 리마다 한 줄로 묶여 보여야 한다.
2. 소교량 외 시설은 기존과 같이 한 곳씩 보여야 한다.
3. 정비계획에 이미 있는 리 묶음도 선택해 이관할 수 있어야 한다.
4. 이관 후 정비계획 목록에 같은 리가 두 줄로 생기지 않아야 한다.

### SP-PLAN-02 정비계획 명세서

```
┌────────────────────────────────────────────────────────────────┐
│ 정비계획 명세서                                                │
├──────────────────────┬──────────┬──────────┬───────────────────┤
│ 시설명칭             │ 위치     │ 전체사업량│ 전체사업비 ...   │
├──────────────────────┼──────────┼──────────┼───────────────────┤
│ 고성리_소교량_통합   │ 고성리   │          │ 38                │
│ 온양리_마을진입로_007│ 온양리   │          │ ...               │
└──────────────────────┴──────────┴──────────┴───────────────────┘
```

#### 설명

1. 소교량은 리 묶음 이름으로 한 줄에 표시되고, 위치는 리 이름이 표시된다.
2. 소교량 외 시설은 관리번호로 찾은 시설명과 위치가 표시된다.

#### 확인사항

1. 소교량 묶음의 시설명칭과 위치가 정상 표시되어야 한다.
2. 엑셀 내보내기에서도 소교량 묶음이 한 줄로 나와야 한다.
