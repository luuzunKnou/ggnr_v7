#### 설명

1. 상세 본문은 서식 제목과 도로정보·건축물 정보·건축물 내용·확인 결과가 한 대장처럼 이어진다.
2. 건축물 내용의 위치는 도로예정지와 접도구역 두 칸으로 나뉜다.
3. 불량 표시는 에이부터 디까지 칸으로 보인다.
4. 확인 결과는 확인일·확인자·결재자를 보여 준다.
5. 첨부파일은 종류 단추 없이 대장 아래에 바로 보인다.

#### 확인사항

1. 상세가 관리대장 서식과 같은 칸 배치로 보여야 한다.
2. 세로로 쓰인 머리글은 없어야 한다.
3. 건축물배치도·종전·변경 단추는 없어야 한다.
4. 첨부 사진이 대장 아래에 바로 보여야 한다.
5. 수정·저장·행 추가는 이전과 같이 동작해야 한다.
