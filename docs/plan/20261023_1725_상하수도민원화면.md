## 개발목표

상수민원, 급수민원, 하수민원, 준설민원은 공통 민원관리와 같은 목록·상세·등록 흐름을 쓴다. 각 메뉴는 자기 자료만 보여 준다. 준설대상지는 별도 목록이 아니라, 준설민원 한 건을 열었을 때 상세 안에 붙는 하위 항목이다. 상수메모, 급수메모, 하수메모, 준설메모는 지금처럼 메모 목록을 유지한다.

## 플로우차트

지도 → 업무별 민원 목록 → 민원 상세 ⇄ 민원 등록

## 화면설계

### MAP-WATER-03 업무별 민원

```
┌ 사이드바 ──────── 목록 ────────────── 지도 ──────── 상세 ─────────┐
│ 상수민원      ┌ 상수민원 ─────────┐              ┌ 민원 정보 ────┐ │
│ 상수메모      │ 검색              │              │ 민원인·주소   │ │
│ 급수민원      │ 전체 접수 점검    │              │ 이력·첨부     │ │
│ 급수메모      │ 카드 목록         │              │ 준설대상지    │ │
└───────────────└───────────────────┘              └───────────────┘─┘
```

#### 설명

1. 민원 메뉴를 누르면 검색, 상태, 카드 목록, 민원 추가가 나온다.
2. 카드를 누르면 오른쪽에 민원 정보와 이력, 첨부, 필지, 건축물 칸이 열린다.
3. 준설민원만 이력 자리에 준설대상지 목록이 붙고, 그 민원에 달린 대상지를 추가·수정한다.
4. 지도에서 민원 위치를 누르면 해당 민원 상세가 열린다.

#### 확인사항

1. 상수·급수·하수·준설 민원 목록이 속성 표가 아니라 민원 카드로 나와야 한다.
2. 준설대상지 탭이 목록 위에 따로 있으면 안 된다.
3. 준설민원을 연 뒤에만 그 민원의 대상지가 보여야 한다.
4. 메모 메뉴는 기존 메모 목록 그대로여야 한다.
