## 개발목표

상세 화면의 속성 표를 기본계획도 속성 화면과 같은 모양으로 맞춘다. 공통점용, 울진하천점용, 점사용료가 대상이다. 왼쪽은 항목명, 오른쪽은 값이며 항목명 칸만 회색이다. 수정 입력은 그대로 두고 보기 화면 모양만 바꾼다.

## 플로우차트

```
상세 열기 → 속성 표(항목명·값) → (수정) → 같은 표 안에서 입력
```

## 화면설계

### DET-ATTR-01 속성 표

```
+----------------------------------------------------------------------+
| 통합지도                                              [로그인계정]   |
+---+------------------+-----------------------------------------------+
|메 | 점용 목록        | 점용 상세                                     |
|뉴 |                  | 상세 속성                                     |
|하 |                  | +------------------------------------------+  |
|천 |                  | | 허가번호 | 2026-97                       |  |
|   |                  | | 상태     | 진행중                        |  |
|점 |                  | | 점용명   | …                             |  |
|용 |                  | +------------------------------------------+  |
|   |                  | 추가 속성 · 필지목록                          |
+---+------------------+-----------------------------------------------+
+----------------------------------------------------------------------+
```

#### 설명

1. 속성 표는 왼쪽 항목명 칸이 회색, 오른쪽 값 칸이 흰색이다.
2. 가로·세로 얇은 줄로 칸을 나눈다.
3. 공통점용·울진하천점용·점사용료 상세가 같은 표를 쓴다.
4. 수정 중에도 표 뼈대는 같고, 값 칸에만 입력이 들어간다.

#### 확인사항

1. 공통점용 상세 속성 표가 기본계획도 속성과 같은 모양이어야 한다.
2. 울진하천점용 상세 속성 표가 같은 모양이어야 한다.
3. 점사용료 상세 속성 표가 같은 모양이어야 한다.
4. 공통점용 추가 속성 보기 화면도 같은 표 모양이어야 한다.
5. 수정 화면에서 점용장소·면적 자동계산 입력이 동작해야 한다.
