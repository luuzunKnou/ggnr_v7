## 개발목표

상수도 행정에서 관망조회를 열면 관로·밸브·제수변·소화전·급수구역을 한 화면에서 본다. 표시 칸이 범례를 겸하고, 끄면 지도와 목록에서 함께 빠진다. 지도를 옮기면 화면에 들어온 것만 목록에 남고, 행을 누르면 상세가 열린다. 다른 상수 메뉴는 빈 화면 그대로다.

## 플로우차트

상수행정 → 관망조회 → (표시·검색) → 목록 ⇄ 상세 → 지도

## 화면설계

### NET-01 관망조회

```
┌────┬────────────────────────────┬──────────────────────────────────┐
│사이│ 관망조회              [×] │                                  │
│드바│                            │                                  │
│    │ 표시                       │      ▨▨▨▨▨▨                  │
│관망│ [v] ── 관로                │      ▨ 영양1블록                │
│조회│ [v] ◆  밸브                │      ▨  ════◆════●════         │
│    │ [v] ●  제수변              │      ▨         ▲               │
│    │ [v] ▲  소화전              │      ▨▨▨▨▨▨                  │
│    │ [v] ▨  급수구역            │                                  │
│    │ [검색                ]     │                                  │
│    │ 구분     번호     구경 상태│                                  │
│    │ 관로     P-1042   150 노후 │                                  │
│    │ 밸브     V-228    150 정상 │                                  │
│    │ 급수구역 영양1     —  주의 │                                  │
└────┴────────────────────────────┴──────────────────────────────────┘
```

#### 설명

1. 사이드바에서 관망조회를 누르면 왼쪽에 표시와 목록이 열린다.
2. 관로·밸브·제수변·소화전·급수구역은 기호와 이름이 한 줄이고, 끄면 지도와 목록에서 빠진다.
3. 지도를 옮기면 화면에 들어온 시설만 목록에 남는다.
4. 목록이나 지도 심볼을 누르면 옆에 상세가 열리고 해당 위치가 강조된다.

#### 확인사항

1. 관망조회를 열면 다섯 표시가 켜진 채로 보여야 한다.
2. 급수구역을 끄면 구역 면과 목록 행이 사라져야 한다.
3. 지도를 옮겨 화면 밖으로 나간 시설은 목록에 없어야 한다.
4. 관로 행을 누르면 구경·재질·연장·매설연도가 나와야 한다.
5. 급수구역 행을 누르면 면적·세대·유입밸브가 나와야 한다.
6. 시설관리·공사대장·급수공사는 빈 화면이어야 한다.
