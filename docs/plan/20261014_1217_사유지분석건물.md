# 작업계획서

2026-10-14 | dev.strcat | 사유지분석 — 구간과 겹치는 건물·건물군 함께 분석

## 개발목표

사유지분석에서 하천·도로 구간을 적용해 분석할 때, 필지뿐 아니라 구간과 겹치는 건물·건물군도 함께 찾아 목록에 보여 준다. 분석 영역 지정 방식은 그대로 두고 분석 결과만 넓힌다.

필터에 «건물»이 추가되고, 건물 행은 소유구분 대신 건물 구분·지목·주소·면적으로 표시한다. 건물을 누르면 분석 정보는 필지와 같은 형식으로 보이고, 그 아래에는 토지 기본정보 대신 건축물대장과 건물허가대장이 나온다. 건물이 놓인 필지는 건물 도형의 안쪽 한 점으로 지적을 찾아 정하며, 대장 조회는 우클릭 주소정보와 같은 방식이다.

## 플로우차트

```
영역 지정 → 적용·분석 → 필지·건물 목록 → (건물 클릭) → 건물 상세(분석 정보·건축물대장·건물허가대장)
```

## 화면설계

### PRIVATE-01 분석 결과 목록 (건물 포함)

```
┌──────────┬──────────────────────────┬──────────────────────────────────────┐
│ 사이드바 │ 사유지분석             X │ 주소검색                              │
│          │ 분석 영역                │                                      │
│          │ 구역  하천구역            │                                      │
│          │ 대상  ○○천               │          지도                        │
│          │ [영역 변경] [재설정]      │   필지 색칠 + 건물 윤곽 표시          │
│          │ [주소·소유구분·지목    ]  │                                      │
│          │ 전체 개인 국유지 군유지 건물│                                      │
│          │ 목록 132건                │                                      │
│          │ 개인 답 사계리 12-3  120㎡│                                      │
│          │ 건물 대 사계리 15    86㎡ │                                      │
│          │ 건물군 대 사계리 15  140㎡│                                      │
└──────────┴──────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 분석을 마치면 구간과 겹치는 필지와 함께 건물·건물군이 목록에 들어온다.
2. 필터 마지막에 «건물» 칩이 생기며, 누르면 건물·건물군만 보인다.
3. 건물 행은 앞 배지에 소유구분 대신 «건물»·«건물군»을 표시하고 지목·주소·편입면적을 보여 준다.
4. 지도에는 걸러진 건물 윤곽이 필지 위에 함께 그려진다.

#### 확인사항

1. 구간과 겹치는 건물·건물군이 목록에 나와야 한다.
2. «건물» 필터 선택 시 필지는 빠지고 건물만 보여야 한다.
3. 소유구분 필터 선택 시 건물은 목록에서 빠져야 한다.
4. 검색어로 건물 주소·지목이 걸러져야 한다.

### PRIVATE-02 건물 상세

```
┌──────────┬──────────────────────────┬──────────────────┬───────────────────┐
│ 사이드바 │ 사유지분석             X │ 건물 상세      X │ 주소검색           │
│          │ ...                      │ 분석 정보         │                   │
│          │ 건물 대 사계리 15   86㎡ │ 주소  사계리 15   │       지도         │
│          │                          │ PNU   …           │                   │
│          │                          │ 지목  대          │                   │
│          │                          │ 구분  건물        │                   │
│          │                          │ 건물면적 / 편입면적│                   │
│          │                          │ 건축물대장        │                   │
│          │                          │ 건물허가대장      │                   │
└──────────┴──────────────────────────┴──────────────────┴───────────────────┘
```

#### 설명

1. 건물 행이나 지도 위 건물을 누르면 우측에 건물 상세가 열린다.
2. 분석 정보는 주소·지목·구분·건물명·건물면적·편입면적·분석레이어를 보여 준다.
3. 그 아래에 건축물대장과 건물허가대장이 차례로 나온다.
4. 대장은 건물이 놓인 필지 기준으로 우클릭 주소정보와 같은 방식으로 조회한다.

#### 확인사항

1. 건물 클릭 시 토지 기본정보 대신 건축물대장·건물허가대장이 보여야 한다.
2. 필지 클릭 시 상세는 기존과 같아야 한다.
3. 대장이 없는 건물은 없음 안내가 나와야 한다.
