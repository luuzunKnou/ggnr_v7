## 개발목표

공통 점용대장 목록에서 단추를 누르면 본표·필지의 점용장소로 지적 필지를 찾아 도형을 넣는다. 지번이 없거나 못 맞추면 도형을 비운다. 장소 글자 원문은 그대로 둔다.

## 플로우차트

```
목록 → 점용장소 도형 → 장소 정리 → 지적 맞춤 → 도형 넣기 또는 비움 → 안내
```

## 화면설계

### OCC-GEOM-01 목록 도형 채우기

```
┌──────────────────────────────────────────────────────────────┐
│ 사이드바 │ 검색                                              │
│          │ ┌──────────────────────────────────────────────┐ │
│  점용대장│ │ 도로점용대장          [점사용료] [점용장소 도형] [추가] [닫기] │
│          │ ├──────────────────────────────────────────────┤ │
│          │ │ 검색                                          │ │
│          │ │ 전체  진행중  종료                             │ │
│          │ │ 상태  점용명  점용장소  시작일  종료일          │ │
│          │ │ …                                             │ │
│          │ └──────────────────────────────────────────────┘ │
│          │                    지도                          │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 목록 위쪽에 «점용장소 도형» 단추가 있다.
2. 누르면 실행 여부를 한 번 확인한다.
3. 작업 중에는 단추가 돌아가며 다시 누르지 못한다.
4. 끝나면 본표·필지 각각 넣은 건수·비운 건수를 알려 준다.

#### 확인사항

1. 지번이 있는 점용장소는 지도에 도형이 보여야 한다.
2. 일원만 있거나 못 맞추는 장소는 도형이 없어야 한다.
3. 점용장소 글자는 그대로여야 한다.
4. 점사용료 단추는 이전과 같아야 한다.
