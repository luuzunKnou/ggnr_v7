## 개발목표

자전거도로 상세에서 구간을 추가할 때 양측·편측을 고른 뒤 지도 도로구간 위에서 여러 점을 찍어 경로를 만든다. 편측은 한 줄·한 행, 양측은 평행 두 줄·표 두 행이다. 일련번호·기점·종점·도로연계·총 연장은 자동으로 채우고, 구간 표는 핵심 열을 고정하고 폭원은 접어 한눈에 보이게 한다.

## 플로우차트

```
상세수정 → 구간추가 → 양측편측선택 → 도로점찍기 → 경로미리보기 → 완료 → 표자동채움 → 폭원수동 → 저장
```

## 화면설계

### BIKE-SEG-01 양측·편측 선택

```
┌──────목록──────┬────────────상세────────────┐
│ 노선목록       │ 속성정보                   │
│                │ 구간 (3)  [추가]           │
│                │ ┌─────────────────────┐   │
│                │ │ ○ 양측  ○ 편측      │   │
│                │ │ [시작] [취소]       │   │
│                │ └─────────────────────┘   │
│                │ 위치도 | 정비·첨부         │
└────────────────┴────────────────────────────┘
```

#### 설명

1. 수정 중 «추가»를 누르면 양측·편측을 고르는 작은 창이 뜬다.
2. «시작»이면 지도에 도로구간이 켜지고 점 찍기 안내가 나온다.
3. «취소»면 선택 창만 닫힌다.

#### 확인사항

1. 조회 모드에서는 추가 버튼이 없어야 한다.
2. 양측·편측 중 하나를 고른 뒤 시작해야 한다.

### BIKE-SEG-02 지도 점 찍기

```
┌──────────────────────────────────────────────┐
│ [사이드]              지도                   │
│                      ┌──────────────────┐   │
│                      │ 도로 따라 점 찍기 │   │
│                      │ [완료][되돌리기][취소]│
│                      └──────────────────┘   │
│                         ●───녹색경로───●     │
│                        기점              종점 │
└──────────────────────────────────────────────┘
```

#### 설명

1. 도로구간 위에만 점이 붙고, 점과 점 사이는 도로를 따른 경로로 이어진다.
2. 여러 점을 찍으면 구간이 이어지고 마지막 점이 종점이다.
3. 완료 시 표에 행이 생기고, 양측이면 두 행·두 줄이다.

#### 확인사항

1. 도로 밖 클릭은 점이 잡히지 않거나 안내가 나와야 한다.
2. 완료 후 일련번호·기점·종점·도로연계·총 연장이 채워져야 한다.
3. 양측이면 지도에 평행 두 줄이 보여야 한다.

### BIKE-SEG-03 구간 표

```
┌ 일련 | 노선 | 기점 | 종점 | 연계 | 종류 | 연장 | [폭원] ┐
│ 7-1  | …R  | …   | …   | ○  | …  | 1.29 | (접힘) │
│ 7-2  | …L  | …   | …   | ○  | …  | 1.29 | (접힘) │
└──────────────────────────────────────────────────────┘
```

#### 설명

1. 왼쪽 핵심 열은 가로 스크롤해도 고정된다.
2. 폭원 열은 기본 접혀 있고 «폭원»으로 펼친다.
3. 수정 시 셀은 테두리 없이 표 칸 안에서만 고친다.

#### 확인사항

1. 핵심 열이 한눈에 들어와야 한다.
2. 폭원을 펼치면 전용·겸용 열이 보여야 한다.
