# 작업계획서

2026-11-13 | 200BingSu | 악취 연계 스키마·센서 테이블

## 개발목표

포항 악취 프로젝트에서만 악취 연계용 데이터베이스 스키마와 센서 위치 테이블을 확보한다. 센서 키·기관·센서명·한글명·포인트 위치를 저장하며, 위치 좌표계는 5181로 고정한다. 지도 화면·레이어 정의·연계 API는 이번 범위에 포함하지 않는다.

## 플로우차트

```
앱 기동 → (포항 악취 프로젝트) → 악취 연계 스키마 확보 → 센서 테이블 확보
```

## 화면설계

### DB-ODOR-01 악취 센서 테이블

```
┌──────────────────────────────────────────┐
│ 악취 연계 스키마                           │
│                                          │
│  센서 테이블                               │
│  · 센서 키                                │
│  · 기관                                   │
│  · 센서명                                 │
│  · 센서 한글명                             │
│  · 위치(포인트)                            │
└──────────────────────────────────────────┘
```

#### 설명

1. 포항 악취 프로젝트로 앱이 기동되면 악취 연계 스키마가 없으면 생성된다.
2. 같은 조건에서 센서 테이블이 없으면 정해진 컬럼 순서로 생성된다.
3. 위치 컬럼은 포인트이며 좌표계는 5181이다.
4. 다른 프로젝트 기동 시에는 이 스키마·테이블을 만들지 않는다.

#### 확인사항

1. 포항 악취 기동 후 악취 연계 스키마가 있어야 한다.
2. 센서 테이블 컬럼 순서가 키·기관·센서명·한글명·위치 이어야 한다.
3. 위치 컬럼이 포인트·5181이어야 한다.
4. 다른 프로젝트 기동 시 해당 스키마·테이블이 새로 생기지 않아야 한다.
