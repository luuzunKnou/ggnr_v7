# 작업계획서

## 개발목표

레이어 관리의 스타일 수정에서 GeoServer 관리 화면으로 바로 들어갈 때, 앱에 로그인되어 있으면 로그인 문구에 멈추지 않고 해당 스타일 편집 화면이 열리게 한다. 지도 조회용 주소는 그대로 두고, 관리 화면 주소만 앱이 한 번 더 받아 세션과 이동 주소를 맞춘다.

## 플로우차트

스타일 수정 → (직접 수정) → 스타일 편집 화면

## 화면설계

### DEV-STYLE-01 스타일 수정

```
┌──────────────────────────────────────────────┐
│ 스타일 수정: 레이어이름                    X │
├──────────────────────────────────────────────┤
│ GeoServer 관리자 화면에서 스타일 직접 수정 → │
│                                              │
│ 도형 타입   [          ]                     │
│                                              │
│                          [취소]  [저장]      │
└──────────────────────────────────────────────┘
```

#### 설명

1. «GeoServer 관리자 화면에서 스타일 직접 수정»은 새 창으로 스타일 편집 화면을 연다.
2. 앱에 로그인되어 있고 레이어 관리를 볼 수 있으면 로그인 문구 없이 해당 스타일이 열린다.
3. 게이트처럼 주소 앞에 프로젝트 이름이 있어도 같은 방식으로 열린다.

#### 확인사항

1. 직접 수정을 누르면 로그인 문구 없이 스타일 편집 화면이 나와야 한다.
2. 로그인하지 않으면 관리 화면으로 들어가지 않아야 한다.
3. 지도 화면의 레이어 그림은 이전과 같이 나와야 한다.
