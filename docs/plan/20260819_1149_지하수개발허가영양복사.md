## 개발목표

울진 건설행정에 이미 있는 «지하수 개발허가» 자료와 데이터조회 노출을 영양 건설행정에도 그대로 둔다. 화면·메뉴·레이어 정의는 공통이라 이번에 새로 만들지 않고, 울진 저장소의 해당 대장만 영양 저장소에 구조·건수·위치까지 복사한다.

복사 후 영양에서 사이드바 «지하수 개발허가» 목록·상세와 데이터조회 «지하수» 그룹이 울진과 같이 보여야 한다. 좌표·속성 값은 울진 원본을 수정하지 않고 그대로 옮긴다.

## 플로우차트

```
영양 지도 → 건설행정 → 지하수 개발허가 목록 → 상세·지도 위치 → 데이터조회 지하수 그룹
```

#### 설명

1. 사이드바에서 «지하수 개발허가»를 열면 영양에서도 울진과 같은 목록이 나온다.
2. 행을 누르면 상세와 지도 위치 강조가 울진과 같이 동작한다.
3. 이번 작업은 화면을 새로 만들지 않고 저장 자료만 복사한다.

#### 확인사항

1. 영양 건설행정에서 «지하수 개발허가» 메뉴가 보여야 한다.
2. 목록 건수가 울진과 같아야 한다.
3. 위치가 있는 건은 지도에 점이 보여야 한다.

3. 속성 조회가 울진과 같이 되어야 한다.
