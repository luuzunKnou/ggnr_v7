## 개발목표

지도 상단 «인쇄»를 누르면 인쇄 전용 전체 화면이 열린다. 메인 지도의 위치·확대·켜진 레이어·배경을 이어받은 뒤, 색·위치·글자·측정·도형·좌표 입력으로 주석을 넣고 이미지 저장·인쇄한다. 인쇄 화면 안에서도 레이어·배경을 바꿀 수 있으며, 하단에는 참고 문구·축척·담당자·일시를 둔다. 이전 버전 인쇄 화면과 같은 업무 흐름을 목표로 한다.

## 플로우차트

```
지도 → 인쇄 → 주석·측정·도형 → (레이어·배경) → 이미지저장·인쇄 → 닫기
```

## 화면설계

### MAP-PRINT-01 인쇄 화면

```
+----------------------------------------------------------------------+
| 통합지도                                                      [로그인]|
+----------------------------------------------------------------------+
| (뒤 화면 어둡게)                                                     |
| +------------------------------------------------------------------+ |
| | 지도 인쇄                                                  [닫기] | |
| +------------------------------------------------------------------+ |
| | [색] | 위치선택 글자입력 | 거리 면적 고도 경사도 |               | |
| | 점 선 직사각형 다각형 정사각형 원 | 좌표입력 선택삭제            | |
| | 되돌리기 다시실행 초기화 | 이미지저장 인쇄 | 레이어 배경지도     | |
| +------------------------------------------------------------------+ |
| |                                                                  | |
| |                         (지도 영역)                              | |
| |                                                                  | |
| |                                                    [+] [-]       | |
| +------------------------------------------------------------------+ |
| | 본 지도는 참고용입니다.              축척 480.00m                | |
| |                                    담당자 : 홍길동               | |
| |                          2026.07.28 오후 4:20:02                 | |
| +------------------------------------------------------------------+ |
+----------------------------------------------------------------------+
```

#### 설명

1. 지도 컨트롤 «인쇄»를 누르면 인쇄 전용 전체 화면이 열린다.
2. 열릴 때 메인 지도의 위치·확대·배경·켜진 레이어를 이어받는다.
3. 상단 도구로 색·위치·글자·측정·도형·편집·저장·인쇄·레이어·배경을 고른다.
4. 하단에는 참고 문구·축척·담당자·일시가 보인다.
5. «닫기»로 인쇄 화면만 닫고 메인 지도는 유지한다.

#### 확인사항

1. «인쇄» 클릭 시 인쇄 화면이 열려야 한다.
2. 메인에서 보던 위치·확대가 인쇄 지도에 반영되어야 한다.
3. 도구 줄·지도·하단 정보가 한 화면에 보여야 한다.
4. «닫기» 후 메인 지도 측정·패널이 깨지지 않아야 한다.

### MAP-PRINT-02 레이어·배경 선택

```
+----------------------------------------------------------------------+
| 통합지도                                                      [로그인]|
+----------------------------------------------------------------------+
| (뒤 화면 어둡게)                                                     |
| +------------------------------------------------------------------+ |
| | 지도 인쇄                                                  [닫기] | |
| +------------------------------------------------------------------+ |
| | ... 도구 줄 ...                              [레이어] [배경지도] | |
| +------------------------------------------------------------------+ |
| |                                                                  | |
| |  (지도)                    +----------------------------------+  | |
| |                            | 레이어                           |  | |
| |                            | [전체 선택] [전체 해제]           |  | |
| |                            | [x] 도로대장  [ ] 하천망         |  | |
| |                            +----------------------------------+  | |
| |                                                    [+] [-]       | |
| +------------------------------------------------------------------+ |
| | 본 지도는 참고용입니다. ...                                      | |
| +------------------------------------------------------------------+ |
+----------------------------------------------------------------------+
```

#### 설명

1. «레이어»를 누르면 인쇄 지도용 레이어 목록이 열린다.
2. «배경지도»를 누르면 배경 목록이 열리며, 둘은 동시에 열리지 않는다.
3. 켜고 끈 결과는 인쇄·이미지 저장에 그대로 반영된다.
4. 인쇄·이미지 저장 직전에는 목록 패널을 잠시 가린다.

#### 확인사항

1. 레이어를 끄면 인쇄 지도에서 해당 내용이 사라져야 한다.
2. 배경을 바꾸면 인쇄 지도 바탕이 바뀌어야 한다.
3. 레이어와 배경 목록이 동시에 열려 있지 않아야 한다.
4. 이미지 저장·인쇄 결과에 목록 창이 포함되지 않아야 한다.

### MAP-PRINT-03 좌표 입력

```
+----------------------------------------------------------------------+
| 통합지도                                                      [로그인]|
+----------------------------------------------------------------------+
| (뒤 화면 어둡게)                                                     |
| +------------------------------------------------------------------+ |
| | 지도 인쇄                                                  [닫기] | |
| +------------------------------------------------------------------+ |
| | ... [좌표입력] ...                                               | |
| +------------------------------------------------------------------+ |
| | +----------------------+                                         | |
| | | 좌표 입력            |                                         | |
| | | 경도 [          ]    |          (지도 영역)                    | |
| | | 위도 [          ]    |                                         | |
| | | [이동] [닫기]        |                                         | |
| | +----------------------+                                         | |
| +------------------------------------------------------------------+ |
| | 본 지도는 참고용입니다. ...                                      | |
| +------------------------------------------------------------------+ |
+----------------------------------------------------------------------+
```

#### 설명

1. «좌표 입력»을 누르면 좌표 입력 창이 열린다.
2. 값을 넣고 이동하면 인쇄 지도가 해당 위치로 이동한다.
3. 창을 닫아도 인쇄 화면은 유지된다.

#### 확인사항

1. 올바른 좌표 입력 시 지도가 이동해야 한다.
2. 잘못된 값이면 안내가 나와야 한다.
3. 좌표 창을 닫아도 인쇄 화면이 닫히지 않아야 한다.
