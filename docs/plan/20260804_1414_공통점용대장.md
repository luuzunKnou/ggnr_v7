## 개발목표

점용대장 화면·동작은 울진 하천점용과 동일하게 한 벌로 만든다. 읽을 테이블만 사업·시스템 설정으로 고른다. 기본은 레이어 스키마에 시스템별 점용대장·지적·물건지 레이어를 따로 두어 중간 적재가 쉽게 하고, 울진 하천만 설정이 지금 쓰는 점용 테이블을 가리키게 한다. 점사용료·울진 데이터 이관은 하지 않는다.

## 플로우차트

```
시스템 진입 → 점용대장 메뉴 → (사업·시스템 설정으로 레이어 결정) → 목록 → (행·지도 클릭) → 상세
```

## 화면설계

### MAP-OCC-01 점용대장 목록

```
+----------------------------------------------------------------------+
| 통합지도                                                             |
+----------------------------------------------------------------------+
| 메뉴 | [측정] [주소검색] [메모] [점용대장] [레이어]                  |
| - 지도 +----------------------------------------------------+        |
| - 측정 | +---------------------------+                      |        |
| - 점용 | | 점용대장              [X] |                      |        |
|        | | [검색...................] |                      |        |
|        | | 점용명 | 점용장소 | 시작일 | 종료일             |        |
|        | | ----------------------------------------------- |        |
|        | | 교량보수 | 울진읍... | 2025-01-01 | 2025-12-31  |        |
|        | | 하천점용 | 근남면... | 2024-03-01 | 2026-02-28  |        |
|        | +---------------------------+                      |        |
|        |                              [+] [-] [현위치]     |        |
|        +----------------------------------------------------+        |
+----------------------------------------------------------------------+
```

#### 설명

1. 사이드바 «점용대장»을 누르면 목록이 열리고, 설정이 가리키는 본대·지적·물건지 레이어가 지도에 켜진다.
2. 검색·행 클릭·지도 맞춤은 울진 하천점용과 같은 방식으로 동작한다.
3. 울진 하천은 설정이 기존 점용 테이블을 쓰고, 다른 사업·시스템은 각자 점용대장 레이어를 쓴다.
4. 레이어는 시스템별로 분리해 두어 데이터 수신·교체가 본대 단위로 이루어진다.

#### 확인사항

1. 울진 하천에서 점용대장을 열면 기존 점용 데이터가 목록·지도에 그대로 나와야 한다.
2. 다른 사업·시스템에서는 자기 점용대장 레이어 데이터만 나와야 한다.
3. 검색·행 클릭·패널 닫기가 울진 하천점용과 같아야 한다.
4. 기능관리에 공통 점용대장 서비스만 있어도 설정으로 올바른 레이어가 연결되어야 한다.

### MAP-OCC-02 점용대장 상세

```
+----------------------------------------------------------------------+
| 통합지도                                                             |
+----------------------------------------------------------------------+
| 메뉴 | [측정] [주소검색] [메모] [점용대장] [레이어]                  |
| - 지도 +----------------------------------------------------+        |
| - 측정 | +-------------+ +----------------------+           |        |
| - 점용 | | 점용대장 [X]| | 점용 상세        [X]|           |        |
|        | | [검색.....] | | 공사명(점용명)       |           |        |
|        | | 점용명 장소 | | 점용장소             |           |        |
|        | | 교량보수 .. | | 허가번호 / 허가일자  |           |        |
|        | |             | | 신청자 / 전화 / 주소 |           |        |
|        | |             | | 담당자 / 상태 / 비고 |           |        |
|        | +-------------+ | [저장] [닫기]        |           |        |
|        |                 +----------------------+           |        |
|        |                         [+] [-] [현위치]          |        |
|        +----------------------------------------------------+        |
+----------------------------------------------------------------------+
```

#### 설명

1. 상세 항목·저장·닫기·지도 클릭 연동은 울진 하천점용 상세와 동일하게 맞춘다.
2. 점용장소와 신청자 주소는 서로 다른 칸으로 표시한다.
3. 지도에서 본대·지적·물건지를 클릭해도 같은 건의 상세로 연결된다.
4. 실제 저장·조회 대상 테이블만 설정값에 따르고, 화면 동작은 사업과 무관하게 같다.

#### 확인사항

1. 울진 하천에서 상세를 열면 기존과 같은 정보가 보여야 한다.
2. 지도 클릭과 목록 행 선택이 같은 상세를 열어야 한다.
3. 목록을 닫으면 상세도 함께 닫혀야 한다.
4. 점사용료 화면·연계는 이번 변경의 영향을 받지 않아야 한다.
