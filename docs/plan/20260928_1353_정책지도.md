## 개발목표

정책지도를 별도 게시판 화면에서 빼서, 지도 왼쪽 메뉴의 일반 기능으로 둔다. 파일을 올리고 목록에서 열어 보는 정도이므로 메모 목록과 같은 왼쪽 패널로 보여 준다.

## 플로우차트

지도 → 정책지도 → 목록 → (등록) → 목록 → (항목 열기) → 정책지도 화면

## 화면설계

### MAP-POLICY-01 정책지도 목록

```
┌──────────────────────────────────────────────────────────┐
│ 메뉴          │ 정책지도                          닫기 │
│ 드론영상      │ 검색                                    │
│ 사진,동영상   │ ┌────────────────────────────────────┐ │
│ 항공뷰        │ │ 제목                          날짜 │ │
│ 항공영상      │ │ 제목                          날짜 │ │
│ 정책지도      │ └────────────────────────────────────┘ │
│               │                          등록            │
│               │                                          │
│               │              지도                        │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 왼쪽 메뉴에서 «정책지도»를 고르면 목록 패널이 열린다.
2. 목록에는 제목과 날짜가 보이고, 항목을 누르면 그 정책지도가 새 창으로 열린다.
3. «등록»으로 제목과 파일을 올리면 목록에 바로 붙는다.
4. 별도 게시판 화면으로는 들어가지 않는다.

#### 확인사항

1. 왼쪽 메뉴에 «정책지도»가 보여야 한다.
2. 누르면 게시판 페이지가 아니라 왼쪽 목록 패널이 열려야 한다.
3. 등록한 항목이 목록에 보여야 한다.
4. 항목을 누르면 해당 정책지도가 열려야 한다.
