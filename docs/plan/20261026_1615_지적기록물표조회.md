## 개발목표

지적기록물 목록과 스캔 파일을 자료 폴더 전체 검색 대신, 안동 개발 자료의 기록물 표에서 읽는다. 읍면동·지번으로 필지를 찾고, 그 필지에 묶인 문서 장수를 목록에 보여 준다. 상세에서 고른 장의 그림은 표의 경로·파일명을 지금 자료 폴더 아래에 이어 연다.

행이 매우 많으므로 처음 열 때 전체를 가져오지 않는다. 읍면동을 고르거나 지번을 넣은 뒤에만 조회한다. 지번이 없는 종류(측량결과도·환지대장·비법인대장)는 검색어가 권·단체명과 맞을 때만 목록에 낸다.

## 플로우차트

```
지도 → 지적기록물 목록 → (읍면동·지번 조회) → (행 선택) → 문서 목록·미리보기 → (클릭) → 뷰어
```

## 화면설계

### MAP-ARCHIVE-01 기록물 목록

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│메뉴│ 지적기록물                 X │                                      │
│    ├──────────────────────────────┤                                      │
│지적│ [전체 읍면동▼] [지번·도곽  ] │                                      │
│기록├──────────────────────────────┤                                      │
│물  │ 소재지              문서     │                                      │
│    │ 예안면 삼계리 5-1   토지대장 │                                      │
│    │ 수상동 575-11       면적측정부 외 1│                                │
│    │ ...                          │                                      │
│    ├──────────────────────────────┤                                      │
│    │ 12건                         │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 사이드바 «지적기록물»을 열면 좌측 목록이 나오고, 읍면동 목록은 행정구역에서 채운다.
2. 읍면동을 고르거나 지번을 넣으면 기록물 표에서 해당 필지를 찾는다.
3. 조건을 넣지 않으면 목록은 비어 있고 안내 문구가 나온다.
4. 행의 문서 칸은 종류 이름과 «외 n»으로 보여 준다.
5. 행을 고르면 옆에 상세가 열린다.

#### 확인사항

1. 조건을 넣기 전에는 목록이 비어 있어야 한다.
2. 읍면동과 지번으로 조회하면 해당 소재지 행이 나와야 한다.
3. 임시 예시 주소(명륜동 등)는 더 이상 나와서는 안 된다.
4. 행을 누르면 상세가 열려야 한다.

### MAP-ARCHIVE-02 문서·미리보기

```
┌────┬──────────────────────┬────────────────────────────┬───────────────────┐
│메뉴│ 지적기록물         X │ 예안면 삼계리 5-1        X │                   │
│    ├──────────────────────┤ 문서 종류  권  페이지 파일명│                   │
│    │ 예안면 삼계리 5-1 ■  │ 토지대장   13  70    …jpg  │                   │
│    │                      │                            │                   │
│    │                      │  (스캔 미리보기)           │                   │
└────┴──────────────────────┴────────────────────────────┴───────────────────┘
```

#### 설명

1. 상세 위쪽에 그 필지(또는 권)에 묶인 문서 장이 표 기준으로 나온다.
2. 한 장을 고르면 아래 미리보기가 해당 스캔으로 바뀐다.
3. 미리보기를 누르면 뷰어가 열린다.
4. 자료 폴더에 파일이 없으면 미리보기는 비고, 목록 행은 유지된다.

#### 확인사항

1. 선택한 소재지의 문서 종류·파일명이 표 값과 같아야 한다.
2. 샘플이 있는 지적도·구대장은 미리보기가 나와야 한다.
3. 다른 행을 누르면 문서 목록이 바뀌어야 한다.
4. 임시 미리보기 그림은 나와서는 안 된다.
