## 개발목표

내 정보 칸에서 더보기 나누기를 없애고, 프로필·촬영요청·알림·즐겨찾기·기본 기능을 한 화면에 둔다. 촬영요청과 알림은 옆 칸으로 연다. 아래 목록은 공지·자료실처럼 시스템에 없는 기본 기능만 보여 준다.

## 플로우차트

```
지도 → 내 정보 → 즐겨찾기·기본 기능 ⇄ (촬영요청·알림) 옆 칸
```

## 화면설계

### ACC-01 내 정보 한 화면

```
┌────┬──────────────────────────────────────────────┐
│    │ 검색                                          │
│ 메 │                                              │
│ 뉴 │                                              │
│    │                                              │
│    │                                              │
│    │                                              │
│ 내 ├──────────┐                                   │
│ 정 │내 정보  ×│                                   │
│ 보 │이름 부서  │                                   │
│    │촬영요청 알림│                                  │
│    │즐겨찾기  ⚙│                                   │
│    │추가·바로가기│                                  │
│    │공지 자료실 │                                   │
└────┴──────────┴───────────────────────────────────┘
```

#### 설명

1. 위쪽 내 정보·더보기 나누기는 없다.
2. 촬영요청·알림 아래에 즐겨찾기가 있다.
3. 그 아래는 시스템에 없는 기본 기능만 보인다.
4. 바로가기 설정은 이전처럼 옆 칸에서 고른다.

#### 확인사항

1. 내 정보를 열면 한 화면에 프로필·단추·즐겨찾기·기본 기능이 보여야 한다.
2. 부서 메뉴 전체 목록은 보이지 않아야 한다.
3. 공지사항·자료실은 기본 기능으로 보여야 한다.

### ACC-02 촬영요청·알림 옆 칸

```
┌────┬──────────────────────────────────────────────┐
│    │ 검색                                          │
│ 메 │                                              │
│ 뉴 │                                              │
│    │                                              │
│    │                                              │
│ 내 ├──────────┬──────────┐                        │
│ 정 │내 정보  ×│알림      ×│                        │
│ 보 │이름 부서  │목록      │                        │
│    │촬영요청 알림│         │                        │
│    │즐겨찾기   │         │                        │
│    │기본 기능  │         │                        │
└────┴──────────┴──────────┴────────────────────────┘
```

#### 설명

1. 촬영요청 또는 알림을 누르면 바로가기 설정과 같은 너비의 옆 칸이 열린다.
2. 다시 누르면 옆 칸이 닫힌다.
3. 즐겨찾기와 기본 기능은 본문에 그대로 둔다.

#### 확인사항

1. 옆 칸 너비가 바로가기 설정과 같아야 한다.
2. 촬영요청과 알림을 같은 칸에서 펼치지 않아야 한다.
3. 옆 칸을 열어도 즐겨찾기가 밀리지 않아야 한다.
