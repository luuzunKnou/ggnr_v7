## 개발목표

공간정보조회 시스템 사이드바에 «개별공시지가» 메뉴를 추가한다. 매일 내려받는 공시지가 파일을 기준으로 기준연도·읍면동별 요약, 필지 목록, 읍면동 통계를 왼쪽 패널에 보여주고, 지도에는 화면 안 필지를 공시지가 구간 또는 전년 대비 변동률 색상으로 칠한다.

목록 행이나 지도 필지를 고르면 오른쪽 상세 패널에 소재지·지목·면적과 연도별 공시지가 추이를 표시한다. 파일에 한 해 자료만 있으면 변동률 관련 표시는 «비교 자료 없음»으로 처리한다. 지도 컨트롤 «공시지가» 라벨과 우클릭 필지정보 공시지가 조회는 그대로 둔다.

영향 받는 기능: 지도 화면 공용 레이아웃(패널 배치·검색창 위치), 지적재조사·데이터 업로드 등 같은 줄에 붙는 패널.

## 플로우차트

```
지도 → 개별공시지가 목록 ⇄ 읍면동 통계 → (행·필지 클릭) → 필지 상세
```

## 화면설계

### MAP-ILP-01 개별공시지가 목록

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│    │ 개별공시지가               X │ [주소/지번 검색                    ] │
│메뉴│ [2026년 ▼] [전체 읍면동 ▼]   │                                      │
│    │ 지도표시 (공시지가)(변동률)  │                                      │
│    ├──────────────────────────────┤                                      │
│    │ 필지  평균  최고  최저 변동률│                                      │
│    ├──────────────────────────────┤             지도                     │
│    │ 범례 ■ ■ ■ ■ ■               │       필지별 색상 표시               │
│    ├──────────────────────────────┤                                      │
│    │ (필지목록)(읍면동 통계)      │                                      │
│    │ [지번 검색       ] [전체 ▼]  │                                      │
│    │ 소재지  지번  공시지가 변동률│                                      │
│    │ 명륜동  12-3  1,230,000 3.2% │                                      │
│    │ ...                          │                                      │
│    │ 1,234건       < 1/62 > 엑셀  │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 사이드바 «개별공시지가»를 누르면 왼쪽에 목록 패널이 열린다.
2. 기준연도는 파일에 있는 연도 중 최신 연도가 기본이며, 읍면동을 고르면 요약·목록·지도가 함께 걸러진다.
3. 지도표시를 «공시지가»로 두면 가격 구간 다섯 단계 색상, «변동률»로 두면 상승·하락 색상으로 필지를 칠한다.
4. 필지 색상은 일정 축척 이상 확대했을 때만 그리며, 그 전에는 «지도를 확대하면 필지 색상이 표시됩니다» 안내를 범례에 보인다.
5. 필지목록은 지번 검색과 변동 구간으로 거르고, 머리글을 눌러 정렬한다. «엑셀»은 현재 조건 전체를 내려받는다.

#### 확인사항

1. 메뉴를 누르면 패널이 열리고 다시 누르면 닫혀야 한다.
2. 기준연도·읍면동을 바꾸면 요약 수치와 목록 건수가 함께 바뀌어야 한다.
3. 비교 연도가 없으면 변동률 칸이 «—»로 나와야 한다.
4. 확대 축척에서 지도에 필지 색상이 보이고 범례와 색이 일치해야 한다.
5. 패널을 닫으면 지도 필지 색상이 남지 않아야 한다.

### MAP-ILP-02 읍면동 통계

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│    │ 개별공시지가               X │ [주소/지번 검색                    ] │
│메뉴│ [2026년 ▼] [전체 읍면동 ▼]   │                                      │
│    │ 지도표시 (공시지가)(변동률)  │                                      │
│    ├──────────────────────────────┤                                      │
│    │ 필지  평균  최고  최저 변동률│             지도                     │
│    ├──────────────────────────────┤                                      │
│    │ (필지목록)(읍면동 통계)      │                                      │
│    │ 읍면동  필지수  평균  변동률 │                                      │
│    │ 명륜동   3,210  850,000  2.1%│                                      │
│    │ 풍산읍  21,400   42,000  4.8%│                                      │
│    │ ...                          │                                      │
│    │ 24개 읍면동             엑셀 │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. «읍면동 통계» 탭에서 기준연도의 읍면동별 필지 수·평균·최고·최저 공시지가와 평균 변동률을 표로 본다.
2. 행을 누르면 위쪽 읍면동 선택이 그 읍면동으로 바뀌고 필지목록 탭으로 넘어간다.
3. «엑셀»은 통계표 전체를 내려받는다.

#### 확인사항

1. 읍면동 이름이 코드 대신 한글로 나와야 한다.
2. 행을 누르면 해당 읍면동 필지목록으로 전환되어야 한다.
3. 읍면동별 필지 수 합계가 전체 필지 수와 같아야 한다.

### MAP-ILP-03 필지 상세

```
┌────┬──────────────────────────────┬──────────────────────┬───────────────┐
│    │ 개별공시지가               X │ 명륜동 12-3 상세   X │               │
│메뉴│ [2026년 ▼] [전체 읍면동 ▼]   ├──────────────────────┤               │
│    │ ...                          │ 소재지   명륜동      │               │
│    │                              │ 지번     12-3        │     지도      │
│    │ 소재지  지번  공시지가 변동률│ 지목     대          │  선택 필지    │
│    │ 명륜동  12-3  1,230,000 3.2% │ 면적     330.5㎡     │  강조 표시    │
│    │ ...                          │ 공시지가 1,230,000원 │               │
│    │                              │ 전년대비 +3.2%       │               │
│    │                              │ 공시일자 2026-04-30  │               │
│    │                              │ 표준지   아니오      │               │
│    │                              ├──────────────────────┤               │
│    │                              │ 연도별 추이          │               │
│    │                              │ ▁ ▂ ▃ ▅ ▇            │               │
│    │                              │ 연도 공시지가 변동률 │               │
│    │                              │ 2026 1,230,000  3.2% │               │
│    │                              │ 2025 1,192,000  2.5% │               │
└────┴──────────────────────────────┴──────────────────────┴───────────────┘
```

#### 설명

1. 목록 행이나 지도 필지를 누르면 오른쪽에 상세 패널이 열리고 지도에서 필지가 강조된다.
2. 목록 행을 누르면 지도가 해당 필지로 이동한다.
3. 기본정보에는 소재지·지번·지목·면적·공시지가·전년 대비·공시일자·표준지 여부·비고를 보여준다.
4. 연도별 추이는 막대 그래프와 표로 함께 보여준다.

#### 확인사항

1. 지도 필지 클릭과 목록 행 클릭 모두 같은 상세가 열려야 한다.
2. 연도별 표의 변동률이 전년 값과 계산이 맞아야 한다.
3. 상세를 닫으면 지도 강조가 사라져야 한다.
