## 개발목표

공간분석 «위상검증»을 실행하면 접합·유수방향 오류를 지도에 표시하고 목록으로 보여 준다. 미연결 시설, 양쪽에서 만나는 유수, 계량기 쪽으로 역도화된 관로를 구분해 낸다.

## 플로우차트

공간분석 → 위상검증 → 검증 실행 → 오류 목록·지도 표시 → (행 선택) → 위치 이동

## 화면설계

### SPA-TOPO-01 위상검증

```
┌──────사이드────────┬──────────지도──────────┐
│ 공간분석 위상검증    │  오류 위치 표시        │
│ 검증실행            │  ● 접합 · ▲ 유수방향   │
│ 오류 목록           │                        │
│ 구분 · 대상 · 설명  │                        │
└────────────────────┴────────────────────────┘
```

#### 설명

1. «검증실행»으로 접합·유수방향 오류를 산출한다.
2. 목록에 구분·대상·설명이 쌓이고, 지도에 오류 위치가 모두 표시된다.
3. 목록 행을 고르면 해당 위치로 지도가 이동한다.

#### 확인사항

1. 검증 후 접합·유수방향 오류가 목록과 지도에 함께 보여야 한다.
2. 목록 행 선택 시 해당 오류 위치로 이동해야 한다.
3. 다른 공간분석 탭과 전환해도 레이어가 남지 않아야 한다.
