## 개발목표

경산 도로행정 지도에 «보안등» 메뉴를 두고, 수급 받은 보안등과 공공자료 보안등을 한 목록에서 본다. 목록은 출처 필터(전체·수급·공공)로 가리고, 행을 고르면 지도가 그 위치로 맞춰지며 출처에 맞는 상세가 열린다. 수급 상세와 공공 상세는 속성 구성이 다르므로 각각 따로 맞춘다. 지도에도 두 출처가 함께 보이되 목록 필터와 맞춰 켜고 끈다. 이번 범위에서는 조회·이동·상세만 다루고 등록·수정·삭제는 넣지 않는다. 두 자료를 하나의 저장 테이블로 합치지는 않는다.

영향 받는 기능: 지도 사이드바 도로 메뉴, 기존 도로 보안등 레이어 표시, 공공 보안등 자료 조회.

## 플로우차트

```
지도 → 보안등 목록 → (출처 필터) → 행 선택 → 지도 이동 ⇄ 출처별 상세
```

## 화면설계

### SEC-01 보안등 목록

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 검색창                                                                   │
├──────────┬────────────────────────────────────┬──────────────────────────┤
│ 사이드바 │ 보안등                           ✕ │                          │
│          │ 전체  수급  공공                   │                          │
│ 보안등   │ [위치·주소 검색          ] 검색   │                          │
│          │────────────────────────────────────│                          │
│ 도로대장 │ 출처  위치              관리번호   │           지도           │
│ …        │ 수급  ○○동 ○○리         12345    │      (수급·공공 점)      │
│          │ 공공  ○○로 12           A-001    │                          │
│          │ 수급  ○○동 ○○리         12346    │                          │
│          │────────────────────────────────────│                          │
│          │ 총 320건                           │                          │
└──────────┴────────────────────────────────────┴──────────────────────────┘
```

#### 설명

1. 사이드바에서 «보안등»을 누르면 왼쪽 목록 패널이 열린다.
2. 위쪽 출처 필터로 전체·수급·공공을 고르면 목록과 지도 점이 함께 가려진다.
3. 검색은 위치·주소 등 공통으로 보이는 글자를 기준으로 목록을 줄인다.
4. 목록 칸은 출처·위치·관리번호처럼 두 출처에서 공통으로 볼 수 있는 항목 위주로 둔다.
5. 행을 누르면 지도가 그 점으로 맞춰지고, 출처에 맞는 상세 패널이 열린다.

#### 확인사항

1. «보안등» 메뉴가 선택된 상태로 보여야 한다.
2. «수급»만 고르면 수급 행과 수급 점만 보여야 한다.
3. «공공»만 고르면 공공 행과 공공 점만 보여야 한다.
4. 목록 아래 건수가 거른 결과와 같아야 한다.
5. 다른 도로 메뉴와 동시에 켜지지 않아야 한다.

### SEC-02 수급 보안등 상세

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ 검색창                                                                        │
├──────────┬──────────────────┬──────────────────────────────┬──────────────────┤
│ 사이드바 │ 보안등 목록      │ 보안등 상세 · 수급        ✕ │                  │
│          │                  │ 목록으로                     │                  │
│ 보안등   │                  │──────────────────────────────│                  │
│          │                  │ 관리번호      12345          │                  │
│          │                  │ 관리기관      ○○시           │       지도       │
│          │                  │ 법정동        ○○동           │    (선택 강조)   │
│          │                  │ 행정읍/면/동  ○○동           │                  │
│          │                  │ 광원종류      ○○             │                  │
│          │                  │ 등기구모형    ○○             │                  │
│          │                  │ 광원용량      ○○             │                  │
│          │                  │ 설치일자      2020-01-01     │                  │
│          │                  │ 공사번호      ○○             │                  │
│          │                  │ 도로구간번호  ○○             │                  │
└──────────┴──────────────────┴──────────────────────────────┴──────────────────┘
```

#### 설명

1. 목록에서 출처가 수급인 행을 누르면 수급용 상세가 열린다.
2. 수급 자료에 있는 속성만 보여 주며, 공공 상세와 같은 칸 구성을 강제하지 않는다.
3. 선택한 점은 지도에서 강조되고, «목록으로»로 상세만 닫을 수 있다.
4. 이번 범위에서는 수정·삭제 버튼을 두지 않는다.

#### 확인사항

1. 수급 행을 누르면 수급 상세가 열려야 한다.
2. 상세에 관리번호·법정동·광원종류·등기구모형 등이 보여야 한다.
3. 지도에서 선택한 점이 구분되어 보여야 한다.
4. «목록으로»를 누르면 상세가 닫히고 목록이 남아 있어야 한다.

```
│          │                  │ 도로명주소    ○○로 12        │    (선택 강조)   │
│          │                  │ 시설유형      보안등          │                  │

└──────────┴──────────────────┴──────────────────────────────┴──────────────────┘
```

#### 설명

1. 목록에서 출처가 공개인 행을 누르면 공공용 상세가 열린다.
2. 주소·도로명주소·시설유형 등 공공 자료 속성을 보여 주며, 수급 상세와 칸을 맞추지 않는다.
3. 선택한 점은 지도에서 강조되고, «목록으로»로 상세만 닫을 수 있다.
4. 이번 범위에서는 수정·삭제 버튼을 두지 않는다.

#### 확인사항

1. 공공 행을 누르면 공공 상세가 열려야 한다.
2. 상세에 주소·도로명주소·시설유형 등이 보여야 한다.
3. 수급 상세와 칸 구성이 달라도 각각 정상적으로 보여야 한다.
4. «목록으로»를 누르면 상세가 닫히고 목록이 남아 있어야 한다.

### SEC-04 지도 점 선택

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ 검색창                                                                        │
├──────────┬────────────────────────────────────┬──────────────────────────────┤
│ 사이드바 │ 보안등                           ✕ │                              │
│          │ 전체  수급  공공                   │                              │
│ 보안등   │ (목록 유지)                        │            지도             │
│          │                                    │         ● 선택 점           │
│          │                                    │                              │
└──────────┴────────────────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 보안등 모드에서 지도의 보안등 점을 눌러도 해당 출처 상세가 열린다.
2. 필터로 가려진 출처의 점은 누르지 않거나 보이지 않게 한다.
3. 점이 겹치면 목록에서 고르는 것과 같이 출처를 구분해 연다.

#### 확인사항

1. 지도에서 수급 점을 누르면 수급 상세가 열려야 한다.
2. 지도에서 공공 점을 누르면 공공 상세가 열려야 한다.
3. «수급» 필터일 때 공공 점이 보이지 않아야 한다.
