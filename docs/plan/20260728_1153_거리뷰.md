# 작업계획서

2026-07-28 | 200BingSu | 거리뷰 필요 기능 정리

## 목표

지도에서 «거리뷰»를 켜면 패널을 제외한 지도 영역을 1:1로 나눠, 한쪽은 기존 지도·다른 한쪽은 카카오 거리뷰를 함께 본다. 거리뷰가 보는 위치·방향·시야각은 지도 위 워커(시야 표시)와 맞추고, 지도 이동 동기화는 켜고 끌 수 있게 한다.

## 플로우차트

```
거리뷰 ON → 화면 1:1 분할(좌우/상하) → 거리뷰·지도 연동(동기화 O/X) → 워커·시야 표시 
→ 지도 중앙 좌표 이동 또는 거리뷰 내 화살표 클릭을 통해 거리뷰 이동 → 거리뷰 OFF·복귀
```

## 기능목록

### 화면 분할

1. 화면 분할은 **거리뷰 전용이 아니라 공통 분할 셸**로 둔다. 이번엔 보조 칸에 거리뷰만 넣고, 이후 같은 자리에 지도·파노라마 등 다른 화면을 끼울 수 있게 한다.
2. 구조는 주 칸(기존 지도)·보조 칸(교체 가능한 내용)·가운데 분할 실선·실선 중앙 컨트롤 섹션으로 나눈다.
   - 주 칸: 기존 지도(항상 유지).
   - 보조 칸: 지금 켜진 기능에 맞는 화면만 넣는다. (이번: 거리뷰. 이후: 지도, 파노라마 등)
   - 컨트롤 섹션: 공통 자리만 두고, 버튼 내용은 보조 칸 기능이 넘긴다. (거리뷰면 동기화 등)
3. 패널을 제외한 남는 영역을 기본 좌우 1:1로 나눈다. 좌(또는 상)=주 칸, 우(또는 하)=보조 칸.
4. 분할이 켜질 때 주 칸(기존 지도)이 한쪽에 맞춰 줄어드는 전환 애니메이션을 둔다. (좌우 분할이면 왼쪽으로 폭이 줄어들고, 상하 분할이면 위쪽으로 높이가 줄어든다.) 끌 때는 반대로 전체가 다시 차는 애니메이션을 둔다. 애니메이션 중·후에 지도 크기를 다시 맞춘다.
5. 패널을 제외한 남는 너비가 좁을 때(기준안: 전체 너비의 50% 미만)에는 상하 1:1로 바꾼다. 창 크기·패널 개폐에 따라 다시 계산한다.
6. 가운데 분할 실선은 굵게 두고, 드래그로 분할 비율을 바꿀 수 있게 한다.
7. 분할 실선 가운데에 컨트롤용 버튼 섹션을 둔다.
   - 좌우 분할일 때는 세로 실선 중앙, 상하 분할일 때는 가로 실선 중앙에 둔다.
   - 실선 드래그(비율 변경)와 버튼 클릭이 서로 방해되지 않게 한다.
8. 지도 이동 동기화(거리뷰 보조 칸일 때)
   - 동기화 켜짐(기본): 거리뷰가 이동하면 지도 중심도 함께 이동한다.
   - 동기화 꺼짐: 거리뷰가 이동해도 주 칸 지도는 고정한다.
   - 동기화 켜기/끄기는 위 컨트롤용 버튼 섹션에 둔다.

### 카카오 거리뷰

1. 현재 화면이 보고 있는 방향·시야각·위치를 지도와 거리뷰에서 확인할 수 있게 한다. (참고: 카카오 로드뷰 이동 샘플)
2. 지도 안 워커(거리뷰가 보고 있는 시야 표시)에 회전 등 시야 변경 조작을 넣는다.
3. 거리뷰 안 화살표 이동·확대·축소는 거리뷰에 기본으로 있는 기능을 그대로 쓴다.
