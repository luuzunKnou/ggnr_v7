## 개발목표

지도에서 «거리뷰»를 켜면 패널을 제외한 지도 영역을 나눠, 한쪽은 기존 지도·다른 한쪽은 거리뷰(목업 또는 카카오 로드뷰)를 함께 본다. 거리뷰가 보는 위치·방향·수직각은 지도 위 워커와 맞추고, 지도 이동 동기화는 켜고 끌 수 있게 한다.

워커는 시야 원·사람 아이콘·시야점으로 방향을 보여 준다. 수직각 양수·음수에 따라 시야점이 위·아래로 움직이되, 음수 쪽은 이동 거리를 짧게 두고 일정 각도 이후에는 더 내리지 않는다. 지도 패닝·줌·시야 원 드래그 시 지도와 화면 부하가 커지지 않도록 갱신을 묶는다.

## 플로우차트

```
거리뷰 ON → 화면 분할(좌우/상하) → 워커·시야(수평·수직) ⇄ 거리뷰 패널 → (동기화 O/X) 지도 연동 → 거리뷰 OFF·복귀
```

## 화면설계

### MAP-SV-01 거리뷰 분할·동기화

```
+----------------------------------------------------------------------+
| 통합지도                                                              |
+------------+---------------------------------------------------------+
| 메뉴       | [측정] [주소검색] [메모] [민원] [필지분석] [거리뷰] [레이어] |
| - 지도     +------------------------+-+------------------------------+
| - 측정     |                        | |                              |
| - 주소검색 |      (기존 지도)        |동기화|      (거리뷰 영역)        |
| - 메모     |         워커            | |                              |
| - 거리뷰   |      [+] [-] [현위치]   | |                              |
+------------+------------------------+-+------------------------------+
+----------------------------------------------------------------------+
```

#### 설명

1. «거리뷰»를 켜면 패널을 제외한 영역을 좌우(또는 상하)로 나눈다.
2. 분할은 공통 셸이며 보조 칸에는 이번엔 거리뷰만 넣는다.
3. 가운데 실선에 «동기화» 등 컨트롤을 두고, 비율 드래그와 버튼 클릭이 서로 방해되지 않게 한다.
4. 동기화가 켜져 있으면 거리뷰·워커 위치 변경 시 지도 중심이 따라간다.

#### 확인사항

1. 거리뷰를 켜면 지도와 거리뷰 영역이 함께 보여야 한다.
2. 동기화를 끄면 거리뷰만 이동하고 지도는 고정되어야 한다.
3. 좁은 폭에서는 상하 분할로 바뀌어야 한다.

### MAP-SV-02 워커·시야 표시

```
+----------------------------------------------------------------------+
| 통합지도 [거리뷰 ON]                                                   |
+------------+---------------------------------------------------------+
| 메뉴       | [거리뷰]                                                 |
| - 거리뷰   +------------------------+-+------------------------------+
|            |                        | | 거리뷰 영역 (목업)            |
|            |   (시야 원·사람 아이콘)  | | 수평각 · 수직각               |
|            |      시야점·머리 음영   |동기화| [수직각 슬라이더]           |
|            |                        | | 경도 · 위도                   |
+------------+------------------------+-+------------------------------+
+----------------------------------------------------------------------+
```

#### 설명

1. 거리뷰가 켜져 있는 동안 시각 중심에 워커가 올라가고 주황 센터마크는 숨긴다.
2. 시야 원을 드래그하면 수평 방향이 바뀌고 거리뷰 수평각과 맞춘다.
3. 수직각 양수면 시야점이 위로, 음수면 아래로 움직인다. 음수 쪽 최대 이동은 양수보다 짧고, 일정 각도 이후에는 더 내리지 않는다.
4. 머리에는 바라보는 방향 반대쪽에 부드러운 음영이 이어진다.
5. 목업에서는 수직각 슬라이더로 조절하고, 카카오 로드뷰를 쓸 때는 로드뷰 시야와 맞춘다.
6. 시야 원 회전·지도 이동·줌 반영은 프레임 단위로 묶어 지도·화면 부하를 줄인다.

#### 확인사항

1. 북쪽을 볼 때 시야점이 바로 숨겨져야 한다.
2. 수직각을 위로 올려도 시야점이 머리 가장자리까지 내려가지 않아야 한다.
3. 지도 패닝·시야 원 드래그 시 이전보다 덜 버벅여야 한다.
4. 지도를 클릭하면 워커가 그 위치로 이동해야 한다.

### MAP-SV-03 카카오 로드뷰(전환 가능)

```
+----------------------------------------------------------------------+
| 통합지도 [거리뷰 ON]                                                   |
+------------+---------------------------------------------------------+
| 메뉴       | [거리뷰]                                                 |
| - 거리뷰   +------------------------+-+------------------------------+
|            |      (기존 지도·워커)   |동기화| (로드뷰 화면)              |
|            |                        | | [확대] [축소] [이동 화살표]   |
+------------+------------------------+-+------------------------------+
+----------------------------------------------------------------------+
```

#### 설명

1. 설정으로 목업과 카카오 로드뷰를 바꿀 수 있게 한다.
2. 로드뷰 안 화살표 이동·확대·축소는 로드뷰 기본 기능을 쓴다.
3. 로드뷰 위치·수평각 변경은 워커·(동기화 시) 지도와 맞춘다.
4. 기본 로드뷰 UI 일부는 끄고, 필요한 조작은 화면 아래 자체 컨트롤로 둔다.

#### 확인사항

1. 목업 모드에서는 카카오 요청 없이 화면만으로 동작해야 한다.
2. 로드뷰 모드에서는 위치·수평각이 워커와 맞아야 한다.
3. 도메인·앱키 오류 시 사용자에게 안내 문구가 보여야 한다.
