# 작업계획서

2026-11-02 | dev.strcat | 기본계획 목록 UI

## 개발목표

하천기본계획 진입 시 사유지분석처럼 지방·소하천을 모달로 고른 뒤, 목록에서 기본계획별·하천별만 전환한다. 목록 행은 한 줄 말줄임으로 본다.

## 플로우차트

```
지도 → 기본계획 → 구역모달(지방|소하천) → 목록(기본계획별|하천별) → 상세
```

## 화면설계

### MAP-RBP-UI-01 구역 모달

```
┌──────────────────────────────────────┐
│ 기본계획 구역 선택              [X]   │
│  지방하천 카드  |  소하천 카드         │
│                         [취소]       │
└──────────────────────────────────────┘
```

#### 설명

1. 기본계획을 열면 모달이 먼저 열린다.
2. 지방·소하천 카드를 고르면 모달이 닫히고 목록이 채워진다.
3. 구역을 고르기 전에 모달을 닫으면 패널도 닫힌다.

#### 확인사항

1. 기본계획 메뉴 선택 시 모달이 먼저 보여야 한다.
2. 구역 미선택 상태에서 모달 취소 시 패널이 닫혀야 한다.

### MAP-RBP-UI-02 목록

```
┌──────────────────────────────────────┐
│ 지방하천 기본계획  구역변경      [X] │
│ 기본계획별 | 하천별                   │
│ [검색]                               │
│ 2023 척산천외 5개…            3      │
│   나곡천                             │
└──────────────────────────────────────┘
```

#### 설명

1. 상단에 기본계획별·하천별만 있다.
2. 긴 계획명은 한 줄에서 말줄임 된다.
3. 구역 변경으로 모달을 다시 연다.

#### 확인사항

1. 지방·소하천 탭이 목록에 없어야 한다.
2. 긴 제목이 한 줄 말줄임 되어야 한다.
3. 구역 변경 후 다른 구역을 고르면 목록이 바뀌어야 한다.
