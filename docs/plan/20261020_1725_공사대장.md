## 개발목표

상수도 행정 «공사대장»을 열면 왼쪽에서 연도별 사업과 공사·변경 건을 보고, 공사를 고르면 오른쪽에 속성과 구역이 나오며 지도 아래쪽에 첨부 목록이 열린다. 원본 공사 자료를 연도 사업으로 묶어 보여 주며, 저장·등록은 하지 않는다.

## 플로우차트

```
상수행정 → 공사대장 → 사업목록 → (사업 선택) → 상세·공사·변경 → (공사 선택) → 우측속성·구역 + 하단첨부
```


#### 설명

1. 사이드바 «공사대장»을 누르면 왼쪽 패널이 열린다.
2. 위쪽에 사업 목록이 기간·총괄금액과 함께 보인다.
3. 사업을 고르면 아래에 상세·공사목록·변경건 칸이 열린다.
4. 공사 행을 누르면 오른쪽에 속성·구역 패널이 열리고 지도 아래에 첨부가 보인다.

#### 확인사항

1. 사업 목록에 기간과 총괄금액이 보여야 한다.
2. 사업 선택 후 공사 목록에 기간·업체·금액이 보여야 한다.
3. 공사 선택 시 오른쪽 패널과 지도 아래 첨부가 열려야 한다.
4. 공사구역이 지도에 표시되어야 한다.
5. 다른 상수도 메뉴로 바꾸면 패널·구역·첨부가 사라져야 한다.
