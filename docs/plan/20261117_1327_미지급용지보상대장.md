## 개발목표

도로 메뉴에 «미지급용지 보상 지급대장»을 두고, 엑셀 대장과 비슷한 목록·상세를 목업으로 보여 준다. 필지·소유자·부대비용 세 구조를 화면에서만 연결한다. 저장·지도 연동은 하지 않는다.

## 플로우차트

지도 → 미지급용지 보상 지급대장 → 목록 → (행 클릭) → 상세

## 화면설계

### MAP-ULC-01 지급대장 목록

```
┌──────┬────────────────────────────────────────────────────────────┐
│ 메뉴 │ 미지급용지 보상 지급대장                              [닫기] │
│      ├────────────────────────────────────────────────────────────┤
│ 도로 │ [검색]  [전체][2013][2014]…                                 │
│      ├────────────────────────────────────────────────────────────┤
│      │ 연도 연번 소재지 지번 지목 면적 소유자 국도 지방도 시군도 … │
│      │ 2013  1  …                                                 │
│      │ 2013  2  …                                                 │
└──────┴────────────────────────────────────────────────────────────┘
```

#### 설명

1. 사이드바에서 메뉴를 열면 왼쪽 목록 패널이 뜬다.
2. 연도 칩과 검색으로 목록을 거른다.
3. 표는 엑셀 대장 열을 따르고, 도로종류에 맞는 칸에만 필지·면적·금액이 채워진다.
4. 행을 누르면 상세가 열린다.

#### 확인사항

1. 메뉴 선택 시 목록이 열려야 한다.
2. «면도 102»처럼 검색이 아니라 소재지·소유자·지번 검색이 되어야 한다.
3. 연도 칩을 바꾸면 해당 연도만 보여야 한다.

### MAP-ULC-02 지급대장 상세

```
┌──────┬──────────────────┬──────────────────────┐
│ 메뉴 │ 목록             │ 상세            [닫기]│
│      │ …                │ 속성정보              │
│      │                  │ 필지 / 소유자 / 수수료│
└──────┴──────────────────┴──────────────────────┘
```

#### 설명

1. 선택한 행의 필지·소유자·부대비용 값을 표로 보여 준다.
2. 이번 단계에서는 수정·저장 버튼은 두지 않는다.

#### 확인사항

1. 목록 행 클릭 시 상세가 열려야 한다.
2. 상세 닫기 후에도 목록은 유지되어야 한다.
