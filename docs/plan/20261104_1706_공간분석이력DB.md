## 개발목표

공간분석(단수구역·누수분석·송수경로·위상검증)의 분석 이력을 세션이 아닌 데이터베이스에 남긴다. 단수·누수·송수는 이어가기 관계를 이력에서 추적할 수 있게 하고, 위상검증은 같은 이력 체계를 쓰되 업무 연결은 약하게 둔다.

공통 이력 헤더에 유형·제목·작성자·시각·출처 이력을 두고, 유형별 상세(단수 본문·면·제수변·수용가, 누수 스냅·제수변, 송수 시설·관로, 위상 오류 목록)를 분리한다. 단수는 상태·문자·도형편집까지 업무 대장으로 쓰고, 누수·송수·위상은 당시 결과 재조회용 스냅샷을 우선한다. 관망 원본이 바뀌어도 당시 분석 결과는 유지한다.

기대 결과는 새로고침·재접속 후에도 이력을 다시 불러 지도·목록에 복원하고, «누수(또는 송수) → 단수» 이어가기 출처를 목록에서 확인할 수 있는 것이다. 이번 범위는 저장 구조·저장·불러오기 설계이며, 문자 발송 실연동·스키마 DB 적용 실행은 별도 승인 후 진행한다.

## 플로우차트

```
분석실행 → 분석결과저장 → 공통이력·유형상세 저장 → 이력목록 → (선택) 지도·패널 복원
누수|송수 저장 → 단수 이어가기 → 단수 저장(출처이력 연결) → 이력에서 출처 표시
위상검증 실행 → 오류목록 저장 → 이력 복원 ⇄ (선택) 수정요청 이력
```

## 화면설계

### MAP-SA-HIST-01 공간분석 이력목록(공통)

```
┌──────────┬──────────────────────────────────────────────┐
│ 사이드바  │  공간분석 · (단수|누수|송수|위상)            │
│ · 공간분석│────────────────────────────────────────────│
│ · …      │  이력                                        │
│          │  · 2026-11-04 17:00  제목…  [출처:누수#…]   │
│          │  · 2026-11-04 16:40  제목…                   │
│          │           [새 분석]  [분석결과저장]           │
│          │────────────────────────────────────────────│
│          │  결과 요약 · 지도 복원                        │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 각 탭 이력은 데이터베이스에 저장된 해당 유형만 시간순으로 보여 준다.
2. 단수 이력에 출처가 있으면 «출처: 누수» 또는 «출처: 송수»와 짧은 식별을 표시한다.
3. 이력을 고르면 당시 스냅샷으로 지도와 결과 패널을 복원한다.
4. «분석결과저장»은 현재 미리보기 결과를 공통 이력과 유형 상세에 저장한다.

#### 확인사항

1. 새로고침 후에도 저장한 이력이 목록에 남아야 한다.
2. 다른 유형 탭의 이력이 섞여 보이지 않아야 한다.
3. 출처가 있는 단수는 목록에서 출처가 보여야 한다.

### MAP-SA-HIST-02 단수구역 저장·상태

```
┌──────────┬──────────────────────────────────────────────┐
│ 사이드바  │  공간분석 · 단수구역                          │
│          │  이력 · 선택 건                               │
│          │  상태: 분석완료 → 설정완료 → … → 종료         │
│          │  사유 · 시작 · 종료 · 세대수                   │
│          │  제수변 · 관로 · 수용가 · 필지                 │
│          │  [도형편집]  [문자 내용]                       │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 단수는 분석 결과뿐 아니라 상태·사유·기간·문자 초안·편집된 단수면을 함께 저장한다.
2. 누수·송수에서 이어가기로 만든 단수는 출처 이력 키를 남긴다.
3. 직접 제수변만 잠근 단수는 출처 없이 저장한다.
4. 도형편집 결과는 당시 면 도형으로 덮어 저장한다.

#### 확인사항

1. 단수 저장 후 상태·면·수용가 요약을 다시 불러올 수 있어야 한다.
2. 이어가기 단수는 출처 누수·송수 이력과 연결되어야 한다.
3. 출처 없이 저장한 단수는 출처 표시가 없어야 한다.

### MAP-SA-HIST-03 누수·송수 저장과 이어가기

```
┌──────────┬──────────────────────────────────────────────┐
│ 사이드바  │  공간분석 · 누수분석(또는 송수경로)           │
│          │  결과 · 제수변 목록                            │
│          │  [분석결과저장]  [단수구역 분석하기]           │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 누수는 스냅 위치·관로·격리 제수변을, 송수는 시설·하류 관로·경로상 제수변을 스냅샷으로 저장한다.
2. «단수구역 분석하기» 전에 출처 분석을 저장해 두면, 이후 단수 저장 시 출처로 연결한다.
3. 이어가기만 하고 단수를 저장하지 않으면 출처만 남고 단수 이력은 생기지 않는다.

#### 확인사항

1. 누수·송수 저장 후 다시 열면 지도 스냅·경로가 복원되어야 한다.
2. 저장된 누수·송수에서 이어가 단수를 저장하면 출처가 연결되어야 한다.

### MAP-SA-HIST-04 위상검증 실행 이력

```
┌──────────┬──────────────────────────────────────────────┐
│ 사이드바  │  공간분석 · 위상검증                          │
│          │  실행 이력 · 오류 건수 요약                    │
│          │  접합확인필요 · 유수방향 확인필요 목록         │
│          │  [다시 검증]                                  │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 위상검증은 실행 단위로 요약과 오류 목록을 저장한다.
2. 단수·누수·송수와 같은 공통 이력 헤더를 쓰되, 이어가기 출처 연결은 두지 않는다.
3. 수정요청·즉시반영이 있으면 실행 이력 아래에 변경 이력으로 남길 수 있게 한다.

#### 확인사항

1. 이전 실행 이력을 고르면 당시 오류 목록·지도 위치가 복원되어야 한다.
2. 위상 이력이 단수·누수·송수 목록에 나타나지 않아야 한다.
