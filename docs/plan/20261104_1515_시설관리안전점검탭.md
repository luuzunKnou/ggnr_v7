## 개발목표
시설관리로 연 상세 화면에서 첨부파일 옆에 «안전점검» 탭을 둔다. 선택한 행의 시설명으로 점검진단실적을 불러와, 기존 안전점검 상세의 점검진단 목록·등급·상세와 같은 형태로 보여 준다. 시설관리가 아닌 데이터조회에서는 탭을 넣지 않는다.

## 플로우차트
시설관리 → 시설 선택 → 상세 → 안전점검 탭 → 시설명 조회 → 점검진단 목록 ⇄ 점검 상세

## 화면설계
### FAC-SAFE-01 시설관리 상세 안전점검 탭
```
┌──────┬────────────────────────────────────────┐
│사이드│ 시설관리 목록                          │
│바    │ ┌────────────────────────────────────┐ │
│ …    │ │ 교량 · …                           │ │
│시설  │ └────────────────────────────────────┘ │
│관리  │ 기본정보 | 이력관리 | 첨부파일 | 안전점검 │
│      │ ┌────────────────────────────────────┐ │
│      │ │ 최근 등급 · 최근 점검일 · 총 N건    │ │
│      │ │ 구분 | 기간 | 등급                 │ │
│      │ │ …                                  │ │
│      │ │ 이전  1/N  다음                    │ │
│      │ │ (행 선택 시 점검 상세)             │ │
│      │ └────────────────────────────────────┘ │
└──────┴────────────────────────────────────────┘
```

#### 설명

1. 시설관리로 연 상세에만 «안전점검» 탭이 첨부파일 오른쪽에 보인다.
2. 탭을 열면 선택 행의 시설명으로 점검진단실적을 불러온다.
3. 목록·최근 등급·페이지·행 선택 상세는 기존 안전점검 상세의 점검진단 영역과 같다.
4. 시설명이 없거나 실적이 없으면 안내만 보인다.

#### 확인사항

1. 시설관리 상세에 «안전점검» 탭이 첨부파일 옆에 보여야 한다.
2. 데이터조회만 연 경우에는 «안전점검» 탭이 없어야 한다.
3. 시설명이 있는 시설을 고르면 같은 이름의 점검진단실적이 목록에 나와야 한다.
4. 실적이 없으면 «점검진단실적이 없습니다» 안내가 나와야 한다.
5. 목록 행을 고르면 기존과 같은 점검 상세가 열려야 한다.
