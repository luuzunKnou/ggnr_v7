## 개발목표

지도 사이드바에 «지적재조사» 메뉴를 추가한다. 메뉴를 열면 좌측에 지구 목록 패널이 열리고 진행 단계로 거를 수 있으며, 지도에는 지구 경계가 사업 단계별 색으로 표시된다.

목록이나 지도에서 지구를 고르면 옆에 지구 상세 패널이 열리고, 기본 정보·사업 현황과 함께 필지 목록이 나온다. 필지를 고르면 지도에서 해당 필지를 강조한다.

이번 범위는 임시 데이터로 만드는 화면이며, 서버 조회·저장은 포함하지 않는다. 실제 데이터 연결 시 임시 데이터 파일만 교체하도록 화면과 데이터를 분리한다.

## 플로우차트

```
지도 → 지적재조사 목록(단계 필터) → (지구 선택) → 지구 상세 → (필지 선택) → 필지 강조
```

## 화면설계

### MAP-RESURVEY-01 지구 목록

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│메뉴│ 지적재조사                 X │ [검색                         ]      │
│    ├──────────────────────────────┤                                      │
│데이│ [연도▼] [읍면동▼] [단계▼]    │        ┌────────┐                    │
│터  │ [검색 (지구명, 위치)       ] │        │ 용상   │                    │
│조회├──────────────────────────────┤        │ 지구   │      ┌──────┐      │
│    │ 지구명  위치  연도 필지 단계 │        └────────┘      │ 정산 │      │
│필지│ 임하2.. 임하면 2026 713 측량 │                        │ 지구 │      │
│분석│ 현내3.. 남선면 2026  66 조서 │                        └──────┘      │
│    │ 정산3.. 예안면 2024 840 등기 │   ┌──────┐                           │
│지적│ ...                          │   │ 임하 │                           │
│재조│                              │   │ 지구 │                           │
│사  ├──────────────────────────────┤   └──────┘                           │
│    │ 25건                         │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 사이드바 «지적재조사»를 누르면 좌측에 목록 패널이 열린다.
2. 전체 지구를 한 목록에 보여주고, 연도·읍면동·진행 단계 선택과 검색으로 좁힌다.
3. 진행 단계 선택지에는 단계별 지구 수를 함께 보여준다.
4. 지도에는 현재 목록에 보이는 지구만 사업 단계별 색으로 표시한다.
5. 지구 행을 누르면 지도가 해당 지구로 이동하고 상세 패널이 열린다.

#### 확인사항

1. 단계를 고르면 목록과 지도 표시 지구가 함께 바뀌어야 한다.
2. 지구 경계가 실제 안동 지적 위치와 겹쳐야 한다.
3. 지도에서 지구를 누르면 해당 행이 선택 표시되고 상세가 열려야 한다.
4. 메뉴를 닫으면 지도에서 지구 경계가 사라져야 한다.

### MAP-RESURVEY-02 지구 상세

```
┌────┬──────────────────────┬────────────────────────────┬───────────────────┐
│메뉴│ 지적재조사         X │ 현내3지구 상세           X │                   │
│    ├──────────────────────┤ ▼ 기본 정보                │   ┌────┬────┐     │
│    │ [연도▼][읍면동▼][단계▼]│   위치 / 기간 / 대행자     │   │    │    │     │
│    │ [검색              ] │ ▼ 사업 현황                │   ├────┼────┤     │
│    │ 현내3..  ■선택       │   필지수 / 진행단계 / 동의율│   │ ■  │    │     │
│    │ 만음1..              │ ▶ 지구 지정 정보           │   └────┴────┘     │
│    │                      ├────────────────────────────┤                   │
│    │                      │ 필지목록 (66)   [엑셀]     │                   │
│    │                      │ [검색                    ] │                   │
│    │                      │ 번호 지번 지목 면적 소유 확정│                   │
│    │                      │ 1 현내리 456 답 512 개인 미확정│                 │
│    │                      │ ...                        │                   │
└────┴──────────────────────┴────────────────────────────┴───────────────────┘
```

#### 설명

1. 기본 정보(위치·기간·대행자·지정상태)·사업 현황(필지수·면적·진행단계·동의율·사업비)·지구 지정 정보를 접고 펼 수 있는 구역으로 보여준다.
2. 위쪽 정보 구역은 패널 높이의 절반 이내에서 따로 스크롤된다.
3. 하단 필지 목록은 리와 지번을 한 열로 합쳐 보여주고 지목·면적·소유구분·확정여부를 함께 표시하며, 목록 안에서만 스크롤된다.
4. 필지 행을 누르거나 지도에서 필지를 누르면 서로 선택이 맞춰지고 필지가 강조된다.

#### 확인사항

1. 필지 목록 건수가 사업 현황의 필지수와 일치해야 한다.
2. 필지가 많아도 목록 안에서만 스크롤되고 위쪽 정보 구역은 그대로 보여야 한다.
3. 필지 행을 누르면 지도가 해당 필지로 이동하고 강조되어야 한다.
4. «엑셀»을 누르면 필지 목록 파일이 내려받아져야 한다.
5. 상세를 닫으면 필지 표시와 강조가 지도에서 사라져야 한다.
