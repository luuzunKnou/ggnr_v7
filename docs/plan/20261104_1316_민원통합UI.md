## 개발목표

목록은 시스템에 맞는 대장만 묶어서 보여 준다.
상수도면 상수민원·급수민원, 하수도면 하수민원·준설민원이다.
통합 검색·접수일(기간)·민원분류·처리 상태로 검색 가능하고, 카드에는 민원분류·세부분류·통계분류·접수번호 태그를 둔다.

통합 검색은 해당 대장의 레이어설정에서 상세 표시로 켜 둔 항목 값 전체를 서버에서 부분 일치로 찾는다. 도형·식별번호는 검색 대상에서 뺀다. 검색창 안내 문구는 «통합 검색»만 두고, 오른쪽에 시설관리와 같은 아이콘+라벨 «초기화»를 고정으로 둔다. 초기화는 통합 검색·접수일 기간·민원분류·처리 상태를 함께 비운다.

목록의 «접수일» 기간은 작성일 기준으로 서버에서 거른다. 카드에 보이는 날짜(신청일시 등)와 섞지 않는다.

통합UI 상세는 상단 입력만 해당 대장의 레이어설정(상세 표시) 항목으로 채우고, 지번·도로명 찾기로 주소를 넣을 수 있게 한다. 하단 이력관리·첨부파일·필지정보·건축물대장은 기존UI와 같은 구성·동작을 유지한다. 기존UI 목록·상세(고정 항목 폼)는 바꾸지 않는다.
