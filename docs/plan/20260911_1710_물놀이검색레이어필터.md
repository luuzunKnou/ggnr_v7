## 개발목표

물놀이 표지판 목록에서 검색어 초기화는 검색 칸 안 엑스로만 하고, 옆의 초기화 단추는 없앤다. 검색 옆에 전체·구조함·표지판을 두어 지도에 보이는 점 종류를 고른다.

## 플로우차트

```
목록 → 검색(엑스) → 전체·구조함·표지판 → 지도 점 표시
```

## 화면설계

### MAP-WPS-LF-01 검색·레이어 필터

```
┌──────┬────────────────────────────────────────────┐
│ 메뉴 │  물놀이 표지판              [명단] [+] [닫기] │
│      ├────────────────────────────────────────────┤
│ 부서 │  🔍 통합 검색 (Enter)  ✕   [전체][구조함][표지판] │
│ 업무 │  읍·면·동 ▼  리 ▼  [구분 전체] …            │
│      │                                            │
│ 물놀 │  구분 │ 주소 │ 제목                         │
│ 이표 │  …                                         │
│ 지판 │                                            │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 검색어가 있으면 칸 안에 엑스가 나오고, 누르면 검색어만 비운다.
2. 검색 옆 초기화 단추는 두지 않는다.
3. 전체·구조함·표지판 중 하나를 고르면 지도에 그 점만 보인다.
4. 목록·읍면동·리·구분 필터는 그대로이다.

#### 확인사항

1. 검색어가 있을 때만 칸 안 엑스가 보여야 한다.
2. 검색 옆에 초기화 단추가 없어야 한다.
3. 전체를 고르면 구조함·표지판 점이 모두 보여야 한다.
4. 구조함만 고르면 구조함 점만 보여야 한다.
5. 표지판만 고르면 표지판 점만 보여야 한다.
