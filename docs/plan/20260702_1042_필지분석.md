## 개발목표

지도 사이드바 «필지분석»으로 분석 모드에 들어가, 도형 그리기 또는 행정경계(읍·면·동·리)로 분석 영역을 확정한 뒤 좌측 패널에서 분석 항목을 켜고 «분석»을 실행한다. 결과는 보고서형 한 화면(목차·섹션 스크롤)으로 확인한다. 메뉴 진입 직후에는 좌측 패널을 띄우지 않고 영역 지정 모달만 연다.

1차 범위는 영역 지정·패널·결과 모달의 목업 화면과 토지·소유자·지목 결과 섹션이다. 시군구 자동 확대, 실제 영역 합침·분석 조회는 2차에서 서버 연동한다. 기본도·건축물대장·시설 통계는 2차 이후에 결과 섹션을 채운다.

## 플로우차트

필지분석 메뉴 → (시군구 확대) → 영역 지정 모달 → 좌측 분석 패널 → 분석 → 결과 모달

## 화면설계

### MAP-PARCEL-01 필지분석 메뉴 진입

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]  [레이어][측정]…   │
│ 사 │                                                                                    │
│ 이 │                         ┌─ 분석 영역 지정 ─────────────── [×] ┐                  │
│ 드 │                         │  분석할 영역을 지정하는 방법을       │                  │
│ 바 │                         │  선택하세요.                         │                  │
│   │  ▶필지분석               │                                      │                  │
│   │                         │  ┌────────────┐  ┌────────────┐      │                  │
│   │                         │  │ 도형 그리기 │  │ 행정경계 선택│      │                  │
│   │                         │  └────────────┘  └────────────┘      │                  │
│   │                         │                          [취소]      │                  │
│   │                         └──────────────────────────────────────┘                  │
│   │              (지도 — 필요 시 시군구가 화면 대부분을 차지)                          │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```



#### 설명

1. 사이드바 «필지분석»을 선택하면 분석 모드가 켜지고 좌측 분석 패널은 아직 보이지 않는다.
2. 지도 위에 «분석 영역 지정» 모달이 중앙에 열린다.
3. 현재 화면이 해당 시군구를 충분히 보여주지 않으면 시군구가 화면 약 80%를 차지하도록 지도를 확대한다.
4. 모달을 닫으면 필지분석 모드가 종료된다.
5. 영역을 확정하기 전까지는 분석 항목 선택·분석 실행을 할 수 없다.



#### 확인사항

1. 메뉴 진입 직후 좌측 분석 패널이 보이지 않아야 한다.
2. «분석 영역 지정» 모달이 지도 위에 표시되어야 한다.
3. «필지분석» 메뉴가 선택된 상태로 보여야 한다.
4. 다른 지도 기능 패널과 겹치지 않아야 한다.



### MAP-PARCEL-02 분석 영역 지정 · 방식 선택

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]                    │
│ 사 │                         ┌─ 분석 영역 지정 ─────────────── [×] ┐                  │
│ 이 │                         │  분석할 영역을 지정하는 방법을       │                  │
│ 드 │                         │  선택하세요.                         │                  │
│ 바 │                         │                                      │                  │
│   │  ▶필지분석               │  ┌────────────────┐ ┌────────────────┐               │
│   │                         │  │   도형 그리기   │ │  행정경계 선택  │               │
│   │                         │  │ 사각·다각·원    │ │ 읍·면·동·리     │               │
│   │                         │  └────────────────┘ └────────────────┘               │
│   │                         │                                      [취소]          │
│   │                         └──────────────────────────────────────┘                  │
│   │              (지도 배경)                                                           │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```



#### 설명

1. «분석 영역 지정» 모달 1단에서 «도형 그리기» 또는 «행정경계 선택» 카드를 고른다.
2. «도형 그리기»를 고르면 도형 그리기 2단 화면으로 넘어간다.
3. «행정경계 선택»을 고르면 행정경계 2단 화면으로 넘어간다.
4. «취소»를 누르면 모달이 닫히고 필지분석 모드가 종료된다.
5. 이미 영역을 확정한 뒤 «변경»으로 다시 열었을 때도 같은 1단부터 시작할 수 있다.



#### 확인사항

1. 두 방식 카드가 나란히 보여야 한다.
2. 카드 선택 시 해당 2단 화면으로 전환되어야 한다.
3. «취소» 시 필지분석이 완전히 종료되어야 한다.



### MAP-PARCEL-03 분석 영역 지정 · 도형 그리기

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]                    │
│ 사 │                         ┌─ 분석 영역 지정 ─────────────── [×] ┐                  │
│ 이 │                         │  [← 뒤로]  도형 그리기               │                  │
│ 드 │                         │  [사각형] [다각형] [원]              │                  │
│ 바 │                         ├──────────────────────────────────────┤                  │
│   │  ▶필지분석               │         (모달 뒤 지도에서 그리기)     │                  │
│   │                         │              ┌───────────┐           │                  │
│   │                         │              │ 선택 영역  │           │                  │
│   │                         │              └───────────┘           │                  │
│   │                         │                      [취소]  [적용]    │                  │
│   │                         └──────────────────────────────────────┘                  │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```



#### 설명

1. «← 뒤로»로 방식 선택 1단으로 돌아갈 수 있다.
2. 사각형·다각형·원 중 하나를 고른 뒤 지도에 영역을 그린다.
3. 그려진 영역은 지도에 하이라이트로 표시된다.
4. «적용»을 누르면 영역이 확정되고 좌측 분석 패널이 나타난다.
5. «취소»는 모달을 닫고 필지분석 모드를 종료한다.



#### 확인사항

1. 도형을 그리기 전 «적용»은 비활성이거나 안내가 나와야 한다.
2. «적용» 후 좌측 분석 패널과 지도 하이라이트가 함께 보여야 한다.
3. 그리기 중 다른 지도 측정·도형 기능과 겹치지 않아야 한다.



### MAP-PARCEL-04 분석 영역 지정 · 행정경계

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]                    │
│ 사 │                         ┌─ 분석 영역 지정 ─────────────── [×] ┐                  │
│ 이 │                         │  [← 뒤로]  행정경계 선택             │                  │
│ 드 │                         │  시도·시군구: 경상북도 경산시         │                  │
│ 바 │                         │  [동부동] [중방동] [옥산동]           │                  │
│   │  ▶필지분석               │  ┌──────────────────────────────┐  │                  │
│   │                         │  │ 동부동  ☑ 전체                 │  │                  │
│   │                         │  │     ☑ 송정리   ☑ 화평리        │  │                  │
│   │                         │  │ 중방동  ☑ 전체                 │  │                  │
│   │                         │  │     ☑ 서부리   ☑ 남부리        │  │                  │
│   │                         │  └──────────────────────────────┘  │                  │
│   │                         │  선택 항목 (3건): 동부동, 중방동…   │                  │
│   │                         │                      [취소]  [적용]  │                  │
│   │                         └──────────────────────────────────────┘                  │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```



#### 설명

1. 시도·시군구는 설정값으로 고정되며 사용자가 바꿀 수 없다.
2. 읍·면·동을 여러 개 선택할 수 있고, 선택한 동마다 리 체크 영역이 펼쳐진다.
3. 동을 처음 고르면 해당 동의 리가 전체 선택된 상태로 시작한다.
4. 리를 모두 고른 동은 «동부동»처럼 동 이름만, 일부만 고르면 «동부동 송정리»처럼 표시한다.
5. «적용» 시 선택 구역이 지도에 맞춰지고 하이라이트되며 좌측 분석 패널이 열린다.



#### 확인사항

1. 선택 항목이 하나도 없으면 «적용»이 되지 않아야 한다.
2. «적용» 후 지도가 선택 구역에 맞게 이동·확대되어야 한다.
3. 동·리 선택 상태가 «변경»으로 모달을 다시 열었을 때 복원되어야 한다.



### MAP-PARCEL-05 좌측 분석 패널

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬──────────────────┬─────────────────────────────────────────────────────────────────┤
│   │ ┌─ 필지분석 ────┐│  [ 🔍 주소·지번 검색________________________________________ ]   │
│ 사 │ │ 분석 영역 [변경]││                                                                 │
│ 이 │ │ 행정경계 3개   ││              ┌─────────────────────────┐                        │
│ 드 │ │ 약 4.2 ha      ││              │    선택 영역 하이라이트   │                        │
│ 바 │ ├───────────────┤│              └─────────────────────────┘                        │
│   │ │ ▼ 기본도 [전체]││                                                                 │
│   │ │   □ 항공영상 … ││                                                                 │
│   │ │ ▼ 필지분석     ││                                                                 │
│   │ │   ☑ 토지현황   ││                                                                 │
│   │ │   ☑ 소유자현황 ││                                                                 │
│   │ │   ☑ 지목별현황 ││                                                                 │
│   │ ├───────────────┤│                                                                 │
│   │ │    [ 분석 ]    ││                                                                 │
│   │ └───────────────┘│                                                                 │
│   │  ▶필지분석       │                                                                 │
└───┴──────────────────┴─────────────────────────────────────────────────────────────────┘
```



#### 설명

1. 영역 «적용» 후에만 좌측 «필지분석» 패널이 나타난다.
2. 상단 «분석 영역»에 방식·요약·면적·시도·시군구가 보이고 «변경»으로 영역 지정 모달을 다시 연다.
3. «기본도»·«건축물»·«필지분석»·«시설목록» 그룹마다 항목 스위치와 «전체»가 있다.
4. 1차에는 «필지분석» 그룹의 토지·소유자·지목 항목만 실제 결과가 채워진다.
5. 영역이 없거나 항목이 하나도 켜지지 않으면 «분석» 버튼을 누를 수 없다.



#### 확인사항

1. 영역 미지정 시 분석 항목과 «분석» 버튼이 비활성이어야 한다.
2. «변경» 시 이전 영역·행정경계 선택이 모달에 복원되어야 한다.
3. «분석» 실행 중에는 진행 안내가 보여야 한다.
4. 패널 너비를 드래그로 조절할 수 있어야 한다.



### MAP-PARCEL-06 분석 결과 모달

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬──────────────────┬─────────────────────────────────────────────────────────────────┤
│   │ ┌─ 필지분석 ────┐│         ┌─ 분석 결과 ───────────── [CSV] [닫기] ─┐            │
│ 사 │ │  (패널 유지)  ││         │ 교차 필지 N건 · 합계 면적 · 항목 M개    │            │
│ 이 │ │               ││         ├──────────┬──────────────────────────────┤            │
│ 드 │ │               ││         │ · 필지분석│  토지현황                    │            │
│ 바 │ │               ││         │   토지현황│  (필지 목록 표)              │            │
│   │ │               ││         │   소유자  │                              │            │
│   │ │               ││         │   지목별  │  소유자 구분 통계            │            │
│   │ │               ││         │ · 기본도  │                              │            │
│   │ │               ││         │           │  지목별 통계                 │            │
│   │ │               ││         └──────────┴──────────────────────────────┘            │
│   │  ▶필지분석       │                                                                 │
└───┴──────────────────┴─────────────────────────────────────────────────────────────────┘
```



#### 설명

1. «분석» 완료 후 지도 위 중앙에 «분석 결과» 모달이 열린다.
2. 좌측은 그룹·항목 목차, 우측은 켜 둔 항목만 섹션으로 이어지는 본문이다.
3. 본문을 스크롤하면 목차에서 해당 항목이 강조되고, 목차를 누르면 그 섹션으로 이동한다.
4. 휠 한 번에 섹션 하나씩 위·아래로 넘기고, 스크롤바 드래그 후에도 가장 가까운 섹션에 맞춘다.
5. «닫기»로 모달만 닫고 좌측 패널·지도 영역은 유지한다.



#### 확인사항

1. 분석 시 켠 항목만 결과 섹션이 생성되어야 한다.
2. 스크롤·목차 클릭 시 목차 강조가 본문 위치와 맞아야 한다.
3. 1차 목업에서는 토지·소유자·지목 섹션에 샘플 데이터가 보여야 한다.
4. «CSV»·«닫기»가 헤더에 보여야 한다.
