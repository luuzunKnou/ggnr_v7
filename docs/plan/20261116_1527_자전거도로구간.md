## 개발목표

자전거도로 노선 속성은 이미 추가·수정·삭제가 된다. 다음 단계는 노선 아래 «구간»을 어떻게 만들고 고칠지 정하는 것이다. 도로망도도 지금은 구간을 목록에서 고르기만 하고, 구간 자체를 새로 넣거나 고치는 UI는 없다. 같은 기준으로 자전거도로 구간도 속성만 먼저 다루고, 지도 도형은 나중에 붙인다.

## 플로우차트

노선 상세 → 구간 목록 → (추가·행 클릭) → 구간 속성 편집 → 구간 목록

## 화면설계

### BIKE-SEG-01 구간 목록 (속성 아래)

```
┌──────────────────────────────────────────────────────────────┐
│도로│ 노선 상세 · 속성정보 …                         [닫기]   │
│ ·  │ ┌ 구간 ─────────────────────────────────────────────┐ │
│자  │ │ 1-1  삼성현로R                         3.60 km    │ │
│전  │ │ 1-2  삼성현로L                         3.60 km    │ │
│거  │ │                              [구간 추가]            │ │
│도로│ └───────────────────────────────────────────────────┘ │
│    │                      (지도)                              │
└────┴─────────────────────────────────────────────────────────┘
```

#### 설명

1. 속성정보 아래에 구간 표가 있다.
2. «구간 추가»는 목록 헤더 또는 표 아래 버튼으로 둔다.
3. 행을 누르면 구간 속성 편집(모달 또는 상세 내 시트)이 열린다.

#### 확인사항

1. 구간이 없는 노선에도 «구간 추가»가 보여야 한다.
2. 행 클릭 시 구간 편집이 열려야 한다.

### BIKE-SEG-02 구간 속성 편집

```
┌──────────────────────────────────────────────────────────────┐
│도로│ 노선 목록 │ 노선 상세 (반투명 위에 구간 편집 카드)      │
│ ·  │           │  ┌ 구간 속성 ─────────────────────────┐   │
│    │           │  │ 일련번호 · 노선명 · 기점 · 종점     │   │
│    │           │  │ 종류 · 연장 · 폭원(구역)            │   │
│    │           │  │              [저장] [삭제] [닫기]   │   │
│    │           │  └─────────────────────────────────────┘   │
└────┴───────────┴─────────────────────────────────────────────┘
```

#### 설명

1. 도로망도 유지보수 모달처럼 목록·상세를 덮는 시트로 연다.
2. 1차는 속성만 저장한다. 지도에 구간 선을 그리는 것은 넣지 않는다.
3. 삭제는 확인 후 구간만 목록에서 뺀다.

#### 확인사항

1. 저장 후 구간 목록에 반영되어야 한다.
2. 삭제 후 목록에서 사라져야 한다.
3. Esc·바깥 클릭으로 닫을 수 있어야 한다.
