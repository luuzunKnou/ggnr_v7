# 작업계획서

## 개발목표

소규모 공공시설관리 시스템에 «예산·공사» 메뉴를 만든다. 정비계획처럼 지도 없이 사이드바 오른쪽을 꽉 채운 화면이며, 위쪽에서 «현황·예산·공사대장»을 바꿔 본다. 이번 단계는 예시 자료로 화면을 먼저 만들고, 새로고침 전까지만 유지한다.

예산 담당자는 연도별 예산을 등록하고, 정비계획 시설·연차에 배정한 뒤 집행 내역을 쌓는다. e호조 연계 방식은 정해지지 않아 이번에는 집행을 직접 넣는다. 공사 담당자는 공사대장에 계약·대상 시설·준공·첨부(설계서·계약서·준공서류·사진)를 관리한다.

준공 처리한 공사의 시공 사업량과 실제 공사비는 정비계획 명세서의 «정비된 부분»에 합쳐져 정비율이 자동으로 바뀐다. 현황에서는 연도별 예산·배정·집행·잔액·집행률, 공사 건수, 읍면별·유형별 집행, 계획 대비 정비율을 본다. 협의·실시설계 입력, 미시행분 이월, 계획과 실적 비교 화면은 다음 단계로 미룬다.

## 플로우차트

```
예산·공사 → 현황 ⇄ 예산 목록 → 예산 상세 → (배정 추가 · 집행 등록) ⇄ 공사대장 → 공사 상세 → 준공 처리 → 정비계획 정비율
```

#### 설명

1. 사이드바 «예산·공사»를 누르면 지도 없이 오른쪽을 꽉 채운 화면이 열리고 처음에는 현황을 보여 준다.
2. 연도를 고르면 카드(총예산·배정·집행·잔액·집행률·공사 건수)가 그 연도 기준으로 바뀐다.
3. 연도별 예산·집행 막대, 그 연도 읍면별·유형별 집행 막대를 보여 준다.
4. 계획 대비 정비율은 정비계획 전체 사업량·사업비와 준공 공사로 정비된 사업량·사업비, 정비율을 보여 준다.

#### 확인사항

1. 연도를 바꾸면 카드와 읍면별·유형별 막대가 그 연도 값으로 바뀌어야 한다.
2. 집행률은 집행 ÷ 예산으로 계산되어야 한다.
3. 공사를 준공 처리하면 정비율이 올라가야 한다.

#### 설명

1. 예산 목록은 연도·재원·검색으로 거르고, 행마다 예산액·배정·집행·잔액·집행률을 보여 준다.
2. 행을 누르면 오른쪽 상세에 예산 정보, 배정 목록, 집행 내역이 보인다.
3. «배정 추가»는 정비계획 시설을 표에서 골라 배정액을 넣고, 연차는 정비계획 값을 따른다.
4. «집행 등록»은 배정 시설·집행일·금액·적요를 넣는다.

#### 확인사항

1. 예산을 등록하면 목록에 바로 나와야 한다.
2. 배정액 합이 예산액을 넘으면 저장되지 않아야 한다.
3. 집행액이 배정액을 넘으면 저장되지 않아야 한다.
4. 배정·집행이 있는 예산은 삭제 전에 확인을 받아야 한다.


#### 설명

1. 공사대장은 연도·상태·검색으로 거르고, 공사명·상태·업체·계약금액·공사기간·대상 시설 수·준공일을 보여 준다.
2. «공사 등록»은 공사명·예산·업체·설계금액·계약금액·공사기간·상태와 대상 시설(정비계획 시설, 여러 곳)을 넣는다.
3. 행을 누르면 오른쪽 상세에 공사 정보, 대상 시설, 첨부(설계서·계약서·준공서류·사진·기타)가 보인다.
4. «준공 처리»는 준공일과 시설별 시공 사업량·실제 공사비를 넣고 상태를 준공으로 바꾼다.
5. 준공한 공사의 사업량·공사비는 정비계획 명세서의 정비된 부분과 정비율에 합쳐진다.

#### 확인사항

1. 대상 시설 없이 공사를 등록하면 안내가 나와야 한다.
2. 준공 처리 후 정비계획 명세서의 해당 시설 정비된 부분에 사업량·사업비가 보여야 한다.
3. 첨부를 구분별로 올리고 미리보기·내려받기·삭제할 수 있어야 한다.
4. 준공한 공사는 수정 없이 첨부만 바꿀 수 있어야 한다.
