## 개발목표

드론영상 작업단위 상세에서 작업일·임무 목적·작성자·메모만 수정해 데이터베이스에 저장한다. 작업단위명과 실제 폴더·원본·변환 타일 경로는 변경하지 않는다. 작업단위·파일 삭제는 원본과 변환 타일까지 함께 제거한다.

영향 받는 기능: 드론영상 목록, 작업단위 상세, 드론영상 지도 표시.

## 플로우차트

드론영상 목록 → 작업단위 상세 ⇄ 업무 속성 수정 → 상세 재조회

## 화면설계

### MEDIA-ORTHO-01 드론영상 작업단위 상세
```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 검색                                           촬영요청  테마  시스템 선택 │
├──────┬──────────────────────────┬───────────────────────────┬───────────────┤
│ 메뉴 │ 드론영상 목록            │ 작업단위 상세             │ 지도          │
│      │                          │ ┌───────────────────────┐ │               │
│ 드론 │ 선택된 작업단위          │ │ 작업단위명      고정  │ │               │
│ 영상 │                          │ │ 작업일         [입력] │ │               │
│      │                          │ │ 임무 목적      [입력] │ │               │
│      │                          │ │ 작성자         [입력] │ │               │
│      │                          │ │ 메모           [입력] │ │               │
│      │                          │ └───────────────────────┘ │               │
│      │                          │             [저장] [취소] │               │
└──────┴──────────────────────────┴───────────────────────────┴───────────────┘
```
#### 설명

1. 작업단위명은 읽기 전용으로 표시한다.
2. 작업일·임무 목적·작성자·메모만 수정한다.
3. 저장 후 목록과 상세를 서버 값으로 갱신한다.

#### 확인사항

1. 작업단위명은 입력창으로 바뀌지 않아야 한다.
2. 지정한 네 가지 속성만 입력할 수 있어야 한다.
3. 저장 후 화면을 다시 열어도 수정값이 유지되어야 한다.
4. 수정 전후 실제 폴더와 지도 타일 경로가 같아야 한다.
