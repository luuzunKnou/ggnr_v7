## 개발목표

누수분석의 격리 제수변·탐색 관로 계산을, 기존 절점만 따라가던 방식에서 레거시 제수변 격리 탐색의 핵심만 가져와 맞춘다. 누수 스냅 지점에서 관로를 따라가며 진행 방향의 첫 제수변에서 멈추고, 지도 강조는 누수 쪽에서 제수변까지로만 남긴다. soft·hard·짧은 분기 예외 전체는 이식하지 않고, 관 위 부착·양방향 추적·반대편 봉인·접속점 형제 제수변·강조 클립만 1차로 적용한다. 본 사례에서는 제수변 너머(해당 관로 번호 이후)가 칠해지면 오류로 본다.

## 플로우차트

```
누수분석 → 관로 스냅 → 양방향 관로 추적 → (첫 제수변) 잠금 목록·강조 클립 → 결과·이력
```

## 화면설계

### MAP-LEAK-TRACE-01 누수 탐색 결과

```
┌──────────┬──────────────────────────────────────────────┐
│ 사이드바  │  공간분석 · 누수분석                          │
│ · 공간분석│  [분석 이력]                                 │
│ · …      │──────────────────────────────────────────────│
│          │  잠글 제수변 목록                              │
│          │  · 제수변 …                                   │
│          │──────────────────────────────────────────────│
│          │  [지도]                                       │
│          │   누수점 · 제수변까지 관로만 강조              │
│          │   (제수변 너머 관로는 미강조)                  │
│          │──────────────────────────────────────────────│
│          │  [새 분석]  [분석결과저장]                     │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 지도에서 관로를 고르면 누수 위치에 스냅된다.
2. 스냅 기준으로 관로를 양쪽으로 따라가며 만나는 첫 제수변을 잠금 대상으로 잡는다.
3. 강조 관로는 누수에서 그 제수변까지이며, 제수변 너머는 칠하지 않는다.
4. 화면 구성·이력·저장 동작은 기존과 같다.

#### 확인사항

1. 제수변이 있는 구간에서는 그 너머 관로가 강조되지 않아야 한다.
2. 잠글 제수변 목록에 경로상 첫 제수변이 포함되어야 한다.
3. 같은 접속점의 짝 제수변도 잠금 목록에 잡힐 수 있어야 한다.
4. 새 분석·이력 불러오기는 이전과 같이 동작해야 한다.
