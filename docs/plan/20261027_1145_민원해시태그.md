## 개발목표

상·하수도 행정에서는 업무별 민원 메뉴 대신 공통 민원관리만 둔다. 목록·등록에서 해시태그로 상수·급수·하수·준설 등을 구분하고, 준설민원 상세에만 준설대상지 하위 영역을 커스텀으로 붙인다. 다른 시스템의 민원관리는 그대로 둔다.

## 플로우차트

지도 → 민원관리 → (태그 필터) → 민원 상세 ⇄ (준설만) 준설대상지

## 화면설계

### MAP-COMP-TAG-01 민원관리 목록

```
┌ 사이드바 ────────────── 지도 ─────────────────────────┐
│ 민원관리         ┌ 민원관리 ────────────────┐         │
│ …                 │ 전체 #상수 #급수 #하수 #준설 │         │
│                   │ 검색·상태 필터              │         │
│                   │ 목록 (제목·주소·태그·상태)  │         │
│                   └────────────────────────────┘         │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 상·하수도 행정 사이드바에 «민원관리»만 민원 메뉴로 둔다.
2. 목록 위에 태그 칩으로 전체 또는 특정 태그만 본다.
3. 각 행에 붙은 태그가 보이며, 선택 시 상세로 간다.
4. 등록 시 태그를 고르거나 붙여 저장한다.

#### 확인사항

1. 상수·급수·하수·준설 전용 사이드바 메뉴가 없어야 한다.
2. 태그 칩을 누르면 해당 태그만 목록에 나와야 한다.
3. 태그 없는 민원은 전체에서만 보이거나 안내에 맞게 처리되어야 한다.

### MAP-COMP-TAG-02 준설민원 상세·대상지

```
┌ 사이드바 ────────────── 지도 ─────────────────────────┐
│ 민원관리         ┌ 민원 상세 ───────────────┐         │
│                   │ 접수·내용·태그(#준설)     │         │
│                   │ 처리내역                  │         │
│                   │ ── 준설대상지 ──          │         │
│                   │ 대상지 목록·추가·수정     │         │
│                   └───────────────────────────┘         │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 태그에 준설이 있을 때만 상세 하단에 준설대상지 영역이 보인다.
2. 대상지는 해당 민원에 붙어 목록·추가·수정한다.
3. 다른 태그 민원 상세에는 대상지 영역이 없다.
4. 지도 강조·이동은 민원과 대상지 선택에 맞게 동작한다.

#### 확인사항

1. 준설이 아닌 민원 상세에 준설대상지가 나오지 않아야 한다.
2. 준설민원에서 대상지를 추가하면 그 민원 아래에만 보여야 한다.
3. 사이드바에 준설대상지 단독 메뉴가 없어야 한다.
