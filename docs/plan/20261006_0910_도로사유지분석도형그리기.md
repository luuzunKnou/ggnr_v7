## 개발목표

도로 사유지분석에서 실폭도로 레이어를 고른 뒤, 지도 안내창에서 범위 지정 방식을 «선 찍기»·«다각형»·«사각형»·«원» 중에서 고른다. 도형을 그리면 도형 안의 실폭도로 면만 잘라 분석 범위로 미리 보여 주고, 적용하면 기존과 같은 필지 목록을 보여 준다.

영향 받는 기능: 사유지분석(도로) 경계선 찍기·미리보기·적용, 사유지분석(하천)은 화면 처리 공유 부분만 회귀 확인.

## 플로우차트

```
레이어 선택 → 지정 방식 선택 ⇄ (선 찍기 | 도형 그리기) → 범위 미리보기 → 적용 → 필지 목록
```

## 화면설계

### MAP-PLA-ROAD-01 지정 방식 선택

```
┌──────────────────────────────────────────────────────────────┐
│ [사이드바] │      [ 검색                              ]       │
│            │   ┌──────────────────────────────────────┐       │
│ 사유지분석 │   │ 선 찍기 │ 다각형 │ 사각형 │ 원        │       │
│            │   └──────────────────────────────────────┘       │
│ 목록 패널  │   ┌──────────────────────────────────────┐       │
│            │   │ 지도를 클릭해 꼭짓점을 찍고           │       │
│            │   │ 더블클릭으로 마치세요.      [취소]    │       │
│            │   └──────────────────────────────────────┘       │
│            │                                                  │
│            │        (노란 도로 면이 깔린 지도)                │
│            │                                                  │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 실폭도로 레이어를 고르면 안내창 위에 지정 방식 버튼 네 개가 나온다.
2. 처음에는 «선 찍기»가 선택되어 있고 기존 경계선 찍기와 같이 동작한다.
3. 도형 방식을 고르면 안내 문구가 그리는 방법으로 바뀐다.
4. 방식을 바꾸면 찍은 선·그린 도형·미리보기가 지워진다.

#### 확인사항

1. 도로 레이어에서만 지정 방식 버튼이 보여야 한다.
2. 하천 레이어에서는 지정 방식 버튼이 보이지 않아야 한다.
3. 방식을 바꾸면 이전에 찍은 선이 지도에서 사라져야 한다.

### MAP-PLA-ROAD-02 도형 범위 미리보기

```
┌──────────────────────────────────────────────────────────────┐
│ [사이드바] │      [ 검색                              ]       │
│            │   ┌──────────────────────────────────────┐       │
│ 사유지분석 │   │ 선 찍기 │ 다각형 │ 사각형 │ 원        │       │
│            │   └──────────────────────────────────────┘       │
│ 목록 패널  │     도형 안 도로가 범위로 잡혔습니다              │
│            │   ┌──────────────────────────────────────┐       │
│            │   │ 다시 그리기 │ 적용 │ 다시 지정 │ 취소 │       │
│            │   └──────────────────────────────────────┘       │
│            │      ┌───────────────┐                           │
│            │      │  빨간 도로 면  │                           │
│            │      └───────────────┘                           │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 도형을 다 그리면 도형 테두리가 남고, 그 안의 도로 면이 빨간색으로 미리 보인다.
2. 확인 중에는 «범위 확인 중…»이 보이고 적용할 수 없다.
3. 다시 그리면 이전 도형을 바꾼다.
4. «다시 그리기»는 도형을 지우고 그리기 상태로 돌아간다.

#### 확인사항

1. 도형 안 도로 면만 미리보기에 나와야 한다.
2. 도로가 없는 곳에 그리면 «도형 안에 도로가 없습니다» 안내가 나와야 한다.
3. 너무 큰 도형은 넓이 상한 안내가 나와야 한다.
4. 적용하면 범위와 겹치는 필지 목록이 나와야 한다.
