## 개발목표

로그인한 사용자가 정책지도 압축 파일을 올리고, 목록에서 바로 열어 보는 화면을 만든다. 울산 UAV에서만 내정보 공통에 바로가기를 둔다. 지도 사이드바 기능이 아니라 공지·자료실처럼 별도 화면이다.

## 플로우차트

내정보 공통 → 정책지도 바로가기 → 목록 → (업로드) 등록 ⇄ (행 클릭) 열람 → 목록

## 화면설계

### UAV-PM-01 정책지도 목록

```
┌──────────────────────────────────────────────────────────┐
│ 사이트헤더                                                │
│ ┌─ 정책지도 바로가기 ────────────────── [등록] ─────────┐│
│ │ 제목                              등록자   날짜        ││
│ │ 동구 정책지도 A                   hong    2026.09.14  ││
│ │ 동구 정책지도 B                   kim     2026.09.10  ││
│ └────────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 목록에서 제목을 누르면 올린 지도를 새 탭으로 연다.
2. 등록을 누르면 제목과 압축 파일을 올려 추가한다.
3. 로그인한 사용자만 등록·삭제가 된다.

#### 확인사항

1. 울산 UAV가 아니면 내정보 공통에 메뉴가 없어야 한다.
2. 압축을 올리면 목록에 제목이 보여야 한다.
3. 제목을 누르면 지도 화면이 열려야 한다.
4. 비로그인으로는 등록할 수 없어야 한다.
