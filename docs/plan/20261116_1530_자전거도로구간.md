## 개발목표

노선 «수정»을 누르면 위쪽 노선 속성과 함께 아래 구간도 같이 고친다. 구간은 한 덩어리가 아니라 행마다 따로 두고, 편집 중에만 `+`로 넣고 `−`로 뺀다. 조회 때는 지금처럼 보기만 한다. 1차는 속성·목록만이고 지도 도형은 넣지 않는다.

## 플로우차트

노선 상세(조회) → 수정 → 속성 편집 + 구간(+/−·행 편집) → 저장 → 노선 상세(조회)

## 화면설계

### BIKE-SEG-10 조회 모드

```
┌──────────────────────────────────────────────────────────────┐
│도로│ 노선 상세                                      [닫기]   │
│ ·  │ 속성정보 (읽기)                                          │
│자  │ 구간 · 전체 8                                            │
│전  │ ┌─────────────────────────────────────────────────────┐ │
│거  │ │ 1-1  삼성현로R                            3.60 km   │ │
│도로│ │ 1-2  삼성현로L                            3.60 km   │ │
│    │ └─────────────────────────────────────────────────────┘ │
│    │ 첨부 …                                                   │
│    │                              [수정] [삭제]               │
└────┴─────────────────────────────────────────────────────────┘
```

#### 설명

1. 구간 표에 `+` `−`가 없다.
2. 행을 누르면 구간 상세(폭원 등) 모달만 연다. 목록 구성은 바꾸지 않는다.
3. 하단 «수정»은 노선 속성·구간 목록을 함께 편집 모드로 바꾼다.

#### 확인사항

1. 조회 중 구간 옆에 `+` `−`가 없어야 한다.
2. 행 클릭 시 구간 조회 모달만 열려야 한다.

### BIKE-SEG-11 수정 모드 (속성 + 구간 +/−)

```
┌──────────────────────────────────────────────────────────────┐
│도로│ 노선 상세                                      [닫기]   │
│ ·  │ 속성정보 (입력)                                          │
│자  │ 구간 · 8                              [+] [−]            │
│전  │ ┌─────────────────────────────────────────────────────┐ │
│거  │ │ 1-1  삼성현로R                            3.60 km   │ │
│도로│ │ 1-2  삼성현로L  ← 선택됨                  3.60 km   │ │
│    │ └─────────────────────────────────────────────────────┘ │
│    │ ※ + 새 구간 행 · − 선택 구간 삭제 · 행 클릭 시 구간 속성 │
│    │                              [저장] [취소]               │
└────┴─────────────────────────────────────────────────────────┘
```

#### 설명

1. 하단 «수정» 후 구간 헤더에 `+` `−`가 보인다.
2. `+`는 빈 구간 한 줄을 맨 아래(또는 맨 위)에 붙이고, 바로 구간 속성 편집 모달을 연다.
3. `−`는 지금 선택된 구간을 확인 후 목록에서 뺀다. 선택이 없으면 안내만 한다.
4. 편집 모드에서 행을 누르면 그 구간의 일련번호·노선명·기점·종점·종류·연장·폭원을 모달에서 고친다.
5. 하단 «저장»은 노선 속성 + 구간 목록을 한 번에 반영한다. «취소»는 둘 다 되돌린다.
6. 일련번호는 저장 시 `1-1`, `1-2`처럼 자동으로 맞춰 주거나, 모달에서 직접 고치게 한다(1차는 자동 권장).

#### 확인사항

1. «수정» 후에만 구간 `+` `−`가 보여야 한다.
2. `+` 후 구간 수가 늘고 편집 모달이 열려야 한다.
3. 구간을 고른 뒤 `−`하면 목록에서 빠져야 한다.
4. «취소» 후 구간 수·내용이 수정 전과 같아야 한다.
5. «저장» 후 조회 모드로 돌아가고 `+` `−`가 사라져야 한다.

### BIKE-SEG-12 구간 속성 모달 (수정 모드에서만 편집)

```
┌ 구간 속성 ─────────────────────────────────────────┐
│ 일련번호 · 노선명 · 기점 · 종점                      │
│ 종류 · 연장 · 폭원(전용·겸용 분리/비분리)             │
│                         [확인] [닫기]                 │
└──────────────────────────────────────────────────────┘
```

#### 설명

1. 목록·상세를 덮는 시트다. «확인»은 임시 구간 목록에만 반영하고, 노선 «저장» 전까지는 확정하지 않는다.
2. 조회 모드 모달은 읽기만, 수정 모드 모달은 입력 가능하다.

#### 확인사항

1. 수정 모드에서 모달 값이 구간 표에 바로 보여야 한다.
2. 모달만 닫고 노선 «취소»하면 모달에서 바꾼 내용도 사라져야 한다.
