## 개발목표

후보지 상세 아래 탭을 후보지 평가·안전점검·피해이력·첨부파일 네 개로 맞춘다. 평가는 파일과 메타를 함께 올려 목록·썸네일·최근 결과로 보고, 피해이력은 시설에 두어 정비계획 분석이 읽어 가되 분석 화면에서는 고치지 않는다.

## 플로우차트

```
후보지 목록 → 시설 상세 → (후보지 평가 ⇄ 안전점검 ⇄ 피해이력 ⇄ 첨부파일) → 정비계획 분석(피해 읽기)
```

## 화면설계

### CAND-DET-01 후보지 상세 탭

```
┌──────────┬──────────────────────────────────────────────┐
│ 후보지   │ 시설명                              [닫기]   │
│ 목록     │──────────────────────────────────────────────│
│          │ ▼ 속성정보                                   │
│          │──────────────────────────────────────────────│
│          │ [후보지 평가][안전점검][피해이력][첨부파일]   │
│          │──────────────────────────────────────────────│
│          │ (선택한 탭 내용)                             │
│          │──────────────────────────────────────────────│
│          │                         [수정] [삭제]        │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 상세 탭은 후보지 평가·안전점검·피해이력·첨부파일만 보인다.
2. 일반·관리 평가·위험도 평가·정비계획 탭과 정비계획으로 이동은 없다.
3. 속성정보 접기·수정·삭제는 그대로다.

#### 확인사항

1. 탭이 네 개만 보여야 한다.
2. 정비계획 관련 탭·이동 버튼이 없어야 한다.

### CAND-DET-02 후보지 평가

```
┌──────────┬──────────────────────────────────────────────┐
│ 후보지   │ …탭…                                         │
│ 목록     │                              [평가 등록]     │
│          │ ┌────────────────────────────────────────┐   │
│          │ │평가일│평가자│선정│[미리보기]            │   │
│          │ └────────────────────────────────────────┘   │
│          │ 최근 결과                                    │
│          │ 평가일 · 평가자 · 선정여부                   │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 평가 등록 시 파일과 평가일·평가자·선정여부를 함께 넣는다.
2. 목록과 썸네일이 한 화면에 나오고, 썸네일·파일 클릭 시 첨부 미리보기가 열린다.
3. 목록 아래에 가장 최근 평가 요약을 보여 준다.

#### 확인사항

1. 등록 후 목록·썸네일·최근 결과가 맞아야 한다.
2. 썸네일 클릭 시 미리보기가 열려야 한다.

### CAND-DET-03 안전점검

```
┌──────────┬──────────────────────────────────────────────┐
│ 후보지   │ …탭…                                         │
│ 목록     │                              [자료 등록]     │
│          │ ┌────────────────────────────────────────┐   │
│          │ │종류│일자│담당│요약│[미리보기]           │   │
│          │ └────────────────────────────────────────┘   │
│          │ 최근 결과 · 등급·점수·평가구분               │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 위험도 평가·일반·관리 평가·현장조사를 한 목록으로 보여 준다.
2. 일반·관리 평가는 해당 연도에 없으면 행이 없다.
3. 목록과 썸네일·최근 결과를 후보지 평가와 같은 방식으로 둔다.

#### 확인사항

1. 세 종류가 한 목록에 나와야 한다.
2. 최근 결과에 최근 위험도·구분이 보여야 한다.

### CAND-DET-04 피해이력·첨부·분석

```
┌──────────┬──────────────────┐     ┌────────────────────┐
│ 피해이력 │ 발생일·항목·물량 │ ──► │ 정비계획 분석      │
│          │ [추가][수정][삭제]│     │ 피해내역(읽기전용) │
└──────────┴──────────────────┘     └────────────────────┘
```

#### 설명

1. 피해이력은 시설에 두고 등록·수정·삭제한다.
2. 첨부파일 탭에는 요약·공공시설대장 등 평가가 아닌 파일만 둔다.
3. 정비계획 분석은 시설 피해이력을 읽어 점수에 쓰고, 분석 화면에서는 고치지 않는다.

#### 확인사항

1. 첨부파일 탭에 평가용 파일이 섞이지 않아야 한다.
2. 분석에서 피해 내역이 시설과 같고 수정이 안 되어야 한다.
