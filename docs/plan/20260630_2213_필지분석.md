## 개발목표

지도 사이드바 «필지분석»으로 전용 분석 모드에 들어가, 도형 또는 행정경계(읍면동·리)로 분석 범위를 정한 뒤 범위 안 필지를 클릭해 지번·토지 기본·소유·이용계획·공시지가·건축물대장·건축인허가를 우측 패널에서 조회한다. 우클릭 주소정보와 패널·동작을 분리한다. 범위 내 다필지 목록 등 2차 기능은 이번 범위에서 제외한다.

## 플로우차트

지도 → 필지분석 모드 → (도형 또는 행정경계) 분석 범위 → 필지정보 패널 → 연관정보·공시지가

## 화면설계

### MAP-PARCEL-01 필지분석 · 도형 범위

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]  [레이어][측정]…   │
│ 사 │  ┌─ 안내 ─────────────────────────────────────────────────────────────────────┐ │
│ 이 │  │ 📍 필지분석 — 분석 범위를 정한 뒤 필지를 클릭하세요.            [모드 종료] │ │
│ 드 │  └──────────────────────────────────────────────────────────────────────────────┘ │
│ 바 │  ┌─ 분석 범위 ─────────────────────────────────────────────────────────────────┐ │
│   │  │ [▶도형] [행정경계]                                                           │ │
│   │  │ [사각형] [다각형] [원]                              [범위 초기화]            │ │
│   │  └──────────────────────────────────────────────────────────────────────────────┘ │
│   │  ┌─ 지도 ──────────────────────────────────────────────────────────────────────┐ │
│   │  │              ╱────────────────╲                                              │ │
│   │  │             ╱   분석 범위      ╲                                             │ │
│   │  │            ╱    ┌─────────┐    ╲                                            │ │
│   │  │           │     │  대 123 │     │                                           │ │
│   │  │            ╲    └─────────┘    ╱                                            │ │
│   │  │             ╲──────────────────╱                                             │ │
│   │  └──────────────────────────────────────────────────────────────────────────────┘ │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 사이드바 «필지분석» 선택 시 분석 모드가 켜지고 안내·분석 범위 영역이 보인다.
2. 기본은 «도형» 탭이며 사각형·다각형·원으로 지도에 범위를 그린다.
3. 그려진 범위가 지도에 표시되고 범위 안 필지만 클릭 대상이 된다.
4. «범위 초기화»로 도형을 지우고 다시 그릴 수 있다.
5. 우클릭 «주소정보»와 별도로 동작한다.

#### 확인사항

1. 필지분석 메뉴가 선택된 상태로 보여야 한다.
2. 범위를 그리기 전 필지 클릭 시 «분석 범위를 먼저 지정하세요» 안내가 나와야 한다.
3. 측정·다른 지도 도형 기능과 동시에 켜지지 않아야 한다.
4. 범위 밖 필지 클릭 시 «분석 범위 밖입니다» 안내가 나와야 한다.

### MAP-PARCEL-02 필지분석 · 행정경계 범위

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]  [레이어][측정]…   │
│ 사 │  ┌─ 안내 ─────────────────────────────────────────────────────────────────────┐ │
│ 이 │  │ 📍 필지분석 — 분석 범위를 정한 뒤 필지를 클릭하세요.            [모드 종료] │ │
│ 드 │  └──────────────────────────────────────────────────────────────────────────────┘ │
│ 바 │  ┌─ 분석 범위 ─────────────────────────────────────────────────────────────────┐ │
│   │  │ [도형] [▶행정경계]                                                           │ │
│   │  │ [읍면동 ▼__________] [리 ▼__________] [+]                                    │ │
│   │  │ [풍산읍 ×] [와룡면 ×] …                              [범위 초기화]         │ │
│   │  └──────────────────────────────────────────────────────────────────────────────┘ │
│   │  ┌─ 지도 ──────────────────────────────────────────────────────────────────────┐ │
│   │  │   ┌──────────────────┐        ┌─────────┐                                  │ │
│   │  │   │ 선택 읍면동 경계   │        │  대 123 │                                  │ │
│   │  │   └──────────────────┘        └─────────┘                                  │ │
│   │  └──────────────────────────────────────────────────────────────────────────────┘ │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. «행정경계» 탭에서 읍면동·리를 고르고 «+»로 분석 대상 목록에 추가한다.
2. 추가 항목은 뱃지로 보이며 «×»로 개별 제거할 수 있다.
3. 선택한 행정구역 경계가 지도에 강조되고 해당 구역 안 필지만 클릭 대상이 된다.
4. 여러 읍면동·리를 한 번에 범위에 넣을 수 있다.
5. «범위 초기화»로 선택과 지도 강조를 모두 지운다.

#### 확인사항

1. 읍면동·리를 추가하지 않으면 필지 클릭 분석을 시작할 수 없어야 한다.
2. 선택만 하고 «+»를 누르지 않으면 범위에 반영되지 않아야 한다.
3. 행정경계 조회 실패 시 오류 안내가 나와야 한다.
4. 범위 밖 필지 클릭 시 «분석 범위 밖입니다» 안내가 나와야 한다.

### MAP-PARCEL-03 필지정보 조회

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]                    │
│ 사 │  ┌─ 지도 ──────────────────────┐ ┌─ 필지정보 ────────────────────────────────┐ │
│ 이 │  │  (분석 범위 + 선택 필지)    │ │ 필지정보                              [×] │ │
│ 드 │  │   ╔═══════════════╗         │ │───────────────────────────────────────────│ │
│ 바 │  │   ║ 선택 필지     ║         │ │ [지번] 경북 … 123-4                       │ │
│   │  │   ╚═══════════════╝         │ │ [도로명] …                                │ │
│   │  │                             │ │ [좌표계 ▼]  x, y                          │ │
│   │  │                             │ │───────────────────────────────────────────│ │
│   │  │                             │ │ [필지정보][건축물대장][건축인허가]         │ │
│   │  │                             │ │───────────────────────────────────────────│ │
│   │  │                             │ │ 토지기본정보                              │ │
│   │  │                             │ │  지목 / 면적 / 용도지역 / 공시지가 [조회] │ │
│   │  │                             │ │ 토지소유내역                              │ │
│   │  │                             │ │ 토지이용계획                              │ │
│   │  └─────────────────────────────┘ └───────────────────────────────────────────┘ │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 분석 범위가 정해진 상태에서 범위 안 필지를 클릭하면 선택 필지 경계가 지도에 강조된다.
2. 우측 필지정보 패널이 열린다.
3. 지번·도로명·좌표계와 토지 기본·소유·이용계획을 본다.
4. 다른 필지를 클릭하면 같은 패널에서 내용만 갱신된다.
5. 분석 범위 표시는 필지 선택 후에도 지도에 유지된다.

#### 확인사항

1. 필지를 식별하지 못하면 안내 문구를 보여 줘야 한다.
2. 외부 연동 설정이 없으면 조회 불가 안내를 보여 줘야 한다.
3. 자료를 불러오는 동안 로딩 표시가 나와야 한다.
4. 메모·민원·측정 등 다른 지도 기능 패널과 동시에 켜지지 않아야 한다.

### MAP-PARCEL-04 연관정보·공시지가

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  GGNR 지도                                                        [알림] [사용자] │
├───┬────────────────────────────────────────────────────────────────────────────────────┤
│   │  [ 🔍 주소·지번 검색________________________________________ ]                    │
│ 사 │  ┌─ 지도 ──────────┐ ┌─ 필지정보 ────────────────────────────────────────────┐ │
│ 이 │  │                 │ │ … [필지정보][▶건축물대장][건축인허가]                   │ │
│ 드 │  │                 │ │───────────────────────────────────────────────────────│ │
│ 바 │  │                 │ │ 건축물대장                                            │ │
│   │  │                 │ │ 주용도│허가일│착공│사용승인│종류│면적                    │ │
│   │  │                 │ │ ─────┼─────┼────┼───────┼───┼────                    │ │
│   │  │                 │ │  …   │ …   │ …  │  …    │ … │ …                      │ │
│   │  │                 │ └───────────────────────────────────────────────────────┘ │
│   │  │                 │   ┌─ 공시지가 이력 ─────────────────────────────────────┐   │
│   │  │                 │   │ 공시지가│공시일│기준년│기준월│…                    │   │
│   │  │                 │   └────────────────────────────────────────────────────┘   │
│   │  └─────────────────┘                                                             │
└───┴────────────────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. «건축물대장»·«건축인허가» 탭에서 해당 목록을 표로 본다.
2. «필지정보» 탭 공시지가 «조회»로 연도별 공시지가 이력 창을 연다.
3. 탭을 바꿀 때만 해당 자료를 새로 조회한다.

#### 확인사항

1. 대장·인허가 결과가 없으면 «조회 결과가 없습니다» 안내를 보여 줘야 한다.
2. 공시지가 창은 바깥 클릭이나 닫기로 닫을 수 있어야 한다.
