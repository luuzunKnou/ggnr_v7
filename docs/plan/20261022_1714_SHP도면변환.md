## 개발목표

개발자 모드 File Converter에 «SHP to DXF»를 추가한다. 전용 작업 폴더에 넣은 형상파일을 도면 파일로 바꾸고, 같은 이름이면 덮어쓴다. 좌표는 원본을 유지한다. 이번 범위는 도면만이며 캐드 전용 형식은 넣지 않는다.

## 플로우차트

```
개발자 모드 → File Converter → SHP to DXF → 작업 선택 → 변환 → 도면 폴더
```


#### 설명

1. File Converter에서 «SHP to DXF»를 고르면 전용 작업 폴더 목록이 나온다.
2. 작업명 아래 SHP 폴더에 형상파일과 짝 파일을 넣는다.
3. 변환 시작을 누르면 같은 작업의 DXF 폴더에 도면이 생긴다.
4. 이미 있는 같은 이름 도면은 덮어쓴다.
5. 좌표값은 바꾸지 않는다.

#### 확인사항

1. File Converter에 «SHP to DXF» 항목이 보여야 한다.
2. 작업 폴더가 없으면 빈 안내가 나와야 한다.
3. SHP 폴더에 형상파일이 있는 작업을 고르면 변환이 되어야 한다.
4. 변환 후 DXF 폴더에 같은 이름 도면이 있어야 한다.
5. 짝 파일(.shx, .dbf)이 없으면 해당 파일은 실패 안내가 나와야 한다.
6. 다른 변환 탭 동작은 그대로여야 한다.
