## 개발목표

사진·동영상 작업단위에 여러 파일을 올리고, 사진 위치는 5181로 저장한 뒤 상세에서 눌러 지도에 보여 준다. 폴더 생성 직후와 영상관리·승인관리에서 올릴 수 있게 한다.

## 플로우차트

승인·영상관리 → 폴더 생성 → 파일 선택 → 저장·등록 → 상세 목록 → (클릭) 지도 이동

## 화면설계

### AV-UP-01 폴더 생성 후 파일 선택

```
┌────────────────────────────────────────────────────────────┐
│ 사이드바 │ 검색        │              지도                 │
│ 영상관리 │             │                                   │
│          │ ┌─────────────────────┐                         │
│          │ │ 사진·동영상 업로드   │                         │
│          │ │ [파일 선택]          │                         │
│          │ │ 진행 n/m             │                         │
│          │ │ [닫기] [업로드]      │                         │
│          │ └─────────────────────┘                         │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 폴더 생성이 끝나면 파일 선택 창이 바로 열린다.
2. 여러 사진·동영상을 고른 뒤 업로드한다.
3. 업로드가 끝나면 목록·상세에 파일이 보인다.

#### 확인사항

1. 사진·동영상 종류에서만 이 창이 이어져야 한다.
2. 업로드 후 상세 파일 목록에 이름이 보여야 한다.
3. 좌표 있는 사진을 누르면 지도가 이동해야 한다.

### AV-UP-02 작업단위 상세 파일 추가

```
┌────────────────────────────────────────────────────────────┐
│ 사이드바 │ 목록 │ 상세              │        지도           │
│          │      │ 파일 목록 [추가]  │                       │
│          │      │ · 사진1.jpg       │                       │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 상세 «추가»로 같은 업로드 창을 연다.
2. 승인 상세의 파일 업로드도 폴더 생성 후 같은 창으로 이어진다.

#### 확인사항

1. 추가 후에도 기존 파일이 유지되어야 한다.
2. 연결 신청이 있으면 업로드 후 등록완료여야 한다.
