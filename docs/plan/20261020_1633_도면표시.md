## 개발목표

지도 왼쪽 메뉴에 «데이터 업로드»와 별도인 «도면 표시»를 추가한다. DXF(가능하면 DWG) 수치지형도를 고른 뒤 좌표계를 맞춰 본 지도에 임시로 겹쳐 본다. 서버 저장·레이어 등록은 하지 않으며, 메뉴를 닫으면 지도에서도 사라진다.

## 플로우차트

```
지도 → 도면 표시 → 파일 선택(DXF·DWG) → 좌표계·레이어 → 지도 임시 표시
```

## 화면설계

### MAP-DRAW-01 도면 표시

```
┌────┬──────────────────────────────┬──────────────────────────────┐
│메뉴│ 도면 표시                [X] │ [ 주소·지명 검색          ]  │
│    │ ─────────────────────────────│                              │
│조회│ ┌──────────────────────────┐ │                              │
│    │ │  파일을 놓거나 눌러 선택  │ │                              │
│도면│ │  DXF · DWG (수치지형도)   │ │            지도              │
│표시│ └──────────────────────────┘ │         (임시 도면)          │
│    │  파일: ○○○.dxf               │                              │
│    │  좌표계 [ 중부원점 2010  ▼]  │                              │
│    │  도면 레이어                 │                              │
│    │  ☑ 도로  ☑ 건물  ☐ 등고     │                              │
│    │  [지우기]                    │                              │
└────┴──────────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 사이드바 «도면 표시»를 누르면 왼쪽 패널이 열린다.
2. DXF는 브라우저에서 바로 읽고, DWG는 서버에서 도면 문자로 바꾼 뒤 같은 방식으로 읽는다.
3. 좌표계를 고르면 수치지형도 좌표가 지도 위치에 맞게 표시되고, 범위로 이동한다.
4. 도면 안 레이어를 켜고 끌 수 있다.
5. 패널을 닫거나 지우면 지도에서 도면이 사라진다. 서버에는 저장하지 않는다.

#### 확인사항

1. «도면 표시» 메뉴가 «데이터 업로드»와 별도로 보여야 한다.
2. DXF를 올리면 지도에 도형이 나타나고 해당 범위로 이동해야 한다.
3. 좌표계를 바꾸면 위치가 다시 맞춰져야 한다.
4. 잘못 고른 좌표계면 국내 범위 벗어남 안내가 나와야 한다.
5. 패널을 닫으면 지도에서 도면이 사라져야 한다.
6. DWG는 변환 환경이 있으면 표시되고, 없으면 안내 문구가 나와야 한다.
