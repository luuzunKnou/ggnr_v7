## 개발목표

도로행정 업무지원시스템에 «사유지분석»을 추가한다. 구역 선택에서 «실폭도로»를 고르면 화면 안 실폭도로를 하나로 합친 면이 지도에 나오고, 사용자는 도로를 가로지르는 경계선을 여러 개 찍어 닫힌 범위를 만든다.

모든 경계선에 둘러싸인 도로 면만 범위가 되며, 범위가 닫히지 않거나 선이 도로를 다 자르지 못하면 안내와 함께 적용을 막는다. 적용하면 바로 필지 분석까지 진행하고 결과 목록·상세는 하천과 같이 쓴다. 하천의 두 선·지류 방식은 그대로 둔다.

## 플로우차트

```
사이드바 사유지분석 → 구역 선택(실폭도로) → 합친 도로 면 → 경계선 여러 개 찍기 ⇄ 선 되돌리기 → 적용 → 필지 목록 → 필지 상세
```

## 화면설계

### MAP-PLA-ROAD-01 구역 선택

```
┌────┬──────────────────────────────────────────────────────────┐
│메뉴│ ┌사유지분석────────┐  ┌검색──────────────┐                 │
│    │ │분석 영역         │                                       │
│사유│ │분석 영역을 먼저  │      ┌분석 구역 선택──────────┐       │
│지분│ │지정하세요.       │      │                        │       │
│석  │ │[영역 지정][재설정]│      │   ┌──────────┐         │       │
│    │ └─────────────────┘      │   │ 실폭도로 │         │       │
│    │                          │   └──────────┘         │       │
│    │                          │               [취소]   │       │
│    │                          └────────────────────────┘       │
└────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 도로 시스템에서 사유지분석을 열면 구역 선택 창이 뜬다.
2. 구역은 «실폭도로» 하나만 보인다.
3. 고르면 창이 닫히고 지도에서 경계선을 찍는 단계로 넘어간다.

#### 확인사항

1. 도로 시스템 사이드바에 «사유지분석»이 보여야 한다.
2. 구역 선택 창에 «실폭도로»만 있어야 한다.
3. 하천 시스템의 구역 선택은 이전과 같아야 한다.

### MAP-PLA-ROAD-02 경계선 찍기

```
┌────┬──────────────────────────────────────────────────────────┐
│메뉴│ ┌사유지분석────────┐  ┌검색──────────────┐                 │
│    │ │분석 영역         │ ┌범위를 닫도록 뻗어나가는 도로마다┐ │
│사유│ │실폭도로          │ │선을 찍으세요                    │ │
│지분│ │경계선을 찍으세요 │ └─────────────────────────────────┘ │
│석  │ │[영역 변경][재설정]│ [선 되돌리기][적용][다시 지정][취소]│
│    │ └─────────────────┘                                      │
│    │        ════╪═══════════════╪════                          │
│    │            │   합친 도로 면 │                              │
│    │        ════╪═══════════════╪════                          │
└────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 화면 안 실폭도로가 하나로 합쳐진 면으로 보인다.
2. 도로 위에 마우스를 올리면 도로 폭 방향 점선이 따라오고, 찍으면 경계선이 확정된다.
3. 선이 2개 이상이면 모든 선에 둘러싸인 구간을 미리 칠해 보여 준다.
4. 범위가 닫히지 않으면 빨간 안내와 함께 적용이 꺼진다.
5. «선 되돌리기»로 마지막 선을 지운다.

#### 확인사항

1. 화면이 너무 넓으면 확대하라는 안내가 나와야 한다.
2. 교차로에서 네 방향에 선을 찍으면 교차로 구간만 칠해져야 한다.
3. 한 방향을 빠뜨리면 범위가 닫히지 않았다는 안내가 나오고 적용이 막혀야 한다.
4. 기존 선과 교차하는 선은 찍히지 않아야 한다.

### MAP-PLA-ROAD-03 분석 결과

```
┌────┬──────────────────────────────────────────────────────────┐
│메뉴│ ┌사유지분석────────┐  ┌검색──────────────┐                 │
│    │ │구역  실폭도로    │                                       │
│사유│ │면적  약 0,000㎡  │                                       │
│지분│ │[영역 변경][재설정]│                                      │
│석  │ │주소·소유구분·지목│        ┌──┐┌──┐┌──┐                  │
│    │ │개인 대 주소  ㎡  │        └──┘└──┘└──┘                  │
│    │ │국유 도 주소  ㎡  │                                       │
│    │ └─────────────────┘                                      │
└────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 적용하면 바로 필지 분석이 진행된다.
2. 결과 중에는 경계선·구간·합친 도로 면을 숨기고 필지만 보인다.
3. 목록·상세는 하천 사유지분석과 같다.

#### 확인사항

1. 적용 후 필지 목록이 나와야 한다.
2. 범위 밖 필지는 목록에 없어야 한다.
3. 영역 변경 시 합친 도로 면이 다시 보여야 한다.
