## 개발목표

지도 우측 주제도 아래에 «수치지형도»를 두고, 데이터 폴더의 축척·묶음 폴더를 레이어처럼 켠다. 켠 폴더의 도엽 중 현재 화면에 겹치는 것만 불러 기존 도면 표시와 같은 방식으로 지도에 그린다. 도엽이 수천 장인 경우를 대비해 축소 시에는 안내만 하고, 확대 후 화면 안 도엽만 표시한다.

## 플로우차트

```
지도 → 수치지형도 버튼 → 폴더 목록 → (폴더 켜기) → (확대·이동) → 화면 안 도엽 표시
```

## 화면설계

### MAP-DM-01 수치지형도 버튼

```
┌──── 지도 우측 컨트롤 ────┐
│ …                        │
│ [주제도]                 │
│ [수치지형도]  ← 추가     │
│ [기초구간]               │
│ …                        │
└──────────────────────────┘
```

#### 설명

1. 주제도 바로 아래에 «수치지형도» 버튼이 보인다.
2. 데이터 폴더가 없거나 하위 폴더가 없으면 버튼을 숨긴다.
3. 폴더를 하나라도 켠 상태면 패널을 닫아도 버튼이 켜진 표시로 남는다.

#### 확인사항

1. 주제도 다음에 수치지형도 버튼이 있어야 한다.
2. 데이터 폴더가 비어 있으면 버튼이 없어야 한다.
3. 폴더를 켠 뒤 패널을 닫아도 버튼이 켜진 상태로 보여야 한다.

### MAP-DM-02 폴더 목록 패널

```
┌─ 지도 ──────────────────────────────┐
│                                      │
│                          ┌─수치지형도─┐
│                          │ 닫기      │
│                          │ □ 폴더A   │
│                          │ ☑ 폴더B   │
│                          │ 안내 문구 │
│                          └───────────┘
└──────────────────────────────────────┘
```

#### 설명

1. 버튼을 누르면 오른쪽에 폴더 체크 목록이 열린다.
2. 폴더를 체크하면 해당 묶음이 켜지고, 해제하면 지도에서 사라진다.
3. 너무 축소된 상태면 «확대한 뒤 도엽이 표시됩니다» 안내가 보인다.
4. 도엽을 불러오는 중이면 진행 안내가 보인다.

#### 확인사항

1. 폴더 목록이 데이터 폴더의 하위 폴더와 같아야 한다.
2. 체크 시 확대된 화면에서 도엽 선·글자가 보여야 한다.
3. 체크 해제 시 해당 폴더 도엽이 지도에서 사라져야 한다.
4. 지도를 이동하면 새 화면 범위의 도엽이 갱신되어야 한다.
