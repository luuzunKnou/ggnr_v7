## 개발목표

지도 사이드바에 «접도구역 표주»를 추가해 접도구역 표주·표지 관리대장을 목록과 상세로 본다. 접도구역 건축물과 같은 자리·목업 방식이다.

목록은 도로의 종류와 노선명만 한 행에 보여 준다. 행을 누르면 그 노선의 표주 점들로 지도가 이동하고, 점 위치에 구역(점) 표시가 붙는다. 상세는 한 노선에 표주가 여러 건 달리는 구조로, 표주 목록을 표로 보여 준다.

이번 작업은 화면 목업이다. 데이터는 화면 안에 넣어 둔 샘플만 쓰고 데이터베이스·서버 저장은 하지 않는다. 새로고침하면 처음 샘플로 돌아간다.

## 플로우차트

```
지도 → 접도구역 표주 목록 → (행 클릭) → 지도 이동·점 표시 → 표주 목록 상세
```

## 화면설계

### RFM-01 접도구역 표주 목록

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ 시스템명                              주소·지번 검색 [                        ]      로그인  │
├──────┬───────────────────────────────────┬────────────────────────────────────────────────────┤
│ 배경 │ 접도구역 표주           추가 닫기 │                                                    │
│ 지도 ├───────────────────────────────────┤                                                    │
│ 지적 │ 검색 [ 노선명·소유자            ] │                                                    │
│ 도로 │ 도로종류   전체  지방도  국도  군도│                                                    │
│ 망도 ├────────────┬──────────────────────┤                    지  도                          │
│ 도로 │ 도로의 종류│ 노선명               │                    · 점 표시                       │
│ 점용 ├────────────┼──────────────────────┤                                                    │
│ 건축 │ 국도       │ 국도 31호선          │                                                    │
│ 물   │ 지방도     │ 지방도 918호선       │                                                    │
│ 표주 │ 군도       │ 군도 7호선           │                                                    │
│      ├────────────┴──────────────────────┤                                                    │
│      │ 목록 3건                          │                                                    │
└──────┴───────────────────────────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 사이드바에서 «접도구역 표주»를 선택하면 좌측에 관리대장 목록 패널이 열린다.
2. 목록은 도로의 종류와 노선명만 한 행에 보여 준다.
3. 행을 누르면 해당 노선의 표주 점들로 지도가 이동하고, 지도에 점 표시가 나타난다.
4. 검색·도로종류 단추로 목록을 걸러 볼 수 있다.
5. 목록 맨 아래에 현재 걸러진 건수를 보여 준다.

#### 확인사항

1. 사이드바에서 «접도구역 표주»가 선택된 상태로 보여야 한다.
2. 목록 열은 도로의 종류와 노선명만 있어야 한다.
3. 행을 누르면 지도가 그 노선 표주 위치로 이동해야 한다.
4. 행을 누르면 지도에 표주 점이 보여야 한다.
5. 닫기를 누르면 목록·상세와 점 표시가 함께 사라져야 한다.

### RFM-02 표주 목록 상세

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ 시스템명                              주소·지번 검색 [                        ]      로그인  │
├──────┬─────────────────┬───────────────────────────────┬──────────────────────────────────────┤
│ 배경 │ 접도구역 표주   │ 국도 31호선          수정 닫기 │                                      │
│ 지도 ├─────────────────┤ ┌───────────────────────────┐ │                                      │
│ 지적 │ 국도            │ │ 기본정보                  │ │                                      │
│ 도로 │ 국도 31호선     │ │ 도로의 종류    국도       │ │            지  도                    │
│ 망도 ├────┬────────────┤ │ 노선명         국도 31호선│ │            · 점                      │
│ 도로 │종류│ 노선명     │ ├───────────────────────────┤ │                                      │
│ 점용 ├────┼────────────┤ │ 표주 목록            추가 │ │                                      │
│ 건축 │국도│ 국도 31호선│ │ 번호 지점거리 설치위치    │ │                                      │
│ 물   │지방│ 918호선    │ │ 1    217  일월 곡강리 …  │ │                                      │
│ 표주 │군도│ 군도 7호선 │ │ 2    218  일월 도계리 …  │ │                                      │
│      │    │            │ │ 3    218  일월 섬촌리 …  │ │                                      │
│      │    │            │ └───────────────────────────┘ │                                      │
└──────┴─────────────────┴───────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 목록 행을 누르면 오른쪽에 상세가 열리고 제목에 노선명이 나온다.
2. 위쪽 기본정보는 도로의 종류와 노선명만 보여 준다.
3. 아래 표주 목록은 한 노선에 달린 표주 여러 건을 표로 보여 준다.
4. 표에는 일련번호, 지점거리, 설치위치, 토지 소유자, 표지, 비고가 나온다.
5. 표 행을 누르면 그 표주 점 위치로 지도가 이동하고 해당 점이 강조된다.
6. 수정을 누르면 기본정보를 고칠 수 있고, 표주 추가·삭제가 나타난다.

#### 확인사항

1. 목록에서 고른 노선명이 상세 제목에 나와야 한다.
2. 표주가 여러 건이면 모두 표에 행으로 나와야 한다.
3. 표 행을 누르면 그 표주 점으로 지도가 이동해야 한다.
4. 다른 노선을 고르면 상세 목록과 지도 점이 그 노선으로 바뀌어야 한다.
5. 상세 닫기를 누르면 목록만 남아야 한다.

### RFM-03 표주 입력

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ 시스템명                              주소·지번 검색 [                        ]      로그인  │
├──────┬─────────────────┬───────────────────────────────┬──────────────────────────────────────┤
│ 배경 │ 접도구역 표주   │ 국도 31호선          저장 취소 │            지  도                    │
│ 지도 ├─────────────────┤                               │                                      │
│      │  ┌──────────────────────────────────────────┐   │                                      │
│      │  │ 표주 추가                           닫기 │   │                                      │
│      │  ├──────────────────────────────────────────┤   │                                      │
│      │  │ 일련번호       [ 4        ]              │   │                                      │
│      │  │ 지점거리       [ 219      ]              │   │                                      │
│      │  │ 군·면·리       [ 영양 ][일월][곡강]      │   │                                      │
│      │  │ 지목·지번      [ 대   ][162-2]           │   │                                      │
│      │  │ 소유자 성명    [          ]              │   │                                      │
│      │  │ 소유자 주소    [          ]              │   │                                      │
│      │  │ 표지           [          ]              │   │                                      │
│      │  │ 비고           [ 상행     ]              │   │                                      │
│      │  ├──────────────────────────────────────────┤   │                                      │
│      │  │                           담기    취소   │   │                                      │
│      │  └──────────────────────────────────────────┘   │                                      │
└──────┴─────────────────────────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 수정 상태에서 표주 목록의 추가를 누르면 입력창이 열린다.
2. 일련번호·지점거리·설치위치·소유자·표지·비고를 넣는다.
3. 담기를 누르면 표 마지막에 행이 늘고, 취소를 누르면 그대로다.
4. 담은 행은 수정 상태에서 삭제할 수 있다.

#### 확인사항

1. 담기를 누르면 표 마지막에 방금 넣은 내용이 나와야 한다.
2. 일련번호를 비우고 담으면 안내가 나와야 한다.
3. 취소하거나 닫기를 누르면 표가 그대로여야 한다.
