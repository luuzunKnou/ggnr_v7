# 작업계획서

2026-11-13 | 200BingSu | 우측 고도 측정 수치지형도 병행

## 개발목표

지도 우측 «고도»에서 기존 등고 고도는 그대로 두고, 슈퍼유저이면서 수치지형도 자료 폴더가 있을 때만 아래에 «수치지형도 고도»를 한 줄 더 보여 준다. 수치지형도 값은 도엽 도면의 등고 표고로 기존 고도와 같은 방식으로 보간한다. 축척 폴더는 하위 폴더명에서 숫자를 뽑아 가장 작은 숫자 폴더만 쓴다.

## 플로우차트

```
고도 모드 → 점 조회 → 등고 고도 → (슈퍼·자료있음) → 수치지형도 고도 → 두 줄 안내
```

## 화면설계

### MAP-ALT-DM-01 고도 미리보기·확정 (슈퍼·자료 있음)

```
┌──────┬────────────────────────────────────────────┐
│메뉴  │                                            │
│      │              지도                          │
│      │                     ┌──────────────────┐   │
│      │                     │고도 : 123.4 m    │   │
│      │                     │수치지형도 고도 : │   │
│      │                     │125.0 m           │   │
│      │                     └──────────────────┘   │
│      │                         ●                  │
├──────┤  주제도  수치지형도  고도 …                │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. «고도»를 켠 뒤 커서를 옮기면 미리보기에 등고 고도가 나온다.
2. 슈퍼유저이고 수치지형도 자료가 있으면 그 아래에 수치지형도 고도가 한 줄 더 나온다.
3. 좌클릭으로 확정해도 같은 두 줄 형식이 유지된다.
4. 일반 사용자이거나 수치지형도 자료가 없으면 기존처럼 한 줄만 보인다.

#### 확인사항

1. 슈퍼유저·자료 있을 때 미리보기·확정 모두 두 줄이어야 한다.
2. 일반 사용자는 «수치지형도 고도» 줄이 없어야 한다.
3. 수치지형도 값을 못 구하면 첫 줄만 나와야 한다.

### MAP-ALT-DM-02 고도 미리보기 (일반·또는 자료 없음)

```
┌──────┬────────────────────────────────────────────┐
│메뉴  │                                            │
│      │              지도                          │
│      │                     ┌──────────────────┐   │
│      │                     │고도 : 123.4 m    │   │
│      │                     └──────────────────┘   │
│      │                         ●                  │
├──────┤  주제도  고도 …                            │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 기존과 같이 «고도 : … m» 한 줄만 표시한다.
2. 시군구 밖·등고 없음 안내는 기존과 같다.

#### 확인사항

1. 한 줄 표시와 오류 안내가 이전과 같아야 한다.
2. 수치지형도 줄이 붙지 않아야 한다.
