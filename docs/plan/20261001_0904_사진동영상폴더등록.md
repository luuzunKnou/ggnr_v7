## 개발목표

사진·동영상 자료 폴더에 작업 폴더를 넣고 파일을 담으면, 서버가 약 1분 간격으로 읽어 작업과 파일로 등록한다. 폴더 이름이 작업 이름이다. 같은 크기·수정 시각이 한 차례 더 확인된 파일만 등록해, 복사 중인 파일은 빠진다. 이미 등록된 파일은 건너뛴다. 드론영상·항공뷰·항공영상 폴더는 읽지 않는다.

## 플로우차트

자료 폴더 → 작업 폴더에 파일 → (크기 확인) → 사진,동영상 목록

## 화면설계

### UAV-DRONE-FOLDER-01 사진·동영상 폴더

```
┌──────────────────────────────────────┐
│ 사진,동영상 자료                       │
│                                      │
│  ┌ 울산동구_2026봄                   │
│  │   전경1.jpg                       │
│  │   전경2.jpg                       │
│  │   현장.mp4                        │
│  └                                  │
│                                      │
│  ┌ 하천점검                          │
│  │   하류.jpg                        │
│  └                                  │
└──────────────────────────────────────┘
```

#### 설명

1. 사진·동영상 자료 안에 작업마다 폴더를 하나 만든다.
2. 폴더 이름이 목록에 보일 작업 이름이다.
3. 사진과 동영상은 그 폴더 바로 안에 넣는다.
4. 폴더 안의 또 다른 폴더는 읽지 않는다.

#### 확인사항

1. 폴더를 넣은 뒤 약 1~2분이 지나면 사진,동영상 목록에 그 이름이 나와야 한다.
2. 복사 중인 파일은 바로 목록에 나오면 안 된다.
3. 이미 목록에 있는 파일은 중복으로 늘면 안 된다.

### UAV-DRONE-FOLDER-02 사진,동영상 목록

```
┌────────────┬───────────────────────────────┐
│            │ 사진,동영상                    │
│            │ ─────────────────────────────│
│   지도     │ 울산동구_2026봄          3   │
│            │ 하천점검                 1   │
│            │                               │
└────────────┴───────────────────────────────┘
```

#### 설명

1. 등록이 끝나면 오른쪽 사진,동영상 목록에 작업이 보인다.
2. 위치 정보가 있는 사진은 지도 점으로 쓸 수 있다.
3. 위치가 없는 사진·동영상은 기존처럼 위치를 나중에 넣을 수 있다.

#### 확인사항

1. 화면에서 직접 올린 작업과 같은 목록에 보여야 한다.
2. 같은 폴더에 파일을 더 넣으면 그 작업의 파일 수만 늘어야 한다.
3. 드론영상 목록에는 이 폴더가 나오면 안 된다.
