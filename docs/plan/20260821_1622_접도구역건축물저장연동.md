## 개발목표

접도구역 건축물 목록·상세를 샘플이 아니라 저장소에 붙인다. 등록·수정·삭제 후 새로고침해도 같은 대장이 남아야 한다. 위치도·건축물·종전·변경 그림은 대장 번호 아래 폴더에 종류당 한 장으로 두고, 기존 첨부 불러오기와 같게 한다. 상세 칸 배치는 바꾸지 않는다.

## 플로우차트

```
목록 → 상세 → (등록·저장) → 저장소 → 목록 · 도면 폴더
```

## 화면설계

### RFB-CRUD-01 목록

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ 시스템명                              주소·지번 검색 [                        ]      로그인  │
├──────┬───────────────────────────────────┬────────────────────────────────────────────────────┤
│ 배경 │ 접도구역 건축물         추가 닫기 │                                                    │
│ 지도 ├───────────────────────────────────┤                                                    │
│ 지적 │ 검색 [                          ] │                    지  도                          │
│ 도로 ├────────┬─────────┬────────┬───────┤                                                    │
│ 망도 │도로종류│ 위치    │노선번호│작성일 │                                                    │
│      ├────────┼─────────┼────────┼───────┤                                                    │
│      │        │         │        │       │                                                    │
└──────┴────────┴─────────┴────────┴───────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 목록은 저장소에서 읽어 온다.
2. 검색어를 넣으면 저장소에서 걸러 보여 준다.
3. 행을 누르면 상세가 열리고, 좌표가 있으면 지도가 그곳으로 이동한다.
4. 샘플 목록은 보이지 않는다.

#### 확인사항

1. 새로고침 후 저장한 대장이 목록에 남아야 한다.
2. 대장이 없으면 목록이 비어 있어야 한다.
3. 검색어를 지우면 전체 목록이 다시 나와야 한다.

### RFB-CRUD-02 상세

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ 시스템명                              주소·지번 검색 [                        ]      로그인  │
├──────┬─────────────────┬───────────────────────────────┬──────────────────────────────────────┤
│ 배경 │ 접도구역 건축물 │ 위치               저장 닫기  │                                      │
│ 지도 ├─────────────────┤ 관리대장 서식                 │            지  도                    │
│      │ 목록            │ 위치도·건축물·종전·변경       │                                      │
└──────┴─────────────────┴───────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 상세는 저장소에서 한 장을 읽어 보여 준다.
2. 저장하면 본문·건축물 내용·확인 결과가 함께 저장된다.
3. 위치도·건축물·종전·변경은 대장 번호 폴더에 종류당 한 장만 둔다.
4. 삭제는 목록에서 빠지고 상세가 닫힌다.
5. 상세 칸 배치는 그대로 둔다.

#### 확인사항

1. 저장 후 다시 열어도 같은 내용이 보여야 한다.
2. 위치도·건축물·종전·변경은 각각 한 장만 보여야 한다.
3. 등록 직후 목록에 새 행이 나와야 한다.
4. 삭제한 대장은 목록에 없어야 한다.
5. 상세 서식 칸 배치는 이전과 같아야 한다.
