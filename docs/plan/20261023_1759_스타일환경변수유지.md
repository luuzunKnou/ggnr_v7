## 개발목표

SLD 스타일은 화면의 색·선·두께만 고치고, 필터와 화살표 설정은 그대로 둔다. 선 색은 화살표가 같은 환경변수를 쓰면 그 기본값도 같이 바뀐다. 제목이 레이어명과 같은 규칙의 값을 화면에 보여 준다.

## 플로우차트

스타일 수정 → (색 저장) → 환경변수 기본값만 변경 → 스타일 수정

## 화면설계

### DEV-STYLE-03 SLD 색 수정

```
┌──────────────────────────────────────────────┐
│ 스타일 수정: 레이어이름                    X │
├──────────────────────────────────────────────┤
│ 관리자 화면에서 스타일 직접 수정 →  [SLD|CSS]│
│ 선 색을 바꾸면 화살표 색도 같이 바뀝니다.    │
│ 선 색상  [          ]                        │
│ 선 두께  [          ]                        │
│                          [취소]  [저장]      │
└──────────────────────────────────────────────┘
```

#### 설명

1. 제목이 레이어명과 같은 규칙에 환경변수가 있으면 색·선 항목이 열린다.
2. 저장하면 그 환경변수의 기본값만 바뀌고 필터와 화살표 모양은 남는다.
3. 선 색 환경변수는 화살표 규칙에 있어도 같은 값으로 바뀐다.

#### 확인사항

1. 선 색을 저장하면 화살표 색의 기본값도 같아야 한다.
2. 필터와 화살표 따라가기 설정은 그대로여야 한다.
3. 환경변수가 없는 SLD는 색 항목이 열리지 않아야 한다.
