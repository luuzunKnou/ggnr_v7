## 개발목표

점사용료 목록에 점용대장 «점용장소 도형»과 같은 단추를 둔다. 누르면 물건지주소로 지적 필지를 찾아 도형을 넣는다. 이미 있는 도형 채우기 처리를 그대로 쓰고, 새 적재 방식은 만들지 않는다.

## 플로우차트

```
점사용료 목록 → 물건지 도형 → 확인 → 물건지주소로 지적 채움 → 지도 갱신
```

## 화면설계

### FEE-LIST-01 점사용료 목록 도형 단추

```
┌──────────────────────────────────────────────────────────┐
│ 하천점사용료          [점용대장][물건지 도형][닫기]       │
│──────────────────────────────────────────────────────────│
│ 검색…                              [전체][미납][수납]     │
│ [전체] [부서…]                                            │
│──────────────────────────────────────────────────────────│
│ 상태 | 대장번호 | 부서명 | 납부자 | 납부금액 | 납기일     │
│ …                                                        │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 목록 제목 옆에 «물건지 도형»을 둔다.
2. 누르면 확인 후 지금 열린 점사용료 표만 채운다.
3. 물건지주소의 지번으로 지적을 찾고, 없는 건·이미 도형이 있는 건은 건너뛴다.
4. 끝나면 건수 안내를 목록 위에 보이고 지도를 다시 그린다.

#### 확인사항

1. 점사용료 목록에 «물건지 도형»이 보여야 한다.
2. 확인을 취소하면 도형이 바뀌지 않아야 한다.
3. 실행 후 넣음·건너뜀 건수가 안내되어야 한다.
4. 하천·도로·국공유지 점사용료는 열린 목록 표만 채워야 한다.
