## 개발목표

개발자 도구 데이터관리에 «레이어비교»를 둔다. 기준은 DB 레이어에서 고르고, 대조는 다른 DB 레이어이거나 첨부 파일(임시 적재)이다. 구조·공간·속성 순으로 대조한 뒤 요약·목록·엑셀 내보내기만 제공하고, DB·레이어 반영은 하지 않는다. 첨부 임시 테이블은 비교 종료 시 정리한다. 미니맵은 1차에서 넣지 않는다.

## 플로우차트

```
개발자도구 → 레이어비교 → 기준·대조 선택 → 구조·컬럼매핑 → (키·공간 짝) → 속성비교 → 결과·내보내기
```

## 화면설계

### DEV-CMP-01 레이어비교 시작

```
┌────────사이드────────┬────────────────────────────────────────────┐
│ 데이터관리           │  레이어비교                                 │
│  · 레이어 관리       │                                             │
│  · 레이어비교  ◀     │  기준 레이어 (DB)                           │
│  · …                 │  [ 레이어 검색·선택 ____________________ ]  │
│                      │                                             │
│                      │  대조 대상                                  │
│                      │  ○ 다른 레이어(DB)  ○ 파일 첨부             │
│                      │  [ 레이어 선택 / 파일 선택 _____________ ]  │
│                      │                                             │
│                      │              [다음: 구조 비교]              │
└──────────────────────┴────────────────────────────────────────────┘
```

#### 설명

1. 데이터관리 그룹에 «레이어비교» 메뉴가 있다.
2. 기준은 기존 DB 레이어만 고른다.
3. 대조는 다른 DB 레이어 또는 파일 첨부 중 하나다. 파일↔파일은 없다.
4. 파일을 고르면 임시로만 올리고 정의·지도서비스·목록에는 남기지 않는다.

#### 확인사항

1. «레이어비교» 메뉴가 데이터관리에 보여야 한다.
2. 기준을 고르지 않으면 다음으로 넘어가지 않아야 한다.
3. 대조가 기준과 같은 레이어이면 진행되지 않거나 안내가 나와야 한다.
4. 첨부 후 레이어 관리 목록에 새 항목이 생기지 않아야 한다.

### DEV-CMP-02 구조·컬럼 매핑

```
┌────────사이드────────┬────────────────────────────────────────────┐
│ 데이터관리           │  레이어비교 · 1단계 구조                    │
│  · 레이어비교  ◀     │                                             │
│                      │  기준 건수 · 도형 · 좌표계                   │
│                      │  대조 건수 · 도형 · 좌표계                   │
│                      │                                             │
│                      │  컬럼 매핑                                  │
│                      │  상태 · 기준칸 · 대조칸 · 한글 · 타입       │
│                      │  자동 · …                                   │
│                      │  후보 · …  [확정] [제외]                    │
│                      │  미매칭 · …                                 │
│                      │  타입불일치 · …                             │
│                      │                                             │
│                      │  짝 짓기 키                                 │
│                      │  기준 키 [선택]  대조 키 [선택]  (선택사항) │
│                      │                                             │
│                      │     [이전]  [다음: 공간·속성 비교]          │
└──────────────────────┴────────────────────────────────────────────┘
```

#### 설명

1. 양측 건수·도형 종류·좌표계를 보여 준다. 도형이 없으면 «도형 없음»으로 표시한다.
2. 컬럼은 영문 동일은 자동, 영문 다르고 한글 동일은 후보(확정·제외), 둘 다 다르면 매칭하지 않는다. 한글만 있으면 한글 동일만 매칭한다.
3. 이름은 맞고 타입만 다르면 매칭 상태로 두고 타입 불일치로 표시한다.
4. 짝 짓기용 키 칸은 비교 시 사용자가 양측에서 각각 고른다. 고르지 않으면 키 없이 진행한다.

#### 확인사항

1. 영문이 같은 칸은 자동 매칭으로 보여야 한다.
2. 한글만 같고 영문이 다른 칸은 후보로 나오고 확정 후에만 다음 단계에 쓰여야 한다.
3. 타입만 다른 칸은 타입 불일치로 구분되어야 한다.
4. 키를 고르지 않아도 다음 단계로 갈 수 있어야 한다.

### DEV-CMP-03 공간·속성 결과

```
┌────────사이드────────┬────────────────────────────────────────────┐
│ 데이터관리           │  레이어비교 · 결과                          │
│  · 레이어비교  ◀     │                                             │
│                      │  [요약] 기준 N · 대조 M                     │
│                      │        일치 · 기준만 · 대조만 · 속성불일치  │
│                      │                                             │
│                      │  [공간] 일치 a · 기준만 b · 대조만 c        │
│                      │         (다중 매칭 d)                       │
│                      │                                             │
│                      │  [속성] 컬럼별 불일치 건수                  │
│                      │         샘플 목록 (다른 칸만 강조)          │
│                      │                                             │
│                      │  [코드값] 기준만 있는 값 · 대조만 있는 값   │
│                      │                                             │
│                      │  [엑셀 내보내기] [CSV]  [다시 비교] [닫기]  │
└──────────────────────┴────────────────────────────────────────────┘
```

#### 설명

1. 키가 있으면 키로 먼저 짝을 맺고, 없으면 기준 레이어 도형 종류에 따른 위치 짝을 쓴다.
2. 점·선·면은 기준 레이어 도형에 맞춘 기본 허용값으로 짝을 맺는다. 정합성의 격자 스냅은 쓰지 않는다.
3. 도형이 없고 키도 없으면 공간 짝을 만들지 않고 안내한다. 키만 있으면 키 짝으로 속성 비교한다.
4. 짝이 난 행만 매핑 컬럼 값을 비교하고, 코드·목록은 값 집합 비교만 한다.
5. 미니맵은 넣지 않는다. 반영 버튼은 없다. 닫거나 끝나면 임시 테이블을 정리한다.

#### 확인사항

1. 키를 고른 경우 같은 키끼리 짝이 나고 일치·기준만·대조만 숫자가 맞아야 한다.
2. 키 없이 점 레이어면 거리 기본값으로 위치 짝이 나야 한다.
3. 키 없이 면 레이어면 겹침비 기본값으로 위치 짝이 나야 한다.
4. 도형 없는 첨부(표)는 공간 요약 대신 키·속성 중심으로 결과가 나와야 한다.
5. 속성 불일치 목록에서 다른 칸만 강조되어야 한다.
6. 엑셀 또는 CSV를 받을 수 있어야 한다.
7. 비교를 끝낸 뒤 임시 테이블이 남지 않아야 한다.
8. 반영·저장 버튼이 없어야 한다.
