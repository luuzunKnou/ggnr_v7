## 개발목표

하천 시스템 사이드바에 «불법점용시설 관리카드» 메뉴를 추가한다. 목록에서 카드를 고르면 원본 관리카드와 같은 칸 배치의 카드형 상세가 열리고, 같은 카드 안에서 추가·수정·삭제한다. 조치현황은 시설 종류 10가지마다 적발·조치·미조치 건수를 칸으로 나눠 입력한다.

여러 줄 항목은 «@»로 나눈 자료를 화면에서 줄바꿈으로 보이고, 입력한 줄바꿈은 저장 시 «@»로 합친다. 이번에는 시제품으로 예시 카드 1건만 넣고 화면 안에서만 반영하며, 자료 항목 영문 이름은 임시로 정해 한 곳에 모아 둔다.

영향 받는 기능: 지도 레이아웃의 패널 폭 합산·패널 위치(맨 끝에 추가하므로 기존 패널 위치는 바뀌지 않음), 하천 시스템 메뉴 목록.

## 플로우차트

```
지도 → 불법점용시설 관리카드 → 카드 목록 → (행 클릭) → 카드 상세 ⇄ 카드 수정 → 카드 목록
```

## 화면설계

### RIVER-ILLEGAL-01 카드 목록

```
┌────┬──────────────────────────┬──────────────────────────────────────────┐
│메뉴│ 불법점용시설 관리카드 추가 ✕│                                          │
│    ├──────────────────────────┤                                          │
│하천│ [검색 (연번, 위치, 행위자)] │                                          │
│    ├──────────────────────────┤                   지도                    │
│    │ 연번       위치    최초확인 │                                          │
│    │ 울진군 재말천-1 북면 26.3.13│                                          │
│    │                          │                                          │
│    ├──────────────────────────┤                                          │
│    │ 1건                       │                                          │
└────┴──────────────────────────┴──────────────────────────────────────────┘
```

#### 설명

1. 사이드바 «불법점용시설 관리카드»를 누르면 카드 목록이 열린다.
2. 목록에는 연번·위치·최초확인일자가 한 행에 보이고 아래에 건수가 보인다.
3. 검색어로 연번·위치·행위자를 찾는다.
4. «추가»를 누르면 빈 카드가 등록 상태로 열린다.

#### 확인사항

1. 하천 시스템에서 메뉴가 보여야 한다.
2. 예시 카드 1건이 목록에 나와야 한다.
3. 검색어와 맞지 않는 카드는 목록에서 빠져야 한다.

#### 설명

1. 목록에서 카드를 고르면 원본 관리카드와 같은 칸 배치로 상세가 열린다.
2. 조치현황은 시설 종류 10가지를 가로 칸으로, 적발·조치·미조치를 세로 행으로 나눈 표다.
3. 위법내용·관련법·조치내용·조치계획·관리책임자·행위자는 줄마다 앞에 표시를 붙여 여러 줄로 보인다.
4. 사진 4칸은 저장된 주소의 그림을 보이고, 그림이 없으면 빈 칸으로 둔다.

#### 확인사항

1. 예시 카드의 관리책임자가 두 줄로 나와야 한다.
2. 조치현황의 평상 등·방갈로 적발 칸 등 입력된 숫자가 맞는 칸에 보여야 한다.
3. 사진이 없는 칸은 «사진 없음»으로 보여야 한다.

### RIVER-ILLEGAL-03 카드 추가·수정

```
┌────┬──────────────────┬──────────────────────────────────────────────────┐
│메뉴│ 목록              │ 불법점용시설 관리카드 등록          취소 등록 ✕  │
│    │                  ├──────────────────────────────────────────────────┤
│    │                  │ ┌──────┬──────────┬────────┬──────────┐          │
│    │                  │ │연번  │[       ] │하천구분│[       ] │          │
│    │                  │ │최초확인│[날짜]  │완료(예정)│[날짜]  │          │
│    │                  │ │위치  │[       ] │재발여부│[선택]    │          │
│    │                  │ │조치  │구분 평상 그늘막 … 기타        │          │
│    │                  │ │현황  │적발 [ ] [ ]  …  [ ]          │          │
│    │                  │ │위법내용│[여러 줄 입력             ]│          │
│    │                  │ │관리책임자│[여러 줄 입력           ]│          │
│    │                  │ │ 위치도 주소 [              ]         │          │
│    │                  │ └────────────┴─────────────┘            │          │
└────┴──────────────────┴──────────────────────────────────────────────────┘
```

#### 설명

1. 수정 또는 추가를 누르면 같은 카드 칸 안이 입력칸으로 바뀐다.
2. 여러 줄 항목은 줄을 바꿔 입력하고, 저장하면 줄 사이가 «@»로 합쳐진다.
3. 조치현황 칸에는 숫자만 입력한다.
4. 사진 칸 아래에 그림 주소를 입력하면 바로 그림이 보인다.

#### 확인사항

1. 두 줄로 입력한 관리책임자가 저장 후에도 두 줄로 보여야 한다.
2. 연번 없이 등록하면 «연번을 입력하세요» 안내가 나와야 한다.
3. 취소하면 수정 전 내용으로 돌아가야 한다.
4. 삭제하면 확인 후 목록에서 빠져야 한다.
