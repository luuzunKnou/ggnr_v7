## 개발목표

도로대장 «도로영상»을 지도 칸을 덮는 화면에서, 지도 위에 뜨는 이동·크기 조절 가능한 창으로 바꾼다. 영상 재생 위치는 노선 선 위 위치로 바꿔 지도에 진행 방향을 가리키는 자동차 모양으로 보이고, 지도에서 자동차를 끌거나 노선을 누르면 영상이 그 위치로 옮겨 간다.

영상에 위치 기록이 없으므로, 영상 처음~끝을 노선 시작~끝(하행은 반대)에 시간 비율로 나누고, 담당자가 기준점을 넣어 어긋난 구간을 맞춘다. 기준점은 영상과 같은 첨부 폴더에 영상별 작은 파일로 저장해 다음에도 쓴다.

영향 받는 기능: 도로대장 상세(보고서·도면 버튼), 도로대장 영상 재생기, 지도 그리기·측정과의 동시 사용, 첨부 파일 올리기·내려받기.

## 플로우차트

```
도로대장 상세 → 도로영상 창 ⇄ 지도 자동차 → (기준점 추가) → 위치 맞춤 저장
```

## 화면설계

### ROAD-VIDEO-01 도로영상 창

```
┌────┬──────────────────┬──────────────────────────────────────────────────┐
│메뉴│ 도로대장 상세     │  ┌ 군도12호선 도로영상  상행 하행   ─  ✕ ┐       │
│    │                  │  │                                    │        │
│    │ 보고서 도면 ...   │  │          360° 영상                 │   ━━━━━│━━
│    │ 도로영상          │  │                                    │     🚗 │
│    │                  │  │ ▶  02:31 / 10:12  ━━━━●━━━━━━      │        │
│    │                  │  │ 지도 따라가기 ☑   기준점 추가 (3)   │        │
│    │                  │  └────────────────────────────────────┘        │
│    │                  │                      지도                       │
└────┴──────────────────┴──────────────────────────────────────────────────┘
```

#### 설명

1. 도로대장 상세의 «도로영상»을 누르면 지도 위에 영상 창이 뜨고 지도는 그대로 보인다.
2. 창은 제목줄을 끌어 옮기고 모서리를 끌어 크기를 바꾸며, 접기와 닫기가 있다.
3. 창 위쪽에서 상행·하행을 바꾸고, 아래에 재생·탐색 막대와 «지도 따라가기», «기준점 추가»가 있다.
4. 영상은 지금과 같은 360° 재생기로 끌어서 둘러본다.

#### 확인사항

1. 영상 창이 떠 있어도 지도를 움직이고 확대할 수 있어야 한다.
2. 창을 옮기고 크기를 바꿔도 영상이 끊기지 않아야 한다.
3. 상행·하행을 바꾸면 그 영상 처음부터 재생할 준비가 되어야 한다.

### ROAD-VIDEO-02 지도 자동차 위치

```
┌────┬──────────────────┬──────────────────────────────────────────────────┐
│메뉴│ 도로대장 상세     │                                                  │
│    │                  │      ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━          │
│    │                  │        지나온 길 ━━━━━━━ 🚗▶ ─ ─ ─ ─ ─ ─           │
│    │                  │                     ◆ 기준점                     │
│    │                  │                                                  │
│    │                  │  ┌ 도로영상 ─────────────── ✕ ┐                  │
│    │                  │  │ ▶  05:10 / 10:12          │                  │
│    │                  │  └───────────────────────────┘                  │
└────┴──────────────────┴──────────────────────────────────────────────────┘
```

#### 설명

1. 영상이 재생되는 동안 지도에 자동차 모양이 노선 선 위를 따라 움직이고 진행 방향으로 돌아간다.
2. 자동차 앞에는 영상에서 보고 있는 방향을 부채꼴로 함께 보인다.
3. 지나온 길과 기준점 위치를 노선 위에 표시한다.
4. «지도 따라가기»를 켜면 자동차가 화면 밖으로 나갈 때 지도가 따라 움직인다.

#### 확인사항

1. 재생 중 자동차가 노선 선을 벗어나지 않아야 한다.
2. 하행 영상에서는 자동차가 노선 끝에서 시작으로 움직여야 한다.
3. 영상을 멈추면 자동차도 멈춰야 한다.

### ROAD-VIDEO-03 지도에서 영상 위치 옮기기

```
┌────┬──────────────────┬──────────────────────────────────────────────────┐
│메뉴│ 도로대장 상세     │                                                  │
│    │                  │      ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━          │
│    │                  │                 🚗 ← 끌어 놓기                    │
│    │                  │                              ✚ 누른 곳            │
│    │                  │  ┌ 도로영상 ─────────────── ✕ ┐                  │
│    │                  │  │ ▶  07:45 / 10:12          │                  │
│    │                  │  └───────────────────────────┘                  │
└────┴──────────────────┴──────────────────────────────────────────────────┘
```

#### 설명

1. 자동차를 끌어 노선 위 다른 곳에 놓으면 영상이 그 위치 시각으로 옮겨 간다.
2. 노선 선 가까이를 누르면 가장 가까운 노선 위 지점의 영상 시각으로 옮겨 간다.
3. 끄는 동안에는 자동차만 움직이고, 놓을 때 영상을 한 번 옮긴다.

#### 확인사항

1. 노선에서 먼 곳에 놓으면 가장 가까운 노선 위 지점으로 붙어야 한다.
2. 영상을 옮긴 뒤 재생하면 자동차가 그 자리부터 움직여야 한다.
3. 측정·공간검색 같은 지도 그리기와 동시에 켜지지 않아야 한다.

### ROAD-VIDEO-04 기준점 맞춤

```
┌────┬──────────────────┬──────────────────────────────────────────────────┐
│메뉴│ 도로대장 상세     │   지도에서 이 장면의 위치를 눌러 주세요  취소    │
│    │                  │      ━━━━━━━━━━━━━━◆━━━━━━━◆━━━━━━━━━━━          │
│    │                  │                                                  │
│    │                  │  ┌ 도로영상 ──────────────────────── ✕ ┐         │
│    │                  │  │ ⏸  03:20 / 10:12                    │         │
│    │                  │  │ 기준점  01:05 교차로    삭제        │         │
│    │                  │  │         03:20 다리 앞   삭제        │         │
│    │                  │  │                     저장            │         │
│    │                  │  └─────────────────────────────────────┘         │
└────┴──────────────────┴──────────────────────────────────────────────────┘
```

#### 설명

1. 영상을 알아보기 쉬운 장면에서 멈추고 «기준점 추가»를 누른 뒤 지도에서 그 위치를 누르면 기준점이 생긴다.
2. 기준점 사이는 시간 비율로 다시 나누어 자동차 위치가 더 정확해진다.
3. 기준점 목록에서 시각을 누르면 그 장면으로 가고, 삭제할 수 있다.
4. «저장»하면 영상과 같은 첨부 폴더에 기준점이 저장되어 다음에 열 때도 쓴다.

#### 확인사항

1. 기준점을 넣은 장면에서 자동차가 기준점 위치에 있어야 한다.
2. 시각 순서와 노선 위 순서가 거꾸로인 기준점은 넣을 수 없다는 안내가 나와야 한다.
3. 저장 후 창을 닫았다 다시 열어도 기준점이 남아 있어야 한다.
