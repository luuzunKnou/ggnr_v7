## 개발목표

통합 도로 선·노선번호 점 자료가 있는 프로젝트에서는 도로망도가 통합 자료 두 개만 사용한다. 등급은 기존 도로종류 탭에 묶고, 철도는 새 탭으로 보인다. 개설여부는 선 종류로 판단한다.

지도에서는 도로 선을 라벨 없이 그리고, 노선번호 점 위치에 등급별 도로 표지판 모양으로 번호를 보인다. 통합 자료가 없으면 기존 동작을 그대로 유지한다.

영향 받는 기능: 도로망도 목록·상세·지도 클릭, 접도구역 건축물·표주 목록의 «도로망도» 켜기 버튼, 공통 지도 레이어 조건 필터(하천기본계획·물놀이 표지판과 같은 방식으로 병합).

## 플로우차트

```
지도 → 도로망도 → (통합 자료 확인) → 등급 탭·개설 필터 → 목록 ⇄ 상세 → 지도 선·표지
```

## 화면설계

### MAP-ROADNET-01 통합 도로망도 목록

```
┌────┬──────────────────────┬──────────────────────────────────────────────┐
│메뉴│ 도로망도   엑셀 + 추가 ✕│                                              │
│    ├──────────────────────┤        ━━━━━━━━[ 7 ]━━━━━━━━━━━━             │
│도로│ 통합검색│도형검색│행정경계│                ┃                              │
│망도│ [검색어      ] 전체 개설 미개설              ┃       ┌───┐                 │
│    │ 전체 국도 지방도 군도 농도 철도 [69]━━━━━━━━│920│━━━━━━━          │
│    ├──────────────────────┤                ┃       └───┘                 │
│    │ [국도] 고속도로 1     │                ┃                              │
│    │ [국도] 국도 7         │      ┄┄┄┄┄┄⬡12⬡┄┄┄┄┄┄                       │
│    │ [지방도] 지방도 920    │                                              │
│    │ [군도] 시군도 12 미개설│                                              │
│    │ [농도] 리도 307       │                                              │
│    │ [철도] 철도           │                                              │
│    └──────────────────────┘                                              │
└────┴──────────────────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 통합 자료가 있으면 목록은 통합 도로 선만으로 구성된다.
2. 등급 탭은 전체·국도·지방도·군도·농도·철도 중 자료가 있는 것만 보인다.
3. 목록 행에는 묶음 종류 뱃지와 원래 등급·번호가 함께 보인다.
4. 탭·개설 필터를 바꾸면 지도의 선과 표지도 같은 조건으로 걸러진다.

#### 확인사항

1. 자료가 없는 일반도로·임도 탭은 보이지 않아야 한다.
2. 국도 탭에 고속도로와 국도가 함께 나와야 한다.
3. 철도 탭을 고르면 철도 선만 보이고 표지는 나오지 않아야 한다.
4. 미개설 필터에서 파선·점선 노선만 나와야 한다.

### MAP-ROADNET-02 노선번호 표지

```
┌────┬──────────────────────────────────────────────────────────────────┐
│메뉴│                                                                  │
│    │     ┌───┐            ╭───╮           ┌────┐         ⬡────⬡       │
│    │ ━━━━│ 1 │━━━━   ━━━━│ 7 │━━━━   ━━━━│920 │━━━━  ━━━│ 12 │━━━    │
│    │     └───┘            ╰───╯           └────┘         ⬡────⬡       │
│    │    고속도로            국도             지방도           시군도       │
│    │                                                                  │
│    │      ┌───┐                                                       │
│    │ ┄┄┄┄┄│307│┄┄┄┄┄                                                  │
│    │      └───┘                                                       │
│    │     면리농도                                                      │
└────┴──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 고속도로는 위 빨강·아래 파랑 네모 안에 흰 번호로 보인다.
2. 국도는 파란 원 안에 흰 번호로 보인다.
3. 지방도·국가지원지방도는 노란 네모 안에 검은 번호로 보인다.
4. 시군도는 파란 테두리 흰 육각형 안에 파란 번호로 보인다.
5. 면·리·농도는 회색 테두리 흰 네모 안에 검은 번호로 작게 보인다.

#### 확인사항

1. 도로 선에는 라벨이 붙지 않아야 한다.
2. 표지는 도로 선보다 위에 그려져야 한다.
3. 번호 자릿수가 늘어도 표지 안에 번호가 들어가야 한다.

### MAP-ROADNET-03 통합 도로망도 상세

```
┌────┬──────────────────────┬──────────────────────┬───────────────────────┐
│메뉴│ 도로망도 목록          │ [국도] 고속도로 1    ✕ │                       │
│    │                      ├──────────────────────┤                       │
│    │                      │ 도로등급   [고속도로 ▼]│                       │
│    │                      │ 도로번호   [1        ]│                       │
│    │                      │ 개설여부   [개설   ▼]  │                       │
│    │                      │ 읍면동     [진량읍    ]│                       │
│    │                      │        수정  저장  삭제 │                       │
│    │                      ├──────────────────────┤                       │
│    │                      │ 유지보수 민원 첨부 이력 │                       │
│    └──────────────────────┴──────────────────────┴───────────────────────┘
```

#### 설명

1. 통합 자료 행은 도로등급·도로번호·개설여부·읍면동을 보여 준다.
2. 도로등급을 바꾸면 묶음 종류가 함께 바뀐다.
3. 저장·삭제·노선 도형 편집은 통합 도로 선에 반영된다.

#### 확인사항

1. 등급을 리도로 바꾸고 미개설로 저장하면 지도에 파선으로 보여야 한다.
2. 지도에서 통합 도로 선을 클릭하면 해당 행 상세가 열려야 한다.
3. 통합 자료가 없는 프로젝트의 상세 화면은 기존과 같아야 한다.
