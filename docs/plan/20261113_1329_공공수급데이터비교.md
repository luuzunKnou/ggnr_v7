## 개발목표

데이터관리에 «공공·수급 비교»를 둔다. 공공 데이터와 수급 데이터를 각각 레이어 또는 파일로 고른 뒤, 검수 리포트 한 화면에서 규모·항목·위치·내용 차이를 판정·요약·상세·엑셀로 본다. 시스템 반영은 하지 않는다. 기존 기술 단계형 «레이어비교» 화면은 이 구성으로 교체한다.

## 플로우차트

```
개발자도구 → 공공·수급 비교 → 양쪽 자료·짝방법 지정 → 검수리포트(판정·요약·상세) → 엑셀
```

## 화면설계

### DEV-PSC-01 자료 지정

```
┌────────사이드────────┬────────────────────────────────────────────────┐
│ 데이터관리           │  공공 · 수급 비교                               │
│  · 공공·수급 비교 ◀  │                                                 │
│                      │  ┌──────── 공공 데이터 ────────┐  ┌── 수급 ──┐ │
│                      │  │ ○ 레이어  ○ 파일            │  │ ○레이어  │ │
│                      │  │ [선택/첨부 _____________]   │  │ ○파일    │ │
│                      │  └─────────────────────────────┘  │ [선택__] │ │
│                      │                                    └──────────┘ │
│                      │  짝 짓는 방법                                   │
│                      │  ○ 식별키  ○ 위치  ○ 식별키+위치               │
│                      │  식별키: 공공 [  ]  수급 [  ]  (해당 시)        │
│                      │                                                 │
│                      │  항목 맞추기 (자동·후보만 요약)                 │
│                      │  자동 N · 후보 M · 공공만 a · 수급만 b          │
│                      │  [후보 확인]                                    │
│                      │                                                 │
│                      │              [비교 실행]                        │
└──────────────────────┴────────────────────────────────────────────────┘
```

#### 설명

1. 양쪽 역할을 «공공 데이터»와 «수급 데이터»로 고정한다.
2. 각각 레이어 또는 파일을 고른다. 둘 다 파일이면 실행하지 않는다.
3. 짝 짓는 방법을 고른다. 식별키가 필요하면 양쪽에 칸을 지정한다.
4. 항목 이름은 자동으로 맞추고, 애매한 후보만 «후보 확인»에서 확정·제외한다.
5. «비교 실행» 후 검수 리포트로 바로 간다. 중간 기술 단계 화면을 길게 두지 않는다.

#### 확인사항

1. 공공·수급 역할 라벨이 화면에 보여야 한다.
2. 파일↔파일만 고르면 비교가 실행되지 않아야 한다.
3. 첨부 후 레이어 목록에 새 항목이 생기지 않아야 한다.
4. 후보가 없으면 후보 확인 없이 바로 비교할 수 있어야 한다.

### DEV-PSC-02 후보 항목 확인 (필요할 때만)

```
┌──────────────────────────────────────────────┐
│ 항목 맞추기                                   │
│ 공공칸 · 수급칸 · 한글 · [확정] [제외]        │
│ …                                             │
│                         [적용] [취소]         │
└──────────────────────────────────────────────┘
```

#### 설명

1. 영문은 다른데 한글이 같은 경우 등 후보만 모은다.
2. 확정한 쌍만 내용 비교에 쓰고, 제외한 쌍은 쓰지 않는다.
3. 타입만 다른 쌍은 «타입 주의»로 표시하고 확정 여부를 고르게 한다.

#### 확인사항

1. 후보가 아닌 자동 매칭은 이 창에 나열하지 않아야 한다.
2. 확정·제외 후 비교에 반영되어야 한다.

### DEV-PSC-03 검수 리포트

```
┌────────사이드────────┬────────────────────────────────────────────────┐
│ 데이터관리           │  공공 · 수급 비교 결과                          │
│  · 공공·수급 비교 ◀  │                                                 │
│                      │  ┌──────────────────────────────────────────┐  │
│                      │  │ 판정: 주의                                │  │
│                      │  │ 한 줄: 위치는 대체로 맞으나 내용 차이 N건 │  │
│                      │  │ 공공 ○○ · 수급 ○○ · [엑셀] [다시]        │  │
│                      │  └──────────────────────────────────────────┘  │
│                      │                                                 │
│                      │  [규모] 공공 N · 수급 M · 차이                 │
│                      │  [항목] 공통 · 공공만 · 수급만 · 타입주의      │
│                      │  [위치] 양쪽 · 공공만 · 수급만 · 애매          │
│                      │  [내용] 값 다른 짝 · 값 집합 다른 항목         │
│                      │                                                 │
│                      │  ▼ 상세 · 위치 차이                            │
│                      │  ▼ 상세 · 내용 차이 (공공값 | 수급값)          │
│                      │  ▼ 상세 · 항목·코드 집합                       │
└──────────────────────┴────────────────────────────────────────────────┘
```

#### 설명

1. 맨 위는 판정(같음·주의·차이 큼)과 한 줄 결론이다. 숫자가 목적이 아니라 판단이 목적이다.
2. 네 영역 카드는 규모·항목·위치·내용만 짧게 보여 준다.
3. 상세는 접혀 있고, 펼치면 식별키·주요 명칭과 공공/수급 값 대비를 본다.
4. 엑셀은 요약·위치차이·내용차이·항목차이 시트로 내려받는다.
5. 반영 버튼과 미니맵은 없다. 닫거나 다시 하면 임시본을 정리한다.

#### 확인사항

1. 결과 첫 화면에 판정과 한 줄 결론이 보여야 한다.
2. 상세를 펼치지 않아도 네 영역 요약으로 차이를 가늠할 수 있어야 한다.
3. 상세 목록에 내부 행번호만 나오고 식별값이 비어 있지 않아야 한다. (키·명칭이 있을 때)
4. 엑셀에 요약과 차이 목록이 나뉘어 있어야 한다.
5. 반영·저장 버튼이 없어야 한다.
