# 작업계획서

2026-11-03 | dev.strcat | 기본계획 보고서별 목록 개선

## 개발목표

기본계획 «보고서별» 목록을 파일 탐색기형 트리(연도 > 보고서 > 하천)로 바꾼다(카드·묶음 목록 안을 검토한 뒤 트리로 결정). 한 줄짜리 촘촘한 행으로 연도와 보고서를 접고 펼 수 있고, 하천을 누르면 그 하천 상세가 열린다. 하천이 하나뿐인 보고서는 접기 없이 보고서 행을 누르면 바로 상세가 열린다.

보고서 폴더에 PDF가 바로 들어 있으면(소하천처럼 한 파일을 모든 하천이 함께 쓰는 경우) 카드에 «보고서» 버튼을 두어 하천을 고르지 않고도 PDF를 연다. 보고서 폴더 안에 하천 폴더가 있으면 지금처럼 하천 상세에서 하천별 보고서를 열고, 카드의 하천 버튼에 보고서 유무를 표시한다.

보고서별 상세에서는 연도·기본계획 표를 숨기고, 상세 패널 기본 너비를 515로 늘린다.

## 플로우차트

```
보고서별 목록 → (연도 머리말) 보고서 카드 → (하천 버튼) 하천 상세 / (보고서 버튼) 보고서 PDF
```

#### 설명

1. 보고서별 목록은 연도 머리말 아래에 보고서 카드를 최신 연도부터 보여 준다.
2. 카드에는 보고서명이 두 줄까지 보이고, 그 아래 하천 수·계획연장 합계·보고서 상태가 한 줄로 붙는다.
3. 소속 하천은 카드 안 작은 버튼으로 바로 보이며, 누르면 해당 하천 상세가 열리고 버튼이 선택 표시된다. 하천이 많으면 일부만 보이고 «더보기»로 펼친다.
4. 보고서 폴더에 PDF가 바로 있으면 카드에 «보고서» 버튼이 생겨 하천을 고르지 않고 PDF를 연다. 하천 폴더로 나뉘어 있으면 하천 버튼에 보고서 유무 점을 표시하고, 보고서는 하천 상세에서 연다.
5. 하천명으로 검색하면 해당 하천이 들어 있는 카드만 남고, 맞는 하천 버튼이 강조된다.

#### 확인사항

1. 보고서 카드가 연도별로 묶여 최신 연도부터 보여야 한다.
2. 긴 보고서명이 두 줄까지 보이고 넘치면 말줄임으로 끝나야 한다.
3. 하천 버튼을 누르면 해당 하천 상세가 열리고 상세 제목 아래에 보고서명이 보여야 한다.
4. 한 파일 보고서 카드의 «보고서» 버튼을 누르면 하천 선택 없이 PDF가 열려야 한다.
5. 하천 폴더로 나뉜 보고서는 하천 버튼에 보고서 유무가 표시되어야 한다.

```

│사│ 보고서별 목록                  │ 2023 척산천외 5개하천 하천기본계획    │                 │
│이├──────────────────────────────┤──────────────────────────────────────┤      지  도      │
│드│ (보고서 카드 목록)             │ [하천구역][색인도][구조물도][종단면도]│                 │
│바│                               │ [횡단면도][사업계획]                  │                 │
│  │                               │ 기본계획 속성                        │                 │
└──┴──────────────────────────────┴──────────────────────────────────────┴─────────────────┘
```

#### 설명

1. 보고서별로 연 상세에는 연도·기본계획 표가 없고, 제목 아래에 고른 보고서명이 보인다.
2. 같은 하천이 다른 보고서 카드에서 선택되면 상세가 그 보고서 기준으로 바뀐다.
3. 상세 패널 기본 너비는 515이다.

#### 확인사항

1. 보고서별 상세에 연도·기본계획 표가 나오지 않아야 한다.
2. 같은 하천을 다른 보고서 카드에서 누르면 상세 보고서명과 속성이 바뀌어야 한다.
3. 하천별 보기의 상세는 기존처럼 연도표가 보여야 한다.
