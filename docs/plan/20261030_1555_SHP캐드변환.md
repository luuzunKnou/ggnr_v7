## 개발목표

File Converter «SHP to DXF»에서 출력 형식을 도면 또는 캐드로 고른다. 도면은 기존과 같고, 캐드는 도면을 만든 뒤 QCAD로 바꾼다. 변환 환경이 없으면 캐드 선택을 막고 안내한다.

## 플로우차트

```
개발자 모드 → File Converter → SHP to DXF → 형식 선택 → 변환 → 도면 또는 캐드 폴더
```

## 화면설계

### DEV-CONV-02 SHP 형식 선택

```
┌──────────┬──────────────────────────────────────────────────────────┐
│데이터관리│ File Converter                                           │
│ File     │ ┌────────┐ ┌────────┐ ┌────────┐                         │
│ Converter│ │SHP to  │ │  ...   │ │        │                         │
│          │ │ DXF    │ │        │ │        │                         │
│          │ └────────┘ └────────┘ └────────┘                         │
│          │                                                          │
│          │ SHPToDXF 폴더                    [새로고침] [변환 시작]   │
│          │ 출력  ○ 도면(DXF)  ○ 캐드(DWG)                            │
│          │                                                          │
│          │ 선택 작업명  형상파일  도면  캐드  짝 파일 없음  수정일    │
│          │  ○  상수테스트  1       1     0      0                    │
└──────────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 출력에서 도면 또는 캐드를 고른다.
2. 도면을 고르면 작업명/DXF 에 도면이 생긴다.
3. 캐드를 고르면 도면을 만든 뒤 작업명/DWG 에 캐드 파일이 생긴다.
4. QCAD가 없으면 캐드 선택이 비활성화되고 안내가 보인다.

#### 확인사항

1. 도면·캐드 선택지가 보여야 한다.
2. 도면 변환 후 DXF 폴더에 파일이 있어야 한다.
3. 캐드 변환 후 DWG 폴더에 파일이 있어야 한다.
4. QCAD가 없으면 캐드 변환은 막고 안내가 나와야 한다.
5. 다른 변환 탭은 그대로여야 한다.
