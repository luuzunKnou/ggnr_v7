## 개발목표

색인도는 직사각형이므로 지도 라벨을 도형 무게중심(가운데)에 두어, 일부 라벨이 아래로 치우쳐 보이던 현상을 없앤다.

## 플로우차트

색인도 레이어 → 직사각형 무게중심 → 번호 라벨

## 화면설계

### MAP-IDX-02 색인도 라벨 위치

```
┌──────────────────────────────────────────────┐
│ [지도]                                        │
│          ┌──────────┐                         │
│          │    13    │  ← 가운데               │
│          └──────────┘                         │
└──────────────────────────────────────────────┘
```

#### 설명

1. 색인도 번호 라벨은 폴리곤 가운데에 표시된다.
2. 직사각형 전제로 무게중심 배치를 사용한다.

#### 확인사항

1. 색인도 번호가 칸 가운데에 보여야 한다.
2. 일부만 아래로 치우쳐 보이지 않아야 한다.
