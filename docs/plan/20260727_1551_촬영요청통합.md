## 개발목표

영상 자료 업무를 영상관리·영상조회·촬영요청 세 갈래로 진행한다. 화면은 현재 목업을 기준으로 두고, 메뉴 배치·기능 정의·챙길 점을 한곳에 모은다. 이어서 촬영요청을 서버·테이블로 옮기고, 승인·반려·승인 취소·촬영형태 네 가지·비행기록부 저장·승인 상세 작업단위 폴더 생성까지 맞춘다. 실제 파일 바이너리 전송·타일 변환 워커는 후속이다. 지도 공통 셸·사이드바·API 게이트웨이·권한 공통은 수정하지 않는다. 데이터베이스 실적용은 사용자 확인 후에만 한다.

영상관리는 무인기 사이드바, 영상조회는 지도 오른쪽 컨트롤, 촬영요청 신청은 모든 시스템 공통이다.

## 플로우차트

```
신청 제출 → 대기 → (승인|반려) ⇄ 승인취소→대기 → 비행기록부·파일업로드 → 작업단위 폴더 → 등록중 → 등록완료 → 영상관리·영상조회
```

## 화면설계

### MENU-01 메뉴 배치

```
┌─────┬──────────────────────────────┬────────────┐
│사이드│ 지도          [배경][드론][3D] │ (우측패널)  │
│관리  │              [촬영요청]       │            │
│조회X │                              │ 내정보·신청 │
└─────┴──────────────────────────────┴────────────┘
```

#### 설명

1. 영상관리는 무인기 사이드바에서만 드론영상·사진동영상·파노라마·항공으로 연다.
2. 영상조회는 사이드바에 두지 않고, 지도 오른쪽 «배경지도»와 «3D지도» 사이 «드론영상» 버튼으로만 연다.
3. 승인관리는 무인기 사이드바에만 둔다.
4. 촬영요청 버튼은 인쇄 아래에 두고, 시스템과 상관없이 2D·3D 모두 같은 자리에 보인다.
5. 내 촬영요청목록은 «내 정보»에서 열며 모든 시스템 공통이다.
6. 영상관리·다른 지도 기능과 동시에 켜지지 않게 맞추고, 영상조회 패널은 우측 레이어형으로 둔다.

#### 확인사항

1. 촬영요청 버튼이 특정 시스템에서만 숨겨지지 않아야 한다.
2. 사이드바에 «영상조회» 탭이 없어야 한다.
3. 영상조회는 «배경지도»와 «3D지도» 사이 버튼으로만 열려야 한다.

### AM-01 영상관리

```
┌─────┬──────────┬──────────┬────────┐
│메뉴 │ 작업목록  │ 상세·탭  │ 지도   │
│     │          │ 기록부   │        │
└─────┴──────────┴──────────┴────────┘
```

#### 설명

1. 드론영상은 목록·상세·폴더 업로드·타일 변환이며, 파일 체크로 지도 타일을 켠다.
2. 사진·동영상은 목록·작업단위 상세·파일 상세(재생)·폴더 업로드다.
3. 파노라마는 목록·상세·폴더 업로드이며, 파일 선택 시 지도 영역을 덮는 뷰어를 연다.
4. 항공영상은 목록·상세·폴더 업로드이며, 변환 완료 시 배경지도 «자체항공영상»에만 둔다.
5. 비행기록부는 작업단위 상세 탭(별지 제5호)으로만 열고, 촬영신청서와 섞지 않는다.
6. 폴더명에서 작업일·구분·좌표계·작업명을 읽고, 형식이 틀리면 업로드 전에 막는다.
7. 큰 파일은 나눠 올리고, 좌표·범위는 저장 전에 통일한다.
8. 같은 키면 같은 폴더에 합치고, 다르면 새 작업단위로 둔다.
9. 업로드 진행은 작업 폴더 진행 파일에 남기고, 창을 닫아도 같은 구분 목록 상단에서 이어 본다.
10. 작업단위·파일 선택 시 촬영 위치로 지도 범위를 맞춘다.
11. 드론영상만 업로드 뒤 타일 변환이 있고, 변환은 전역에서 한 번에 한 건만 한다.
12. 사진·동영상은 파일 클릭 시 옆에 파일 상세가 열려 최대 네 칸이 된다.

#### 확인사항

1. 목록과 상세를 한 칸에서 바꾸지 않고, 상세는 «닫기»로만 접혀야 한다.
2. 다른 구분 메뉴에는 해당 업로드 배너가 보이지 않아야 한다.
3. 드론영상 체크박스는 타일 표시, 파일 클릭은 위치 이동으로 나뉘어야 한다.
4. 항공영상 목록에는 체크박스가 없고 배경지도에서만 켜고 꺼야 한다.

### AV-01 영상조회

```
┌─────┬──────────────────┬────────────┐
│메뉴 │ 지도              │ 드론영상   │
│     │                  │ 탭·목록·✓ │
└─────┴──────────────────┴────────────┘
```

#### 설명

1. 조회만 하며 업로드·변환·삭제·비행기록부·속성 상세는 두지 않는다.
2. 상단에 드론영상·사진동영상·파노라마 탭 세 줄이 한 줄로 보인다. 항공영상 탭은 없다.
3. 탭마다 작업단위 목록만 보이고, 체크하면 지도에 표시·해제하면 숨긴다.
4. 행 클릭은 선택·지도 맞춤 정도이며, 관리 화면의 파일 상세는 열지 않는다.
5. 작업단위명으로 목록을 줄일 수 있다.
6. 노출 허용 자료만 보이고, 드론영상은 변환 완료된 것만 대상이다.

#### 확인사항

1. 사이드바에 영상조회가 없어야 한다.
2. 관리용 업로드·변환·삭제·비행기록부가 이 패널에 없어야 한다.
3. 체크 on이면 지도에 보이고 off이면 사라져야 한다.
4. 영상관리와 동시에 켜질 때 한쪽만 크게 덮지 않아야 한다.

### BE-SR-01 촬영요청 백엔드 (화면 변경 없음)

```
┌────────────────────────────────────────────────────────────┐
│  (화면 없음)                                                 │
│  · 신청 저장 · 내 목록·상세 · 승인·반려 · 테이블 스키마      │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 지도·사이드바·신청서 목업 화면은 그대로 두고 서버·테이블만 추가한다.
2. 제출 직후 상태는 대기로 저장한다.
3. 승인·반려는 대기 건만 처리하며, 반려 시 사유를 필수로 받는다.
4. 지도 범위는 텍스트(좌표 기준 도형 문자열)로 저장한다.
5. 상태는 대기·승인·등록중·등록완료·반려로 통일한다.

#### 확인사항

1. 공통 지도 셸·사이드바·컨텍스트 파일이 변경되지 않아야 한다.
2. 스키마·서비스·서비스 등록만 추가되어야 한다.
3. 데이터베이스 푸시는 사용자 요청 전에는 실행되지 않아야 한다.

### UI-SR-01 내 신청·승인관리

```
┌─────┬──────────────────────────────┬────────────┐
│메뉴 │ 지도                          │ 내신청목록  │
│     │                              │ 대기·승인   │
│     │                              │ 상세·신청서 │
└─────┴──────────────────────────────┴────────────┘
```

#### 설명

1. 목록을 열면 서버에서 내 신청 또는 승인관리 목록을 불러온다.
2. 신청서 제출 시 서버에 저장되고 상태가 대기로 보인다.
3. 신청서는 부서·신청자·목적·기간·촬영형태·상세요청·지번·지도 범위를 담는다.
4. 범위 없이 제출하면 안내가 나온다.
5. 단독 접속으로 열면 지도·사이드바 없이 신청서만 보인다.
6. 요청자는 상태 확인만 하고, 자료 등록 버튼은 없다.
7. 승인관리는 대기·승인·반려 요약·필터·검색·승인·반려만 한다.
8. 자료 등록은 승인관리의 승인 계열 상세에서만 한다.

#### 확인사항

1. 로그인 후 신청 제출이 목록에 바로 보여야 한다.
2. 승인관리에서 승인·반려 후 상태가 바뀌어야 한다.
3. 새로고침 후에도 신청 데이터가 남아 있어야 한다.
4. 반려 사유가 승인관리와 내 신청에 같이 보여야 한다.
5. 요청자 화면에 자료 등록 버튼이 없어야 한다.

### SR-CANCEL-01 승인 취소

```
┌──────────────────────────────────────────────────────────┐
│ [사이드]  지도                    │ 신청 상세            │
│                                   │ [승인 취소] → 대기   │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 승인 또는 등록중 상세에서 «승인 취소»를 누른다.
2. 서버가 상태를 대기로 되돌리고 승인·등록 관련 값을 비운다.
3. 등록완료는 취소하지 않는다.

#### 확인사항

1. 승인·등록중 건을 취소하면 대기로 돌아가야 한다.
2. 등록완료 건은 취소되지 않아야 한다.
3. 승인관리 권한 없는 사용자는 취소할 수 없어야 한다.

### SR-TYPE-01 촬영형태

```
┌──────────────────────────────────────┐
│ 촬영형태                              │
│ ○ 1. 드론영상  ○ 2. 사진·동영상       │
│ ○ 3. 파노라마  ○ 4. 항공영상          │
└──────────────────────────────────────┘
```

#### 설명

1. 신청서·PDF에 네 가지 촬영형태만 보인다.
2. 선택값과 영상관리 메뉴 분류가 같다.
3. 예전에 저장된 값은 읽을 때 가까운 새 분류로 맞춰 보여 준다.

#### 확인사항

1. 신청서에서 네 가지만 선택할 수 있어야 한다.
2. PDF에도 같은 네 가지가 체크 형태로 보여야 한다.
3. 승인한 뒤 파일 업로드 시 선택한 형태에 맞는 영상 종류로 안내되어야 한다.

### FL-01 비행기록부 저장

```
┌────────────────────────────────────────┐
│ 무인비행장치 비행기록부                  │
│ [PDF 내려받기] [기록부 제출]             │
└────────────────────────────────────────┘
```

#### 설명

1. 기록부 제출을 누르면 서버에 저장된다.
2. 같은 신청(또는 작업단위)으로 다시 열면 저장된 내용이 채워진다.
3. 이미 있으면 수정 저장된다.

#### 확인사항

1. 승인 상세에서 작성·제출 후 다시 열면 내용이 남아 있어야 한다.
2. PDF 내려받기는 이전과 같이 동작해야 한다.
3. 승인·반려 등 기존 기능은 그대로여야 한다.

### SR-UP-01 폴더 일괄 업로드

```
┌────────────────────────────────────────────────────────────┐
│ 승인관리 · 상세                                              │
│                     ┌──────────────────────┐               │
│                     │ 폴더 일괄 업로드      │               │
│                     │ 작업단위명 [        ] │               │
│                     │ [닫기] [업로드 시작]  │               │
│                     └──────────────────────┘               │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 승인·등록중 건의 상세에서 파일 업로드를 열면 작업단위명 입력이 보인다.
2. 업로드 시작을 누르면 서버가 데이터 루트 아래 촬영형태·작업단위 폴더를 만든다.
3. 폴더 생성이 성공한 뒤 진행 표시가 이어지고, 끝나면 등록완료로 바뀔 수 있다.
4. 영상관리 목록 상단에 신청 요약이 뜨고, 배너 «해제»는 연결만 끊는다.

#### 확인사항

1. 작업단위명 없이 시작 버튼이 비활성이어야 한다.
2. 시작 후 데이터 루트에 촬영형태·작업단위 폴더가 생겨야 한다.
3. 같은 이름으로 다시 시작해도 오류 없이 이어지거나 안내가 명확해야 한다.
4. 지도 다른 메뉴는 이전과 같이 동작해야 한다.
