2026-08-21 | JungWooojin | 접도구역 건축물 확인창

## 개발목표

관리대장에서 등록·저장·수정·삭제·취소를 누르기 전에, 브라우저 기본 창이 아니라 화면에 맞춘 확인 창을 한 번 더 띄운다. 실패 안내도 같은 창으로 보여 준다. 상세 칸 배치는 바꾸지 않는다.

## 플로우차트

```
등록·저장·수정·삭제·취소 → 확인 창 → (확인) → 반영
```

```
│      │                                   │ │ 변경한 내용이 반영됩니다.  │                     │
│      │                                   │ │         [취소] [저장]      │                     │
│      │                                   │ └────────────────────────────┘                     │
└──────┴───────────────────────────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 저장·등록·수정·삭제·취소를 누르면 확인 창이  overlay로 뜬다.
2. 취소를 누르면 창만 닫히고 내용은 그대로다.
3. 확인을 누르면 해당 동작이 진행된다.
4. 저장·삭제 실패 안내는 같은 형태의 알림 창으로 보여 준다.

#### 확인사항

1. 저장을 누르면 확인 창이 뜬 뒤 확인해야 저장되어야 한다.
2. 삭제를 누르면 확인 창이 뜬 뒤 확인해야 삭제되어야 한다.
3. 수정을 누르면 확인 창이 뜬 뒤 편집으로 들어가야 한다.
4. 취소를 누르면 확인 창이 뜬 뒤 편집이 끝나야 한다.
5. 확인 창에서 취소를 누르면 아무 것도 바뀌지 않아야 한다.
