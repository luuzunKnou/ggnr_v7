## 개발목표

지도 우측 컨트롤의 배경지도 묶음에 «세부원도» 버튼을 추가한다. 좌측 메뉴는 한 번에 하나만 열리므로, 필지분석·지적재조사 등 좌측 업무를 하면서 원도를 함께 참고할 수 있도록 지적도·드론영상처럼 우측 버튼으로 둔다. 버튼은 원도 폴더가 있는 프로젝트에서만 보인다.

버튼을 켜면 2019년 모자이크 사업 산출물(현재 길안면 지적 원도 339장, 임야 원도 5장)의 도곽 경계가 지도에 표시된다. 도곽을 클릭하면 원도가 1장일 때는 바로, 여러 장이 겹친 곳은 클릭한 자리의 목록에서 골라 원본 스캔 이미지를 실제 좌표와 회전까지 반영해 지적도 아래에 겹쳐 본다.

원도 목록은 서버 데이터 폴더의 원도 이미지와 네 모서리 좌표 정보 파일을 읽어 자동으로 만든다. 데이터베이스는 바꾸지 않고 서버가 읽은 목록을 보관해 둔다. 이미지는 변환하지 않고 원본을 그대로 쓴다.

## 플로우차트

```
지도 → 세부원도 버튼 → 도곽 경계 → (도곽 클릭: 1장 바로 표시 / 여러 장 목록 팝업) → 원도 겹쳐 보기 ⇄ 투명도·접기
```

## 화면설계

### MAP-WONDO-01 세부원도 패널

```
┌────┬──────────────────────────────────────────────────────────┬────┐
│    │ [ 주소 검색                 ]   ┌──────────────────────┐ │배경│
│ 메 │                                 │ 세부원도     ⟳  ˄  ✕ │ │지도│
│ 뉴 │     ┌ ─ ─ ─ ┐┌ ─ ─ ─ ┐          ├──────────────────────┤ │드론│
│    │     │ 고란동 ││ 고란동 │          │ [ 동명, 원도번호   ] │ │영상│
│    │     │   1    ││   2    │          │ (전체)(지적)(임야)   │ │세부│
│    │     └ ─ ─ ─ ┘└ ─ ─ ─ ┘          ├──────────────────────┤ │원도│
│    │     ┌ ─ ─ ─ ┐                   │ 344장 · 표시 중 0장  │ ├────┤
│    │     │ 금곡동 │                   ├──────────────────────┤ │지적│
│    │     │   3    │                   │ 고란동 1   지적  👁 │ │도  │
│    │     └ ─ ─ ─ ┘                   │ 고란동 2   지적  👁 │ │주제│
│    │                                 │ 금곡동 1   지적  👁 │ │도  │
│    │                                 │ …                    │ │    │
│    │                                 └──────────────────────┘ │    │
└────┴──────────────────────────────────────────────────────────┴────┘
```

#### 설명

1. 우측 «세부원도» 버튼을 누르면 버튼 왼쪽에 패널이 열리고 지도에 원도별 도곽 경계가 점선으로 표시된다.
2. 목록은 동명·원도번호 검색과 구분(전체·지적·임야)으로 좁히며, 지도 도곽도 함께 좁혀진다.
3. 지금 화면에 원도가 하나도 없을 때만 전체 원도 범위로 지도가 이동한다.
4. 좌측 메뉴와 별개라 필지분석 등 좌측 업무 패널과 함께 열 수 있다.
5. 원도 폴더가 없는 프로젝트에서는 버튼이 보이지 않는다.

#### 확인사항

1. 버튼을 켜면 원도 건수(344장)가 표시되어야 한다.
2. 도곽 경계가 길안면 일대에 표시되어야 한다.
3. 좌측 메뉴를 연 상태에서도 버튼을 켤 수 있어야 한다.
4. 버튼을 다시 누르거나 닫기를 누르면 도곽과 겹친 원도가 모두 사라져야 한다.

### MAP-WONDO-02 지도 위치 원도 선택

```
┌────┬──────────────────────────────────────────────────────────┬────┐
│    │ [ 주소 검색                 ]   ┌──────────────────────┐ │배경│
│ 메 │        ┌────────────────────┐   │ 세부원도     ⟳  ˄  ✕ │ │지도│
│ 뉴 │        │ 이 위치 원도 2장  ✕│   ├──────────────────────┤ │드론│
│    │        │ 고란동 1  지적   👁│   │ [ 동명, 원도번호   ] │ │영상│
│    │        │ 고란동 2  지적   👁│   │ (전체)(지적)(임야)   │ │세부│
│    │        └─────────┬──────────┘   ├──────────────────────┤ │원도│
│    │     ┌───────┐┌ ─ ┼ ─ ┐          │ 344장 · 표시 중 0장  │ ├────┤
│    │     │ 고란동 ││    ●  │          ├──────────────────────┤ │지적│
│    │     │   1    ││ 고란동 │          │ 고란동 1   지적  👁 │ │도  │
│    │     └───────┘└ ─ ─ ─ ┘          │ …                    │ │    │
│    │                                 └──────────────────────┘ │    │
└────┴──────────────────────────────────────────────────────────┴────┘
```

#### 설명

1. 원도가 1장뿐인 도곽을 클릭하면 그 원도가 바로 지도에 겹쳐 표시된다.
2. 같은 위치에 동만 다른 원도 등 여러 장이 겹쳐 있으면 클릭한 자리에 목록 팝업이 뜬다.
3. 팝업의 행을 누르면 해당 원도를 켜고 끈다.
4. 원도가 없는 곳을 클릭하면 팝업이 닫힌다.
5. 측정·도형 그리기·도형 편집 중에는 지도 클릭으로 원도를 고르지 않는다.

#### 확인사항

1. 1장인 도곽을 클릭하면 바로 원도가 표시되어야 한다.
2. 여러 장 겹친 곳을 클릭하면 클릭 위치에 팝업이 나와야 한다.
3. 빈 곳을 클릭하면 팝업이 사라져야 한다.

### MAP-WONDO-03 원도 겹쳐 보기·패널 접기

```
┌────┬──────────────────────────────────────────────────────────┬────┐
│    │ [ 주소 검색                 ]   ┌──────────────────────┐ │배경│
│ 메 │  ┌──────────────────────────┐   │ 세부원도 표시 중 1장 │ │지도│
│ 뉴 │  │ ░░░░ 원도 이미지 ░░░░░░ │   │              ⟳  ˅  ✕ │ │드론│
│    │  │ ░░ ┌──┐ ░░░░░░░░░░░░░░ │   └──────────────────────┘ │영상│
│    │  │ ░░ │  │ 지적도 경계 ░░ │                            │세부│
│    │  │ ░░ └──┘ ░░░░░░░░░░░░░░ │                            │원도│
│    │  │ ░░░░░░░░░░░░░░░░░░░░░░ │                            ├────┤
│    │  └──────────────────────────┘                            │지적│
│    │                                                          │도  │
└────┴──────────────────────────────────────────────────────────┴────┘
```

#### 설명

1. 원도는 실제 좌표·회전대로 지적도 아래에 깔려 지적 경계선과 함께 비교할 수 있다.
2. 표시 중인 원도마다 패널에서 투명도 조절과 «위치로 이동»을 제공하고, «모두 끄기»로 한 번에 끈다.
3. 패널을 접으면 헤더만 남고 켜 둔 원도와 그 도곽만 지도에 남는다.
4. 접힌 동안에는 지도 클릭으로 원도를 고르지 않아 좌측 업무의 지도 클릭과 겹치지 않는다.

#### 확인사항

1. 원도의 빨간 도곽선이 같은 좌표의 지적 도곽·필지 경계와 어긋나지 않아야 한다.
2. 투명도를 바꾸면 즉시 지도에 반영되어야 한다.
3. 패널을 접은 뒤 지도를 클릭해도 원도가 새로 켜지거나 팝업이 뜨지 않아야 한다.
4. 지적도·드론영상·배경지도 버튼과 측정 도구가 기존과 같이 동작해야 한다.
