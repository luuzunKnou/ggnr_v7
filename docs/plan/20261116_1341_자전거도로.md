## 개발목표

도로 사이드바에 «자전거도로» 프로토타입을 둔다. 켜면 시점~종점 노선 목록이 나오고, 노선을 고르면 속성·구간 목록·첨부가 보인다. 구간은 일련번호·노선명·연장만 표로 두고, 클릭 시 모달에서 폭원 등 상세를 구역별로 본다. 1차는 목 데이터·화면 흐름만.

## 플로우차트

지도 → 자전거도로 목록 → 노선 상세(속성·구간·첨부) → (구간 클릭) → 구간 상세 모달

## 화면설계

### BIKE-01 노선 목록

```
┌──────────────────────────────────────────────────────────────┐
│ [검색]                                                        │
├────┬─────────────────────────────────────────────────────────┤
│도로│ 자전거도로                                    [닫기]     │
│ ·  │ ┌─────────────────────────────────────────────────────┐ │
│망도│ │ 삼성현로(대구시계) ~ 대학로(압량농협네거리)          │ │
│ ·  │ │ 연장 12.3km · 구간 8                                │ │
│자  │ ├─────────────────────────────────────────────────────┤ │
│전  │ │ 금호강(대정동) ~ 금호강(와촌면)                      │ │
│거  │ │ 연장 … · 구간 …                                     │ │
│도로│ └─────────────────────────────────────────────────────┘ │
│    │                      (지도)                              │
└────┴─────────────────────────────────────────────────────────┘
```

#### 설명

1. 사이드바 «자전거도로»를 켜면 왼쪽 목록만 먼저 보인다.
2. 각 행 제목은 시점~종점 문구다.
3. 보조로 연장·구간 수를 짧게 보여 준다.

#### 확인사항

1. 메뉴를 켜면 노선 목록이 보여야 한다.
2. 행 제목이 시점~종점 형태여야 한다.
3. 도로망도와 동시에 같은 방식으로 켜지지 않아야 한다.

### BIKE-02 노선 상세

```
┌────┬──────────────────┬──────────────────────────────────────┐
│도로│ 노선 목록         │ 노선 상세                     [닫기] │
│ ·  │ (선택 행 강조)    │ 삼성현로(대구시계)~대학로(…)         │
│자  │                   │ ┌ 속성 ───────────────────────────┐ │
│전  │                   │ │ 연장 · 진행방향 · 시점 · 종점    │ │
│거  │                   │ │ 교량 · 지하철역 · 비고           │ │
│도로│                   │ └─────────────────────────────────┘ │
│    │                   │ ┌ 구간 목록 ──────────────────────┐ │
│    │                   │ │ 일련번호 │ 노선명 │ 연장        │ │
│    │                   │ │ 1-1 │ 삼성현로R │ 3.60         │ │
│    │                   │ │ 1-2 │ 삼성현로L │ 3.60         │ │
│    │                   │ └─────────────────────────────────┘ │
│    │                   │ ┌ 첨부 ───────────────────────────┐ │
│    │                   │ │ (파일 목록)                      │ │
│    │                   │ └─────────────────────────────────┘ │
└────┴──────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 목록에서 노선을 누르면 상세가 열린다.
2. 위쪽에 노선 속성 일곱 항목을 둔다.
3. 아래에 구간 표(일련번호·노선명·연장)를 둔다.
4. 첨부는 도로망도와 비슷한 위치에 둔다.

#### 확인사항

1. 노선 클릭 시 상세에 속성이 보여야 한다.
2. 구간 표에 일련번호·노선명·연장만 보여야 한다.
3. 목록으로 돌아가거나 닫을 수 있어야 한다.

### BIKE-03 구간 상세 모달

```
┌──────────────────────────────────────────────────────────────┐
│ (목록·상세 위 오버레이 모달)                                   │
│ 구간 상세                                              [닫기] │
│ 1-1 · 삼성현로R · 3.60km                                     │
│ ┌ 기본 ────────────────────────────────────────────────────┐ │
│ │ 기점 · 종점 · 도로 연계성 · 종류 · 연장                    │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌ 폭원(m) ─────────────────────────────────────────────────┐ │
│ │ 전용도로 · 전용차로 · 우선도로                             │ │
│ │ 겸용(분리형): 자전거도로 · 보도 · 유효폭원                 │ │
│ │ 겸용(비분리형): 도로폭원 · 유효폭원                        │ │
│ └──────────────────────────────────────────────────────────┘ │
│                                              [닫기]           │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 구간 행을 누르면 모달이 열린다.
2. 기본 항목과 폭원 구역을 나눠 보여 준다.
3. 모달 위치·닫기 동작은 도로망도 구간/현장 모달과 비슷한 느낌을 쓴다.

#### 확인사항

1. 구간 클릭 시 모달이 열려야 한다.
2. 폭원 항목이 구역별로 나뉘어 보여야 한다.
3. 닫으면 노선 상세·구간 목록이 그대로여야 한다.
