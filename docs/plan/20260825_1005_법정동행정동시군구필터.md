## 개발목표

레이어설정 코드에서 법정동·행정동 목록만, 실행환경 시군구 앞 다섯 자리에 맞는 항목을 보여 준다. 저장 시 다른 시군구 값은 그대로 둔다. 지도 부서업무 필터는 이번에 넣지 않고, 같은 거르기 규칙을 나중에 쓸 수 있게 둔다.

## 플로우차트

레이어설정 → 코드 → 법정동·행정동 선택 → 시군구 기준 목록 → 수정·저장(다른 시군구 유지)

## 화면설계

### LAY-CODE-01 법정동·행정동 코드 목록

```
┌──────────────────────────────────────────────────────────────────┐
│ 개발  ·  레이어설정  ·  코드                                      │
├────────────┬────────────┬────────────────────────────────────────┤
│ 전체 public │ 필드 검색  │ [저장] [초기화]                       │
│ 접속 DB만  │            │ 시군구 기준 12개 / 전체 3500개         │
│ 레이어검색 │ 법정동     │ ┌────────┬────────┬────┐               │
│            │ 행정동     │ │코드명  │한글명  │삭제│               │
│ 도로-가로수│ 관리기관   │ │47760… │영양읍  │삭제│               │
│            │            │ │47760… │입암면  │삭제│               │
│            │            │ └────────┴────────┴────┘               │
└────────────┴────────────┴────────────────────────────────────────┘
```

#### 설명

1. 가운데에서 법정동 또는 행정동을 고르면 오른쪽 목록이 시군구 기준으로 줄어든다.
2. 건수에 시군구 기준 건수와 전체 건수가 함께 보인다.
3. 저장하면 화면에 보이는 시군구만 반영하고, 다른 시군구 값은 파일에 남긴다.
4. 다른 코드 필드는 기존처럼 전체를 보여 준다.

#### 확인사항

1. 법정동·행정동에서만 시군구 기준 목록이 나와야 한다.
2. 관리기관 같은 다른 코드는 전체가 나와야 한다.
3. 영양에서 저장해도 다른 시군구 코드가 사라져서는 안 된다.
4. 시군구 값이 없으면 법정동·행정동도 전체를 보여야 한다.

### LAY-CODE-02 해당 시군구 없음

```
┌──────────────────────────────────────────────────────────────────┐
│ 개발  ·  레이어설정  ·  코드                                      │
├────────────┬────────────┬────────────────────────────────────────┤
│ 레이어목록 │ 법정동     │ [저장] [초기화]                       │
│            │            │ 시군구 기준 0개 / 전체 24개            │
│            │            │ 현재 시군구에 해당하는 코드가 없습니다 │
└────────────┴────────────┴────────────────────────────────────────┘
```

#### 설명

1. 코드표에 해당 시군구가 아직 없으면 빈 안내가 나온다.
2. 저장해도 다른 시군구 기존 값은 유지된다.

#### 확인사항

1. 빈 안내가 나와야 한다.
2. 저장 후 다른 시군구 코드가 그대로여야 한다.
