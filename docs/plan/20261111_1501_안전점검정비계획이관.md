## 개발목표

안전점검 보고서 상세 상단(엑셀 오른쪽)에 «정비계획 이관»을 둔다. 이번 보고서에서 점검이 끝난 시설 중 평가구분이 위험으로 바뀐 것만 골라 정비계획에 넣고, 정비계획 화면을 열어 분석·순위 흐름으로 이어지게 한다. 공사·예산 이관은 넣지 않는다.

## 플로우차트

```
안전점검 보고서 → 정비계획 이관 → (위험 전환 시설 일괄 선택) → 정비계획 분석 목록·순위
```

## 화면설계

### MAP-INSP-XFER-01 보고서 상세(이관 버튼)

```
┌──────────────────────────────────────────┐
│ 2025년 안전점검 보고서              [×]  │
├──────────────────────────────────────────┤
│ [보고서] [엑셀] [정비계획 이관]          │
│ ┌ 개요 ………………………………………           │
│ └ 점검 대상 목록 ……………………………           │
└──────────────────────────────────────────┘
```

#### 설명

1. 상단에 보고서·엑셀·정비계획 이관이 나란히 있다.
2. 이관을 누르면 위험으로 바뀐 시설 선택 창이 열린다.
3. 대상이 없으면 안내만 하고 창을 열지 않는다.

#### 확인사항

1. 엑셀 오른쪽에 «정비계획 이관»이 있어야 한다.
2. 대상이 없을 때 안내가 나와야 한다.
3. 보고서·엑셀 동작은 그대로여야 한다.

### MAP-INSP-XFER-02 이관 시설 선택

```
┌──────────────────────────────────────────┐
│ 정비계획 이관                            │
│ 점검 후 위험으로 바뀐 시설을 고르세요    │
├──────────────────────────────────────────┤
│ [전체 선택] [전체 해제]                  │
│ ☑ 시설명 · 유형 · 일반→위험 · 점검일    │
│ ☐ 시설명 · … (이미 포함)                 │
├──────────────────────────────────────────┤
│                    [이관] [취소]         │
└──────────────────────────────────────────┘
```

#### 설명

1. 점검 결과 위험이고 이전 구분이 위험이 아닌 시설만 목록에 나온다.
2. 이미 정비계획에 있는 시설은 «이미 포함»으로 두고 기본 선택은 끈다.
3. 이관을 누르면 선택된 시설만 정비계획으로 넘기고 정비계획 화면이 열린다.

#### 확인사항

1. 전체 선택·해제가 되어야 한다.
2. 이미 포함된 시설은 다시 추가되지 않아야 한다.
3. 이관 후 정비계획 화면이 열려야 한다.
