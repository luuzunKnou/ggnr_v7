## 개발목표

공간분석 «누수분석»에서 관망에 스냅해 누수 위치를 고르면, 그 구간을 막기 위해 잠가야 할 제수변 목록을 보여 준다. 화면은 단수구역과 같은 이력·결과·하단 액션 패턴을 쓴다.

## 플로우차트

공간분석 → 누수분석 → 관망 클릭(스냅) → 제수변 목록 → 분석결과저장

## 화면설계

### SPA-LEAK-01 누수분석

```
┌──────사이드────────┬──────────지도──────────┐
│ 공간분석 누수분석    │  관로 · 스냅 위치      │
│ 이력               │  ● 잠글 제수변          │
│ 누수위치 · 제수변목록 │                       │
│ 새분석 · 결과저장   │                        │
└────────────────────┴────────────────────────┘
```

#### 설명

1. 지도를 클릭하면 가까운 상수관로에 위치가 붙는다.
2. 그 지점에서 관로를 따라가 만나는 제수변을 잠글 대상으로 목록에 올린다.
3. 분석결과저장으로 세션 이력에 남기고, 새 분석으로 다시 고른다.

#### 확인사항

1. 관로에서 먼 곳을 클릭하면 스냅되지 않거나 안내가 나와야 한다.
2. 스냅 후 잠글 제수변이 목록·지도에 보여야 한다.
3. 단수구역 탭과 전환해도 서로 레이어가 남지 않아야 한다.
