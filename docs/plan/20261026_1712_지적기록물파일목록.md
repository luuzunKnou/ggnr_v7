## 개발목표

지적기록물 목록을 지번 한 줄이 아니라 스캔 파일 한 줄로 바꾼다. 읍면동·지번 검색은 그대로 두고, 검색에 걸린 장이 목록에 나온다. 한 장이 여러 지번에 묶여 있으면 지번 칸에 대표 주소와 나머지 개수를 보여 준다. 상세는 그 장의 미리보기와 묶인 지번 목록이다.

## 플로우차트

```
지도 → 지적기록물 파일 목록 → (행 선택) → 미리보기·묶인 지번 → (미리보기 클릭) → 뷰어
```

## 화면설계

### MAP-ARCHIVE-11 파일 목록

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│메뉴│ 지적기록물                 X │                                      │
│    ├──────────────────────────────┤                                      │
│지적│ [전체 읍면동▼] [지번·권    ] │                                      │
│기록├──────────────────────────────┤                                      │
│물  │ 종류        파일        지번 │                                      │
│    │ 폐쇄지적도  …002-01.jpg  금곡동 180-26 외 48│                        │
│    │ 구대장      b0450323.jpg  …        │                                │
│    │ 측량결과도  c00090010.jpg 권 9     │                                │
│    ├──────────────────────────────┤                                      │
│    │ 3건                          │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 목록 한 줄은 스캔 파일 한 장이다. 같은 장을 여러 지번이 가리켜도 한 줄이다.
2. 읍면동·지번으로 거르면 그 지번이 묶인 장만 남는다.
3. 지번 칸은 대표 주소와 «외 n»이다. 지번이 없으면 권·단체명 또는 빈 칸이다.
4. 행을 누르면 옆에 상세가 열린다.

#### 확인사항

1. 같은 지적도 장이 지번 수만큼 반복되지 않아야 한다.
2. 파일이 있는 장만 나와야 한다.
3. 지번으로 검색하면 해당 지번이 묶인 장이 나와야 한다.

### MAP-ARCHIVE-12 미리보기·지번

```
┌────┬──────────────────────┬────────────────────────────┬───────────────────┐
│메뉴│ 지적기록물         X │ 폐쇄지적도 …002-01.jpg   X │                   │
│    ├──────────────────────┤ 권 · 페이지                │                   │
│    │ 폐쇄지적도 … ■       │ 금곡동 180-26              │                   │
│    │                      │ 금곡동 180-20              │                   │
│    │                      │ … 외 더 보기               │                   │
│    │                      │ (스캔 미리보기)            │                   │
└────┴──────────────────────┴────────────────────────────┴───────────────────┘
```

#### 설명

1. 상세 제목은 종류와 파일명이다.
2. 위쪽에 이 장이 묶인 지번이 나오고, 많으면 일부만 보인 뒤 펼친다.
3. 아래 미리보기를 누르면 뷰어가 열린다.
4. 지번이 없는 장(측량결과도 등)은 지번 목록 없이 미리보기만 보여 준다.

#### 확인사항

1. 상세에 선택한 장 미리보기가 나와야 한다.
2. 지적도처럼 여러 지번에 묶인 장은 지번이 여러 줄 나와야 한다.
3. 미리보기를 누르면 뷰어가 열려야 한다.
