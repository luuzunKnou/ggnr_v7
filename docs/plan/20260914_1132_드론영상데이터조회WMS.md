## 개발목표

데이터 조회에서 변환 완료된 드론영상 범위를 보라색 상자로 켜고, 상자를 클릭하면 그 영상이 지도에 겹쳐 보이게 한다. 레이어권한에는 같은 드론영상을 목록에 올려 읽기 허용 시 QGIS에서 WMS로 영상을 불러올 수 있게 한다. 기존 영상조회 체크 표시는 그대로 둔다.

## 플로우차트

```
데이터조회 → 드론영상범위 켜기 → 보라색상자 → (클릭) → 드론영상표시
레이어권한 → 드론영상 읽기허용 → QGIS WMS → 영상표시
```

## 화면설계

### MAP-ORTHO-01 데이터조회 드론영상 범위

```
┌──────────────────────────────────────────────────────────┐
│ 사이드바 │ 검색…          │              지도            │
│          │                │                              │
│ 데이터조회│ 드론영상       │   ┌──────────┐               │
│  ···     │ ☑ 드론영상 범위 │   │ 보라색   │               │
│          │                │   │ 상자×N   │               │
│          │                │   └──────────┘               │
│          │                │                              │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 데이터 조회 목록에 «드론영상» 그룹과 «드론영상 범위» 항목이 보인다.
2. 항목을 켜면 변환이 끝난 영상마다 보라색 상자가 지도에 그려진다.
3. 상자를 클릭하면 그 드론영상이 지도 위에 표시되고 해당 범위로 맞춘다.
4. 항목을 끄면 보라색 상자와 클릭으로 켠 영상 표시가 함께 꺼진다.

#### 확인사항

1. 데이터 조회에서 «드론영상 범위»를 켜면 보라색 상자가 보여야 한다.
2. 상자를 클릭하면 해당 드론영상이 지도에 떠야 한다.
3. 영상조회에서 켜 둔 다른 영상과 함께 동작해도 오류가 없어야 한다.
4. «드론영상 범위»를 끄면 상자·클릭 영상이 사라져야 한다.

### MAP-ORTHO-02 레이어권한 QGIS WMS

```
┌──────────────────────────────────────────────────────────┐
│ 레이어권한                                                │
│ 사용자 선택 · 접속키                                      │
│ 드론영상                                                  │
│  ☑ 읽기  작업명_파일명 …                                  │
│                                                          │
│ QGIS: WMS 주소 + 키 → 허용 영상 목록·지도 표시            │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 레이어권한 목록에 변환 완료 드론영상이 «드론영상» 그룹으로 보인다.
2. 읽기를 허용한 영상만 QGIS WMS 능력 문서에 나타난다.
3. QGIS에서 해당 레이어를 켜면 영상 그림이 지도에 나온다.

#### 확인사항

1. 레이어권한에 드론영상 항목이 보여야 한다.
2. 읽기 허용 후 QGIS WMS에 해당 레이어가 보여야 한다.
3. 읽기 거부된 영상은 QGIS에 나오지 않아야 한다.
4. 허용 영상을 QGIS에서 켜면 영상이 보여야 한다.
