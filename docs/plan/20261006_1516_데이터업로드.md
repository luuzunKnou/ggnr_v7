# 작업계획서

## 개발목표

지도 왼쪽 메뉴에 «데이터 업로드»를 추가하고, 왼쪽 패널 하나 안에서 파일 선택 → 설정 → 미리보기 세 단계로 SHP·엑셀 자료를 확인하는 화면을 만든다.

파일 내용은 브라우저에서 바로 읽어 구성 파일 점검, 좌표계·인코딩 자동 감지, 속성 미리보기까지 보여준다. 서버 저장과 레이어 등록, 데이터조회 연결은 이번 범위에서 제외하고 «등록» 버튼은 준비 중으로 둔다.

## 플로우차트

```
지도 → 데이터 업로드 → 파일 선택 → 설정(SHP ⇄ 엑셀) → 미리보기 → 등록(후속)
```

## 화면설계

### MAP-UPLOAD-01 파일 선택

```
┌────┬──────────────────────────────┬──────────────────────────────┐
│메뉴│ 데이터 업로드            [X] │ [ 주소·지명 검색          ]  │
│    │ ─────────────────────────────│                              │
│데이│  ● 파일 선택 ─ ○ 설정 ─ ○ 미리보기                          │
│터  │ ┌──────────────────────────┐ │                              │
│조회│ │      파일을 놓거나        │ │                              │
│    │ │      눌러 선택            │ │            지도              │
│데이│ │ SHP(zip·개별), 엑셀, CSV │ │                              │
│터  │ └──────────────────────────┘ │                              │
│업로│  형식: SHP                   │                              │
│드  │  자료: 도로경계 [변경 ▼]     │                              │
│    │  ✓ 도형  ✓ 색인  ✓ 속성      │                              │
│    │  ✓ 좌표계  ─ 인코딩          │                              │
│    │                [지우기][다음]│                              │
└────┴──────────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 사이드바 «데이터 업로드»를 누르면 왼쪽 패널이 열리고 첫 단계가 선택된다.
2. 끌어다 놓기 또는 눌러 선택으로 zip, 개별 SHP 구성 파일, 엑셀, CSV를 받는다.
3. 확장자로 형식을 자동 판별하고, SHP는 구성 파일별 있음·없음을 표시한다.
4. zip 안에 SHP 자료가 여러 개면 자료 이름을 골라야 한다.

#### 확인사항

1. 도형·색인·속성 파일 중 하나라도 없으면 «다음»이 눌리지 않아야 한다.
2. 지원하지 않는 파일만 올리면 안내 문구가 나와야 한다.
3. 좌표계·인코딩 파일이 없으면 권장 항목으로만 표시되고 진행은 가능해야 한다.

### MAP-UPLOAD-02 설정 (SHP)

```
┌────┬──────────────────────────────┬──────────────────────────────┐
│메뉴│ 데이터 업로드            [X] │ [ 주소·지명 검색          ]  │
│    │ ─────────────────────────────│                              │
│    │  ✓ 파일 선택 ─ ● 설정 ─ ○ 미리보기                          │
│    │  레이어 이름                 │                              │
│    │  [ 도로경계               ]  │                              │
│    │  공개 범위                   │            지도              │
│    │  (●나만) (○부서) (○전체)     │                              │
│    │  좌표계            자동 감지 │                              │
│    │  [ 중부원점 2010         ▼]  │                              │
│    │  속성 인코딩                 │                              │
│    │  [ 국내 표준(한글)       ▼]  │                              │
│    │                [이전][다음]  │                              │
└────┴──────────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 레이어 이름은 파일 이름으로 미리 채워진다.
2. 좌표계 정의 파일이 있으면 좌표계를 자동으로 고르고 «자동 감지»를 표시한다.
3. 정의 파일이 없으면 좌표 범위로 추정한 값을 고르고 «추정»으로 표시한다.
4. 인코딩 파일이 있으면 그 값을, 없으면 국내 표준(한글)을 기본으로 한다.

#### 확인사항

1. 레이어 이름이 비어 있으면 «다음»이 눌리지 않아야 한다.
2. 인코딩을 바꾸면 미리보기의 한글 속성이 바뀐 인코딩으로 다시 읽혀야 한다.
3. 좌표계가 추정값이면 확인을 권하는 안내가 나와야 한다.

### MAP-UPLOAD-03 설정 (엑셀)

```
┌────┬──────────────────────────────┬──────────────────────────────┐
│메뉴│ 데이터 업로드            [X] │ [ 주소·지명 검색          ]  │
│    │ ─────────────────────────────│                              │
│    │  ✓ 파일 선택 ─ ● 설정 ─ ○ 미리보기                          │
│    │  레이어 이름 [ 가로등대장  ] │                              │
│    │  공개 범위 (●나만)(○부서)(○전체)                            │
│    │  시트 [Sheet1 ▼] 머리글 행 [1▼]                              │
│    │  위치 지정                   │            지도              │
│    │  (●좌표) (○주소) (○도형문자) │                              │
│    │  경도·X [ 경도          ▼]   │                              │
│    │  위도·Y [ 위도          ▼]   │                              │
│    │  좌표계 [ 위경도        ▼]   │                              │
│    │                [이전][다음]  │                              │
└────┴──────────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 시트와 머리글 행을 고르면 컬럼 목록이 다시 만들어진다.
2. 컬럼 이름으로 좌표·주소·도형문자 컬럼을 자동으로 골라 둔다.
3. 위치 지정이 좌표이면 경도·위도 컬럼과 좌표계를, 주소이면 주소 컬럼을, 도형문자이면 해당 컬럼과 좌표계를 고른다.
4. 좌표 값 크기로 위경도·평면좌표를 추정해 좌표계를 미리 고른다.

#### 확인사항

1. 위치 컬럼을 고르지 않으면 «다음»이 눌리지 않아야 한다.
2. 경도·위도가 바뀐 것으로 보이면 안내가 나와야 한다.
3. 머리글 행을 바꾸면 컬럼 목록이 바뀌어야 한다.

### MAP-UPLOAD-04 미리보기

```
┌────┬──────────────────────────────┬──────────────────────────────┐
│메뉴│ 데이터 업로드            [X] │ [ 주소·지명 검색          ]  │
│    │ ─────────────────────────────│                              │
│    │  ✓ 파일 선택 ─ ✓ 설정 ─ ● 미리보기                          │
│    │  레이어  도로경계            │                              │
│    │  건수 1,204  도형 면         │                              │
│    │  좌표계 중부원점 2010        │            지도              │
│    │  위치 없음 0건               │                              │
│    │  속성 미리보기 (앞 20건)     │                              │
│    │ ┌────┬──────┬──────┬───────┐ │                              │
│    │ │번호│도로명│폭    │관리기관│ │                              │
│    │ ├────┼──────┼──────┼───────┤ │                              │
│    │ │1   │중앙로│12    │안동시 │ │                              │
│    │ └────┴──────┴──────┴───────┘ │                              │
│    │                [이전][등록]  │                              │
└────┴──────────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 형식, 건수, 도형 유형, 좌표계, 공개 범위를 요약해 보여준다.
2. 엑셀은 위치를 만들 수 없는 행 수를 따로 보여준다.
3. 속성 컬럼과 앞 20건을 표로 보여주며 가로로 스크롤된다.
4. «등록»은 서버 저장이 연결되기 전까지 준비 중으로 비활성화한다.

#### 확인사항

1. SHP 건수가 속성 파일의 실제 건수와 같아야 한다.
2. 한글 속성이 깨지지 않아야 한다.
3. 위치 없음 행이 있으면 경고 색으로 표시되어야 한다.
4. 패널을 닫았다 열면 처음 단계부터 다시 시작해야 한다.
