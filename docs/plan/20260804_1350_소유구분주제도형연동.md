## 개발목표

지도 우측 «소유구분»을 주제도와 같은 방식으로 맞춘다. 버튼을 누르면 목록 패널이 열리고, 정의의 소유자정보 그룹만 보여 주며, 데이터가 있는 항목만 골라 지도에 켠다. 레이어 업로드는 별도이므로 목록이 비어 있어도 패널·버튼 동작은 주제도와 동일하게 둔다.

## 플로우차트

```
지도 → 소유구분 버튼 → 소유구분 패널 → 레이어 선택 → 지도 표시
```

## 화면설계

### MAP-OWN-01 소유구분 패널

```
+----------------------------------------------------------------------+
| 통합지도                                                             |
+----------------------------------------------------------------------+
| 메뉴 | [측정] [주소검색] [메모] [소유구분] [주제도] [레이어]         |
| - 지도 +----------------------------------------------------+        |
| - 측정 |                                                    |        |
| - 주소 |              (지도 영역)                           |        |
| - 메모 |   +-------------+                                  |        |
| - 소유 |   | 소유구분  X |                                  |        |
| - 주제 |   | 전체선택|해제|                                 |        |
|        |   | v 소유자정보 |                                 |        |
|        |   | [색] 국유지  [x]|                              |        |
|        |   | [색] 군유지  [ ]|                              |        |
|        |   +-------------+  [+][-][현위치]                  |        |
|        +----------------------------------------------------+        |
+----------------------------------------------------------------------+
```

#### 설명

1. 우측 «소유구분»을 누르면 주제도 패널과 같은 형태의 목록이 열린다.
2. 목록은 소유자정보 그룹만 보이며 전체 선택·해제가 가능하다.
3. 체크한 항목만 지도에 표시되고, 닫기나 버튼을 다시 누르면 패널만 닫힌다.
4. 데이터가 아직 없으면 목록이 비어 있거나 안내만 보인다.

#### 확인사항

1. «소유구분» 선택 시 패널이 열리고 버튼이 선택된 상태로 보여야 한다.
2. 주제도 패널과 동시에 같은 목록이 섞여 나오지 않아야 한다.
3. 체크를 모두 끄면 지도에서 소유구분 레이어가 꺼져야 한다.
4. 지목·주제도 버튼 동작은 이전과 같아야 한다.
