## 개발목표

접도구역 건축물 관리대장을 화면에만 두지 않고 저장소에 둔다. 한 장의 대장에 건축물 내용·확인 결과·도면 사진이 여러 건 달린다. 목록·상세·저장·삭제는 서버를 통해 한다. 이번은 저장 구조와 조회·저장 연결까지 만든다. 화면 칸 배치는 바꾸지 않는다.

## 플로우차트

```
목록 → 상세 → 저장 → 저장소 → 목록
```

## 화면설계

### RFB-API-01 저장

```
┌────────────────────────────────────────┐
│ 접도구역 건축물              저장 닫기 │
│ 도로의 종류 · 위치 · 소유자            │
│ 건축물 내용 · 확인 결과 · 도면 사진    │
└────────────────────────────────────────┘
```

#### 설명

1. 저장을 누르면 관리대장과 딸린 내용·확인·사진이 함께 저장된다.
2. 목록은 저장소에서 다시 읽는다.
3. 삭제는 목록에서 빠지고 딸린 건도 함께 지워진다.

#### 확인사항

1. 저장 후 새로고침해도 같은 대장이 남아야 한다.
2. 건축물 내용·확인 결과가 대장과 같이 저장되어야 한다.
3. 삭제한 대장은 목록에 없어야 한다.
