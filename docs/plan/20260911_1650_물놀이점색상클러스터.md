## 개발목표

물놀이 표지판을 열면 표지판 점은 파란 그림, 구조함 점은 주황 그림으로 구분한다. 지도를 축소하면 가까운 점끼리 묶어 개수를 보여 주고, 확대하면 묶음이 풀려 개별 위치가 보인다. 개별 점에는 글자를 붙이지 않는다.

## 플로우차트

```
부서업무 열림 → 축소(개수 묶음) → 확대 → 개별 위치(파란 표지판·주황 구조함)
```

## 화면설계

### MAP-WPS-CL-01 축소 개수 묶음

```
┌──────┬────────────────────────────────────────────┐
│ 메뉴 │  지도에서 분석할 필지를 클릭하세요    [종료] │
│      │                                            │
│ 부서 │     ┌──┐                                   │
│ 업무 │     │5 │  주황 묶음(구조함)                  │
│      │     └──┘                                   │
│ 물놀 │          ┌──┐                              │
│ 이표 │          │2 │  파란 묶음(표지판)             │
│ 지판 │          └──┘                              │
│      │                                            │
├──────┤  물놀이 표지판                              │
│목록  │  구분 │ 주소 │ 제목                         │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 축소된 지도에서는 가까운 점을 묶어 가운데에 개수만 보여 준다.
2. 구조함 묶음은 주황, 표지판 묶음은 파랑이다.
3. 종류가 다르면 한 묶음으로 합치지 않는다.

#### 확인사항

1. 축소 시 겹친 자리에 개수가 보여야 한다.
2. 주황 숫자와 파란 숫자가 섞여 한 묶음이 되지 않아야 한다.
3. 묶음 옆에 주소 글자는 없어야 한다.

### MAP-WPS-CL-02 확대 개별 위치

```
┌──────┬────────────────────────────────────────────┐
│ 메뉴 │                                            │
│      │      ● 주황 십자(구조함)                    │
│ 부서 │                                            │
│ 업무 │         ● 파란 금지(표지판)                 │
│      │                                            │
│      │      ● 주황 십자(구조함)                    │
│      │                                            │
├──────┤  물놀이 표지판                              │
│목록  │  구분 │ 주소 │ 제목                         │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 확대하면 묶음이 풀리고 점마다 그림이 나온다.
2. 표지판은 파란 원 안 금지 표시, 구조함은 주황 원 안 십자이다.
3. 개별 점에는 주소 글자를 붙이지 않는다.

#### 확인사항

1. 확대한 뒤 표지판과 구조함 색·그림이 달라야 한다.
2. 개별 점 옆에 숫자가 남아 있지 않아야 한다.
3. 상세에서 필지 선이 나와도 점이 선 위에 보여야 한다.
