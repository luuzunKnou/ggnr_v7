## 개발목표

공간분석 «단수구역»에서 제수변을 잠그고 단수 범위를 지도에 그린다. 분석 결과는 이력으로 남아 다시 열어 볼 수 있다. 필지·도로명주소·수용가를 보고 단수 문자를 보낸다. 이번 단계는 예시 데이터와 화면·지도 표현까지다.

## 플로우차트

```
이력목록 ⇄ 신규분석 → 제수변선택·잠금 → 분석실행 → 지도·대상목록 → 문자발송 → 이력저장
```

## 화면설계

### SPA-OUT-01 단수구역

```
┌──────사이드────────┬──────────지도──────────┐
│ 공간분석            │  ░ 단수범위             │
│ [단수][누수][송수][위상]│ ● 잠근 제수변          │
│────────────────────│                        │
│ 분석 이력           │                        │
│ · 일시 · 제수변 ·상태│                        │
│ [새 분석]           │                        │
│────────────────────│                        │
│ 제수변 · 잠금/해제  │                        │
│ [분석실행]          │                        │
│────────────────────│                        │
│ [필지][도로명][수용가]│                        │
│ 목록 · [문자발송]   │                        │
└────────────────────┴────────────────────────┘
```

#### 설명

1. «단수구역» 탭만 이 화면을 채운다.
2. 이력 행을 누르면 그때 잠근 제수변·범위·대상이 복원된다.
3. 새 분석에서는 지도 또는 목록에서 제수변을 고르고 잠근 뒤 분석을 실행한다.
4. 분석 후 필지·도로명·수용가 목록이 나오고 문자를 보낼 수 있다.

#### 확인사항

1. 잠금 전에는 분석실행이 비활성이어야 한다.
2. 이력 복원 시 지도에 단수 면과 제수변이 다시 보여야 한다.
3. 문자 모달에 제목·사유·시작·종료가 있어야 한다.

### SPA-OUT-02 단수 문자

```
┌──────단수 문자──────┐
│ 제목                 │
│ 단수사유             │
│ 시작 · 종료          │
│ 미리보기             │
│ 대상 건수            │
│ [발송] [취소]        │
└─────────────────────┘
```

#### 설명

1. 수용가 중 연락처가 있는 건을 대상으로 한다.
2. 발송하면 해당 이력 상태가 문자발송으로 바뀐다.

#### 확인사항

1. 시작이 종료보다 늦으면 발송이 막혀야 한다.
2. 연락처 없는 수용가는 발송 대상에서 빠져야 한다.
