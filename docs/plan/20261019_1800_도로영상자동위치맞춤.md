## 개발목표

서버가 10분마다 도로대장 첨부 폴더의 도로영상 중 위치 맞춤 자료가 없는 영상을 한 개씩 분석한다. 영상 화면의 회전·전진을 노선 굽이·거리에 맞춰 시각별 노선 위치를 구하고, 영상 정보와 시각별 위치를 DB 두 테이블에 저장한다. 교차로에서 한 바퀴 도는 구간은 교차시설 면이 노선과 겹치는 곳에서만 제자리 회전으로 처리하고, 노선 방향(시작→끝, 반대)은 자동 판단한다.

도로대장 상세의 «도로영상»은 지도를 덮던 화면에서 이동·크기 조절 창으로 바꾼다. 재생 위치에 맞춰 지도에 자동차 모양이 노선 위를 진행 방향으로 움직이고, 자동차를 끌거나 노선을 누르면 영상이 그 장면으로 옮겨 간다. 분석 전 영상은 노선 시작~끝을 시간 비율로 나눈 위치로 보여 준다.

영향 받는 기능: 도로대장 상세(보고서·도면 버튼), 서버 기동 시 스케줄러 등록, Python 환경 설치(개발자 모드), 지도 그리기·측정과의 동시 사용.

## 플로우차트

```
첨부 폴더 영상 → (10분마다) 위치 맞춤 분석 → DB 저장 → 도로대장 상세 → 도로영상 창 ⇄ 지도 자동차
```

## 화면설계

### ROAD-VIDEO-01 도로영상 창

```
┌────┬──────────────────┬────────────────────────────────────────────────────┐
│메뉴│ 도로대장 상세     │   ┌ 군도12호선 도로영상   상행  하행      ─  ✕ ┐   │
│    │                  │   │                                          │   │
│    │ 보고서 도면 ...   │   │              360° 영상                   │   │
│    │ 도로영상          │   │                                          │   │
│    │                  │   │ ▶ ━━━━━●━━━━━━━  2:31 / 10:13  －  ＋  ⛶ │   │
│    │                  │   │ 자동 위치 맞춤 완료         ☑ 지도 따라가기 │   │
│    │                  │   └──────────────────────────────────────────┘   │
│    │                  │                         지도                       │
└────┴──────────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 도로대장 상세에서 «도로영상»을 누르면 지도 위에 영상 창이 뜨고 지도는 그대로 보인다.
2. 창은 제목줄을 끌어 옮기고 오른쪽 아래 모서리를 끌어 크기를 바꾸며, 접기와 닫기가 있다.
3. 제목줄에서 상행·하행을 바꾸고, 아래에 재생·탐색 막대, 확대·축소, 전체화면이 있다.
4. 맨 아래 줄에 위치 맞춤 상태(«자동 위치 맞춤 완료», «위치 분석 대기 중 — 시간 비율 위치», «위치 분석 실패 — 시간 비율 위치»)와 «지도 따라가기»가 있다.

#### 확인사항

1. 영상 창이 떠 있어도 지도를 움직이고 확대할 수 있어야 한다.
2. 창을 옮기고 크기를 바꿔도 영상이 끊기지 않아야 한다.
3. 상행·하행을 바꾸면 그 영상의 위치 맞춤 상태가 다시 표시되어야 한다.
4. 전체화면에서도 재생과 닫기가 되어야 한다.

### ROAD-VIDEO-02 지도 자동차 위치

```
┌────┬──────────────────┬────────────────────────────────────────────────────┐
│메뉴│ 도로대장 상세     │                                                    │
│    │                  │     ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━       │
│    │                  │       ━━━━━━━━━━━━━━ 🚗 ─ ─ ─ ─ ─ ─ ─ ─ ─          │
│    │                  │                                                    │
│    │                  │   ┌ 군도12호선 도로영상   상행  하행      ─  ✕ ┐   │
│    │                  │   │ ▶ ━━━━━●━━━━━━━  5:10 / 10:13           │   │
│    │                  │   └──────────────────────────────────────────┘   │
└────┴──────────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 영상이 재생되는 동안 지도에 자동차 모양이 노선 위를 따라 움직이고 진행 방향으로 돌아간다.
2. 노선 전체를 옅게, 지나온 구간을 진하게 표시한다.
3. 창을 처음 열면 지도가 노선 전체가 보이게 맞춰진다.
4. «지도 따라가기»를 켜면 자동차가 화면 가장자리에 가면 지도가 따라 움직인다.

#### 확인사항

1. 재생 중 자동차가 노선 선을 벗어나지 않아야 한다.
2. 하행 영상에서는 자동차가 노선 끝에서 시작 쪽으로 움직여야 한다.
3. 영상을 멈추면 자동차도 멈춰야 한다.
4. 교차로를 한 바퀴 도는 장면에서는 자동차가 교차로 근처에 머물러야 한다.

```
│    │                  │   │ ▶ ━━━━━━━━━━●━━  7:45 / 10:13           │   │
│    │                  │   └──────────────────────────────────────────┘   │
└────┴──────────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 자동차를 끌어 노선 위 다른 곳에 놓으면 영상이 그 위치 장면으로 옮겨 간다.
2. 노선 가까이를 누르면 가장 가까운 노선 위 지점의 장면으로 영상이 옮겨 간다.
3. 끄는 동안에는 자동차만 노선에 붙어 움직이고, 놓을 때 영상을 한 번 옮긴다.

#### 확인사항

1. 노선에서 먼 곳에 놓아도 가장 가까운 노선 위 지점으로 붙어야 한다.
2. 영상을 옮긴 뒤 재생하면 자동차가 그 자리부터 움직여야 한다.
3. 측정·공간검색 같은 지도 그리기가 켜져 있으면 노선 누르기로 영상이 옮겨 가지 않아야 한다.

### ROAD-VIDEO-04 자동 위치 맞춤 (화면 없음, 서버 작업)

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 서버 작업 기록                                                            │
│                                                                          │
│ 도로영상 위치 맞춤  군도12호선 상행  분석 시작                             │
│ 도로영상 위치 맞춤  군도12호선 상행  완료  노선 시작→끝  기준점 614개       │
│ 도로영상 위치 맞춤  군도12호선 하행  완료  노선 끝→시작  기준점 601개       │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 서버가 10분마다 도로대장 첨부 폴더의 영상 목록을 읽고, DB에 같은 파일(이름·크기·수정시각) 기록이 없는 영상을 한 개 고른다.
2. 노선 선형과 노선에 겹치는 교차시설 구간을 읽어 분석 도구에 넘기고, 끝나면 영상 정보와 1초 간격 노선 위치를 저장한다.
3. 분석 중에는 다음 확인을 건너뛰고, 실패하면 실패 사유를 저장해 같은 파일은 다시 시도하지 않는다.
4. 영상 파일이 바뀌면 이전 결과를 지우고 다시 분석한다.

#### 확인사항

1. 서버 기동 직후에는 분석이 바로 돌지 않고 10분 주기에 맞춰 시작해야 한다.
2. 분석이 끝난 영상은 다음 주기에 다시 분석되지 않아야 한다.
3. 분석 도구가 없는 서버에서는 실패 사유가 남고 다른 기능에 영향이 없어야 한다.
4. 스케줄러 끄기 설정을 하면 등록되지 않아야 한다.
