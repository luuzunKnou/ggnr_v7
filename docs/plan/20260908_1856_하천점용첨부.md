## 개발목표

울진 하천점용 상세에만 공사대장과 같은 첨부 영역을 둔다. 점사용료 이력 아래에 두고, 파일은 저장소 폴더에 점용 키로 둔다. 공통점용에는 넣지 않는다.

## 플로우차트

```
하천점용 상세 → 점사용료 이력 → 첨부파일 → (저장 후) 올리기·미리보기·내려받기
```

## 화면설계

```

└────┴──────────┴──────────────────────────────────────┘
```

#### 설명

1. 저장된 건의 상세에서만 첨부 영역이 점사용료 이력 아래에 보인다.
2. 머리글·전체 내려받기·올리기·폴더 탭·미리보기 칸은 공사대장과 같다.
3. 아직 저장하지 않은 등록 화면에는 첨부 영역을 두지 않는다.
4. 공통점용 상세에는 이 영역을 넣지 않는다.

#### 확인사항

1. 하천점용 상세를 열면 점사용료 이력 아래에 첨부파일이 보여야 한다.
2. 저장한 뒤에만 파일을 올릴 수 있어야 한다.
3. 올린 파일이 미리보기·내려받기·삭제로 다뤄져야 한다.
4. 공통점용 상세에는 첨부 영역이 없어야 한다.
