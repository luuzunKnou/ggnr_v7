## 개발목표

개발자 모드 «시스템관리» 그룹에 «시스템 통합제어» 메뉴를 추가하고, 최고 관리자(su)만 보고 바꿀 수 있게 한다. 항목별 켜기·끄기는 통합제어 테이블에 저장한다.

첫 항목은 «개인정보 마스킹»이며, 켜면 필지정보 소유자명과 공유인·변동연혁 모달의 소유자가 모든 사용자에게 * 로 표시된다. 시스템 변수에서 관리하던 마스킹 값과 최고 관리자 예외는 제거한다. 두 번째 항목으로 «드론영상 고화질 제한»을 두고, 드론영상 패널의 기존 스위치와 같은 값을 쓴다.

영향 받는 기능: 개발자 모드 메뉴, 필지정보(우클릭 주소정보 등 필지정보 패널), 콘솔 메뉴 권한 목록.

## 플로우차트

```
개발자 모드 → 시스템관리 → 시스템 통합제어 → (켜기·끄기) → 저장 → 필지정보 소유자명 표시
```

## 화면설계

### DEV-CTRL-01 시스템 통합제어

```
┌──────────────────────────────────────────────────────────────────────┐
│ 개발자 모드                                               로그아웃   │
├──────────────────┬───────────────────────────────────────────────────┤
│ 시스템관리       │ 시스템 통합제어                                   │
│   시스템 목록관리│ 시스템 전체에 적용되는 기능을 켜고 끕니다.        │
│   기능 목록관리  ├───────────────────────────────────────────────────┤
│   시스템 변수    │                                      [새로고침]   │
│   시스템 통합제어│ ┌────────────────┬──────────────────────┬───────┐ │
│   프로젝트 구성  │ │ 항목           │ 설명                 │ 사용  │ │
│ 데이터관리       │ ├────────────────┼──────────────────────┼───────┤ │
│ 시스템 사용현황  │ │ 개인정보 마스킹│ 필지정보 소유자명 *  │ [ON ] │ │
│ 기타기능         │ └────────────────┴──────────────────────┴───────┘ │
│ 버전관리         │                                                   │
└──────────────────┴───────────────────────────────────────────────────┘
```

#### 설명

1. 개발자 모드 좌측 «시스템관리» 그룹의 «시스템 변수» 아래에 «시스템 통합제어»가 보인다.
2. 항목마다 이름·설명·사용 스위치가 한 줄로 보인다.
3. 스위치를 바꾸면 즉시 저장되고, 실패하면 이전 상태로 되돌린다.
4. su 계정으로 로그인하지 않았으면 메뉴 자체가 보이지 않는다.

#### 확인사항

1. su 계정에서만 «시스템 통합제어» 메뉴가 보여야 한다.
2. 다른 계정이나 비로그인 상태에서는 메뉴가 보이지 않고, 직접 호출해도 조회·저장이 거부되어야 한다.
3. 스위치를 바꾼 뒤 새로고침해도 바뀐 값이 유지되어야 한다.
4. 개인정보 마스킹을 켜면 su 계정에서도 필지정보 소유자명이 * 로 보여야 한다.
