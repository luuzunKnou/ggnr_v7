## 개발목표

업무자료(문서·도면) 원본을 소스 폴더가 아니라 프로젝트 데이터 폴더 아래 업무자료 위치에 둔다. 화면 구성과 업로드·미리보기 흐름은 그대로 두고, 저장 위치만 바꾼다. 문서와 도면은 그 안에서 구분해 둔다.

## 플로우차트

```
업무자료 → 문서·도면 목록 → 데이터폴더 업무자료 → 열람·업로드
```

## 화면설계

### MAP-DOC-01 업무자료 도면 탭

```
┌─────────────────────────────────────────────────────────────┐
│ 검색                                                        │
├────┬──────────────────────────────────────────┬─────────────┤
│메뉴│ 지도                                     │             │
│    │                                          │ 업무자료    │
│    │                                          │ 편람 문서 도면│
│    │                                          │ (파일 없음) │
│    │                                          │ [업로드]    │
└────┴──────────────────────────────────────────┴─────────────┘
```

#### 설명

1. 화면 배치와 탭은 기존과 같다.
2. 목록이 비면 도면 파일이 없다는 안내만 보인다.
3. 업로드하면 데이터 폴더의 업무자료 위치에 저장된다.
4. 미리보기용 그림도 원본과 같은 폴더에 만든다.

#### 확인사항

1. 문서·도면 목록이 데이터 폴더 기준으로 나와야 한다.
2. 업로드한 파일이 소스 폴더가 아닌 데이터 폴더에 있어야 한다.
3. 폴더가 없어도 빈 목록으로 열려야 한다.
4. 다른 지도 메뉴는 그대로여야 한다.
