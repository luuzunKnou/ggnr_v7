## 개발목표

하천 시스템 사이드바에 «사유지분석» 메뉴를 추가한다. 대상 레이어를 고른 뒤 지도에서 하천 위를 두 번 찍어 시작선·끝선을 정하고, 적용한 구간과 겹치는 필지 전체를 소유구분·주소로 걸러 보는 목록과 오른쪽 상세 패널을 제공한다.

도로 시스템은 이번 범위에서 제외한다. 하천기본계획 상세의 기존 사유지 기능은 건드리지 않는다.

## 플로우차트

```
사유지분석 메뉴 → 레이어 선택 → (지도 찍기) 시작선 → (이동·찍기) 끝선 → 적용 → 분석 → 필지 목록 ⇄ 필지 상세
```

## 화면설계

### MAP-PLA-01 레이어 선택

```
┌────┬──────────────────────┬──────────────────────────────────────┐
│    │ 사유지분석         ✕ │        [ 주소 검색            ]      │
│ 메 ├──────────────────────┤                                      │
│ 뉴 │ 분석할 레이어를 선택 │   ( 분석할 레이어를 선택하세요 )     │
│    │                      │                                      │
│    │ ○ 하천구역           │                                      │
│    │ ○ 소하천구역         │                                      │
│    │                      │                                      │
│    │ 분석 구간            │                                      │
│    │ 레이어를 먼저 선택   │                                      │
│    │                      │                                      │
│    │ [적용]      [분석]   │                                      │
└────┴──────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 사이드바 «사유지분석»을 누르면 왼쪽에 사유지분석 패널이 열린다.
2. 패널 상단에 하천 대상 레이어(하천구역·소하천구역)가 선택 목록으로 보인다.
3. 지도 상단 안내에 «분석할 레이어를 선택하세요»가 보인다.
4. 적용·분석 버튼은 구간 지정 전까지 꺼져 있다.

#### 확인사항

1. 하천 시스템 사이드바에 «사유지분석» 메뉴가 보여야 한다.
2. 레이어를 고르기 전에는 지도를 찍어도 아무것도 생기지 않아야 한다.
3. 적용·분석 버튼이 꺼진 상태로 보여야 한다.

### MAP-PLA-02 구간 지정

```
┌────┬──────────────────────┬──────────────────────────────────────┐
│    │ 사유지분석         ✕ │        [ 주소 검색            ]      │
│ 메 ├──────────────────────┤                                      │
│ 뉴 │ 분석할 레이어를 선택 │ ( 끝 위치를 찍으세요          ✕ )    │
│    │                      │                                      │
│    │ ○ 하천구역           │    ┃░░░░░░░░░░░░░░░░░░░┃   하천       │
│    │ ○ 소하천구역         │    ┃░░░░░░░░░░░░░░░░░░░┃              │
│    │                      │    ━━━━━━━━━━━━━━━━━━━━━━━━━━        │
│    │ 분석 구간            │                                      │
│    │ 끝 위치 지정 중      │                                      │
│    │                      │                                      │
│    │ [적용]      [분석]   │                                      │
└────┴──────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 레이어를 고르면 지도에 그 레이어가 켜지고 안내가 «하천 위에서 시작 위치를 찍으세요»로 바뀐다.
2. 레이어 범위 밖을 찍으면 «선택한 레이어 범위가 아닙니다» 안내만 나온다.
3. 레이어 위를 찍으면 그 지점에서 하천 양쪽 경계까지 가장 짧게 가로지르는 시작선이 생긴다.
4. 하천을 따라 마우스를 움직이면 같은 방식의 끝선이 따라오고, 두 선 사이 하천 구간이 하천 모양 그대로 반투명으로 보인다.
5. 다시 찍으면 끝선이 정해지고 «적용» 버튼이 켜진다.

#### 확인사항

1. 레이어 밖에서는 시작선이 생기지 않아야 한다.
2. 시작선이 하천 폭 방향으로 양쪽 경계까지 그려져야 한다.
3. 마우스를 움직이는 동안 두 선 사이 구간이 보여야 한다.
4. 끝선이 정해지기 전에는 적용 버튼이 꺼져 있어야 한다.

### MAP-PLA-03 적용·분석

```
┌────┬──────────────────────┬──────────────────────────────────────┐
│    │ 사유지분석         ✕ │        [ 주소 검색            ]      │
│ 메 ├──────────────────────┤                                      │
│ 뉴 │ 하천구역             │ ( 분석을 눌러 필지를 조회하세요 ✕ )  │
│    │ 분석 구간  적용됨    │                                      │
│    │                      │    ━━━━━━━━━━━━━━━━━━━━━━━━━━        │
│    │ [영역변경] [재설정]  │    ┃▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓┃   하천       │
│    │                      │    ┃▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓┃              │
│    │ [적용]      [분석]   │    ━━━━━━━━━━━━━━━━━━━━━━━━━━        │
│    │                      │                                      │
└────┴──────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. «적용»을 누르면 두 선 사이 하천 구간만 잘라 지도에 파랗게 표시한다.
2. 적용이 끝나면 «분석» 버튼이 켜진다.
3. 두 선 사이 구간을 찾지 못하면 안내를 띄우고 구간을 다시 지정하게 한다.

#### 확인사항

1. 적용 후 두 선 사이 하천만 표시되어야 한다.
2. 적용 전에는 분석 버튼이 꺼져 있어야 한다.
3. 구간을 찾지 못하면 안내가 나와야 한다.

### MAP-PLA-04 필지 목록·상세

```
┌────┬──────────────────────┬────────────────────┬─────────────────┐
│    │ 사유지분석         ✕ │ 필지 상세        ✕ │ [ 주소 검색 ]   │
│ 메 ├──────────────────────┼────────────────────┤                 │
│ 뉴 │ 하천구역 총 42건     │ 필지 정보          │                 │
│    │ [영역변경] [재설정]  │ 주소   ○○리 123    │                 │
│    │ [ 주소 검색        ] │ 지목   답          │      지도       │
│    │ [전체][개인][국유지] │ 필지면적  1,200㎡  │                 │
│    │ [군유지][법인][기타] │ 편입면적    320㎡  │                 │
│    │ ┌──────────────────┐ │ 소유구분 개인      │                 │
│    │ │No 주소 소유  면적│ │                    │                 │
│    │ │1  ○○리 개인 320㎡│ │ 소유 정보          │                 │
│    │ │2  ○○리 국유 120㎡│ │ 소유자명  홍○○     │                 │
│    │ │3  ○○리 개인  80㎡│ │ 공유인수  1        │                 │
│    │ └──────────────────┘ │ 변동원인  매매     │                 │
└────┴──────────────────────┴────────────────────┴─────────────────┘
```

#### 설명

1. «분석»을 누르면 구간과 겹치는 필지 전체가 목록으로 나오고 지도에 필지가 표시된다.
2. 목록 위에서 소유구분 칩과 주소 검색으로 거를 수 있으며, 칩마다 건수가 보인다.
3. 필지를 누르면 오른쪽 상세 패널에 필지 정보와 소유 정보가 나오고 지도가 그 필지로 이동해 강조된다.
4. 지도에서 필지를 눌러도 같은 필지가 목록에서 선택된다.
5. «영역변경»은 레이어는 그대로 두고 구간 지정부터, «재설정»은 레이어 선택부터 다시 시작한다.

#### 확인사항

1. 소유구분 칩을 누르면 해당 구분 필지만 목록에 남아야 한다.
2. 주소 검색어가 포함된 필지만 보여야 한다.
3. 필지 선택 시 오른쪽 상세 패널이 열려야 한다.
4. 영역변경·재설정 후 목록·상세·지도 표시가 모두 지워져야 한다.
5. 메뉴를 닫으면 지도에 그린 선·구간·필지가 남지 않아야 한다.
