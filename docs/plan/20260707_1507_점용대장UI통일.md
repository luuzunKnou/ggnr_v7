## 개발목표

도로점용·하천점용·국공유지 점용대장의 목록·상세·지도 연동을 **하나의 공통 화면**으로 통합한다. 지금 구현의 레이아웃·검색·표·필지 입력은 **거의 그대로** 두고, 유형별 차이(열·분석 버튼·속성)만 **설정 한 곳**에서 나눈다.

화면은 **메뉴 | 목록 | 상세 | 지도** 4열이다. 목록이 먼저 열리고, 헤더에 **추가·닫기**(도로만 **도로점용 분석**), 아래 **검색·표**가 온다. 행 클릭 시 목록 옆에 상세가 붙는다. 상세 탭은 **기본 · 공시지가 · 점사용료** 3개이다.

**지도** — 지도에 원래 있는 **지적도·거리·면적·고도·확대축소** 등은 **그대로 둔다**. 점용 패널에서 **같은 기능을 또 만들지 않는다**. 수정·등록 중에만 점용 전용 **도형추가·초기화·도형삭제** UI가 지도에 추가된다.

**물건지목록** — 화면 정의(와이어프레임·동작)를 **먼저** 잡고, 소스에는 **필요한 유형만** 붙인다. **1차는 하천만** 적용한다. 도로·국공유지 등은 나중에 필요하면 같은 정의를 기준으로 추가한다.

**점용대장 알림** — 하루 한 번 점검해 **점용 종료일 경과**·**점사용료 미납** 건을 공통 알림(`20260713_1351_로그인알림모달`)으로 보낸다. 금액·납부 관련이므로 **중요 알림 자동**(별도 체크 없음). 알림 항목 클릭 시 해당 유형 점용대장 목록·상세로 연다.

## 플로우차트

점용 메뉴 → 목록·검색 → (행 클릭) 상세 → 기본·공시지가·점사용료 탭 → (수정) 필지·물건지 → (지도) 도형 편집 → 저장 / (도로) 분석 모달 / (알림) 만료·미납 → 점용 상세

## 화면설계

와이어프레임은 **점용 패널 영역**만 그린다. 오른쪽 열은 **점용 업무용 지도** — 기존 지도 도구는 유지, **점용 패널 전용 UI만** 추가로 겹친다.

**목록 열(유형별)**

- 도로점용: 허가번호 · 점용장소 · 점용면적 · 점용시작일 · 점용종료일
- 하천점용: 부과번호 · 소재지 · 부과연도 · 부과일자
- 국공유지: 국유/공유 · 소재지 · 사용시작일 · 사용종료일

**상세 탭**

- **기본** — 속성·필지목록·(유형에 붙인 경우) 물건지목록 — **1차 하천만**
- **공시지가** — 기본 탭 필지목록 지번 + 인접지번 금액 비교
- **점사용료** — 부과·납부 이력(UI 틀, 차세대 연계 전)

#### 설명

2. 유형마다 **열 이름(컬럼)만** 다르다.

5. 와이어프레임 위치는 공통 알림과 같이 **사이드바 하단에 맞춘 아래 정렬**이다.

#### 확인사항

1. 종료일 경과·미납 건수가 실제 데이터와 맞아야 한다.
2. 점용대장 알림은 모두 **중요**로 표시되어야 한다.
3. 스케줄은 하루 1회만 실행되어 중복 알림이 쌓이지 않아야 한다.

### MAP-USELDG-NOTIF-02 점용대장 알림 → 상세 이동

```
+------------------------------------------------------------------------+
|+---+  +-- 알림 --------------------------- [지우기] --+                |
||알 |  |  ▼ 점용 기간 만료된 건이 3건 있습니다        |                |
||림 |  |     · 하천 ○○지 2024-부과-012    [삭제]    |                |
||   |  |     · 도로 ○○로 123  허가-001    [삭제]    |                |
||사 |  |     · 국공유지 ○○동 45           [삭제]    |                |
||용 |  |  ▶ 점사용료 미납 건이 2건 있습니다           |                |
||자 |  +-----------------------------------------------+                |
|+---+                         지도                                      |
+------------------------------------------------------------------------+
```

#### 설명

1. 건별 목록에 **유형·제목**(허가번호·부과번호·소재지 등)을 표시한다.
2. 항목 클릭 시 해당 **점용대장 메뉴**를 열고 목록·상세에 해당 건을 선택한다.
3. 상세 조회 후 알림에 **읽음** 표시가 된다.
4. 항목 **[삭제]** 로 해당 알림만 제거한다.
5. 미납·만료가 해소되면 다음 스케줄에서 새 알림을 만들지 않는다(또는 기존 건 갱신 규칙은 구현 시 확정).

#### 확인사항

1. 하천·도로·국공유지 각각 올바른 목록·상세로 열려야 한다.
2. 알림에서 연 상세와 지도 위치가 일치해야 한다.
3. 읽음·삭제 후 알림 모달 목록이 갱신되어야 한다.
