## 개발목표

지적기록물 목록이 7~8초 걸리는 원인을 줄이기 위해, 파일명·경로로 찾을 때 쓰는 검색용 인덱스를 기록물 표에 단다. 조회문도 인덱스를 탈 수 있게 맞춘다.

## 플로우차트

```
지도 → 지적기록물 목록(인덱스 조회) → 파일 목록
```

## 화면설계

### MAP-ARCHIVE-15 목록 속도

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│메뉴│ 지적기록물                 X │                                      │
│    ├──────────────────────────────┤                                      │
│지적│ [전체 읍면동▼] [지번·권    ] │                                      │
│기록│ 종류        파일        지번 │                                      │
│물  │ …                            │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. 목록은 자료 폴더 파일명으로 표를 찾되, 인덱스로 해당 행만 읽는다.
2. 화면 구성은 그대로이다.

#### 확인사항

1. 지적기록물 목록이 수 초 안에 나와야 한다.
2. 파일이 있는 장만 나와야 한다.
3. 지번 검색·상세 미리보기는 이전과 같아야 한다.
