## 개발목표

메인에 상수행정 업무지원과 하수행정 업무지원을 추가한다. 메뉴는 데이터조회, 변동이력분석, 필지분석, 민원관리, 메모관리, 도형편집기만 둔다. 영양군 사용 시스템에 넣어 포털에 보이게 한다.

## 플로우차트

메인 → 상수행정 업무지원 → 데이터조회·변동이력분석·필지분석·민원관리·메모관리·도형편집기

## 화면설계

### IDX-WTL-01 상수행정 업무지원 카드

```
┌──────────────────────────────────────────────┐
│ 메인                                         │
│  [상수행정 업무지원 시스템]                  │
│  #데이터조회 #변동이력 #필지분석 #민원       │
└──────────────────────────────────────────────┘
```

#### 설명

1. 메인에 «상수행정 업무지원 시스템» 카드가 보인다.
2. 들어가면 데이터조회, 변동이력분석, 필지분석, 민원관리, 메모관리, 도형편집기만 있다.

#### 확인사항

1. 상수행정 업무지원 카드가 나와야 한다.
2. 요청한 여섯 메뉴만 보여야 한다.

### IDX-SWL-01 하수행정 업무지원 카드

```
┌──────────────────────────────────────────────┐
│ 메인                                         │
│  [하수행정 업무지원 시스템]                  │
│  #데이터조회 #변동이력 #필지분석 #민원       │
└──────────────────────────────────────────────┘
```

#### 설명

1. 메인에 «하수행정 업무지원 시스템» 카드가 보인다.
2. 메뉴 구성은 상수행정과 같다.

#### 확인사항

1. 하수행정 업무지원 카드가 나와야 한다.
2. 기존 상수도·하수도 통합관리 카드와 별도로 보여야 한다.
