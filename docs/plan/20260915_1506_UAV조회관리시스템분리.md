## 개발목표

울산 UAV를 조회용·관리용 두 시스템으로 나눈다. 조회에는 영상조회와 본인 촬영요청을 두고, 관리에는 종류별 영상관리·승인·지상기준점·레이어권한을 둔다. 시스템 전환으로 메뉴를 바로 확인할 수 있게 한다.

## 플로우차트

시스템선택 → 조회(영상조회·촬영요청) ⇄ 관리(영상관리·승인·권한)

## 화면설계

### UAV-SYS-01 조회 시스템

```
┌──────────────────────────────────────────────────────────────┐
│ 시스템: UAV공간정보조회시스템                                 │
│ ┌────┐ ┌────────────────────────────────────────┐ ┌──────┐ │
│ │영상│ │ 지도 · 드론영상 on/off · 촬영요청 단축  │ │우측  │ │
│ │조회│ │                                        │ │컨트롤│ │
│ │촬영│ │                                        │ │      │ │
│ │요청│ │                                        │ │      │ │
│ └────┘ └────────────────────────────────────────┘ └──────┘ │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 시스템 목록에서 조회용을 고르면 사이드바에 영상조회·촬영요청 등 조회 메뉴만 보인다.
2. 영상조회는 등록된 자료를 종류별로 보기만 한다.
3. 촬영요청은 본인 신청·상태 확인용이다.
4. 우측 단축으로 드론영상·촬영요청을 바로 쓸 수 있다.

#### 확인사항

1. 조회 시스템에 승인관리·레이어권한이 없어야 한다.
2. 영상조회·촬영요청이 사이드바에 보여야 한다.
3. 우측 드론영상·촬영요청이 동작해야 한다.

### UAV-SYS-02 관리 시스템

```
┌──────────────────────────────────────────────────────────────┐
│ 시스템: UAV공간정보관리시스템                                 │
│ ┌────┐ ┌────────────────────────────────────────┐ ┌──────┐ │
│ │드론│ │ 지도 · 관리·승인 작업                   │ │우측  │ │
│ │파노│ │                                        │ │컨트롤│ │
│ │승인│ │                                        │ │      │ │
│ │권한│ │                                        │ │      │ │
│ └────┘ └────────────────────────────────────────┘ └──────┘ │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 관리 시스템을 고르면 종류별 영상관리·승인관리·지상기준점·레이어권한이 보인다.
2. 업로드·변환·승인·권한 설정은 여기에서만 한다.
3. 우측 단축도 동일하게 쓸 수 있다.

#### 확인사항

1. 관리 시스템에 종류별 영상관리·승인관리가 보여야 한다.
2. 레이어권한·지상기준점이 보여야 한다.
3. 시스템 전환 시 메뉴가 서로 바뀌어야 한다.
