# 작업계획서

2026-07-31 | 200BingSu | 분할지도

## 개발목표

지도 화면을 좌우 두 개의 지도로 나눠 같은 지역을 서로 다른 배경·레이어로 비교한다. 거리뷰 분할에서 쓰는 분할 화면 틀과 분할선을 그대로 재사용하고, 분할 지도를 하나 더 띄운다.

분할선 가운데 컨트롤 구역에 «분할선 이동/잠금», «이동 싱크», «배경지도 싱크», «분할 종료» 네 가지를 둔다. 이동 싱크와 레이어 싱크는 각각 켜고 끌 수 있어, 두 지도를 함께 움직이며 배경만 바꿔 보거나 아예 다른 위치를 나란히 볼 수 있다.

## 플로우차트

```
지도 → 지도분할 → 좌우 두 지도 ⇄ (이동 싱크·레이어 싱크 전환) → 분할 종료 → 지도
```

## 기능 목록

### 1. 지도 안에서의 조작
1. 마지막 위치·확대 수준·배경지도를 브라우저에 저장하는 값은 좌측 지도를 기준으로 한다. 
2. 지도 내 레이어 객체 선택시 좌우 지도 모두 해당 객체로 지도 중심을 이동하고, 좌측 패널을 연다.

### 2. 분할 진입·종료

1. 우측 지도 메뉴에 «지도분할»을 추가하고, 누르면 화면이 좌우 두 칸으로 나뉘며 우측에 두 번째 지도가 뜬다.
2. 진입 시 우측 지도는 좌측 지도의 위치·확대 수준을 그대로 받아 같은 화면에서 시작한다.
3. 컨트롤 구역의 «분할 종료»를 누르면 우측 지도가 닫히고 좌측 지도가 화면 전체로 돌아간다. 종료해도 좌측 지도의 위치·레이어는 그대로 유지한다.
4. 거리뷰가 켜져 있는 상태에서는 지도 분할로 바로 바꿀 수 있고, 두 기능이 동시에 켜지지는 않는다.

### 3. 분할선 이동·잠금

1. 두 지도 사이 실선을 좌우로 끌어 화면 비율을 바꾼다. 거리뷰 분할과 동작·모양을 같게 한다.
2. 컨트롤 구역 첫 버튼으로 분할선 이동을 잠그면, 실선을 끌어도 비율이 바뀌지 않는다.
3. 비율을 바꾸는 동안 두 지도 모두 크기를 다시 계산해 지도가 늘어나거나 잘려 보이지 않아야 한다.

### 4. 지도 이동 싱크

1. 켜면 한쪽 지도를 움직이거나 확대·축소할 때 다른 쪽도 같은 위치·같은 확대 수준으로 따라온다.
2. 끄면 두 지도가 완전히 분리되어 각각 다른 위치, 확대 수준으로 지도를 볼 수 있다.

### 5. 배경지도 싱크

1. 켜면 배경지도를 동기화한다.
2. 끄면 배경지도를 좌우 따로 변경할 수 있도록 한다.
- 예시
```
                   좌        우
항공영상(vworld)    ◉   |    ◯
```
