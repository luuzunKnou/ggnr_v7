## 개발목표

지적기록물 파일 목록이 늦게 뜨는 이유를 줄인다. 자료 폴더에 있는 파일명으로 표를 먼저 좁힌 뒤 묶음·지번을 센다. 상세의 묶인 지번은 표로 보여주고, 첨부 미리보기 위아래 빈 칸은 없앤다.

## 플로우차트

```
지도 → 지적기록물 파일 목록 → (행 선택) → 미리보기·지번 표
```


#### 설명

1. 목록은 자료 폴더에 있는 파일명으로 표를 좁혀 불러 온다.
2. 상세 지번은 소재지·지번 열의 표이다. 많으면 표 안에서 스크롤한다.
3. 첨부 그림은 패널을 세로로 채우지 않고, 위아래 빈 칸 없이 붙인다.

#### 확인사항

1. 지적기록물 목록이 이전보다 빨리 나와야 한다.
2. 상세 지번이 표로 보여야 한다.
3. 첨부 그림 위아래에 회색 빈 칸이 없어야 한다.
