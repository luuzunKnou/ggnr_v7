## 개발목표

상수도 행정 업무지원과 하수도 행정 업무지원에서 공통 민원관리·메모관리 대신 업무별 메뉴를 사이드바에 둔다. 메뉴를 누르면 그 메뉴에 해당하는 민원 또는 메모만 목록에 나온다. 다른 시스템의 민원관리·메모관리는 그대로 둔다.

## 플로우차트

지도 → (상수·급수·하수·준설 메뉴) → 해당 목록

## 화면설계

### MAP-WATER-01 상수도 행정 업무지원

```
┌ 사이드바 ────────────── 지도 ─────────────────────────┐
│ 상수민원          ┌ 상수민원 목록 ─────────┐            │
│ 상수메모          │ 제목·주소·상태          │            │
│ 급수민원          │                        │            │
│ 급수메모          └────────────────────────┘            │
└────────────────────────────────────────────────────────┘
```

#### 설명

1. 상수도 행정 업무지원 사이드바에 상수민원, 상수메모, 급수민원, 급수메모가 보인다.
2. 상수민원을 누르면 상수민원만, 급수민원을 누르면 급수민원만 목록에 나온다.
3. 상수메모·급수메모도 각각 해당 메모만 나온다.
4. 공통 민원관리·메모관리는 이 시스템 사이드바에서 빠진다.

#### 확인사항

1. 상수민원 목록에 급수·하수·준설 자료가 섞이지 않아야 한다.
2. 상수메모를 누르면 상수 메모만 보여야 한다.
3. 급수민원·급수메모도 각자 자료만 나와야 한다.

### MAP-WATER-02 하수도 행정 업무지원

```
┌ 사이드바 ────────────── 지도 ─────────────────────────┐
│ 하수민원          ┌ 준설민원 ────────────────┐          │
│ 하수메모          │ 준설민원 | 준설대상지     │          │
│ 준설민원          │ 목록                     │          │
│ 준설메모          └──────────────────────────┘          │
└────────────────────────────────────────────────────────┘
```

#### 설명

1. 하수도 행정 업무지원 사이드바에 하수민원, 하수메모, 준설민원, 준설메모가 보인다.
2. 하수민원·하수메모는 각각 하수 자료만 보여 준다.
3. 준설민원은 준설민원과 준설대상지를 한 메뉴에서 바꿔 본다.
4. 준설메모는 준설 메모만 보여 준다.

#### 확인사항

1. 하수민원 목록에 상수·급수·준설 자료가 없어야 한다.
2. 준설민원에서 준설민원과 준설대상지를 바꿀 수 있어야 한다.
3. 다른 시스템 사이드바의 민원관리·메모관리는 유지되어야 한다.
