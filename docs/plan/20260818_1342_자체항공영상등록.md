## 개발목표

영상관리 «항공영상»을 실기능으로 연결한다. 작업단위 폴더 생성·TIF 업로드·변환 진행은 드론영상과 같은 API 흐름을 쓰고, 변환 결과만 배경지도 «자체항공영상»에 등록한다. 항공영상 목록에는 체크박스가 없고 지도 on/off는 배경지도에서만 한다.

## 플로우차트

```
영상관리 항공영상 → 폴더 생성·TIF 업로드 → 타일 변환 → 배경지도 자체항공영상 등록 → 배경지도에서 on/off
```

## 화면설계

### AV-SAT-01 항공영상 목록·상세

```
┌─────┬──────────────────────────────┬────────────────────┐
│메뉴 │ 지도                          │ 항공영상 목록       │
│     │                              │ 검색·새로고침·업로드 │
│     │                              │ 작업단위 행         │
│     │                              ├────────────────────┤
│     │                              │ 작업단위 상세       │
│     │                              │ 속성·파일·변환상태  │
│     │                              │ 수정·삭제·닫기      │
└─────┴──────────────────────────────┴────────────────────┘
```

#### 설명

1. 항공영상 메뉴를 열면 실저장 작업단위 목록이 보인다.
2. 업로드로 작업단위 폴더를 만들고 TIF를 올리면 변환이 이어진다.
3. 변환이 끝나면 배경지도 «자체항공영상»에 항목이 생긴다.
4. 목록에는 체크박스가 없고, 지도 표시는 배경지도에서만 켠다.
5. 상세에서 파일·변환 상태를 확인하고 수정·삭제를 한다.

#### 확인사항

1. 항공영상 폴더 업로드 후 변환 진행이 보여야 한다.
2. 변환 완료 후 배경지도 «자체항공영상»에 새 항목이 보여야 한다.
3. 드론영상 변환 결과가 자체항공영상 목록에 섞이지 않아야 한다.
4. 항공영상 목록에 지도 체크박스가 없어야 한다.
5. 사진·동영상·파노라마·드론영상 기존 동작이 유지되어야 한다.

### AV-SAT-02 배경지도 자체항공영상

```
┌─────┬──────────────────────────────┐
│메뉴 │ 지도                          │
│     │ 배경지도                      │
│     │ 자체항공영상                  │
│     │ ○ 항목1  ○ 항목2             │
└─────┴──────────────────────────────┘
```

#### 설명

1. 변환 완료된 항공영상만 자체항공영상 선택 목록에 나타난다.
2. 항목을 고르면 지도 배경이 해당 타일로 바뀐다.
3. 영상관리 항공영상 화면에서는 지도 배경을 직접 체크하지 않는다.

#### 확인사항

1. 새로 변환한 항목이 배경지도 목록에 보여야 한다.
2. 선택한 자체항공영상이 지도 배경으로 표시되어야 한다.
