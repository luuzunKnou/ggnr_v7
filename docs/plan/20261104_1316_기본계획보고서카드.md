# 작업계획서

2026-11-04 | dev.strcat | 기본계획 «보고서별» 목록을 카드형으로 변경

## 개발목표

기본계획 «보고서별» 목록을 폴더처럼 펼치는 방식에서 보고서 카드 목록으로 바꾼다. 카드에는 보고서명, 합계연장, 전체 개소, «보고서» 버튼을 보여 준다. 하천이 여러 곳인 보고서는 하천 연장을 합친 값을, 한 곳이면 그 하천 연장을 보여 준다.

카드를 누르면 목록과 상세 사이에 그 보고서의 하천 목록이 하나 더 열리고, 하천을 누르면 지금처럼 상세가 열린다. 카드의 «보고서» 버튼은 보고서 폴더 바로 아래 PDF와 하천별 폴더의 PDF를 함께 열며, «보고서별» 상세에서는 «보고서» 버튼을 없앤다. 카드가 들어가는 만큼 «보고서별» 목록은 «하천별»보다 조금 넓게 연다.

«하천별» 목록과 상세는 바뀌지 않는다.

## 플로우차트

```
보고서 카드 목록 → (카드 클릭) → 하천 목록 → (하천 클릭) → 기본계획 상세
```

## 화면설계

### RBP-CARD-01 보고서 카드 목록

```
┌──────────────────────────────────────────────────────────────────────┐
│ 검색창                                                               │
├──────────┬──────────────────────────────┬────────────────────────────┤
│ 사이드바 │ 지방하천 기본계획   보기 변경│                            │
│          │ 지방하천 │ 소하천           │                            │
│          │ 전체 연도 ▾  보고서·하천명 검색                           │
│          │ ┌──────────────────────────┐ │                            │
│          │ │ 2023                     │ │           지도             │
│          │ │ 동해안권역 하천기본계획  │ │                            │
│          │ │ 합계연장 12.3km  3개소   │ │                            │
│          │ │                 보고서   │ │                            │
│          │ └──────────────────────────┘ │                            │
│          │ ┌──────────────────────────┐ │                            │
│          │ │ 2015                     │ │                            │
│          │ │ 울령천 하천기본계획      │ │                            │
│          │ │ 합계연장 12.1km  1개소   │ │                            │
│          │ │                 보고서   │ │                            │
│          │ └──────────────────────────┘ │                            │
└──────────┴──────────────────────────────┴────────────────────────────┘
```

#### 설명

1. 연도 선택과 검색은 지금과 같고, 보고서마다 카드 하나로 보인다.
2. 카드에는 연도, 보고서명, 합계연장, 전체 개소, «보고서» 버튼이 있다.
3. 보고서 파일이 없으면 «보고서» 버튼이 흐리게 보인다.
4. 하천명으로 검색하면 카드에 검색에 걸린 하천 수가 함께 보인다.

#### 확인사항

1. 하천이 여러 곳인 보고서는 연장 합계가 나와야 한다.
2. 하천이 한 곳인 보고서는 그 하천 연장과 «1개소»가 나와야 한다.
3. «보고서»를 누르면 보고서 PDF가 열려야 한다.
4. 목록이 «하천별»보다 조금 넓게 열려야 한다.

### RBP-CARD-02 보고서 하천 목록

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 검색창                                                                       │
├──────────┬──────────────────────┬──────────────────┬─────────────────────────┤
│ 사이드바 │ 보고서 카드 목록     │ 동해안권역 …   ✕ │                         │
│          │ ┌──────────────────┐ │ 2023 · 3개소     │                         │
│          │ │ 선택된 카드      │ │ 합계연장 12.3km  │          지도           │
│          │ └──────────────────┘ │──────────────────│                         │
│          │ ┌──────────────────┐ │ 감률천    6.06km │                         │
│          │ │ 다른 카드        │ │ 지경천    4.20km │                         │
│          │ └──────────────────┘ │ 창하천    2.04km │                         │
└──────────┴──────────────────────┴──────────────────┴─────────────────────────┘
```

#### 설명

1. 카드를 누르면 목록 오른쪽에 그 보고서의 하천 목록이 열린다.
2. 같은 카드를 다시 누르거나 닫기를 누르면 하천 목록이 닫힌다.
3. 하천 목록 위에는 보고서명, 연도, 개소, 합계연장이 보인다.
4. 하천이 한 곳인 보고서는 카드를 누르면 그 하천 상세까지 바로 열린다.

#### 확인사항

1. 카드를 누르면 하천 목록이 목록과 상세 사이에 열려야 한다.
2. 하천 목록의 하천을 누르면 상세가 열리고 지도가 그 하천으로 이동해야 한다.
3. 다른 카드를 누르면 하천 목록이 그 보고서로 바뀌어야 한다.

```
│          │                  │                  │ 2023 동해안권역 … │     지도     │
│          │                  │                  │ 속성·도면         │              │
└──────────┴──────────────────┴──────────────────┴───────────────────┴──────────────┘
```

#### 설명

1. 상세 제목줄에는 «보고서» 버튼이 없고 닫기만 있다.
2. 상세 내용은 지금과 같다.

#### 확인사항

1. «보고서별» 상세에 «보고서» 버튼이 없어야 한다.
2. «하천별» 상세에는 «보고서» 버튼이 그대로 있어야 한다.
