# 작업계획서

2026-07-22 | gyujin | 하천색인도 라벨을 코드 끝 번호로 표시

## 개발목표

하천색인도 지도 라벨이 도면명 고정 구간 자르기 때문에 0만 나오던 문제를, 관리코드 끝 세 자리를 숫자로 읽어 색인도 번호만 보이도록 고친다.

## 플로우차트

색인도 레이어 → 관리코드 끝번호 → 지도 라벨

## 화면설계

### MAP-IDX-01 색인도 라벨

```
┌──────────────────────────────────────────────┐
│ [지도]                                        │
│          ┌───┐                                │
│          │13 │  ← 색인도 번호                 │
│          └───┘                                │
└──────────────────────────────────────────────┘
```

#### 설명

1. 색인도 레이어를 켜고 충분히 확대하면 폴리곤 안에 번호가 보인다.
2. 번호는 관리코드 끝의 세 자리를 숫자로 변환한 값이다.
3. 앞자리 0은 표시에서 빠진다.

#### 확인사항

1. 관리코드가 MB_009_INDEX_013 형태면 지도에 13이 보여야 한다.
2. 모든 색인도에 0만 반복되지 않아야 한다.
3. 확대 전에는 라벨 없이 경계만 보여야 한다.
