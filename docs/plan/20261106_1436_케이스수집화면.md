## 개발목표

누수분석, 단수구역, 송수경로에서 탐색 결과가 틀리면 맞는 선을 케이스로 남긴다. 칠해진 관로에서 선을 이어 그리고 메모와 함께 저장한다. 저장해도 연결 간격과 제수변 절단 거리는 바뀌지 않는다.

규칙 이름과 새 규칙 필요는 아이디가 su인 계정만 붙인다. 현장 사용자는 규칙 이름을 고르지 않는다. 이름이 붙은 케이스는 나중에 코드를 고친 뒤 같은 지점을 다시 탐색해 맞는지 비교하는 기준이다. 선 모양만으로 규칙을 만들지 않는다.

## 플로우차트

지도 → 케이스 수집 → 선 연장 → 케이스 저장 → (su) 규칙 이름 또는 새 규칙

## 화면설계

### MAP-CASE-01 케이스 수집

```
┌──────────────────────────────────────────────────────────┐
│ 검색                                                       │
├────┬─────────────────────────────────────────┬───────────┤
│메뉴│ 지도                                      │ 누수분석   │
│    │  칠해진 관로 · 이어 그린 선                 │ 케이스 수집 │
│    │                                          │ 안내       │
│    │                                          │ 현재 n개   │
│    │                                          │ 메모       │
│    │                                          │ 처음 선으로 │
│    │                                          │ 케이스 저장 │
│    │                                          │ 저장 목록   │
└────┴─────────────────────────────────────────┴───────────┘
```

#### 설명

1. 누수분석, 단수구역, 송수경로 결과에서 «케이스 수집»을 연다.
2. 칠해진 관로에서 선을 이어 그리고, 방금 더한 선만 되돌릴 수 있다.
3. 메모를 적고 «케이스 저장»을 누르면 이어 그린 관로가 목록에 남는다.
4. 목록에는 규칙 표시, 관로, 메모가 보인다. 저장 직후에는 «미정»이다.
5. 연결 거리와 제수변 절단 거리, 실행 버튼은 이 화면에 없다.

#### 확인사항

1. 버튼 문구가 «케이스 수집»이어야 한다.
2. 선을 잇지 않으면 «케이스 저장»이 막혀야 한다.
3. 저장 후 목록에 관로와 메모가 보여야 한다.
4. 저장해도 다음 탐색의 연결 간격이 늘지 않아야 한다.
5. «처음 선으로»를 누르면 분석 결과 선으로 돌아가야 한다.

### MAP-CASE-02 규칙 이름

```
┌──────────────────────────────────────────────────────────┐
│ 검색                                                       │
├────┬─────────────────────────────────────────┬───────────┤
│메뉴│ 지도                                      │ 케이스 목록 │
│    │                                          │ 미정 · 관로 │
│    │                                          │ 규칙 이름   │
│    │                                          │ 지정        │
│    │                                          │ 새 규칙     │
└────┴─────────────────────────────────────────┴───────────┘
```

#### 설명

1. su로 들어오면 각 케이스에 규칙 이름 칸, «지정», «새 규칙»이 보인다.
2. 이름을 적고 «지정»을 누르면 그 케이스의 표시가 그 이름으로 바뀐다.
3. «새 규칙»을 누르면 이름 없이 «새규칙»으로 표시된다.
4. su가 아니면 이름 칸과 두 버튼이 보이지 않는다.
5. 이름을 붙여도 탐색 결과는 바뀌지 않는다.

#### 확인사항

1. su가 아닌 계정에는 규칙 이름 칸이 없어야 한다.
2. 이름 없이 «지정»을 누르면 안내가 나와야 한다.
3. «새 규칙» 뒤에는 목록 앞이 «새규칙»이어야 한다.
4. 이름을 붙여도 연결 간격 숫자가 바뀌지 않아야 한다.
