# 작업계획서

2026-11-20 | 213am | odor_ph Index · 시안 G 대시보드·관제지도

## 개발목표

하수악취 Index 콘솔 좌측 메뉴에 「실시간 통합 현황」을 추가하고, 시안 G 홈 대시보드와 같은 풀패널 구성을 넣는다. 「관제 지도」는 외부 이동 안내 대신 콘솔 안에서 기존 OpenLayers 기반 항공·읍면동 지도와 지점 목록·주의·심각 목록을 보여 준다. 경보 목록 시안 교체는 범위 밖이다.

## 플로우차트

```
좌측메뉴 → 실시간 통합 현황 → 대시보드 풀패널 ⇄ 관제 지도(지도·목록·주의심각) → (링크) 경보 목록
```

## 화면설계

### ODOR-LIVE-01 실시간 통합 현황

```
┌──────┬────────────────────────────────────────────────────────────┐
│ 홈   │ 측정지점  정상  주의(3)  경보(4·5)  저감 가동  통신율        │
│ 실시 │ ┌──────────┬────────────────────┬──────────────┐          │
│ 시통 │ │악취 등급 │                    │ 최근 경보    │          │
│ 합현 │ │ 분포     │   관제 현황 지도   │              │          │
│ 황   │ ├──────────┤   (항공·경계)      ├──────────────┤          │
│ 모니 │ │오늘의    │                    │ 경보목록     │          │
│ 터링 │ │동향      │                    │ (미니 표)    │          │
│ ·관제│ └──────────┴────────────────────┴──────────────┘          │
│ 지도 │                                                            │
└──────┴────────────────────────────────────────────────────────────┘
```

#### 설명

1. 모니터링 그룹에 「실시간 통합 현황」을 두고 선택 시 본문만 대시보드로 채운다.
2. 상단 요약 여섯 칸은 센서·등급 목업으로 채운다.
3. 중앙 지도는 기존 Index 미니맵을 재사용하고 「관제 지도」로 이동할 수 있다.
4. 최근 경보·경보 미니 표에서 「경보 목록」으로 이동한다.

#### 확인사항

1. 좌측 메뉴가 보이는 상태에서 본문이 대시보드로 채워져야 한다.
2. 측정지점 수와 등급 분포 합이 맞아야 한다.
3. 「관제지도」·「경보목록」 링크가 해당 메뉴로 바뀌어야 한다.

### ODOR-MAP-01 관제 지도

```
┌──────┬──────────────────────────────────────────┬────────────┐
│ …    │ [측정지점] [하수관망 예정] [시설물 예정]   │ 악취등급   │
│ 관제 │ [검색] [3~5등급만]  지도|목록            │ 주의·심각  │
│ 지도 │ 범례 · 지도(또는 지점 표)                 │ 목록       │
│      │                                          │            │
└──────┴──────────────────────────────────────────┴────────────┘
```

#### 설명

1. 본문에 지도·도구줄·우측 주의·심각 목록을 둔다.
2. 지도·목록 전환과 지점 검색·3~5등급 필터를 제공한다.
3. 지도 조작(이동·줌)이 가능하며 카카오맵은 쓰지 않는다.
4. 목록 행·우측 행 선택 시 해당 지점을 강조한다.

#### 확인사항

1. 「관제 지도」 선택 시 외부 페이지로 나가지 않아야 한다.
2. 3~5등급만 켜면 지도·목록이 함께 걸러져야 한다.
3. 주의·심각 목록과 지도 강조가 연동되어야 한다.
