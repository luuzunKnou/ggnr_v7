## 개발목표

점용 종료 임박 알림의 자료 출처를 프로젝트에 맞게 나눈다. 울진은 울진 하천점용과 공통점용 종료일을 모두 보고, 그 외는 공통점용 종료일만 본다. 알림을 누르면 그 자료의 점용 상세가 열린다.

## 플로우차트

```
알림 수집 → (울진이면 울진점용+공통점용 · 아니면 공통점용) → 해당 시스템만 표시 → (항목 클릭) → 점용 상세
```

## 화면설계

### NOTIF-EXP-01 점용 종료 임박

```
+----------------------------------------------------------------------+
| 통합지도                                              [로그인계정]   |
+---+------------------------------------------------------------------+
|메 | [내 정보]                                                        |
|뉴 | +---------------- 알림 ------------------+                       |
|하 | 점용 종료 임박                           |                       |
|천 | · 하천점용 …                             |                       |
|   +------------------------------------------+                       |
|점 | (지도 · 하천)                                                    |
|용 |                                                                  |
+---+------------------------------------------------------------------+
+----------------------------------------------------------------------+
```

#### 설명

1. 울진에서는 울진 하천점용과 공통점용 종료일이 가까운 건이 모두 알림에 나온다.
2. 영양 등 다른 곳에서는 공통점용 종료일이 가까운 건만 나온다. 하천·도로·국공유지는 각 시스템에만 보인다.
3. 항목을 누르면 그 점용 목록과 상세가 열린다.

#### 확인사항

1. 영양 하천에서 울진 점용 테이블이 없다는 오류가 알림에 나오지 않아야 한다.
2. 영양 하천 알림에는 하천 공통점용 종료 임박만 보여야 한다.
3. 도로·국공유지 공통점용 종료 임박은 각 시스템 알림에만 나와야 한다.
4. 울진 하천 알림에는 울진 하천점용과 하천 공통점용 종료 임박이 모두 나와야 한다.
5. 알림 항목을 누르면 해당 점용 상세가 열려야 한다.
