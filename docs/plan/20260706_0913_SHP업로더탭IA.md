## 개발목표

dev **개발자 모드** `SHP File Uploader` 상단 탭 `[ SHP 업로드 ]` · `[ 레이어 상태 ]` · `[ 이력 조회 ]`의 역할을 재정의한다. 한 탭이 하나의 업무 질문만 답하도록 나눈다. `지금 올리고 마무리할 작업`(업로드·동기화), `레이어 전체가 정상인가`(상태·복구), `과거에 무슨 일이 있었고 되돌릴 수 있는가`(이력 조회·롤백).

현재 `[ 이력 조회 ]` 탭은 이름과 달리 동기화 상세·미결 처리까지 담당해 `[ SHP 업로드 ]` 탭과 역할이 겹친다. **모든 동기화(세션·과거 미결)** 는 `[ SHP 업로드 ]` 탭으로 모으고, `[ 이력 조회 ]` 탭은 **조회·되돌리기만** 남긴다. `[ 레이어 상태 ]` 탭은 점검·복구·다운로드 역할을 그대로 유지한다.

본 계획은 [20260703_0722_레이어업로드전체.md](20260703_0722_레이어업로드전체.md) 통합 계획의 **탭·화면 IA 보완**이며, 좌표계·컬럼 검증·동기화 상세 모달 본문 등 기능 구현 범위는 통합 계획을 따른다.

## 플로우차트

```
SHP 업로드 — 폴더·후처리 → (동기화 필요) 미결 목록·동기화 상세 → 완료 / 레이어 상태 — 점검·복구·다운로드 / 이력 조회 — 배치·상세 조회 → (필요 시) 되돌리기
```



## 화면설계

와이어프레임은 **개발자 모드** 전체 화면(좌측 메뉴·우측 카드) 기준이다. **와이어프레임**에서 탭 선택은 `[x]`·`[ ]`, **설명·확인사항**에서는 `[ SHP 업로드 ]` **·** `[ 레이어 상태 ]` **·** `[ 이력 조회 ]` 로 적는다. **DEV-SHP-IA-02** 와이어프레임을 정렬·표 폭 기준으로 삼는다.

### DEV-SHP-IA-01 SHP 업로드 (대기·미결 목록)

```
+-----------------------------------------------------------------------------------------------------------------+
|개발자 모드                                                                   [테마변경]  [로그아웃]  [메인으로] |
+------------------------+----------------------------------------------------------------------------------------+
|> 시스템관리            |SHP File Uploader                                                                       |
|> 데이터관리            |SHP 파일 업로드 및 GeoServer·스타일 확인·후처리                                       |
|> Tools                 |[x] SHP 업로드   |   [ ] 레이어 상태   |   [ ] 이력 조회                                |
|v 기타기능              |----------------------------------------------------------------------------------------|
|  * SHP File Uploader   |[상위로]  shp_data                                             [새로고침]  [폴더 업로드]|
|    Excel File Uploader |----------------------------------------------------------------------------------------|
|    Data File Upload    |+------+------------------+--------+---------------------------------------------------+|
|    정사영상관리        |  종류 | 이름             | 크기   | 수정일                                             |
|    LAS File Uploader   |  fld  | 20250703         |   -    | 2026-07-03 10:00                                   |
|    LAS Fixer           |  shp  | 하천망.shp       | 1.2 MB | 2026-07-03 09:30                                   |
|> 버전관리              |  shp  | 도로대장.shp     | 890 KB | 2026-07-02 18:00                                   |
|                        |+------+------------------+--------+---------------------------------------------------+|
|                        |                                                                                        |
|                        |--- 미결 동기화 (1) ---                                                       [새로고침]|
|                        |----------------------------------------------------------------------------------------|
|                        |+------+----------+--------+------------------------------------------------+----------+|
|                        |  결과 | 레이어   | 구분   | 업데이트 내용                                    | 액션    |
|                        |  대기 | 기본계획 | 동기화 | 동기화 대기                                      | [처리]  |
|                        |+------+----------+--------+------------------------------------------------+----------+|
+------------------------+----------------------------------------------------------------------------------------+
```



#### 설명

1. **개발자 모드**에서 좌측 **기타기능** 그룹의 **SHP File Uploader**를 선택한 화면이다. `[ SHP 업로드 ]` 탭이 선택된 상태이다.
2. 상단 도구줄에서 폴더 경로 이동·목록 새로고침·**폴더 업로드**를 한다. 대기 중에는 현재 경로의 폴더·SHP 파일 목록이 본문에 표시된다.
3. 업로드·후처리와 별도로 **미결 동기화** 목록을 항상(또는 접이식으로) 보여 준다. 서버에 남은 과거 미결 건도 포함한다.
4. 미결 행 **처리**를 누르면 동기화 상세 모달이 열린다. 세션과 무관하게 여기서 동기화를 마친다.



#### 확인사항

1. **개발자 모드** 헤더(`[테마변경]`·`[로그아웃]`·`[메인으로]` 우측 정렬)·좌측 메뉴·우측 카드가 다른 dev 메뉴와 같은 레이아웃이어야 한다.
2. `[ SHP 업로드 ]` 탭에서 현재 세션·과거 미결 동기화를 모두 처리할 수 있어야 한다.
3. `[ 레이어 상태 ]`·`[ 이력 조회 ]` 탭으로 바꿔도 공유 폴더 경로가 유지되어야 한다.



### DEV-SHP-IA-02 SHP 업로드 (업로드·후처리 진행)

```
+-----------------------------------------------------------------------------------------------------------------+
|개발자 모드                                                                   [테마변경]  [로그아웃]  [메인으로] |

|> 시스템관리            |SHP File Uploader                                                                       |
|> 데이터관리            |SHP 파일 업로드 및 GeoServer·스타일 확인·후처리                                       |
|> Tools                 |[x] SHP 업로드   |   [ ] 레이어 상태   |   [ ] 이력 조회                                |
|v 기타기능              |----------------------------------------------------------------------------------------|
|  * SHP File Uploader   |[상위로]  shp_data/20250703                                    [새로고침]  [폴더 업로드]|
|    Excel File Uploader |----------------------------------------------------------------------------------------|
|    Data File Upload    |업로드 진행: 5 / 12 파일                                                          [취소]|

|    LAS Fixer           |+-------------+-------+-------+-------+--------+------+------+------+------------------+|
|> 버전관리              |  파일        | Table | Layer | Style | Define | 현재 | 변경 | 추가 | 비고              |
|                        |  하천망.shp  |   O   |   O   |   O   |   O    | 120  |  3   |  0   | [동기화 상세]     |
|                        |  도로대장.shp|   X   |   -   |   -   |   -    |  -   |  -   |  -   | 테이블 실패       |
|                        |+-------------+-------+-------+-------+--------+------+------+------+------------------+|
|                        |                                                                                        |
|                        |--- 미결 동기화 (2) ---                                                       [새로고침]|
|                        |----------------------------------------------------------------------------------------|
|                        |+------+----------+--------+------------------------------------------------+----------+|
|                        |  대기 | 하천망   | 동기화 | 동기화 대기                                    | [처리]    |
|                        |  대기 | 기본계획 | 동기화 | 동기화 대기                                    | [처리]    |
|                        |+------+----------+--------+------------------------------------------------+----------+|
|                        |후처리 완료: 3건 성공, 2건 동기화 대기                             [ 이력 조회 ]  [닫기]|
+------------------------+----------------------------------------------------------------------------------------+
```



#### 설명

1. DEV-SHP-IA-01과 같은 틀이며 `[ SHP 업로드 ]` 탭 선택 상태에서 본문만 업로드·후처리 진행 중으로 바뀐다.
2. 폴더 업로드 중에는 진행률·취소가, 후처리 중에는 파일별 단계(Table·Layer·Style·Define) 로그가 본문을 채운다.
3. `동기화 대기` 파일은 로그 **비고**·**상세** 링크와 미결 목록 양쪽에 표시된다.
4. 배치가 끝나면 하단 요약과 `[ 이력 조회 ]` 링크가 나온다. 링크는 `[ 이력 조회 ]` 탭으로만 전환한다.
5. 좌표계 선택·컬럼 불일치·동기화 상세 모달은 우측 카드 **앞에 겹쳐** 뜨며, 카드 본문은 **뒤 화면 어둡게** 처리된다(와이어프레임 생략, 통합 계획 DEV-SHP-CRS·SCHEMA·SYNC 참고).



#### 확인사항

1. 이번 세션 `동기화 대기`와 예전 미결 건이 미결 목록에 함께 보여야 한다.
2. **처리**·**상세** 후 동기화 상세에서 마치면 미결 목록·후처리 로그·이력 기록이 일치하게 갱신되어야 한다.
3. 미결 건이 남으면 해당 파일·행이 `완료`로 표시되지 않아야 한다.
4. `[ 이력 조회 ]` 링크는 탭 전환만 하고 동기화 모달을 열지 않아야 한다.



### DEV-SHP-IA-03 이력 조회

```
+-----------------------------------------------------------------------------------------------------------------+
|개발자 모드                                                                   [테마변경]  [로그아웃]  [메인으로] |
+------------------------+----------------------------------------------------------------------------------------+
|> 시스템관리            |SHP File Uploader                                                                       |
|> 데이터관리            |SHP 파일 업로드 및 GeoServer·스타일 확인·후처리                                       |
|> Tools                 |[ ] SHP 업로드   |   [ ] 레이어 상태   |   [x] 이력 조회                                |
|v 기타기능              |----------------------------------------------------------------------------------------|
|  * SHP File Uploader   |레이어 업데이트 이력   총 42건                                                [새로고침]|
|    Excel File Uploader |----------------------------------------------------------------------------------------|
|    Data File Upload    |+--------------+--------+----------+------+------+------+------------------------------+|
|    정사영상관리        |  업데이트일시 | 작업자 | 레이어수 | 성공 | 실패 |      | 업데이트 내용                 |
|    LAS File Uploader   |  2026-07-05   | 123    |    5     |  4   |  1   |  v   | 폴더 업로드 ...               |
|    LAS Fixer           |+--------------+--------+----------+------+------+------+------------------------------+|
|> 버전관리              |  (펼침)                                                                                |
|                        |    +------+----------+--------+--------------------------------------------+----------+|
|                        |      결과 | 레이어   | 구분   | 업데이트 내용                              | 액션      |
|                        |      대기 | 하천망   | 동기화 | 동기화 대기                                |    -      |
|                        |      성공 | 도로대장 | 신규   | 업데이트 완료 (1200건)                     | [되돌리기]|
|                        |    +------+----------+--------+--------------------------------------------+----------+|
|                        |미결 동기화는 SHP 업로드 탭에서 처리합니다.                        [ SHP 업로드로 이동 ]|
|                        |                                                                     [이전]  1/3  [다음]|
+------------------------+----------------------------------------------------------------------------------------+
```



#### 설명

1. `[ 이력 조회 ]` 탭이 선택된 화면이다. 배치 목록·펼친 상세·페이지 이동까지 카드 본문에 들어간다.
2. 배치를 펼치면 레이어별 결과·구분·`업데이트 내용`·건수 요약을 읽는다.
3. **동기화** 버튼과 행 클릭 → 동기화 상세 진입은 **제거**한다.
4. `동기화 대기` 행은 상태만 보여 주고, **SHP 업로드로 이동**으로 `[ SHP 업로드 ]` 탭·미결 목록으로 보낸다.
5. 처리가 끝난 행만 **되돌리기**로 되돌리기 확인 화면(모달)을 연다.



#### 확인사항

1. `[ 이력 조회 ]` 탭 어디에서도 동기화 상세(충돌·삭제·신규 편집)가 열리지 않아야 한다.
2. `동기화 대기` 행에 **되돌리기**가 없고 **SHP 업로드로 이동**이 동작해야 한다.
3. **되돌리기** 실행 후 결과·`업데이트 내용`·롤백 표시가 목록에 반영되어야 한다.
4. `[ SHP 업로드 ]` 탭에서 마친 작업과 이력 배치·상세 행·건수가 서로 대응되어야 한다.

```
|                        |              되돌리면 위 반영분이 취소됩니다.                                          |

```



#### 설명

1. `[ 이력 조회 ]` 탭 선택 상태에서 **되돌리기**를 누르면 좌측 메뉴·상단 헤더는 그대로 두고, 카드 본문은 **뒤 화면 어둡게** 처리되며 확인 모달이 앞에 뜬다.
2. 동기화 상세처럼 충돌·삭제·신규를 편집하지 않고, 이미 적용된 내용을 되돌릴지 여부만 묻는다.
3. 확인 후 서버에 되돌리기를 요청하고, 성공하면 이력 목록·상세가 갱신된다.



#### 확인사항

1. 이 화면에서 동기화 편집 UI가 보이지 않아야 한다.
2. 되돌리기 후 이력 상세의 결과·`업데이트 내용`이 롤백 상태로 바뀌어야 한다.
3. `동기화 대기`·미적용 건에는 **되돌리기**가 나오지 않아야 한다.

#### 설명

1. `[ 레이어 상태 ]` 탭이 선택된 화면이다. 스키마 전환·그룹 필터·검색·목록·복구·다운로드가 카드 본문에 들어간다.
2. 등록된 레이어의 DB·GeoServer·스타일·필드 정의 완성도를 점검하고, 누락 단계만 복구하거나 SHP를 내려받는다.
3. 통합 계획 DEV-SHP-STATUS-01의 동작·확인사항을 따른다. 이번 IA 변경으로 본문 기능은 바꾸지 않는다.



#### 확인사항

1. 테이블은 있는데 GeoServer만 없는 것처럼 단계별로 따로 복구할 수 있어야 한다.
2. 불일치 배지·표시가 실제 GeoServer·DB 조회 결과와 맞아야 한다.
