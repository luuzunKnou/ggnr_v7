# 작업계획서

2026-08-18 | JungWooojin | 접도구역 건축물 관리대장 목업 요청

## 개발목표

지도 사이드바에 «접도구역 건축물»을 추가해 접도구역 안에 있는 기존 건축물(공작물) 관리대장을 목록과 상세로 본다. 도로점용 화면과 같은 구성으로, 좌측에 관리대장 목록이 뜨고 행을 고르면 오른쪽에 상세가 열린다.

상세는 관리대장 기본정보 아래에 건축물내용 여러 건을 표로, 확인결과이력 여러 건을 목록으로 붙인다. 한 건의 관리대장에 건축물내용과 확인결과이력이 각각 여러 개 달리는 구조를 화면으로 확인하는 것이 목적이다.

이번 작업은 화면 목업이다. 데이터는 화면 안에 넣어 둔 샘플만 쓰고 데이터베이스·서버 저장은 하지 않는다. 새로고침하면 처음 샘플로 돌아간다.

## 플로우차트

```
지도 → 접도구역 건축물 목록 → (행 클릭) → 관리대장 상세 → 건축물내용 ⇄ 확인결과이력
```

#### 설명

1. 사이드바에서 «접도구역 건축물»을 선택하면 좌측에 관리대장 목록 패널이 열린다.
2. 목록은 도로의 종류, 노선번호, 위치를 한 행에 보여 준다.
3. 검색창에 지번·소유자·노선명을 넣으면 목록이 걸러지고, 도로종류 단추로 지방도·국도·군도를 나눠 볼 수 있다.
4. 행을 누르면 지도가 그 관리대장 위치로 이동하고 오른쪽에 상세 패널이 열린다.
5. 목록 맨 아래에 현재 걸러진 건수를 보여 준다.

#### 확인사항

1. 사이드바에서 «접도구역 건축물»이 선택된 상태로 보여야 한다.
2. 검색어를 지우면 전체 목록이 다시 나와야 한다.
3. 도로종류를 «국도»로 고르면 국도만 남아야 한다.
4. 행을 누르면 지도가 해당 위치로 이동해야 한다.
5. 닫기를 누르면 목록과 상세가 함께 닫혀야 한다.

#### 설명

1. 상세 패널은 위에서 아래로 기본정보, 건축물내용, 확인결과이력, 첨부파일 네 묶음으로 나뉜다.
2. 기본정보는 도로의 종류, 노선번호(노선명), 일련번호, 작성연월일, 위치, 현 거주자, 건축물 소유자, 토지 소유자를 서식과 같이 보여 준다.
3. 건축물내용은 여러 동을 표로 보여 주며, 동 구분·설치연월일·구조·용도·면적과 불량 건축물 표시를 나타낸다.
4. 확인결과이력은 확인연월일·확인자·결재자를 최근 순으로 나열한다.
5. 첨부파일은 위치도·건축물배치도·종전·변경 네 단추로 나뉘고, 고른 종류의 사진 한 장을 아래에 보여 준다. 위치도는 등록 시 지금 보이는 지도를 넣는다. 사진이 있는 종류는 단추에 표시가 붙는다.
6. 수정을 누르면 기본정보를 입력칸으로 바꾸고, 건축물내용·확인결과이력에는 추가와 행 삭제가, 첨부파일에는 등록·변경·삭제가 나타난다.
7. 패널이 길어지면 상세 안에서 스크롤되어 첨부파일이 잘리지 않는다.

#### 확인사항

1. 목록에서 고른 관리대장의 위치가 상세 제목에 나와야 한다.
2. 건축물내용이 여러 건이면 모두 표에 행으로 나와야 한다.
3. 확인결과이력이 없는 관리대장은 «확인결과이력이 없습니다» 안내가 나와야 한다.
4. 첨부파일 단추가 위치도·건축물배치도·종전·변경 네 개로 보여야 한다.
5. 단추를 바꾸면 그 종류의 사진만 보여야 하고, 사진은 종류별 한 장만 들어가야 한다.
6. 확인결과이력 아래 첨부파일 영역이 잘리지 않고 끝까지 보여야 한다.
7. 수정 상태에서만 추가·삭제와 사진 등록이 보여야 한다.
8. 다른 관리대장을 고르면 상세 내용이 그 대장으로 바뀌어야 한다.
9. 상세 닫기를 누르면 목록만 남아야 한다.

│      │  │ 불량 건축물 표시  [A] [B] [C] [D]        │   │                                      │
│      │  ├──────────────────────────────────────────┤   │                                      │

#### 설명

1. 수정 상태에서 건축물내용의 추가를 누르면 입력창이 화면 가운데에 열린다.
2. 동 구분·설치연월일·구조·용도·면적을 넣는다.
3. 불량 건축물 표시는 여럿 고를 수 있고 고른 것만 표에 표시된다.
4. 담기를 누르면 상세의 건축물내용 표에 행이 하나 늘고, 취소를 누르면 아무 것도 바뀌지 않는다.
5. 확인결과이력 추가도 같은 방식이며 확인연월일·확인자·결재자만 넣는다.

#### 확인사항

1. 담기를 누르면 표 마지막에 방금 넣은 내용이 나와야 한다.
2. 설치연월일에 «1923.»처럼 날짜가 아닌 표기를 넣어도 그대로 담겨야 한다.
3. 면적을 비우고 담으면 «면적을 입력해 주세요» 안내가 나와야 한다.
4. 취소하거나 닫기를 누르면 표가 그대로여야 한다.
5. 담은 행은 수정 상태에서 삭제할 수 있어야 한다.
