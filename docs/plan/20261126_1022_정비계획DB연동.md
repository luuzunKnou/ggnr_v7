# 작업계획서

2026-11-26 | dev.strcat | 정비계획 명세서 DB 사용 전환 요청

## 개발목표

정비계획 명세서를 임시 저장소가 아니라 DB의 정비계획·계획시설 표로 불러오고 저장한다. 시설명칭과 위치는 관리번호로 각 시설 표를 찾아 시설명과 «읍면 리»로 채우고, 소교량 묶음은 묶음 관리번호와 리 정보로 채운다.

안전점검의 «정비계획 이관»도 DB에 직접 작성중 상태로 추가하며, 이미 계획에 들어간 시설과 소교량 묶음은 중복 추가하지 않는다. 예산 화면은 기존 임시 저장소를 계속 사용한다.

## 플로우차트

안전점검 → 이관 확인 → (DB 추가) → 정비계획 명세서 ⇄ 연도구간 선택 → 입력 → 저장 → 엑셀

## 화면설계

### SP-PLAN-01 정비계획 명세서

```
┌────────┬───────────────────────────────────────────────────────────────────────────┐
│사이드바│ 정비계획  중기 정비계획 명세서 (단위: m, 백만원, %)    [연도 등록][엑셀][X] │
│        ├───────────────────────────────────────────────────────────────────────────┤
│        │ [전체 읍면 v] [2026~2030년 v] [시설명·리명 검색]      대상 170곳 총사업비 │
│        ├──────────┬────────┬─────────┬────────┬──────────────┬─────────┬──────────┤
│        │ 시설명칭 │ 위치   │전체정비 │정비된  │ 중기 정비계획│5개년 후 │ 우선순위 │
│        ├──────────┼────────┼─────────┼────────┼──────────────┼─────────┼──────────┤
│        │ 계       │ 80곳   │         │        │              │         │          │
│        │ 온양리_… │울진읍  │         │        │              │         │ 1        │
│        │          │온양리  │         │        │              │         │          │
│        │ 부구리_소│북면    │         │        │              │         │ 3        │
│        │ 교량_통합│부구리  │         │        │              │         │          │
│        ├──────────┴────────┴─────────┴────────┴──────────────┴─────────┴──────────┤
│        │ 총 80건                                              [저장] [취소]        │
└────────┴───────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 화면을 열면 현재 연도가 포함된 연도구간의 명세서를 DB에서 불러온다.
2. 연도구간 선택을 바꾸면 해당 구간의 계획시설만 다시 불러온다.
3. 시설명칭은 관리번호로 찾은 시설명, 위치는 «읍면 리»로 보인다. 소교량 묶음은 묶음 관리번호와 리 정보로 보인다.
4. 정비된 부분, 중기 연차별 사업량·사업비, 사업효과, 5개년 후 값은 직접 입력하며 사업비 단위는 백만원이다.
5. 저장을 누르면 입력한 행만 DB에 반영되고 입력 칸 배경 표시가 풀린다.

#### 확인사항

1. 시설명칭과 위치가 비어 있는 행이 없어야 한다.
2. 소교량 묶음 행은 «리명_소교량_통합»과 해당 읍면·리가 나와야 한다.
3. 연도구간을 바꾸면 행 수가 달라지고(첫 구간 80곳, 둘째 구간 90곳) 합계가 맞아야 한다.
4. 저장 후 다시 열어도 입력한 값이 유지되어야 한다.
5. 연도 등록 시 새 구간이 선택 목록에 나타나야 한다.

### SP-PLAN-02 이관 확인

```
┌────────┬───────────────────────────────────────────────────────────────────────────┐
│사이드바│ 정비계획으로 이관                                                          │
│        ├───────────────────────────────────────────────────────────────────────────┤
│        │ [ ] 시설명        구분    읍면   리      직전구분  점검일     비고         │
│        │ [x] 고성리_소교량_통합 (3곳)  죽변면  고성리  관리      2026-11-01          │
│        │ [ ] 온양리_농로_003    농로    울진읍  온양리  관리      2026-11-01 포함됨   │
│        ├───────────────────────────────────────────────────────────────────────────┤
│        │                                                   [취소]  [이관]          │
└────────┴───────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 창을 열 때 DB에 이미 들어간 관리번호를 조회해 «포함됨»을 표시한다.
2. 소교량은 리 단위 한 줄로 보이고 소속 곳 수가 함께 나온다.
3. 이관하면 시설은 개별로, 소교량은 묶음 한 건으로 작성중 상태로 추가된다.

#### 확인사항

1. 이미 계획에 있는 시설은 선택할 수 없어야 한다.
2. 이관 후 정비계획 명세서가 열리고 추가된 행이 보여야 한다.
3. 같은 리 소교량을 다시 이관해도 묶음이 중복 추가되지 않아야 한다.
