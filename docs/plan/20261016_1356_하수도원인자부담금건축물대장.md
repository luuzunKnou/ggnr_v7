# 작업계획서

2026-10-16 | 213am | 하수도 원인자부담금 건축물대장 연동

## 개발목표

의성 하수도 원인자부담금 등록·변경 화면에서 주소를 고르면, 해당 필지의 건축물대장 표제부와 층별개요를 불러와 산정 행 초안을 채운다. 동·층·면적·세대수와 대장 용도명은 초안에 넣고, 단가표의 건축용도는 담당자가 확인해서 고른다.

대장의 주용도명과 원인자부담금 건축용도는 같지 않으므로 자동으로 확정하지 않는다. 호별 전유면적·오수정화시설은 이번 범위에 넣지 않는다. 인증키는 기존 시스템 설정에만 두고 서버에서 조회한다. 영향 받는 기능: 원인자부담금 등록·변경·조회, 주소 검색.

## 플로우차트

```
원인자부담금 상세 → 주소 선택 → (대장 조회) → 산정 행 초안 → 건축용도 확인 → 저장
```

## 화면설계

### FEE-BLDG-01 주소 선택 후 대장 조회

```
┌──────────────┬──────────────────────────────────────────────────────────┐
│ 원인자부담금 │ 납부자명 [        ]          납부자번호 [        ]       │
│ [추가][검색] │ 주소     [의성군 ○○면 ○○리 123]  상세주소 [        ]    │
│              │ 건물명   [                              ]               │
│ 2024-01 홍길동│──────────────────────────────────────────────────────────│
│ 의성군 ○○면   │ 원인자부담금          [부과대장] [건축용도 & 단가표]   │
│              │ 건축물대장을 조회하는 중입니다.                          │
│ 2023-11 김○○ │ ┌────────────────────────────────────────────────────┐ │
│ 의성군 ○○읍   │ │건축용도│동별│층별│세대수│입력값│오수발생량│산정오수량│ │
│              │ │        │    │    │      │      │          │          │ │
│              │ └────────────────────────────────────────────────────┘ │
└──────────────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 등록·변경 화면에서 주소를 고르면 필지번호로 건축물대장을 조회한다.
2. 조회하는 동안 «건축물대장을 조회하는 중입니다»가 보인다.
3. 조회 화면에서는 주소를 다시 골라도 대장을 조회하지 않는다.
4. 조회가 실패해도 선택한 주소는 남고, 이미 있는 산정 행은 바꾸지 않는다.

#### 확인사항

1. 주소를 고르면 조회 안내가 보여야 한다.
2. 조회에 실패하면 «건축물대장을 불러오지 못했습니다. 직접 입력하세요» 안내가 나와야 한다.
3. 저장된 건을 열람만 할 때는 대장 조회가 되지 않아야 한다.

### FEE-BLDG-02 산정 행 초안

```
┌──────────────┬──────────────────────────────────────────────────────────┐
│ 원인자부담금 │ 납부자명 [홍길동]            납부자번호 [        ]       │
│              │ 주소     [의성군 ○○면 ○○리 123]  상세주소 [        ]    │
│              │ 건물명   [                              ]               │
│              │──────────────────────────────────────────────────────────│
│              │ 원인자부담금                                             │
│              │ 대장 용도: 다가구주택 · 연면적 320㎡. 건축용도를 선택하세요.│
│              │ ┌────────────────────────────────────────────────────┐ │
│              │ │건축용도│동별  │층별│세대수│입력값│오수발생량│비고      │ │
│              │ │[선택] │본동  │1층│ 4    │120   │          │다가구주택│ │
│              │ │[선택] │본동  │2층│      │200   │          │다가구주택│ │
│              │ └────────────────────────────────────────────────────┘ │
│              │                              [저장]                     │
└──────────────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 산정 행이 비어 있으면 층별개요 한 층이 한 행이 된다.
2. 동 이름·층은 동별·층별에, 층 면적은 입력값에 넣는다.
3. 세대수는 같은 동의 첫 행에만 넣고, 대장 용도명은 비고에 넣는다.
4. 건축용도 칸은 비워 두고, 안내 문구로 대장 용도·연면적을 보여 준다.
5. 이미 산정 행이 있으면 «기존 산정 내용을 건축물대장 기준으로 바꿀까요?»를 확인한 뒤에만 바꾼다.

#### 확인사항

1. 층이 두 개면 산정 행이 두 줄로 채워져야 한다.
2. 세대수가 모든 층에 반복되지 않아야 한다.
3. 건축용도를 고르기 전에는 저장되지 않아야 한다.
4. 바꾸기 확인에서 취소하면 기존 산정 행이 유지되어야 한다.

### FEE-BLDG-03 대장 없음·여러 동

```
┌──────────────┬──────────────────────────────────────────────────────────┐
│ 원인자부담금 │ 주소 [의성군 ○○면 ○○리 산 12]                            │
│              │──────────────────────────────────────────────────────────│
│              │ 건축물대장을 찾을 수 없습니다. 직접 입력하세요.           │
│              │ ┌────────────────────────────────────────────────────┐ │
│              │ │건축용도│동별│층별│세대수│입력값│오수발생량│산정오수량│ │
│              │ │[선택] │    │    │      │      │          │          │ │
│              │ └────────────────────────────────────────────────────┘ │
└──────────────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 대장이 없으면 안내만 하고 빈 행으로 직접 입력한다.
2. 동이 여러 개면 동마다 층별 행을 나눠 채운다.
3. 한 번에 가져오는 목록이 많으면 이어서 조회해 빠뜨리지 않는다.

#### 확인사항

1. 대장이 없는 주소는 빈 산정표가 유지되어야 한다.
2. 동이 두 개면 동별 값이 다르게 채워져야 한다.
3. 변경 화면에서도 당초가 아닌 변경 산정표에만 초안이 들어가야 한다.
