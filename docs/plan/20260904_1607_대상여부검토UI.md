## 개발목표

업무자료 대상여부 검토에서 사업규모 입력과 절차 목록이 한 좁은 칸에 세로로 쌓여 둘 다 잘리지 않게 한다. 지도를 더 가려도 되므로 검토 화면만 가로로 넓히고, 왼쪽은 규모 작성·오른쪽은 목록이 보이게 나눈다. 문서·도면 탭 너비와 판정 계산은 바꾸지 않는다.

## 플로우차트

```
업무자료 → 대상여부 검토 → 사업규모 입력·적용 → 절차 목록 → 절차 상세
```

## 화면설계

### ROAD-HB-UI-01 대상여부 검토 두 칸

```
┌────┬──────────────────────────────────────────────────────────────────────┐
│    │ 검색                                                                  │
│ 지 ├──────────────────────────────────────────────────────────────────────┤
│ 도 │ 업무자료                                                              │
│ 사 │ 대상여부 검토 및 설계실무요령                                         │
│ 이 ├──────────────────────────────────────────────────────────────────────┤
│ 드 │ 문서    도면    대상여부 검토    설계실무요령 자료                    │
│ 바 ├───────────────────┬──────────────────────────────────────────────────┤
│    │ 사업규모          │ 절차명, 기준, 법령 검색                           │
│    │ 입력 후 적용      │ 전체  해당  미만  입력필요  판단                  │
│    │                   ├──────────────────────────────────────────────────┤
│    │ 신설구간          │ 해당  과업포함                                    │
│    │ [    ] km  구간   │ 1. 사전재해영향성검토                             │
│    │ 확장구간          │ 신설 4km 이상 또는 확장 10km 이상 · 기본설계      │
│    │ [    ] km  구간   ├──────────────────────────────────────────────────┤
│    │ 사업면적          │ 입력필요  별도                                    │
│    │ [    ] ㎡  범위   │ 2. 사전환경성검토                                 │
│    │ 용도지역          │ 관리지역별 면적 기준 · 기본설계                   │
│    │ [선택          ]  ├──────────────────────────────────────────────────┤
│    │ 도로 종류         │ …                                                 │
│    │ [선택          ]  │                                                   │
│    │ 총공사비          │                                                   │
│    │ [    ] 억원       │                                                   │
│    │ 1·2종 시설물      │                                                   │
│    │ [선택          ]  │                                                   │
│    │                   │                                                   │
│    │ [적용] [취소]     │                                                   │
│    └───────────────────┴──────────────────────┬───────────────────────────┤
│                                               │ 사전재해영향성검토        │
│                                               │ 관련 법령 · 대상 기준     │
└───────────────────────────────────────────────┴───────────────────────────┘
```

#### 설명

1. 대상여부 검토를 열면 업무자료 칸이 문서·도면보다 넓어지고, 안을 사업규모와 절차 목록 두 칸으로 나눈다.
2. 왼쪽에서 규모를 적고 적용하면 오른쪽 목록의 해당·미만·입력필요 표시가 바뀐다.
3. 검색과 해당·미만 필터는 오른쪽 목록 위에만 둔다.
4. 절차 이름과 기준은 한 줄에서 자르지 않고 두 줄까지 보이게 한다.
5. 문서·도면으로 돌아가면 이전처럼 좁은 칸을 쓴다.

#### 확인사항

1. 대상여부 검토에서 규모 작성과 절차 목록이 좌우로 나란히 보여야 한다.
2. 규모 칸이 길어도 오른쪽 목록 높이가 줄어들지 않아야 한다.
3. 절차 이름·기준이 칸 너비 안에서 두 줄까지 보여야 한다.
4. 적용 후 목록 배지가 바뀌고, 취소하면 입력이 비워져야 한다.
5. 문서·도면 탭은 이전 너비로 보여야 한다.

### ROAD-HB-UI-02 설계실무요령 자료

```
┌────┬──────────────────────────────────────────────────────────────────────┐
│ 지 │ 업무자료                                                              │
│ 도 │ 문서    도면    대상여부 검토    설계실무요령 자료                    │
│ 사 ├──────────────────────────────────────────────────────────────────────┤
│ 이 │ 자료명, 파일명, 출처 검색                                             │
│ 드 ├──────────────────────────────────────────────────────────────────────┤
│ 바 │ 1,2장. 적용범위, 실시설계용역                                         │
│    │ 도로법 시행령 · 원문                                                  │
└────┴──────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 설계실무요령 자료는 규모 칸 없이 같은 넓은 목록만 쓴다.

#### 확인사항

1. 설계실무요령 자료에서 왼쪽 규모 칸이 나오지 않아야 한다.
