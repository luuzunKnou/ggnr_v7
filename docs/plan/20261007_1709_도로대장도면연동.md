## 개발목표

도로대장 상세의 «매설물도·종평면도·용지도» 버튼에 경산 도면 구역 레이어를 연결한다. 버튼을 켜면 시설과 같은 탭 줄에 도면 탭이 생기고, 탭 안에는 해당 노선의 도면 목록이 나온다.

도면을 고르면 지도에서 그 구역으로 이동·강조하고, 탭 영역이 하천 기본계획 색인도 상세처럼 첨부 도면 미리보기와 속성표로 바뀐다. 첨부는 분할코드 폴더에서 읽고, 속성은 레이어 관리 설정(한글명·상세 표시 여부·순서)을 따른다.

영향 받는 기능: 도로대장 상세의 시설 버튼·건수·시설 탭 목록, 시설 속성 팝업, 지도 클릭 시설 식별, 도로대장 지도 강조.

## 플로우차트

```
도로대장 목록 → 노선 상세 → (도면 버튼) → 도면 목록 탭 ⇄ 도면 상세(첨부·속성) → 전체화면 미리보기
```

#### 설명

1. 레이어가 올라와 있으면 «매설물도·종평면도·용지도» 버튼이 활성화되고 노선 도면 건수가 괄호로 나온다.
2. 버튼을 누르면 지도에 도면 구역 레이어가 켜지고, 아래 탭 줄에 해당 도면 탭이 추가·선택된다.
3. 도면 탭에는 노선에 해당하는 도면이 분할코드 순으로 두 줄 격자 버튼으로 나온다.
4. 시설 탭(주요시설 등)은 기존처럼 표 목록과 속성 팝업으로 동작한다.

#### 확인사항

1. 레이어가 없는 프로젝트에서는 세 버튼이 비활성으로 보여야 한다.
2. 버튼 건수와 탭 목록 건수가 같아야 한다.
3. 버튼을 다시 누르면 지도 레이어와 탭이 함께 사라져야 한다.
4. 다른 노선의 도면이 목록에 섞이지 않아야 한다.

```
│    │              │ │ │분할코드 │ KS_GD_..02 ││ │                              │
│    │              │ └────────────────────────┘ │                              │
└────┴──────────────┴──────────────────────────┴──────────────────────────────┘
```

#### 설명

1. 목록에서 도면을 고르면 지도가 해당 구역으로 이동하고 강조 표시된다.
2. 탭 영역이 상세로 바뀌어 위쪽에 첫 이미지·PDF 미리보기, 아래에 첨부파일 목록과 속성표가 나온다.
3. 미리보기나 첨부파일을 누르면 이미지·PDF 전체화면 미리보기가 열리고 여러 장을 넘겨 볼 수 있다.
4. 이미지·PDF가 아닌 첨부는 내려받기로 처리한다.
5. «‹»(목록으로)를 누르면 강조가 해제되고 도면 목록으로 돌아간다.

#### 확인사항

1. 첨부 폴더가 없으면 «첨부 도면이 없습니다» 안내가 나와야 한다.
2. 속성 항목은 레이어 관리의 한글명과 상세 표시 설정을 따라야 한다.
3. 지도에서 도면 구역을 클릭해도 같은 상세가 열려야 한다.
4. 시설 속성 팝업이 도면 선택 때 함께 뜨지 않아야 한다.
