## 개발목표

위상검증 «유수방향 확인필요» 중 양방향 만남을, 임의 한 관로 반전이 아니라 접합점 단위 검토 도구로 바꾼다. 상단 필터(`전체 | 접합확인필요 | 유수방향 확인필요`)는 그대로 두고, 양방향 세부 유형은 **오류 목록 문구·라벨로만** 구분한다. 2단 필터는 두지 않는다. 접합점에 모인 관로를 모두 보여 주고, 담당자가 뒤집을 관로만 고른 뒤 미리보기로 확인한 다음 저장한다. 시스템이 추천을 줄 수는 있으나 자동 일괄 반전은 하지 않는다.

## 플로우차트

```
위상검증 → 오류 목록(유형 라벨) → 접합점 선택 → 관로 전체 표시 → (선택·추천) 반전 미리보기 → 확정 저장 → 재검증
```

## 화면설계

### MAP-TOPO-MEET-01 오류 목록(유형 라벨)

```
┌──────────┬──────────────────────────────────────────────┐
│ 사이드바  │  공간분석 · 위상검증                          │
│ · 공간분석│  전체 | 접합확인필요 | 유수방향 확인필요      │
│ · …      │  (필터 형태·위치 유지, 아래 추가 필터 없음)   │
│          │──────────────────────────────────────────────│
│          │  오류 목록                                     │
│          │  구분              대상              내용      │
│          │  유수방향 확인필요  접합점(3)·서로마주봄  …    │
│          │  유수방향 확인필요  접합점(2)·하류없음    …    │
│          │  유수방향 확인필요  관로 #123 · 역방향     …    │
│          │           [지도 · 오류 위치]                   │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 상단 필터는 지금과 동일하게 세 칸만 둔다. 유수방향 아래에 세부 칩·드롭다운을 추가하지 않는다.
2. 양방향 만남 유형(서로 마주 봄·하류 없음·한쪽 반전 후보 등)은 대상 또는 내용 칸 문구·짧은 라벨로만 보여 준다.
3. 역방향 도화는 기존처럼 내용 문구로 구분하고, 목록 높이·레이아웃은 현재와 같게 유지한다.
4. 행을 고르면 해당 접합점(또는 관로)으로 지도가 이동하고, 양방향이면 접합점 검토로 이어진다.

#### 확인사항

1. 상단 필터가 세 칸 그대로여야 한다.
2. 양방향 만남 행에 유형 라벨이 대상 또는 내용에 보여야 한다.
3. 유수방향 선택 시에도 목록 영역 높이가 지금과 비슷해야 한다.
4. 임의 한 관로만 반전 대상으로 잡히지 않아야 한다.

### MAP-TOPO-MEET-02 접합점 관로 검토

```
┌──────────┬──────────────────────────────────────────────┐
│ 사이드바  │  접합점 검토                    [미리보기] [저장]│
│ · 공간분석│  유형: 서로 마주 봄 · 유입 3개                 │
│          │──────────────────────────────────────────────│
│          │  ☑ 관로 A  (추천 반전)                         │
│          │  ☐ 관로 B                                     │
│          │  ☑ 관로 C  (추천 반전)                         │
│          │──────────────────────────────────────────────│
│          │  안내: 선택 관로만 유수방향이 바뀝니다.         │
│          │           [지도 · 선택 관로 강조]               │
└──────────┴──────────────────────────────────────────────┘
```

#### 설명

1. 접합점에 모인 관로를 전부 목록·지도에 표시하고 체크박스로 반전 대상을 고른다.
2. 추천이 있으면 표시하되, 기본 선택은 담당자가 바꾸기 전까지 확정으로 쓰지 않는다.
3. 미리보기는 세션에만 반영하고, 저장을 눌렀을 때만 실제 반영한다.
4. 저장 후 위상검증을 다시 돌려 해당 접합점이 줄었는지 바로 볼 수 있게 한다.

#### 확인사항

1. 유입 n개가 모두 목록과 지도에 보여야 한다.
2. 체크하지 않은 관로는 반전·저장되지 않아야 한다.
3. 미리보기 후 저장 취소 시 도형이 원래대로여야 한다.
4. 저장 후 재검증에서 해당 만남이 해소되거나 유형이 바뀌어야 한다.
5. 일괄 자동 반전 버튼은 없어야 한다.
