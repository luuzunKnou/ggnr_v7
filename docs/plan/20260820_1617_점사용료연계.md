## 개발목표

차세대 점사용료 연계가 조회 테이블의 세입과목명에 하천·도로·국유·공유·도유가 들어 있는지 보고 세 테이블에 나눠 넣는다. 한 건을 받아 저장할 때 물건지주소로 지적을 찾아 도형을 함께 넣는다. 도형을 못 찾으면 속성은 그대로 저장한다.

## 플로우차트

```
조회테이블 → 두 인터페이스 조합조회 → (세입과목명 포함) 하천·도로·국공유지 테이블 → 물건지주소 정규화·지적검색 → 속성·도형 저장
```

## 화면설계

### FEE-SYNC-01 점사용료 연계 저장

```
┌──────────────────────────────────────────────────────────────┐
│ [사이드]  검색│필터│지도                                      │
│  점사용료     ┌────────────────────────────────────────────┐ │
│              │ 목록 (해당 시스템 테이블)                     │
│              │ 상태 · 대장번호 · 부서 · 납부자 …            │
│              └────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 연계는 매일 정해진 시각에 돌고, 조회 테이블의 사용 중인 행과 두 인터페이스를 조합해 받아 온다.
2. 세입과목명에 하천이 있으면 하천 점사용료, 도로가 있으면 도로 점사용료, 국유·공유·도유가 있으면 국공유지 점사용료에 넣는다.
3. 저장 직전에 물건지주소 한 건을 정규화해 지적 도형을 붙인다. 실패해도 속성은 남긴다.
4. 화면은 시스템마다 해당 테이블만 보여 준다.

#### 확인사항

1. 하천점용료·소하천점용료는 하천 점사용료 테이블에 들어가야 한다.
2. 계속도로점용료·도로사용료는 도로 점사용료 테이블에 들어가야 한다.
3. 국유·공유·도유가 들어간 과목명은 국공유지 점사용료 테이블에 들어가야 한다.
4. 저장 행에 물건지주소가 있고 지번이 있으면 도형이 같이 들어가야 한다.
5. 주소를 해석하지 못해도 속성 저장은 되어야 한다.
