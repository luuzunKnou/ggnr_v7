## 개발목표

수치지형도(25000)를 도엽 파일(100~165MB)에서 매번 읽어 만들던 방식에서, 미리 데이터베이스에 적재한 도형을 줌 단계별 타일로 내려받아 그리는 방식으로 바꾼다.

원본 도면의 선 색상(레이어 색), 점선 선종류, 글자(한글·크기·회전각)를 그대로 유지한다. 하천·건물·등고선 등 기존에 잘려 나가던 요소도 줌에 맞춰 나타나게 한다.

데이터베이스 적재가 끝난 폴더만 새 방식을 쓰고, 적재되지 않은 폴더(1000·5000 등)는 기존 방식을 그대로 쓴다. 적재는 사용자가 명시적으로 지시했을 때만 실행하는 별도 명령으로 분리한다.

## 플로우차트

수치지형도 폴더 체크 → (적재 여부 확인) → 타일 방식 / 기존 방식 → 줌별 타일 요청 → 서버 도형 추출 → 지도 표시

## 화면설계

### MAP-DGM-01 수치지형도 확대 표시

```
┌────────────────────────────────────────────────────────────────────┐
│ [검색창                                  ]                [수치지형도] │
├──────┬─────────────────────────────────────────────┬──────────────┤
│ 사이 │                                             │ 수치지형도    │
│ 드바 │                                             │ ─────────────│
│      │        지도 (도로·하천·등고선·건물·글자)       │ 수치지형도(1000)│
│ 메모 │                                             │   [ 꺼짐 ]    │
│ 민원 │                                             │ 수치지형도(5000)│
│ 측정 │                                             │   [ 꺼짐 ]    │
│      │                                             │ 수치지형도(25000)│
│      │                                             │   [ 켜짐 ]    │
│      │                                             │              │
└──────┴─────────────────────────────────────────────┴──────────────┘
```

#### 설명

1. 우측 «수치지형도» 목록에서 폴더를 켜면 해당 폴더가 적재되어 있는지 먼저 확인한다.
2. 적재된 폴더는 도엽 파일을 읽지 않고, 보이는 화면 범위의 타일만 내려받아 그린다.
3. 축소 상태에서는 도엽 테두리만 보이고, 일정 수준 이상 확대하면 도로·하천·등고선이 나타난다. 더 확대할수록 건물·시설·지명·표고 글자가 추가로 나타난다.
4. 선 색상, 점선, 글자는 원본 도면과 같게 보인다. 글자는 확대할수록 커지고 회전각이 유지된다.
5. 적재되지 않은 폴더는 지금처럼 도엽 파일을 읽어 그린다.

#### 확인사항

1. 수치지형도(25000)를 켜면 첫 화면이 몇 초 안에 그려져야 한다.
2. 확대할수록 하천·건물·등고선이 추가로 나타나야 한다.
3. 건물·울타리 등 점선 선종류가 점선으로 보여야 한다.
4. 한글 지명이 깨지지 않고 보여야 한다.
5. 적재되지 않은 수치지형도(1000)·(5000)는 기존과 똑같이 동작해야 한다.
6. 다른 지도 기능 패널을 열고 닫아도 수치지형도 표시가 남아 있어야 한다.
