## 개발목표

레이어 설정에서 CAD 다운로드를 누르면 레이어와 DXF·DWG를 고르는 창이 열린다. 현재 지도 화면에 보이는 범위의 선택한 벡터 레이어 도형을 하나의 CAD 파일로 내려받는다. 배경·정사는 선택 대상이 아니다.

## 플로우차트

```
지도 → 레이어 설정 → CAD 다운로드 → 레이어·형식 선택 → 단일 CAD 파일
```

## 화면설계

### MAP-LAYER-CAD-01 레이어 설정 CAD 버튼

```
┌──────┬──────────────────────────────────────────────────────────┐
│메뉴  │  검색                                                    │
│      │ ┌──────────────────────────────────────────────────────┐ │
│      │ │레이어 설정                    [CAD 다운로드] [닫기]  │ │
│      │ │지도에 보여줄 레이어를 설정합니다                      │ │
│      │ │ [레이어 검색________________]                         │ │
│      │ │  □ 그룹A   □ 레이어1  □ 레이어2 …                     │ │
│      │ └──────────────────────────────────────────────────────┘ │
│      │                         지도                             │
└──────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 레이어 설정 헤더에 CAD 다운로드 버튼이 있다.
2. 버튼을 누르면 레이어·형식 선택 창이 열린다.
3. 기존 레이어 켜기·끄기는 그대로 동작한다.

#### 확인사항

1. CAD 다운로드 버튼이 레이어 설정에 보여야 한다.
2. 버튼을 누르면 선택 창이 열려야 한다.
3. 선택 창을 닫아도 레이어 설정은 유지되어야 한다.

### MAP-LAYER-CAD-02 레이어·형식 선택

```
┌──────┬──────────────────────────────────────────────────────────┐
│메뉴  │  검색                                                    │
│      │                         지도                             │
│      │          ┌────────────────────────────┐                  │
│      │          │ CAD 다운로드               │                  │
│      │          │ 현재 화면 범위의 도형만    │                  │
│      │          │ ☑ 레이어1  ☐ 레이어2 …    │                  │
│      │          │ ○ 도면(DXF)  ○ 캐드(DWG)  │                  │
│      │          │        [취소] [다운로드]   │                  │
│      │          └────────────────────────────┘                  │
└──────┴──────────────────────────────────────────────────────────┘
```

#### 설명

1. 기본으로 현재 켜진 레이어가 선택되어 있다.
2. 도면·캐드 중 하나를 고른 뒤 다운로드한다.
3. 캐드 변환이 없으면 캐드 항목은 비활성이다.
4. 진행 중에는 안내가 보이고, 끝나면 파일이 저장된다.

#### 확인사항

1. 켜진 레이어가 기본 선택되어야 한다.
2. 레이어를 하나도 고르지 않으면 다운로드가 진행되지 않아야 한다.
3. 다운로드 후 도면 또는 캐드 파일 하나가 받아져야 한다.
4. 화면 밖 도형만 있는 레이어는 결과에서 빠지거나 안내가 나와야 한다.
