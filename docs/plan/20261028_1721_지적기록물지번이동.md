## 개발목표

지적기록물 상세에서 지번 행을 누르면 해당 필지로 지도를 옮긴다. 첨부 위에 있던 종류·권·쪽·묶인 지번 안내 문구는 없앤다.

## 플로우차트

```
상세 지번 표 → (행 클릭) → 해당 필지로 이동
```

#### 설명

3. 고른 행은 선택된 상태로 보인다.

1. 첨부 위에 권·쪽·묶인 지번 문구가 없어야 한다.
2. 지번 행을 누르면 해당 필지로 지도가 이동해야 한다.
3. 없는 필지를 누르면 찾을 수 없다는 안내가 나와야 한다.
