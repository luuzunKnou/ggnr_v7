## 개발목표

하수 관망조회 시설목록의 공간 범위를 «화면 범위»와 «읍면동 선택» 두 가지로 바꿔 가며 쓸 수 있게 한다. 읍면동 모드에서는 지도에 읍면동 경계가 보이고, 마우스를 올리면 강조되며, 클릭하면 그 행정구역으로 목록이 고정된다. 상수 관망은 이번에 넣지 않는다.

## 플로우차트

```
시설목록 → (화면 범위|읍면동 선택) → (읍면동 모드면) 경계표시 → 호버강조 → 클릭고정 → 목록조회
```

## 화면설계

### SWL-NET-SCOPE-01 범위 모드 선택

```
┌────────────────────────────────────────────────────────────┐
│ 사이드 │ 검색조건 │ 시설목록                              │
│        │          │ [화면 범위] [읍면동 선택]             │
│        │          │ (선택 시) 금성면 · 선택 해제          │
│        │          │ 목록 …                               │
│        │          │                          ┌ 지도 ───┐ │
│        │          │                          │ 읍면동   │ │
│        │          │                          │ 경계·강조│ │
│        │          │                          └─────────┘ │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 시설목록 상단에 화면 범위와 읍면동 선택 중 하나를 고른다.
2. 화면 범위는 지금처럼 지도에 보이는 구역의 시설만 목록에 올린다.
3. 읍면동 선택으로 바꾸면 지도에 읍면동 경계가 켜지고, 구역 위에 마우스를 올리면 강조된다.
4. 읍면동을 클릭하면 그 구역으로 목록이 고정되고, 선택 해제로 다시 고를 수 있다.

#### 확인사항

1. 화면 범위와 읍면동 선택이 동시에 켜지지 않아야 한다.
2. 읍면동 모드에서 경계가 지도에 보여야 한다.
3. 마우스를 올린 구역이 강조되어야 한다.
4. 클릭한 읍면동 시설만 목록에 나와야 한다.
5. 화면 범위로 되돌리면 읍면동 경계·선택이 사라져야 한다.
