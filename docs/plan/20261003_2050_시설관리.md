## 개발목표

시설관리에 들어가면 관망조회와 같이 위쪽에 밑줄 탭이 보인다. 탭은 취수장, 정수장, 배수지, 가압장, 감압변, 소방시설, CCTV이다. 이번은 탭 전환과 빈 본문만 두고, 목록·상세는 다음에 넣는다.

## 플로우차트

```
지도 → 시설관리 → 상단 탭 전환 → (이후 목록·상세)
```

## 화면설계

### FAC-01 시설관리 탭

```
┌────┬──────────────────────────────────────┐
│상수│ 시설관리                          ✕  │
│행정│──────────────────────────────────────│
│    │취수장 정수장 배수지 가압장 감압변 … │
│시설│──────────────────────────────────────│
│관리│                                      │
│    │         (선택한 탭 본문)             │
│    │                                      │
└────┴──────────────────────────────────────┘
```

#### 설명

1. 사이드바에서 «시설관리»를 누르면 왼쪽 패널이 열린다.
2. 패널 위쪽에 일곱 개 밑줄 탭이 한 줄로 있다.
3. 탭을 누르면 선택 표시가 바뀌고 아래 본문이 바뀐다.
4. 이번 단계에서는 본문에 선택한 탭 이름만 안내한다.

#### 확인사항

1. 시설관리를 열면 취수장부터 CCTV까지 탭이 보여야 한다.
2. 탭을 바꾸면 선택이 바뀌고 아래에 해당 이름이 나와야 한다.
3. 관망조회와 같이 아이콘 없는 밑줄 탭이어야 한다.
