## 개발목표

데이터조회에서 레이어를 켜고 지도를 클릭했을 때, 여러 건이 겹치면 후보 목록을 지도 위에 띄운다. 그 중 하나를 고르면 오른쪽은 기존 목록 화면을 유지한 채 해당 항목 페이지로 이동하고 상세를 연다. 한 건이면 지도 위 목록 없이 바로 이동한다. 지도 위 목록 닫기는 창만 바로 닫는다.

## 플로우차트

```
데이터조회 → 레이어 켜기 → 지도 클릭 → (여러 건) 지도 위 목록 → 항목 선택 → 기존 목록 해당 페이지·상세
```

## 화면설계

### MAP-DQ-PICK-01 지도 위 다중 선택 목록

```
┌──────────────────────────────────────────────────────────┐
│ 공간정보조회                                              │
│┌──┐┌────────┐┌─────────────────────────────────────────┐│
││메││레이어  ││                                         ││
││뉴││목록    ││          지도                           ││
││  ││☑ 가로등││     ┌─────────────────┐                 ││
││  ││        ││     │데이터 목록 (2)  │                 ││
││  ││        ││     │가로등 | 19      │                 ││
││  ││        ││     │가로등 | 20      │                 ││
││  ││        ││     │          닫기   │                 ││
││  ││        ││     └─────────────────┘                 ││
│└──┘└────────┘└─────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 데이터조회에서 레이어를 켠 뒤 지도를 클릭해 여러 건이 맞으면 클릭 위치에 목록이 뜬다.
2. 오른쪽은 식별 결과로 바뀌지 않고, 열려 있던 기존 목록이 그대로 유지된다.
3. 목록에서 한 줄을 고르면 지도 위 창이 닫히고 오른쪽 기존 목록이 그 항목 페이지로 이동한다.
4. 닫기를 누르면 지도 위 창만 바로 닫힌다.

#### 확인사항

1. 여러 건이 맞으면 지도 위에 후보 목록이 떠야 한다.
2. 오른쪽이 «지도에서 선택된 항목»으로 바뀌지 않아야 한다.
3. 닫기를 누르면 지도 위 창만 닫히고 목록은 그대로여야 한다.

### MAP-DQ-PICK-02 목록 항목 선택 후 상세

```
┌──────────────────────────────────────────────────────────┐
│ 공간정보조회                                              │
│┌──┐┌────────┐┌────────────┐┌───────────────────────────┐│
││메││레이어  ││가로등      ││                           ││
││뉴││목록    ││번호 위치 … ││          지도             ││
││  ││☑ 가로등││19  …       ││                           ││
││  ││        ││────────────││                           ││
││  ││        ││기본정보    ││                           ││
││  ││        ││번호  19    ││                           ││
│└──┘└────────┘└────────────┘└───────────────────────────┘│
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 지도 위 목록에서 고른 항목이 기존 목록의 해당 페이지에 선택되어 보인다.
2. 아래 상세에 그 항목의 기본정보가 열린다.
3. 한 건만 맞으면 지도 위 목록 없이 같은 목록·상세로 바로 이동한다.

#### 확인사항

1. 고른 항목이 목록에서 선택·상세로 보여야 한다.
2. 목록 페이지가 그 항목이 있는 쪽으로 바뀌어야 한다.
3. 한 건 클릭 시 지도 위 목록이 뜨지 않아야 한다.
