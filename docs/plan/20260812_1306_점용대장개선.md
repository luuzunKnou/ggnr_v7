# 작업계획서

2026-08-12 | dev.strcat | docs/brief/20260812_1306_점용대장개선.md

## 개발목표

울진·공통 점용 상세에서 허가번호·키 미리보기·면적 자동계산·점용장소 검색·도형 중심주소 자동입력을 맞추고, 울진은 불필요 필드를 숨긴 뒤 하천명·하천유형을 하천계획 레이어로 선택하게 한다.

## 플로우차트

상세 추가·수정 → 허가번호·키 미리보기 → 하천명 선택 → 하천유형 자동 → 점용장소 검색 ⇄ 도형 추가·수정 → 중심주소·면적 반영 → 저장

## 화면설계

### OCC-01 허가번호·키·면적

```
┌────────────────────────────────────────────┐
│ 상세 속성                                  │
│ 키        [9]                              │
│ 허가번호  [2026-01            ]            │
│ 점용면적  [121214.3 ] m²  [자동계산]       │
└────────────────────────────────────────────┘
```

#### 설명

1. 추가 직후 허가번호가 «년도-번호»로 바로 보인다.
2. 공통 키는 다음 순번이 읽기 전용으로 바로 보인다.
3. 면적 옆 자동계산으로 본표 도형 면적을 넣는다.

#### 확인사항

1. 해당 연도 첫 건은 01번이어야 한다.
2. 해가 바뀌면 번호가 01부터여야 한다.
3. 자동계산 후 면적 값을 손으로 고칠 수 있어야 한다.

### OCC-02 점용장소 검색·도형주소

```
┌────────────────────────────────────────────┐
│ 상세 속성                                  │
│ 점용장소  [울진군 울진읍 …    🔍]         │
│ 지도 도형 추가·수정 시 중심 주소 반영      │
└────────────────────────────────────────────┘
```

#### 설명

1. 울진·공통 모두 점용장소에서 주소검색을 한다.
2. 도형 추가·수정이 끝나면 중심 주소가 점용장소에 들어간다.
3. 기존 값과 관계없이 도형 기준으로 갱신한다.

#### 확인사항

1. 울진·공통 점용장소 검색·선택이 되어야 한다.
2. 도형 추가 후에도 점용장소에 주소가 채워져야 한다.
3. 검색으로 고른 뒤에도 값을 수정할 수 있어야 한다.

### OCC-03 울진 하천명·유형·필드정리

```
┌────────────────────────────────────────────┐
│ 상세 속성                                  │
│ 하천명    [ 왕피천            ▼ ]         │
│ 하천유형  [ 지방하천          ] (입력불가) │
│ (읍면동·리·본번·부번·구분·일시면적 없음)   │
│ (더보기·접기 없음)                         │
└────────────────────────────────────────────┘
```

#### 설명

1. 숨긴 여섯 항목은 상세에 나오지 않는다.
2. 하천명은 목록에서 고르고, 하천유형은 자동으로 맞춰지며 직접 고치지 않는다.
3. 더보기·접기 없이 남은 속성을 한 번에 본다.

#### 확인사항

1. 숨긴 항목이 화면에 없어야 한다.
2. 하천명 선택 시 하천유형이 맞게 채워져야 한다.
3. 하천유형은 직접 바꿀 수 없어야 한다.
