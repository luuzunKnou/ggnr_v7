## 개발목표

지적기록물 상세에 들어오면 그 장에 묶인 필지를 지도에 도형으로 그린다. 지번 행을 누르면 해당 필지만 강조하고 그쪽으로 이동한다.

## 플로우차트

```
상세 열림 → 묶인 필지 도형 표시 → (행 클릭) → 해당 필지 강조·이동
```

```
└────┴──────────────────────┴────────────────────────────┘
```

#### 설명

1. 상세가 열리면 묶인 필지 도형이 지도에 그려진다.
2. 지도는 그 필지들이 보이도록 맞춘다.
3. 지번 행을 누르면 그 필지만 강조되고 그 위치로 이동한다.
4. 상세를 닫으면 도형은 사라진다.

#### 확인사항

1. 상세를 열면 묶인 필지 도형이 지도에 나와야 한다.
2. 지번 행을 누르면 해당 필지가 강조되고 지도가 이동해야 한다.
3. 상세를 닫으면 도형이 남아 있지 않아야 한다.
