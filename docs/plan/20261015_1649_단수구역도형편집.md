## 개발목표

제수변 잠금으로 단수 관로를 미리 본 뒤 «분석결과저장»으로 이력에 남긴다. 저장 후 단수 면은 기존 도형 수정·읍면동리 선택·직접그리기 세 가지로 고칠 수 있게 한다. 새 분석은 잠금부터 다시 시작한다.

## 플로우차트

새 분석 → 제수변 잠금(미리보기) → 분석결과저장 → 도형편집(수정·읍면동리·직접그리기) → 문자·설정

## 화면설계

### SPA-OUT-05 분석결과저장·도형편집

```
┌──────사이드────────┬──────────지도──────────┐
│ 이력 · 새 분석      │  제수변·단수관로        │
│ 잠금 · 분석결과저장  │  단수면(편집 가능)     │
│ 도형편집            │                        │
│ 기존수정·읍면동리·그리기 │                     │
└────────────────────┴────────────────────────┘
```

#### 설명

1. 잠금 후 미리보기가 보이면 «분석결과저장»으로 이력에 남긴다.
2. 저장 후 도형편집 메뉴가 열린다.
3. 기존 도형 수정은 꼭짓점을 드래그해 고친다.
4. 읍면동리 선택·직접그리기로 단수 면을 바꿀 수 있다.

#### 확인사항

1. 버튼 문구가 «분석결과저장»이어야 한다.
2. 저장 전에는 도형편집이 비활성·안 보여야 한다.
3. 세 가지 편집 방식 모두 단수 면이 바뀌어야 한다.
4. 새 분석 시 잠금·결과·편집이 초기화되어야 한다.
