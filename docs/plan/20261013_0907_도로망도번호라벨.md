## 개발목표

경산 도로망도는 선 레이어와 번호 포인트 레이어가 따로 있다. 레이어 목록에는 «도로망도» 하나만 보이게 하고, 켜면 선은 도로 분류·선종류별 색과 점선·파선으로, 포인트 위치에는 노선 번호가 분류별 바탕 도형(원·사각) 안에 표시되도록 한다.

포인트 레이어가 없는 프로젝트는 지금처럼 선 스타일만 그대로 보인다.

## 플로우차트

```
레이어 목록 → 도로망도 켜기 → 선 + 번호 라벨 함께 표시 → 도로망도 끄기 → 둘 다 숨김
```

#### 설명

1. 레이어 목록에는 «도로망도» 한 항목만 보이고, 번호 포인트 레이어는 따로 나오지 않는다.
2. «도로망도»를 켜면 선과 번호 라벨이 함께 그려지고, 끄면 함께 사라진다.
3. 선은 고속도로·국도·지방도·시군도·면도·리도·농도·철도별 색과 굵기, 선종류가 점선·파선이면 끊어진 선으로 그린다.
4. 번호 라벨은 점 표시 없이 포인트 위치에 놓이며, 분류별로 원 또는 사각 바탕과 색이 다르다.

#### 확인사항

1. 경산에서 «도로망도»를 켜면 번호 라벨이 포인트 위치에 보여야 한다.
2. 레이어 목록에 번호 포인트 레이어가 따로 보이지 않아야 한다.
3. 포인트 레이어가 없는 프로젝트는 기존 도로망도 표시와 같아야 한다.
4. 번호 라벨이 선 위에 그려져야 한다.
