# 기능목록 · 챙길점 (영상 통합)

2026-07-21 | JungWooojin | 영상관리 · 영상조회 · 촬영요청

관련(업무지시): `docs/brief/20260720_0944_영상조회촬영요청통합.md`

이 문서 하나로 영상 자료 업무(영상관리·영상조회·촬영요청) 개발을 진행한다. 화면 레이아웃은 현재 목업(HTML·CSS)을 기준으로 하고, 여기서는 **기능 정의**와 **목록별 챙길 점**만 정리한다. 업무는 세 갈래이며, 영상관리는 UAV 사이드바, 영상조회는 지도 오른쪽 컨트롤, 촬영요청 신청은 모든 시스템 공통이다.

## 메뉴 배치 (시스템 기준)

| 기능 | 진입 위치 | 노출 |
|------|-----------|------|
| 영상관리 (드론영상·사진동영상·파노라마·항공) | UAV 사이드바 (각각 메뉴) | UAV 전용 |
| 영상조회 (드론영상·사진동영상·파노라마) | 지도 오른쪽 컨트롤 — «배경지도»와 «3D지도» **사이** «드론영상» 버튼 | UAV 전용 |
| 승인관리 | UAV 사이드바 | UAV 전용 |
| 촬영요청 → 신청서 | 지도 오른쪽 버튼 (인쇄 아래) | **모든 시스템 공통** |
| 내 촬영요청목록 | 사이드바 맨 아래 «내 정보» → «내 촬영요청목록» | **모든 시스템 공통** |

**챙길 점**

1. 촬영요청 버튼은 시스템과 상관없이 지도 오른쪽 인쇄 아래에 항상 보인다. (특정 시스템 전용 아님)
2. 촬영요청 버튼·내 촬영요청목록은 2D·3D 지도 모두 같은 자리에 나온다.
3. 영상관리는 UAV 사이드바에서만 노출한다.
4. **영상조회는 UAV 사이드바 탭에 두지 않는다.** 지도 오른쪽에서 «배경지도»와 «3D지도» 사이 버튼으로만 연다.
5. 영상관리·다른 지도 기능(메모·측정·필지분석)과 동시에 켜지지 않는다. 영상조회 패널은 배경지도·레이어 패널과 비슷한 **우측 레이어형**으로 두고, 사이드바 메뉴와 배타 규칙을 맞춘다.

## A. 영상관리 (UAV) — 등록·변환·비행기록부

자료를 올리고·변환하고·관리한다. 화면은 «메뉴 | 목록 | 상세 | 지도»가 나란히 보이며, 목록과 상세를 한 칸에서 바꿔 쓰지 않고 상세는 «닫기»로만 접는다.

| 구분 | 정의 |
|------|------|
| 드론영상(정사) | 목록·상세·폴더 업로드·타일 변환. 파일 체크로 지도 타일 on/off |
| 사진·동영상 | 목록·작업단위 상세·파일 상세(재생)·폴더 업로드 |
| 파노라마 | 목록·상세·폴더 업로드. 파일 선택 시 파노라마 뷰어(판넬럼) |
| 항공영상 | 목록·상세·폴더 업로드. 변환 완료 시 배경지도 «자체항공영상» 등록 |
| 비행기록부 | 작업단위 상세 탭(별지 제5호). 드론영상·사진동영상·파노라마·항공 공통 |

### 챙길 점

**공통 · 폴더 업로드**
1. 폴더명에서 작업일·구분·좌표계 힌트·작업명을 파싱한다. 좌표계 힌트가 없거나 형식이 틀리면 업로드 전에 막는다.
2. 큰 파일은 분할(청크) 업로드한다. 좌표·범위는 저장 전에 5181로 통일한다.
3. 같은 키(작업일+구분+좌표계+작업명)면 같은 폴더에 병합, 다르면 신규 작업단위.
4. 드론영상·사진동영상·항공은 파일 부분 체크섬으로 구분하고, 파노라마는 DB 1대다·파일 경로로만 관리한다.
5. 목록·작업일·작업명은 저장 폴더 스캔·폴더명 파싱으로 채운다(파노라마만 DB).

**업로드 진행률 유지**
1. 파일 직렬(청크)로 진행하고 진행 상태를 작업 폴더의 진행 파일(목업)에 남긴다.
2. 업로드 창을 닫거나 다른 메뉴를 다녀와도 같은 구분 목록 상단 배너에서 진행률을 다시 본다.
3. 다른 구분 메뉴에는 그 배너가 보이지 않고, 완료되면 배너가 사라진다.

**좌표·지도 이동 (모든 구분 공통)**
1. 모든 파일(정사 tif·사진동영상·파노라마·항공)은 좌표계(5181)와 촬영 위치 좌표를 가진다. 목업 데이터에도 파일별 좌표를 넣어 지도 이동을 확인할 수 있게 한다.
2. 작업단위를 선택하면 그 안 파일들의 좌표를 모아 전체가 보이도록 지도 범위를 맞춘다(한 개면 그 지점으로 이동).
3. 파일을 클릭하면 지도가 해당 파일 촬영 위치로 이동하고 그 위치를 강조한다. 저장·비교 좌표는 5181 기준이다.
4. 드론영상에서 체크박스는 지도 타일 on/off, 파일 클릭은 위치 이동으로 역할을 나눈다(둘은 별개 동작).

**드론영상(정사)**
1. 원본을 지도에 직접 올리지 않고, 기존 정사 타일 변환 결과만 켠다.
2. 파일이 여러 장이면 합본 후 타일을 만든다. 변환 완료된 것만 체크·표시 대상이다.
3. tif 파일마다 좌표계·촬영 위치 좌표가 있어(목업 포함), 목록에서 파일을 클릭하면 지도가 그 위치로 이동한다. 파일 행에는 촬영 위치 좌표를 함께 보여 준다.
4. 사진·동영상·파노라마는 폴더 업로드가 끝나면 등록이 끝이다. 드론영상(정사)만 업로드 뒤에 **타일 변환** 단계가 있다.
5. 목록·파일 상태: 업로드 직후 «대기» → 변환이 돌면 «변환중» → 끝나면 «변환완료». (화면 배지로 구분)

**드론영상(정사) · 타일 변환 직렬 (실구현 시)**
1. 업로드와 변환은 나눈다. 업로드(청크·직렬)가 끝난 뒤 변환 큐에만 넣고, 브라우저가 변환을 돌리지 않는다.
2. 변환은 **전역에서 한 번에 한 건만** 한다. 여러 작업단위 업로드가 끝나도 변환을 동시에(병렬) 돌리지 않는다. 중간에 실패·꼬임 시 되돌리기 어렵기 때문이다.
3. 작업단위(또는 변환 작업) 폴더에 **변환 잠금 파일**이 있으면, 다른 건은 업로드가 끝났어도 변환을 시작하지 않고 «대기»로 둔다.
4. 워커가 잡을 집기 전: 잠금 파일이 없는지 확인한다. 없으면 잠금 파일을 만들고 «변환중»으로 바꾼 뒤 합본·타일 변환을 수행한다.
5. 성공하면 잠금 파일을 지우고 **변환 완료 파일**을 만든다. 상태를 «변환완료»로 두고, 큐의 다음 «대기» 건만 이어서 변환한다.
6. 실패하면 잠금 파일만 지우고 완료 파일은 만들지 않는다. 상태는 실패·재시도 가능으로 두고, 로그를 남긴다.
7. 상세의 «변환» 버튼은 재시도·강제 재변환용으로 두고, 평소에는 업로드 완료 → 큐 등록 → 워커 직렬 처리가 기본이다.
8. 1차 화면 목업은 상태 배지·안내 문구 수준만 두고, 잠금·완료 파일·큐 워커는 **실 API·디스크 연동 단계에서 구현**한다.

**사진·동영상**
1. 파일 클릭 시 작업단위 상세는 유지한 채 옆에 파일 상세가 열려 최대 네 칸(목록·작업단위 상세·파일 상세·지도)이 된다.
2. 파일 상세에서 사진·동영상을 재생한다.

**파노라마**
1. 부분 체크섬을 쓰지 않는다.
2. 파일 선택 시 파노라마 뷰어(판넬럼)가 **지도 영역 전체를 덮어** 뷰어만 보인다. 지도는 가리고, 뷰어를 닫으면 다시 지도가 보인다.

**항공영상**
1. 목록 체크박스는 없다. 변환 완료 결과는 배경지도 «자체항공영상»에 추가되고, on/off도 배경지도에서만 한다.
2. 상세에 «상세정보»·«비행기록부» 탭을 둔다.

**비행기록부**
1. 단독 메뉴가 아니라 작업단위 상세 탭으로만 연다. 촬영신청서(별지 제3호)와 섞지 않는다.

## B. 영상조회 (UAV) — 우측 레이어형 조회

영상관리와 별개로 **조회만** 한다. 업로드·변환·삭제·비행기록부·작업단위/파일 상세 패널은 두지 않는다. 항공영상은 이 패널에 두지 않는다(배경지도 «자체항공영상»으로만).

**진입**
1. UAV 사이드바 «영상조회» 탭은 **제거**한다.
2. 지도 오른쪽 컨트롤에 버튼을 둔다. 위치는 **«배경지도»와 «3D지도» 사이**.
3. 버튼·패널 제목 이름은 «드론영상»으로 한다.
4. 누르면 배경지도·레이어 목록처럼 **우측(또는 컨트롤 옆) 패널**이 열린다.

**패널 구성 (레이어처럼)**
1. 상단에 **종류 탭 3개(한 줄)**: 드론영상 · 사진,동영상 · 파노라마.
2. 탭을 바꾸면 그 종류의 **작업단위 목록만** 보인다. (파일 목록·상세 속성은 이 패널에 없음)
3. 각 작업단위 행에 **체크박스**가 있다. 체크하면 해당 작업단위가 지도에 보이고, 해제하면 숨긴다.
4. 행 클릭(이름 등)은 선택·지도 맞춤(범위 fit) 정도로 두고, 체크와 역할을 나눈다. (관리 화면의 파일 단위 상세는 열지 않음)

| 구분 | 정의 |
|------|------|
| 드론영상 | 작업단위 목록 + 체크 → 변환 완료 타일 on/off. 노출 허용·변환완료만 대상 |
| 사진,동영상 | 작업단위 목록 + 체크 → 촬영 위치(점·범위) 지도 표시 |
| 파노라마 | 작업단위 목록 + 체크 → 촬영 위치 표시. (뷰어는 필요 시 후속; 1차는 위치·목록 중심) |

### 챙길 점

1. 사이드바에 «영상조회»가 없어야 하고, 우측 «배경지도»·«3D지도» 사이 «드론영상» 버튼으로만 연다.
2. 패널은 **작업단위 목록 + 체크(표시)** 가 핵심이다. 관리용 업로드·변환·삭제·비행기록부·속성 상세는 없어야 한다.
3. 종류 탭 3개가 한 줄로 보여야 하고, 탭마다 해당 작업단위만 나와야 한다. 항공영상 탭은 없다.
4. **검색:** 작업단위명만으로 목록을 줄일 수 있어야 한다.
5. 노출 허용 자료만 보이고, 드론영상(정사)은 변환 완료된 것만 체크·표시 대상이다.
6. 체크 on → 지도에 보이고, off → 사라져야 한다. (레이어 목록과 같은 감각)
7. 영상관리 사이드바와 동시에 켜질 때 배타·폭 overlapping 규칙을 맞춘다. (배경지도 패널과 비슷하게 한쪽만 크게 덮지 않게)

## C. 촬영요청 — 신청(공통) / 승인관리(UAV)

신청·내 신청 확인은 모든 시스템 공통, 승인관리는 UAV 사이드바다. 신청서는 무인비행장치 촬영신청서(별지 제3호서식)를 따른다.

**상태 (다섯 가지):** 대기 · 승인 · 등록중 · 등록완료 · 반려
승인 후 «자료 등록»으로 이어지면 등록중, 자료가 올라가면 등록완료. 승인·등록중·등록완료를 «승인 계열»로 묶는다. «거부» 등 다른 명칭은 쓰지 않는다.

| 기능 | 정의 |
|------|------|
| 신청서 | 지도 오른쪽 «촬영요청» → 별지 제3호 작성·지도 범위·제출·내려받기. **단독 URL** `/drone` 로 들어오면 지도·사이드바 없이 신청서만 |
| 내 촬영요청목록 | «내 정보» → 내가 낸 신청 목록·상세 조회 |
| 승인관리 | UAV 사이드바. 전체·대기·승인·반려 필터·검색·승인·반려 |
| 자료 등록 연동 | 승인 계열만 영상관리 등록 대상. 대기·반려는 아님 |

### 챙길 점

**공통**
1. 촬영요청 버튼은 시스템과 상관없이 항상 보인다.
2. 촬영형태는 조감도·영상·항공사진·항공사진+중첩 네 가지다.
3. 상태는 대기·승인·등록중·등록완료·반려로 통일한다.

**신청서 작성**
1. 신청 정보(부서·신청자·관리자)·목적·기간·사용일·촬영형태·상세요청·안내를 별지 제3호 항목대로 담는다.
2. 촬영지역은 지번과 함께 지도에 그린 범위를 반드시 담는다. 범위 없이 제출하면 안내가 나온다.
3. 제출 직후 상태는 대기다. 내 촬영요청목록·승인관리에 바로 반영된다. 내려받기·닫기가 동작한다.
4. **단독 접속:** `/drone` 로 열면 지도·사이드바 없이 신청서만 보인다. 닫기·접수 후에는 지도로 이동할 수 있다. (지도 안 «촬영요청» 버튼은 기존처럼 지도 위 모달)

**내 촬영요청목록** (요청자 · 조회 전용)
1. 목적·지번·부서·상태로 검색한다. 카드에 신청일·목적·부서·촬영형태·촬영일·지번·상태 뱃지가 보인다.
2. «신청서 작성»으로 새 신청을 시작하고, 행을 누르면 신청 내용·지도 범위를 조회한다.
3. 내역이 없으면 «신청 내역이 없습니다»·작성 안내가 나온다. 반려 건은 사유 요약이 보인다.
4. 요청자는 **상태 확인만** 한다. 승인·등록중·등록완료 건도 «자료 등록» 버튼은 없다. (자료 등록은 관리자 승인관리에서만)
5. 승인 계열 건은 «승인되었습니다 · 담당자가 영상관리에 자료를 등록합니다» 식으로 상태만 안내한다.

**승인관리**
1. 대기·승인·반려 건수 요약과 전체·대기·승인·반려 필터(기본 대기)가 있다.
2. 추가·제출은 없다(담당자는 접수 건만 처리). 행 클릭 시 상세에서 신청서·지도 범위를 조회한다.
3. 승인 계열 건에 «영상관리 등록 대상 · 자료 등록»(또는 등록중·등록완료), 반려 건에 사유가 보인다.

**승인 · 반려**
1. 대기 건 상세에만 승인·반려 버튼이 있다. 승인 시 «자료 등록» 안내가 나온다.
2. 반려 시 사유는 필수다. 빈 값이면 안내가 나오고, 확정 후 상태·사유가 저장된다.
3. 처리(승인 계열·반려)된 건은 재처리 없이 조회만 한다. 처리일을 남긴다.

**반려 사유 공유**
1. 반려 사유는 승인관리와 내 촬영요청목록에 동일하게 보인다.
2. 내 신청 상세 반려 건이면 «담당자 반려 · 사유를 확인하세요» 안내가 있어야 한다.

**자료 등록 연동** (관리자 · 승인관리에서만)
1. «자료 등록»은 **관리자만** 한다. 승인관리(UAV 사이드바)의 승인 계열 건 상세에서만 «자료 등록» 버튼이 보인다. 요청자 화면(내 촬영요청목록)에는 없다.
2. 승인 계열만 대상이다. 누르면 촬영형태에 맞는 영상관리 메뉴를 연다(예: 항공사진 계열 → 항공영상).
3. 영상관리 목록 상단에 신청 요약 배너(목적·촬영형태·촬영일)가 뜨고, 폴더 업로드를 마치면 등록완료로 바뀐다.
4. 배너 «해제»는 연결만 끊고, 이미 바뀐 상태는 유지한다.

## 상태 흐름

```
신청 제출 → 대기
  대기 →(승인) 승인 →(관리자 자료 등록) 등록중 →(업로드 완료) 등록완료
  대기 →(반려·사유 필수) 반려 → 내 신청에서도 사유 조회
승인 계열(승인·등록중·등록완료) = 영상관리 등록 대상 / 대기·반려 = 대상 아님
```

## 역할 관계

```
[모든 시스템 공통]  지도 «촬영요청» 버튼 → 신청서+범위 → 접수(대기)
                    «내 정보» → «내 촬영요청목록» → 내 신청·상태·반려 사유

[UAV]               «승인관리»(사이드바) → 필터·검색 → 승인 / 반려(사유 필수)
                        └ 승인 → «자료 등록» → 영상관리 배너·업로드 → 등록완료 → 비행기록부
                    «영상관리»(사이드바 · 드론영상·사진동영상·파노라마·항공)
                        → 업로드·변환·비행기록부·속성 상세
                    «영상조회»(지도 오른쪽 · 배경지도↔3D지도 사이 버튼)
                        → 종류 탭 4개 · 작업단위 목록 · 체크로 지도 표시
                    항공 변환 결과 → 배경지도 «자체항공영상»
```
