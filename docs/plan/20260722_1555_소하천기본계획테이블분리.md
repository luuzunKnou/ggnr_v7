## 개발목표

하천 기본계획의 소하천 탭은 기존에 지방·소하천이 섞인 기본계획 테이블에서 유형 문자로 걸러 조회했다. 소하천 전용 기본계획 테이블이 있으므로, 소하천 탭은 그 테이블 전체를 기준으로 목록·상세·범위를 조회하도록 바꾼다. 색인도·종단·횡단·구조물도 소하천 전용 레이어를 함께 쓴다.

## 플로우차트

기본계획 → 소하천 탭 → 소하천기본계획·색인도 조회 → 상세·도면

## 화면설계

### RBP-SR-01 소하천 탭 목록

```
┌──────────────────────────────────────────────────────────────┐
│ [사이드바]  │ 소하천 기본계획                          [닫기] │
│  기본계획   │ ┌────────────┬────────────┐                   │
│             │ │ 지방하천   │ 소하천     │                   │
│             │ └────────────┴────────────┘                   │
│             │ [하천명 통합검색........................]       │
│             │ ○○○천  기본계획 N건                             │
│             │ ○○○천  기본계획 N건                             │
│             │                                                │
│             │                    [지도]                      │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 소하천 탭을 누르면 소하천 전용 기본계획 데이터로 목록이 채워진다.
2. 목록에 나온 하천을 선택하면 소하천 색인도·기본계획 레이어가 켜지고 지도가 해당 범위로 이동한다.
3. 지방하천 탭은 기존과 같이 지방 하천 기본계획 테이블을 사용한다.

#### 확인사항

1. 소하천 탭에서 소하천 기본계획 하천 목록이 보여야 한다.
2. 지방하천 탭과 소하천 탭 목록이 서로 섞이지 않아야 한다.
3. 소하천 하천 선택 시 상세 패널과 지도 이동이 되어야 한다.
