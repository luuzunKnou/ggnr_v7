# 작업계획서

2026-11-26 | 213am | KRAS 조회 이력 메뉴를 조회 이력·개인정보 권한 설정 통합으로 전환

## 개발목표

시스템 사용현황의 «KRAS 조회 이력»을 없애고, 한 메뉴에서 KRAS 연계 조회 이력과 «KRAS 개인정보 열람 권한»만 사용자별로 부여·회수할 수 있게 한다. 일반 서비스·시스템 권한관리·권한 신청 처리와는 분리하며, 이 메뉴에서는 KRAS 응답에 실리는 소유자명·등록번호·주소 등 개인정보 항목에 대한 허용 여부만 다룬다.

전역 개인정보 마스킹(시스템 통합제어)과 역할을 나눈다. 전역 마스킹은 화면 표시 방식이고, 이 메뉴의 권한은 «누가 KRAS 개인정보 포함 조회를 할 수 있는지»를 사용자 단위로 제어한다. 권한 변경은 기존 사용자 권한 관리 이력 체계에 남겨 감사에 쓴다. 조회 이력 적재·목록·내려받기는 현행을 유지·재배치한다.

## 플로우차트

메뉴 진입 → (탭) 조회 이력 ⇄ 개인정보 권한 → 사용자별 허용·회수 → 권한 이력 기록 → 지도 KRAS 조회 시 권한 검사

메뉴 진입 → 조회 이력 → 검색·상세·내려받기

## 화면설계

### KRAS-HUB-01 통합 메뉴

```
┌─ 개발자 모드 / 시스템관리 ─────────────────────────────────────┐
│ [시스템 사용현황]                                               │
│  · KRAS 개인정보·조회  ←                                        │
│                                                                 │
│  ┌─ KRAS 개인정보·조회 ──────────────────────────────────────┐ │
│  │ [조회 이력]  [개인정보 권한]                                │ │
│  │ (선택한 탭 본문)                                            │ │
│  └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 기존 «KRAS 조회 이력» 메뉴 이름·설명을 «KRAS 개인정보·조회»로 바꾼다.
2. 한 패널 안에 탭 두 개만 둔다. 일반 권한관리 화면으로 가지 않는다.
3. 기본 탭은 조회 이력이다.
4. 시스템관리 콘솔에도 같은 메뉴·패널을 둔다.

#### 확인사항

1. 사이드바에 «KRAS 조회 이력» 대신 «KRAS 개인정보·조회»가 보여야 한다.
2. 탭 전환 시 다른 시스템 사용현황 패널과 동시에 열리지 않아야 한다.
3. 권한관리·권한 신청 처리 메뉴와 화면이 섞이지 않아야 한다.

### KRAS-HUB-02 조회 이력 탭

```
┌─ KRAS 개인정보·조회 / 조회 이력 ───────────────────────────────┐
│ 시작·종료 · 구분 · 상태 · 개인정보 · 사용자 · [검색] [초기화]  │
│                                              [내려받기]         │
│ 목록(묶음) · 상세 보기                                          │
│ (현재 조회 이력 화면과 동일 구성)                               │
└─────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 기간·구분·상태·개인정보·사용자 검색과 목록·묶음 상세·엑셀 내려받기는 지금 기능을 그대로 쓴다.
2. 개인정보 열에 포함·마스킹·원문 표시도 유지한다.
3. 이 탭에서는 권한을 바꾸지 않는다.

#### 확인사항

1. 탭을 «조회 이력»으로 두면 이전과 같이 검색·상세·내려받기가 되어야 한다.
2. 개인정보 포함 조회에 마스킹·원문 구분이 보여야 한다.
3. 내려받기 파일이 현재 조건의 상세 행을 담아야 한다.

### KRAS-HUB-03 개인정보 권한 탭

```
┌─ KRAS 개인정보·조회 / 개인정보 권한 ───────────────────────────┐
│ 사용자 검색 [________]  [검색]                                  │
│                                                                 │
│ 사용자 ID | 이름 | KRAS 개인정보 열람 | 변경                   │
│ ────────┼──────┼──────────────────┼──────                     │
│ user01  | 홍길동 | 허용 / 불가          | [허용] [회수]         │
│                                                                 │
│ · 허용: KRAS 개인정보 포함 조회·원문 표시 가능                  │
│ · 불가: 해당 사용자에게는 개인정보 항목 비표시 또는 차단         │
│ · 변경 시 사용자 권한 관리 이력에 남김                           │
└─────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 사용자 목록에서 KRAS 개인정보 열람 허용·불가만 토글한다.
2. 일반 메뉴·레이어·시스템 권한은 이 화면에서 다루지 않는다.
3. 허용·회수 시 기존 사용자 권한 관리 이력에 «KRAS 개인정보» 성격으로 남긴다.
4. 지도·필지정보 등 KRAS 호출 경로에서는 이 권한을 보고, 불가 사용자는 개인정보 항목을 보지 못하거나 조회를 막는다. 전역 마스킹이 켜져 있으면 허용 사용자에게도 마스킹 표시는 유지할 수 있다.

#### 확인사항

1. 허용으로 바꾼 뒤 해당 계정으로 로그인하면 개인정보 포함 KRAS 조회가 가능해야 한다.
2. 회수 후 같은 계정으로는 개인정보 항목이 안 보이거나 조회가 막혀야 한다.
3. 허용·회수 후 사용자 권한 관리 이력에 변경 건이 남아야 한다.
4. 서비스·시스템 권한관리 화면의 매핑은 이 탭에서 바뀌지 않아야 한다.

### KRAS-HUB-04 지도 조회 시 권한 반영

```
┌─ 지도 (필지정보·모달 등) ──────────────────────────────────────┐
│  KRAS 개인정보 포함 조회 시도                                   │
│   → 권한 허용: 조회·표시(전역 마스킹 규칙 적용)                 │
│   → 권한 불가: 안내 후 개인정보 항목 생략 또는 조회 거부         │
└─────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 우클릭 필지정보·모달·필지분석 등 개인정보가 실리는 KRAS 경로에만 권한 검사를 넣는다.
2. 공시지가·레이어목록·이용계획처럼 개인정보 미포함 조회는 이 권한과 무관하게 동작한다.
3. 권한 불가여도 조회 이력에는 «시도·결과»를 남겨 감사할 수 있게 한다.

#### 확인사항

1. 권한 불가 사용자가 공유인·변동연혁 등을 열면 개인정보가 노출되지 않아야 한다.
2. 권한 허용 사용자는 기존과 같이 조회할 수 있어야 한다.
3. 권한 불가 시도도 조회 이력에 남아야 한다.
