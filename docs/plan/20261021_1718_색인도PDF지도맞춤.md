# 작업계획서

2026-10-21 | gyujin | 색인도 미리보기 방향

## 개발목표

색인도 도면을 글자 방향으로 돌리지 않는다. 지도 칸의 모양과 칸 안 종단선을 도면 그림에 맞춰 바로 세운다. 보고서는 그대로 둔다.

## 플로우차트

```
색인도 칸·종단선 → 도면 네 방향 비교 → 맞는 각도로 미리보기
```

#### 설명

1. 미리보기 방향은 지도 칸과 종단선으로만 정한다.
2. 가로 칸의 세로 저장 도면은 가로로 바로 선다.
3. 세로 칸의 뒤집힌 도면은 위아래가 바로 선다.
4. 보고서는 돌리지 않는다.

#### 확인사항

1. 고곡천 색인도 2번은 지도와 같은 방향으로 보여야 한다.
2. 괴시천 가로 색인도는 가로로 바로 서야 한다.
3. 대동2천 세로 색인도는 위아래가 바로 서야 한다.
4. 보고서는 이전 방향 그대로여야 한다.
