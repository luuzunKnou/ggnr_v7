# 작업계획서

2026-11-17 | 213am | 공간분석 전 탭 레이어 속성조회 공존

## 개발목표

공간분석이 열린 상태에서도 켜진 레이어를 지도에서 클릭해 속성 상세를 볼 수 있게 한다. 지금은 공간분석이 열리면 속성 상세를 통째로 막아, 단수·누수·위상·송수 어디서든 속성조회가 안 된다.

관망도와 같이 «이 기능이 쓰는 레이어»만 속성 모달에서 빼고, 그 외 레이어는 속성조회를 허용한다. 동시에 각 탭이 실제로 처리한 클릭(잠금 버튼, 누수 분석 스냅, 위상 피처 선택, 편집)만 가로채고, 빈 곳·다른 레이어 클릭은 속성조회로 넘긴다.

제수변·관로처럼 소유 레이어의 속성까지 보려면 이후 단계에서 수정 키 클릭 예외를 둘 수 있으나, 1차 범위에는 넣지 않는다.

## 플로우차트

```
공간분석 열림 → 지도 클릭 → (탭이 실제 히트·편집이면 기능 처리) → (아니면) 속성 식별 → 소유 레이어 제외 → 남은 히트만 속성 상세
```

## 화면설계

### MAP-SPATIAL-ID-01 단수구역 · 일반 잠금 모드

```
┌──────┬────────────────────────────────────────────┐
│공간분석│  [열림·잠금이 보이는 축척까지…] 또는 잠금 안내 │
│단수구역│                                            │
│      │              지도                            │
│잠금 없음│     (필지·건물 등 클릭)                     │
│      │         ┌──────────────┐                    │
│      │         │ 레이어 속성   │                    │
│      │         │ 상세          │                    │
│      │         └──────────────┘                    │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 그리기·지우기·건물·도형수정이 꺼진 상태에서 필지·건물 등 소유 밖 레이어를 클릭하면 속성 상세가 열린다.
2. 제수변 열림·잠금 버튼과 수용가 점 클릭은 단수 동작만 하고 속성 상세는 열지 않는다.
3. 축척 안내·잠금 안내는 기존과 같이 지도 상단에 유지한다.

#### 확인사항

1. 공간분석·단수 탭에서 필지 등 일반 레이어 클릭 시 속성 상세가 열려야 한다.
2. 열림·잠금 버튼 클릭 시 잠금·해제만 되고 속성 상세는 열리지 않아야 한다.
3. 수용가 점 클릭 시 목록 선택만 되고 속성 상세는 열리지 않아야 한다.

### MAP-SPATIAL-ID-02 단수구역 · 편집 모드

```
┌──────┬────────────────────────────────────────────┐
│공간분석│     [그리기 도구모음 · 안내]                 │
│단수구역│              지도 (편집 커서)                │
│      │     편집 클릭은 면 합치기·빼기만               │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 그리기·지우기·건물·도형수정 중에는 지도 클릭이 편집에만 쓰인다.
2. 이 구간에서는 속성 상세를 열지 않는다.
3. 편집을 끄면 다시 일반 잠금 모드 규칙으로 돌아간다.

#### 확인사항

1. 그리기 모드에서 지도 클릭 시 속성 상세가 열리지 않아야 한다.
2. 완료 후 일반 모드에서 다시 속성 상세가 열려야 한다.

### MAP-SPATIAL-ID-03 누수분석

```
┌──────┬────────────────────────────────────────────┐
│공간분석│  [누수 위치 클릭 안내 / 축척 안내]            │
│누수분석│              지도                            │
│      │  관로 스냅·제수변·결과선 → 누수 처리           │
│      │  스냅 실패·다른 레이어 → 속성 상세             │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 관로에 스냅되거나 제수변·결과 관로를 누른 클릭은 누수 분석·선택만 한다.
2. 관로에 붙지 않은 빈 곳이나 소유 밖 레이어 클릭은 속성 상세를 연다.
3. 선 편집·그리기 도구가 켜진 동안에는 편집이 클릭을 가져가고 속성 상세는 열지 않는다.

#### 확인사항

1. 관로에서 떨어진 필지 클릭 시 속성 상세가 열려야 한다.
2. 관로 스냅 위치 클릭 시 누수 분석이 되고 속성 상세는 열리지 않아야 한다.
3. 제수변·결과 관로 클릭 시 누수 선택만 되어야 한다.

### MAP-SPATIAL-ID-04 위상검증

```
┌──────┬────────────────────────────────────────────┐
│공간분석│              지도                            │
│위상검증│  관로·시설 히트 → 선택·반전·수정               │
│      │  히트 없음·다른 레이어 → 속성 상세             │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 방향 반전·수정 대상 고르기 중에 관로·시설이 잡히면 위상 동작만 한다.
2. 피처가 없는 빈 곳 클릭에서는 속성 식별을 막지 않고, 소유 밖 레이어면 속성 상세를 연다.
3. 대기 상태(도구 꺼짐)에서는 지도 클릭이 위상 피커에 잡히지 않으므로 속성조회가 기본이다.

#### 확인사항

1. 수정·반전 도구 켜고 빈 곳을 클릭해도 속성 상세가 막히지 않아야 한다.
2. 관로·시설이 잡힌 클릭에서는 위상 선택만 되고 속성 상세는 열리지 않아야 한다.
3. 도구가 꺼진 상태에서 일반 레이어 클릭 시 속성 상세가 열려야 한다.

### MAP-SPATIAL-ID-05 송수경로

```
┌──────┬────────────────────────────────────────────┐
│공간분석│              지도                            │
│송수경로│     일반 레이어 클릭 → 속성 상세              │
└──────┴────────────────────────────────────────────┘
```

#### 설명

1. 송수경로는 지도 클릭을 거의 가로채지 않으므로, 게이트만 풀리면 속성조회가 바로 된다.
2. 소유 레이어 규칙은 다른 탭과 동일하게 적용한다.

#### 확인사항

1. 송수 탭에서 필지 등 클릭 시 속성 상세가 열려야 한다.
