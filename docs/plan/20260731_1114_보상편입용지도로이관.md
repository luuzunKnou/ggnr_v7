# 작업계획서

2026-07-31 | gyujin | 보상편입용지 UI 개선 후속 지시 (모달 비차단화·도형편집·도로시스템 이관)

## 개발목표

보상편입용지 화면을 하천 시스템에서 도로 시스템으로 옮기고, 필지 정보를 가운데 뜨는 모달 대신 목록 옆 상세 패널 안에서 바로 입력하도록 바꾼다. 필지마다 지도에서 편입 영역 도형을 직접 그리거나 수정할 수 있게 하여, 편집 중에도 지도 조작이 막히지 않게 한다. 상세 속성 표시 방식은 공사대장 화면과 같은 형식(항목명 칸 + 값 칸이 짝을 이루는 표)으로 맞춘다.

## 플로우차트

```
도로 시스템 메뉴 → 보상편입용지 목록 → 건 선택 → 상세(조회) → 수정 → 필지별 도형추가/수정(지도) → 저장
```

## 화면설계

### ROAD-REWARD-01 보상편입용지 목록

```
+----------------------------------------------------------------------+
| 통합지도 [로그인]                                                    |
| 메뉴 | [측정] [주소검색] [메모] [민원] [필지분석] [레이어]           |
| - 도로망                                                             |
| - 도로대장                                                           |
| * 보상편입용지     +--------------------------------+                |
| - 도로점용대장     | 보상편입용지            [+][X] |                |
| - 도로시설물       | [검색 (건명)              ]    |                |
|                    +--------------------------------+                |
|                    | 동해대로 확장사업 보상편입     |     (지도 영역)|
|                    | 필지 2건                       |                |
|                    +--------------------------------+                |
|                    | 매화지방도 선형개량사업 보상편입|               |
|                    | 필지 1건                       |                |
|                    +--------------------------------+                |
|                    | 3건                                             |
|                    +--------------------------------+                |
|                                        [+] [-] [현위치]              |
+----------------------------------------------------------------------+
```

#### 설명

1. 도로행정 업무지원시스템 메뉴에서 «보상편입용지»를 선택하면 목록 패널이 열린다.
2. 목록은 건명과 필지 건수만 보여주는 단순한 줄 목록이며, 검색창으로 건명을 찾을 수 있다.
3. «+» 버튼으로 새 건을 만들면 바로 상세 패널이 열린다.
4. 건을 클릭하면 오른쪽에 상세 패널이 열린다.

#### 확인사항

1. 도로행정 업무지원시스템 메뉴에만 «보상편입용지»가 보여야 한다.
2. 건명 검색 시 목록이 즉시 걸러져야 한다.
3. «+»로 만든 새 건은 목록 맨 위에 나타나야 한다.
4. 목록·상세 패널이 열려 있어도 지도는 계속 조작 가능해야 한다.

### ROAD-REWARD-02 상세(조회)

```
+----------------------------------------------------------------------+
| 통합지도 [로그인]                                                    |
| 메뉴 | [측정] [주소검색] [메모] [민원] [필지분석] [레이어]           |
| - 도로망  +---------------------------------------------+            |
| - 도로대장| 동해대로 확장사업 보상편입      [수정][X]    |           |
| * 보상편입| 상세 속성                                    |           |
| - 점용대장| 조직 | 도로과      | 정책 | 도로정비사업     |           |
| - 시설물  | 단위 | 도로확장    | 세부 | 동해대로 확장사업|           |
|           | 편성목|공유재산관리비| 통계목| 보상금        |           |
|           | 감정기관1|새롬감정 | 감정기관2|대호감정      |           |
|           | 필지목록 (2)                                 | (지도)    |
|           +----------+--------+----------+---------------+           |
|           | 읍면동   |지번(편입)|편입면적(㎡)|보상금액(원)|          |
|           +----------+--------+----------+---------------+           |
|           |울진읍 연지리|123-4 |    120   |  20,900,000  |           |
|           |울진읍 연지리|125-1 |     85   |  15,130,000  |           |
|           +----------+--------+----------+---------------+           |
|                                        [+] [-] [현위치]              |
+----------------------------------------------------------------------+
```

#### 설명

1. 상세 속성은 항목명 칸과 값 칸이 짝을 이루는 표(공사대장과 같은 형식)로 보여준다.
2. 필지목록은 읍면동·지번(편입)·편입면적·보상금액 네 항목만 요약해서 보여준다.
3. 필지 행을 클릭하면 모달 없이 지도만 해당 위치로 이동한다.
4. «수정» 버튼을 눌러야 속성과 필지 편집이 시작된다.

#### 확인사항

1. 상세 속성 표에 빈 칸이 세로로 넓게 남지 않아야 한다.
2. 필지 행 클릭 시 지도가 해당 필지 쪽으로 이동해야 한다.
3. 감정평가1·2 기관명은 건마다 다르게 표시되어야 한다.
4. 필지가 없으면 안내 문구만 보여야 한다.

### ROAD-REWARD-03 상세(수정) — 필지 인라인 편집

```
+----------------------------------------------------------------------+
| 통합지도 [로그인]                                                    |
| 메뉴 | [측정] [주소검색] [메모] [민원] [필지분석] [레이어]           |
| - 도로망  +---------------------------------------------+            |
| - 도로대장| 동해대로 확장사업 보상편입      [저장][취소] |           |
| * 보상편입| 상세 속성                                    |           |
| - 점용대장| 조직 [도로과       ] 정책 [도로정비사업    ] |           |
| - 시설물  | 단위 [도로확장     ] 세부 [동해대로 확장사업] |          |
|           | 필지목록 (2)                   [+ 추가]      | (지도)    |
|           +---------------------------------------------+            |
|           | 필지 1                        [도형] [X]    |            |
|           | 읍면동[울진읍 연지리] 지번(편입)[123-4    ]  |           |
|           | 편입면적[   120] 새롬감정[  185000        ]  |           |
|           | 대호감정[179000] 적용단가[  182000 (자동)]  |            |
|           | 보상금액[   21,840,000 (자동)              ] |           |
|           | 토지소유자 주소 [주소 검색 (도로명/지번) ]   |           |
|           +---------------------------------------------+            |
|                                        [+] [-] [현위치]              |
+----------------------------------------------------------------------+
```

#### 설명

1. «수정»을 누르면 속성과 필지목록이 함께 입력 모드로 바뀐다.
2. 필지는 모달을 띄우지 않고 목록 안에서 카드 형태로 바로 입력한다.
3. 필지 카드의 «도형» 버튼을 누르면 해당 필지의 지도 편집이 시작된다.
4. 적용단가·보상금액은 감정평가1·2 금액과 편입면적으로 자동 계산되어 직접 입력할 수 없다.
5. 토지소유자 주소는 직접 입력 대신 주소 검색으로만 채운다.
6. «+ 추가»로 새 필지 카드를 만들고, «X»로 필지를 지운다.

#### 확인사항

1. 속성과 필지목록 입력 중에도 지도는 계속 눌리고 이동되어야 한다.
2. 감정평가1·2 금액이나 편입면적을 바꾸면 적용단가·보상금액이 즉시 갱신되어야 한다.
3. «취소»를 누르면 수정 전 값으로 되돌아가야 한다.
4. «저장»을 눌러야 목록·조회 화면에 반영되어야 한다.

### ROAD-REWARD-04 지도 위 도형편집 (비차단)

```
+----------------------------------------------------------------------+
| 통합지도 [로그인]                                                    |
| 메뉴 | [측정] [주소검색] [메모] [민원] [필지분석] [레이어]           |
| - 도로망  +---------------------------------------------+            |
| - 도로대장| 동해대로 확장사업 보상편입      [저장][취소] |           |
| * 보상편입| 상세 속성                                    |           |
| - 점용대장| (편집 중 — 지도가 계속 눌리고 이동됩니다)    |           |
| - 시설물  | 필지목록 (2)                   [+ 추가]      |           |
|           +---------------------------------------------+            |
|           | 필지 1                     [도형 편집중][X] |            |
|           | 읍면동[울진읍 연지리] 지번(편입)[123-4    ]  |           |
|           +---------------------------------------------+            |
|                     +------------------------------+                 |
|                     |1번 필지 편입 영역을 지도에서  |                |
|                     |그려 주세요.                   |                |
|                     |     [완료] [초기화] [삭제]     |                |
|                     +------------------------------+                 |
|                                        [+] [-] [현위치]              |
+----------------------------------------------------------------------+
```

#### 설명

1. «도형» 버튼을 누르면 가운데 뜨는 창 없이 지도 위에 작은 안내 문구가 나타난다.
2. 도형이 없는 필지는 지도를 클릭해 다각형을 그리고, 이미 있는 필지는 정점을 끌어 수정한다.
3. 편집 중에도 왼쪽 상세 패널의 다른 필지·속성 입력은 그대로 유지된다.
4. «완료»로 편집을 마치고, «초기화»로 편집 시작 시점으로 되돌리고, «삭제»로 도형을 지운다.

#### 확인사항

1. 도형 편집 중 지도 확대·축소·이동이 막히지 않아야 한다.
2. 다각형을 세 점 미만으로 그리면 안내와 함께 다시 그릴 수 있어야 한다.
3. 같은 필지의 «도형» 버튼을 다시 누르면 편집이 종료되어야 한다.
4. 다른 지도 기능(측정·주소검색 등)과 동시에 도형편집이 겹치지 않아야 한다.
