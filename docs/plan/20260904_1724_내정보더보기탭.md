## 개발목표

사이드바 아래 내 정보는 지금처럼 하나만 둔다. 누르면 열리는 칸에 촬영요청·알림 옆에 더보기 칸을 넣어, 나머지 메뉴를 그 안에서 고를 수 있게 해 본다. 사이드바 메뉴 목록은 이번엔 빼지 않는다.

## 플로우차트

```
지도 → 내 정보 → 더보기 → 메뉴 선택 → 해당 화면
```

## 화면설계

### MAP-MY-01 내 정보 더보기

```
┌────┬──────────────────────────────────────────────────────────────────────┐
│ 로 │ 검색                                                                  │
│ 고 │                                                                      │
│ 메 │                         지도                                         │
│ 뉴 │                                                                      │
│    │  ┌─────────────────────────┐                                         │
│────│  │ 내 정보              ✕ │                                         │
│ 나 │  │ 이름 · 부서 · 로그아웃  │                                         │
│ 정 │  │ 촬영요청  알림  더보기  │                                         │
│ 보 │  │ 도로대장                │                                         │
│    │  │ 도로시설물              │                                         │
└────┴──┴─────────────────────────┴─────────────────────────────────────────┘
```

#### 설명

1. 사이드바 아래는 내 정보만 두고, 더보기 단추는 따로 만들지 않는다.
2. 내 정보를 누르면 기존처럼 칸이 열리고, 촬영요청·알림 옆에 더보기가 있다.
3. 더보기를 누르면 지금 시스템의 메뉴가 이름 목록으로 나온다.
4. 목록에서 고르면 그 화면이 열리고 내 정보 칸은 닫힌다.

#### 확인사항

1. 사이드바 아래에 내 정보만 있어야 한다.
2. 내 정보 칸에 더보기 칸이 보여야 한다.
3. 더보기에서 메뉴를 고르면 해당 화면이 열려야 한다.
4. 촬영요청·알림은 이전과 같이 동작해야 한다.
