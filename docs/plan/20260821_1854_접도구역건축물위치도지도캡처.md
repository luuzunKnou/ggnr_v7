## 개발목표

제2쪽 «위치도»는 파일을 올리는 칸이 아니다. «위치»에서 주소를 고르면 지도가 그 자리로 이동하고, 그때 켜 둔 배경지도를 그대로 담아 점을 찍은 그림을 위치도에 보여 준다. 배치도·종전·변경 사진 칸은 그대로 둔다. 상세 칸 배치는 바꾸지 않는다.

## 플로우차트

```
위치 주소검색 → 지도 이동 → 배경지도 담기 · 점 표시 → 위치도
```

## 화면설계

### RFB-MAP-01 위치도 지도 담기

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ 시스템명                              주소·지번 검색 [                        ]      로그인  │
├──────┬───────────────────────────────────┬────────────────────────────────────────────────────┤
│ 배경 │ 접도구역 건축물 목록              │ 접도구역 건축물 관리대장                           │
│ 지도 ├───────────────────────────────────┤                                                    │
│      │                                   │ 위치 [주소·지번 검색                         ]   │
│      │         ● 점                      │ …                                               │
│      │              지  도               │ 위치도              │ 건축물 배치도             │
│      │                                   │ (배경지도+점)       │ (사진 등록)               │
└──────┴───────────────────────────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 위치도에는 올리기·삭제 단추가 없다.
2. 위치에서 주소를 고르면 지도가 이동한 뒤 지금 배경지도를 담아 점을 찍는다.
3. 담는 동안 위치도에 잠시 안내가 보인다.
4. 저장하면 그 그림이 위치도로 남고, 인쇄에도 같다.
5. 배치도·종전·변경은 예전처럼 사진을 올린다.

#### 확인사항

1. 주소를 고르면 위치도에 지금 배경지도와 점이 보여야 한다.
2. 위치도에 올리기 단추가 없어야 한다.
3. 배경지도를 바꿔 두고 주소를 고르면 바뀐 배경이 담겨야 한다.
4. 배치도·종전·변경은 사진을 올리고 지울 수 있어야 한다.
5. 저장 후 다시 열면 위치도 그림이 남아 있어야 한다.
