## 개발목표

점용대장 상세의 추가 속성에서 «속성을 추가해주세요»를 누르면 속성명과 자료형을 고르는 작은 창이 열리게 한다. 지금은 빈 행이 바로 붙고 자료형은 문자로만 들어간다. 값으로 형을 짐작하지 않고, 사용자가 문자·숫자·날짜 중 하나를 고른 뒤 목록에서 값을 넣는다.

정의에서 고르는 추가는 형이 이미 있으므로 그대로 둔다.

## 플로우차트

```
상세 수정 → 속성을 추가해주세요 → 속성명·자료형 창 → (확인) → 목록에서 값 입력 → 저장
```

## 화면설계

### MAP-EXTRA-01 속성 추가 창

```
+------------------------------------------------------------------+
|메  | 점용대장 목록     | 상세 [저장][취소]     |                 |
|뉴  |                   | 기본 속성 …           |                 |
|    |                   | 추가 속성             |                 |
|    |                   |  (필드) (값) [-]      |                 |
|    |                   | [속성을 추가해주세요] |                 |
|    |                   +----------------------+                 |
|    |                   | 속성 추가            |                 |
|    |                   | 속성명 [          ]  |                 |
|    |                   | 자료형 (•)문자 ( )숫자 ( )날짜         |
|    |                   |        [취소] [추가] |                 |
+------------------------------------------------------------------+
```

#### 설명

1. 수정 중에 «속성을 추가해주세요»를 누르면 속성 추가 창이 열린다.
2. 속성명은 반드시 넣고, 자료형은 문자·숫자·날짜 중 고른다. 기본은 문자다.
3. 확인하면 빈 값 행이 붙고, 날짜는 날짜 칸, 숫자는 숫자 칸, 문자는 글 칸이 나온다.
4. 같은 이름의 속성이 이미 있으면 안내하고 추가하지 않는다.
5. 정의에서 고르는 추가는 창 없이 기존처럼 목록에 붙는다.

#### 확인사항

1. 버튼을 누르면 속성명·자료형 창이 나와야 한다.
2. 속성명 없이 추가하면 안내가 나와야 한다.
3. 날짜를 고르면 값 칸이 날짜 선택이어야 한다.
4. 숫자를 고르면 값 칸이 숫자 입력이어야 한다.
5. 정의에서 추가는 창 없이 동작해야 한다.
