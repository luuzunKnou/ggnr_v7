## 개발목표

기준 DB 레이어와 첨부 파일을 비교하는 단순 화면을 만든다. 먼저 컬럼·건수·도형 타입·좌표계를 맞춰 보고, 맞춰진 데이터끼리 값 차이를 결과로 보여 준다. 반영은 하지 않는다.

## 플로우차트

```
개발자도구 → 비교 → 기준레이어·파일 → 1차 구조비교 → (짝·매칭) → 값 차이 결과 → 엑셀
```

## 화면설계

### DEV-LFC-01 자료 선택

```
┌────────사이드────────┬────────────────────────────────────────────┐
│ 데이터관리           │  레이어·파일 비교                           │
│                      │                                             │
│                      │  기준 레이어 (DB)                           │
│                      │  [ 검색·선택 _________________________ ]    │
│                      │                                             │
│                      │  비교 파일                                  │
│                      │  [ 파일 선택 (xlsx·shp·zip·dbf) ]           │
│                      │                                             │
│                      │              [구조 비교]                    │
└──────────────────────┴────────────────────────────────────────────┘
```

#### 설명

1. 기준은 DB 레이어만 고른다.
2. 비교는 파일만 첨부한다. 임시 적재만 하고 목록·정의·지도서비스에 남기지 않는다.
3. «구조 비교»를 누르면 1차 결과로 간다.

#### 확인사항

1. 기준 또는 파일이 없으면 구조 비교가 진행되지 않아야 한다.
2. 첨부 후 레이어 목록에 새 항목이 생기지 않아야 한다.

### DEV-LFC-02 1차 구조 비교

```
┌────────사이드────────┬────────────────────────────────────────────┐
│                      │  1차 구조 비교                              │
│                      │                                             │
│                      │  ┌ 건수 ──────┐  ┌ 도형 ────┐  ┌ 좌표계 ─┐ │
│                      │  │ 기준 N     │  │ 기준 …  │  │ 기준 … │ │
│                      │  │ 파일 M     │  │ 파일 …  │  │ 파일 … │ │
│                      │  │ 같음/다름  │  │ 같음/다름│  │같음/다름│ │
│                      │  └────────────┘  └─────────┘  └────────┘ │
│                      │                                             │
│                      │  컬럼                                       │
│                      │  같음 · 기준만 · 파일만  (표)               │
│                      │  (영문 같음 자동 / 한글 같으면 후보 표시)   │
│                      │                                             │
│                      │  데이터 맞추기                              │
│                      │  ○ 식별키  ○ 위치                           │
│                      │  키: 기준 [ ]  파일 [ ]                     │
│                      │                                             │
│                      │     [이전]  [맞춰서 값 비교]                │
└──────────────────────┴────────────────────────────────────────────┘
```

#### 설명

1. 건수·도형 타입·좌표계를 기준/파일로 나란히 보여 같고 다름을 표시한다. 파일에 도형이 없으면 «없음»으로 표시한다.
2. 컬럼은 같음·기준만·파일만으로 나눈다. 영문이 같으면 자동으로 같음, 영문 다르고 한글이 같으면 후보로 두고 확인한다.
3. 값 비교 전에 짝 방법(식별키 또는 위치)을 고른다. 식별키면 양쪽에 칸을 고른다.
4. 구조만 보고 끝낼 수도 있고, «맞춰서 값 비교»로 다음으로 갈 수 있다.

#### 확인사항

1. 건수·도형·좌표계가 양쪽으로 보여야 한다.
2. 컬럼이 같음·기준만·파일만으로 나뉘어 보여야 한다.
3. 도형 없는 파일은 도형·좌표계가 «없음»으로 보여야 한다.

### DEV-LFC-03 맞춰진 데이터 차이

```
┌────────사이드────────┬────────────────────────────────────────────┐
│                      │  값 비교 결과                               │
│                      │                                             │
│                      │  맞춤 N · 기준만 a · 파일만 b · 값다른 c    │
│                      │                                             │
│                      │  차이 목록                                  │
│                      │  식별 · 항목 · 기준값 · 파일값              │
│                      │  …                                          │
│                      │                                             │
│                      │  [엑셀]  [처음으로]                         │
└──────────────────────┴────────────────────────────────────────────┘
```

#### 설명

1. 맞춰진 건수와 한쪽만 있는 건수, 값은 다른 건수를 짧게 보여 준다.
2. 목록에는 맞춰진 뒤 값이 다른 것만 보여 준다. 식별값과 기준값·파일값을 나란히 둔다.
3. 엑셀로 내려받을 수 있다. 반영 버튼은 없다.

#### 확인사항

1. 맞춰진 뒤 값이 다른 행이 목록에 나와야 한다.
2. 같은 값은 기본 목록에 나열하지 않아야 한다.
3. 엑셀을 받을 수 있어야 한다.
4. 끝나면 임시 파일이 정리되어야 한다.
