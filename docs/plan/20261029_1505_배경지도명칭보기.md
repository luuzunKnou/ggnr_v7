## 개발목표

배경지도 패널 상단에 «명칭보기» 체크를 둔다. 항공영상·자체항공영상을 고르면 체크가 자동으로 켜지고, 다음 명칭 타일이 영상 위에 겹쳐 보인다. 체크를 끄면 명칭만 숨긴다.

## 플로우차트

```
지도 → 배경지도 → (항공영상 선택) → 명칭보기 자동 켜짐 ⇄ 체크 해제
```

## 화면설계

### MAP-BG-01 배경지도 명칭보기

```
┌────┬──────────────────────────────────────────┐
│메뉴│  [ 주소·지명 검색                     ]  │
│    │                                          │
│조회│                     지도                 │
│    │                  (항공영상)              │
│    │                  (명칭 겹침)             │
│    │                                          │
│    │                    ┌──────────────────┐  │
│    │                    │ ☑ 명칭보기       │  │
│    │                    │ 자체항공영상     │  │
│    │                    │ 항공영상         │  │
│    │                    │  ○ 항공영상     │  │
│    │                    │ 일반영상         │  │
│    │                    │ 지형도           │  │
│    │                    │ 기타영상         │  │
│    │                    └──────────────────┘  │
└────┴──────────────────────────────────────────┘
```

#### 설명

1. 오른쪽 «배경지도»를 열면 목록 맨 위에 «명칭보기» 체크가 있다.
2. 항공영상 또는 자체항공영상을 고르면 명칭보기가 자동으로 켜지고, 영상에 지명·도로명이 겹친다.
3. 체크를 끄면 명칭만 사라지고 배경 영상은 그대로다.
4. 일반영상·지형도·기타로 바꿔도 체크는 그대로 둘 수 있으며, 다시 항공영상을 고르면 자동으로 켜진다.

#### 확인사항

1. 배경지도 패널 맨 위에 «명칭보기»가 보여야 한다.
2. 항공영상을 고르면 명칭보기가 체크되고 지도에 명칭이 나와야 한다.
3. 체크를 끄면 명칭이 사라져야 한다.
4. 자체항공영상을 고를 때도 명칭보기가 자동으로 켜져야 한다.
5. 명칭을 켠 채 지적도 등 다른 레이어는 그대로 보여야 한다.
