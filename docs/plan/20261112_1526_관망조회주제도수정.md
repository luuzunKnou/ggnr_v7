# 작업계획서

2026-11-12 | 200BingSu | 관망조회·주제도 UI 수정

## 개발목표

상수 관망조회 SHP 다운로드 모달에 레이어 등록과 같은 좌표계 선택을 두고 기본은 통일좌표계로 한다. 단면도 삼차원에서 관로에 마우스를 올리면 관경 치수가 항상 관 윗쪽에 붙게 한다. 주제도 등고선은 하위 목록 없이 그룹 켜기·끄기만 남긴다.

## 플로우차트

```
관망조회 → SHP 다운로드(좌표계 선택) → 파일
관망조회 → 단면도 삼차원 → 관로 호버 → 관경 윗면
지도 → 주제도 → 등고선 그룹 켜기·끄기
```

## 화면설계

### NET-DL-01 SHP 다운로드 좌표계

```
┌────────────────────────────────────────────┐
│ [사이드]  검색·지도            [패널]      │
│           ┌─ SHP 다운로드 ─────────────┐   │
│           │ ○ 전체  ● 검색조건         │   │
│           │ 좌표계 [UTM-K(5179) ▼]     │   │
│           │ □ 관로 □ 변류 …            │   │
│           │              [취소][다운로드]│   │
│           └────────────────────────────┘   │
└────────────────────────────────────────────┘
```

#### 설명

1. 하단 «다운로드»를 누르면 SHP 모달이 열린다.
2. 좌표계 목록은 레이어 등록과 같고 처음 값은 통일좌표계이다.
3. 선택한 좌표계로 SHP가 내려받는다.
4. Excel 모달에는 좌표계 선택이 없다.

#### 확인사항

1. 모달 열 때 좌표계 기본이 통일좌표계여야 한다.
2. 다른 좌표계를 고르면 그 값으로 파일이 나와야 한다.
3. Excel 모달에는 좌표계 선택이 없어야 한다.

### NET-3D-01 관경 윗면

```
┌────────────────────────────────────────────┐
│ [사이드]  지도·단면도패널                  │
│           ┌─ 삼차원 ───────────────────┐   │
│           │  지형·관로                 │   │
│           │  관로 호버 → 관경(윗쪽)    │   │
│           └────────────────────────────┘   │
└────────────────────────────────────────────┘
```

#### 설명

1. 삼차원 탭에서 관로에 마우스를 올리면 토피와 관경이 보인다.
2. 관경 치수는 마우스 위치에 따라 관을 따라 움직이되 항상 윗면에 붙는다.

#### 확인사항

1. 관로 호버 시 관경이 관 아랫면으로 내려가지 않아야 한다.
2. 토피 표시는 기존과 같아야 한다.

### THEM-EL-01 등고선 그룹

```
┌────────────────────────────────────────────┐
│ [사이드]  지도              [주제도]       │
│                             ┌─ 등고선  □  │
│                             │ (하위목록X) │
│                             └─────────────│
└────────────────────────────────────────────┘
```

#### 설명

1. 주제도에서 등고선은 그룹 한 줄과 일괄 체크만 보인다.
2. 펼침 하위 목록(계곡선 등)은 보이지 않는다.
3. 그룹 체크로 등고선 전체가 켜지거나 꺼진다.

#### 확인사항

1. 등고선 아래에 세부 레이어 행이 없어야 한다.
2. 그룹 체크로 등고선이 지도에 보여야 한다.
