## 개발목표

공간분석 «송수경로»에서 정수장·배수지를 고르면, 그 지점에서 관로 유수방향을 따라 하류 경로를 그리고 물이 흘러가는 애니메이션을 보여 준다.

## 플로우차트

공간분석 → 송수경로 → 정수장·배수지 선택 → 하류 관로 표시·흐름 애니메이션

## 화면설계

### SPA-SUPPLY-01 송수경로

```
┌──────사이드────────┬──────────지도──────────┐
│ 공간분석 송수경로    │  관로 · 흐름 애니메이션 │
│ 정수장 · 배수지 목록 │  ● 선택 시설           │
│ 경로 요약           │                        │
│ 새분석 · 재생       │                        │
└────────────────────┴────────────────────────┘
```

#### 설명

1. 상단에 정수장·배수지 구분을 두고 시설 목록을 보여 준다.
2. 시설을 고르면 하류 관로가 지도에 표시되고 흐름 애니메이션이 재생된다.
3. 새 분석으로 선택을 비우고, 재생으로 애니메이션을 다시 돌린다.

#### 확인사항

1. 정수장·배수지 목록이 보여야 한다.
2. 시설 선택 시 관로를 따라 흐름이 보여야 한다.
3. 다른 공간분석 탭과 전환해도 레이어가 남지 않아야 한다.
