## 개발목표

물놀이 표지판 관리 구간은 주소로 찾은 지적 면을 합쳐 멀티폴리곤으로 보여 준다. 목록은 구분·주소·제목만 두고, 상세 속성과 이력 사이에 구조함·표지판 위치 목록을 점용대장 필지목록처럼 둔다. 수정 때 지도에 점을 찍어 각 레이어에 넣는다.

## 플로우차트

```
목록(구분·주소·제목) → 상세 속성 → 구조함·표지판 위치 ⇄ 지도 점 찍기 → 이력
```

## 화면설계

### WPS-01 물놀이 표지판 목록

```
┌────┬──────────────────────────────────────────────┐
│    │ 검색                                          │
│ 메 │                                              │
│ 뉴 │  ┌──────────────────┐                        │
│    │  │물놀이 표지판     │                        │
│    │  │구분 주소 제목    │                        │
│    │  │하천 … 계곡쉼터   │                        │
│    │  │못   …            │                        │
│    │  └──────────────────┘                        │
│    │                                              │
└────┴──────────────────────────────────────────────┘
```

#### 설명

1. 목록 열은 구분, 주소, 제목 순이다.
2. 구조함·표지판 수량과 합계는 목록에 나오지 않는다.
3. 행을 누르면 상세가 열리고 지도가 해당 구간으로 맞춰진다.

#### 확인사항

1. 목록에 수량 열이 없어야 한다.
2. 열 순서가 구분, 주소, 제목이어야 한다.
3. 행 클릭 시 상세와 지도 이동이 되어야 한다.

### WPS-02 상세 · 구조함·표지판 위치

```
┌────┬──────────┬──────────┬────────────────────────┐
│ 메 │물놀이    │상세      │                        │
│ 뉴 │표지판    │속성보기  │                        │
│    │목록      │구분 주소 │                        │
│    │          │구조함    │                        │
│    │          │1. 주소   │                        │
│    │          │표지판    │                        │
│    │          │1. 주소   │                        │
│    │          │이력      │                        │
└────┴──────────┴──────────┴────────────────────────┘
```

#### 설명

1. 속성과 이력 사이에 구조함 목록과 표지판 목록이 있다.
2. 주소를 누르면 해당 점으로 지도가 이동한다.
3. 수정 중에는 추가로 지도를 찍어 점을 넣을 수 있다.
4. 이력은 이전과 같고, 속성에서 구분을 고칠 수 있다.

#### 확인사항

1. 구조함·표지판 목록이 속성 아래, 이력 위에 있어야 한다.
2. 수정 중 추가 후 해당 레이어에 점이 보여야 한다.
3. 이력이 이전처럼 보여야 한다.
