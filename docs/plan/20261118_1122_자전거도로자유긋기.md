## 개발목표

자전거도로 구간 추가를 도로 안내선 위 자유 점 잇기로 바꾸고, 편측·우측·좌측을 줄마다 따로 그린 뒤 세션 초안에 모아 일괄 반영한다. 점 사이 도로 최단경로는 쓰지 않는다.

## 플로우차트

```
상세 → 추가 → 측선택 → 점찍기 → 이줄확정 → (측선택·점찍기 반복) → 일괄반영 → 구간표
```

## 화면설계

### BR-FREE-01 구간 세션 · 자유 긋기

```
┌──────┬─────────────────────────────────────────────┐
│ 사이드 │  [검색]                                      │
│        │ ┌─────────────────────────────────────────┐ │
│        │ │ 구간 추가 · 우측  점 3 · 초안 1줄          │ │
│        │ │ [되돌리기][이 줄 확정][일괄 반영][취소]     │ │
│        │ │ 도로 위를 클릭해 점을 이으세요.            │ │
│        │ └─────────────────────────────────────────┘ │
│        │            (하늘색 도로 안내선)               │
│        │              ●──●──●  초록 현재 줄            │
│        │         (초안 줄은 다른 색으로)               │
│        │                              ┌─ 상세 ─┐     │
│        │                              │ 구간 표 │     │
└──────┴──────────────────────────────┴─────────┘
```

#### 설명

1. «추가»에서 편측·우측·좌측을 고르면 세션이 시작되고 도로 안내선이 보인다.
2. 클릭한 점을 순서대로 이어 현재 줄을 만들고, «이 줄 확정»으로 초안에 넣는다.
3. 측을 다시 고르며 줄을 더 그린 뒤 «일괄 반영»으로 표에 한꺼번에 넣는다.
4. «취소»는 초안과 현재 줄을 모두 버린다.

#### 확인사항

1. 점 사이가 한 바퀴 도는 최단경로가 아니라 찍은 순서대로 이어져야 한다.
2. 우측·좌측을 따로 긋면 기점·종점·길이가 서로 달라도 표에 각각 들어가야 한다.
3. 초안이 여러 줄일 때 일괄 반영 한 번에 표에 모두 추가되어야 한다.
4. 취소 시 표에 새 행이 생기지 않아야 한다.
5. 되돌리기는 현재 줄의 마지막 점만 지워야 한다.
