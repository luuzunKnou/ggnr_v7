## 개발목표

상수행정 사이드바에 관망도조회·시설관리·공사대장·급수공사를 추가한다. 누르면 제목만 있는 빈 패널이 열린다. 공통 여섯 메뉴는 아래에 그대로 둔다.

## 플로우차트

상수행정 → (메뉴 클릭) → 빈 패널

## 화면설계

### MAP-WTL-01 상수행정 빈 패널

```
┌────┬─────────────────────────────┐
│사이│ 관망도조회              [×] │
│드바│                             │
│    │                             │
│관망│                             │
│시설│                             │
│공사│                             │
│급수│                             │
│…   │                             │
└────┴─────────────────────────────┘
```

#### 설명

1. 상수행정에서 네 메뉴가 공통 메뉴보다 위에 보인다.
2. 메뉴를 누르면 왼쪽에 제목과 닫기만 있는 빈 패널이 열린다.
3. 다른 메뉴로 바꾸면 같은 빈 패널에 제목만 바뀐다.

#### 확인사항

1. 네 메뉴가 사이드바에 보여야 한다.
2. 클릭 시 빈 패널이 열려야 한다.
3. 닫기를 누르면 패널이 사라져야 한다.
