# 작업계획서

2026-07-22 | gyujin | 기본계획 연장값 소수 끝0 제거

## 개발목표

기본계획 상세의 연장·속성 숫자 표시에서 DB numeric 자릿수 때문에 붙는 끝자리 0을 제거하고, 읽기 쉬운 숫자로 보여 준다.

## 플로우차트

기본계획 상세 → 연도목록 연장·속성숫자 → 끝0 제거 표시

## 화면설계

### RBP-LEN-01 연장 표시

```
┌──────────────────────────────────────────────┐
│ 기본계획 | 연장                                │
│ 20xx계획 | 1.75 km                             │
└──────────────────────────────────────────────┘
```

#### 설명

1. 연장 칸에는 불필요한 소수 끝 0이 붙지 않는다.
2. 속성정보 숫자 필드도 같은 방식으로 정리한다.

#### 확인사항

1. 연장에 1.7500000000 대신 1.75가 보여야 한다.
2. 정수 연장은 소수점 없이 보여야 한다.
3. 속성정보의 연장·길이 숫자도 끝 0이 없어야 한다.
