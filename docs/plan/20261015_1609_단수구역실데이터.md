## 개발목표

공간분석 «단수구역»을 의성 상수 레이어로 돌린다. 지도에서 제수변을 잠그면 주변 관로·급수전을 모아 단수 범위를 그리고, 수용가 목록을 보여 준다. 이력·문자 화면은 유지하되 저장소 없이 세션 이력만 쓴다. 필지 레이어가 없으면 필지 탭은 비운다.

## 플로우차트

공간분석 → 단수구역 → 제수변 잠금 → 분석실행 → 단수범위·수용가 → (문자)

## 화면설계

### SPA-OUT-03 단수구역(실데이터)

```
┌──────사이드────────┬──────────지도──────────┐
│ 공간분석 단수구역    │  관로·제수변           │
│ 이력 · 새 분석      │  ● 잠금 제수변         │
│ 제수변 잠금 · 분석  │  ░ 단수범위 · 단수관로 │
│ 필지·도로명·수용가  │                        │
└────────────────────┴────────────────────────┘
```

#### 설명

1. 지도에 상수관로·제수변이 켜지고, 제수변을 골라 잠근다.
2. 분석실행 시 잠긴 제수변 주변 관로를 모아 단수 면·단수 관로를 그린다.
3. 범위 안 급수전계량기로 수용가·도로명주소 목록을 채운다.
4. 지적 레이어가 없으면 필지 목록은 비어 있다.

#### 확인사항

1. 제수변 잠금 전에는 분석실행이 비활성이어야 한다.
2. 분석 후 지도에 단수 면과 단수 관로가 보여야 한다.
3. 수용가 탭에 범위 안 급수전 정보가 나와야 한다.
4. 새 분석 시 잠금·결과가 초기화되어야 한다.
