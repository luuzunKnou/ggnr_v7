## 개발목표

SHP 폴더 업로드 두 번째 단계에서 신규 레이어만, 고른 속성을 일반 컬럼이 아니라 추가속성으로 빼고 한글 이름과 미리보기를 본 뒤 올린다. 선택을 안 하면 지금과 같다. 기존 레이어 정합성은 건드리지 않는다.

## 플로우차트

```
폴더 선택 → 구성요소 검사 → (신규) 속성 선택·한글명·미리보기 → 생성·정합성 → 결과
```

## 화면설계

### DEV-SHP-EXTRA-01 구성요소 검사·추가속성 선택

```
┌────────────────────────────────────────────────────────────┐
│ SHP 폴더 업로드 — 레이어 구성요소 검사 (2/4)                  │
├────────────────────────────────────────────────────────────┤
│ [상태 안내] Table · Layer · Style · Define                  │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 파일        Table  Layer  Style  Define                 │ │
│ │ a.shp        ○      ○      ○      ○                     │ │
│ └────────────────────────────────────────────────────────┘ │
│                                                            │
│ 추가속성으로 넣을 속성 (신규만)                               │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ □ ROAD_NM   [도로명________]                            │ │
│ │ ☑ MEMO      [메모__________]                            │ │
│ │ 미리보기 (json) …                                       │ │
│ └────────────────────────────────────────────────────────┘ │
│                                      [이전]  [시작] [다음]  │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 두 번째 단계에서 신규 레이어에만 속성 선택과 한글 이름 입력이 보인다.
2. 고른 속성은 일반 컬럼이 아니라 추가속성으로만 저장된다고 안내한다.
3. 미리보기로 저장될 추가속성 형태를 한 건 기준으로 보여 준다.
4. 기존 레이어 행에는 이 선택 칸이 없다.

#### 확인사항

1. 신규가 아닌 레이어에는 추가속성 선택이 보이지 않아야 한다.
2. 선택을 하지 않고 올리면 모든 속성이 일반 컬럼으로 남아야 한다.
3. 일부만 고르면 그 속성은 테이블 일반 컬럼에 없고 추가속성에만 있어야 한다.
4. 미리보기 형태가 실제 저장과 같아야 한다.
