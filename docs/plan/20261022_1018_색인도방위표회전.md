# 작업계획서

2026-10-22 | gyujin | 세로 색인도 방위표로 바로 세우기

## 개발목표

색인도 도면 안의 방위표 글자(북)로 미리보기 위아래·좌우를 정한다. 방위표가 없는 가로 원본은 뒤집지 않는다. 보고서는 그대로 둔다.

## 플로우차트

```
색인도 선택 → (방위표 있음) → 북이 위로 → 미리보기
```

#### 설명

1. 도면에 방위표가 있으면 북이 화면 위를 향하도록 미리보기를 돌린다.
2. 가로로 저장된 원본에 방위표 글자가 없으면 원본 가로를 유지한다.
3. 방위표를 못 찾으면 이전처럼 지도 칸·종단선으로 맞춘다.
4. 보고서는 돌리지 않는다.

#### 확인사항

1. 손두들천 세로 색인도는 방위표 북이 위를 향해야 한다.
2. 고곡천 세로 색인도는 글자가 바로 보여야 한다.
3. 신안천 가로 색인도는 원본처럼 가로·위아래가 그대로여야 한다.
4. 보고서는 이전 방향 그대로여야 한다.
