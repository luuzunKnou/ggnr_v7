# 작업계획서

2026-08-25 | dev.strcat | 민원·메모 상세 하나만 표시

## 개발목표

민원과 메모의 떠 있는 추가·상세는 한 번에 하나만 보이게 한다. 두 기능끼리 옮길 때만 앞서 열려 있던 화면을 닫고, 점사용료 등 다른 부서 업무로 갈 때는 둘 다 그대로 남긴다. 목록에서 같은 행을 한 번 더 누르면 상세가 닫히고, 필지분석·변동이력분석·도형편집기로 갈 때는 두 상세 모두 닫힌다.

떠 있는 화면은 지도 영역이 아니라 브라우저 화면을 기준으로 띄운다. 목록 패널과 다른 부서 업무 패널 위로 옮길 수 있고, 화면 밖으로는 나가지 않는다. 처음 열릴 때 위치는 지금처럼 지도 왼쪽에서 조금 떨어진 곳이다.

## 플로우차트

```
민원 상세 → (다른 부서 업무) → 민원 상세 유지 ⇄ (메모관리) → 메모 상세만 표시
```

## 화면설계

### 메모-01 메모 상세만

```
┌──────────────────────────────────────────────────────────────────┐
│ 메모관리          │                    지도                      │
│ 검색 · 카드       │  ┌──────────────────────────────┐            │
│ [카드 행]         │  │ 메모 상세                 [닫기]│          │
│                   │  │ 제목 · 작성자 · 위치          │            │
│                   │  └──────────────────────────────┘            │
└──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 민원 상세가 열린 상태에서 메모관리로 가면 민원 상세·추가는 닫힌다.
2. 메모 행을 누르거나 메모 추가를 누르면 떠 있는 메모 화면만 보인다.
3. 점사용료 등 다른 부서 업무로 가도 메모 상세·추가는 남는다.
4. 열려 있는 메모 행을 한 번 더 누르면 상세가 닫힌다.
5. 필지분석·변동이력분석·도형편집기로 가면 메모 상세는 닫힌다.

#### 확인사항

1. 민원 상세를 연 뒤 메모관리로 가면 민원 상세가 사라져야 한다.
2. 메모 상세가 열려 있을 때 민원 상세가 같이 보이면 안 된다.
3. 메모 상세를 연 뒤 다른 부서 업무로 가도 메모 상세가 남아야 한다.
4. 같은 메모 행을 다시 누르면 상세와 지도 강조가 사라져야 한다.
5. 필지분석·변동이력분석·도형편집기로 가면 메모 상세가 사라져야 한다.

### 민원-01 민원 상세만

```
┌──────────────────────────────────────────────────────────────────┐
│ 민원관리          │                    지도                      │
│ 검색 · 카드       │  ┌──────────────────────────────┐            │
│ [카드 행]         │  │ 민원 상세                 [닫기]│          │
│                   │  │ 내용 · 위치                   │            │
│                   │  └──────────────────────────────┘            │
└──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 메모 상세가 열린 상태에서 민원관리로 가면 메모 추가·상세는 닫힌다.
2. 민원 떠 있는 화면과 메모 떠 있는 화면은 동시에 나오지 않는다.
3. 민원관리를 떠나 다른 부서 업무로 가도 민원 추가·상세는 남는다.
4. 열려 있는 민원 행을 한 번 더 누르면 상세가 닫힌다.
5. 필지분석·변동이력분석·도형편집기로 가면 민원 상세는 닫힌다.

#### 확인사항

1. 메모 상세를 연 뒤 민원 행을 누르면 메모 상세가 닫혀야 한다.
2. 민원 추가를 누르면 메모 추가·상세가 없어야 한다.
3. 민원 상세를 연 뒤 다른 부서 업무로 가도 민원 상세가 남아야 한다.
4. 같은 민원 행을 다시 누르면 상세와 지도 강조가 사라져야 한다.
5. 필지분석·변동이력분석·도형편집기로 가면 민원 상세가 사라져야 한다.

### 위치-01 화면 기준 떠 있는 화면

```
┌──────────────────────────────────────────────────────────────────┐
│ 사이드 │ 목록 패널 │ 업무 패널 │              지도                │
│  바    │ ┌──────────────────────────────┐                        │
│        │ │ 메모 상세                 [닫기]│  ← 목록·업무 패널 위 │
│        │ │ 제목 · 작성자 · 위치          │                        │
│        │ └──────────────────────────────┘                        │
└──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 처음 열릴 때는 지도 왼쪽 끝에서 조금 떨어진 곳에 놓인다.
2. 머리글을 끌어 목록 패널과 다른 부서 업무 패널 위로도 옮길 수 있다.
3. 위·아래·좌·우 어느 쪽으로도 화면 밖으로는 나가지 않는다.
4. 창 크기를 줄이면 화면 안으로 다시 들어온다.

#### 확인사항

1. 머리글을 끌어 목록 패널 위까지 옮길 수 있어야 한다.
2. 화면 왼쪽·오른쪽·위·아래 밖으로 나가지 않아야 한다.
3. 목록 패널·업무 패널에 가려지지 않아야 한다.
4. 처음 열릴 때 위치는 이전과 같아야 한다.
