# 작업계획서

## 개발목표

운영(행망)에서는 KRAS·KOREPS·세움터 등 행정망 연계를 우선 사용하고, **연계 실패·무응답·미보강 필지는 브이월드·공공데이터포털로 자동 대체**한다. 개발(외부망)에서는 처음부터 브이월드·포털만 쓴다. 우클릭 «필지정보»와 필지분석 4차 보강이 같은 분기·변환 규칙을 공유한다.

행망 사용 여부는 별도 플래그 없이 **서버 실행 환경 구분값으로 자동 결정**한다(개발이 아니면 행망 우선). 브이월드 보강은 서버가 아니라 **브라우저에서 직접 호출**하며, 우클릭·필지분석·공시지가가 같은 호출 코드를 공유한다.

키는 프로젝트별 런타임 설정 파일에 평문 저장(확정). 암호화 저장은 하지 않으므로 외부망 노출 환경에서는 행망 키를 넣지 않는다(주석으로 미리 기입만 해 둔다).

## 플로우차트

우클릭·필지분석 → 실행 환경 확인 → (행망) 서버 연계 조회 → (실패·미보강 필지) 브라우저 브이월드·포털 → 공통 형식 변환 → 화면 / (개발) 브이월드·포털 → 공통 형식 변환 → 화면

## 화면설계

### MAP-LAND-01 우클릭 필지정보(행망)

```
+----------------------------------------------------------------------+
| 통합지도 [로그인]                                                    |
+----------------------------------------------------------------------+
| 메뉴 | (지도) [+] [-] [현위치]                                       |
| - 지도 | +--------------------+                                      |
|        | | 필지정보           |                                      |
|        | | 지번 · 도로명      |                                      |
|        | | [필지][건축물대장] |                                      |
|        | | [인허가]           |                                      |
|        | | 토지기본 · 소유    |                                      |
|        | | 이용계획 · 공시지가|                                      |
|        | +--------------------+                                      |
+----------------------------------------------------------------------+
```

#### 설명

1. 우클릭 «주소정보»로 패널을 연다. 지번·도로명은 우리 지적·주소 조회를 쓴다.
2. 토지기본·소유·이용계획은 서버에서 행망 연계를 먼저 시도하고, 실패·빈 결과면 브라우저에서 브이월드로 대체 조회한다.
3. 대체 조회 값도 같은 표 구성으로 표시한다. 연계 출처 색·범례를 함께 보여줄 수 있다.
4. 행망·브이월드 모두 실패한 값은 «연계실패»로 주황색 표시한다.

#### 확인사항

1. 운영 서버(행망)에서 연계 정상 시 토지·소유·공시지가가 채워져야 한다.
2. 행망 연계 실패 시 브이월드로 조회되어 빈 화면·«연계 진행중»만 보이면 안 된다.
3. 모든 연계가 실패한 필지는 «연계실패» 표시와 안내 툴팁이 나와야 한다.

### MAP-LAND-02 우클릭 필지정보(외부망·개발·시연)

```
+----------------------------------------------------------------------+
| 통합지도 [로그인]                                                    |
+----------------------------------------------------------------------+
| 메뉴 | (지도) [+] [-] [현위치]                                       |
| - 지도 | +--------------------+                                      |
|        | | 필지정보           |                                      |
|        | | 지번 · 도로명      |                                      |
|        | | [필지][건축물대장] |                                      |
|        | | [인허가]           |                                      |
|        | | 토지기본 · 소유    |                                      |
|        | | 이용계획 · 공시지가|                                      |
|        | +--------------------+                                      |
+----------------------------------------------------------------------+
```

#### 설명

1. 실행 환경이 개발이면 행망을 호출하지 않고 브이월드만으로 토지·소유·공시지가를 조회한다.
2. 건축물대장·인허가는 세움터 적재 DB를 먼저 보고, 없거나 실패하면 공공데이터포털로 조회한다.
3. 화면 구성은 행망과 동일하며, 브이월드에 없는 값은 «-»로 둔다.
4. 연계 출처 색·범례는 행망 화면과 같이 표시할 수 있다.

#### 확인사항

1. 개발·시연 서버에서 행망 호출 없이 필지 탭이 정상 조회되어야 한다.
2. 브이월드 키가 없으면 빈 목록·안내가 나와야 하고, 앱이 멈추지 않아야 한다.
3. 건축물대장·인허가 탭은 세움터 값이 있으면 세움터, 없으면 포털 값으로 나와야 한다.

### MAP-PARCEL-4A 필지분석 결과(4차 보강)

```
+----------------------------------------------------------------------+
| 통합지도 [로그인]                                                    |
+----------------------------------------------------------------------+
| 메뉴 | +----------------------------------------------+              |
| *필지 | | 공간분석 결과                                |             |
| 분석  | | 목차 | 토지현황 · 소유자 · 지목 · 건축물대장 |             |
|       | |      | (표 · 불러오는 중)                    |             |
|       | +----------------------------------------------+             |
| (지도 배경)                                                          |
+----------------------------------------------------------------------+
```

#### 설명

1. 분석 직후에는 지적 DB 값(지번·면적 등)으로 표·통계를 먼저 보여 준다.
2. 이후 필지를 묶음 단위로 점진 로딩하며 소유·지목·공시지가를 보강하고 표·통계를 갱신한다.
3. 행망이면 서버 연계를 우선 쓰고, 못 채운 필지는 브라우저 브이월드로 보강한다(우클릭 필지정보와 동일 변환).
4. 소유구분·지목별 테마 지도는 보강이 끝난 뒤 최종 값으로 그린다.

#### 확인사항

1. 행망에서 «분석» 후 토지 목록 공시·면적·소유가 보강되어야 한다.
2. 개발 환경에서 브이월드만으로도 표·통계·테마 지도가 채워져야 한다.
3. 연계 일부 실패 시에도 표·통계는 유지되고 실패 구간 안내가 나와야 한다.
