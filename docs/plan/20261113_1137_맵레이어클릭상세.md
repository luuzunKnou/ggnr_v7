## 개발목표

지도에서 레이어를 클릭했을 때, 이미 클릭으로 모달·패널을 여는 업무가 아니면 최소화 가능한 플로팅에 목록 표시 필드만 보여 준다. 데이터조회·도로기반·관망조회·시설관리 등 기존 동작은 바꾸지 않는다.

## 플로우차트

지도 클릭 → 식별 → (업무 패널·데이터조회·도로기반이면 기존) → 레이어 클릭 상세 플로팅 ⇄ 최소화

## 화면설계

### MAP-LAYER-CLICK-01 레이어 클릭 상세

```
┌──────┬──────────────────────────────────────────────┐
│ 메뉴 │  지도                                        │
│      │                         ┌─────────────────┐  │
│      │                         │ 레이어명        │  │
│      │                         │ 제목 · [선택▼] ─ □ ✕│
│      │                         │ 항목 | 값       │  │
│      │                         │ …               │  │
│      │                         └─────────────────┘  │
│      │                                              │
└──────┴──────────────────────────────────────────────┘
```

#### 설명

1. 업무 메뉴 없이 켜진 레이어를 클릭하면 우측 근처에 상세 플로팅이 열린다.
2. 목록 표시가 켜진 필드만 표로 보인다.
3. 여러 피처가 잡히면 헤더 선택으로 전환한다.
4. 최소화하면 하단 바에 붙고, 펼치면 직전 위치로 돌아온다.

#### 확인사항

1. 메뉴 없이 레이어만 켠 뒤 클릭 시 플로팅이 열려야 한다.
2. 목록 표시가 꺼진 필드는 보이지 않아야 한다.
3. 데이터조회·관망조회 등에서는 기존 화면만 열려야 한다.
4. 최소화 후 펼치면 직전 위치에 있어야 한다.

### MAP-LAYER-CLICK-02 최소화 바

```
┌──────┬──────────────────────────────────────────────┐
│ 메뉴 │  지도                                        │
│      │                                              │
│      │                                              │
│      │  ┌──────────────┐                            │
│      │  │ 레이어 · □ ✕ │                            │
│      │  └──────────────┘                            │
└──────┴──────────────────────────────────────────────┘
```

#### 설명

1. 최소화 시 하단에 짧은 바가 붙는다.
2. 펼치기·닫기로 다시 펼치거나 종료한다.

#### 확인사항

1. 최소화 바가 하단에 보여야 한다.
2. 펼치기 시 본문이 다시 보여야 한다.
