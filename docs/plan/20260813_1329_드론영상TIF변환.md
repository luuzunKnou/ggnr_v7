## 개발목표

드론촬영 «드론영상»을 목업에서 실기능으로 바꾼다. 촬영요청이 드론영상이면 작업단위 폴더를 만들고 TIF를 올린 뒤, 업로드 완료와 동시에 정사 변환 큐에 넣어 진행률을 보여 준다. 변환 결과는 자체항공영상이 아니라 드론영상 화면의 체크로 지도에 켜고 끈다. TIF 메타는 전용 테이블에 저장한다.

## 플로우차트

```
촬영요청(드론영상) → 작업단위 폴더 → TIF 업로드(진행률) → 변환 큐(진행률) → 드론영상 목록·상세 → (체크) 지도 타일 on/off
```

## 화면설계

### AIR-ORTHO-01 드론영상 목록·업로드

```
┌────────────────────────────────────────────────────────────┐
│ 영상관리 │ 드론영상 │ 사진,동영상 │ 파노라마 │ 항공영상 │
│          ├──────────┬──────────────────────────────────────┤
│          │ 드론영상  │ 지도                                 │
│          │ [검색][업로드] │                                  │
│          │ 업로드·변환 진행률 배너                         │
│          │ 작업단위 목록                                    │
│          │  · 변환중 / 변환완료                             │
│          │           │                                      │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 목록은 실제 작업단위·TIF·변환 상태를 보여 주고 목업 행은 쓰지 않는다.
2. 업로드를 누르면 폴더 생성 후 TIF를 고르며, 사진·동영상과 같은 진행률 배너가 뜬다.
3. 파일 업로드가 끝나면 변환이 바로 이어지고 배너에 변환 진행이 표시된다.
4. 변환이 끝난 작업단위만 지도 표시용 체크가 가능하다.

#### 확인사항

1. 촬영요청이 드론영상인 건에서 폴더명에 «드론영상»이 들어가야 한다.
2. 업로드 중·변환 중 진행률이 목록 상단에 보여야 한다.
3. 변환 완료 후 자체항공영상 목록에는 새 항목이 생기지 않아야 한다.

### AIR-ORTHO-02 작업단위 상세·지도 on/off

```
┌────────────────────────────────────────────────────────────┐
│ 목록 │ 작업단위 상세          │ 지도                        │
│      │ 상세정보 / 비행기록부  │                             │
│      │ 파일 목록              │  (체크한 변환완료 타일)     │
│      │ ☑ 변환완료.tif         │                             │
│      │ □ 변환중.tif           │                             │
│      │ [추가][삭제][닫기]     │                             │
└────────────────────────────────────────────────────────────┘
```

#### 설명

1. 상세 파일 목록에 변환 상태가 보인다.
2. 변환완료만 체크해 지도에 타일을 올리고, 체크를 해제하면 끈다.
3. 우측 드론영상 레이어 패널의 작업단위 체크도 같은 지도 타일 on/off와 맞춘다.
4. 추가 업로드도 끝나면 변환 큐에 바로 들어간다.

#### 확인사항

1. 변환완료 파일만 체크할 수 있어야 한다.
2. 체크 시 지도에 해당 타일이 보여야 하고, 해제 시 사라져야 한다.
3. 변환 실패 시 목록에 실패가 보이고 재시도 안내가 가능해야 한다.
