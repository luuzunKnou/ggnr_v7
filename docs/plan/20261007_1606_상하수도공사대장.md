## 개발목표

하천 공사대장 화면을 공용으로 바꿔, 사이드바 메뉴가 «공사대장»(하천)·«상수도 공사대장»·«하수도 공사대장» 중 무엇이냐에 따라 불러오고 저장하는 레이어를 다르게 한다. 화면은 같고 저장은 레이어별로 분리된다.

상세 속성은 해당 레이어에 실제로 있는 항목만 보여 준다. 필지는 레이어마다 다른 주소 항목을 읽고, 저장할 때 화면에 없는 필지 속성을 그대로 유지한다. 영향 받는 기능: 하천 공사대장(목록·상세·필지·첨부·지도 강조).

## 플로우차트

```
사이드바 메뉴(하천·상수·하수) → 공사대장 목록 → (행 클릭) → 공사 상세 ⇄ 편집 → 저장
```

## 화면설계

### MAP-CONS-01 하수도 공사대장 목록

```
┌────┬──────────────────────────┬──────────────────────────────────────┐
│메뉴│ 하수도 공사대장   [+] [X] │                                      │
│    ├──────────────────────────┤                                      │
│하수│ [통합검색][도형검색][행정경계]│              지  도                  │
│공사│ [공사명·업체명·착수일자  ] │                                      │
│대장│ 목록 3건                 │                                      │
│    ├──────────────────────────┤                                      │
│    │ 공사명     업체명  착수일자 │                                      │
│    │ ○○하수관로  ○○건설 2024-03 │                                      │
│    │ 구미처리장  ○○종합 2023-05 │                                      │
└────┴──────────────────────────┴──────────────────────────────────────┘
```

#### 설명

1. «하수도 공사대장»을 누르면 하수 공사대장 레이어만 켜지고 목록이 열린다.
2. 상수·하수 목록에는 «하천» 열이 없고 검색 안내에서도 하천이 빠진다.
3. «공사대장»(하천)은 지금처럼 하천 열과 함께 보인다.

#### 확인사항

1. 하수 메뉴에서는 하수 공사만 목록에 나와야 한다.
2. 상수 메뉴에서는 상수 공사만 목록에 나와야 한다.
3. 레이어가 아직 없으면 «테이블이 없습니다» 안내가 나와야 한다.

### MAP-CONS-02 공사 상세

```
┌────┬──────────────────────┬──────────────────────┬────────────────┐
│메뉴│ 하수도 공사대장       │ 공사 상세   [수정][X] │                │
│    │ ...                  ├──────────────────────┤                │
│    │                      │ 공사명 │ 구미처리장   │     지  도      │
│    │                      │ 공사위치│ 영덕읍 ...  │                │
│    │                      │ 계약일 │ ...│착수일자│ │                │
│    │                      │ 업체명 │ ...│대표자명│ │                │
│    │                      │ 사업비_전 ...        │                │
│    │                      ├──────────────────────┤                │
│    │                      │ 필지 목록   [필지 추가]│                │
│    │                      │ 영덕읍 구미리 35      │                │
│    │                      ├──────────────────────┤                │
│    │                      │ 첨부  [도면][조서]    │                │
└────┴──────────────────────┴──────────────────────┴────────────────┘
```

#### 설명

1. 속성표는 레이어에 있는 항목만 그린다. 상수·하수에는 «대상 하천»이 없다.
2. 필지 목록은 하수 레이어의 도로명주소 항목을 주소로 보여 준다.
3. 저장하면 선택한 메뉴의 레이어에만 기록되고, 첨부는 해당 레이어 폴더에 저장된다.

#### 확인사항

1. 하수 상세에 «대상 하천» 칸이 보이지 않아야 한다.
2. 필지를 추가·삭제 후 저장해도 기존 필지의 필지코드·비고 값이 유지되어야 한다.
3. 신규 필지는 다음 필지코드가 자동으로 채워져야 한다.
4. 하천 공사대장 상세·저장은 기존과 같아야 한다.
