## 개발목표

드론 영상 위치를 맞추는 지상기준점을 부서업무로 연다. 목록·상세는 점용대장과 같이 두고, 여러 점을 한 번에 점검할 수 있게 한다. 지도 점 색은 상태와 맞춘다. 이번엔 칸 안 시험 자료만 쓴다.

## 플로우차트

```
지도 → 지상기준점 목록 → (행 선택) → 상세 ⇄ 점검 작성 → 목록
```

## 화면설계

### MAP-GCP-01 지상기준점 목록

```
┌────┬──────────────┬─────────────────────────────────┐
│ 로 │ 지상기준점   │ 검색                            │
│ 고 │ 목록      ✕ │                                │
│ 메 │ 점검 작성    │              지도               │
│ 뉴 │ ☐ 1 정상     │   · 파랑 점                     │
│    │   울산 …     │   · 주황 점                     │
│────│ ☐ 2 점검필요 │   · 빨강 점                     │
│ 나 │   울산 …     │                                │
│ 정 │              │                                │
│ 보 │              │                                │
└────┴──────────────┴─────────────────────────────────┘
```

#### 설명

1. 사이드바에서 지상기준점을 고르면 왼쪽 목록이 열린다.
2. 행을 누르면 옆에 상세가 열리고 지도가 그 점으로 간다.
3. 여러 행을 고른 뒤 점검 작성으로 한꺼번에 이력을 남긴다.
4. 지도 점 색은 상태와 같다.

#### 확인사항

1. 지상기준점 메뉴를 고르면 목록이 열려야 한다.
2. 행을 누르면 상세가 옆에 열려야 한다.
3. 지도에서 점 색으로 점검 필요와 지워진 점을 구분할 수 있어야 한다.

### MAP-GCP-02 지상기준점 상세

```
┌────┬──────────────┬──────────────┬──────────────────┐
│ 로 │ 지상기준점   │ 상세      ✕ │                  │
│ 고 │ 목록         │ 번호 · 좌표  │      지도        │
│ 메 │              │ 위치 설명    │                  │
│ 뉴 │              │ 설치일 상태  │                  │
│    │              │ 주소         │                  │
│────│              │ 위치 사진    │                  │
│ 나 │              │ 점검 이력    │                  │
│ 정 │              │ 이 점 점검   │                  │
│ 보 │              │              │                  │
└────┴──────────────┴──────────────┴──────────────────┘
```

#### 설명

1. 번호·좌표·높이, 위치 설명은 한 줄로 보여 준다.
2. 최초 설치일·상태·주소가 보인다.
3. 위치 사진과 점검 이력이 아래에 있다.
4. 이 점만 따로 점검을 작성할 수 있다.

#### 확인사항

1. 위치 설명이 한 줄로 보여야 한다.
2. 사진과 점검 이력이 보여야 한다.
3. 목록을 닫지 않고 상세만 닫을 수 있어야 한다.

### MAP-GCP-03 점검 작성

```
┌────┬──────────────┬──────────────┬──────────────────┐
│ 로 │ 지상기준점   │ 점검 작성 ✕ │                  │
│ 고 │ 목록         │ 점검일자     │      지도        │
│ 메 │ ☑ 1  ☑ 3    │ 1 상태 사진  │                  │
│ 뉴 │              │ 3 상태 사진  │                  │
│    │              │ 확인  취소   │                  │
└────┴──────────────┴──────────────┴──────────────────┘
```

#### 설명

1. 목록에서 고른 점들이 점검 칸에 나온다.
2. 점검일자는 공통이고, 점마다 상태와 사진을 넣을 수 있다.
3. 확인하면 목록·상세·지도 색이 같이 바뀐다.

#### 확인사항

1. 여러 점을 한 번에 점검할 수 있어야 한다.
2. 한 점만 지워짐으로 바꾸고 사진을 올릴 수 있어야 한다.
3. 확인 후 지도 점 색이 바뀌어야 한다.
