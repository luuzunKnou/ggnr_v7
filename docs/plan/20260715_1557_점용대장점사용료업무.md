## 개발목표

점용대장은 도로·하천·국공유지를 **공통 화면**으로 관리하고, 유형별로만 다른 항목을 붙인다. 기능은 대장 목록·속성(기간 만료 알림)·점용지 도형·필지목록·물건지목록·공시지가 레이어·점사용료 이력(미납 알림)·점용분석(허가 심사·사용료 가상 책정)이다. 점사용료는 **별도 부서업무 조회 전용**이며, 대장 **관리코드**를 차세대 세외수입 **관리번호5·관리번호6**에 넣으면 하루 1회 연계 후 이력에 쌓인다. 과거 건은 매핑 불가이므로 이력을 비운다.

상세 탭은 **기본 · 점사용료 이력** 두 개이다. 공시지가는 탭을 열 때 지도 레이어로 켠다. 도형·필지·물건지는 각각 입력하되 부서업무·레이어·목록 선택 시 묶음으로 보인다. 점용 기간 만료·미납 수납 기한은 각각 **15일 전** 공통 중요 알림이다. 화면은 **메뉴 | 목록 | 상세 | 지도** 이다.

## 플로우차트

```
점용분석(중첩·가상책정) → 허가 → 점용대장 등록(관리코드 자동) → 도형·필지·물건지 → 세외수입(관리번호5·6) → 일1회 연계 → 이력·점사용료 조회 / (알림) 만료·미납 15일전
```

## 화면설계

와이어프레임은 **전체화면**이다. 오른쪽은 점용·점사용료 업무용 지도이며, 기존 지도 도구는 유지한다.

### 명칭

- **점용** — 지자체 소유 토지를 개인이 쓰는 행위. 허가와 사용료 납부가 필요하며 5년마다 진행한다.
- **점사용료** — 점용 허가된 필지에 대해 사용료를 부과·납부하며 1년마다 진행한다. 계산식은 점용면적 × (공시지가 × 요율) × 점용기간이며, 산정기준에 따라 요율은 달라질 수 있다(0.02 / 0.05 / 0.0X 등).
- **물건지** — 공사 자재·가설 건축물·관로 등이 놓일 세부 위치나 설치물 명칭이다.

### 기능 목록

- 점용 대장 관리 목록
- 점용 대장 속성 (점용기간 만료 시 알림)
- 점용지 도형 그리기
- 필지 목록 / 물건지 목록
- 공시지가 레이어 표시
- 점사용료 이력 관리 (미납 시 알림)
- 점용 분석 (허가 심사 확인용 / 사용료 가상 책정)

### 점용분석

- **허가 심사 확인용** — 신청 점용과 기존 점용 주소·국공유지 등과의 중복·중첩, 기준 충족을 확인한다.
- **사용료 가상 책정** — 산정기준에 따라 면적·관 길이·건축물 층수 등 입력이 달라진다. 맞는 값을 넣으면 계산식에 따른 예상 금액을 확인한다. 시스템 점사용료 등록은 하지 않는다.

### 점용대장 속성 — 공통

공통: 관리번호 · 점용명 · 허가번호 · 허가일 · 점용장소(도로·하천 주소) · 점용목적 · 점용면적 · 점용기간(시작~종료) 

도로·하천·국공유지 모두 위 공통을 쓰고, 유형별로만 아래를 추가한다.

### 점용대장 속성 — 유형별 추가

- 도로 — 도로종류 · 노선번호 (법령: 도로종류 및 노선번호)
- 하천 — 하천등급 (하천유형·하천코드·하천명)
- 국공유지 — 지목 (도로 또는 하천)

### 목록 열

공통 위주: 관리코드 · 점용명 · 점용위치 · 점용기간 · 영구/일시면적(요약) · 허가일 · 허가번호

유형 표시용 보조 열: 도로(도로종류·노선번호) · 하천(하천명·하천등급) · 국공유지(지목·구분)

### 상세 탭

- **기본** — 공통·유형별 속성 · 필지목록 · 물건지목록 · 도형 그리기

3. 조회 모드에 필지·물건지 추가 버튼이 없어야 한다.
4. 탭 전환 시 공시지가 레이어가 켜져야 한다.

#### 설명

1. 과거 건은 이력 목록을 비우고 안내만 보여 준다.
2. 신규 등록분부터 관리코드·관리번호5·6 연계로 이력을 쌓는다.

#### 확인사항

1. 과거 건에 빈 안내가 나와야 한다.
2. 수동 이력 입력 UI가 없어야 한다.

### MAP-USELDG-06 점사용료 속성 (이력·부서업무 공통)

```
+-------------------------------------------------------------------------------------------------------+
```

3. 분석 결과만으로 점사용료 데이터가 생기지 않아야 한다.
