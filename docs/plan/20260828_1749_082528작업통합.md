## 개발목표

8월 25~28일 작업을 한 묶음으로 정리한다. 레이어설정 법정동·행정동 시군구 필터, 메모관리 UI·지도 점 찍기, 민원·메모 떠 있는 상세 배타·화면 기준 이동, 알림 시스템별·점용 종료 임박 분리, 상세 속성 표 통일, 도로 업무편람(규모 검토·설계실무요령 자료·법령 첨부)을 포함한다.

## 화면설계

### LAY-CODE-01 법정동·행정동 코드 목록

```
┌──────────────────────────────────────────────────────────────────┐
│ 개발  ·  레이어설정  ·  코드                                      │
├────────────┬────────────┬────────────────────────────────────────┤
│ 법정동     │            │ 시군구 기준 12개 / 전체 3500개         │
│ 행정동     │            │ ┌────────┬────────┬────┐               │
│            │            │ │코드명  │한글명  │삭제│               │
│            │            │ └────────┴────────┴────┘               │
└────────────┴────────────┴────────────────────────────────────────┘
```

#### 설명

1. 법정동·행정동만 시군구 기준으로 줄인다. 저장 시 다른 시군구 값은 유지한다.

#### 확인사항

1. 법정동·행정동에서만 시군구 기준 목록이 나와야 한다.
2. 저장 후 다른 시군구 코드가 사라지지 않아야 한다.

### MEMO-01 메모 목록·추가·상세

#### 설명

1. 목록은 민원과 같은 머리글·검색·카드. 추가·상세는 지도 위 떠 있는 패널.
2. 위치는 점 찍기, 칸에는 주소. 작성일·작성자는 읽기 전용.

#### 확인사항

1. 메모 추가 시 가운데를 가리는 창이 열리지 않아야 한다.
2. 행 클릭 시 지도 이동·점 강조가 되어야 한다.

### MEMO-COMP-01 민원·메모 상세 배타

#### 설명

1. 민원·메모 떠 있는 화면은 한 번에 하나만. 다른 부서 업무로 갈 때는 유지.
2. 화면 기준으로 띄우고 목록·업무 패널 위로 옮길 수 있다.

#### 확인사항

1. 민원·메모 상세가 동시에 보이지 않아야 한다.
2. 화면 밖으로 나가지 않아야 한다.

### NOTIF-SYS-01 시스템별 알림

#### 설명

1. 점사용료·점용 종료 알림을 도로·하천·국공유지에 맞게 나눈다.
2. 울진은 울진점용+공통점용, 그 외는 공통점용만 본다.

#### 확인사항

1. 하천 알림에 도로 점사용료가 나오지 않아야 한다.
2. 항목 클릭 시 해당 시스템 상세가 열려야 한다.

### DET-ATTR-01 속성 표

#### 설명

1. 공통점용·울진하천점용·점사용료 상세 속성을 기본계획도와 같은 두 칸 표로 맞춘다.

#### 확인사항

1. 항목명 칸만 회색, 값 칸은 흰색이어야 한다.

### ROAD-HB-01 업무편람

#### 설명

1. 대상여부 검토: 규모 입력·적용 후 절차 전체 유지, 해당 표시 갱신.
2. 설계실무요령 자료: HWP 1~10장 21건, 법령은 XML 첨부 조회.

#### 확인사항

1. 적용 후 «해당» 필터가 자동 선택되지 않아야 한다.
2. 도로설계기준 선택 시 법령 첨부가 내려받기로 표시되어야 한다.
