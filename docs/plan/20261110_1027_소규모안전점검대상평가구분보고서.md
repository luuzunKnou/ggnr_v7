# 작업계획서

2026-11-10 | dev.strcat | docs/brief/20261110_1027_소규모정비계획예산공사.md (1단계: 후보지·안전점검 수정)

## 개발목표

안전점검 대상을 일반·관리 시설로 자동 구성하고, 그 밖의 시설(위험시설 재점검 등)은 «시설 등록»으로 추가한다. 점검마다 평가구분(일반·관리·위험)을 남기며, 가장 최근 점검의 평가구분이 후보지 시설 구분에 자동 반영된다. 위험으로 바뀐 시설은 위험시설 지정일이 채워지고 점검 목록에 그대로 남는다.

안전점검 목록에 «보고서»를 두어, 연도·기준일을 정해 점검 대상 목록(엑셀)과 사업발주 근거자료(미리보기·인쇄)를 내려받는다. 출력할 때마다 그 기준일 목록을 보관해 «지난 출력»에서 다시 열 수 있다. 예시 자료 단계이므로 보관은 새로고침 전까지만 유지된다.

정비계획 연결(위험시설을 정비계획에 추가, 후보지 상세의 정비계획 상태·순위 표시)은 정비계획 단계에서 함께 만든다.

## 플로우차트

```
안전점검 목록 → 시설 상세 → 점검 등록(평가구분) → 시설 구분 자동 반영 → 후보지
안전점검 목록 → 보고서 → (엑셀·인쇄) → 기준일 보관 ⇄ 지난 출력
```

## 화면설계

### SPI-01 안전점검 목록

```
┌──────┬─────────────────────────────────────┬───────────────────────────────┐
│사이드│ 안전점검        [보고서] [+시설 등록] ✕ │                               │
│ 바   │ [세천][소교량][취입보][마을진입로][농로][낙차공]                     │
│      │ [전체][양호][보통][불량]                │                               │
│      │ [시설명·리명·점검일 검색_____________]  │           지     도          │
│      │ 시설명      읍면   구분  최근 점검일 등급│                               │
│      │ 두천리 세천  북면   관리  2026-03-12 보통│                               │
│      │ 고성리 세천  근남면 위험  2026-03-20 불량│                               │
│      │ 매화리 세천  매화면 일반  2025-03-14 양호│                               │
│      │ 총 18건 · 올해 점검 6건                 │                               │
└──────┴─────────────────────────────────────┴───────────────────────────────┘
```

#### 설명

1. 목록에는 일반·관리 시설이 자동으로 들어오고, «시설 등록»으로 추가한 시설(위험시설 등)이 함께 보인다.
2. 구분 열에 시설의 현재 평가구분(일반·관리·위험)을 표시하고, 머리줄로 정렬할 수 있다.
3. 상단 «보고서»를 누르면 보고서 창이 열린다.
4. «시설 등록» 창에는 자동 대상이 아닌 시설(위험 등, 제외 빼고)만 나온다.

#### 확인사항

1. 후보지에서 일반·관리 시설은 따로 등록하지 않아도 안전점검 목록에 보여야 한다.
2. 후보지에서 제외로 바꾼 시설은 안전점검 목록에서 빠져야 한다.
3. «시설 등록» 창에 이미 목록에 있는 시설이 나오지 않아야 한다.

### SPI-02 점검 등록

```
┌──────┬──────────────────────────────────────────────────────────────────┐
│사이드│ ┌ 점검 등록 · 두천리 세천 ────────────────────────────────────┐ │
│ 바   │ │ 점검일*      점검자        평가구분*     위치                │ │
│      │ │ [2026-11-10] [__________]  [관리 ▼]     북면 두천리 · 연장 …│ │
│      │ │ 저장하면 시설 구분이 관리 → 위험으로 바뀝니다                 │ │
│      │ │ ┌ 위험도 평가표 ─────────────────────────────────────────┐ │ │
│      │ │ │ 점검항목   세부사항        A   B   C   점수              │ │ │
│      │ │ └────────────────────────────────────────────────────────┘ │ │
│      │ │ 기타의견 [____________________________________________]     │ │
│      │ │ 원본 점검표 첨부(선택) [스캔본 등 파일 선택]                  │ │
│      │ │ 계 54점 · 보통                              [저장] [취소]   │ │
│      │ └────────────────────────────────────────────────────────────┘ │
└──────┴──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 평가구분은 일반·관리·위험 중 하나를 고르며, 처음에는 시설의 현재 구분이 들어 있다.
2. 현재 구분과 다른 값을 고르면 저장 시 바뀌는 내용을 한 줄로 알려 준다.
3. 저장한 점검이 그 시설의 가장 최근 점검이면 시설 구분이 평가구분으로 바뀐다.
4. 위험으로 바뀌면 위험시설 지정일이 비어 있을 때 점검일로 채워지고, 시설은 점검 목록에 계속 남는다.

#### 확인사항

1. 평가구분을 고르지 않으면 저장되지 않아야 한다.
2. 최근 점검을 위험으로 저장하면 후보지 목록·상세의 구분이 위험으로 보여야 한다.
3. 과거 날짜 점검을 저장할 때는 시설 구분이 바뀌지 않아야 한다.
4. 위험으로 저장한 시설이 안전점검 목록에서 사라지지 않아야 한다.

### SPI-03 점검 상세

```
┌──────┬──────────────────────┬───────────────────────────────┬──────────────┐
│사이드│ 안전점검 목록         │ [세천] 두천리 세천           ✕ │              │
│ 바   │                      │ ▾ 속성정보                    │              │
│      │                      │ 점검이력              [+점검 등록]│    지  도   │
│      │                      │ 구분 관리 · 최근 등급 보통 · 총 3건│              │
│      │                      │ 점검일  구분 점검자 점수 등급  │              │
│      │                      │ ┌ 점검 상세 · 2026년 3월 12일 ┐│              │
│      │                      │ │ 점검자     울진군 건설과    ││              │
│      │                      │ │ 평가구분   관리             ││              │
│      │                      │ │ 합계점수   54점 · 등급 보통 ││              │
│      │                      │ └─────────────────────────────┘│              │
└──────┴──────────────────────┴───────────────────────────────┴──────────────┘
```

#### 설명

1. 점검 상세에 평가구분 줄을 추가한다(평가구분이 없는 연계 점검은 줄 없음).
2. 점검이력 위 요약에 시설의 현재 구분을 함께 보여 준다.

#### 확인사항

1. 점검 상세에 평가구분이 구분 색 뱃지로 보여야 한다.
2. 최근 점검을 삭제하면 그 이전 점검의 평가구분으로 시설 구분이 돌아가야 한다.

### SPI-04 안전점검 보고서

```
┌──────┬──────────────────────────────────────────────────────────────────┐
│사이드│ ┌ 안전점검 보고서 ──────────────────────────────────────────┐ │
│ 바   │ │ 연도 [2026 ▼]  기준일 [2026-11-10]  지난 출력 [새로 작성 ▼]│ │
│      │ │ 대상 18곳 · 신규 2 · 제외 1 · 구분 변경 1                   │ │
│      │ │ ┌ 사업발주 근거자료 미리보기 ─────────────────────────────┐ │ │
│      │ │ │ 2026년 소규모 공공시설 안전점검 대상                     │ │ │
│      │ │ │ 1. 개요   2. 선정 기준   3. 법적 근거                    │ │ │
│      │ │ │ 4. 대상 목록   5. 전년 대비 변동                         │ │ │
│      │ │ └─────────────────────────────────────────────────────────┘ │ │
│      │ │                         [대상 목록 엑셀] [근거자료 인쇄] [닫기]│ │
│      │ └────────────────────────────────────────────────────────────┘ │
└──────┴──────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 연도·기준일을 고르면 그 시점의 점검 대상과 직전 평가구분·직전 점검일(기준일 이전 마지막 점검)로 근거자료를 만든다.
2. 근거자료는 개요(연도·기준일·대상 수·읍면별·유형별 집계), 선정 기준, 법적 근거(법령 원문 확인 후 기재 칸), 대상 목록, 전년 대비 변동(신규·제외·구분 변경)으로 구성한다.
3. «대상 목록 엑셀»은 대상 목록과 집계를 시트로 나눠 내려받고, «근거자료 인쇄»는 미리보기를 인쇄(또는 PDF 저장)한다.
4. 엑셀이나 인쇄를 하면 그 기준일 목록을 보관하고, «지난 출력»에서 고르면 그때 목록으로 다시 보여 준다.
5. 전년 대비 변동은 직전 연도에 보관한 목록과 비교하며, 없으면 «비교할 전년 출력이 없습니다»로 표시한다.

#### 확인사항

1. 기준일을 바꾸면 직전 점검일·직전 평가구분이 기준일 이전 점검으로 바뀌어야 한다.
2. 엑셀 파일에 대상 목록과 집계 시트가 있어야 한다.
3. 출력 후 «지난 출력»에서 고르면 시설 구분이 바뀌었어도 출력 당시 목록이 보여야 한다.
4. 전년 출력과 비교해 신규·제외·구분 변경 시설이 맞게 나와야 한다.
