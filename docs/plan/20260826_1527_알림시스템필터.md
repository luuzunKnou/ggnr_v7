## 개발목표

업무 알림의 점사용료 미납 임박 항목을 도로·하천·국공유지 시스템에 맞게 나눈다. 하천 알림에 도로 점사용료가 섞여 클릭해도 해당 화면으로 가지 못하는 문제를 없앤다.

## 플로우차트

```
알림 수집 → (소속 시스템으로 분류) → 해당 시스템 알림만 표시 → (항목 클릭) → 그 시스템 점사용료 상세
```

## 화면설계

### NOTIF-SYS-01 시스템별 알림

```
+----------------------------------------------------------------------+
| 통합지도                                              [로그인계정]   |
+---+------------------------------------------------------------------+
|메 | [내 정보]                                                        |
|뉴 | +---------------- 알림 ------------------+                       |
|하 | 점사용료 납기 임박                       |                       |
|천 | · 하천점사용료 …                         |                       |
|   +------------------------------------------+                       |
|점 | (지도 · 하천)                                                    |
|사 |                                                                  |
|용 |                                                                  |
|료 |                                                                  |
+---+------------------------------------------------------------------+
+----------------------------------------------------------------------+
```

#### 설명

1. 하천 시스템에 들어오면 하천 점사용료 미납 임박만 보인다.
2. 도로·국공유지 점사용료는 각 시스템 알림에만 나온다.
3. 항목을 누르면 그 시스템의 점사용료 목록과 상세가 열린다.

#### 확인사항

1. 하천 알림에 도로 점사용료 사용자가 나오지 않아야 한다.
2. 도로 알림에서 도로 점사용료 항목을 누르면 도로 점사용료 상세가 열려야 한다.
3. 국공유지 알림에서 국공유지 점사용료 항목을 누르면 해당 상세가 열려야 한다.
4. 하천 점용 종료 임박 알림은 하천에서만 보여야 한다.
