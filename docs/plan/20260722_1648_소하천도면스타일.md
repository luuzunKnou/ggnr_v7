## 개발목표

소하천 색인도·종단면도·횡단면도 지도 스타일을 지방하천과 같게 맞춰, 소하천 탭에서도 동일한 선·라벨 표현을 쓴다.

## 플로우차트

소하천 레이어 → 지방하천 스타일 기준 → 색인도·종단·횡단 표시

## 화면설계

### MAP-SR-STYLE-01 소하천 도면 스타일

```
┌──────────────────────────────────────────────┐
│ [지도]                                        │
│   ┌───┐ 색인도 번호(가운데)                    │
│   └───┘                                       │
│   ─── 종단(양끝 막대)  ─── 횡단+라벨            │
└──────────────────────────────────────────────┘
```

#### 설명

1. 소하천 색인도는 지방하천과 같은 테두리·번호 라벨이다.
2. 소하천 종단은 분홍 선과 양끝 막대 표시이다.
3. 소하천 횡단은 분홍 선과 도면명 라벨이다.

#### 확인사항

1. 소하천 색인도 번호가 칸 가운데에 보여야 한다.
2. 소하천 종단·횡단 선 색이 지방하천과 같아야 한다.
3. 소하천 횡단 확대 시 도면명 라벨이 보여야 한다.
