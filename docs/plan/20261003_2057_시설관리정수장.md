## 개발목표

시설관리 «정수장»에서 도로 시설관리처럼 위쪽에 목록, 아래쪽에 상세가 같이 보이게 한다. 상세에서는 기본정보와 내부설비를 보고, 설비를 고르면 제원·유지보수·정기점검·계약정보까지 본다.

## 플로우차트

```
시설관리 → 정수장 탭 → 목록+기본정보 → (오른쪽) 내부설비 → 설비정보 ⇄ 유지보수·점검·계약
```

## 화면설계

### FAC-WTP-01 목록과 상세

```
┌────────────────────────────────┐
│ 시설관리                    ✕  │
│취수장 정수장 배수지 …          │
│        ─────                   │
│ 시설명     용량    준공 상태   │
│ 영양정수장 3000    2008 가동   │
│ 입암정수장 1200    2014 가동   │
│────────────────────────────────│
│ 영양 정수장            가동    │
│ 기본정보 │ 내부설비            │
│ 시설명 영양 정수장 …           │
└────────────────────────────────┘
```

#### 설명

1. 위는 정수장 목록이고, 아래는 고른 행의 상세다.
2. 도로 시설관리 목록·기본정보와 같이 한 패널에 위·아래로 나뉜다.
3. 상세 탭은 기본정보와 내부설비다.

#### 확인사항

1. 정수장 탭에서 목록과 상세가 같이 보여야 한다.
2. 다른 정수장을 누르면 아래 상세가 바뀌어야 한다.

### FAC-WTP-02 내부설비와 이력

```
┌────────────────────────────────┐
│ …목록…                         │
│────────────────────────────────│
│ ← 내부설비  영양 › 취수펌프1호 │
│ 제원│유지보수│정기점검│계약정보│
│ 형식 원심펌프 …                │
└────────────────────────────────┘
```

#### 설명

1. 내부설비 행을 누르면 같은 아래 칸에서 설비 상세로 바뀐다.
2. «내부설비»로 돌아가면 설비 목록이 다시 나온다.
3. 유지보수·정기점검·계약은 표로 본다.

#### 확인사항

1. 설비 상세에 제원과 이력 탭이 있어야 한다.
2. 돌아가면 같은 정수장의 내부설비 목록이 나와야 한다.
