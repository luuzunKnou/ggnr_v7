# 작업계획서

2026-08-21 | JungWooojin | 접도구역 건축물 사진확인인쇄

## 개발목표

종전·변경·건축물 사진은 칸마다 한 장만 둔다. 이미 사진이 있는데 다시 올리거나 지우면 확인 창을 띄운 뒤, 확인하면 덮어쓰거나 삭제한다. 위치에서 담은 지도 그림은 위치도 폴더에 넣고, 인쇄에도 그 그림이 나와야 한다. 상세 칸 배치는 바꾸지 않는다.

## 플로우차트

```
사진 등록·삭제 → 확인 창 → (확인) → 덮어쓰기·삭제 · 위치도 담기 → 폴더 → 인쇄
```


#### 설명

1. 종전·변경·건축물 칸은 사진 한 장만 보여 준다.
2. 사진이 있는 칸에 다시 올리면 덮어쓰기 확인 창이 뜬다.
3. 삭제 단추를 눌러도 확인 창이 뜬 뒤에만 지운다.
4. 위치도는 주소를 고르면 지도를 담아 위치도 폴더에 넣고, 인쇄 제2쪽에 그 그림이 나온다.

#### 확인사항

1. 사진이 없는 칸은 확인 없이 바로 올릴 수 있어야 한다.
2. 사진이 있는 칸에 다시 올리면 확인 후 덮어써야 한다.
3. 사진 삭제는 확인 후에만 지워져야 한다.
4. 주소를 고른 뒤 저장하면 위치도 폴더에 그림이 있어야 한다.
5. 인쇄 제2쪽 위치도에 그 그림이 나와야 한다.
