## 개발목표

«소규모 공공시설관리 시스템»에 부서업무 메뉴 «후보지»와 «안전점검»을 만든다. 후보지는 세천, 소교량, 취입보, 마을진입로, 농로, 낙차공을 유형별로 보고, 선정·제외와 선정 안의 일반·관리·위험시설로 나눠 본다. 상세에서 시설 속성, 위험도평가 이력, 정비계획 첨부파일을 본다.

안전점검은 시설 유형별로 위치, 최근 점검일, 최근 등급을 보고, 상세에서 점검 이력과 점검표를 본다. 점검 결과는 연계로 가져오는 것이 기본이고, 직접 등록·수정·삭제도 할 수 있다. 점검 항목은 해마다 바뀔 수 있어 시스템에는 합계점수와 등급만 저장하고, 항목 내용은 첨부한 점검표 파일로 본다. 빈 점검표 한글 양식은 시설 유형별로 내려받을 수 있다.

후보지의 위험도평가 이력과 안전점검의 점검 이력은 같은 점검 자료이며, 시설의 위험도등급·점수는 가장 최근 점검 결과로 맞춰진다. 외부 연계 가져오기는 연계 대상이 정해진 뒤 별도로 붙인다.

## 플로우차트

```
지도 → 후보지 목록 ⇄ 후보지 상세 → (이력 클릭) → 위험도평가 모달 / 안전점검 목록 ⇄ 안전점검 상세 → 점검 등록
```

## 화면설계

### SPF-CAND-01 후보지 목록

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 검색창                                                                   │
├──────────┬────────────────────────────────────┬──────────────────────────┤
│ 사이드바 │ 후보지                           ✕ │                          │
│          │ 세천│소교량│취입보│진입로│농로│낙차공│                          │
│ 후보지   │ 전체  선정  제외                   │                          │
│ 안전점검 │ 전체  일반  관리  위험             │           지도           │
│          │ 읍면 ▾  시설명·관리번호 검색       │                          │
│ 데이터   │────────────────────────────────────│                          │
│ 조회     │ 관리번호  시설명     리명   구분 등급│                          │
│          │ 세천-003  연지리세천 연지리 위험 불량│                          │
│ 필지분석 │ 세천-009  고성리세천 고성리 관리 보통│                          │
│          │ 세천-012  명도리세천 명도리 일반 양호│                          │
│ 민원     │────────────────────────────────────│                          │
│ 메모     │ 총 120건                           │                          │
└──────────┴────────────────────────────────────┴──────────────────────────┘
```

#### 설명

1. 상단 탭으로 시설 유형을 고르고, 그 아래에서 선정·제외를 고른다.
2. 선정을 고르면 일반·관리·위험 구분이 한 줄 더 나와 다시 걸러 볼 수 있다.
3. 읍면 선택과 시설명·관리번호 검색으로 목록을 줄인다.
4. 지도에는 고른 유형의 시설이 구분별 색으로 보이고, 지도에서 시설을 눌러도 상세가 열린다.

#### 확인사항

1. 탭을 바꾸면 그 유형 시설만 목록과 지도에 보여야 한다.
2. 제외를 고르면 일반·관리·위험 구분 줄이 숨겨져야 한다.
3. 목록 아래 건수가 거른 결과와 같아야 한다.
4. 목록 행을 누르면 지도가 그 시설로 이동해야 한다.

#### 설명

1. 위쪽에 시설 속성 19개를 표로 보여 주고, 수정을 누르면 같은 자리에서 고친다.
2. 위험도등급·점수는 가장 최근 점검 결과가 자동으로 들어가며 직접 고치지 않는다.
3. 아래 탭 «위험도평가 이력»은 이 시설의 점검을 최근 순으로 보여 준다.
4. 아래 탭 «정비계획 첨부»는 이미 진행한 정비계획 파일을 올리고 미리보기·내려받기한다.
5. 위치 편집으로 시설 도형을 지도에서 고칠 수 있다.

#### 확인사항

1. 속성 19개가 모두 보이고 수정 후 저장되어야 한다.
2. 위험도등급·점수가 이력 맨 위 점검과 같아야 한다.
3. 정비계획 첨부의 PDF·이미지·엑셀은 화면에서 열려야 한다.
4. 이력이 없으면 «위험도평가 이력이 없습니다» 안내가 나와야 한다.

#### 설명

1. 상단 탭으로 시설 유형을 고르고, 선정된 시설만 점검 대상으로 보여 준다.
2. 행마다 시설명, 리명, 최근 점검일, 최근 등급이 보이고, 등급으로 걸러 볼 수 있다.
3. «점검표 양식»을 누르면 시설 유형별 빈 점검표 한글 파일을 내려받고, 관리자는 새 양식으로 바꿔 올린다.
4. «등록»을 누르면 점검 등록 모달이 열린다.
5. 목록 아래에 전체 건수와 올해 점검한 건수가 보인다.

#### 확인사항

1. 아직 점검하지 않은 시설은 «점검 없음»으로 보여야 한다.
2. 점검표 양식은 지금 고른 유형의 양식이 내려받아져야 한다.
3. 관리자가 아니면 양식 바꾸기가 보이지 않아야 한다.
4. 지도에서 시설을 누르면 상세가 열려야 한다.


#### 설명

1. 위에 시설 요약과 최근 등급·최근 점검일·총 건수가 보인다.
2. 점검이력 표에서 행을 고르면 아래 점검 상세에 점검자, 비고, 점검표 미리보기가 나온다.
3. 직접 등록한 점검만 수정·삭제할 수 있고, 연계로 받은 점검은 점검표 파일만 추가할 수 있다.
4. «후보지에서 보기»를 누르면 후보지 메뉴의 같은 시설 상세로 이동한다.

#### 확인사항

1. 점검이력이 최근 점검일 순으로 나와야 한다.
2. 연계 점검을 고르면 수정·삭제가 보이지 않아야 한다.
3. 점검을 삭제하면 시설의 위험도등급·점수가 남은 점검 중 최근 것으로 바뀌어야 한다.
4. 점검이력이 없으면 «점검 이력이 없습니다» 안내가 나와야 한다.

### SPF-INSP-03 점검 등록

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ 검색창                                                                        │
├──────────┬──────────────────┬──────────────────────────────┬──────────────────┤

│          │        ┌───────────────────────────────────────────┐                │
│          │        │ 점검 등록                                ✕ │                │
│          │        │ 시설     연지리 세천 세천-003   지도에서 선택│                │
│          │        │ 점검일   2026-03-20                        │                │
│          │        │ 점검자   홍길동                            │                │
│          │        │ 합계점수 74                                │                │
│          │        │ 등급     양호  보통  불량                  │                │
│          │        │ 비고                                       │                │
│          │        │ 점검표   파일 선택     점검표 양식 내려받기│                │
│          │        │                              취소   저장   │                │
│          │        └───────────────────────────────────────────┘                │
└──────────┴──────────────────┴──────────────────────────────┴──────────────────┘
```

#### 설명

1. 상세에서 열면 시설이 미리 채워지고, 목록에서 열면 시설을 검색하거나 지도에서 고른다.
2. 합계점수를 넣으면 지금 기준(30점 이하 양호, 31~70점 보통, 71점 이상 불량)으로 등급이 먼저 골라지고, 사람이 바꿀 수 있다.
3. 고른 시설 유형의 빈 점검표 한글 양식을 이 화면에서도 내려받을 수 있다.
4. 저장하면 점검이력에 추가되고 시설의 위험도등급·점수가 갱신된다.
5. 수정도 같은 모달을 쓰며, 기존 점검표를 바꾸거나 지울 수 있다.

#### 확인사항

1. 시설, 점검일, 합계점수, 등급이 없으면 저장되지 않아야 한다.
2. 합계점수는 0~100 사이 숫자만 받아야 한다.
3. 같은 시설·같은 점검일 점검이 이미 있으면 안내가 나와야 한다.
4. 저장 후 후보지 상세의 위험도평가 이력에도 바로 보여야 한다.
