# 작업계획서

2026-10-21 | gyujin | 세로 색인도 도면이 뒤집혀 좌우가 바뀐 경우

## 개발목표

세로 색인도 칸의 세로 도면이 위아래·좌우가 뒤집혀 있으면, 지명처럼 가로로 쓰인 글로 바로 세운다. 가로 칸에서 90도로 돌리는 규칙은 그대로 둔다. 원본 파일은 바꾸지 않는다.

## 플로우차트

```
색인도 선택 → (세로 칸·뒤집힌 도면) → 가로 글자 방향으로 180도 → 썸네일·전체화면
```


#### 설명

1. 지도에서 세로로 놓인 색인도 칸을 고른다.
2. 도면 속 지명·비포장 같은 가로 글자가 뒤집혀 있으면 180도 돌려 바로 세운다.
3. 지번처럼 하천을 따라 돌아간 글자는 방향 판단에 쓰지 않는다.

#### 확인사항

1. 대동2천처럼 뒤집힌 세로 도면은 한글이 바로 서야 한다.
2. 가로 색인도 칸의 세로 도면은 이전처럼 바로 서야 한다.
3. 처음부터 바로 선 세로 도면은 돌지 않아야 한다.
