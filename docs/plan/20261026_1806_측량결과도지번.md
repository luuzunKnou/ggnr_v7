## 개발목표

측량결과도 목록·상세의 지번을 본표가 아니라 하위 표에서 읽어 온다. 한 장에 여러 지번이 묶이면 다른 기록물과 같이 대표 주소와 나머지 개수를 보여 준다. 읍면동·지번 검색도 하위 표 지번으로 거른다.

## 플로우차트

```
지도 → 지적기록물 목록 → (측량결과도 행) → 미리보기·하위 표 지번
```

#### 설명

1. 측량결과도 한 줄은 스캔 파일 한 장이다.
2. 지번 칸은 하위 표에 있는 대표 주소와 «외 n»이다.
3. 읍면동·지번으로 검색하면 그 지번이 묶인 측량결과도 장만 남는다.
4. 상세에는 같은 하위 표 지번이 나열된다.

#### 확인사항

1. 측량결과도 지번 칸에 권이 아니라 실제 지번이 나와야 한다.
2. 한 장에 지번이 여러 개면 «외 n»과 상세 목록이 나와야 한다.
3. 읍면동을 골라도 해당 지번이 묶인 측량결과도가 목록에 남아야 한다.
