## 개발목표

공통 점용(하천점용·도로점용·국공유지)과 울진 하천점용을 공통 점용 하나로 합친다. 대장마다 같은 뜻의 칸은 같은 이름(10글자 이내)으로 맞추고, 대장에만 있는 칸은 추가속성에 넣는다. 기준 자료는 울진 하천점용이다.

1단계(이번)에서는 필지·물건지 연결을 허가번호에서 점용 건 고유키로 바꾸고, 점용 시작·종료를 날짜 선택 대신 글자 입력으로 바꾼다. 날짜로 읽히는 글자(2024.03.01, 2024.03, 2024 등)만 진행중·종료 판단과 만료 알림에 쓰고, «영구»가 들어 있으면 진행중으로 본다. 허가번호로만 묶여 있던 기존 필지는 계속 보이고, 그 건을 저장할 때 고유키 연결로 옮겨진다.

2단계에서는 하천점용·도로점용 테이블을 받은 자료 테이블로 바꾸고 칸 이름을 맞춘다. 3단계에서는 상세 화면을 보상편입용지처럼 필지목록·필지 상세 구조로 바꾸고, 물건지·점사용료 이력을 상단 버튼으로 펼치게 한다.

영향 받는 기능: 공통 점용 목록·상세·등록·수정·삭제, 지도에서 점용 필지 누르기, 점용 만료 업무알림, 점사용료 연계 레이어, 공통 편집기(필지 저장·삭제)를 쓰는 다른 대장(울진 하천점용·공사대장 등).

## 플로우차트

```
점용 목록 → 점용 상세 ⇄ 수정(기간 글자 입력) → 저장(필지 고유키 연결) → 점용 상세 → 필지 상세
```

## 화면설계

### OCC-01 점용 목록

```
┌────┬──────────────────────────────┬──────────────────────────────────┐
│메뉴│ 도로점용                  ✕ │                                  │
│    │ [검색어            ] [상태▾] │                                  │
│    │ 상태  점용명  점용장소  시작  종료│              지도                │
│    │ 진행중 ○○    ○○리 1  2024.03.01 영구│                                  │
│    │ 종료   ○○    ○○리 2  2019.01  2020.12│                                  │
│    │ 진행중 ○○    ○○리 3  허가일로부터 3년 │                                  │
│    │                     추가        │                                  │
└────┴──────────────────────────────┴──────────────────────────────────┘
```

#### 설명

1. 시작·종료 칸은 입력한 글자를 그대로 보여 준다.
2. 상태는 종료 칸이 날짜로 읽히면 오늘과 비교해 진행중·종료로, «영구»나 날짜로 읽히지 않으면 진행중으로 보여 준다.
3. 시작·종료 정렬은 날짜로 읽히는 값끼리 날짜 순, 읽히지 않는 값은 뒤에 둔다.

#### 확인사항

1. 날짜가 아닌 기간도 목록에 그대로 보여야 한다.
2. 종료가 지난 날짜인 건은 종료로 보여야 한다.
3. 종료에 «영구»가 들어 있으면 진행중으로 보여야 한다.

### OCC-02 점용 상세·수정

```
┌────┬──────────────────────────────┬──────────────────────────────────┐
│메뉴│ 도로점용 상세              ✕ │                                  │
│    │ 상세 속성       수정  삭제   │                                  │
│    │ 점용명     │ ○○              │                                  │
│    │ 허가번호   │                 │              지도                │
│    │ 점용 시작일│ [2024.03      ] │                                  │
│    │ 점용 종료일│ [영구         ] │                                  │
│    │ 상태       │ 진행중          │                                  │
│    │ 필지목록                     │                                  │
│    │  ○○리 1                     │                                  │
│    │ 물건지목록                   │                                  │
└────┴──────────────────────────────┴──────────────────────────────────┘
```

#### 설명

1. 점용 시작일·종료일은 날짜 선택 대신 글자 입력칸으로 바뀐다.
2. 종료일을 바꾸면 상태가 바로 다시 계산된다.
3. 허가번호가 없어도 필지·물건지를 저장할 수 있다.
4. 필지·물건지는 점용 건 고유키로 연결되고, 예전에 허가번호로만 묶인 필지도 그대로 보인다.

#### 확인사항

1. 시작·종료에 «영구», «허가일로부터 3개월» 같은 글자를 넣어 저장할 수 있어야 한다.
2. 허가번호를 비운 채 필지를 넣고 저장할 수 있어야 한다.
3. 기존 도로점용 건을 열면 필지목록이 예전처럼 보여야 한다.
4. 기존 도로점용 건을 저장한 뒤에도 필지목록이 그대로 남아 있어야 한다.
5. 점용 건을 삭제하면 연결된 필지·물건지도 함께 지워져야 한다.

### OCC-03 지도에서 점용 필지 누르기

```
┌────┬──────────────────────────────┬──────────────────────────────────┐
│메뉴│ 도로점용 상세              ✕ │      ┌──────┐                    │
│    │ 상세 속성                    │      │ 필지 │  ← 누름             │
│    │ 점용명     │ ○○              │      └──────┘                    │
│    │ ...                          │              지도                │
└────┴──────────────────────────────┴──────────────────────────────────┘
```

#### 설명

1. 지도에서 점용 필지를 누르면 그 필지가 속한 점용 건 상세가 열린다.
2. 고유키로 연결된 필지와 허가번호로만 묶인 예전 필지 모두 같은 점용 건을 찾는다.

#### 확인사항

1. 새로 저장한 필지를 누르면 해당 점용 건 상세가 열려야 한다.
2. 예전 도로점용 필지를 눌러도 해당 점용 건 상세가 열려야 한다.
