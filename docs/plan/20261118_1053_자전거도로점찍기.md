## 개발목표

자전거도로 구간 추가를 드래그 따라그리기에서 점 찍기로 바꾼다. 도로구간을 이어 붙인 경로망 안내선 위에 점을 찍고, 점 사이는 도로를 따른 경로로 잇는다. 사거리에서는 다음 점을 원하는 갈래에 찍어 꺾이게 한다. 양측·편측 저장·배너는 유지한다.

## 플로우차트

```
상세 → 구간추가 → 양측편측 → 도로점찍기 → (사거리 갈래 선택) → 완료 → 구간표
```

## 화면설계

### BR-DRAW-01 구간 추가 · 점 찍기

```
┌──────┬─────────────────────────────────────────────┐
│ 사이드 │  [검색]                                      │
│ 메뉴   │ ┌─────────────────────────────────────────┐ │
│ ···    │ │ 구간 추가 · 편측   점 2  [되돌리기][완료][취소] │ │
│ 자전거 │ │ 도로 위를 클릭해 점을 찍으세요. 사거리는 갈래에 찍으세요. │ │
│ 도로   │ └─────────────────────────────────────────┘ │
│        │                                             │
│        │            (지도 · 하늘색 도로 안내선)         │
│        │                 ●─────●                     │
│        │                    ╲                        │
│        │                     ●  ← 옆 갈래에 찍은 점    │
│        │                                             │
│        │                              ┌─ 상세 패널 ─┐ │
│        │                              │ 구간 표 …   │ │
│        │                              └─────────────┘ │
└──────┴─────────────────────────────────────────────┘
```

#### 설명

1. 구간 추가를 켜면 지도에 이어 붙인 도로 안내선과 안내 배너가 보인다.
2. 도로 위를 클릭할 때마다 점이 찍히고, 직전 점과 도로를 따라 이어진다.
3. 사거리에서는 가고 싶은 갈래 위에 다음 점을 찍으면 경로가 그쪽으로 꺾인다.
4. 되돌리기는 마지막 점을 지우고, 완료 시 편측·양측 구간이 표에 반영된다.

#### 확인사항

1. 도로 위 점 두 개 이상 찍고 완료하면 구간이 생겨야 한다.
2. 사거리에서 옆 갈래에 점을 찍으면 경로가 그쪽으로 꺾여야 한다.
3. 도로 밖 클릭은 점이 잡히지 않거나 안내가 나와야 한다.
4. 이어지지 않은 두 도로를 찍으면 직선으로 건너뛰지 않아야 한다.
5. 되돌리기·취소·양측편측 저장은 기존과 같아야 한다.
