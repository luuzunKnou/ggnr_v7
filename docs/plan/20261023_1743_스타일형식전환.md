## 개발목표

레이어 설정의 스타일 수정에서 CSS와 SLD를 고르면, 그 형식으로 스타일 본문을 다시 저장한다. 저장은 지오서버가 받아 설정 파일의 형식과 파일명을 바꾸게 한다. SLD로 바꾸면 지금 화면의 색과 선으로 기본 스타일을 만들고, 화살표처럼 복잡한 규칙은 관리자 화면에서 잇는다. CSS로 바꾸면 그 복잡한 규칙이 빠진다는 확인 뒤에 화면의 단순 스타일로 덮는다.

## 플로우차트

스타일 수정 → (형식 선택) → 확인 → 스타일 다시 저장 → 스타일 수정

## 화면설계

### DEV-STYLE-02 스타일 형식

```
┌──────────────────────────────────────────────┐
│ 스타일 수정: 레이어이름                    X │
├──────────────────────────────────────────────┤
│ 관리자 화면에서 스타일 직접 수정 →  [SLD|CSS]│
│                                              │
│ 도형 타입   [          ]                     │
│                                              │
│                          [취소]  [저장]      │
└──────────────────────────────────────────────┘
```

#### 설명

1. 관리자 화면 버튼 오른쪽에 SLD와 CSS 선택이 보인다.
2. 지금 형식과 같은 쪽은 선택된 상태로 보인다.
3. CSS에서 SLD를 고르면 화면의 색과 선으로 기본 SLD를 저장한다.
4. SLD에서 CSS를 고르면 추가 규칙이 사라진다는 확인 뒤에 단순 스타일로 저장한다.
5. SLD인 동안에는 색·선 항목 대신 관리자 화면에서 고치라는 안내가 보인다.

#### 확인사항

1. SLD를 고르면 설정 파일의 형식이 SLD로 바뀌어야 한다.
2. CSS를 고르면 설정 파일의 형식이 CSS로 바뀌어야 한다.
3. SLD에서 CSS로 바꿀 때 확인을 취소하면 형식이 유지되어야 한다.
4. 바꾼 뒤 지도 범례가 그 스타일로 나와야 한다.
