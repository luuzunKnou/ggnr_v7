## 개발목표

설치파일을 만들 때 파이썬 환경을 매번 처음부터 나누어 압축하지 않는다. 환경 내용이 같으면 지난번에 만든 분할본을 그대로 넣고, 패키지가 바뀐 뒤에만 다시 압축한다. 시연용으로 새 폴더에 풀어도 분할본은 설치파일 안에 그대로 들어간다.

## 플로우차트

```
설치파일 만들기 → 파이썬 환경 확인 → (같음) 저장된 분할본 사용 → 설치파일 / (다름) 다시 압축·분할 → 저장 → 설치파일
```

#### 설명

1. 파이썬 환경 포함을 켠 채 설치파일을 만들면 환경이 같은지 먼저 본다.
2. 같으면 진행 안내에 저장된 분할본을 쓴다는 문구가 나온다.
3. 다르거나 저장된 분할본이 없으면 이전처럼 압축·분할하고 그 결과를 다음에 쓰도록 남긴다.
4. 포함을 끄면 예전처럼 파이썬 분할을 넣지 않는다.

#### 확인사항

1. 같은 환경으로 설치파일을 두 번 만들면 두 번째는 분할 압축을 다시 하지 않아야 한다.
2. 두 번째 진행 안내에 저장된 분할본을 쓴다는 문구가 나와야 한다.
3. 파이썬 패키지를 바꾼 뒤에는 다시 압축·분할되어야 한다.
4. 설치파일을 시연 새 폴더에 풀면 시작 시 파이썬 환경이 복원되어야 한다.
5. 포함을 끄면 분할본이 들어가지 않아야 한다.
