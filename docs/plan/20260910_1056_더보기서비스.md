## 개발목표

사이드바 내 정보를 열면 칸 위에서 내 정보와 더보기를 나눈다. 더보기는 즐겨찾기·검색·기능 목록이고, 바로가기 설정은 옆에 따로 연다. 칸 크기와 옆·아래 간격은 내 정보·부서업무와 같게 둔다.

## 플로우차트

```
지도 → 내 정보 ⇄ 더보기 ⇄ 바로가기 설정 → 기능 화면
```

## 화면설계

### MAP-MORE-01 내 정보

```
┌────┬────────────────────────────────────────────────────┐
│ 로 │ 검색                                               │
│ 고 │                                                    │
│ 메 │                     지도                           │
│ 뉴 │  ┌──────────────┐                                  │
│    │  │ 내 정보 더보기 ✕ │                              │
│────│  │ 이름 · 부서      │                              │
│ 나 │  │ 로그아웃         │                              │
│ 정 │  │ 촬영요청  알림   │                              │
│ 보 │  └──────────────┘                                  │
└────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 칸 위에서 내 정보와 더보기를 구간 단추로 고른다.
2. 내 정보에는 이름·부서·로그아웃과 촬영요청·알림이 있다.
3. 촬영요청·알림은 눌러 펼친다.
4. 칸 너비와 알림을 최대로 펼친 높이가 더보기와 같다.

#### 확인사항

1. 내 정보 단추가 선택된 상태로 보여야 한다.
2. 촬영요청·알림은 이전처럼 열리고 접혀야 한다.
3. 더보기로 화면이 바뀌어야 한다.

### MAP-MORE-02 더보기

```
┌────┬────────────────────────────────────────────────────┐
│ 로 │ 검색                                               │
│ 고 │                                                    │
│ 메 │                     지도                           │
│ 뉴 │  ┌──────────────┐                                  │
│    │  │ 내 정보 더보기 ✕ │                              │
│────│  │ 즐겨찾기     ⚙  │                              │
│ 나 │  │ 〈 공지 자료 메모 민원 〉 │                      │
│ 정 │  │ 검색             │                              │
│ 보 │  │ 공지 자료 메모   │                              │
│    │  │ 민원 점용 …      │                              │
│    │  └──────────────┘                                  │
└────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 더보기 칸 크기·옆·아래 간격은 내 정보·부서업무와 같다.
2. 즐겨찾기는 고른 항목만 한 줄에 두고, 넘치면 화살표나 끌어 넘기기로 본다.
3. 비어 있으면 추가만 보이며, 높이는 글씨·테두리까지 즐겨찾기 칸과 같다.
4. 아래 목록은 겹침 없이 한 번에 보여 주고, 공지사항·자료실이 앞에 온다.
5. 검색어를 넣으면 이름에 맞는 기능만 남는다.
6. 기능을 고르면 그 화면이 열리고 이 칸은 닫힌다.

#### 확인사항

1. 더보기 단추가 선택된 상태로 보여야 한다.
2. 칸 너비와 높이가 내 정보에서 알림을 최대로 펼친 크기와 같아야 한다.
3. 즐겨찾기가 한 줄을 넘으면 화살표나 끌어 넘기기가 되고 스크롤 막대는 보이지 않아야 한다.
4. 목록 맨 앞에 공지사항·자료실이 있어야 한다.
5. 같은 기능이 목록에 두 번 나오지 않아야 한다.
6. 기능을 고르면 해당 화면이 열리고 칸은 닫혀야 한다.

### MAP-MORE-03 바로가기 설정

```
┌────┬────────────────────────────────────────────────────┐
│ 로 │ 검색                                               │
│ 고 │                                                    │
│ 메 │                     지도                           │
│ 뉴 │  ┌──────────────┐ ┌──────────────┐                 │
│    │  │ 내 정보 더보기 ✕ │ │ 바로가기 설정  3개 │        │
│────│  │ 즐겨찾기     ⚙  │ │ 기본            │           │
│ 나 │  │ 공지 자료 메모 민원 │ │ 공지사항  자료실  │       │
│ 정 │  │ 검색             │ │ 하천            │           │
│ 보 │  │ 공지 자료 …      │ │ 메모      민원  │           │
│    │  └──────────────┘ │ 초기화  확인 취소 │           │
│    │                   └──────────────┘                 │
└────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 톱니 또는 추가로 바로가기 설정이 더보기 옆에 열린다.
2. 항목은 한 줄에 두 개씩이고, 개수 제한 없이 고른다.
3. 시스템별 묶음은 이 칸에만 둔다.
4. 확인하면 즐겨찾기에 반영되고, 취소하면 닫힌다.

#### 확인사항

1. 바로가기 설정은 옆 칸으로 따로 열려야 한다.
2. 항목이 한 줄에 두 개씩 보여야 한다.
3. 네 개를 넘어도 고를 수 있어야 한다.
4. 확인하면 위에 고른 항목만 보여야 한다.
5. 사이드바 메뉴는 그대로여야 한다.
