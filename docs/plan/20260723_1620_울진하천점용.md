## 개발목표

울진은 점용대장 기준으로 하천점용 목록·상세·지도 연동을 별도 기능으로 제공한다. 기존 부과대장 기반 하천점용과 UI는 유사하되 데이터·메뉴를 분리하고, 울진 런타임에서만 새 메뉴를 보이게 한다.

## 플로우차트

지도 → 하천점용(울진) → 점용 목록 → 점용 상세 ⇄ 지도 이동

## 화면설계

### MAP-UJ-USAGE-01 점용 목록

```
┌──────────────────────────────────────────────────────────┐
│ [사이드바]     │ 하천점용                          [+] [×] │
│  하천점용 ●    │ ┌────────────────────────────────────┐ │
│  …             │ │ 검색 (허가번호, 위치, 하천명 등)     │ │
│                │ └────────────────────────────────────┘ │
│                │ 허가번호 │ 점용위치 │ 하천명 │ 점용자   │
│                │ ─────────┼─────────┼───────┼──────── │
│                │ …        │ …       │ …     │ …       │
│                │                              N건      │
│                │              [지도]                     │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 사이드바에서 «하천점용»을 선택하면 점용대장 기준 목록 패널이 열린다.
2. 검색어로 허가번호·위치·하천명·점용자 등을 좁힐 수 있다.
3. 행을 클릭하면 상세가 열리고 지도가 해당 위치로 이동한다.
4. 패널이 열리면 점용대장 지도 레이어가 켜진다.

#### 확인사항

1. 울진에서만 해당 메뉴가 보여야 한다.
2. 목록이 점용대장 데이터로 채워져야 한다.
3. 행 클릭 시 상세와 지도 이동이 되어야 한다.

### MAP-UJ-USAGE-02 점용 상세

```
┌──────────────────────────────────────────────────────────┐
│ [사이드바] │ 하천점용 목록 │ 하천점용 상세  [수정][×]     │
│            │               │ 허가번호 …                  │
│            │               │ 하천명 …                    │
│            │               │ 점용위치 …                  │
│            │               │ 점용자 …                    │
│            │               │ …                           │
│            │               │         [지도]              │
└──────────────────────────────────────────────────────────┘
```

#### 설명

1. 목록에서 선택한 건의 속성을 상세 패널에 표시한다.
2. 수정·저장·삭제·신규 등록은 기존 레이어 행 편집 패턴을 따른다.
3. 필지목록·물건지 섹션은 두지 않는다.

#### 확인사항

1. 상세 속성이 한글로 보여야 한다.
2. 저장 후 목록이 갱신되어야 한다.
3. 다른 시군 부과대장 하천점용과 동시에 같은 메뉴로 섞이지 않아야 한다.
