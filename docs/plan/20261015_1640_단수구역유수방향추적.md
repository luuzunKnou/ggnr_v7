## 개발목표

단수구역을 거리 버퍼가 아니라 관로 유수방향을 따라 잡는다. 잠근 제수변에서 관로 선을 타고 하류로만 이어가며 단수 관로·범위를 그린다. 관로에 별도 방향 속성이 없으면 도형 시작에서 끝으로 그린 방향을 유수로 본다.

## 플로우차트

제수변 잠금 → 근처 관로 시드 → 유수방향(시작→끝) 라인 추적 → 단수관로·면·수용가

## 화면설계

### SPA-OUT-04 단수구역(유수방향)

```
┌──────사이드────────┬──────────지도──────────┐
│ 공간분석 단수구역    │  관로·제수변           │
│ 잠금 · 분석        │  ● 잠금 → 하류 주황관로 │
│ 수용가 목록         │                        │
└────────────────────┴────────────────────────┘
```

#### 설명

1. 제수변을 잠그면 근처 관로를 시드로 잡는다.
2. 관로 도형 시작에서 끝 방향으로만 이어지는 관로를 따라가 단수 구간으로 표시한다.
3. 상류로는 올라가지 않는다.
4. 모인 관로 주변으로 단수 면과 수용가를 채운다.

#### 확인사항

1. 잠금 후 단수 관로가 제수변 한쪽(하류)으로만 이어져야 한다.
2. 거리로 넓게 퍼지던 이전보다 관로를 따라 가야 한다.
3. 여러 제수변 잠금 시 각 하류가 합쳐져 보여야 한다.
