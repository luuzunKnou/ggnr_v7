## 개발목표

데이터 요청 목록을 역할(본인·팀장·관리자·슈퍼)에 맞게 나누고, 사용자 검색은 일반 사용자에게 숨긴다. 별도 «데이터 요청 승인» 화면에서 대기 건을 기본으로 보여 주고 승인·반려하며, 팀장은 부서의 팀장 승인 건만, 관리자·슈퍼는 전체를 본다. 새 테이블은 만들지 않는다.

## 플로우차트

```
포털 → 데이터 요청(역할별 목록) → 다운로드
포털 → 데이터 요청 승인 → (대기 기본) → 승인·반려 → 데이터 요청
```

## 화면설계

### DR-01 데이터 요청 목록

```
+----------------------------------------------------------------------+
| 메인 포털                                              [테마] [로그아웃]|
+----------------------------------------------------------------------+
| [뒤로] 데이터 요청                                                    |
+----------------------------------------------------------------------+
| 검색어 [        ] 시작일 [        ] 종료일 [        ] 분류 [전체 v]   |
| 사용자 [이름 검색] (팀장·관리자·슈퍼만)  [검색] [초기화]              |
+----------------------------------------------------------------------+
| 총 N건                                                               |
+----+--------+--------+----------+----------+------+--------+--------+
|순번|사용자명|요청 IP |요청일시  |레이어명  |...   |승인상태|다운로드|
+----+--------+--------+----------+----------+------+--------+--------+
| 1  |홍길동  |1.2.3.4 |2026-...  |도로대장  |...   |승인    | [다운] |
+----+--------+--------+----------+----------+------+--------+--------+
```

#### 설명

1. 일반 사용자는 본인 요청만 보이고 사용자 검색란이 없다.
2. 팀장은 같은 부서 팀원 요청까지 보이고 사용자 검색란이 있다.
3. 관리자·슈퍼는 전체 요청과 사용자 검색란을 쓴다.
4. 승인된 건만 다운로드할 수 있다.

#### 확인사항

1. 일반 계정으로 로그인하면 사용자 검색란이 보이지 않아야 한다.
2. 팀장 계정은 같은 부서 팀원 요청이 목록에 나와야 한다.
3. 다른 부서 요청은 팀장 목록에 나오지 않아야 한다.
4. 관리자·슈퍼는 전체 요청이 보여야 한다.

### DR-02 데이터 요청 승인

```
+----------------------------------------------------------------------+
| 메인 포털                                              [테마] [로그아웃]|
+----------------------------------------------------------------------+
| [뒤로] 데이터 요청 승인                                               |
+----------------------------------------------------------------------+
| 검색어 [        ] 시작일 [        ] 종료일 [        ] 분류 [전체 v]   |
| 사용자 [이름 검색] 승인상태 [대기 v]  [검색] [초기화]                 |
+----------------------------------------------------------------------+
| 총 N건                                                               |
+----+--------+----------+----------+------+--------+--------+--------+
|순번|사용자명|요청일시  |레이어명  |분류 |승인상태|승인주체|[승인][반려]|
+----+--------+----------+----------+------+--------+--------+--------+
| 1  |홍길동  |2026-...  |도로대장  |SHP   |진행중  |팀장    |[승인][반려]|
+----+--------+----------+----------+------+--------+--------+--------+
```

#### 설명

1. 메인 포털에 «데이터 요청 승인» 메뉴로 들어간다.
2. 검색 조건은 데이터 요청과 같고, 승인상태는 기본이 대기다.
3. 팀장은 승인주체가 팀장인 같은 부서 요청만 본다.
4. 관리자·슈퍼는 전체 요청을 보며 대기 건에 승인·반려을 한다.
5. 일반 사용자는 이 화면에 들어오면 권한 없음 안내만 본다.

#### 확인사항

1. 승인상태 기본값이 대기여야 한다.
2. 팀장 승인 대기 건은 해당 부서 팀장 화면에만 보여야 한다.
3. 관리자 승인 대기 건은 팀장 화면에 나오지 않아야 한다.
4. 승인·반려 후 목록 상태가 바뀌어야 한다.
5. 새 테이블 없이 기존 요청 이력이 갱신되어야 한다.
