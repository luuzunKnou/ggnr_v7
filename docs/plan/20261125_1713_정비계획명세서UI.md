# 작업계획서

2026-11-25 | dev.strcat | 정비계획 명세서 UI 정리

## 개발목표

중기 정비계획 명세서에서 연차 입력은 숫자와 소수점만 받고 칸 테두리를 없앤다. 시설명·위치는 관리번호로 시설을 찾아 표시하고, 전체 정비계획은 중기 계와 같게 맞춘다. 상태 열을 빼 헤더·본문 세로선을 맞추고, 연도 등록은 모달로 열며 엑셀은 내려받기만 둔다.

## 플로우차트

```
정비계획 → 연도 등록(모달) → 중기 연차 입력 → 중기 계·전체 반영 → 엑셀 다운
```

## 화면설계

### PLAN-SHEET-01 정비계획 명세서

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 사이드바 │ 검색                                              [지도]      │
│          │ ┌──────────────────────────────────────────────────────────┐ │
│ 후보지   │ │ 정비계획  중기 정비계획 명세서    [연도 등록] [엑셀] [X] │ │
│ 안전점검 │ ├──────────────────────────────────────────────────────────┤ │
│ 정비계획 │ │ 읍면 │ 상태 │ 연도구간 │ 검색          대상·총사업비… │ │
│          │ ├──────────────────────────────────────────────────────────┤ │
│          │ │ 시설명칭│위치│전체│정비된│중기계│연도…│효과│5개년후│순위│ │
│          │ │ 계     │ N곳│ … │ …  │ …  │ … │ … │ …    │    │ │
│          │ │ (시설) │읍리│ … │ …  │ …  │입력│ … │ …    │ 1  │ │
│          │ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 상단 «연도 등록»을 누르면 시작·종료 연도 모달이 열린다.
2. 중기 연차 칸은 숫자와 소수점만 입력되며 칸 테두리가 보이지 않는다.
3. 시설명·위치는 관리번호로 시설을 조회해 채우고, 전체 정비계획은 중기 계와 같다.
4. 상태 열은 없고, 엑셀은 내려받기만 있다.

#### 확인사항

1. 연차 칸에 문자 입력 시 반영되지 않아야 한다.
2. 헤더와 본문 세로선이 맞아야 한다.
3. 연도 등록이 모달로 열려야 한다.
4. 엑셀 가져오기 버튼이 없어야 한다.

### PLAN-SHEET-02 연도 등록 모달

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 사이드바 │                                              [지도]           │
│          │         ┌──────────────────────────┐                          │
│          │         │ 중기 연도구간 등록       │                          │
│          │         │ 시작연도 [    ]          │                          │
│          │         │ 종료연도 [    ]          │                          │
│          │         │          [취소] [등록]   │                          │
│          │         └──────────────────────────┘                          │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 설명

1. 시작·종료 연도를 넣고 등록하면 연도구간 목록에 추가된다.
2. 이미 같은 구간이 있으면 추가하지 않는다.
3. 등록 후 해당 구간이 선택된다.

#### 확인사항

1. 잘못된 연도면 안내가 나와야 한다.
2. 등록 후 표 머리연도가 바뀌어야 한다.
