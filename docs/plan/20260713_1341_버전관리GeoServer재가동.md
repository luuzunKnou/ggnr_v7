## 개발목표

버전관리로 최신 소스를 적용할 때 GeoServer가 떠 있으면 JDK 파일이 잠겨 덮어쓰기가 실패한다. 적용 시 항상 GeoServer를 먼저 끄고 소스를 반영한 뒤, 앱 재시작 예약 직전에 다시 켠다. 개발자 모드의 기동·중지와 같은 방식을 쓴다.

## 플로우차트

```
버전관리 적용 → GeoServer 중지 → 소스 복사 → GeoServer 기동 → 앱 재시작 예약
```


#### 설명

1. 최신 소스 적용은 재시작 설정과 관계없이 GeoServer를 중지한 뒤 소스를 복사한다.
2. 복사와 재시작 신호 기록 후, 앱 재시작 예약 직전에 GeoServer를 다시 기동한다.
3. 적용 결과에 GeoServer 중지·기동 안내 한 줄이 표시된다.
4. GeoServer가 이미 꺼져 있거나 스크립트가 없어도 소스 적용은 계속된다.

#### 확인사항

1. GeoServer가 떠 있는 상태에서 적용해도 파일 잠김으로 복사가 실패하지 않아야 한다.
2. 적용 후 GeoServer가 다시 기동되어야 한다.
3. 재시작을 끄거나 «재시작 안 함»이어도 GeoServer는 중지 후 기동되어야 한다.
4. 적용 결과에 GeoServer 안내 문구가 보여야 한다.
