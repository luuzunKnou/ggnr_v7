## 개발목표

하수도 행정 업무지원의 사이드 메뉴에 관망조회를 추가한다. 상수 관망조회와 같이 왼쪽에서 레이어를 켜고, 필터·목록·상세·지도 클릭·구역·단면도·내려받기·현황을 한 화면에서 쓴다. 조회만 하며 저장은 하지 않는다.

## 플로우차트

하수도 행정 → 관망조회 → 레이어·필터 → 시설목록 ⇄ 상세 → 구역·단면도·내려받기

## 화면설계

### MAP-SWL-NET-01 하수 관망조회

```
┌──────────────────────────────────────────────────────────────┐
│ 사이드 │ 관망조회                          │ 시설목록        │ 지도 │
│ 관망조회│ 관로 배수설비 하수도시설 기타      │ 화면에 보이는   │      │
│ 데이터  │ 하수관거 측구 하수연결관           │ 시설만          │      │
│ 변동이력│ 연도 관경 재질 통합검색            │ 하수관거 · n건  │      │
│        │ 관경별 연장 재질별 연장 시설 개수   │ 번호 구경 재질  │      │
│        │ 구역설정 다운로드 단면도 Excel     │                 │      │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. 사이드에서 관망조회를 누르면 왼쪽 패널과 시설목록이 열린다.
2. 관로, 배수설비, 하수도시설, 기타 탭에서 시설을 켜고 끈다.
3. 연도·관경·재질·검색과 화면 범위로 목록이 바뀌고, 행이나 지도 클릭으로 상세가 열린다.
4. 구역설정은 지도에 사각형을 그려 그 안의 시설만 본다.
5. 단면도는 선택한 관로를 보여주고, 엑셀과 다운로드는 현재 목록을 파일로 받는다.

#### 확인사항

1. 하수도 행정 메뉴 맨 앞에 관망조회가 보여야 한다.
2. 처음에는 하수관거만 켜져 있어야 한다.
3. 하수도시설 탭에 맨홀, 물받이, 토구, 환기구, 펌프장, 처리장이 보여야 한다.
4. 목록 행을 누르면 상세에 구분과 관리번호가 나와야 한다.
5. 관망조회를 닫으면 패널이 지도에 남지 않아야 한다.
