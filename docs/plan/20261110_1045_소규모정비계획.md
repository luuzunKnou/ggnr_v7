# 작업계획서

2026-11-10 | dev.strcat | docs/brief/20261110_1027_소규모정비계획예산공사.md (2단계: 정비계획)

## 개발목표

소규모 공공시설 부서업무에 «정비계획»을 추가한다. 위험시설을 정비계획에 넣고, 시설별 분석에서 개요·정비내용·사업비와 보상비·기본평가·부가평가·결과 순서로 값을 채우면 총점·순위·단계·연차가 계산된다. 값마다 자동·기본값·수기·실적·미입력 출처를 보여 주고, 미입력이 있어도 계산되는 만큼 계산해 완성도와 «참고용 추정치»로 표시한다.

목록은 중기계획 명세서 형태(순위·시설명·유형·위치·사업량·사업비·단계·연차·상태·완성도)이며 대상 수·총사업비·1·2단계 사업비·평균 완성도를 위에 보여 준다. 엑셀은 명세서 시트와 읍면별 종합표 시트로 내려받는다. 연간 예산 한도를 넣으면 1단계 시설을 순위대로 1~5차년에 배분하고, 시설별로 연차를 바꿀 수 있다.

기준값(공종 단가·보상배율·배점 구간·선택 점수·동점 순서·피해 항목 지원기준지수·가중치·설정값)은 마스터 스키마 시드 값을 그대로 옮긴 기준 자료에서 읽는다. 설계서의 확인 필요 항목(최종순위 조정 규칙, 사망·부상 반영, 보상배율 방식, 1단계 기준 등)은 설정값으로 두고 결과 화면 산출근거에 «확인 필요»로 표시한다. 예시 자료 단계이므로 위험시설 10곳으로 정비계획을 미리 만들어 두고, 저장은 새로고침 전까지만 유지된다. 편입 필지는 지적 교차 대신 예시 필지로 채운다.

후보지 상세에는 정비계획에 들어간 시설의 상태·순위·사업비를 보여 준다. 공사 실적 반영(진행·완료 상태, 실제 공사비)은 예산·공사 단계에서 연결한다.

## 플로우차트

```
정비계획 목록 → (추가) → 위험시설 선택 → 시설별 분석
정비계획 목록 → (행 클릭) → 시설별 분석: 개요 → 정비내용 → 사업비·보상 → 기본평가 → 부가평가 → 결과 → (확정 요청 → 승인)
정비계획 목록 → 연차 배분 → 목록
```

#### 설명

1. 목록은 순위 순으로 보이고, 머리줄을 눌러 다른 열로 정렬할 수 있다.
2. «분석 미완료»를 고르면 완성도가 100% 미만인 시설만 보인다.
3. 위쪽 요약에 대상 수·총사업비·1·2단계 사업비·평균 완성도를 보여 준다.
4. 행을 누르면 오른쪽에 시설별 분석이 열리고 지도에서 그 시설로 이동한다.
5. «엑셀»은 명세서(1~5차년·5개년 후 사업비, 사업효과 포함)와 읍면별 종합표를 시트로 나눠 내려받는다.

#### 확인사항

1. 순위·단계·연차가 시설별 분석 결과와 같아야 한다.
2. 읍면·상태·검색 조건이 함께 걸려야 한다.
3. 엑셀에 명세서와 읍면별 종합표 시트가 있어야 한다.

#### 설명

1. 평가구분이 위험이면서 정비계획에 없는 시설만 나온다.
2. 추가하면 추정 상태의 1판 계획이 만들어지고 시설별 분석의 개요 단계가 열린다.

#### 확인사항

1. 이미 계획에 있는 시설은 목록에 나오지 않아야 한다.
2. 안전점검에서 위험으로 바뀐 시설이 이 목록에 나와야 한다.

### SPP-03 시설별 분석

```
┌──────┬──────────────┬────────────────────────────────────────────────────┐
│사이드│ 정비계획 목록 │ [세천] 봉평리 세천 · 1판 · 추정                    ✕ │
│ 바   │              │ 법령·고시 기준 개략 산정이며 확정값이 아님          │
│      │              │┌단계─────┐┌ 정비내용 ─────────────────┐┌ 요약 ─────┐│
│      │              ││개요     ││ [공종 제안] [+공종]        ││총점 62/100 ││
│      │              ││정비내용 ││ 공종     수량 단가 금액 출처││잠정        ││

│      │              ││기본평가 ││         임시 단가          ││사업비 57.7 ││
│      │              ││부가평가 ││ 부속 시설                  ││공사 57.7   ││
│      │              ││결과     ││ 이름 위치 L B 사업비        ││보상 0      ││
│      │              │└─────────┘│ [이전] [임시저장] [다음]    ││1단계 · 2차 ││
│      │              │           └────────────────────────────┘│완성도 62%  ││

│      │              │                                          │참고용 추정치│└
```

#### 설명

1. 왼쪽 단계 목록에서 개요·정비내용·사업비와 보상·기본평가·부가평가·결과로 이동하며, 단계마다 미입력이 있으면 표시가 붙는다.
2. 가운데에서 값을 넣고, 값 옆에 자동·기본값·수기·실적·미입력 표시와 계산식 안내를 붙인다.
3. 오른쪽 요약은 총점·예상 순위·사업비(공사·보상·기타)·단계·연차·완성도·수기 입력 필요 건수를 늘 보여 준다.
4. 개요는 시설 제원·최근 점검 결과·위험 판정 근거와 위험시설 지정일을 보여 주고, 지정일을 고칠 수 있다.
5. 정비내용은 시설 유형에 맞는 공종과 수량(시설 연장 등)을 제안하고, 공종·수량을 고치면 수기로 바뀐다. 선형개선처럼 단가로 못 구하는 공종은 금액을 직접 넣는다.
6. 사업비·보상은 공사비 합계, 편입 필지(지목·편입면적·공시지가·보상배율·보상 제외), 건물·영업보상·설계비 등 기타 금액을 넣어 사업비를 계산한다.
7. «임시저장»을 눌러야 계획에 반영되고, 저장하지 않고 닫으면 확인을 묻는다.

#### 확인사항

1. 공종 수량·단가를 바꾸면 공사비·사업비·요약이 바로 바뀌어야 한다.
2. 임시 단가 공종에는 «임시 단가» 표시가 보여야 한다.
3. 보상 제외 필지는 보상비가 0이어야 한다.
4. 미입력 항목은 미입력 표시와 함께 요약의 수기 입력 필요 건수에 세어져야 한다.

### SPP-04 기본평가·부가평가

```
┌──────┬──────────────┬────────────────────────────────────────────────────┐
│사이드│ 정비계획 목록 │ [세천] 봉평리 세천 · 1판 · 추정                    ✕ │
│ 바   │              │┌단계─────┐┌ 기본평가 ─────────────────┐┌ 요약 ─────┐│
│      │              ││         ││ 비용-편익비  B/C [____] 15/15 기본값││        ││
│      │              ││         ││ 피해이력지수 [지수 입력][항목 지수][물량]││        ││
│      │              ││         ││   발생일 항목 물량  지수   10.2/25 수기││        ││
│      │              ││         ││ 재해위험도  [가등급▼][없음▼]   20/30 수기││        ││
│      │              ││         ││ 주민불편도  인구[__] 면적[__]ha 12/20 자동││        ││
│      │              ││         ││ 경과년수    지정일 2020-12-31  8/10 자동││        ││
│      │              │└─────────┘└────────────────────────────┘└───────────┘│
└──────┴──────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 비용-편익비는 값을 넣으면 구간 점수, 비워 두면 기본 점수(15점)를 쓴다.
2. 피해이력은 지수 직접 입력·항목별 재난지수·항목과 물량 세 가지 방식 중 하나로 넣고, 최근 5년만 합산해 점수로 바꾼다. «피해 없음»을 고르면 0점이다.
3. 재해위험도는 위험등급과 인명피해를 골라 합산하며 최대 30점이다.
4. 주민불편도는 거주인구와 영향 면적으로 명/ha를 계산해 구간 점수를, 경과년수는 위험시설 지정일로 구간 점수를 자동으로 매긴다.
5. 부가평가는 지속성·정책성·계획성을 1·0으로 고르며, 각 항목의 1·0 기준 문구를 함께 보여 준다.

#### 확인사항

1. 각 항목 점수가 배점을 넘지 않아야 한다.
2. 피해이력은 지정 기간 밖 발생일을 합산하지 않아야 한다.
3. 위험등급을 고르지 않으면 재해위험도가 미입력으로 보여야 한다.

```

│      │              ││         ││ 산출근거 단가·고시·배율·설정값          ││        ││
│      │              ││         ││ 변경 이력                              ││        ││
│      │              ││         ││ [확정 요청] [승인] [반려] [새 판 수정] ││        ││

└──────┴──────────────┴────────────────────────────────────────────────────┘
```

#### 설명

1. 총점·기초순위·최종순위·단계를 보여 주고, 연차와 사업효과를 넣는다.
2. 저장된 계획과 지금 입력을 비교해 순위 변동과 그 때문에 밀리는 시설을 보여 준다.
3. 후속 절차 체크리스트와 산출근거(적용 단가·출처·고시 번호·보상배율·설정값·확인 필요 항목)를 보여 준다.
4. 추정→검토(확정 요청)→확정(승인) 흐름이며, 검토에서 반려하면 추정으로 돌아간다. 확정된 계획은 읽기 전용이고 «새 판으로 수정»하면 다음 판이 추정으로 만들어지며 이전 판은 보관된다.
5. 저장·상태 변경은 변경 이력에 남는다.

#### 확인사항

1. 확정된 계획은 값을 고칠 수 없어야 한다.
2. 새 판을 만들면 판 번호가 하나 늘고 이전 판 값을 볼 수 있어야 한다.
3. 순위 변동 미리보기가 저장 전 입력 기준으로 바뀌어야 한다.

### SPP-06 연차 배분

```
┌──────┬──────────────────────────────────────────────────────┬────────────┐
│사이드│ 정비계획 목록                                          │            │
│ 바   │        ┌ 연차 배분 ──────────────────────────┐        │            │
│      │        │ 연간 예산 한도 [____] 백만원            │        │   지  도  │
│      │        │ 1차 320 · 2차 298 · 3차 … · 5개년 후 2곳 │        │            │
│      │        │ 직접 정한 연차 유지 ☑                   │        │            │
│      │        │                          [배분] [취소]│        │            │
│      │        └───────────────────────────────────────┘        │            │
└──────┴──────────────────────────────────────────────────────┴────────────┘
```

#### 설명

1. 1단계 시설을 최종순위 순으로 연간 한도 안에서 1차년부터 채우고, 한 시설의 사업비는 한 연차에 모두 넣는다.
2. 5차년을 넘거나 2단계인 시설은 5개년 후로 둔다.
3. 배분 전에 연차별 합계와 5개년 후 시설 수를 미리 보여 준다.

#### 확인사항
