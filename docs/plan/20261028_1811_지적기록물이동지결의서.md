## 개발목표

이동지결의서는 종류를 이동지결의서로 보이게 한다. 자료 폴더에 있는 장은 지번이 비어 있어도 목록에 나오게 한다.

## 플로우차트

```
자료 폴더 → 이동지결의서 목록 → (종류 이동지결의서) → 상세
```
