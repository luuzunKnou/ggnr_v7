## 개발목표

공간정보조회에서 «지적기준점»을 열면 종류별 목록과 지도 점이 보이고, 고르면 상세만 조회한다. 등록·편집·점검은 하지 않으며, 안동 일원 임시 자료로 화면을 맞춘다.

## 플로우차트

```
지도 → 지적기준점 목록 → (행·지도 선택) → 상세
```

## 화면설계

### MAP-CCP-01 지적기준점 목록

```
┌────┬──────────────────┬─────────────────────────────┐
│ 로 │ 지적기준점     ✕ │                             │
│ 고 │ [전체][삼각]…    │                             │
│ 메 │ 검색             │            지도             │
│ 뉴 │ 번호 종류 소재지 │   · 빨강·주황·파랑 점       │
│────│ 행…              │                             │
│ 나 │                  │                             │
│ 정 │ n건              │                             │
│ 보 │                  │                             │
└────┴──────────────────┴─────────────────────────────┘
```

#### 설명

1. 사이드바에서 «지적기준점»을 고르면 왼쪽 목록이 열린다.
2. 종류 탭으로 전체·지적삼각점·지적삼각보조점·지적도근점을 가른다.
3. 검색으로 점번호·소재지·위치설명을 찾는다.
4. 행을 누르면 상세가 열리고 지도가 그 점으로 간다.
5. 지도 점 색은 종류와 같다.

#### 확인사항

1. 지적기준점 메뉴를 고르면 목록이 열려야 한다.
2. 종류 탭을 바꾸면 목록과 지도 점이 같이 걸러져야 한다.
3. 행을 누르면 상세가 옆에 열려야 한다.
4. 지도에서 점을 눌러도 상세가 열려야 한다.

### MAP-CCP-02 지적기준점 상세

```
┌────┬──────────────────┬──────────────┬──────────────┐
│ 로 │ 지적기준점       │ 상세      ✕ │              │
│ 고 │ 목록             │ 번호·종류    │    지도      │
│ 메 │                  │ 좌표·표고    │              │
│ 뉴 │                  │ 소재지·설명  │              │
│────│                  │ 관리기관     │              │
│ 나 │                  │ 비고         │              │
│ 정 │                  │              │              │
│ 보 │                  │              │              │
└────┴──────────────────┴──────────────┴──────────────┘
```

#### 설명

1. 점번호·종류·평면좌표·표고·소재지·위치설명·관리기관·설치일·비고를 읽기만 한다.
2. 목록을 닫지 않고 상세만 닫을 수 있다.
3. 저장·편집 버튼은 없다.

#### 확인사항

1. 선택한 점의 속성이 보여야 한다.
2. 상세만 닫아도 목록과 지도 점은 남아 있어야 한다.
3. 목록을 닫으면 상세와 지도 점도 사라져야 한다.
