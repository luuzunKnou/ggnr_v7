## 개발목표

촬영요청에서 파노라마로 승인·등록하면 사진·동영상과 같은 경로로 폴더를 만들고 이미지를 올린다. 지도 «파노라마» 메뉴는 목업 대신 서버 목록을 쓰고, 추가·삭제·미리보기를 제공한다. 타일 변환은 없다.

## 플로우차트

```
촬영요청 승인 → 폴더 생성 → 파노라마 업로드 → 파노라마 목록 → 파일 선택 미리보기
```

## 화면설계

### MAP-PANO-01 파노라마 목록·상세

```
┌──────────────────────────────────────────────────────────────┐
│ [드론영상] [파노라마] [사진,동영상] [항공영상]                  │
│ ┌────────────┐ ┌──────────────────┐                          │
│ │ 작업단위목록 │ │ 작업단위 상세     │         (지도)           │
│ │ 울산 동구…  │ │ 파일목록 [추가]   │                          │
│ │ …          │ │ 이미지1.jpg      │                          │
│ └────────────┘ └──────────────────┘                          │
└──────────────────────────────────────────────────────────────┘
```

#### 설명

1. «파노라마»를 선택하면 서버에 등록된 작업단위 목록이 보인다.
2. 상세에서 파일을 추가·삭제할 수 있다.
3. 파일을 선택하면 지도 위에 미리보기가 열린다.

#### 확인사항

1. 목업 안동·울산 고정 목록이 아닌 실제 등록 건만 보여야 한다.
2. 변환완료 체크(드론영상)와 달리 업로드완료면 바로 선택·미리보기가 되어야 한다.
3. 삭제 후 목록에서 사라져야 한다.

### MAP-PANO-02 촬영요청 등록

```
┌──────────────────────────────────────┐
│ 촬영요청 상세 (파노라마)              │
│ [비행기록부] [파일 업로드]            │
└──────────────────────────────────────┘
```

#### 설명

1. 승인된 파노라마 요청에서 파일 업로드로 폴더를 만든다.
2. 폴더 생성 직후 파일 선택 창이 이어진다.
3. 업로드가 끝나면 요청이 등록 완료로 바뀐다.

#### 확인사항

1. 파노라마 요청에서도 사진·동영상과 같이 파일 업로드가 열려야 한다.
2. 드론영상 TIF 업로드와 혼동되지 않아야 한다.
