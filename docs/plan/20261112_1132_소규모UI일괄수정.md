## 개발목표

안전점검 목록·상세 너비를 줄이고 점검을 첨부 등록·보기로 바꾼다. 예시 자료를 맞추고, 미리보기 페이지·스크롤을 고친다. 정비계획은 예산 선택 칸을 넓히고 분석은 행 클릭으로 바로 시작하며 추정도 예산에 넣는다. 피해이력은 모달로 연다.

## 플로우차트

```
안전점검 목록 → 보고서 상세 → 시설 점검(첨부) ⇄ 점검 등록
정비계획 → (행 선택) → 예산 계획 / (분석 행 클릭) → 분석
후보지 → 피해이력 → 상세 모달
```

## 화면설계

### SPI-01 안전점검 공간·첨부

```
┌──────────┬────────────────────────────┐
│ 보고서   │ 보고서 제목         [닫기] │
│ 목록     │ [보고서][엑셀][정비계획]   │
│(좁게)    │ ▶ 보고서 개요             │
│          │ 점검 대상 · 필터          │
│          │ 시설명 일자 등급 …        │
└──────────┴────────────────────────────┘
```

#### 설명

1. 목록·상세 기본 너비를 후보지와 비슷하게 줄인다.
2. 보고서 개요는 기본으로 접혀 있다.
3. 점검 등록은 파일·점검일·점검자·등급·비고만 받는다.
4. 시설 점검 보기에는 평가표 대신 요약과 첨부 미리보기를 둔다.

#### 확인사항

1. 목록·상세가 이전보다 좁게 열려야 한다.
2. 개요가 처음부터 접혀 있어야 한다.
3. 점검 등록에 평가표 점수 칸이 없어야 한다.
4. 점검 보기에 첨부 미리보기가 나와야 한다.

### SPP-01 정비계획 선택·분석·예산

```
┌────────────────────────────────────────┐
│ 정비계획  … [분석][예산 계획]          │
│ □ 시설명 …                             │
│ (체크 칸 전체 클릭으로 선택)           │
└────────────────────────────────────────┘
```

#### 설명

1. 예산 선택은 체크 칸 전체를 눌러도 된다.
2. 추정 시설도 예산 계획에 넣을 수 있고, 검토만 뺀다.
3. 분석할 시설 목록에서 행을 누르면 바로 분석이 열린다.

#### 확인사항

1. 체크 칸을 눌러도 선택이 바뀌어야 한다.
2. 추정 행을 골라 예산 계획이 열려야 한다.
3. 검토 행은 예산 선택이 안 되어야 한다.
4. 분석 시설 행을 누르면 분석 시작을 다시 누르지 않아도 된다.

### CAND-01 피해이력 모달

```
┌──────────┬────────────────────────────┐
│ 후보지   │ … 피해이력 탭 …            │
│          │ 발생일 항목 물량           │
│          │ (행 클릭 → 모달)           │
└──────────┴────────────────────────────┘
```

#### 설명

1. 피해 행을 누르면 아래에 펼치지 않고 모달이 열린다.
2. 등록 모달과 같은 형태로 수정·삭제한다.

#### 확인사항

1. 행 클릭 시 모달이 열려야 한다.
2. 목록 아래에 편집 칸이 펼쳐지지 않아야 한다.
