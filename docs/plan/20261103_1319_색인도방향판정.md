## 개발목표

하천기본계획 색인도 도면(PDF)의 방향을, 색인도 칸 안의 하천 모양(지도)과 도면 속 하천 모양(하늘색 수면)을 비교해 서버에서 한 번 판정하고 색인도별로 저장한다. 상세 화면의 썸네일·전체화면은 저장된 방향을 그대로 써서 항상 같은 방향으로 보인다.

개발 콘솔에 «색인도 방향» 화면을 두어, 지방하천·소하천 색인도 전체를 한 번에 판정하고 진행 상황을 본다. 확신도가 낮은 장부터 지도 하천 모양과 도면을 나란히 보며 네 방향 중 맞는 방향으로 바로잡아 확정한다. 확정한 장은 다시 판정해도 바뀌지 않는다. 원본 PDF는 수정하지 않는다.

## 플로우차트

```
개발 콘솔 → 색인도 방향 → (전체 판정) → 검토 목록 ⇄ 방향 확정 → 기본계획 상세 색인도
```

## 화면설계

### DEV-IDXORI-01 색인도 방향 검토

```
┌────────┬──────────────────────────────────────────────────────────────────────────┐
│ 개발   │ 색인도 방향                                                              │
│ 콘솔   │ [지방하천] [소하천]        판정 312/439 · 검토 필요 18   [미판정만 판정] [전체 다시 판정] │
│        ├──────────────────────────────────────────────────────────────────────────┤
│ 데이터 │ [전체 ▾] [검색: 하천명·파일명]                                           │
│ 관리   ├──────────┬──────────┬──────────────┬────────────┬─────────────────────────┤
│  ...   │ 하천     │ 파일     │ 지도 하천 모양 │ 도면(판정)  │ 방향                   │
│ 색인도 │ 왕피천   │ 왕피01   │ ┌──────────┐ │ ┌────────┐ │ 270° · 확신 0.42 · 모양 │
│ 방향   │          │          │ │  ≈≈≈     │ │ │ 도면   │ │ [0°][90°][180°][270°]   │
│        │          │          │ └──────────┘ │ └────────┘ │ 확정                    │
│        │ 남대천   │ 남대06   │ ...          │ ...        │ 90° · 확신 0.05 · 검토   │
└────────┴──────────┴──────────┴──────────────┴────────────┴─────────────────────────┘
```

#### 설명

1. 지방하천·소하천을 골라 색인도 전체 목록을 확신도가 낮은 순으로 본다.
2. «미판정만 판정»은 결과가 없는 장만, «전체 다시 판정»은 사람이 확정하지 않은 장을 모두 다시 판정하며 진행 건수가 보인다.
3. 각 줄에 지도 하천 모양과 판정 방향으로 돌린 도면이 나란히 보이고, 방향·확신도·판정 방법(모양 비교/파일 회전값/판정 불가)이 표시된다.
4. 네 방향 버튼으로 바로잡으면 그 장은 사람 확정이 되고 도면이 바로 다시 그려진다.
5. «검토 필요»만 골라 볼 수 있다.

#### 확인사항

1. 전체 판정 중에도 다른 화면이 느려지지 않아야 한다.
2. 왕피01은 판정 결과가 270°여야 한다.
3. 방향 버튼으로 확정한 장은 다시 판정해도 바뀌지 않아야 한다.
4. 확신도가 낮은 장이 목록 위쪽에 와야 한다.

### MAP-RIVPLAN-21 기본계획 색인도

```
┌──┬──────────────────────┬──────────────────────────────────────┬──────────────────┐
│  │ 지방하천 기본계획     │ 왕피천                     [보고서] ✕ │                  │
│사│ ...                   │ [하천구역][색인도][구조물도]...       │                  │
│이│                       │ 색인도                             ‹ │      지  도      │
│드│                       │ ┌──────────────────────────────────┐ │                  │
│바│                       │ │  저장된 방향으로 돌린 색인도 도면 │ │                  │
│  │                       │ └──────────────────────────────────┘ │                  │
│  │                       │ 상세목록                             │                  │
└──┴──────────────────────┴──────────────────────────────────────┴──────────────────┘
```

#### 설명

1. 색인도 썸네일과 전체화면은 저장된 방향이 있으면 그 방향으로 보인다.
2. 저장된 방향이 없으면 지금처럼 화면에서 방향을 추정한다.

#### 확인사항

1. 썸네일과 전체화면 방향이 같아야 한다.
2. 판정 결과가 있는 장은 지도 하천 모양과 같은 방향이어야 한다.
