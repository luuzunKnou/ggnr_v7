# 백로그 — 계량기위치 보고서 지도 캡처

2026-11-03 | 계량기위치

## 현황

- **클라이언트 숨김 지도**로 구역 캡처 (메인 지도 이동 없음).
- 배경: 인쇄와 동일 Canvas 타일/자체정사(`/api/2dtiles`) — 브라우저가 로드 (폐쇄망 적합).
- 지적: GeoServer jijuk + PNU CQL (`geoserverWmsImageLoadFunction`).
- 계량기: 점 벡터.
- 숨김 host는 `left:-9999` + opacity 1 (opacity:0 타일 미렌더 회피).
- 서버 VWorld 합성 API는 폐쇄망 비적합으로 **보류**.

## 남은 과제

1. 폐쇄망에서 외부 배경(VWorld 등)만 선택된 경우 타일 실패 → 자체정사 유도·안내.
2. 대량 구역 순차 캡처 시간.
3. (선택) 내부망 전용: GeoServer GetMap만으로 지적+점 합성 API.
